# AI超级导演成长证据账本

这份账本只记录能改变下一次输出的成长。普通整理、单纯链接修复或没有新输出动作的改动，不写入这里。

## 2026-06-08

### 小说/剧情导入与全类型影视改编

- 主短板：客户交付 / Seedance 稳定。
- 为什么选它：用户要求导入小说或剧情后，能剖析并转成短剧、短片、电视剧、电影、动漫等成片方案。
- 本轮动作：新增小说/剧情导入与全类型影视改编引擎，并接入 README 和总索引。
- 新增输出动作：先找原文心脏，再选改编形态，把心理描写改成动作、站位、声音、反应镜头和 Seedance 提示词。
- 成长证据：入口证据 + 模板证据。
- 分数：4。
- 退化风险：长文本改编容易变成剧情概述，下一轮要检查第一帧和可拍主场面。
- 下一轮相反训练：第一判断。

### 提示词人味优化与活人导演转译

- 主短板：人物表演 / Seedance 稳定。
- 为什么选它：提示词容易只变得“更专业”，但人物不活、抽象情绪多、Seedance 不一定能执行。
- 本轮动作：新增提示词人味优化与活人导演转译器，并接入 README 和总索引。
- 新增输出动作：每条最终提示词前加入人味压缩行，把抽象情绪改成外在任务、防御动作、泄露点和收回动作。
- 成长证据：入口证据 + 模板证据 + 禁用证据。
- 分数：4。
- 退化风险：人味过强会让提示词变长，下一轮要检查单镜任务预算。
- 下一轮相反训练：Seedance 稳定。

### 成长仪表盘与训练排期器

- 主短板：第一判断。
- 为什么选它：“继续成长”这类短指令需要先判断本轮练什么，而不是随机新增能力。
- 本轮动作：新增成长仪表盘与训练排期器，并接入 README 和总索引。
- 新增输出动作：先从 8 个维度选一个主短板，再写保留、舍掉、第一刀、训练题、通过标准和下一轮相反训练。
- 成长证据：入口证据 + 模板证据。
- 分数：4。
- 退化风险：如果只排期不入账，下一轮仍可能忘记为什么练这一块。
- 下一轮相反训练：成长证据。

### 成长证据账本与能力增量闭环

### 短需求第一判断训练样本库

- 主短板：第一判断 / 现场输出速度。
- 为什么选它：上一轮成长证据补足后，下一步要让一句话需求能快速拍板，不先展开能力目录。
- 本轮动作：新增短需求第一判断训练样本库，并接入 README 和总索引。
- 新增输出动作：面对 30 类高频短需求，4 行内先写我会这样拍、保留、舍掉、第一刀，再进入分镜、Seedance、客户或发布专项。
- 成长证据：样本库证据 + 入口证据 + 回归题证据。
- 分数：4。
- 退化风险：拍板太快可能压缩客户交付细节；进入客户场合时仍要切到客户版摘要。
- 下一轮相反训练：客户交付压缩 / 证据链。

### 客户提案证据链验钞增强

- 主短板：客户交付压缩 / 证据链。
- 为什么选它：短需求拍板变快后，客户版必须能一眼看懂商业价值，并证明不是只有漂亮概念。
- 本轮动作：增强客户提案三层压缩表达协议，补客户证据链验钞和一页客户版骨架，并补总索引精确路由。
- 新增输出动作：客户版先写客户相信句，必须证明“动作 -> 变化 -> 确认”，一页客户版只保一个主价值、第一帧、证明链、记忆点、风险控制和客户需确认变量。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：客户版过度压缩可能丢执行细节；确认后必须展开导演版细案和执行版提示词。
- 下一轮相反训练：Seedance 执行稳定 / 单镜任务预算。
### Seedance 单镜任务预算计分闸门增强

- 主短板：Seedance 执行稳定 / 单镜任务预算。
- 为什么选它：客户版和导演版都变强后，最终 Seedance 提示词更容易一镜塞入口型、产品证明、群像、特效、运镜、文字和多参考，生成前必须有硬预算。
- 本轮动作：增强 Seedance 提示词终检与负面约束压缩器，补预算计分闸门和过载自动拆法，并接入 README 与总索引路由。
- 新增输出动作：按 0.5 / 1 / 2 / 3 分计变量，2 分变量一镜最多保一个，3 分变量默认后期、拆镜或替代；过载时必须写第 1 镜保什么、第 2 镜接什么、哪些交给后期/画外声。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：过度保守会削弱记忆点和第一帧抓力，不能把所有高光都拆碎。
- 下一轮相反训练：记忆复述 / 封面停留点。

### 发布前封面停留点与三秒复述增强

- 主短板：记忆复述 / 封面停留点。
- 为什么选它：上一轮把单镜预算收紧后，成片更稳但可能变得过度保守；发布前必须证明陌生观众愿意停、三秒内看懂、看完能讲给朋友。
- 本轮动作：增强发布前可复述、可截图与传播记忆测试协议，补封面停留点验钞和三秒复述压力测试，并接入 README 与总索引路由。
- 新增输出动作：封面必须写第一眼主体、停留问题、标题安全区、缩小后仍可辨认的轮廓或变化；三秒复述必须写封面句、第 3 秒动作句和完整转述句。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：过度追求封面停留可能诱导标题党或牺牲作品余味；不能把“停住”误当成“夸张”。
- 下一轮相反训练：情绪余味 / 克制收束。

### 记忆复述与封面停留点增强

- 主短板：记忆复述 / 封面停留点。
- 为什么选它：上一轮强化单镜任务预算后，容易变稳但弱记忆，需要把记忆钉子反推成手机封面也能停住的画面。
- 本轮动作：增强作品记忆点、视觉母题与余味系统，补封面停留点反推、输出字段、自检和回归测试，并同步 README 与总索引。
- 新增输出动作：记忆点方案必须说明封面停留点来自主动作中点、反应停顿、结果变化或母题回收，并写清标题安全区和手机缩略图可读性。
- 成长证据：模板证据 + 回归题证据 + 入口证据。
- 分数：4。
- 退化风险：过度追求封面会牺牲成片余味，不能让标题和封面抢走记忆钉子的回收。
- 下一轮相反训练：现场输出速度 / 第一判断。

### 情绪余味与克制收束闸门增强

- 主短板：情绪余味 / 克制收束。
- 为什么选它：上一轮强化封面停留和三秒复述后，作品更容易抓人，但情感片、怀旧片和品牌微电影可能被推向标题化、金句化和过度煽情。
- 本轮动作：增强克制情感、旧物叙事与余味留白引擎，补情绪收束闸门，并接入 README 与总索引路由。
- 新增输出动作：结尾必须判断收在动作、声音、物件还是空间里，写清最后一个余味动作或状态、声音尾巴，以及必须删掉的解释性旁白、金句或大哭。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：过度克制会让短剧、广告或发布包装失去明确行动入口；进入转化或追更场景时，要保留产品证明、评论接话口或下一集问题。
- 下一轮相反训练：现场输出速度 / 第一判断。

- 退化风险：短快拍板可能让客户版、执行版变薄；当用户要客户或生成时必须立刻切到 D/E 档。

### 客户版防薄三问与 A0 转 D 档增强

- 主短板：客户交付压缩 / 证据链。
- 为什么选它：A0 四行拍板会让第一反应变快，但给客户看时不能只剩判断和口号，必须立刻补价值、证据和确认变量。

- 分数：4。
- 退化风险：客户版过度补证据可能变长；一页客户版仍然只保一个主价值，不塞完整分镜表和长提示词。

### Seedance 生成前冻结三件套增强

- 主短板：Seedance 执行稳定 / 执行版提示词。
- 为什么选它：客户版和导演版压清后，执行版最终提示词容易把预算阶段删掉的口型、文字、群像、强运镜或卖点又塞回来。
- 本轮动作：增强 Seedance 提示词终检与负面约束压缩器，补生成前冻结三件套，并同步 README 与总索引路由。
- 新增输出动作：最终提示词前必须冻结主任务、主变量和失败第一刀；确认不把已删变量塞回提示词，失败后只改一个可执行字段。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：冻结过死可能削弱第一帧抓力和记忆点；如果主变量本身不够强，先回到主镜头或记忆点系统，而不是硬跑。
- 下一轮相反训练：记忆复述 / 封面停留点。

### A0 到 D 档客户证据链切换增强

- 主短板：客户交付压缩 / 证据链。
- 为什么选它：上一轮强化 A0 四行拍板后，短需求变快，但“给客户看”不能停在轻量判断，必须补客户相信句和证明链。
- 本轮动作：增强客户提案三层压缩表达协议和输出档位切换器，补 A0 到 D 档切换门禁，并同步 README 与总索引。
- 新增输出动作：客户短需求先 4 行拍板，再立刻切 D 档，写客户相信句、证明链、一页客户版、导演版取舍和执行版最小路径。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：客户版更清楚后，执行层可能被压薄；用户确认后必须展开执行版提示词和 Seedance 风险。
- 下一轮相反训练：Seedance 执行稳定 / 执行版提示词。

### D 档到 E 档 Seedance 执行交接增强

- 主短板：Seedance 执行稳定 / 执行版提示词。
- 为什么选它：客户版确认后，不能把客户话术直接塞进提示词，必须把价值、卖点、品牌字和风险转成镜头任务、动作、后期和预算。
- 本轮动作：增强客户提案三层压缩表达协议和 Seedance 提示词终检，补 D 到 E 档执行交接卡与客户确认后执行版终检，并同步 README 与总索引。
- 新增输出动作：客户确认后必须写 D 档确认变量、E 档执行卡、单镜任务预算、后期文字安全区、禁止项、先测镜和失败第一刀。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：执行版过稳会削弱传播记忆，不能把记忆帧、声音钩子和封面停留点全删掉。
- 下一轮相反训练：发布记忆 / 成片可复述。

### Seedance 执行后发布记忆回检增强

- 主短板：发布记忆 / 成片可复述。
- 为什么选它：上一轮把客户确认后的执行版收稳了，但素材跑完后如果只看画质、连续性和提示词完成度，容易出现“能剪进片子，却没人记得住、也不适合发”的断层。
- 本轮动作：增强生成后回放验片与剪辑救援协议、发布前可复述测试协议，并同步 README 与总索引路由。
- 新增输出动作：Seedance 执行版跑完后，必须做素材发布记忆复核，写清观众一句话复述、截图帧、动作或声音钩子、评论接话口、误解风险和最弱传播变量；技术可用但复述不出、截图不住的素材，只能算素材可用，不能算发布可用。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：过度追求发布记忆可能让剪辑救援变成标题封面优化，忽略主任务、连续性和客户价值；必须先确认素材职能，再判断能否发布复用。
- 下一轮相反训练：生成后返工 / 单变量救片。

### 生成后返工变量冻结增强

- 主短板：生成后返工 / 单变量救片。
- 为什么选它：上一轮强化发布记忆后，返工时容易为了封面、记忆点或传播变量重新改一堆东西，导致上一版已经成功的角色、产品、构图、风格或可用段被新提示词改坏。
- 本轮动作：增强失败镜头诊断表与返工改法映射、Seedance 2.0 返工迭代协议，并同步 README 与总索引路由。
- 新增输出动作：单变量返工前必须写救片变量冻结单，说明上一版可继承段、已经成立的变量、本轮唯一可改变量、绝对不许改、需要删掉的诱惑、重试提示词只新增什么，以及新版本改坏冻结项后的回滚方式。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：冻结过严会让真正需要拆镜、换机位或重做关键帧的镜头继续小修；连续两次“改好一个、改坏三个”必须停止单变量重试。
- 下一轮相反训练：现场输出速度 / 短返工拍板。

### 冻结后记忆回填与封面停留点增强

- 主短板：记忆复述 / 封面停留点。
- 为什么选它：生成前冻结三件套能提高 Seedance 执行稳定，但可能把口型、文字、复杂群像、强运镜或特效记忆点删掉，导致成片稳了却记不住。
- 本轮动作：增强作品记忆点、视觉母题与余味系统，补“冻结后记忆回填”，并接入 README 与总索引入口。
- 新增输出动作：执行版删掉记忆点时，先保冻结主任务和主变量，再用反应停顿、声音钩子、道具状态、构图轮廓或后期入口补回；不把被删高风险变量塞回 Seedance。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：回填过多会重新撑爆单镜预算；记忆补强只能选一种低风险方式，不能同时补台词、字幕金句、强运镜和复杂特效。
- 下一轮相反训练：现场输出速度 / 第一判断。

### 短返工 F0 四行拍板增强

- 主短板：现场输出速度 / 短返工拍板。
- 为什么选它：上一轮强化返工变量冻结后，返工回答容易变成完整诊断表；用户只问“下一版怎么改，短点”时，必须先像现场导演一样快速砍第一刀。
- 本轮动作：增强输出档位与场合切换器、短需求第一判断训练样本库，并同步 README 与总索引路由。
- 新增输出动作：返工短句先走 F0，4 行内输出主病灶、上一版保留项、舍掉诱惑和单变量第一刀；只有用户要具体提示词或细案时，才切完整 F档，补救片变量冻结单、通过标准和失败后的下一刀。
- 成长证据：模板证据 + 入口证据 + 回归题证据。
- 分数：4。
- 退化风险：F0 太短可能漏掉关键冻结项；只要用户要“具体下一版提示词、怎么写、完整返工”，必须立刻切 F档，不停在口头判断。
- 下一轮相反训练：客户交付压缩 / 返工解释给客户看。

### A0 反压缩止损线增强

- 主短板：现场输出速度 / 第一判断。
- 为什么选它：连续强化客户、Seedance、发布、返工和记忆后，短需求容易拍板后自动膨胀成完整交付包，反而不像现场导演先判断。
- 本轮动作：增强短需求第一判断训练样本库和输出档位切换器，补 A0 反压缩止损线、切档证据门禁和止步句式，并同步 README 与总索引。
- 新增输出动作：短需求先 4 行拍板；只有出现展开、分镜、客户版、Seedance、返工或发布检查等切档证据，才进入对应档位；没有证据时停在 A0/A档，只给下一步入口。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：止损过严会让用户明确要完整方案时输出过薄；只要出现“完整、分镜、客户、Seedance、返工、发布”等信号，必须立刻切到对应档位补足交付。
- 下一轮相反训练：客户交付压缩 / 防止过薄。

### D0 极简客户卡防薄增强

- 主短板：客户交付压缩 / 防止过薄。
- 为什么选它：上一轮 A0 反压缩让短需求不会自动写厚，但“给客户看 + 别写太长”可能被误判成轻量方向，导致客户版只剩判断和口号。
- 本轮动作：增强客户提案三层压缩表达协议和输出档位切换器，补 D0 极简客户卡、客户信号优先于“别写太长”的裁决，并同步 README 与总索引。
- 新增输出动作：当“客户/甲方/提案/一页方案”和“别写太长/先给一版”同句出现时，切 D0：一句话价值、客户为什么会在乎、第一帧、证明链、风险控制、客户下一步确认六项必须齐。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：D0 过硬可能在用户只想聊天时误切客户版；必须同时出现客户交付信号和短压缩信号，才启用 D0。
- 下一轮相反训练：Seedance 执行稳定 / D到E交接。

### D0 到 E0 最小执行交接增强

- 主短板：Seedance 执行稳定 / D到E交接。
- 为什么选它：D0 极简客户卡能让客户快速看懂，但客户一确认就直接写 Seedance 长提示词，容易缺画幅、时长、唯一主卖点、不可变项、后期责任和先测镜，让模型替团队猜执行地基。
- 本轮动作：增强客户提案三层压缩表达协议、输出档位与场合切换器、Seedance 提示词终检，并同步 README 与总索引路由。
- 新增输出动作：D0 确认后先过 E0 最小执行交接，补画幅与时长、主镜头任务、唯一主卖点、角色/产品/场景不可变项、后期文字/Logo/参数责任、先测镜、失败第一刀和缺失变量；E0 通过后才展开 E 档逐镜提示词。
- 成长证据：模板证据 + 入口证据 + 禁用证据。
- 分数：4。
- 退化风险：E0 过度门禁会拖慢明确执行需求；如果 D档确认变量已经完整，可以直接进入 E档，但仍要保留后期责任、单镜任务预算和先测镜。
- 下一轮相反训练：发布记忆 / E档执行后发布回检。
