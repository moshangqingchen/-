# AI超级导演跨类型导演精华吸收实验室

## 1. 定位

这份实验室用于让 AI超级导演持续吸收电影、特摄、短片、广告、MV、纪录片、短剧和优秀 AI 视频里的导演精华，并沉淀成可调用的原创导演能力。

它不负责模仿某个作品，也不负责复刻名场面。它负责把“为什么好看、为什么抓人、为什么能记住”拆成导演 DNA，再转译成原创分镜、Seedance 2.0 提示词、交付模板和回归测试题。

一句话原则：

```text
学骨架，不学皮相；学调度，不学截图；学观众感受，不学符号外壳。
```

## 2. 导演 DNA 卡

每吸收一个参考类型，都要沉淀成一张导演 DNA 卡。

```text
DNA 卡名：
来源类型：
观众感受：
情绪引擎：
冲突规则：
空间压力：
镜头身体：
视觉母题：
声音记忆：
表演动作：
剪辑节奏：
原创替换规则：
Seedance 可生成拆法：
禁止复刻项：
适合调用场景：
回归测试题：
```

判断标准：

- 如果只能说“高级、电影感、很燃、很治愈”，还没有吸收到精华。
- 如果能说清“谁被什么空间压住、哪个动作触发变化、声音在哪里提前进入、结尾用什么动作回收”，才算吸收到导演方法。

## 2.1 方法指纹与外壳指纹

吸收精华前，先把参考拆成两类指纹。能进入长期能力的是方法指纹；必须删掉或替换的是外壳指纹。  
如果两类指纹分不开，本次只能作为临时灵感，不能写入导演 DNA 卡。

| 指纹类型 | 可以怎么写 | 不能怎么写 |
| --- | --- | --- |
| 情绪方法 | 观众先被压住，再在一个小动作里松开 | 像某角色那种孤独、某片那种哭法 |
| 结构方法 | 先给反常结果，再用三次可见证据倒推原因 | 按原片桥段顺序重排一遍 |
| 空间方法 | 人物被门、桌、墙角或人群挤出选择 | 复刻原场景、原走廊、原构图 |
| 动作方法 | 触发、接触、受力、反应四步清楚 | 照搬标志动作、必杀姿势、招牌手势 |
| 声音方法 | 声音先到、画面晚半拍，或爆发前抽空半秒 | 使用原曲、原音效、原口头禅 |
| 视觉母题方法 | 让一个原创物件首次出现、中段变形、结尾回收 | 拿原道具、原颜色组合、原符号外形 |
| Seedance 方法 | 4-6 秒只测试一个导演方法，一个主动作，一个声音落点 | 一镜继承原构图、角色、台词、动作和符号 |

方法指纹必须能改写成不含参考名称的句子：

```text
当【角色处境】遇到【压力方向】时，用【动作/声音/空间变化】让观众产生【具体感受】。
```

外壳指纹必须写进禁用项：

```text
不继承：角色名、脸、服装、专属道具、口号、台词、Logo、标志构图、原声音、原场景任务和世界观设定。
```

如果一句方法必须靠原作品名、角色名或标志画面才说得清，说明还没有吸收到骨架。第一刀不是扩写，而是重拆观众感受、压力方向、动作因果和声音功能。

## 3. 七步吸收流程

### 3.1 第一步：锁定观众感受

先问：

```text
观众为什么停住？
观众在第几秒产生问题？
观众看完能复述哪一帧？
```

常见感受层：

| 感受 | 真正抓手 |
| --- | --- |
| 燃 | 现实压力被一个动作顶回去 |
| 治愈 | 微小伤口被轻轻看见 |
| 悬疑 | 有东西不该出现在那里 |
| 好笑 | 角色认真执行一个荒唐理解 |
| 高级 | 情绪被压住，用动作泄出一点 |
| 爽 | 阻碍者的权力被可见地反转 |
| 震撼 | 尺度变化前有现实参照物 |

### 3.2 第二步：拆情绪引擎

情绪不是形容词，要拆成动作链。

```text
情绪起点 -> 防御动作 -> 外部压力 -> 动作中点 -> 反应停顿 -> 情绪泄出 -> 余味动作
```

示例：

```text
不是“她很难过”，而是：
她把旧钥匙放回抽屉，手指停了一下，又把钥匙推到最里面；关抽屉时声音很轻，像怕吵醒某个人。
```

### 3.3 第三步：拆冲突规则

每个好看的类型都有规则。

```text
谁想要什么？
谁阻止他？
阻止方式是什么？
代价怎么升级？
主角最后必须做什么选择？
```

如果没有选择，只是漂亮镜头；如果没有代价，只是事件说明。

### 3.4 第四步：拆空间压力

空间必须参与戏。

| 类型 | 空间压力 |
| --- | --- |
| 短剧 | 门口、饭桌、办公室座位制造权力关系 |
| 悬疑 | 走廊、门缝、窗帘、镜面隐藏信息 |
| 情感 | 餐桌距离、旧房间、床边、玄关承载关系 |
| 打斗 | 楼梯、狭窄通道、墙角、车辆限制动作方向 |
| 广告 | 桌面、手部区域、产品与结果的距离 |
| 特摄 | 日常街角、天台、操场给奇观现实基准 |

空间拆解句：

```text
这个空间怎样逼角色靠近、后退、停住、低头、绕开或选择？
```

### 3.5 第五步：拆镜头身体

镜头不是乱动，是有身体立场。

| 镜头身体 | 用途 |
| --- | --- |
| 眼睛 | 代入观察、发现异常、情绪迟疑 |
| 胸口 | 紧张、后退、被推近、呼吸感 |
| 手部 | 产品证明、道具触发、微动作 |
| 过肩 | 关系压力、对白秩序、信息差 |
| 道具 | 旧物叙事、记忆触发、悬疑伏笔 |
| 旁观者 | 群像、喜剧反应、荒诞现场 |
| 记忆 | 怀旧、梦境、内心残影 |
| 监控 | 冷感、荒诞、不可控现场 |

每次吸收一个参考，都要说清：

```text
这个方法的镜头像谁的身体？能怎么动？不能怎么动？什么时候切换视角？
```

### 3.6 第六步：拆声音记忆

声音要成为信息，不只是 BGM。

| 声音方法 | 用途 |
| --- | --- |
| 声音先行 | 画面出现前先制造问题 |
| 静音点 | 爆发前抽空空气 |
| 环境声 | 让场景像真实存在 |
| 道具声 | 让记忆点可复述 |
| 低频压力 | 悬疑、怪兽、机械、权力压迫 |
| 反差声音 | 喜剧、荒诞、可爱误会 |
| 结尾回声 | 余味、系列记忆、品牌记忆 |

声音拆解句：

```text
如果关掉画面，观众还能通过哪个声音记住这条片？
```

### 3.7 第七步：原创替换与可生成拆镜

每张 DNA 卡必须完成三类替换：

1. 角色关系替换。
2. 场景任务替换。
3. 视觉母题替换。

高风险参考再加两类替换：

4. 声音记忆替换。
5. 结尾回收替换。

Seedance 拆镜原则：

- 每镜只继承一种导演方法。
- 每镜 4-6 秒优先。
- 一镜一个主动作或主说话人。
- 复杂奇观先有现实基准，再升级。
- 字幕、Logo、品牌字和可读中文默认后期添加。

## 4. 六类精华吸收模板

### 4.1 电影感吸收模板

```text
观众感受：
人物选择：
空间压力：
镜头立场：
情绪停顿：
声音先行：
余味动作：
原创替换：
```

判断：

电影感不是黑边、雨夜和蓝橙光，而是人物在空间压力下做选择。

### 4.2 特摄感吸收模板

```text
日常基准：

仪式动作：
能力规则：
尺度参照：
必杀前停顿：

人群反应：
原创替换：
```

判断：

特摄感不是更炸，而是现实基准、仪式、规则、尺度和受力结果都站得住。

### 4.3 高概念短片吸收模板

```text

单一规则：

角色选择：
情绪转向：
余味动作：
可生成拆镜：
```

判断：

好短片通常只证明一个规则，不铺一个世界。

### 4.4 创意广告吸收模板

```text

转化入口：
```

判断：

广告里的电影感必须服务证明链，不能只服务漂亮画面。

### 4.5 爆款视频吸收模板

```text

```

判断：

爆款结构不是承诺必火，而是让观众在前三秒欠下一个问题。

### 4.6 AI 视频失败案例吸收模板

```text
失败现象：
跑偏原因：
本该锁定：
本该删掉：
应该拆成几镜：
下一版只改：
通过标准：
```

判断：

失败案例也是导演训练素材。每次失败都要变成一条防错规则。

## 5. 吸收后原创演练闭环

吸收参考后不能只写 DNA 卡。必须立刻做三题原创演练，验证这次学到的是导演方法，不是参考外壳。

三题固定结构：

| 训练题 | 目的 | 必须产出 |
| --- | --- | --- |
| 一题创意 | 验证能不能脱离原作品生成新场面 | 新角色关系、新场景任务、新视觉母题、一句导演拍板 |
| 一题改稿 | 验证能不能识别“像原作”的皮相残留 | 保留方法、删掉外壳、第一刀改法、新版通过标准 |
| 一题 Seedance 小样 | 验证能不能转成可生成镜头 | 4-6 秒镜头、一个主动作、一个声音落点、失败第一刀 |

演练规则：

1. 创意题不得使用原作品角色关系、场景任务、标志道具、台词、口号、Logo 或专属造型。
2. 改稿题必须指出至少一个“看起来像学习，其实是复刻”的风险。
3. Seedance 小样只能继承一个导演方法，不能同时继承构图、角色、台词、符号和动作。
4. 三题里至少有一题要换到完全不同类型，例如把电影名场面方法转成产品广告、把特摄仪式感转成可爱治愈、把悬疑信息差转成短剧冲突。
5. 每题都要写“如果像原作，第一刀删什么”。

原创演练输出卡：

```text
我先把这次精华练成自己的：

本次只继承的方法：
【情绪引擎 / 空间压力 / 镜头身体 / 声音记忆 / 冲突规则】

一题创意：
新场面：
导演拍板：
禁用原作外壳：

一题改稿：
皮相残留：
保留方法：
第一刀：
新版通过标准：

一题 Seedance 小样：
时长与画幅：
主动作：
声音落点：
可生成风险：
失败第一刀：

回归测试题：
下次遇到类似参考时，必须先问【一个能防复刻的问题】。
```

这三题不通过，本次参考只能留作临时灵感，不能写入长期能力。

## 6. 跨场景迁移压力测试

三题原创演练通过后，还不能马上把方法写成长期能力。必须再做一次跨场景迁移压力测试：同一个导演方法，换到三个完全不同的片种和任务里，仍然能成立，才说明学到的是方法，不是参考氛围。

测试原则：

```text
同一个方法，三种场景。
换角色，换任务，换视觉母题。
只保留导演机制，不保留参考外壳。
```

三场景必须覆盖：

| 场景 | 测什么 | 必须换掉 |
| --- | --- | --- |
| 原类型邻近场景 | 方法离开原作品后是否还稳 | 原角色、原场面、原道具 |
| 完全不同商业/类型场景 | 方法能否服务新目标 | 原情绪包装、原结构顺序 |
| Seedance 最小镜头场景 | 方法能否变成 4-6 秒可生成镜头 | 原构图、台词、符号和复杂调度 |

迁移输出卡：

```text
本次只迁移的方法：
【空间压力 / 声音先行 / 仪式停顿 / 反应剪辑 / 证明链 / 余味回收】

场景一：原类型邻近迁移
新角色关系：
新场景任务：
新视觉母题：
保留的方法：
必须删掉的外壳：

场景二：完全不同类型迁移
新片种：
新目标：
方法如何变形：
第一帧：
第一刀：

场景三：Seedance 最小镜头迁移
4-6秒镜头任务：
主动作：
声音落点：
可生成风险：
失败第一刀：

迁移结论：
【可入库 / 只能作为类型打法 / 只能作为临时灵感 / 写入禁用教训】
```

判定标准：

1. 三个场景不得共用原作品角色关系、场面任务、标志道具、台词、Logo 或专属造型。
2. 三个场景必须都能说清“保留的方法”和“删掉的外壳”。
3. 至少一个场景必须跨到广告、可爱治愈、短剧、打斗特效、纪录真实或喜剧荒诞里的不同领域。
4. Seedance 最小镜头必须只保一个主动作和一个声音落点。
5. 如果三场景里有两场只能靠原作品氛围成立，本次方法不得入库。

压力测试通过后，才允许把 DNA 卡交给导演味觉进化与精华沉淀协议。

### 6.1 迁移失败诊断卡

跨场景迁移失败时，不要继续包装成“已吸收精华”。先判断失败类型，再决定降级、回修或写入禁用教训。

| 失败类型 | 症状 | 第一刀 |
| --- | --- | --- |
| 外壳残留 | 换到新片种后还需要参考名、原角色关系、原道具或名场面才成立 | 回到方法指纹与外壳指纹，删掉残留外壳 |
| 方法太窄 | 只能在原类型成立，跨到广告、短剧、可爱或打斗就失效 | 降级为类型打法，不写入通用长期能力 |
| 目标错配 | 方法很漂亮，但不服务新片种的主目标：转化、追更、治愈、受力或记忆 | 改新目标，重写第一帧、主动作和声音落点 |
| 证据不足 | 能讲道理，但没有可见动作、空间压力、反应或声音证据 | 补一条 4-6 秒 Seedance 小样验证 |
| 生成过载 | 方法一迁移就需要复杂群像、长对白、文字、Logo 或多重特效 | 拆成主动作镜、反应镜或后期处理 |

诊断输出：

```text
迁移失败类型：
失败证据：
不能入库的原因：
本轮第一刀：
降级结论：
【回修原创替换 / 降级为类型打法 / 只作临时灵感 / 写入禁用教训】
下一次验证题：
```

硬规则：

1. 三场景只要有两场失败，不能写入长期能力。
2. Seedance 最小镜头失败时，不得用文字解释补救，必须拆镜、换动作或降级方法。
3. 如果失败原因是“目标错配”，优先保新片种目标，不保参考方法。
4. 迁移失败也有价值，但只能写成禁用教训或类型边界，不能假装进化成功。

## 7. 精华入库标准

一个参考只有满足以下条件，才允许写入能力库：

1. 已经说清可继承层和禁用层。
2. 已经完成至少三次原创替换。
3. 已经转成可见动作，而不是停留在形容词。
4. 已经给出 Seedance 可生成拆镜策略。
5. 已经写出声音记忆点或结尾回收。
6. 已经补一条回归测试题。
7. 已经完成一题创意、一题改稿和一题 Seedance 小样演练。
8. 已经通过跨场景迁移压力测试，证明方法离开原参考仍然成立。
9. 已经通过去名盲测门禁，证明拿掉参考名称和外壳后仍能拍。

不满足时，只能作为临时灵感，不进入核心资产。

### 7.1 去名盲测门禁

精华转译最危险的不是抄，而是自己以为在学方法，其实还靠参考名称、角色外壳和名场面撑着。入库前必须做一次去名盲测。

测试方法：

| 步骤 | 做法 | 通过标准 |
| --- | --- | --- |
| 去名 | 删掉参考作品名、角色名、招牌台词、Logo、专属道具和标志构图 | 剩下的句子不依赖任何 IP 识别 |
| 盲讲 | 用一句不含参考名的话讲这个导演方法 | 能讲清动作、压力、信息释放和声音落点 |
| 换壳 | 换到一个完全不同题材、人物关系和场景任务里 | 主动作、空间压力、情绪推进仍然成立 |
| 反查 | 问“观众会不会一眼想到原作外壳” | 如果会，继续替换视觉母题、道具或场面结构 |

输出句式：

```text
去名盲测：
不提参考名后，这个方法是【动作/压力/信息/声音规则】。
换到【新题材】里，它还能靠【主动作】和【空间压力】成立。
仍有复刻风险的是【外壳残留】，第一刀替换成【原创元素】。
```

硬规则：

1. 去名后只剩“燃、电影感、宿命感、英雄感”，不准入库。
2. 去名后必须还能写成一条 Seedance 可生成镜头任务。
3. 盲测失败时，不继续做风格包装，先回到原创替换。
4. 只要观众需要知道参考名才懂，就说明学到的是外壳，不是方法。

## 9. 与现有资产的关系

- 参考作品拆解、原创替换与合规转译闸门负责先判断能不能继承。
- 电影、特摄、短片与创意精华转译库负责提供已有类型转译方法。
- 类型样片案例与导演拆解库负责把方法变成可参考的原创样片。
- 这份精华吸收实验室负责把新参考沉淀成导演 DNA 卡，并回写到模板、提示词、防错和回归测试里。

默认顺序：

```text
参考合规闸门
-> 跨类型导演精华吸收实验室
-> 跨场景迁移压力测试
-> 电影/特摄/短片精华转译库
-> 一页式实战指挥台
-> 不出错防错协议
-> 自我校准与回归测试套件
```

## 10. 自检

输出前自问：

1. 我有没有只继承方法，没有继承角色、台词、Logo、IP 符号和标志性画面？
2. 我有没有把“电影感、燃、治愈、高级”拆成动作和空间压力？
3. 我有没有写清镜头身体，而不是只写运镜形容词？
4. 我有没有设计声音记忆点？
5. 我有没有完成三次原创替换？
6. 我有没有给 Seedance 可生成拆镜，而不是一镜硬塞复杂场面？
7. 我有没有留下回归测试题，让这次吸收能被以后检查？
8. 我有没有完成一题创意、一题改稿和一题 Seedance 小样，证明这次学到的是方法而不是外壳？
9. 我有没有做跨场景迁移压力测试，证明同一个方法能离开原参考，在三个不同场景里成立？
10. 如果迁移失败，我有没有判断是外壳残留、方法太窄、目标错配、证据不足还是生成过载，并降级处理？
11. 我有没有做去名盲测，证明拿掉参考名、角色外壳和标志画面后仍然可拍？
