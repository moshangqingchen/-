# Seedance 2.0 AI短片生成质量提升与缺口雷达

## 1. 定位

这份文档只服务一个目标：用 Seedance 2.0 更稳定地生成 AI 短片、短剧开场、创意广告、产品视频、可爱治愈片、特效打斗片和相关视频素材。

它不是泛泛的导演理论，而是生成前、生成中、生成后都能用的实战雷达：

1. 生成前知道哪一镜最容易失败。
2. 写提示词时知道该锁什么、删什么、拆什么。
3. 多镜头项目知道怎样保持角色、风格、空间和情绪连续。
4. 生成失败后知道是提示词问题、分镜问题、首帧问题、参考图问题，还是镜头目标太贪。
5. 返工时一轮只改一个变量，不把提示词越写越长。

一句话原则：

```text
Seedance 2.0 不是用来一镜完成整场戏的，它最适合生成清楚、短促、有单一动作目标的镜头，再靠剪辑、声音和后期文字拼成片。
```

## 2. Seedance 2.0 成片感的关键缺口

| 缺口 | 常见表现 | 生成前补法 | 失败后第一刀 |
| --- | --- | --- | --- |
| 首帧不稳 | 第一眼不知道看哪里，片子开头散 | 先定第一帧停留点、主体比例、字幕安全区 | 重做首帧，不先改全片 |
| 风格不统一 | 每镜像不同项目 | 写一条全片风格锁定句，每镜继承 | 删掉每镜互相冲突的风格词 |
| 角色漂移 | 发型、衣服、年龄、体态变 | 做角色锁定句和标准帧 | 补角色圣经或先生成角色参考 |
| 场景漂移 | 门窗、桌椅、光源方向乱 | 做场景锁定句和空间方向 | 改成局部镜头或重做场景标准帧 |
| 动作不清 | 起点、接触、结果跳过 | 一镜只保留一个动作链 | 拆成起点、触发、结果、反应 |
| 运镜过度 | 镜头飘、乱转、主体丢失 | 固定机位或轻推轻移 | 删“电影感动态运镜”，改具体运动 |
| 口型穿帮 | 多人说话、长句对不上 | 一镜一个说话人，3-8字短句 | 改画外声、反应镜头或后期配音 |
| 群像融合 | 多角色脸和身体混 | 同框人数降到 2-4，其他做背景反应 | 拆成群像建立、单人动作、双人反应 |
| 特效糊成一团 | 爆炸、能量、变身不清 | 从小异常开始，先给现实基准 | 拆成触发、反应、升级、结果 |
| 打斗看不懂 | 谁打谁、受力方向不清 | 先写空间基准和攻防目标 | 一镜只保留一次接触或躲避 |
| 产品证明弱 | 产品出现了但卖点没被证明 | 手部任务 + 微距证据 + 结果变化 | 固定产品位置，只证明一个卖点 |
| 字幕乱码 | 中文、Logo、招牌不可控 | 画面留白，文字后期添加 | 删除画内可读文字要求 |
| 镜头剪不起来 | 入点出点不清，没有反应镜头 | 每镜写入点、出点、声音桥 | 增加反应镜头和保底出点 |

## 3. 生成前必须锁定的五件事

### 3.1 风格锁定句

多镜头项目先写一条全片共用的风格句。它不要太长，但必须稳定。

模板：

```text
全片风格锁定：竖屏9:16，真实电影感短片，柔和自然光，低饱和但不灰，人物皮肤和服装保持真实质感，镜头克制，背景干净但有生活痕迹，中文字幕和品牌字后期添加。
```

可按类型替换：

- 可爱治愈：柔软材质、低风险动作、明亮自然光、群像反应有停顿。
- 短剧冲突：中近景为主、空间方向清楚、反应镜头多、光线有压力。
- 创意广告：产品清楚、手部动作稳定、前后对比可见、后期文字安全区干净。
- 特效打斗：现实基准清楚、小规模特效起步、受力结果明确、镜头不乱晃。

### 3.2 角色锁定句

每个主要角色都要有一个可复制的锁定句。

模板：

```text
角色锁定：同一位[年龄段/性别/身份]，[发型]，[服装主色和款式]，[一个标志性道具或动作]，[体态和表情习惯]，所有镜头保持一致，不改变年龄、发型、服装、体态和道具。
```

不要只写“漂亮女孩、可爱男孩、帅气英雄”。要写可见特征。

### 3.3 场景锁定句

场景不是背景词，要锁方向。

模板：

```text
场景锁定：同一间[场景]，门在画面左侧，窗在后方，主光从右侧进入，关键道具在桌面中央，人物主要从左向右移动，所有镜头保持空间方向一致。
```

打斗、短剧、多人对话必须先锁场景方向。

### 3.4 动作链

每镜只写一个动作链：

```text
看见目标 -> 开始动作 -> 接触或触发 -> 结果出现 -> 反应停顿
```

如果一镜里超过两个“->”，优先拆镜。

### 3.5 剪辑出点

每镜都要知道为什么切出去。

常用出点：

- 眼神抬起。
- 手停住。
- 门刚打开。
- 产品结果刚出现。
- 对手后退半步。
- 群像沉默半秒。
- 声音先于画面进入下一镜。

## 4. Seedance 2.0 稳定镜头标准

稳定镜头默认长这样：

```text
4-6秒，竖屏9:16，一个主要主体，一个主要动作，一个明确机位，一个清楚入点，一个清楚出点，无画内可读中文，无复杂Logo，无多人同时说话，无大幅运镜和复杂特效叠加。
```

高风险信号：

1. 同一镜头里有三段以上动作。
2. 角色边跑边说话边拿道具。
3. 四个以上角色同框且动作不同。
4. 镜头环绕、推近、升降、跟拍同时存在。
5. 既要精确口型，又要复杂运镜。
6. 既要打斗接触，又要大特效爆发。
7. 画面里要求清晰中文、Logo、包装字。
8. 角色从远景跑到近景还要表情稳定。

导演判断：

```text
如果一个镜头同时承担剧情、动作、口型、特效、产品证明和转场，它不是主镜头，是失败清单。先拆。
```

## 5. AI短片生成流程

### 5.1 先做片子骨架

不要一上来写提示词。先定：

```text
片长：
画幅：
主类型：
副类型：
观众站位：
第一帧：
前三秒问题：
中段升级：
结尾记忆点：
全片风格锁定句：
```

### 5.2 再做镜头优先级

把镜头分成五类：

| 镜头类型 | 作用 | 生成顺序 |
| --- | --- | --- |
| 主镜头 | 片子的核心动作或冲突 | 第1批测试 |
| 证明镜头 | 产品、能力、关系或信息的证据 | 第1-2批 |
| 反应镜头 | 让人物像活人，方便剪辑 | 第2批 |
| 桥镜头 | 转场、空间、声音桥 | 第3批 |
| 记忆镜头 | 封面、结尾、可截图点 | 第1批或最后强化 |

先生成最容易失败但不能删除的镜头。

### 5.3 再写逐镜提示词

逐镜提示词格式：

```text

镜头职责：
可生成性评级：
风格锁定句：
角色锁定：
场景锁定：
时长与画幅：
入点：
动作链：
机位与景别：
镜头运动：
出点：
声音桥：
字幕安全区：
禁止项：
失败后第一刀：
```

## 6. 类型专用生成策略

### 6.1 可爱治愈短片

稳定策略：

1. 小主体，大任务。
2. 动作慢一点，反应停半秒。
3. 群像同框不超过 4 个主要角色。
4. 群像笑点靠反应顺序，不靠每个角色同时乱动。
5. 材质写清：毛绒、软布、纸杯、木桌、晨光。

最容易缺：

- 角色太多导致融合。
- 表情过度夸张。
- 场景变成空背景。
- 可爱只剩形容词，没有动作任务。

第一刀：

```text
删掉多余角色，只保留一个主动作角色和两个反应角色；让主角认真完成一个小任务，笑点放在反应停顿上。
```

### 6.2 竖屏短剧

稳定策略：

1. 第一镜给冲突或反常结果，不解释背景。
2. 空间方向锁死，避免左右跳。
3. 对白拆正反打，一镜一个说话人。
4. 反应镜头比解释更重要。
5. 下一集问题用一个动作或眼神抛出。

最容易缺：

- 开场解释太多。
- 多人同框抢话。
- 口型长句穿帮。
- 反转靠台词，不靠视觉伏笔。

第一刀：

```text
把长对白拆成一句短台词、一个反应镜头和一个证据插入镜头；第一帧直接给反常结果。
```

### 6.3 创意广告与产品视频

稳定策略：

1. 一镜只证明一个卖点。
2. 产品位置固定，手部动作清楚。
3. 微距证据比口号重要。
4. 前后对比要可见。
5. 品牌字和卖点字幕后期添加。

最容易缺：

- 产品出现但没证明。
- 手部和产品接触不清。
- 包装字乱码。
- 前后对比不明显。

第一刀：

```text
把产品镜头改成固定近景，手只做一个动作；删掉画内文字，把卖点放到后期字幕。
```

### 6.4 特效与打斗

稳定策略：

1. 先现实基准，再小异常，再升级。
2. 打斗先交代谁在左谁在右。
3. 一镜只保留一次接触、躲避或受力结果。
4. 特效从手部、道具、地面小变化开始。
5. 大爆发用关键帧或后期，不强塞一镜。

最容易缺：

- 动作因果乱。
- 特效遮住主体。
- 受力方向不清。
- 镜头乱晃假装激烈。

第一刀：

```text
先砍掉大范围爆炸，保留一次清楚接触；用反应镜头和声音打击点补力量。
```

### 6.5 电影感情感短片

稳定策略：

1. 情绪越重，动作越小。
2. 旧物、声音、停顿比哭更重要。
3. 回忆不要一镜硬转，靠声音桥进入。
4. 结尾留一个动作，不解释主题。

最容易缺：

- 表演太满。
- 旁白解释太多。
- 回忆风格漂移。
- 结尾没有余味动作。

第一刀：

```text
删掉大哭和解释旁白，改成手停在旧物上半秒，声音先进入下一镜。
```

## 7. 失败诊断总表

| 失败现象 | 本质问题 | 立刻改什么 | 不要改什么 |
| --- | --- | --- | --- |
| 镜头乱 | 运镜和动作都太多 | 固定机位，只保留一个动作 | 不要继续加电影感词 |
| 角色漂 | 缺角色锁定或参考职责不清 | 补角色锁定句/标准帧 | 不要只加“同一个人” |
| 风格漂 | 每镜风格词不同 | 统一风格锁定句 | 不要每镜换审美词 |
| 动作跳 | 动作链缺接触点 | 写起点、接触、结果 | 不要写“流畅完成复杂动作” |
| 口型错 | 台词太长或说话人太多 | 短句、单人、近景 | 不要让多人同框同时说 |
| 群像融合 | 主体数量太多 | 降人数，分层反应 | 不要写每个人不同动作 |
| 产品不清 | 手、产品、结果不在同一逻辑 | 固定产品和手部动作 | 不要靠口播解释卖点 |
| 特效糊 | 规模太大、触发点不清 | 从小异常开始 | 不要首秒满屏爆发 |
| 剪不起来 | 没有入点、出点、反应 | 增加反应和声音桥 | 不要只重跑主镜头 |
| 字幕乱码 | 让模型生成中文 | 留白后期加字 | 不要要求清晰复杂中文 |

## 8. 生成前预检清单

每条 Seedance 2.0 镜头生成前，问：

1. 这镜头的职责是什么？
2. 观众第一眼看哪里？
3. 只有一个主要主体吗？
4. 只有一个主要动作吗？
5. 角色、服装、道具、场景方向是否锁住？
6. 入点和出点是否明确？
7. 口型是否低风险？
8. 是否有画内可读中文或 Logo 风险？
9. 如果失败，第一刀改什么？
10. 这镜头能不能剪到上一镜和下一镜？

如果第 3、4、6、9、10 任意两项答不上来，先不生成，先改镜头。

示例：

```text
镜头编号：03
镜头职责：产品证明镜头，证明按钮按下后灯光变柔和。
可生成性评级：A

风格锁定句：竖屏9:16，真实生活方式广告，自然暖光，画面干净但有生活痕迹，字幕和品牌字后期添加。
角色锁定：同一位年轻女性，低马尾，浅灰针织衫，右手佩戴细银戒指，动作克制。
场景锁定：同一张木桌，产品位于画面中央偏下，窗光从右侧进入，背景保持轻微虚化。

时长与画幅：4秒，竖屏9:16。
入点：右手停在产品按钮上方半秒。
动作链：食指轻轻按下按钮 -> 产品边缘亮起柔和暖光 -> 手停住。
机位与景别：近景，眼平机位，产品和手部占画面下半部。
镜头运动：固定机位，无摇晃。
出点：暖光稳定后停半秒。

声音桥：轻微按键声，暖光出现时加入很轻的环境嗡鸣。
后期文字规划：右上角留干净区域，后期添加卖点短句。
字幕安全区：画面上方 20% 不出现复杂背景。

禁止项：不要生成可读中文，不要改变产品形状，不要让手指变形，不要突然切换角度。
失败后第一刀：如果手部不稳，改成产品特写和按钮亮起，不要求手指完整入镜。
```

## 10. 继续完善时优先补什么

针对 Seedance 2.0 AI短片，后续最该补的不是更多泛类型，而是这些生成硬能力：

1. 首帧与关键帧标准库。
2. 角色锁定句与角色圣经模板。
3. 场景锁定和空间方向模板。
4. 反应镜头与保底出点库。
5. 失败镜头诊断与返工改法映射。
6. 产品手部动作稳定模板。
7. 群像降风险模板。
8. 口型同步降风险模板。
9. 特效打斗拆镜模板。
10. 发布前成片感审片表。

下一轮优先级：先补“首帧与关键帧标准库”。因为 Seedance 2.0 的多镜头短片，最怕第一帧、角色标准帧和场景标准帧没锁住；后面所有提示词都会漂。
