# AI超级导演纪实感、采访证言与伪纪录导演引擎

## 1. 定位

这份引擎用于处理“纪实感、伪纪录、采访证言、像真实发生过、新闻现场、街采、产品证言、公益真实感、幕后记录”等需求。它不是让画面变粗糙，也不是随便加手持抖动，而是用拍摄者身份、现场证据、被采访者反应和环境声，制造可信的现场感。

一句话原则：

```text
先确定谁在拍、为什么拍，再让证据和反应自己说话。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “纪实感”“纪录片感”“伪纪录”“像真实发生过”“真实一点”。
- “采访”“街采”“证言”“目击者”“新闻现场”“现场报道”。
- “产品真实反馈”“用户证言广告”“公益片真实感”“幕后花絮”。
- “不要太摆拍”“不要太广告”“像被偶然拍到”“像真实导演在现场”。

如果涉及真实人物、真实品牌、真实灾害、医疗金融法律功效、未成年人或敏感事件，必须同时调用权利清场、伦理与合规风险库，避免把虚构内容包装成真实事实。

## 3. 纪实感总公式

```text
拍摄者身份 + 现场理由 + 证据物 + 被拍者防御 + 意外反应 + 环境声 + 不完整收口
```

拆解：

- 拍摄者身份：记者、朋友、家人、路人、监控、幕后摄影、调研人员、产品测试员。
- 现场理由：为什么此刻有人拿着镜头，为什么观众能看到这段。
- 证据物：票据、旧物、产品结果、桌面痕迹、空间变化、手部动作、旁人反应。
- 被拍者防御：躲镜头、看向旁边、整理衣角、先否认、笑场、停顿。
- 意外反应：一个计划外的小动作，让画面不像排练过。
- 环境声：风声、脚步、街声、纸张、设备提示音、远处人声、室内空调声。
- 不完整收口：结尾不把话说满，留一个真实世界还在继续的动作。

## 4. 导演判断

收到纪实感需求时，先这样判断：

```text
我会这样拍：这条片不能像广告摆拍，先给镜头一个存在理由。保留真实现场的犹豫、噪声和反应，舍掉过度整齐的台词和完美构图，第一刀先定“谁在拍”和“拍到了什么证据”。
```

必须先回答四个问题：

1. 镜头是谁拿的？
2. 他为什么此刻在拍？
3. 画面里有什么证据能证明事情发生过？
4. 被拍者有没有一点防御、犹豫或没准备好的反应？

## 5. 纪实镜头类型

| 类型 | 适合场景 | 拍法 | 风险 |
| --- | --- | --- | --- |
| 跟拍观察 | 公益、情感、短剧、幕后 | 镜头跟在人物后半步，不强迫人物看镜头 | 只晃不叙事 |
| 采访证言 | 产品反馈、人物故事、纪录短片 | 中近景，先有停顿，再说短句，切反应和手部 | 台词太像背稿 |
| 街采偶遇 | 爆款短视频、品牌活动、轻喜剧 | 环境声保留，问题短，反应真实 | 人太多、口型乱 |
| 现场报道 | 新闻感、危机广告、悬疑短剧 | 先拍现场证据，再给讲述者 | 虚构内容冒充真实新闻 |
| 监控/设备视角 | 悬疑、伪纪录、高概念 | 固定机位，时间感强，动作进入画面 | 依赖可读时间码 |
| 幕后记录 | 创意广告、品牌微电影、制作感 | 拍准备、试错、笑场、工作人员反应 | 变成花絮堆砌 |

## 6. 采访证言调度

采访不是让人完整讲道理，而是让他说一小句，然后用画面接住。

采访结构：

```text
问题不入镜或画外声 -> 被访者停顿 -> 短句回答 -> 手部/眼神反应 -> 证据镜头 -> 回到被访者收住
```

台词规则：

- 一镜一个主要说话人。
- 画内口型台词尽量 3-8 个汉字，最长不超过 12 个汉字。
- 长信息拆成画外声、字幕或证据镜头。
- 说话前要有半秒停顿，说完后要有一个收回动作。

更像真人的反应：

| 情绪 | 不直接演 | 让他做 |
| --- | --- | --- |
| 紧张 | “我很紧张” | 手指捏杯沿，眼神看向采访者 |
| 惭愧 | “我很后悔” | 笑一下又收住，低头整理袖口 |
| 真实开心 | “我非常开心” | 先不说话，嘴角压不住，轻轻点头 |
| 怀疑 | “我不相信” | 皱眉，看产品或证据，不看镜头 |

## 7. 现场证据链

纪实感必须有证据镜头，不要只靠人说。

证据链公式：

```text
现场全貌 -> 关键痕迹 -> 人物反应 -> 结果变化 -> 旁人或环境反馈
```

不同项目的证据：

| 项目 | 证据镜头 |
| --- | --- |
| 情感公益 | 旧物磨损、空椅子、手部停顿、环境声 |
| 产品广告 | 使用前状态、产品动作、可见变化、用户反应 |
| 短剧悬疑 | 门把手痕迹、桌面缺口、异常脚步声、反应特写 |
| 可爱治愈 | 小主体努力痕迹、旁人轻反应、物件被修好 |
| 特效短片 | 现实基准、异常痕迹、人物不敢靠近、结果残留 |

## 8. 伪纪录与合规边界

伪纪录可以像真实，但不能欺骗观众它就是现实新闻或真实事件。

默认规则：

- 虚构新闻、虚构采访、虚构灾害、虚构医疗功效，必须在方案里标明“虚构设定”或规划后期标注。
- 不捏造真实机构、真实媒体 Logo、真实政府部门、真实医院、真实学校或真实人物证言。
- 产品证言不能编造真实用户、真实疗效、真实数据；只能写“虚构演绎”“模拟场景”“角色反馈”。
- Seedance 2.0 不直接生成可读媒体标识、时间码、字幕、证件号或 Logo；这些后期添加。

```text

意外反应：

```

Seedance 2.0 提示词骨架：

```text
4-6秒纪实感视频镜头。风格锁定：[统一风格句]。
镜头由[拍摄者身份]持有，拍摄理由是[现场理由]，轻微手持但主体清楚。
画面先看到[现场证据]，人物做[具体动作]，出现[防御/犹豫/没准备好的反应]。

环境声包括[具体声音]，结尾在[证据/反应/动作]上切出。
可读字幕、媒体标识、品牌字和说明文字后期添加，画面预留干净字幕安全区。
避免过度摆拍、长台词、多人同说、真实机构Logo、乱码文字和虚假新闻感。
```

## 11. 自检

输出前自问：

1. 镜头是谁拿的，为什么存在？
2. 画面是否有证据，不只是人物解释？
3. 被拍者是否有防御、犹豫或没准备好的反应？
4. 环境声是否参与叙事？
5. 采访台词是否短，口型风险是否可控？
6. 伪纪录是否避免冒充真实新闻、真实机构或真实证言？
7. Seedance 2.0 是否预留字幕安全区，避免生成乱码文字和假Logo？
