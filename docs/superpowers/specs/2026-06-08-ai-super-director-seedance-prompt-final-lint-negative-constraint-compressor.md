# AI超级导演 Seedance 提示词终检与负面约束压缩器

## 1. 定位

这份协议用于 Seedance 2.0 生成前的最后一遍提示词体检。很多镜头前期判断是对的，但最终提示词会越写越长：风格、动作、口型、群像、特效、字幕、Logo、情绪、运镜全塞进去，结果生成失败后还不知道错在哪。

本协议不替代提示词与镜头生成库，也不替代可生成性拆镜库。它只做最后一关：删掉过载信息，压缩负面约束，确认这条提示词能跑、能剪、能复盘。

一句话原则：

```text
最终提示词不是越全越好，而是越清楚越稳。
```

默认目标：

1. 每条 Seedance 提示词只承担一个镜头任务。
2. 每镜只保留一个主动作和一个主要运镜。
3. 禁止项不散乱堆叠，而是压成最关键的 3-7 条。
4. 可读中文、Logo、品牌字、字幕和屏幕字明确后期添加。
5. 如果提示词仍然过载，先拆镜或先测，不硬跑。

## 2. 什么时候必须启用

遇到以下信号，默认调用本协议：

1. 用户说“最终提示词、生成前检查、提示词太长、提示词会不会跑偏、帮我压一下、负面词怎么写、禁止项怎么写”。
2. 完整 Seedance 分镜已经写完，准备逐镜生成。
3. 一条提示词包含多人、口型、复杂动作、强运镜、特效、可读文字或产品证明。
4. 之前生成失败，怀疑提示词过载、禁止项缺失或变量太多。
5. 多镜头项目需要统一提示词格式和禁止项。
6. 客户提案前要确认提示词能稳定生成。

不必启用的情况：

1. 用户只要创意、分镜或导演方案，不进入生成。
2. 单镜极简单，已符合稳定镜头规则。
3. 用户明确要长提示词草稿而不是最终生成版。

## 3. 最终提示词合格结构

一条可生成的 Seedance 2.0 最终提示词至少包含：

```text
镜头任务：
时长与画幅：
风格锁定：
主体：
主动作：
场景与空间：
摄影：
声音：
剪辑点：
一致性：
后期文字：
禁止项：
```

其中必须压清：

1. 镜头任务只回答一个问题。
2. 主动作只写一个动作链。
3. 摄影只写一个主要运镜。
4. 声音只保留一个最重要的声音落点。
5. 禁止项只写最可能翻车的风险。

## 4. 提示词终检表

| 检查项 | 通过标准 | 不通过处理 |
| --- | --- | --- |
| 镜头任务 | 一句话说清本镜干什么 | 回到镜头优先级 |
| 主体 | 1个主主体，辅助角色只轻反应 | 减人或拆反应镜 |
| 主动作 | 起点、变化、结果清楚 | 拆成动作镜和结果镜 |
| 运镜 | 一个主要运镜，有理由 | 删除多余运镜 |
| 口型 | 单说话人、短句、嘴部可见 | 改画外声、字幕或反应镜 |
| 文字 | 可读文字后期添加 | 写安全区，不写生成文字 |
| 风格 | 一条统一风格锁定句 | 删副风格 |
| 连续性 | 角色、服装、道具、空间锁定 | 补场记字段 |
| 禁止项 | 3-7 条关键风险 | 删泛泛负面词，补真实风险 |
| 失败复盘 | 能判断失败变量 | 本轮只测一个变量 |

## 5. 负面约束压缩规则

禁止项不要越写越长。按优先级选 3-7 条：

1. 文字风险：不要生成可读中文、字幕、Logo、品牌字、屏幕字。
2. 角色风险：不要换脸、脸部漂移、服装变化、新增人物。
3. 动作风险：不要动作跳变、肢体变形、手指变形、物体穿模。
4. 道具风险：不要道具消失、产品形状变化、颜色变化。
5. 运镜风险：不要快速环绕、频繁视角切换、无意义晃动。
6. 群像风险：不要多人同时说话、角色融合、站位跳。
7. 合规风险：不要真实Logo、真实IP角色、真实机构标识、可识别名人。

坏写法：

```text
避免低质量、模糊、错误、变形、不自然、奇怪、混乱、不美观、违和、画面不好。
```

好写法：

```text
避免：脸部漂移，右手道具消失，中文标题乱码，错误Logo，多人同时开口，快速环绕，新增角色。
```

## 6. 提示词压缩手术

如果提示词太长，按顺序删：

1. 删同义形容词：高级、电影感、质感、氛围感重复出现时只保留一个规则。
2. 删副风格：主风格只留一条，Moodboard 只写可执行规则。
3. 删多余剧情解释：提示词只写本镜，不写整集故事。
4. 删不可生成文字：中文、Logo、品牌字、参数和价格改后期。
5. 删过多动作：保留本镜主动作，其余拆镜。
6. 删多余运镜：保留一个主要运镜。
7. 删泛泛禁止项：改成具体风险。

压缩后必须还能回答：

```text
谁在什么地方，做什么动作，镜头怎么拍，声音落在哪里，哪里切出，不能生成什么。
```

## 7. 变量冲突刹车表

最终提示词不能只看“有没有写全”，还要看变量之间会不会互相打架。只要同一镜头里同时出现两个以上高风险变量，就先触发刹车，不继续扩写。

高风险变量包括：

1. 多人同框或多人对白。
2. 口型同步或可读台词。
3. 复杂动作、打斗、追逐或特效。
4. 快速运镜、环绕、穿越或频繁视角切换。
5. 产品证明、手部操作或道具形变风险。
6. 可读中文、Logo、品牌字、参数或屏幕信息。
7. 多参考图、多风格、多角色或系列连续性。

刹车判断：

| 冲突组合 | 为什么危险 | 处理方式 |
| --- | --- | --- |
| 多人对白 + 强运镜 | 口型、站位和视角同时漂 | 保一个主说话人，运镜降为轻推或固定机位 |
| 打斗特效 + 快速环绕 | 接触受力看不清，空间轴线乱 | 保接触受力，删环绕，拆结果反应镜 |
| 产品证明 + 长口播 | 手部和嘴部同时抢生成资源 | 保产品动作，口播改画外声或后期字幕 |
| 可读文字 + 真实Logo | 乱码和合规风险同时出现 | 画面只留安全区，文字与Logo后期添加 |
| 多参考图 + 多风格 | 角色、场景和色调互相拉扯 | 每镜只继承一个主参考职责，其他降为隐性限制 |
| 群像 + 复杂动作 | 角色融合、站位跳、动作乱 | 只让一个角色做主动作，其他角色轻反应 |
| 口型 + 特效爆发 | 嘴部稳定和特效变化互相冲突 | 台词提前或延后，爆发镜不承担口型 |

刹车输出必须按这个顺序：

```text
我先踩刹车：这镜同时塞了[变量A]和[变量B]，硬跑会坏在[具体风险]。
保一个：[本镜必须保留的主变量]
拆一个：[拆到下一镜的变量]
后期一个：[交给字幕、Logo、配音、参数或品牌包装的变量]
删一个：[不影响本镜成败的变量]
先测一个：[如果还不稳，先测的最小变量]
```

刹车后重写提示词时，必须只保留一个主变量。被拆掉的变量要写入下一镜、后期清单或小样测试，不能在同一条提示词里换个说法又塞回来。

## 8. 单镜任务预算

变量冲突不是最后才发现。最终提示词写完前，先给这条镜头算任务预算。

默认预算：

```text
一条 4-6 秒 Seedance 镜头最多承载 3 个任务点。
超过 3 点，必须压缩、拆镜、后期或先测小样。
```

任务点计算：

| 变量 | 点数 | 说明 |
| --- | --- | --- |
| 一个主动作 | 1 | 本镜必须有，不能再叠多个动作链 |
| 一个主要运镜 | 1 | 固定机位或轻推可算 0.5，快速环绕算 2 |
| 单人短口型 | 1 | 3-8 个汉字，嘴部可见 |
| 多人同框轻反应 | 1 | 同类反应，不承担复杂动作 |
| 产品手部证明 | 2 | 手部、产品外观和结果都要稳 |
| 打斗接触或追逐 | 2 | 起点、接触、受力结果要清楚 |
| 特效变化 | 2 | 小异常算 1，大爆发或变形算 2 |
| 多参考继承 | 1 | 本镜只继承一个主参考职责；多风格算 2 |
| 可读文字/Logo/品牌字 | 3 | 默认不进生成，改后期 |
| 多人对白 | 3 | 默认拆成正反打、反应镜或画外声 |

### 8.1 预算计分闸门

预算不是感觉判断，必须逐项计分。先把这一镜所有显性要求拆成变量，再按 0.5、1、2、3 分计入。

| 点数 | 变量类型 | 例子 | 处理 |
| --- | --- | --- | --- |
| 0.5 | 轻约束 | 固定机位、轻微手持、环境声、单一光线方向、字幕安全区 | 可保留，但不能拿来当主任务 |
| 1 | 普通任务 | 一个主动作、一个反应停顿、一个声音落点、一个轻推镜头、单人短句 | 可进入最终提示词 |
| 2 | 高风险任务 | 产品手部证明、打斗接触、追逐、明显特效、复杂道具变化、多人同框轻反应 | 一镜最多保一个 |
| 3 | 禁止生成任务 | 可读中文、Logo、屏幕文字、多人对白、长台词、多风格混合、强环绕加复杂动作 | 默认后期、拆镜或替代 |

计分顺序：

```text
1. 先圈主任务：这镜删掉后会少掉什么？
2. 再圈生成风险：口型、群像、文字、特效、产品、运镜、参考继承。
3. 再圈剪辑任务：入点、出点、声音桥、反应钩子。
4. 最后圈后期任务：字幕、Logo、品牌字、参数、屏幕信息。
```

硬规则：

1. 3 分变量原则上不进画面生成；除非用户明确测试它，且这一镜不再承担其他高风险任务。
2. 2 分变量一镜最多保一个；如果同时出现两个 2 分变量，必须拆镜或先测。
3. 口型和手部产品证明不能同镜都做主任务；一个画内，一个画外或后期。
4. 强运镜不能和复杂动作同镜抢主任务；保动作，降运镜。
5. 如果总分看似 3 分以内，但变量跨口型、文字、群像、特效四类之一，仍要触发变量冲突刹车。

### 8.2 过载自动拆法

当预算临界或过载时，不要只说“建议拆镜”，必须给出拆法：

| 过载来源 | 第一刀 | 拆成 |
| --- | --- | --- |
| 主动作 + 长口型 | 保主动作，台词改画外声 | 主动作镜 + 反应/画外声镜 |
| 产品证明 + 口播 | 保手部证据，口播后期 | 手部证明镜 + 字幕/配音 |
| 群像 + 复杂动作 | 保一个主动作角色 | 主动作镜 + 群像反应镜 |
| 特效 + 强运镜 | 保特效触发和受力结果 | 触发镜 + 结果反应镜 |
| 屏幕文字 + 人物表演 | 文字后期，表演保画内 | 表演镜 + 后期屏幕/插入镜 |
| 多参考 + 多角色 | 只保一个全局参考 | 角色锁定镜 + 场景/风格镜 |

拆镜输出句：

```text
这镜预算【总分】分，结论【临界/过载】。
我不硬塞成一条：第 1 镜保【主变量】，第 2 镜接【被拆变量】，文字/Logo/口播交给【后期/画外声】。
```

预算结论：

| 总点数 | 结论 | 处理 |
| --- | --- | --- |
| 1-3 | 可控 | 可写最终提示词 |
| 4-5 | 临界 | 只保一个主变量，另一个降级或后期 |
| 6+ | 过载 | 必须拆镜或先测，不写成一条最终提示词 |

预算输出句：

```text
单镜任务预算：
【变量A】=【点数】，【变量B】=【点数】，合计【总点数】。
结论：【可控 / 临界 / 过载】。
第一刀：保【主变量】，把【变量】拆到下一镜 / 后期处理 / 删除 / 先测小样。
```

禁止预算作弊：

1. 不要把“轻微、自然、电影感”当成降难，它们不会减少任务点。
2. 不要把多段动作写成“一个流畅动作”来逃避拆镜。
3. 不要把多人对白写成“大家自然交谈”，这仍然是高风险变量。
4. 不要把文字风险塞进负面词，正确做法是后期添加。
5. 不要让一个镜头同时证明两个卖点，产品证明一镜只证一个点。

### 8.3 生成前冻结三件套

预算算完后，最终执行版不能再把刚删掉的变量偷偷塞回提示词。写压缩后的最终提示词前，必须先冻结三件事：

```text
冻结主任务：本镜只完成【一个镜头任务】。
冻结主变量：本镜只保【一个最重要变量】，其他变量进入下一镜、后期或小样。
冻结失败第一刀：如果失败，下一轮只改【一个变量】，不全量重写。
```

冻结判断：

| 冻结项 | 必须写清 | 失败信号 | 第一刀 |
| --- | --- | --- | --- |
| 主任务 | 这镜删掉会少掉什么 | 同时承担剧情、证明、口型、特效和记忆帧 | 只保删掉会断片的任务 |
| 主变量 | 本轮最该赌稳的变量 | 又把拆掉的口型、文字、群像或强运镜塞回来 | 保一个，其他移出画面 |
| 失败第一刀 | 失败后只改什么 | 写“整体优化、再自然一点、更电影感” | 改成机位、动作、时长、口型、道具或风格锁定之一 |

冻结输出句：

```text
生成前冻结：本镜只赌【主变量】。我不会把【被删变量】塞回最终提示词；如果失败，下一轮只改【第一刀变量】。
```

硬规则：

1. 冻结后不再新增角色、台词、运镜、文字、特效或卖点。
2. 如果客户版、导演版或分镜表里还有好看的额外想法，只能进入下一镜、后期清单或备选版。
3. 失败第一刀必须能直接改提示词字段，不能写成审美感受。

## 9. 高风险镜头终检

### 9.1 多人对白

必须满足：

1. 一镜一个主说话人。
2. 台词 3-8 个汉字，最长不超过 12 个汉字。
3. 其他人只做轻反应。
4. 站位固定。
5. 长对白改画外声、字幕或正反打。

终检句：

```text
本镜只让【角色A】说一句短话，【角色B】只做反应，不让多人同时开口。
```

### 9.2 打斗特效

必须满足：

1. 空间方向清楚。
2. 起点、触发点、受力结果清楚。
3. 特效跟动作因果走。
4. 不同时快速运镜和复杂连招。
5. 声音打击点明确。

终检句：

```text
本镜只拍一次接触受力，不拍完整大战。
```

### 9.3 产品证明

必须满足：

1. 手部任务清楚。
2. 产品外观不变。
3. 结果变化可见。
4. 参数、价格、品牌字后期添加。
5. 不加长口播。

终检句：

```text
本镜只证明一个卖点，文字和参数后期添加。
```

### 9.4 可爱治愈

必须满足：

1. 小主体任务清楚。
2. 动作小而可见。
3. 群像只轻反应。
4. 不堆表情和道具。
5. 截图点明确。

终检句：

```text
本镜只拍小主体完成一个笨拙动作，其他角色不抢戏。
```

## 11. 终检输出卡

当用户让你检查最终提示词时，输出：

```text
我先做生成前终检：

结论：
可直接跑 / 先压缩 / 先拆镜 / 先测小样 / 先重写首帧

主风险：
【一个最大风险】

变量冲突：
【是否触发刹车；如果触发，写明保一个、拆一个、后期一个、删一个、先测一个】

单镜任务预算：
【总点数，可控/临界/过载】

生成前冻结：
【主任务、主变量、失败第一刀；确认不把已删变量塞回最终提示词】

【删掉的冗余风格、动作、运镜或文字要求】

保留：
【本镜必须保留的核心】

【可直接复制生成的版本】

失败第一刀：
【如果失败，下一轮只改一个变量】
```

### 11.1 客户确认后执行版终检

当客户版已经确认，准备把 D 档客户提案转成 E 档 Seedance 执行卡时，先做这道门禁。它确保客户价值不会变成画面口号，也确保执行版能生成、能剪、能复盘。

```text
客户确认变量：
【主价值 / 产品卖点 / 画幅 / 预算级别 / 品牌禁用项 / 投放场景】

执行版转换：
客户价值 -> 镜头任务：
客户卖点 -> 产品/人物动作：
客户品牌字 -> 后期文字：
客户风险 -> 禁止项或先测镜：
客户确认项 -> 一致性锁定：

单镜任务预算：
【变量A】=【点数】，【变量B】=【点数】，合计【总点数】。

结论：
可转执行版 / 先删变量 / 先拆镜 / 先测小样 / 回客户确认
```

硬规则：

1. 客户价值只允许转成镜头任务、动作结果或后期包装，不直接生成大段可读文字。
2. 客户确认的品牌字、Logo、参数、屏幕字全部进入后期文字，不进生成画面。
3. 客户确认多个卖点时，每镜只证明一个卖点。
4. 如果客户确认变量仍不清楚，先回客户确认，不编造产品卖点或品牌禁用项。
5. 每条执行版提示词仍必须经过单镜任务预算、禁止项和失败第一刀。

失败信号：

1. 执行版只有客户话术，没有主体、动作、机位、声音、入点和出点。
2. 没有把 Logo、字幕、参数和品牌字移交后期。
3. 客户版多个价值被同一条 Seedance 镜头同时证明。
4. 生成失败后无法判断该改角色、动作、产品、运镜、文字还是声音。

### 11.2 D0 到 E0 最小执行终检

当客户只确认了 D0 极简客户卡，先不要直接写完整 Seedance 长提示词。D0 信息少，必须先补 E0 最小执行终检，判断能不能进入 E 档。

```text
D0 到 E0 终检：
D0 一句话价值：
D0 第一帧：
D0 证明链：
客户确认变量：
主镜头任务：
唯一主卖点：
不可变项：
后期文字/Logo/参数责任：
先测镜：
缺失变量：
结论：
【可进 E档 / 先回客户确认 / 先补导演版细案 / 先测小样】
```

硬规则：

1. 缺少画幅、时长、产品卖点、品牌禁用项、预算级别或投放场景时，不直接写 E 档长提示词。
2. 证明链不完整时，先补“动作 -> 变化 -> 确认”，不靠字幕解释卖点。
3. D0 的客户语言只能转成主镜头任务、后期包装或确认变量，不能原样塞进生成画面。
4. E0 通过后，仍要进入单镜任务预算、生成前冻结三件套和具体禁止项。

## 12. 与其他能力衔接

默认顺序：

```text
成片级分镜编译器
-> Seedance 镜头可生成性评分与拆镜
-> 最小测试小样选择器
-> Seedance 提示词终检与负面约束压缩器
-> 生成后回放验片与剪辑救援协议
-> 错误记忆与自动避坑案例库
```

分工：

1. 成片级分镜编译器决定镜头任务。
2. 可生成性评分决定能不能一条生成。
3. 最小测试小样选择器决定先测哪个变量。
4. 本协议决定最终提示词是否足够稳。
5. 回放验片判断生成素材能不能用。
6. 错误记忆库沉淀反复失败的提示词病灶。

## 13. 自检闸门

输出最终提示词前检查：

1. 是否只有一个镜头任务？
2. 是否只有一个主动作？
3. 是否只有一个主要运镜？
4. 是否明确后期文字和字幕安全区？
5. 禁止项是否具体而不是泛泛？
6. 是否能从失败结果判断下轮该改什么？
7. 高风险镜头是否已拆镜或先测小样？
8. 是否检查了变量冲突，并在两个以上高风险变量同镜时先踩刹车？
9. 是否计算了单镜任务预算，超过 3 点时是否降级、拆镜、后期或先测？
10. 是否做了生成前冻结，确认主任务、主变量和失败第一刀没有被后续扩写冲掉？

## 14. 最小合格线

一次 Seedance 提示词终检至少要输出：

1. 结论。
2. 主风险。
3. 变量冲突判断。
4. 单镜任务预算。
5. 生成前冻结。
6. 删掉什么。
7. 保留什么。
8. 压缩后的最终提示词。
9. 具体禁止项。
10. 失败第一刀。

少一项，就不是终检，只是把提示词又抄了一遍。
