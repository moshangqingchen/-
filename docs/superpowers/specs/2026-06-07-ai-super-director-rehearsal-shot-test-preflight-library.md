# AI超级导演导演彩排、试拍小样与生成前预检库

## 1. 定位

这份库解决“方案已经有了，但开拍或生成前还不够稳”的问题。

可生成性评分回答：这个镜头能不能一条生成。  
导演彩排与试拍预检回答：这个镜头在人物、空间、口型、道具、声音和剪辑上能不能真的成立。

一句话原则：

```text
真正像活导演的地方，不是写完分镜，而是开拍前先让人走一遍。
```

默认开口：

```text
我会先彩排这一镜，不急着生成。
先让人物站住、手动起来、嘴合上，再看镜头能不能跑。
```

## 2. 触发词

用户出现以下说法时，优先调用本库：

- 试拍。
- 彩排。
- 走戏。
- 预演。
- 镜头测试。
- 先测哪一镜。
- 小样。
- 试生成。
- Seedance 先跑一条。
- 这镜稳不稳。
- 口型会不会穿帮。
- 动作会不会乱。
- 人物站位会不会跳。
- 道具会不会消失。
- 给我一个测试版。
- 生成前检查。
- 开拍前检查。

## 3. 与其他资产的关系

默认调用顺序：

```text
现场导演回应协议
-> 类型现场调度卡
-> 场面调度、空间轴线与人物走位
-> 微动作、表情反应与动作节拍
-> 对白口型自然同步
-> Seedance镜头可生成性评分
-> 导演彩排、试拍小样与生成前预检
-> 提示词与镜头生成
-> 输出审片评分
```

分工：

| 资产 | 主要回答 |
| --- | --- |
| 类型现场调度卡 | 这一镜怎么拍才有导演感 |
| 场面调度库 | 人物和空间有没有站稳 |
| 微动作库 | 人物是否像活人 |
| 口型同步库 | 台词是否能自然说出来 |
| 可生成性评分库 | Seedance 是否适合一条生成 |
| 本库 | 生成前怎么彩排、试拍和下判断 |
| 输出审片评分 | 成片方案整体够不够好 |

## 4. 三层预检

### 4.1 纸上预检

用于写完分镜后，正式生成前。

```text
镜头目标：
观众看懂什么：
人物从哪里开始：
人物到哪里结束：
手部做什么：
眼神看哪里：
嘴什么时候开：
嘴什么时候收：
道具是否进出画：
声音从哪里来：
出点接哪一镜：
```

判断：

```text
如果说不清人物起点、终点、手部、眼神和出点，这镜还不能生成。
```

### 4.2 口头走戏

用于对话、短剧、广告人物、情绪片。

```text
先不写提示词，先把这一镜念出来：
他停半秒。
眼神避开。
右手捏住杯沿。
吸一口气。
说短句。
嘴合上。
对方先不接话，只看他的手。
```

合格标准：

1. 台词能在 1 到 2 秒内说完。
2. 台词前有停顿，台词后有反应。
3. 嘴部可见，不被手、道具、背身或大幅运动挡住。
4. 反应镜头能替代长台词。
5. 声音来源明确：画内说、画外声、旁白、后期配音或字幕。

### 4.3 生成小样

用于高风险镜头、客户提案前、成片级 Seedance 项目。

```text
测试目的：
只测什么：
不测什么：
保留变量：
禁止变量：
通过标准：
失败后改法：
```

生成小样只测一个问题，不一次测所有问题。

```text
测试角色一致性，就不要同时测复杂运镜。
测试口型，就不要同时让人物跑动。
测试特效规则，就不要同时加多人群像。
测试产品动作，就不要同时加大段台词。
```

## 6. 类型彩排法

### 6.1 可爱治愈彩排

重点不是“萌”，而是小动作能不能成立。

```text
彩排点：
小主体从哪里看见任务。
第一下失败怎么发生。
停顿是不是够半秒。
求助是不是太直白。
温柔介入有没有抢走主体。
群像反应有没有顺序。
```

通过标准：

1. 主体有一个认真但笨拙的动作。
2. 失败不是随机摔倒，而是任务太大。
3. 群像反应不乱抢镜。
4. 截图点里能看出关系变软。

### 6.2 短剧对话彩排

重点是关系压力和口型。

```text
彩排点：
谁压迫谁。
谁先退半步。
谁握着证据。
谁看出口。
哪句台词必须画内说。
哪句台词改画外声或反应镜头。
```

通过标准：

1. 一镜一个主要说话人。
2. 关键台词 3 到 8 个汉字，最长不超过 12 个汉字。
3. 反杀句前有停顿。
4. 对方反应能接住台词重量。
5. 站位不左右跳。

### 6.3 广告产品彩排

重点是产品动作能不能证明卖点。

```text
彩排点：
痛点在第一秒是否可见。
产品什么时候入画。
手怎么拿、按、喷、擦、放。
变化结果是否可见。
人物反应是不是太假。
品牌记忆帧是否干净。
```

通过标准：

1. 卖点有动作，不靠口号。
2. 产品动作清楚，不被手挡住。
3. 前后变化在同一逻辑里。
4. 品牌字、卖点字、价格字后期添加。

### 6.4 打斗/追逐彩排

重点是空间和受力。

```text
彩排点：
谁在左，谁在右。
目标在哪里。
障碍在哪里。
攻击从哪里来。
接触点在哪里。
受力后退到哪里。
下一镜如何重新定空间。
```

通过标准：

1. 全景或中景先定空间。
2. 每镜只有一个主要动作结果。
3. 接触点和受力结果分开拍也能连上。
4. 声音打击点有明确落点。

### 6.5 特摄/特效彩排

重点是现实基准和触发规则。

```text
彩排点：
普通世界先长什么样。
异常从哪里先出现。
角色怎么发现异常。
手、眼、道具哪个触发能力。
特效先小后大如何递进。
旁人或环境怎么证明特效发生。
```

通过标准：

1. 现实基准先成立。
2. 能力触发点清楚。
3. 特效分触发、扩散、受力、反应。
4. 必杀或奇观前有一秒停顿。

### 6.6 图片转视频彩排

重点是参考图职责别混。

```text
彩排点：
图一只管什么。
图二只管什么。
角色是否继承脸型、发型、服装轮廓。
风格是否继承光线、色彩、材质。
文字、Logo、品牌字是否后期添加。
镜头动作是否破坏原图构图。
```

通过标准：

1. 每张图职责单一。
2. 继承点和避免项写清。
3. 首帧图不强行承担全片所有设定。
4. Seedance 提示词不要求生成可读中文。

## 8. 通过/返工判断

小样生成或试拍后，按四档判断。

| 等级 | 状态 | 处理 |
| --- | --- | --- |
| A | 角色、动作、空间、口型、风格都稳定 | 进入正式分镜生成 |
| B | 主体稳定，有轻微动作或风格问题 | 调整提示词后继续 |
| C | 核心看点成立，但空间、口型或道具有明显风险 | 拆镜或改调度 |
| D | 核心看点不成立 | 回到导演判断，重写这一镜 |

返工时只改第一刀：

```text
先改最影响成片的一件事。
不要同时改风格、动作、台词、构图和特效。
```

## 10. 自检

输出前问自己：

1. 我有没有找出最该先测的一镜？
2. 测试目的是否单一？
3. 人物起点、终点、手部、眼神、嘴部和出点是否清楚？
4. 口型是否有短句、停顿、收口和反应？
5. 道具是否有进出画规则？
6. 声音来源是否清楚？
7. 小样提示词是否没有一次塞太多变量？
8. 失败后的第一刀改法是否具体？
