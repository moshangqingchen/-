# AI超级导演类型样片案例与导演拆解库

## 1. 定位

类型样片案例与导演拆解库负责把已有方法论转化成可直接改写、扩展和执行的原创样片母题。

它不是抄热门账号，也不是把别人的作品改名重用。它的作用是：

1. 给创意阶段提供可迅速启动的样片方向。
2. 给分镜阶段提供可复用的镜头骨架。
3. 给AI生成阶段提供角色、场景、关键帧和视频提示词方向。
4. 给发布阶段提供标题、封面、前三秒和评论区入口。
5. 给系列化阶段提供角色、道具和栏目延展。

当用户说“像某类电影/特摄/短片/广告的感觉，但要原创”时，先调用电影、特摄、短片与创意精华转译库，把参考对象拆成情绪、结构、场面调度、视觉母题、声音记忆点和原创替换规则，再进入本案例库生成原创样片母题。

默认原则：

- 学结构，不学皮相。
- 借方法，不借设定。
- 每个案例都要能换角色、换场景、换产品、换情绪。
- 每个案例都要有最强一帧和可执行分镜。
- 每个案例都要能回写到类型公式、分镜模板、提示词库和发布包装库。

## 3. 案例一：月亮失物招领处

主类型：可爱搞笑群像  
副类型：奇幻、系列IP  
适合片长：30秒、60秒

一句话创意：

```text
一个幼儿园班级发现午睡区多了一颗小月亮，孩子们认真成立“月亮失物招领处”，结果每个人都来认领。
```

观众为什么停下：

- 幼儿园和月亮的尺度反差强。
- 小角色处理大问题天然可爱。
- 每个角色都能贡献一个误会笑点。

情绪曲线：

```text
惊讶 -> 认真调查 -> 集体误会 -> 温柔收场
```

前三秒：

```text
午睡垫上躺着一颗发光的小月亮，值日生严肃地说：“是谁把夜晚带到教室里了？”
```

最强一帧：

```text
一群小朋友围着发光小月亮开会，黑板上写着“失物招领”，老师在旁边举手也想发言。
```

故事结构：

1. 发现：午睡区出现小月亮。
2. 调查：孩子们各自给出荒唐证词。
3. 误会：每个人都说月亮像自己的东西。
4. 升级：月亮越听越亮，把教室变成夜空。
5. 收束：原来月亮只是想找一个安静睡觉的地方。
6. 系列钩子：第二天太阳贴纸也来报到。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 午睡垫特写，小月亮轻轻发光 | 第一秒异常 |
| 2 | 值日生低头严肃检查月亮 | 小角色大任务 |
| 3 | 黑板写“月亮失物招领处” | 栏目记忆 |
| 4 | 三个孩子轮流举手认领 | 群像笑点 |
| 5 | 教室天花板变成星空 | 奇幻升级 |
| 6 | 大家给月亮盖小毯子 | 温柔落点 |

声音设计：

- 轻快木琴和拨弦。
- 月亮出现时加入柔软风铃。
- 孩子举手时用小鼓点制造节奏。
- 结尾降低音乐，让月亮的呼吸声成为治愈点。

AI提示词方向：

```text
soft cute kindergarten classroom, tiny glowing moon on nap mat, children gathering around with serious expressions, whimsical warm light, rounded character design, gentle comedy, cinematic close-up, clean composition
```

发布包装：

- 标题A：幼儿园今天捡到一颗月亮
- 标题B：谁把夜晚带到午睡区了？
- 标题C：全班都来认领这颗月亮
- 封面：孩子们围着发光月亮开会，黑板写“失物招领”。
- 置顶评论：如果你是老师，会让谁负责照顾月亮？

可变体：

- 换成“小太阳迟到登记处”。
- 换成“小云朵体检中心”。
- 换成品牌广告：产品变成帮助孩子记录奇思妙想的学习工具。

风险提醒：

- 不复刻任何具体账号角色。
- 不使用真实幼儿园、真实儿童肖像和真实学校标识。
- 保持善意幽默，不嘲笑孩子。

## 4. 案例二：只在雨天响起的留声机

主类型：怀旧情感  
副类型：旧物叙事、公益、亲情  
适合片长：60秒、3分钟

一句话创意：

```text
一台旧留声机只在雨天播放声音，主角每次听见的都是母亲年轻时没来得及说完的话。
```

观众为什么停下：

- 旧物和声音天然承载记忆。
- 雨天触发规则清楚。
- “没说完的话”有情感悬念。

情绪曲线：

```text
安静 -> 疑惑 -> 记忆打开 -> 情绪压住 -> 温柔回应
```

前三秒：

```text
雨滴打在窗台，留声机针头自动落下，一个年轻女人的声音说：“今天如果下雨，你记得别逞强。”
```

最强一帧：

```text
主角坐在昏黄房间中央，留声机发出微光，墙上的旧照片像被雨水慢慢照亮。
```

故事结构：

1. 触发：雨天，留声机自己播放。
2. 怀疑：主角以为机器坏了。
3. 发现：每一段声音都对应一张旧照片。
4. 情绪：主角听见母亲年轻时的担心、玩笑和道歉。
5. 回应：主角对着留声机说出自己没说过的话。
6. 留白：雨停后，留声机仍轻轻转着。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 雨滴落在窗台，室内静 | 声音入口 |
| 2 | 针头自己落下 | 旧物异常 |
| 3 | 主角手停在半空 | 情绪悬停 |
| 4 | 老照片被声音点亮 | 记忆可视化 |
| 5 | 主角背对镜头听完一句话 | 克制情绪 |
| 6 | 主角把伞放在门口，轻声回应 | 当下选择 |

声音设计：

- 雨声持续但不压过人声。
- 留声机底噪要保留年代感。
- 旁白不要过多解释，声音留言承担叙事。
- 结尾只留雨停后的房间声。

AI提示词方向：

```text
nostalgic rainy evening room, vintage gramophone glowing softly, old family photos on the wall, middle-aged protagonist listening silently, warm amber light, gentle melancholy, cinematic stillness, shallow depth of field
```

发布包装：

- 标题A：这台留声机只在雨天叫我的名字
- 标题B：有些话，隔了很多年才回来
- 标题C：我以为它坏了，直到听见妈妈的声音
- 封面：主角坐在留声机前，墙上旧照片被雨光照亮。
- 置顶评论：如果它只能播放一句话，你最想听见谁的声音？

可变体：

- 换成旧相机、旧收音机、旧雨伞、旧饭盒。
- 换成公益主题：关注空巢老人、亲情陪伴、声音记忆。
- 换成品牌故事：产品不主导煽情，而是作为保存记忆的媒介。

风险提醒：

- 不使用未授权真人照片、声音和家庭故事。
- 不把丧亲、疾病、灾难写成廉价煽情。
- 情绪要克制，避免台词过满。

## 5. 案例三：会给杯子盖被子的咖啡机

主类型：创意广告  
副类型：治愈、轻喜剧、产品拟人  
适合片长：15秒、30秒

一句话创意：

```text
一台咖啡机发现用户总是忙到咖啡变冷，于是偷偷给每个杯子盖上“小被子”，提醒人先照顾自己。
```

观众为什么停下：

- 产品拟人动作可爱。
- “咖啡变冷”是高频生活痛点。
- 卖点通过动作呈现，而不是口播硬讲。

情绪曲线：

```text
忙乱 -> 被照顾 -> 微笑 -> 记住产品
```

前三秒：

```text
桌上三杯咖啡都冒着最后一点热气，咖啡机伸出小机械臂，把一块迷你毛毯盖在杯口。
```

最强一帧：

```text
一排杯子盖着不同颜色的小被子，咖啡机在旁边像值夜班一样亮着小灯。
```

故事结构：

1. 痛点：主角忙到忘了喝咖啡。
2. 产品动作：咖啡机给杯子保温。
3. 情绪：主角回头发现小被子，笑了。
4. 卖点：保温、定时、安静提醒被动作展示。
5. 记忆帧：咖啡机灯光像小夜灯。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 冷掉的咖啡旁堆满文件 | 痛点 |
| 2 | 咖啡机小灯亮起 | 产品苏醒 |
| 3 | 机械臂轻轻盖杯垫 | 卖点动作化 |
| 4 | 主角看见杯子冒热气 | 结果证明 |
| 5 | 产品特写和品牌记忆句 | 商业收束 |

声音设计：

- 办公室键盘声作为忙乱底色。
- 咖啡机动作加轻微机械拟人音。
- 主角笑时音乐变暖。

AI提示词方向：

```text
cozy modern office desk, cute smart coffee machine with tiny mechanical arm, coffee cup covered with miniature blanket, warm steam, gentle product advertising, soft light, clean commercial composition
```

发布包装：

- 标题A：这台咖啡机比我还会照顾我
- 标题B：咖啡冷掉前，它先心疼了
- 标题C：把保温卖点拍成一个小动作
- 封面：杯子盖着小被子，咖啡机亮着温柔小灯。
- 置顶评论：你最想让哪个电器偷偷照顾你？

可变体：

- 空气净化器给房间“深呼吸”。
- 台灯帮熬夜的人把光调软。
- 收纳盒把桌面混乱排成队。

风险提醒：

- 产品功效必须真实，不夸大功能。
- 品牌露出要清楚但不压过创意。

## 6. 案例四：楼梯把时间折回昨天

主类型：特效短片  
副类型：悬疑、情感、奇观  
适合片长：60秒、3分钟

一句话创意：

```text
主角每上一层旧楼梯，都会回到昨天同一时间，直到他发现自己真正要改变的不是时间，而是一句没说出口的道歉。
```

观众为什么停下：

- 空间规则简单：楼梯等于时间回退。
- 特效奇观服务情感目标。
- 悬疑和情感可以双线推进。

情绪曲线：

```text
惊奇 -> 试探 -> 失控 -> 明白 -> 释放
```

前三秒：

```text
主角抬脚跨上楼梯，墙上的钟表倒转一圈，门外雨水瞬间倒流回天空。
```

最强一帧：

```text
螺旋楼梯悬在半空，每一级台阶上都站着昨天的主角残影。
```

故事结构：

1. 发现规则：上楼会回到昨天。
2. 测试规则：主角改变小事，现实轻微变化。
3. 目标误导：他想挽回一个结果。
4. 奇观升级：楼梯变成时间螺旋。
5. 真相：他真正逃避的是一句道歉。
6. 收束：他停在原地，不再上楼，而是打电话。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 脚踏上旧楼梯 | 规则启动 |
| 2 | 时钟、雨水、灯光倒流 | 特效验证 |
| 3 | 主角反复跑楼梯 | 欲望升级 |
| 4 | 楼梯空间折叠 | 奇观爆发 |
| 5 | 主角看见过去的自己 | 情绪真相 |
| 6 | 他放下脚，拨出电话 | 人物选择 |

声音设计：

- 时间倒流用磁带回卷音和低频上升。
- 楼梯脚步声要成为节奏骨架。
- 真相出现时停止大音乐，只留呼吸。

AI提示词方向：

```text
old apartment staircase bending through time, clocks reversing, rain flowing upward, protagonist surrounded by ghostly echoes of yesterday, cinematic sci-fi drama, realistic lighting, emotional surrealism
```

发布包装：

- 标题A：他每上一层楼，就回到昨天
- 标题B：这段楼梯把时间折坏了
- 标题C：他想改变过去，却只差一句道歉
- 封面：螺旋楼梯和多个主角残影。
- 置顶评论：如果你能回到昨天，你会先改哪一句话？

可变体：

- 电梯每开一次门进入不同时间。
- 地铁站台只通向错过的那一天。
- 商业广告：产品帮助记录、提醒或修复错过。

风险提醒：

- 特效不能只炫技，要服务人物选择。
- 时间规则要简单，避免一分钟内解释太多。

## 7. 案例五：便利店三步守门

主类型：动作打斗  
副类型：短剧、轻喜剧、空间动作  
适合片长：30秒、60秒

一句话创意：

```text
一个便利店夜班店员只用门口三步范围，挡住三个闯入者，原因只是不能让他们踩坏刚拖好的地。
```

观众为什么停下：

- 动机荒唐但明确。
- 空间限制清楚，动作好看。
- 打斗和喜剧可以同时成立。

情绪曲线：

```text
平静 -> 挑衅 -> 爆发 -> 反差笑点
```

前三秒：

```text
夜班店员刚拖完地，三个黑影推门进来，他举起“小心地滑”牌子说：“鞋底，先擦。”
```

最强一帧：

```text
店员单脚踩在拖把上滑出半步，避开攻击，同时把“小心地滑”牌子挡在门口。
```

故事结构：

1. 空间交代：便利店门口、地垫、货架、拖把、水桶。
2. 冲突：闯入者不擦鞋。
3. 第一段：店员用地垫卸力。
4. 第二段：用拖把制造滑步。
5. 第三段：用货架反弹控制距离。
6. 笑点：店员打完继续拖地，补一句“欢迎下次光临，但先擦鞋”。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 全景交代门口三步空间 | 动作地理 |
| 2 | 店员放下拖把抬眼 | 角色压迫 |
| 3 | 第一人冲进被地垫绊偏 | 攻防逻辑 |
| 4 | 店员借拖把滑步绕后 | 标志动作 |
| 5 | 货架商品整齐震动但不掉 | 喜剧控制 |
| 6 | 店员把地重新拖亮 | 反差收尾 |

声音设计：

- 开门铃作为打斗开始信号。
- 拖把、水桶、地垫都要有清晰音效。
- 打击声不必过重，保留轻喜剧质感。

AI提示词方向：

```text
night convenience store entrance, calm clerk defending freshly mopped floor, mop as improvised movement tool, clear action choreography, three-step fighting space, comedic martial arts tone, bright fluorescent light
```

发布包装：

- 标题A：他守住便利店，只为这块刚拖好的地
- 标题B：夜班店员的三步防线
- 标题C：不擦鞋，就别想进门
- 封面：店员用拖把滑步挡在门口。
- 置顶评论：你还想看他用什么店内道具打下一场？

可变体：

- 咖啡店吧台三步守杯。
- 武馆门口不许踩线。
- 品牌广告：清洁产品、地垫、便利店服务。

风险提醒：

- 动作要清楚，不写暴力血腥。
- 不让危险动作看起来适合普通人模仿。

## 8. 案例六：不会撒谎的广告牌

主类型：创意广告  
副类型：喜剧、城市奇幻、品牌传播  
适合片长：30秒、60秒

一句话创意：

```text
城市里有一块广告牌不会撒谎，所有夸张广告都会被它自动改成真实体验，直到一个真正好用的产品经过。
```

观众为什么停下：

- 广告牌“不会撒谎”的设定有讽刺喜感。
- 很适合产品证明和品牌价值。
- 可以用视觉替换制造连续笑点。

情绪曲线：

```text
好奇 -> 连续笑点 -> 产品证明 -> 记住品牌
```

前三秒：

```text
一块广告牌刚写出“全城第一”，立刻自己擦掉，改成“我也就还行”。
```

最强一帧：

```text
广告牌像有表情一样皱起灯光，把夸张口号改成一句诚实评价。
```

故事结构：

1. 建立规则：广告牌会自动纠正夸张话术。
2. 连续笑点：几个虚夸广告被改写。
3. 产品登场：一个产品只写真实卖点。
4. 验证：路人实际使用，结果符合。
5. 品牌记忆：广告牌第一次不改字，只亮得更清楚。

关键分镜：

| 镜头 | 画面 | 导演意图 |
| --- | --- | --- |
| 1 | 城市广告牌自动改字 | 设定钩子 |
| 2 | 路人停下看笑 | 观众代理 |
| 3 | 多个夸张口号被纠正 | 节奏连击 |
| 4 | 真实产品卖点出现 | 品牌进入 |
| 5 | 路人使用后点头 | 证明 |
| 6 | 广告牌安静亮起品牌句 | 记忆帧 |

声音设计：

- 广告牌改字用轻微电子擦除声。
- 每次改字给一个短促喜剧音效。

## 15. 快速改写方法

当用户喜欢某个案例，但想换题材时，按以下顺序改写：

1. 保留核心规则：例如“旧物播放声音”“小角色做大任务”“产品把痛点动作化”。
2. 替换主体：人、动物、道具、产品或空间。
3. 替换情绪：搞笑、治愈、情感、燃、悬疑或商业。
4. 替换场景：幼儿园、旧房间、便利店、办公室、地铁、门店、未来城市。
5. 替换最强一帧：保持识别度，但换成新主体的标志动作。
6. 替换发布包装：标题、封面、置顶评论跟着目标平台调整。

改写模板：

```text
我喜欢案例：
要替换成的主体：
目标类型：
目标平台：
目标片长：
必须保留的情绪：
必须展示的产品 / 主题：
不要出现的内容：
```

## 16. 导演自检

使用案例库时，必须检查：

1. 是否只是套皮，还是已经换成新的核心表达？
2. 是否有清楚的前三秒？
3. 是否有可截图成封面的最强一帧？
4. 是否至少有6个可执行镜头？
5. 是否有声音设计，而不是只有画面？
6. 是否能转成AI生图和视频提示词？
7. 是否能发布到具体平台？
8. 是否能扩展成系列？
9. 是否避开抄袭、冒用、夸大和敏感风险？
10. 是否能写回到类型公式或复盘系统？
