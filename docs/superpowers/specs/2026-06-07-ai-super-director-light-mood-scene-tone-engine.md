# AI超级导演光线情绪、场景调性与夜戏质感导演引擎

## 1. 定位

这套引擎专门处理“电影感光线、夜戏、逆光、低调光、高调光、色温、场景调性、不要影楼感、光线怎么打、画面太平、氛围不对”的需求。

它不替代视觉风格与美术指导库。视觉风格库负责统一色彩、构图、材质和风格；本引擎负责把光线当成现场调度工具：让光线推动人物选择、空间压力、产品证明、情绪变化和记忆帧。

默认判断：

```text
我会这样拍：先不说“电影感”。我先找这场戏的光从哪里来，谁站在光里，谁被压在阴影里，人物什么时候走进光、什么时候退回暗处。光线不是滤镜，是人物关系和情绪变化。
```

核心公式：

```text
戏剧任务 + 主光来源 + 明暗关系 + 色温情绪 + 人物与光的动作 + 阴影压力 + 光线变化点 + 记忆收束
```

## 3. 光线不是漂亮，是戏

光线要先服务这三个问题：

1. 观众现在应该看清什么？
2. 观众现在应该感到什么压力？
3. 人物和光的关系有没有变化？

常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 满画面都亮 | 没有重点和秘密 | 降低背景亮度，只保留主体动作的光 |
| 只说电影感 | 没有光源和方向 | 写清主光来自窗、门、屏幕、街灯、台灯或火光 |
| 夜戏全黑 | 看不清动作和表情 | 给眼神、手和关键道具留边缘光 |
| 光线乱跳 | 风格不连续 | 固定主光方向和色温，只让一个变化点发生 |
| 影楼感 | 光太干净、人物太摆 | 加入现实光源、空间遮挡、局部阴影和生活动作 |
| 情绪靠滤镜 | 人物没有被光改变 | 让人物走入光、躲开光、被光暴露或被阴影保护 |

## 4. 光线调度七问

开拍前先问：

1. 这场戏的真实光源是什么：窗、门、台灯、屏幕、路灯、车灯、冰箱、走廊灯、火光还是日光？
2. 主体最重要的动作落在哪里：脸、手、道具、产品、门口、桌面还是地面？
3. 光是保护人物，还是暴露人物？
4. 阴影压在哪里：脸一侧、背后空间、门缝、走廊尽头还是对手身上？
5. 色温关系是什么：冷压暖、暖压冷、冷暖混合、从冷到暖还是从暖到冷？
6. 这场戏有没有一个光线变化点：开灯、关灯、门开、窗帘拉开、屏幕亮起、车灯扫过、火光熄灭？
7. 最后一帧留下哪种光：留白、压迫、治愈、危险、品牌记忆还是下一集悬念？

## 5. 光线类型卡

| 光线卡 | 用途 | 现场拍法 | 避免 |
| --- | --- | --- | --- |
| 窗边柔光卡 | 治愈、生活、情感、产品质感 | 主体靠近窗边，脸和手有柔和亮面，背景低对比 | 全脸磨平、没有生活动作 |
| 侧逆光卡 | 怀旧、孤独、人物轮廓 | 光从人物后侧来，脸部留一点暗面 | 逆光过强看不清表情 |
| 门缝光卡 | 悬疑、短剧、选择压力 | 门缝或走廊光切出窄亮区，人物被迫进入或避开 | 门外信息太多、文字乱码 |
| 台灯局部光卡 | 克制情感、夜谈、旧物 | 光只照亮手、旧物、半张脸，周围保持暗 | 画面全黑或只剩台灯空镜 |
| 屏幕冷光卡 | 科技、孤独、信息压力 | 冷光落在脸和手上，屏幕内容后期添加 | 让屏幕直接生成可读字 |
| 街灯顶光卡 | 现实、危险、深夜城市 | 顶部或侧上方硬光压住人物，地面有影子 | 脸完全黑掉 |
| 霓虹混色卡 | 城市、欲望、赛博、酒吧 | 一冷一暖两种色块固定方向，人物穿过色块 | 颜色太多变成廉价滤镜 |
| 车灯扫过卡 | 追逐、惊吓、揭露 | 光束从背景或人物脸上扫过，暴露一个信息 | 频繁闪烁、动作看不清 |
| 开灯转折卡 | 产品证明、情绪转暖、空间改善 | 开关动作和结果同框或连续，光线变干净 | 只拍灯亮，不拍人反应 |
| 关灯收束卡 | 余味、结束、秘密保留 | 人物完成动作后关灯，留下声音或轮廓 | 黑场太久、信息断掉 |

## 6. 类型专用光线打法

### 6.1 可爱治愈

```text
光线任务：让小主体看起来被世界温柔接住。
```

拍法：

- 主光柔和，阴影很浅。
- 光最好落在手、杯子、毛绒边缘或桌面小任务上。
- 情绪变化用“暖光慢慢出现”，不要突然大亮。
- 最后一帧可以让主体、热气、灯光和小道具同框。

### 6.2 克制情感

```text
光线任务：让没说出口的话留在暗处。
```

拍法：

- 不要把人物全照亮。
- 旧物、手和半张脸比大哭更重要。
- 暖光出现得晚一点，像人物终于松动。
- 结尾不要大逆光煽情，用一小块光落回旧位置。

### 6.3 悬疑短剧

```text
光线任务：让观众知道哪里有危险，但暂时看不全。
```

拍法：

- 给空间一个清楚危险方向：走廊尽头、门后、桌下、窗外。
- 光线只暴露一部分证据，不把真相全部照明。
- 反转时用光线变化兑现伏笔：屏幕亮起、门打开、车灯扫到证据。
- 禁止用纯黑代替悬疑。

### 6.4 打斗动作

```text
光线任务：让动作看清楚，让受力点有重量。
```

拍法：

- 空间基准要亮：地面、出口、障碍物和双方方向清楚。
- 打击点可以用硬光、边缘光或阴影切割。
- 不要用频繁闪光遮动作。
- 每次转位都要让观众知道人从哪块光走到哪块暗。

### 6.5 特效奇观

```text
光线任务：先建立现实基准，再让异常光进入。
```

拍法：

- 开头用普通现实光，别一上来满屏能量。
- 异常光只用一种颜色或一个方向。
- 人物反应要被光照到，证明奇观在同一个空间里。
- 光线变化要有触发点：手碰道具、按钮按下、门打开、声音响起。

### 6.6 创意广告

```text
光线任务：把卖点变成看得见的变化。
```

拍法：

- 产品出现前，痛点光线可以混乱、暗、脏或冷。
- 产品动作后，光线变得更集中、更干净或更有秩序。
- 不要只拍产品发光，要拍人物和空间被改变。
- 品牌记忆帧里保留产品、结果和一块干净后期文字区。

### 6.7 企业品牌片

```text
光线任务：真实可信，不像PPT摆拍。
```

拍法：

- 混合自然光和办公室实际灯光。
- 人物脸上保留轻微阴影，不要磨平。
- 解决方案出现时，光线不必变神圣，只要工作场景变清楚。
- 数据、Logo、屏幕字和客户名后期添加。

## 7. 夜戏调度

夜戏不是“画面很黑”，而是“世界只剩必要的光”。

夜戏三层：

| 层级 | 作用 | 例子 |
| --- | --- | --- |
| 可见层 | 让观众看懂动作 | 脸侧、手、门把手、地面路线 |
| 压力层 | 让空间有未知 | 背景暗处、走廊尽头、窗外反光 |
| 记忆层 | 留下一帧 | 台灯、路灯、车灯、手机冷光、月光边缘 |

夜戏 Seedance 写法：

```text
夜戏但主体动作清楚，主光来自[台灯/街灯/屏幕/门缝/车灯]，光线只照亮[脸侧/手/关键道具]，背景保持低亮度但能看见空间轮廓。人物从[暗处/亮处]走向[亮处/暗处]，动作克制，避免纯黑、过曝、频繁闪烁和看不清表情。
```

## 8. 光线变化点

一场戏最多保留一个主要光线变化点。变化点要和剧情有关。

| 变化点 | 适合 | 表达 |
| --- | --- | --- |
| 开灯 | 产品、空间、顿悟 | 问题被解决或信息被看见 |
| 关灯 | 余味、秘密、结束 | 人物选择沉默或故事留白 |
| 门开进光 | 短剧、悬疑、关系 | 外部压力进入 |
| 窗帘拉开 | 治愈、重启、生活 | 人物愿意面对世界 |
| 屏幕亮起 | 科技、孤独、信息差 | 信息暴露或压力到来 |
| 车灯扫过 | 动作、追逐、惊吓 | 危险临近或真相闪现 |
| 火光变弱 | 情感、灾难、古风 | 希望、记忆或生命力变化 |
| 霓虹变色 | 城市、欲望、反转 | 人物状态或空间规则改变 |

## 12. 自检

输出前检查：

1. 是否写清真实光源，而不是只写“电影感”？
2. 是否写清主光方向和光质？
3. 主体动作、脸、手和关键道具是否能看清？
4. 阴影是否有叙事功能，而不是随便黑？
5. 色温关系是否服务情绪或空间，不是乱堆颜色？
6. 是否只有一个主要光线变化点？
7. 夜戏是否保留可见层、压力层和记忆层？
8. 是否避免影楼感、过曝、纯黑、频繁闪烁和看不清动作？
9. 屏幕字、Logo、品牌字和可读中文是否规划为后期添加？
