# AI超级导演分镜模板库

## 1. 使用方式

这份模板库用于把创意快速拆成可拍、可生成、可剪辑的镜头结构。用户给出片长、类型或一句想法后，AI超级导演先选择片长模板，再叠加类型公式。

默认判断顺序：

1. 片长：15秒、30秒、60秒、3分钟、5分钟。
2. 目的：广告转化、剧情钩子、情绪表达、特效展示、动作场面。
3. 主类型：可爱、治愈、特效、打斗、创意广告、短剧等。
4. 输出：镜头表、节奏说明、声音剪辑、AI提示词骨架。

## 2. 15秒模板

### 2.1 适用场景

强钩子广告、产品种草、可爱片段、治愈小瞬间、单一卖点展示。

### 2.2 节奏结构

| 时间 | 镜头 | 目标 |
| --- | --- | --- |
| 0-2秒 | 镜头1 | 钩子：异常画面、可爱动作、痛点瞬间或强台词 |
| 2-5秒 | 镜头2 | 建立主体和场景 |
| 5-9秒 | 镜头3 | 产品、情绪或动作介入 |
| 9-13秒 | 镜头4 | 结果变化或记忆瞬间 |
| 13-15秒 | 镜头5 | 标志性收束：一句话、一个动作、一帧画面 |

### 2.3 分镜规则

- 镜头数量控制在4到6个。
- 第一镜必须直接给看点，不铺背景。
- 每个镜头只表达一个动作或一个卖点。
- 结尾要能截图，适合做封面或海报。

### 2.4 AI提示词骨架

15秒短视频，第一镜强钩子，中段主体动作清楚，后段展示结果变化，最后一帧形成记忆点，节奏紧凑，镜头运动简洁，适合竖屏传播。

## 3. 30秒模板

### 3.1 适用场景

完整广告、治愈短片、小反转剧情、产品使用场景、轻剧情种草。

### 3.2 节奏结构

| 时间 | 段落 | 目标 |
| --- | --- | --- |
| 0-3秒 | 钩子 | 痛点、反差、情绪或悬念 |
| 3-8秒 | 建立 | 主体、空间、关系、问题 |
| 8-15秒 | 介入 | 产品、人物动作、事件变化 |
| 15-23秒 | 证明 | 前后对比、情绪松动、效果显现 |
| 23-30秒 | 收束 | 品牌记忆、反转、治愈落点或传播句 |

### 3.3 分镜规则

- 镜头数量控制在7到10个。
- 8秒前必须让观众知道“发生了什么”。
- 广告片要让产品至少出现两次：一次介入，一次证明。
- 情绪片要有状态变化：紧绷到放松、失落到被接住。

### 3.4 AI提示词骨架

30秒短片结构，开头强钩子，快速建立人物和问题，中段产品或事件介入，后段通过对比和反应证明变化，结尾有清楚记忆点，电影感但节奏紧凑。

## 4. 60秒模板

### 4.1 适用场景

短剧开场、创意广告、情绪短片、特效展示、完整产品故事。

### 4.2 节奏结构

| 时间 | 段落 | 目标 |
| --- | --- | --- |
| 0-5秒 | 开场钩子 | 冲突台词、危险动作、奇观或痛点 |
| 5-15秒 | 关系建立 | 主角欲望、场景、阻碍 |
| 15-30秒 | 第一次升级 | 误会、产品介入、特效异常、打斗试探 |
| 30-45秒 | 第二次升级 | 代价加大、奇观爆发、情绪转折 |
| 45-55秒 | 释放 | 反转、证明、胜负、情绪修复 |
| 55-60秒 | 余味 | 悬念、品牌记忆或最强一帧 |

### 4.3 分镜规则

- 镜头数量控制在12到18个。
- 30秒处需要一次明显升级，避免中段松掉。
- 如果是短剧，结尾留新问题。
- 如果是广告，结尾回到卖点或品牌动作。
- 如果是特效，至少有“现实基准、异常、爆发、反应”四类镜头。

### 4.4 AI提示词骨架

60秒竖屏或横屏短片，开场高强度钩子，中段两次升级，包含人物欲望、冲突和视觉变化，结尾释放后留下记忆点或悬念，镜头表清晰，声音和剪辑节奏完整。

## 5. 3分钟模板

### 5.1 适用场景

完整短片、治愈故事、动作段落、特效短片、品牌故事、短剧试播段落。

### 5.2 节奏结构

| 时间 | 段落 | 目标 |
| --- | --- | --- |
| 0-15秒 | 引子 | 一帧抓人，明确气质 |
| 15-45秒 | 建立 | 主角、欲望、空间、问题 |
| 45-90秒 | 发展 | 行动开始，阻碍出现 |
| 90-135秒 | 升级 | 冲突加剧，情绪或视觉进入高点 |
| 135-165秒 | 转折 | 反转、失败、发现或牺牲 |
| 165-180秒 | 落点 | 释放、余味、品牌或悬念 |

### 5.3 分镜规则

- 镜头数量控制在25到45个。
- 45秒前完成世界和人物建立。
- 90秒左右必须改变方向，不能只是重复同一种情绪。
- 打斗段落要分段：试探、压制、反击、反转。
- 治愈段落要分层：疲惫、靠近、松动、接住。

### 5.4 AI提示词骨架

3分钟完整短片，结构包含引子、建立、发展、升级、转折和落点，人物动机明确，镜头有情绪递进，关键段落具备可生成画面提示词，整体有电影节奏和清楚剪辑点。

## 6. 5分钟模板

### 6.1 适用场景

短剧单集、完整短片、复杂动作戏、复杂特效段落、品牌微电影。

### 6.2 节奏结构

| 时间 | 段落 | 目标 |
| --- | --- | --- |
| 0-20秒 | 强开场 | 直接给冲突、悬念、奇观或情绪状态 |
| 20-60秒 | 第一场 | 建立人物欲望和主要阻碍 |
| 60-120秒 | 第二场 | 行动展开，问题变复杂 |
| 120-210秒 | 第三场 | 冲突升级，打斗/特效/情感爆点 |
| 210-270秒 | 第四场 | 反转、失败、代价或真相 |
| 270-300秒 | 结尾 | 情绪释放、品牌收束或下一集悬念 |

### 6.3 分镜规则

- 镜头数量控制在45到80个。
- 每一场都必须改变人物处境。
- 单集短剧结尾留悬念；完整短片结尾留余味。
- 打斗或特效不能只集中在结尾，前面要埋规则和空间。
- 广告微电影要让品牌价值嵌入人物选择，而不是最后贴标。

### 6.4 AI提示词骨架

5分钟短剧或短片，强开场进入冲突，四到五场推进人物欲望、阻碍和代价，中段有明显爆点，后段反转或情绪释放，结尾形成悬念或余味，镜头可拍可生成，声音和剪辑策略完整。

## 7. 类型叠加规则

### 7.1 可爱叠加

- 增加特写比例。
- 每15秒至少安排一个可截图小动作。
- 声音使用轻快细节音，不压过主体。

### 7.2 治愈叠加

- 镜头平均时长略微拉长。
- 用光线和环境声推动情绪。
- 结尾留白，不用过度解释。

### 7.3 特效叠加

- 任何片长都要先建立现实基准。
- 特效升级至少三层：异常、变化、爆发。
- 奇观后接人物反应镜头。

### 7.4 打斗叠加

- 开打前先交代空间。
- 每段动作都要有攻防因果。
- 关键打击点配合停顿、音效和表情。

### 7.5 创意广告叠加

- 前3秒给痛点或反常识画面。
- 卖点必须变成动作。
- 结尾必须有品牌记忆帧。

### 7.6 短剧叠加

- 第一场直接进入冲突。
- 每场都有新代价。
- 结尾留下一句台词、一个动作或一个画面悬念。

## 9. 导演自检

1. 片长结构是否匹配用户需求？
2. 前3到5秒是否有钩子？
3. 中段是否有升级而不是平铺？
4. 结尾是否有记忆点、余味或悬念？
5. 镜头是否包含景别、机位、运动、声音和剪辑点？
6. AI提示词是否能生成具体画面？
