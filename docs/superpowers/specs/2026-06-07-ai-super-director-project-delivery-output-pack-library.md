# AI超级导演项目交付包与输出模板库

## 1. 定位

项目交付包与输出模板库负责把AI超级导演的能力组织成“用户拿到手就能继续执行”的标准交付物。

前面的能力库解决“怎么想、怎么拍、怎么生成、怎么发布”。这份文档解决：

1. 用户说不同需求时，应该交付哪一包内容。
2. 每个交付包包含哪些固定模块。
3. 交付物怎样从灵感走到执行。
4. 什么样的输出算完整，什么样只是半成品。
5. 如何让短片、短剧、广告、AI生成、系列IP和发布复盘都有统一交付标准。

核心原则：

```text
交付不是多写内容，而是让下一步更容易发生。
```

## 2. 交付分级

### 2.1 快速包

适合：

- 用户只想先看方向。
- 需要快速判断一个创意能不能做。
- 需要多个备选方案。

交付标准：

- 1句话判断。
- 1个主推方向。
- 3到5个关键点。
- 1个最强一帧。
- 1个升级建议。

### 2.2 标准包

适合：

- 用户要完整导演方案。
- 需要进入分镜或AI生成。
- 需要给团队或客户看。

交付标准：

- 类型判断。
- 创意核。
- 故事结构。
- 角色和场景。
- 分镜表。
- 视觉风格。
- 声音设计。
- AI提示词。
- 发布包装。

### 2.3 制作包

适合：

- 用户要马上拍、生成、剪辑。
- 需要镜头级执行。
- 需要控制角色一致性和画面一致性。

交付标准：

- 角色圣经。
- 场景圣经。
- 镜头表。
- 关键帧提示词。
- 视频提示词。
- 声音提示词。
- 剪辑节奏表。
- 质量门禁。

### 2.4 商业包

适合：

- 产品广告。
- 门店宣传。
- 品牌故事。
- 信息流投放。
- 招商或客户提案。

交付标准：

- 卖点提炼。
- 观众痛点。
- 创意钩子。
- 产品动作。
- 证明镜头。
- 品牌记忆帧。
- 标题封面。
- 投放版本。
- 风险边界。

### 2.5 复盘包

适合：

- 已有方案需要升级。
- 已发布作品需要总结。
- 需要沉淀可复用经验。

交付标准：

- 一句话判断。
- 最强一帧。
- 最弱一段。
- 问题定位。
- 升级方案。
- 可写回经验。
- 下次测试变量。

## 3. 交付包选择规则

```text
用户说“先看看方向” -> 快速创意包
用户说“完整方案” -> 完整导演提案包
用户说“分镜/拍摄/镜头” -> 分镜制作包
用户说“生图/视频/关键帧” -> AI生成执行包
用户说“广告/产品/品牌/门店” -> 商业广告投放包
用户说“短剧/一集/连载” -> 短剧开发包
用户说“IP/系列/角色宇宙” -> 系列IP孵化包
用户说“发布/爆款/封面标题” -> 平台发布包
用户说“升级/复盘/哪里不行” -> 复盘升级包
用户说“给客户看/提案” -> 客户提案包
用户说“成片级/直接可执行/整条Seedance/按类型做完整片” -> 类型成片交付标准包库
```

如果用户没有指定，默认使用“标准包”，但内容长度根据任务复杂度收缩。

## 4. 快速创意包

### 4.1 触发场景

- “帮我想一个短片创意。”
- “这个方向能不能做？”
- “给我几个点子。”
- “要一个像绒耀幼儿园那种，但原创。”
- “要一个像旧梦留声机那种情感方向。”

### 4.2 交付模板

```text
一句话判断：
主类型：
副类型：
一句话创意：
观众为什么会停下：
最强一帧：
前三秒：
情绪走向：
可扩展方向：
我最推荐的升级：
```

### 4.3 合格标准

1. 不是只给题材词，而是给完整创意句。
2. 有观众停下的理由。
3. 有能截图成封面的最强一帧。
4. 有下一步可扩展方向。

## 14. 组合交付规则

复杂项目可以组合多个交付包。

示例：

```text
AI短片正式制作 = 完整导演提案包 + 分镜制作包 + AI生成执行包 + 平台发布包
商业广告 = 商业广告投放包 + 分镜制作包 + 客户提案包 + 平台发布包
系列账号 = 系列IP孵化包 + 类型样片案例包 + 平台发布包 + 复盘升级包
短剧项目 = 短剧开发包 + 分镜制作包 + 表演台词包 + 平台发布包
成片级Seedance项目 = 类型成片交付标准包 + AI生成执行包 + 输出审片评分包
```

组合时避免重复输出。已经在前一包写过的内容，后一包只引用和深化。

## 15. 交付完整性检查

每次交付前检查：

1. 用户需求是否被识别成正确交付包？
2. 是否有一句话导演判断？
3. 是否有明确主类型和副类型？
4. 是否有观众停下的理由？
5. 是否有最强一帧？
6. 是否能拆成镜头？
7. 是否包含声音或音乐方向？
8. 是否有AI提示词或执行说明？
9. 是否有标题、封面或发布建议？
10. 是否有风险提醒？
11. 是否知道下一步该做什么？

## 16. 常见半成品警报

以下输出不算合格交付：

- 只有灵感，没有结构。
- 只有剧情，没有镜头。
- 只有分镜，没有声音。
- 只有提示词，没有生成顺序。
- 只有广告口号，没有卖点动作。
- 只有标题，没有封面和前三秒。
- 只有复盘批评，没有可执行升级。
- 只有客户话术，没有执行流程。

每次交付最后可以用一句简短收尾，告诉用户下一步。

可选句式：


```text

```


```text

```
