# AI超级导演高概念短片、单一规则与一分钟叙事引擎

## 1. 定位

这份引擎专门处理“高概念短片、创意短片、一分钟短片、一个规则撑起一条片”的需求。它不负责铺庞大世界观，而是把一个反常规则压进可拍、可剪、可生成的短片结构里。

一句话原则：

```text
先让观众看见反常结果，再用最少镜头证明规则，最后把规则逼到人物选择上。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “高概念短片”“一分钟短片”“创意短片”“一个规则撑起一条片”。
- “想一个脑洞但要能拍”“规则感强一点”“不要铺太多设定”。
- “第一帧要反常”“用一个设定讲完”“短片要有余味”。
- “像短片导演一样处理”“不要只给概念，要能拆成 Seedance 镜头”。

如果用户同时说“电影感、特摄感、吸取精华、像某类作品但原创”，先用电影、特摄、短片与创意精华转译库提炼导演骨架，再用本引擎把“规则”落成短片结构。

## 3. 高概念短片总公式

```text
一个反常结果 + 一个简单规则 + 三次规则证明 + 一个角色选择 + 一个情绪转向 + 一个余味动作
```

拆解：

- 反常结果：第一帧直接出现，观众不用听解释也会停住。
- 简单规则：一句话能讲清，最好能被画面证明。
- 三次规则证明：第一次让观众懂，第二次升级，第三次逼人物做选择。
- 角色选择：主角不是参观设定，而是在规则里失去或得到某样东西。
- 情绪转向：从好奇、好笑、紧张或奇观，转到心软、刺痛、释放或余味。
- 余味动作：结尾不解释，用一个小动作让观众自己补完。

## 4. 导演判断

收到高概念需求时，先这样判断：

```text
我会这样拍：这个短片不能先讲设定，先让规则造成一个看得见的后果。保留一个最强反常点，舍掉世界观解释，第一刀先把规则压成一句话，再把它逼到人物选择上。
```

必须先回答四个问题：

1. 规则一句话是什么？
2. 第一帧的反常结果是什么？
3. 这个规则会伤到谁、帮到谁或逼谁选择？
4. 结尾有没有一个不用台词解释的余味动作？

## 5. 单一规则设计

好规则要满足四个条件：

| 条件 | 判断方式 | 失败表现 |
| --- | --- | --- |
| 可见 | 观众能从画面看懂规则发生了 | 全靠旁白解释 |
| 可升级 | 同一规则能越来越麻烦或越来越动人 | 只有一个脑洞，没有后续 |
| 有代价 | 角色使用或抵抗规则会失去东西 | 像展示设定 |
| 可落地 | 4-6秒镜头能生成一个明确动作 | 一镜里塞太多变化 |

规则写法：

```text
在这个世界里，[普通动作/物件/声音] 会导致 [反常结果]，但代价是 [关系/时间/记忆/身体/选择]。
```

示例骨架：

- 每次说谎，身边的灯就少亮一盏。
- 被忘记的人，会先从合照里的影子消失。
- 只要有人道歉，地上的裂缝就往回合拢一点。
- 产品广告里：每解决一次痛点，空间里的噪音就少一层。

## 6. 一分钟结构

默认按 60 秒拆：

| 段落 | 时间 | 功能 | 拍法 |
| --- | --- | --- | --- |
| 反常开门 | 0-3秒 | 让观众停住 | 直接给反常结果，不解释 |
| 规则证明1 | 3-12秒 | 让观众看懂规则 | 一次普通动作触发一次结果 |
| 规则证明2 | 12-25秒 | 让规则升级 | 结果影响到关系、空间或目标 |
| 角色选择 | 25-42秒 | 把脑洞变成人物戏 | 主角必须用规则或拒绝规则 |
| 情绪转向 | 42-52秒 | 从脑洞转成人心 | 角色反应、停顿、收回动作 |
| 余味收口 | 52-60秒 | 留下可复述结尾 | 一个小动作回收规则和母题 |

## 7. 第一帧与前三秒

高概念短片的第一帧不要解释背景。第一帧直接给：

- 反常结果：人影从镜子里迟到半秒。
- 反常秩序：全班同学都静止，只有一只铅笔在写字。
- 反常物件：桌上的旧照片里少了一个人，但椅子还在动。
- 反常声音：画面安静，人物嘴没动，广播却说出他的心里话。

前三秒问题：

```text
为什么这个普通世界突然按这个奇怪规则运转？
```

不要把前三秒用来讲世界观、角色履历、字幕设定或旁白说明。

```text

画面预留干净字幕安全区；可读文字、标题和品牌字后期添加。
避免多规则、长解释、复杂文字、过多人物同时动作和不可控Logo。
```

## 11. 自检

输出前自问：

1. 规则是否一句话能讲清？
2. 第一帧是否直接出现反常结果？
3. 三次规则证明是否逐步升级，而不是重复同一个展示？
4. 角色是否真的做了选择？
5. 情绪是否从脑洞转向人心、关系、代价或余味？
6. 结尾是否有一个可截图、可复述的小动作？
7. Seedance 2.0 每镜是否只证明一个变量？
8. 是否避免了世界观过载、长旁白、乱码文字和一镜多规则？
