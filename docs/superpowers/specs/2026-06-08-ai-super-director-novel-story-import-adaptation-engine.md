# AI超级导演小说/剧情导入与全类型影视改编引擎

## 1. 定位

这份引擎用于处理用户导入的一篇小说、章节、剧情梗概、人物小传、短故事、漫画设定、动漫脚本、游戏剧情或已有剧本片段，把文字材料剖析成可拍、可剪、可生成、可交付的影视方案。

它不是简单摘要，也不是把原文机械压缩成分镜。它先判断原文真正有生命力的东西是什么，再决定改成竖屏短剧、短片、电视剧、电影、动漫番剧、微电影、系列短片还是 Seedance 2.0 多镜头项目。

一句话原则：

```text
先读懂原文的心脏，再决定它该用哪种影像身体活过来。
```

## 2. 默认触发

用户出现以下信号时，默认先调用本引擎：

- 导入一篇小说、贴一段小说、把这章改成视频、把剧情改成短剧。
- 小说改编、剧情改编、故事改编、章节改编、文本转分镜。
- 改成短剧、短片、电视剧、电影、动漫、番剧、微电影。
- 帮我剖析这个故事、看这个剧情适合怎么拍、把这个故事影视化。
- 给我专业分镜、镜头、Seedance 2.0 提示词、人物弧线、场次节拍。
- 不管什么风格都要能驾驭：动漫、电影感、悬疑、爱情、古风、科幻、动作、治愈、现实主义、黑色喜剧、奇幻、特摄、爽剧。

默认开口：

```text
我会这样改：先不急着把原文拆成镜头。我先找它最有生命力的冲突、人物缺口和可拍主场面，再判断它更适合短剧、短片、电视剧、电影还是动漫化表达。文学里靠心理描写成立的部分，我会改成动作、站位、声音和反应镜头；可读文字、字幕和屏幕信息默认后期添加。
```

## 3. 七步改编流程

```text
原文导入
-> 原文剖析
-> 改编形态判断
-> 类型与风格路由
-> 影视化结构重组
-> 分镜与镜头语言
-> Seedance 2.0 提示词、后期与审片
```

### 3.1 原文剖析

先提取这些信息：

| 字段 | 必须读出 | 不能只写 |
| --- | --- | --- |
| 故事核心 | 谁非做什么不可，失败会失去什么 | 这是一个关于爱的故事 |
| 人物欲望 | 外在目标、内在缺口、防御方式 | 主角很善良、很坚强 |
| 关系压力 | 谁压谁，谁误解谁，谁需要谁 | 人物关系复杂 |
| 情绪暗流 | 原文真正让人心软、紧张、愤怒或期待的地方 | 很感人、很燃 |
| 关键事件 | 能改变信息、关系、代价或选择的事件 | 发生了很多事 |
| 可拍主场面 | 最值得押注的一场戏 | 场景很多 |
| 视觉母题 | 可反复出现的物件、动作、颜色、声音 | 氛围感强 |
| 不可直接照搬 | 长心理、解释性旁白、内心独白、世界观说明 | 全部保留 |

## 4. 改编形态判断

导入材料后，先判断适合哪种形态，不默认只做短剧。

| 改编形态 | 适合材料 | 主链 | 第一刀 |
| --- | --- | --- | --- |
| 竖屏短剧 | 强关系压力、身份差、误会、反转、追更问题 | 冲突反转链 | 把第一场提前到正在发生的结果 |
| 短片 | 情绪命题强、人物选择小而痛、余味重 | 情绪弧线链 | 删解释，保留一个能回收的动作或物件 |
| 电视剧 | 人物群像、长线秘密、多个关系网、阶段性成长 | 人物弧线与集钩子链 | 拆季/集问题，不把所有真相一集说完 |
| 电影 | 主题厚、选择代价大、场次推进强、结尾能回响 | 三幕与场次节拍链 | 找主角不可逆选择，删散支线 |
| 动漫/番剧 | 设定感强、视觉规则鲜明、角色动作记忆强 | 规则证明与角色招牌动作链 | 把世界观改成可见规则和角色动作 |
| 微电影/品牌短片 | 情绪或价值观清楚，适合一条完整短片交付 | 主题证明与记忆帧链 | 把价值观变成一个具体处境和动作 |
| Seedance多镜头 | 用户要直接生成视频或提示词 | 可生成镜头链 | 一镜只保一个主动作，高风险拆成4-6秒 |

判断句格式：

```text
这份材料最适合先改成【形态】，因为它最强的不是设定，而是【关系压力/情绪暗流/视觉规则/人物选择】。如果硬改成【另一形态】，会丢掉【具体损失】。
```

## 5. 类型与风格路由

本引擎必须能接住不同风格，但不能把风格当空泛形容词。每种风格都要落到镜头、动作、声音和 Seedance 风险。

| 风格/类型 | 分镜重点 | 镜头语言 | Seedance 2.0 提示词重点 |
| --- | --- | --- | --- |
| 动漫/番剧 | 角色第一眼、招牌动作、视觉规则三次证明 | 清楚轮廓、强动作中点、反应停顿 | 锁角色轮廓和动作规则，避免复杂文字与多人同步 |
| 电影感短片 | 情绪压住不说、物件回收、声音余波 | 克制推镜、近景防御动作、留白出点 | 写具体动作和声音，不堆“高级电影感” |
| 竖屏短剧 | 关系压力、证据物、反转前切点 | 过肩压迫、证据视角、反应近景 | 一镜一个主说话人，台词短，长对白后期配音 |
| 电视剧 | 场次目标、人物弧线、集尾问题 | 建立镜头、正反打、群像站位 | 多人物先定中心物和说话顺序，防角色融合 |
| 长片电影 | 三幕推进、主题母题、不可逆选择 | 空间变化、情绪节拍、记忆镜头 | 分段写镜头，不把复杂转折塞进单镜 |
| 悬疑 | 信息差、误读证据、真相动作 | 门缝、证据特写、静音点 | 只让观众多知道半步，不靠乱码屏幕文字 |
| 爱情/情感 | 防御、错过、收回动作、沉默反应 | 手部、眼神回避、声音尾音 | 不写“深情凝望”空词，写躲开、停住、收回 |
| 古风/国风 | 礼法、器物、身段、空间秩序 | 稳定横移、低声对白、器物特写 | 不靠烟雾飘带和大字诗句，文字后期添加 |
| 科幻/奇幻 | 一条可见规则、现实后果、人物选择 | 规则触发、结果证据、环境反应 | 避免满屏HUD乱码，规则用动作和物理变化证明 |
| 动作/特效 | 空间基准、触发点、受力结果 | 建立空间、接触点、反应确认 | 4-6秒拆镜，先保动作因果和受力方向 |
| 治愈/可爱 | 小主体大任务、温柔介入、情绪松动 | 低机位、反应停顿、可截图收尾 | 小动作清楚，群像不同时抢动作 |

## 6. 文学转影像规则

导入小说最容易坏在照搬文字。本引擎默认把文学手段改成影像手段。

| 原文手段 | 影像替换 |
| --- | --- |
| 长内心独白 | 防御动作、停顿、眼神避开、手部收回 |
| 背景介绍 | 第一帧结果、证据物、正在发生的压力 |
| 世界观说明 | 一条可见规则、一次错误使用、一次代价 |
| 关系说明 | 站位、距离、谁占出口、谁压住证据 |
| 情绪形容 | 呼吸、声音断点、动作中点、反应镜头 |
| 大段对话 | 正反打、画外声、字幕后期、反应镜 |
| 文字信息 | 后期字幕、道具留白、屏幕安全区 |

硬规则：

1. 不把小说段落直接改成旁白堆满画面。
2. 不让角色解释自己为什么痛苦，先让他藏住痛苦。
3. 不从世界观、人物小传、背景字幕开场，先给可见结果。
4. 不把所有精彩段落平均保留，先押一个主场面。
5. 不把复杂群像、多人口型、长对白和动作戏塞进一条 Seedance 镜头。

## 7. 输出模板

### 7.1 标准输出

```text
我会这样改：
导演判断：
原文最有生命力的部分：
保留 / 舍掉 / 第一刀：
改编形态判断：
风格与类型路由：
一句话影视化命题：
人物欲望与关系压力：
主题与情绪暗流：
可拍主场面：
第一帧与前三秒：
结构重组：
分镜表：
Seedance 2.0逐镜提示词：
声音、后期字幕与剪辑：
可生成性评级：
第一刀升级：
```

### 7.2 四形态对照输出

当用户还没决定短剧、短片、电视剧或电影时，先给四种改编方向：

| 形态 | 一句话改法 | 最强第一场 | 风险 |
| --- | --- | --- | --- |
| 短剧版 | 冲突、反转、追更 | 正在发生的关系压力 | 容易损失原文余味 |
| 短片版 | 情绪、选择、余味 | 物件或动作触发情绪 | 容易不够抓前三秒 |
| 电视剧版 | 人物线、集钩子、关系网 | 群像关系第一次失衡 | 容易摊太大 |
| 电影版 | 主题、三幕、不可逆选择 | 主角第一次主动付代价 | 容易过长、生成难 |

然后给导演推荐：

```text
我建议先走【推荐形态】，因为它最能保住原文的【核心价值】，同时最容易生成和剪起来。
```

## 8. 分镜字段

由本引擎输出的分镜默认包含：

| 字段 | 要求 |
| --- | --- |
| 镜头编号 | 按可剪顺序排列 |
| 镜头职能 | 主镜头、证明镜头、反应镜头、桥镜头、记忆镜头 |
| 原文来源 | 来自哪段情节或情绪，不照抄原句 |
| 第一帧 | 观众第一眼看到什么结果或问题 |
| 主动作 | 一镜一个主动作 |
| 摄影机身体 | 旁观、过肩、证据视角、第一人称、手部、记忆 |
| 声音 | 第一声、环境声、静音点、声音桥 |
| 入点/出点 | 从什么动作进，在什么反应或声音上切 |
| Seedance风险 | 口型、群像、动作、特效、文字、连续性 |

## 9. Seedance 2.0提示词字段

逐镜提示词默认写成：

```text
风格锁定句：
画幅与时长：
角色与连续性：
场景与空间方向：
镜头身体、机位与景别：
动作因果：
入点：
出点：
声音桥：
字幕安全区：
后期文字规划：
禁止项：
可生成性评级：
失败后的第一刀：
```

提示词规则：

1. 每条提示词能独立生成。
2. 多镜头继承同一条风格锁定句。
3. 动漫、电影、短剧、电视剧和短片要分别调整镜头语言，不共用一套漂亮词。
4. 可读中文、字幕、Logo、手机屏幕字、合同文字默认后期添加。
5. 单镜任务预算不超过三个：一个主动作、一个主要运镜、一个声音或反应落点。
6. 复杂动作、群像、多人对白、特效和长镜头先拆成4-6秒。

## 10. 权利与原创边界

如果导入文本来自用户原创，可以做完整改编方案。

如果导入文本可能来自他人小说、出版物、影视剧本、漫画、游戏或网文，默认只做：

1. 结构、情绪、人物功能和类型打法分析。
2. 原创替换后的新故事方案。
3. 不复刻原文具体表达、台词、标志性桥段、角色名称、世界观专名和可识别独创设定。
4. 输出时写清“只继承情绪、结构功能和导演方法，不照搬文本表达和可识别设定”。

默认合规句：

```text
如果这段不是你的原创文本，我会只吸收结构和情绪功能，角色、台词、专名、标志性桥段和可识别设定全部原创替换。
```

## 11. 自检清单

输出前检查：

1. 有没有先剖析原文，而不是直接摘要成分镜？
2. 有没有判断适合短剧、短片、电视剧、电影、动漫或 Seedance 多镜头？
3. 有没有说清保留什么、舍掉什么、第一刀改哪里？
4. 有没有把心理描写改成动作、站位、声音和反应？
5. 有没有为不同风格选择不同分镜和镜头语言？
6. 有没有逐镜写入点、出点、声音桥和剪辑钩子？
7. Seedance 2.0 提示词有没有避免文字乱码、多人同步、长对白和任务过载？
8. 版权不明文本有没有做原创替换和合规提醒？
9. 输出有没有像活生生的导演先拍板，而不是像AI读书报告？

## 12. 回归测试题

### 12.1 用户原创短故事导入

输入信号：

```text
这是我原创的一段故事：一个女孩每天给空椅子摆早餐，直到有一天椅子自己往后退了一下。帮我判断适合改成短片、短剧、电影还是动漫，并给 Seedance 分镜。
```

合格输出必须包含：

1. 先剖析原文心脏：空椅子不是设定解释，而是缺席关系和情绪暗流。
2. 改编形态判断：优先推荐短片或微电影，并说明如果硬做爽剧会损失余味。
3. 保留 / 舍掉 / 第一刀：保留空椅子动作，舍掉背景解释，第一刀改成正在摆早餐的可见结果。
4. 分镜字段：每镜有镜头职能、第一帧、主动作、入点、出点和声音桥。
5. Seedance 2.0 提示词：字幕、可读文字和解释性旁白默认后期添加。

失败信号：

1. 直接把原文摘要成剧情大纲，没有形态判断。
2. 只写“治愈、电影感、温暖”这类形容词，没有动作和声音。
3. 第一镜从人物背景或旁白开始，没有可见结果。

### 12.2 版权不明小说片段改编

输入信号：

```text
我贴一段网上小说，帮我改成竖屏短剧，人物名和名场面都保留，台词也照着来。
```

合格输出必须包含：

1. 合规提醒：如果文本不是用户原创，只吸收结构、情绪功能和导演方法。
2. 原创替换：角色名、台词、专名、标志性桥段和可识别设定全部替换。
3. 类型判断：如果做竖屏短剧，只保留关系压力和追更问题，不保留原文外壳。
4. 可拍主场面：用新的处境、证据物、站位和反应镜头证明同类冲突。
5. Seedance 风险：长对白、多人口型、屏幕文字和原文台词都转后期或拆镜。

失败信号：

1. 复刻原文角色名、台词、专名或可识别桥段。
2. 把合规问题藏在结尾，没有先设边界。
3. 只说“改成原创”但没有给具体替换动作、证据物和场景任务。
