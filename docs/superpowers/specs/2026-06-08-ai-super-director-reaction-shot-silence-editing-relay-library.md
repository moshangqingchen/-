# AI超级导演反应镜头、沉默表演与剪辑接力库

## 1. 定位

这份库专门处理反应镜头：事件发生后，谁先反应，怎么反应，沉默留多久，声音怎么接，下一镜从哪里进。

它不替代微动作库、镜头呼吸库和覆盖镜头库：

- 微动作库负责身体细节。
- 镜头呼吸库负责一镜内部节奏。
- 覆盖镜头库负责一场戏能不能剪起来。
- 本库负责把“事件之后的人”拍活。

一句话：

```text
主镜头让事情发生，反应镜头让事情被相信。
```

很多 AI 短片的问题不是缺事件，而是事件发生后没人真正接住：打中了像没打中，产品生效了像没生效，情绪来了像没进身体，笑点发生了却没人慢半拍，反转说完就切，观众来不及感到“这一下重要”。

## 2. 触发信号

用户出现这些说法时，默认调用本库：

- “人物不活。”
- “没有反应。”
- “情绪没落点。”
- “笑点不响。”
- “动作没重量。”
- “特效不可信。”
- “产品效果没人确认。”
- “这场戏剪不起来。”
- “反应镜头怎么补？”
- “沉默怎么拍？”
- “台词说完怎么接？”
- “别让人物尬演。”
- “像真人导演一点。”
- “口型风险太高，能不能用反应镜？”
- “主镜头失败了，怎么用反应救？”

## 3. 导演判断

```text
我会这样拍：
先别急着让人物解释。事件发生后，先看谁被打中，谁忍住，谁假装没事，谁慢半拍懂了。反应镜头不是拖节奏，是让观众知道这一秒真的改变了关系。
```

保留：

- 事件后的第一眼。
- 手、肩、呼吸、身体重心。
- 沉默里的压力。
- 能接下一镜的声音或视线。

舍掉：

- 所有人同时震惊。
- 夸张表情替代真实反应。
- 台词解释刚发生了什么。
- 每个反应镜都大哭、大喊、大瞪眼。
- 反应没有出点，剪辑悬空。

第一刀：

```text
先选一个最该反应的人，再决定反应落在眼神、手、身体、声音还是沉默上。
```

## 4. 反应镜头五问

每个反应镜头先问：

1. 谁最需要反应：主角、对手、旁观者、使用者、环境还是道具？
2. 他知道了什么：被伤到、看懂秘密、确认结果、意识到危险、发现荒诞？
3. 他想藏住什么：害怕、心软、得意、心虚、痛、尴尬、被感动？
4. 身体哪里先暴露：眼神、手、呼吸、肩膀、脚步、嘴角、道具触碰？
5. 下一镜接什么：视线、动作、声音、道具、沉默还是反向台词？

判断句：

```text
反应不是演情绪，是人物努力不让情绪露出来时，身体先露馅。
```

## 5. 主反应人裁决

多人、群像、广告见证、打斗围观和短剧对峙里，不是每个人都应该同等反应。每个事件先选一个主反应人，其他人只能做副反应、延迟反应或不反应。

判断顺序：

```text
谁的关系被改变最大？
谁掌握的信息刚刚变化？
谁最想藏住反应？
谁的反应能证明事件真的发生？
谁的反应能接下一镜？
```

反应归属表：

| 场景 | 主反应人 | 副反应 | 禁止 |
| --- | --- | --- | --- |
| 短剧狠话 | 被打中的主角或关系对象 | 旁观者交换眼神 | 全员同时震惊 |
| 广告效果 | 正在使用产品的人 | 旁人停下催促或靠近 | 人物对镜夸产品 |
| 打斗受力 | 被打中或刚站稳的人 | 对手重新锁定目标 | 只拍爆炸不拍身体 |
| 特效奇观 | 第一个相信奇观的人 | 环境轻动或人群后退 | 所有人同一秒尖叫 |
| 可爱群像 | 最认真误解的小主体 | 其他角色慢半拍 | 群像同时卖萌 |
| 情感旧物 | 和旧物关系最深的人 | 旁人不打扰 | 用台词解释回忆 |
| 悬疑发现 | 第一个发现异常的人 | 另一个人没发现 | 镜头替角色解释 |
| 产品证明 | 手部动作执行者 | 结果旁观者确认 | 产品自己宣布卖点 |

裁决输出：

```text
主反应人：
为什么是他：
副反应谁做：
谁不反应：
反应落点：
下一镜接法：
```

如果选不出主反应人，说明事件没有真正打到关系、信息、身体或证据上，先回到主镜头重写触发事件。

## 6. 反应时间轴

### 6.1 听见前

用途：让观众知道人物还没准备好。

可拍动作：

- 手正要拿杯子。
- 眼神还停在别处。
- 身体正要离开。
- 嘴角还保持礼貌。
- 旁人正在做小动作。

Seedance 写法：

```text
事件发生前，角色手停在杯沿旁，眼神还没有看向说话人，身体保持克制。
```

### 6.2 听见中

用途：让信息打到身体上。

可拍动作：

- 手停住。
- 眼神轻轻抬起。
- 呼吸断一下。
- 肩膀绷住。
- 身体重心没动，但脚尖定住。

Seedance 写法：

```text
听到那句话的一瞬间，角色没有立刻说话，手指停在杯沿，眼神只抬起一点。
```

### 6.3 忍住反应

用途：高级、真实、克制。

可拍动作：

- 眼神想看对方又收回。
- 手指松开又重新握住。
- 嘴角想动但压住。
- 低头整理无关物件。
- 呼吸变浅，不开口。

### 6.4 假装没事

用途：短剧、情感、喜剧、职场、家庭。

可拍动作：

- 继续做原动作，但慢半拍。
- 把手机扣回桌面。
- 低头喝水掩饰。
- 点头太快。
- 笑了一下，马上没了。

导演句：

```text
不要演“我没事”，演他为了让别人相信没事，做了一个多余的小动作。
```

### 6.5 破防瞬间

用途：情感释放、短剧反转、广告结果确认。

可拍动作：

- 眼神终于看向对方。
- 肩膀落下来。
- 手从道具上松开。
- 身体后退半步。
- 想说话但没说出来。

### 6.6 收回动作

用途：余味和剪辑出点。

可拍动作：

- 把手收回袖口。
- 把旧物放回原处。
- 视线落到门口。
- 杯底轻轻碰桌。
- 环境声重新进入。

剪辑点：

```text
在收回动作完成的一拍切，不要等人物解释。
```

## 7. 反应镜头类型

| 类型 | 用途 | 反应落点 | 避免 |
| --- | --- | --- | --- |
| 听见反应 | 台词、秘密、告白、审问 | 眼神、呼吸、手停住 | 立刻用台词解释 |
| 受力反应 | 打斗、撞击、超能力 | 肩膀、脚步、扶墙、喘气 | 只有爆炸没有身体 |
| 结果确认 | 产品、广告、实验、科普 | 看问题再看结果 | 产品效果一闪而过 |
| 喜剧慢半拍 | 荒诞、误会、可爱群像 | 一个人先懂或最后懂 | 全员同时夸张 |
| 沉默压迫 | 短剧、家庭、职场、悬疑 | 不回答、低头、旁人退半步 | 空停太久 |
| 破防收回 | 情感、治愈、旧物 | 手松开、眼神收回、长呼气 | 直接大哭 |
| 群像波纹 | 会议、饭桌、教室、团队 | 由近到远依次反应 | 同时动同时说 |
| 环境反应 | 特效、悬疑、灾变、魔法 | 灯闪、窗震、灰尘落 | 环境抢主角 |
| 道具反应 | 怀旧、产品、证据 | 旧物响、杯子晃、合同滑动 | 要求可读文字 |
| 口型兜底 | 长对白或口型失败 | 听的人反应、画外声 | 硬拍长句嘴型 |

## 8. 台词后余波接力

台词不是嘴巴闭上就结束。真正像真人的对白，必须有“说完后的半秒”：说话人收回自己，听的人接住信息，声音或动作给剪辑出点。

默认接力顺序：

```text
台词落点 -> 说话人收口 -> 听者反应 -> 声音余波 -> 下一镜钩子
```

五种收口方式：

| 台词类型 | 说话人收口 | 听者反应 | 声音余波 | 剪辑出点 |
| --- | --- | --- | --- | --- |
| 狠话/威胁 | 眼神不追对方，低头整理物件 | 被打中者手停住 | 房间静一拍 | 手停住或视线抬起 |
| 告白/心软 | 说完马上移开视线 | 对方先不笑，呼吸松一点 | 环境声回来 | 对方眼神回看前切 |
| 反转信息 | 说完不解释 | 听者慢半拍懂了 | 远处脚步或道具声 | 听者第一次看向证据 |
| 广告确认 | 不夸产品，手停住 | 旁人看结果而不是看镜头 | 产品动作声尾音 | 结果被确认的一拍 |
| 喜剧短句 | 说话人继续认真 | 群像静半拍 | 小道具声封口 | 静默后主角继续做事 |

输出时必须补一句：

```text
说完后的半秒：
【说话人怎么收回】 -> 【听者身体哪里先反应】 -> 【声音怎么封口】 -> 【下一镜从哪里接】
```

禁忌：

1. 不要台词一结束就切空镜，除非空镜本身承担反应。
2. 不要让说话人说完还等对方用台词解释。
3. 不要让听者立刻满表情，先给身体一个小反应。
4. 不要用大段旁白补台词余波，优先用呼吸、道具声、环境声或视线。
5. 口型高风险时，关键句后面必须接反应镜或画外声兜底。

## 9. 类型反应打法

### 9.1 短剧

原则：

```text
狠话之后先看被打中的人，不急着接下一句。
```

拍法：

- 压迫者说短句。
- 主角不马上回嘴。
- 手抓包带或压住证据。
- 旁观者交换眼神。
- 主角最后抬眼，切下一镜。

### 9.2 情感治愈

原则：

```text
情绪不要直接流出来，先被身体藏一下。
```

拍法：

- 听到旧声音。
- 手指停在旧物边缘。
- 低头吸气。
- 想抬眼但没有。
- 环境声接住沉默。

### 9.3 喜剧可爱

原则：

```text
笑点不是荒诞动作本身，是大家认真对待它之后的停顿。
```

拍法：

- 荒诞任务完成。
- 认真角色先点头。
- 慢半拍角色才反应。
- 群像停住一拍。
- 一个小道具声封口。

### 9.4 打斗特效

原则：

```text
力量落在受力反应里。
```

拍法：

- 打击点清楚。
- 受力者退到障碍前。
- 手扶墙稳住。
- 呼吸变重。
- 眼神重新锁定对手。

### 9.5 创意广告

原则：

```text
卖点需要人确认，不是产品自己宣布。
```

拍法：

- 使用者先看痛点。
- 产品动作完成。
- 使用者手停住。
- 眼神从结果回到产品。
- 肩膀放松或旁人停下催促。

### 9.6 群像会议

原则：

```text
群像反应像波纹，不像开关。
```

拍法：

- 离中心物最近的人先停。
- 主角眼神变化。
- 阻碍者压住反应。
- 旁观者慢半拍交换眼神。
- 收尾角色用一个小动作接住。

## 10. Seedance 2.0 反应镜字段

每条反应镜提示词默认增加：

```text

触发事件：

身体落点：
是否说话：
声音余波：
台词后接力：
剪辑出点：
禁止项：
```

提示词骨架：

```text
4-6秒视频镜头。风格锁定：[延续项目视觉圣经]。
本镜是反应镜头，反应对象是[角色/群像/使用者/对手/环境/道具]，触发事件是[一句话/动作结果/产品效果/打击点/特效异常]。
反应阶段：[听见中/忍住反应/假装没事/破防瞬间/收回动作]。身体落点只选一个：[眼神/手部/呼吸/肩膀/脚步/道具触碰]。
角色[不说话/只说一句3-8个汉字短句]，其他人只做轻反应。声音余波是[环境声/道具声/呼吸/短静音]。
台词后接力：[说话人收回动作 -> 听者身体反应 -> 声音封口 -> 下一镜钩子]。
剪辑出点停在[眼神收回/手放下/杯底轻响/身体后退半步/环境声进入]。
避免夸张表情、多人同时说话、长台词、复杂运镜、可读文字、Logo和字幕乱码。
```

## 11. 反应镜作为救援

主镜头失败时，先判断能不能用反应镜救：

| 主镜问题 | 反应镜救法 | 不能救的情况 |
| --- | --- | --- |
| 动作后半段乱 | 保留前半段，切受力或结果反应 | 动作因果完全反了 |
| 口型有点怪 | 改画外声，切听的人反应 | 关键信息听不懂 |
| 产品结果太短 | 补使用者确认反应 | 产品外观或功能错 |
| 特效不够可信 | 补人物看见异常的反应 | 特效方向和剧情相反 |
| 笑点不响 | 补慢半拍反应和封口声 | 荒诞动作本身看不懂 |
| 情绪太平 | 补手部停顿或眼神收回 | 人物关系没建立 |
| 群像太乱 | 改成单人反应和中心物插入 | 角色已经融合变形 |

判断句：

```text
能用反应镜救的，不急着重跑主镜。不能救地基的，别用反应镜硬遮。
```

## 13. 最小合格线

一次反应镜设计至少要写清：

1. 触发事件。
2. 主反应人和为什么是他。
3. 副反应或不反应的人。
4. 反应阶段。
5. 身体落点。
6. 是否说话。
7. 声音余波。
8. 说完后的半秒或台词后接力。
9. 剪辑出点。
10. 禁止项。

少一项，反应镜就容易变成“给个表情”，而不是能剪、能演、能生成的导演动作。

## 14. 自检

输出前自问：

1. 事件发生后，谁最应该被看见？
2. 有没有选出唯一主反应人，并压低其他人的反应？
3. 这个人知道了什么，想藏住什么？
4. 反应是否落在一个身体部位，而不是抽象情绪词？
5. 是否避免所有人同时震惊？
6. 是否用沉默、道具声或环境声接住情绪？
7. 是否有明确剪辑出点？
8. 是否能降低口型、群像、动作或特效风险？
9. Seedance 2.0 提示词是否只要求一个主要反应？
10. 如果有台词，是否写清台词落点后的收口、听者反应、声音封口和下一镜钩子？
