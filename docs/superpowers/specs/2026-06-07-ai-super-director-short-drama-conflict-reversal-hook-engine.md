# AI超级导演短剧冲突、反转与追更钩子导演引擎

## 1. 定位

这份引擎专门处理竖屏短剧、短剧开头、爽剧、反转剧情、悬疑短片、情感冲突、连续剧集、特效短剧和追更型内容。

它不替代剧本结构库，而是把“短剧怎么抓人、怎么压关系、怎么反转、怎么让观众想看下一集”拆成现场导演能直接执行的镜头动作。

短剧的核心不是“讲一个故事”，而是让观众立刻站进一个关系压力里。

## 2. 默认调用时机

用户说以下词，默认先调用本引擎：

- 短剧、竖屏短剧、短剧开头、第一集、连续剧、爽剧。
- 冲突、压迫、反转、悬念、误会、秘密、身份反转、下一集。
- 想看后续、追更、站队、爽点、打脸、反杀、关系拉扯。
- 开头太慢、没冲突、不够爽、反转平、结尾没钩子。

默认开口：

```text
我会这样拍：
第一镜不解释背景，先把观众扔进关系压力里。让一个人想要东西，另一个人挡住他，中间放一个证据或秘密。短剧要先让观众站队，再让反转重新解释刚才那一切。
```

## 3. 短剧核心公式

```text
人物欲望 + 阻碍者 + 关系压力 + 信息差 + 视觉伏笔 + 选择代价 + 反转释放 + 下一集问题
```

现场导演拆法：

1. 主角现在必须要什么。
2. 谁挡住他。
3. 两个人关系里谁压谁。
4. 观众知道什么，角色不知道什么。
5. 哪个道具或动作提前埋下反转。
6. 主角如果赢，会失去什么。
7. 反转不是吓人，是重新解释动机。
8. 结尾不是“未完待续”，而是留下一个具体新问题。

## 4. 第一场冲突公式

短剧第一场不能慢热。默认用这个结构：

```text
正在发生的结果 + 冲突台词 + 关系压迫 + 证据出现 + 主角被迫选择
```

例子：

```text
门被推开，女主手里攥着离婚协议。
男主没看她，只把一枚戒指放到桌上。
第一句台词：“你现在签，还是等他们把照片发出去？”
```

导演判断：

- 不先解释他们是谁。
- 不让角色寒暄。
- 第一件事就让观众知道：有人被逼到选择边缘。

### 4.1 关系压力事件账本

短剧开场不能只有“吵起来了”，必须有一件正在发生、会改变关系的事。观众要在第一场就看见谁逼谁、拿什么逼、主角如果不动会失去什么。

先填这张账本：

| 字段 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 正在发生的结果 | 第一帧已经发生了什么不可逆事件 | 从人物背景讲起 |
| 主角欲望 | 主角此刻非要拿到、守住或阻止什么 | 主角只是被动挨骂 |
| 阻碍动作 | 阻碍者用什么具体动作挡住他 | 只写“反派很坏” |
| 关系压力 | 谁有权力、谁被迫选择、谁不能退 | 只有台词，没有站位 |
| 证据物 | 哪个道具、文件、手机、伤痕或位置能改变局面 | 反转靠口头解释 |
| 信息差 | 观众、主角、阻碍者各多知道哪半步 | 全员都知道或全员都不知道 |
| 选择代价 | 主角赢了会失去什么，输了会失去什么 | 赢了就赢了，没有代价 |
| 第一切点 | 在哪个动作、声音或眼神上切断 | 镜头自然结束，没有追更 |

硬规则：

- 第一场必须有一件“正在发生的结果”，不要从人物介绍、字幕背景或世界观设定开始。
- 阻碍者必须做动作：挡门、按住证据、逼近半步、把手机反扣、把合同推近、叫人进来。
- 关系压力必须能从站位看见：谁占出口、谁压住证据、谁坐着不动、谁被迫站住。
- 反转释放前必须有一个“看见但没理解”的证据物；反转后用一个动作改写证据意义。
- 第一切点不要切在解释上，要切在证据露出、脚步响起、手机震动、眼神变了或手停住。

快速输出格式：

| 正在发生的结果 | 主角欲望 | 阻碍动作 | 关系压力 | 证据物 | 信息差 | 选择代价 | 第一切点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [第一帧结果] | [非要什么] | [挡住动作] | [谁压谁] | [可拍伏笔] | [谁多知道半步] | [赢/输的代价] | [切断动作/声音] |

### 4.2 观众站队句门禁

短剧第一场不是让观众知道设定，而是让观众立刻站队。输出前必须写出一句观众会说的话。

| 门禁项 | 必须回答 | 不合格信号 | 第一刀 |
| --- | --- | --- | --- |
| 我站谁 | 观众会先替谁着急、替谁不服或想看谁反击 | 两边都只是吵，谁都不想支持 | 加主角欲望或被逼选择 |
| 因为什么动作 | 哪个阻碍动作、越界动作或保护动作让观众站队 | 只有狠话，没有动作证据 | 改成挡门、按证据、逼近、收回、护住 |
| 我想看什么后果 | 观众下一秒想看打脸、解释、逃出、救人还是反杀 | 只想知道背景 | 改第一切点，切在代价或证据上 |

输出句式：

```text
观众站队句：
我站【角色】，因为我看见【对方/他自己做了什么动作】，所以我想看【下一步后果】。
```

硬规则：

1. 站队句说不出来，不进入分镜，先重写第一场冲突。
2. “他好惨/他很帅/她很强”不算站队理由，必须有动作证据。
3. 如果观众只想知道背景，不想看下一步，第一切点失败。
4. 站队可以临时误导，但反转后必须重新解释这个站队理由。

## 5. 冲突类型表

| 冲突类型 | 核心问题 | 可拍动作 | 适合题材 |
| --- | --- | --- | --- |
| 权力冲突 | 谁能控制局面 | 挡门、按住文件、逼近、停住对方手 | 爽剧、职场、豪门 |
| 身份冲突 | 真实身份会不会暴露 | 戒指、证件、伤痕、旧照片被看见 | 反转、悬疑、都市 |
| 情感冲突 | 谁先承认在乎 | 不看对方、递物又收回、说狠话后停顿 | 情感、复合、亲情 |
| 利益冲突 | 谁会失去利益 | 合同、转账、录音、钥匙出现 | 商战、职场、家庭 |
| 秘密冲突 | 谁知道真相 | 手机消息亮起、录音机启动、门外有人听见 | 悬疑、狗血、反转 |
| 危险冲突 | 谁会受伤或被追上 | 倒计时、脚步逼近、门锁晃动 | 动作、特效、逃亡 |
| 道德冲突 | 谁做了不能回头的事 | 主角放下证据或撕掉证据 | 情感、现实、悬疑 |

## 6. 信息差设计

短剧留人靠信息差，不靠乱藏信息。

### 6.1 观众知道，角色不知道

适合制造紧张。

```text
观众看到门外的人影，角色还在屋里说秘密。
```

### 6.2 角色知道，观众不知道

适合制造悬疑。

```text
主角听到一句话后突然停住，但镜头只给她握紧的手。
```

### 6.3 A知道，B不知道

适合制造压迫。

```text
男主知道照片是假的，但女主不知道；他故意不解释，让她先签字。
```

### 6.4 所有人都误会一件事

适合反转释放。

```text
大家以为主角在逃，其实他一直在引对方进入有监控的走廊。
```

## 7. 反转规则

反转必须提前埋伏笔。

```text
伏笔动作 -> 错误理解 -> 冲突升级 -> 真相动作 -> 重新解释
```

| 伏笔 | 前半段误导 | 后半段反转 |
| --- | --- | --- |
| 戒指 | 以为是感情背叛 | 原来是身份证明 |
| 伤痕 | 以为主角软弱 | 原来他保护过对方 |
| 合同 | 以为要卖掉公司 | 原来是救人的交换条件 |
| 手机消息 | 以为是暧昧 | 原来是求救信号 |
| 钥匙 | 以为要离开 | 原来能打开密室或证据柜 |
| 录音 | 以为是威胁 | 原来是替人留证 |

导演判断：

- 反转前要有一镜让观众“看见但没理解”。
- 反转后不要解释太久，用一个动作改写前面。
- 反转释放要带代价，否则不爽。

## 8. 爽点和释放

爽点不是主角突然赢，而是压力被看见、忍耐有原因、反击有证据。

```text
被压迫 -> 忍住不解释 -> 对方越界 -> 证据落下 -> 主角反击 -> 对方第一次停住
```

| 爽点类型 | 释放动作 | 必须满足 |
| --- | --- | --- |
| 打脸 | 证据公开、身份揭开 | 前面被误解过 |
| 反杀 | 主角用对方规则赢 | 前面被压制过 |
| 救场 | 关键人物或证据出现 | 前面给过缺口 |
| 保护 | 主角替别人挡住代价 | 前面建立在乎 |
| 觉醒 | 主角不再后退 | 前面有防御和忍耐 |
| 反讽 | 对方说过的话反打自己 | 前面台词要短而狠 |

## 9. 关系压迫调度

关系要用空间拍出来。

| 关系状态 | 站位 | 镜头 |
| --- | --- | --- |
| 一方控制 | 控制者靠近门、证据或出口 | 低机位中近景 |
| 被逼选择 | 被压者在桌边或墙边不退 | 近景，留手部动作 |
| 秘密夹在中间 | 证据放在两人之间 | 俯拍或过肩 |
| 关系松动 | 两人距离缩短半步 | 稳定推镜 |
| 权力反转 | 原本坐着的人站起，原本逼近的人停住 | 中景看清距离变化 |

Seedance 2.0 空间锁定示例：

```text
空间锁定：门在画面右后方，桌子在中央，录音笔放在桌面中间。女主站在桌子左侧，男主站在门口右侧。冲突升级时男主向桌边靠近半步，女主不后退，只把手压在录音笔上。
```

## 10. 人称运镜

| 人称 | 摄影机像谁 | 适合任务 |
| --- | --- | --- |
| 旁观第三人称 | 像站在房间角落的人 | 建立关系和站位 |
| 过肩压迫 | 像被某人挡住视线 | 对话冲突、逼问 |
| 第一人称被逼问 | 像观众就是被压迫的人 | 强代入、危险、羞辱 |
| 证据视角 | 像桌上的合同、手机、录音笔 | 反转伏笔 |
| 门缝/偷听视角 | 像第三方在暗处看 | 悬疑、秘密曝光 |
| 反应近景 | 像导演贴近脸看变化 | 爽点释放、真相落下 |

导演判断：

- 同一条 Seedance 2.0 镜头只保留一个人称身份。
- 人称切换放在剪辑点，不在镜头里硬切。
- 反转前用证据视角，反转后用反应近景。

## 11. 短剧节奏模板

### 11.1 15秒强钩子

```text
0-2秒：冲突结果已经发生。
2-5秒：第一句狠话或危险动作。
5-9秒：证据或秘密露出一点。
9-13秒：主角被迫选择。
13-15秒：反转前切断，留下具体问题。
```

### 11.2 60秒短剧开头

```text
0-5秒：关系冲突或身份反转。
5-15秒：主角欲望和阻碍者清楚。
15-30秒：误会、秘密或代价升级。
30-45秒：视觉伏笔出现，主角第一次失势。
45-55秒：反转释放或证据落下。
55-60秒：新问题出现，指向下一集。
```

### 11.3 3分钟竖屏短剧

```text
0-10秒：强冲突开场。
10-40秒：欲望、阻碍、关系压力。
40-80秒：第一次误会升级。
80-120秒：第二个秘密或新阻碍。
120-160秒：主角选择付出代价。
160-175秒：反转释放。
175-180秒：下一集问题。
```

## 14. 自检清单

输出短剧方案前检查：

1. 第一镜是否直接进入冲突、危险、反常结果或身份问题？
2. 第一场是否有正在发生的结果，而不是背景介绍？
3. 主角欲望是否一句话能说清？
4. 阻碍者是否用具体动作挡住主角？
5. 关系压力是否能从站位和动作看见？
6. 是否有证据物提前出现，并能在反转后被重新解释？
7. 信息差是否明确，不是乱藏信息？
8. 选择代价是否成立，主角赢或输都要付出东西？
9. 第一切点是否落在动作、声音、视线或证据上？
10. 反转是否提前埋了视觉伏笔？
11. 爽点是否来自压力释放，而不是突然赢？
12. 下一集问题是否具体？
13. Seedance 2.0 每镜是否只承担一个冲突动作或一个信息变化？
14. 关键台词、手机字、合同字和字幕是否规划为后期添加？
15. 是否写出观众站队句，并且站队理由来自动作证据？
