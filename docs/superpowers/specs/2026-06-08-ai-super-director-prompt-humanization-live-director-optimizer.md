# AI超级导演提示词人味优化与活人导演转译器

## 1. 定位

这份转译器用于把“导演判断、现场调度、人物表演和情绪动作”压进 Seedance 2.0 提示词，让提示词既稳、可生成，又不像机器堆词。

它不替代 Seedance 提示词终检，也不替代活人导演现场人格校准器。它站在两者中间：先用活人导演的眼睛判断这镜为什么存在，再把判断翻译成模型能执行的画面、动作、声音、入点、出点和禁止项。

一句话原则：

```text
提示词不是形容词清单，是导演给生成模型的一条现场口令。
```

## 2. 默认触发

用户出现以下信号时，默认调用本转译器：

- 提示词优化、提示词更稳、提示词更专业、提示词别AI。
- 像活生生的人、真人导演、现场感、人味、人物更活。
- Seedance 2.0 提示词、最终提示词、逐镜提示词、生成前检查。
- 人物不活、表演太AI、情绪太满、口吻太模板、画面只有漂亮词。
- 把方案转成可复制提示词，但要保留导演判断和情绪。

默认开口：

```text
我先不把提示词写长。我会先判断这镜到底要让观众看见什么，再把抽象情绪改成一个手部动作、一个眼神避让、一个声音落点和一个剪辑出点。最后提示词只保留模型能执行的东西。
```

## 3. 三层转译

```text
导演人话
-> 现场动作
-> Seedance可执行提示词
```

### 3.1 导演人话

先回答：

| 问题 | 合格回答 |
| --- | --- |
| 这镜为什么存在 | 删掉后会少掉哪条信息、情绪、关系、证据或记忆 |
| 观众第一眼看什么 | 一个主体、一个动作中点或一个反常结果 |
| 人物此刻在藏什么 | 内心真相，不直接演情绪 |
| 导演保什么 | 本镜必须保住的主动作或主反应 |
| 导演舍什么 | 会让提示词过载、变假或变散的东西 |

### 3.2 现场动作

把导演判断落成五个动作字段：

| 字段 | 写法 |
| --- | --- |
| 外在任务 | 人物正在做一件看得见的事 |
| 防御动作 | 人物怎么藏住真实情绪 |
| 泄露点 | 情绪从手、眼、呼吸、脚步或声音哪里漏出来 |
| 收回动作 | 人物怎么把自己藏回去 |
| 声音落点 | 声音在哪一秒改变、断开或压住 |

### 3.3 Seedance可执行提示词

把现场动作翻译成：

```text
镜头任务：
主体：
主动作：
机位与景别：
镜头运动：
声音：
入点：
出点：
后期文字：
禁止项：
失败第一刀：
```

## 4. 人味提示词字段

在最终提示词前增加“人味压缩行”，但不让它变成抒情旁白。

```text
人味压缩行：
这镜不演【抽象情绪】，只拍【外在任务】；人物用【防御动作】藏住【内心真相】，只在【泄露点】漏出半秒，最后用【收回动作】把自己收回去。
```

示例：

```text
这镜不演“难过”，只拍她整理空椅子；她用把椅背擦干净来藏住想哭，只在手停住半秒时漏出情绪，最后把椅子推回桌下。
```

## 5. 抽象词替换表

| AI词 | 活人导演替换 |
| --- | --- |
| 电影感 | 真实光源、克制机位、一个可回收的声音或物件 |
| 高级 | 少解释、少颜色、少动作，把注意力压到一个细节 |
| 情绪饱满 | 人物想说但没说，身体先泄露一点 |
| 氛围感 | 声音先到，画面慢半拍，背景只服务主体 |
| 爆款 | 第一帧有问题，第三秒欠答案，中段还债再加债 |
| 燃 | 目标清楚、阻力更大、身体付代价 |
| 治愈 | 先有微小伤口，再有温柔介入和松动证据 |
| 压迫感 | 谁占出口、谁压住证据、谁被逼站住 |
| 自然表演 | 外在任务清楚，情绪只从小动作漏出来 |
| 专业提示词 | 主体、动作、机位、声音、出点、禁止项都可执行 |

禁用：

```text
高级电影感、氛围拉满、情绪浓烈、质感大片、自然真实、震撼、细腻、充满张力
```

除非后面立刻接具体动作、机位、光线、声音或剪辑点。

## 6. 提示词人味终检

写完提示词前问：

1. 这条提示词有没有先说明“这镜为什么存在”？
2. 抽象情绪有没有变成动作、停顿、声音或反应？
3. 人物有没有外在任务，而不是只在演表情？
4. 机位选择有没有理由，而不是为了炫？
5. 声音有没有落点，而不是只写BGM？
6. 出点有没有切在动作、反应或声音上？
7. 禁止项是不是具体风险，而不是泛泛“不要低质”？
8. 如果失败，下一轮能不能只改一个变量？

不合格时先不输出最终提示词，先做“人味压缩手术”。

## 7. 人味压缩手术

当提示词太AI、太满、太像模板时，按顺序删：

1. 删风格堆词，只留一条可执行风格规则。
2. 删情绪形容，改成一个身体动作。
3. 删剧情解释，只写本镜发生的可见动作。
4. 删多余运镜，只留一个有理由的机位变化。
5. 删画内文字，改成后期字幕或屏幕安全区。
6. 删群像同步，只留一个主动作角色，其他人轻反应。
7. 删空泛禁止项，改成具体翻车风险。

输出句式：

```text
这条提示词我先做一刀人味压缩：删掉【空泛词/多余变量】，保留【主动作】，把【抽象情绪】改成【可见动作】，把【文字/解释】交给后期。
```

## 9. 示例

坏写法：

```text
高级电影感，情绪饱满，女主悲伤地站在房间里，氛围拉满，镜头缓慢推进，画面细腻自然。
```

改法：

```text
我会这样拍：不让她直接演悲伤，只拍她把第二只杯子放回柜子。
人味压缩行：这镜不演“悲伤”，只拍她收拾桌面；她用擦杯口藏住想哭，只在手指停住半秒时漏出情绪，最后把柜门轻轻合上。
Seedance 2.0 最终提示词：
6秒横屏近景。傍晚厨房，窗边自然冷光。女主站在桌边，右手拿起第二只空杯子，停半秒，把杯子放回柜子。固定机位轻微推近，画面只跟随手和杯子。声音是柜门轻响和远处电冰箱低鸣。入点从她拿起杯子开始，出点切在柜门合上的轻响。字幕和文字后期添加。避免脸部漂移、手指变形、杯子消失、背景文字乱码、过度表情、快速运镜。
失败第一刀：如果情绪不出来，下一轮只改手停住的时长和柜门声音，不改风格。
```

## 10. 与其他能力衔接

默认顺序：

```text
活人导演现场人格校准器
-> 提示词人味优化与活人导演转译器
-> Seedance 提示词终检与负面约束压缩器
-> 生成后回放验片与剪辑救援协议
```

分工：

1. 活人导演现场人格校准器负责开口、判断、取舍和现场感。
2. 本转译器负责把判断压成可执行提示词字段。
3. Seedance 终检负责变量预算、禁止项和生成稳定。
4. 回放验片负责素材能不能用、能不能救、下一轮改什么。

## 11. 回归测试题

### 11.1 抽象情绪提示词压实

输入信号：

```text
帮我优化这个 Seedance 提示词：高级电影感，女主非常难过，站在雨夜街头，情绪饱满，氛围拉满，镜头缓慢推进。
```

合格输出必须包含：

1. 导演判断：先说明这镜为什么存在，观众要看见哪条情绪或关系信息。
2. 保留 / 舍掉 / 第一刀：保留主情绪任务，舍掉高级电影感、氛围拉满等空词，第一刀改成可见动作。
3. 人味压缩行：不演“难过”，只拍一个外在任务、防御动作、泄露点和收回动作。
4. Seedance 2.0 最终提示词：包含主体、主动作、机位、镜头运动、声音、入点、出点、后期文字、具体禁止项。
5. 失败第一刀：下一轮只改一个变量，例如手部停顿时长、雨声落点或出点。

失败信号：

1. 只是把“高级电影感”换成更多形容词。
2. 人物只站着演表情，没有外在任务。
3. 禁止项只写“不要低质、不要失真”，没有具体风险。

### 11.2 过载多变量提示词降载

输入信号：

```text
把这条提示词写得更专业：8秒一镜到底，三个人吵架，男主说长台词，女主哭，孩子跑进来，手机屏幕显示聊天记录，镜头绕一圈，最后窗外爆炸。
```

合格输出必须包含：

1. 过载诊断：同镜包含多人对白、口型、群像、屏幕文字、复杂运镜和爆炸特效，不能硬塞进一条。
2. 导演取舍：本轮只保一个主任务，例如“男主压住手机证据”或“女主收回情绪”。
3. 拆法建议：把长台词、屏幕文字、孩子动作和爆炸分别转成反应镜、后期字幕、桥镜或下一镜。
4. 最终提示词：一镜一个主说话人或直接改成无口型反应镜，文字默认后期添加。
5. 失败第一刀：如果仍乱，下一轮只改机位或主动作，不同时改表演、文字和特效。

失败信号：

1. 继续保留三人同步动作、长台词、屏幕文字和爆炸。
2. 只把提示词写长，没有删变量。
3. 没有说明哪些内容交给后期或拆到下一镜。
