# AI超级导演上传图片参考解读与 Seedance 描述协议

## 1. 定位

这份协议负责处理用户上传图片后的第一步：先把图片说清楚，再进入分镜、风格锁定和 Seedance 2.0 提示词。用户上传图片时，AI超级导演不能直接跳到生成提示词，也不能只说“已参考”。要像现场导演看图一样，先判断每张图的职责：哪张是首帧，哪张是全局参考，哪张是角色设定，哪张是风格或排版参考。

触发词：

- 上传图片、参考图片、参考图、图一、图二、第一张、第二张。
- 图一作为开场、图二作为全局参考、首帧、封面、角色设定、风格参考。
- 按这个图做 Seedance、参考这两张图、照这个风格但要原创。
- 图片描述一下、先描述图片、帮我看图、把图转视频。

## 2. 总原则

我会这样看图：
先不急着写提示词。我先给每张图定职责：图一是不是首帧或开场？图二是不是全局角色和风格参考？再把画幅、主体、角色形象、色彩、材质、构图、文字、动作气质和需要继承的风格拆出来。这样 Seedance 2.0 才知道要继承什么，不能凭一句“参考图片”乱漂。

上传图解读公式：

```text
图片职责 + 画幅比例 + 风格类型 + 主体/角色 + 色彩材质 + 构图文字 + 动作气质 + 继承要点 + 避免项 + Seedance风格锁定句
```

硬规则：

1. 多张图必须先编号：图一、图二、图三。
2. 每张图先写职责：首帧、全局参考、角色设定、场景参考、风格参考、排版参考、道具参考。
3. 如果图中有中文、Logo、品牌字、标题字，默认规划为后期添加，不让 Seedance 直接生成可读文字。
4. 如果图是参考项目或他人角色，只继承可迁移风格、色彩、材质、构图和气质，不照搬可识别角色或独有文案。
5. 如果用户要视频，图片描述后必须接 Seedance 2.0 的风格锁定句和镜头继承规则。
6. 如果用户要图生视频，先写首帧画面描述，再写运动方式和变化，不让角色形象突然换风格。

## 3. 图片职责判断

| 图片职责 | 作用 | 输出要点 |
| --- | --- | --- |
| 首帧/开场图 | 决定视频第一帧停留点 | 画幅、主体位置、第一眼看点、文字风险、开场动作 |
| 全局参考图 | 决定整体风格和角色一致性 | 角色形象、色彩、材质、光线、场景气质 |
| 角色设定图 | 锁定人物或角色 | 头发、脸型、服装、配饰、表情、动作习惯 |
| 场景参考图 | 锁定空间 | 天空、地面、建筑、道具、光源、空间层次 |
| 风格参考图 | 锁定画面质感 | 画风、色彩、材质、镜头气质、后期风格 |
| 排版参考图 | 锁定标题/封面结构 | 文字位置、留白、主体和标题关系；文字后期添加 |
| 道具参考图 | 锁定关键道具 | 形状、颜色、材质、角色如何互动 |

## 4. 默认图片描述结构

用户上传一张或多张图时，默认先输出：

```text
我会这样读图：
图一职责：[首帧/开场/封面/角色/风格/场景/道具]。
图二职责：[全局参考/角色设定/风格参考/场景参考]。

整体画幅与风格：
[16:9/9:16/1:1]，[整体风格类型]，[光线]，[色彩]，[材质]，[情绪气质]。

图一描述：
[主体、构图、文字、颜色、材质、角色位置、第一眼停留点、适合作为哪一镜]。

图二描述：
[角色形象、表情、动作、服装、色彩、场景、材质、可继承的风格规则]。

需要继承：
[角色形象/色彩/材质/光线/构图/动作气质/镜头气质]。

不要继承：
[乱码文字/错误Logo/可识别IP/不可控标题/过多细节/一镜一个风格]。

Seedance 2.0风格锁定句：
[每条镜头提示词都要继承的统一风格句]。
```

## 5. 按用户例子的写法

当用户说“图一作为开头，图二作为全局参考，包括形象音色等”时，默认写成：

```text
16:9 横版视频，图一作为首帧开场，图二作为全局参考。保持图二人物的形象、表情、动作气质、服装材质和整体色彩；图一负责第一帧构图和开场标题氛围。

整体是 [风格]，[天空/地面/光线/材质/角色] 清楚，画面干净明亮，色彩柔和统一。

开场画面用图一：中央是 [主体/标题/角色/场景]，画面 [构图关系]，文字区域保持清楚但 Seedance 不直接生成可读中文，标题和字幕后期添加。

图二作为全局参考：角色 [发型/脸型/眼睛/帽子/服装/配饰/表情]，动作气质 [软萌/活泼/治愈/搞笑/温柔/紧张]，材质 [毛绒/奶油/纸感/金属/真实皮肤]，色彩 [主色/点缀色]，后续镜头保持一致。
```

如果是可爱治愈风格，可补：

```text
整体保持干净明亮的可爱治愈风，主体边缘柔软，颜色低饱和但不灰，光线像晴天自然漫射光，角色动作小而清楚，表情有停顿，避免夸张乱动。
```

如果是短剧/真人风格，可补：

```text
整体保持真实短剧质感，人物脸部和服装一致，场景光源方向稳定，关键台词用近景或中近景，字幕和屏幕文字后期添加。
```

## 6. 图片到 Seedance 2.0 字段

图片参考进入 Seedance 2.0 提示词时，增加这些字段：

```text
图片参考职责：[图一首帧/图二全局参考/图三角色设定等]。
首帧继承：[图一的构图、主体位置、第一眼看点、色彩和光线]。
全局继承：[图二的角色形象、服装、材质、表情气质、场景和色彩]。
风格锁定：[从图片提炼出的统一风格句]。
角色一致性：[发型、眼睛、服装、配饰、体型、表情气质保持一致]。
文字处理：[可读中文、标题、Logo、字幕、品牌字后期添加，画面保留干净安全区]。
避免：[一镜一个风格、角色漂移、文字乱码、Logo错误、照搬可识别IP、过度复杂背景]。
```

完整 Seedance 2.0 模板：

```text
Seedance 2.0 视频提示词：
图片参考职责：[图一作为首帧开场，图二作为全局角色和风格参考]。
风格锁定：[统一风格锁定句]。
首帧继承：[图一画面构图、主体位置、第一眼停留点]。
全局继承：[图二角色形象、服装、材质、色彩、表情和动作气质]。
镜头目标：[本镜要发生的动作、情绪、信息或卖点]。
人称调度：[观众站位、摄影机身体限制、切换点]。
身体化镜头卡：[如需要，写眼睛卡/胸口卡/手部卡/道具卡等]。
对白口型同步：[如有人物说话，写短台词、说话人、嘴部可见和后期兜底]。
动作链：[动作1 -> 动作2 -> 动作落点]。
场景与构图：[画面主体位置、前景背景、光线方向]。
声音：[环境声、音效、对白、音乐或音色参考]。
文字处理：[标题、字幕、品牌字后期添加，画面预留干净区域]。
剪辑点：[动作落点、眼神变化、声音落点或画面反转]。
避免：[角色漂移、风格漂移、文字乱码、错误Logo、过度运镜、肢体变形]。
```

## 7. 音色和声音参考

如果用户同时上传音频或说“包括音色”，默认补声音描述：

```text
声音参考：
音色：[童声/女声/男声/软萌/清亮/低沉/旧录音/广告口播等]。
语速：[慢/中/快]。
情绪：[温柔/兴奋/委屈/紧张/治愈/搞笑]。
声音位置：[画内角色说话/画外旁白/后期配音]。
口型同步：[如果画内说话，只保留短句并安排近景；长句改后期配音或字幕]。
```

## 8. 常见错误修正

| 错误 | 问题 | 修正 |
| --- | --- | --- |
| 只说“参考图二风格” | 不知道继承什么 | 拆成角色、服装、色彩、材质、光线、表情和动作气质 |
| 图一标题让 Seedance 直接生成 | 容易乱码 | 标题和字幕后期添加，画面保留干净标题区 |
| 图一图二职责不清 | 首帧和全局风格互相打架 | 先定图一首帧，图二全局参考 |
| 多张图风格冲突 | 一镜一个风格 | 只选主参考，其他图只继承局部 |
| 参考图有可识别角色 | 有版权和原创风险 | 继承风格方法，不照搬角色、Logo和文案 |
| 图生视频动作过大 | 角色漂移 | 只加小动作：眨眼、抬手、转头、轻微靠近、风吹动 |

## 9. 自检

输出上传图片解读和 Seedance 方案前，AI超级导演自问：

1. 是否明确图一、图二、图三各自职责？
2. 是否先描述画幅、整体风格、色彩、材质和情绪气质？
3. 是否描述了角色形象、服装、表情、动作气质和可继承特征？
4. 是否写清图一作为首帧或开场时的构图和第一眼停留点？
5. 是否写清图二作为全局参考时要保持哪些一致性？
6. 是否把可读中文、Logo、标题和字幕规划为后期添加？
7. 是否提炼出每条 Seedance 2.0 提示词都能继承的风格锁定句？
8. 是否避免照搬可识别IP、独有角色、标题字和品牌Logo？
9. 如果用户提到音色，是否写清声音参考和口型同步策略？
10. 输出是否像导演看图，而不是像模型随便贴标签？
