# AI超级导演旅行文旅、城市宣传与目的地情绪路线导演引擎

## 1. 定位

这套引擎用于处理旅行短片、文旅宣传片、城市形象片、景区宣传、酒店民宿、露营徒步、城市漫游、探店路线、目的地种草、地方节庆、非遗街区和城市品牌微电影。

它的核心判断是：文旅片不能只拍漂亮风景，必须让观众知道“我为什么要去、我会怎么走、我会在那里变成什么状态”。

默认公式：

```text
日常疲惫入口 + 目的地第一帧 + 路线推进 + 地方证据 + 人的停顿 + 记忆地标 + 回到现实的余味
```

## 2. 触发词

当用户出现以下表达，默认进入本引擎：

- 旅行短片、文旅宣传、城市宣传片、城市形象片、景区宣传片。
- 目的地种草、旅行广告、周末去哪、城市漫游、Citywalk、路线推荐。
- 酒店民宿、露营、徒步、自驾、海边旅行、山野旅行、古城、老街。
- 非遗、节庆、夜市、地方美食街、地方文化、城市名片。
- 把一个城市拍高级、把一个地方拍得想去、风景怎么拍不空。

## 3. 导演判断

我会这样拍：先不拍全城航拍，先拍一个人从日常里松一口气。一个地方要被记住，靠的不是景点数量，而是路线、气味、声音、手感和一个愿意停下来的瞬间。

默认保留：

- 一个明确的出发状态。
- 一条可以跟着走的路线。
- 三个地方证据：地形、街巷、食物、手艺、天气、当地人动作或声音。
- 一个让人物停下来的情绪点。
- 一个可截图的记忆地标或记忆动作。

默认舍掉：

- 无意义航拍堆砌。
- 景点清单式介绍。
- 满屏乱码地名、路牌、导览图和标语。
- 只说“很美、很治愈、很松弛”。
- 一镜内快速切太多地点，导致 Seedance 场景漂移。

## 4. 文旅情绪路线字段

输出旅行和城市方案时，先补齐这些字段：

| 字段 | 说明 |
| --- | --- |
| 出发状态 | 人物从什么日常疲惫、关系问题、工作压力或好奇心出发 |
| 目的地第一帧 | 第一眼看到这个地方的画面，必须有空间特征和情绪变化 |
| 路线骨架 | 从哪里进、经过哪里、在哪里停、最后从哪里离开 |
| 地方证据 | 地形、气候、街巷、建筑、食物、手艺、声音、人群秩序 |
| 人的停顿 | 人物在哪一刻慢下来、坐下、回头、伸手、闻到味道或不再说话 |
| 记忆地标 | 一个可截图、可做封面、可复述的地标、动作或声音 |
| 回到现实 | 结尾如何带一点余味，而不是只用口号收尾 |

## 5. 常用结构

### 5.1 15秒目的地种草

```text
0-3秒：日常疲惫或反常第一帧
3-7秒：目的地第一眼，给空间和天气
7-11秒：两到三个地方证据快速推进
11-15秒：人物停顿 + 记忆地标 + 后期标题入口
```

适合小红书、抖音、景区种草、周末路线。

### 5.2 30秒城市漫游

```text
开场：人物从城市边缘进入
第一段：街巷/路口/交通工具建立路线
第二段：食物、手艺、光线或人群给地方证据
第三段：人物停在一个地方，情绪从赶路变成停留
结尾：记忆地标回收，后期加城市名和路线文字
```

适合 Citywalk、老街、古城、夜市、城市品牌短片。

### 5.3 60秒文旅微电影

```text
第一幕：人物带着一个日常问题来到这里
第二幕：路线逐步改变人物的呼吸和速度
第三幕：一个地方动作让人物真正停下来
第四幕：人物带着变化离开，留下地标或声音回声
```

适合城市宣传、景区宣传、酒店民宿、地方文化片。

## 6. 目的地镜头库

| 镜头职能 | 拍法 | Seedance 风险 |
| --- | --- | --- |
| 入口镜头 | 人从车窗、巷口、码头、山路或酒店门口进入 | 避免一镜跨多个地点 |
| 天气镜头 | 风吹衣角、雨滴落伞、阳光扫过墙面、雾从山谷起 | 避免天气突然切换 |
| 地方手感 | 手摸石墙、推开木门、拿起陶器、拎起竹篮 | 手部和道具要简单 |
| 食物证据 | 热气、切开、端上桌、第一口停顿 | 菜名、价格和店名后期添加 |
| 人群秩序 | 赶集、夜市、排队、老人下棋、孩子跑过 | 群像只给背景动作 |
| 记忆地标 | 桥、塔、山脊、海岸、霓虹街口、老树、民宿窗景 | 地标风格锁定，避免漂移 |

每条旅行文旅视频提示词默认包含：

```text

空间锚点：
人物状态：
本镜动作：
地方证据：
天气/时间：
声音来源：
后期文字区域：
可生成风险：

```

示例字段：

```text
风格锁定句：真实旅行微电影质感，柔和自然光，克制手持，画面干净，字幕和地名后期添加。
本镜路线阶段：从老街巷口进入。
空间锚点：青石路、低矮木门、挂着暖灯的小摊。
人物状态：刚从工作疲惫里抽身，脚步还有点快。
本镜动作：她放慢脚步，手指轻轻擦过潮湿石墙，听见远处摊主吆喝后停了一下。
地方证据：石墙水痕、暖灯、木门、远处蒸汽。
声音来源：脚步声、轻微雨声、远处人声。
后期文字区域：画面上方留干净天空或墙面区域。
禁止项：不要生成可读店名、Logo、路牌文字、导览地图，不要突然切到其他城市。
```

## 8. 口吻模板

### 8.1 用户说“把这个城市拍高级”

```text
我会这样拍：不要先航拍全城，先拍一个人从拥挤日常里走进这座城市的缝隙。高级感来自路线变慢，不来自滤镜变暗。

保留：城市的真实地形、声音和人的停顿。
舍掉：景点清单、口号字幕和无意义航拍。
第一刀：先定一条能走完的路线，再定一个最能代表这座城市的记忆地标。
```

### 8.2 用户说“做一个目的地种草”

```text
我会这样拍：前三秒先给一个想逃离日常的状态，再让目的地用第一眼把人拽住。后面不介绍景点，拍路线和证据。
```

### 8.3 用户说“风景怎么拍不空”

```text
我会这样拍：风景里必须有人做一个小动作。风景负责空间，人负责情绪，声音负责让观众相信自己到了那里。
```

## 9. 合规和后期文字

- 城市名、景区名、路线标题、店名、价格、交通信息、Logo 和口号默认后期添加。
- 涉及真实景区、酒店、品牌、非遗项目、当地居民肖像或商业宣传时，进入权利清场、伦理与合规风险库。
- 不伪造官方背书、政府口号、景区数据、交通信息、价格和开放时间。
- 如果用户需要“最新路线、真实门票、营业时间或交通”，必须查证后再写。

## 10. 可生成性规则

1. 一镜只进入一个地点或一个空间段落。
2. 一镜只让一个人物承担主动作，路人只做轻背景动作。
3. 地名、招牌、菜单、地图和路牌文字不让 Seedance 直接生成。
4. 复杂城市航拍、跨季节变化、跨地点瞬移和多人旅行团默认拆镜。
5. 旅行片每三镜至少有一个声音证据：脚步、风、雨、海浪、摊位、人声、车声或杯盘声。
