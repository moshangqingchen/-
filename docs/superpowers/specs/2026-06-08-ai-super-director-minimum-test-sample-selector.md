# AI超级导演最小测试小样选择器

## 1. 定位

这份选择器解决一个现场问题：方案已经很大，但最该先测试的不是整条片，而是那个最小、最危险、最能决定成败的小样。

它不替代导演彩排、试拍小样与生成前预检库。彩排库回答“这一镜怎么走”；本选择器回答“到底先测哪一镜、只测哪个变量、通过后才放大到哪一段”。

一句话原则：

```text
先用最小小样验证最大风险，不用整条片赌运气。
```

默认目标：

1. 完整 Seedance 项目先找到一个最小测试镜头。
2. 每次小样只测试一个变量。
3. 通过后再扩展到同风格、同角色或同动作链。
4. 失败后知道第一刀改哪里，而不是重写整条方案。

## 2. 什么时候必须启用

遇到以下信号，默认调用本选择器：

1. 用户说“先测哪一镜、先跑哪条、小样怎么选、先试生成一条、哪一镜最容易翻车、生成前先验证什么”。
2. 项目里同时存在多个高风险变量：新角色、新风格、复杂动作、对白口型、产品操作、特效、群像或可读文字。
3. 客户提案前需要证明方案能生成、能剪起来。
4. 整条片需要统一角色、场景、风格或视觉母题。
5. 第一镜、主场面、产品证明场或记忆帧承担成败。
6. 已经失败一次，但还不知道是风格、角色、动作、口型还是提示词过载导致。

不必启用的情况：

1. 用户只要一句创意或轻量方向，不进入生成验证。
2. 单镜风险很低，只需要直接写 Seedance 提示词。
3. 用户明确只要完整方案，不需要生成前测试策略。

## 3. 最小测试小样类型

| 小样类型 | 测什么 | 不测什么 | 合格信号 |
| --- | --- | --- | --- |
| 风格小样 | 光线、色彩、质感、镜头气质 | 复杂剧情、多人动作、长台词 | 一眼看出统一风格，画面不漂 |
| 角色小样 | 脸、服装、道具、姿态连续性 | 强运镜、复杂特效 | 角色不变形，服装道具稳定 |
| 动作小样 | 起点、触发点、受力结果、反应 | 群像、台词、字幕 | 动作因果清楚，结果看得见 |
| 口型小样 | 单说话人、短台词、开口收口 | 跑动、遮挡、多人对白 | 嘴部可见，台词前后有停顿 |
| 产品小样 | 手部任务、产品动作、结果变化 | 大场景、长口播 | 卖点被动作证明 |
| 群像小样 | 中心物、站位、反应顺序 | 多人同时说长台词 | 人物不融合，视线顺序清楚 |
| 特效规则小样 | 触发物、能力规则、可见后果 | 完整大战、快速环绕 | 特效跟动作因果走 |
| 记忆帧小样 | 封面帧、视觉母题、声音钩子 | 完整叙事 | 可截图、可复用、能被复述 |

## 4. 选择顺序

先问五个问题：

1. 这条片成败押在哪一场？
2. 哪个变量最可能导致生成失败？
3. 哪个变量一旦失败，后面都不能用？
4. 哪个变量最容易用一个 4-6 秒镜头验证？
5. 通过这个小样后，能不能复用到整条片？

默认优先级：

```text
主场面风险
-> 角色连续性
-> 动作或产品证明
-> 口型同步
-> 风格统一
-> 记忆帧
```

特殊情况：

1. 如果项目需要固定角色，先测角色，不先测炫技镜头。
2. 如果广告卖点必须成立，先测产品动作，不先测空镜风格。
3. 如果短剧靠一句反杀台词成立，先测口型和反应，不先测大场面。
4. 如果打斗或特效是卖点，先测接触受力或能力规则，不先测完整大战。
5. 如果客户只看第一眼，先测第一帧或记忆帧。

## 5. 一镜一变量规则

小样只测一个变量：

```text
测角色，就锁死风格、机位、动作和道具。
测动作，就锁死角色、景别、空间和时长。
测口型，就锁死人物位置，不让人物走动。
测产品，就锁死手部任务，不加长台词。
测风格，就降低动作复杂度，不引入新剧情。
```

禁止这样测：

```text
一个 8 秒小样里同时测新角色、新风格、打斗、口型、Logo、字幕和复杂运镜。
```

这种小样失败后无法判断原因，不算测试。

## 6. 类型项目先测什么

| 类型 | 先测小样 | 为什么 |
| --- | --- | --- |
| 可爱治愈 | 小主体完成大任务的 4 秒动作 | 测萌点是否来自动作，而不是形容词 |
| 竖屏短剧 | 主角一句短台词加对方反应 | 测关系压力、口型和停顿 |
| 创意广告 | 产品介入前后变化 | 测卖点是否可见 |
| 打斗特效 | 一次接触受力 | 测空间、触发和结果 |
| 特摄英雄 | 仪式动作到登场姿态 | 测规则和记忆帧 |
| 怀旧情感 | 旧物动作和收回手 | 测克制表演和余味 |
| 科幻产品 | 日常动作触发技术后果 | 测科技规则是否看得懂 |
| 群像喜剧 | 中心物引发三人反应顺序 | 测角色不融合和笑点节拍 |
| 企业品牌片 | 一次团队协作动作 | 测可信度是否落在具体任务上 |
| 直播种草 | 主播手部证明加一句短话 | 测产品动作和口播自然度 |

## 7. 小样决策卡

每次输出小样策略，按这个格式：

```text
我会先测这一镜：

小样目的：
【只测一个变量】

为什么先测它：
【它决定整条片的哪一个成败点】

镜头范围：
【4-6 秒 / 只拍哪一个动作或反应】

锁定变量：
角色：
服装：
场景：
道具：
风格句：

本轮不测：
【明确删掉的变量】

通过标准：
1. 【可检查标准一】
2. 【可检查标准二】
3. 【可检查标准三】

失败第一刀：
【只改一个变量】

通过后扩展：
【下一步复制到哪些镜头或场次】
```

## 8. 失败后的判断

小样失败，不直接重写全片。先判失败类型：

| 失败症状 | 根因判断 | 第一刀 |
| --- | --- | --- |
| 角色漂 | 首帧或角色设定不稳 | 重做角色关键帧，降低运镜 |
| 风格漂 | 风格句太虚或参考混杂 | 锁一个主风格，删副风格 |
| 动作乱 | 起点、触发、受力结果不清 | 拆成起点镜和结果镜 |
| 口型怪 | 台词太长或嘴部不可见 | 缩短台词，改近景或画外声 |
| 产品看不清 | 手挡产品或动作无结果 | 改手位和微距证据 |
| 群像融合 | 中心物和反应顺序不清 | 减人，定主动作角色 |
| 特效乱飞 | 特效没有触发规则 | 先拍触发物，再拍后果 |
| 记忆帧弱 | 画面没有可复述动作 | 加一个道具动作或声音钩子 |

连续两次失败：

```text
不要继续微调同一条提示词。第二轮拆镜或换机位，第三轮重做首帧、关键帧或换测试变量。
```

## 9. 与其他能力衔接

默认顺序：

```text
现场判断中枢
-> 类型主场面选择与押注协议
-> 最小测试小样选择器
-> 导演彩排、试拍小样与生成前预检库
-> Seedance 镜头可生成性评分
-> 生成后回放验片与剪辑救援协议
-> 错误记忆与自动避坑案例库
```

分工：

1. 现场判断中枢决定这条片怎么赢。
2. 类型主场面选择决定押哪一场。
3. 本选择器决定先测哪一个最小样。
4. 彩排预检库把小样走细。
5. 可生成性评分决定是否继续拆镜。
6. 回放验片判断小样能不能用。
7. 错误记忆库把失败沉淀成下次避坑。

## 10. 自检闸门

输出小样策略前，必须检查：

1. 有没有只测一个变量？
2. 有没有写清本轮不测什么？
3. 有没有锁住角色、场景、道具和风格句？
4. 有没有 2-4 条可检查通过标准？
5. 有没有失败后的第一刀？
6. 有没有通过后扩展路径？

## 11. 最小合格线

一次最小测试小样选择至少要输出：

1. 小样目的。
2. 为什么先测它。
3. 镜头范围。
4. 锁定变量。
5. 本轮不测。
6. 通过标准。
7. 失败第一刀。
8. 通过后扩展。

少一项，就不是测试策略，只是又多写了一条提示词。
