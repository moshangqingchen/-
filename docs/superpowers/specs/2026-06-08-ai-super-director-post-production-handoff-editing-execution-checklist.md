# AI超级导演后期交接与剪辑执行清单协议

## 1. 定位

这份协议负责把导演方案、Seedance 分镜、生成素材和客户交付要求，整理成剪辑师、声音、字幕、调色、包装和发布执行者能直接使用的后期交接单。

它不替代剪辑节奏与声音设计库，也不替代画外音、字幕与口播文案库。本协议负责最后一公里：把“怎么拍”转成“怎么剪、怎么配、怎么加字、怎么交付、怎么验收”。

一句话原则：

```text
后期不是收尾，是第二次导演。
```

默认目标：

1. 让每个镜头知道剪到哪里、接到哪里。
2. 让声音、字幕、品牌字、Logo、标题和屏幕文字全部后期可控。
3. 让调色、混音、包装和输出规格有清单。
4. 让客户版、发布版、测试版的后期处理分开。
5. 让交付前能按清单逐项验收。

## 2. 什么时候必须启用

遇到以下信号，默认调用本协议：

1. 用户说“后期怎么做、剪辑怎么交接、给剪辑师、后期清单、交付清单、字幕怎么加、声音怎么做、调色怎么定、输出规格”。
2. 完整方案、客户提案、成片级分镜或整条 Seedance 已经完成，需要进入执行。
3. 素材已经生成，需要判断怎么剪救、补后期、加字幕或交付。
4. 需要区分客户版、发布版、A/B 版本、平台版和内部测试版。
5. 项目包含可读中文、Logo、品牌字、字幕、价格、参数、活动信息或货架入口。
6. 发布前或客户交付前需要最后一份执行验收表。

不必启用的情况：

1. 用户只要创意方向，不进入后期。
2. 用户只要单条 Seedance 提示词，没有成片交付。
3. 只是修改一句文案或一个标题。

## 3. 后期交接总表

每条片进入后期时，先输出：

```text
项目名：
版本类型：
片长：
画幅：
交付对象：
主目标：
主版本：
备用版本：
素材状态：
不可动核心：
可调整项：
交付截止：
```

判断：

```text
如果主目标是客户过审，后期优先清楚、稳定、合规。
如果主目标是平台传播，后期优先第一帧、前三秒、封面、标题和评论入口。
如果主目标是产品转化，后期优先卖点字幕、产品动作、结果证明和行动入口。
```

## 4. 镜头剪辑执行表

每个镜头都要有剪辑任务：

```text
镜头号：
素材状态：可直接用 / 可剪救 / 后期补 / 单变量重跑 / 拆镜重做
入点：
出点：
必须保留：
必须删掉：
接上一镜方式：
接下一镜方式：
声音桥：
字幕/屏幕字：
风险：
后期处理：
```

剪辑判断：

1. 主动作不清的镜头不能当主镜头，只能当气氛或桥镜头。
2. 人物反应好的镜头可以救结构。
3. 产品动作失败的镜头不能靠字幕硬补。
4. 文字乱码的画面要裁掉、遮掉、替换或重跑。
5. 角色漂移严重的镜头不能放进同一连续段。

## 5. 声音交接

声音不是最后铺 BGM。每条片至少交接：

```text
第一声：
环境声：
动作音效：
产品声音：
人物对白：
画外音：
音乐气质：
静音点：
声音桥：
结尾回声：
混音优先级：
```

混音优先级：

1. 关键对白和产品动作声优先。
2. 情绪片保留环境声，不用音乐盖满。
3. 打斗特效让接触声和受力结果先清楚。
4. 广告证明镜头让产品声音可识别。
5. 可爱搞笑保留反应停顿，不把笑点填满。

## 6. 字幕、屏幕字与品牌字

可读文字默认后期添加：

| 类型 | 后期处理 | 画面要求 |
| --- | --- | --- |
| 字幕 | 后期加，短句优先 | 不遮脸、手、产品、关键道具 |
| 标题 | 后期加 | 首帧预留干净区域 |
| 品牌字 | 后期加 | 结尾或产品证明后露出 |
| Logo | 后期加 | 不让 Seedance 直接生成 |
| 价格/参数 | 后期加 | 与产品动作或结果绑定 |
| 货架入口 | 后期加 | 直播/种草画面预留侧边或底部 |
| 手机/屏幕内容 | 后期合成或模糊处理 | 生成画面不硬做可读字 |

字幕安全区检查：

1. 竖屏底部不遮手、嘴和产品。
2. 横版下方不遮关键动作。
3. 标题不压主体脸部和表情。
4. 品牌字不抢结尾余味。
5. 可读中文不交给视频模型硬生成。

## 7. 调色与画面统一

调色交接字段：

```text
主色调：
辅助色：
肤色规则：
产品颜色保护：
黑白灰层次：
高光处理：
阴影处理：
风格禁区：
跨镜头统一方法：
```

常见修法：

| 问题 | 后期修法 | 不能修的情况 |
| --- | --- | --- |
| 镜头轻微色偏 | 调色统一 | 角色服装颜色完全变了 |
| 光线强弱不一 | 降高光、提阴影、统一色温 | 光源方向完全相反且影响空间 |
| 背景太抢 | 降饱和、压亮度、加轻微虚化 | 背景遮挡主体动作 |
| 产品不突出 | 保产品色、压背景色 | 产品形状生成错误 |
| 画面太AI | 加真实颗粒、减锐化、补环境声 | 人物和空间逻辑错误 |

## 10. 类型专用后期重点

| 类型 | 后期重点 |
| --- | --- |
| 可爱治愈 | 反应停顿、轻音效、封面可截图、字幕少而软 |
| 竖屏短剧 | 台词清楚、反应镜接住、下一集问题、字幕不挡嘴 |
| 创意广告 | 产品动作声、卖点短字、前后对比、品牌记忆帧 |
| 打斗特效 | 接触声、受力结果、动作剪辑、空间方向不乱 |
| 情感短片 | 环境声、静音点、旧物声音、字幕克制 |
| 企业品牌片 | 信息清楚、人物可信、品牌露出稳、节奏不PPT |
| 直播种草 | 货架入口、价格参数后期、口播字幕、手部证明 |
| 文旅美食 | 地方声音、食物声音、封面食欲/目的地记忆 |

## 11. 交付前验收

交付前逐项检查：

1. 片长和画幅是否正确？
2. 第一帧是否能静音看懂？
3. 主镜头是否承担主任务？
4. 产品或人物动作是否清楚？
5. 字幕、Logo、品牌字是否后期添加且无错字？
6. 声音是否没有盖住关键动作和台词？
7. 调色是否保护人物肤色和产品颜色？
8. 客户版和发布版是否分流？
9. 是否有无字幕版、字幕版或水印版需求？
10. 是否有合规、版权、真实品牌和平台风险？

不通过处理：

```text
如果只是字幕、声音、调色问题，后期修。
如果主动作、产品证明、角色连续性失败，不能靠后期硬救，回到回放验片或单变量重跑。
```

## 12. 与其他能力衔接

默认顺序：

```text
成片级分镜编译器
-> 生成后回放验片与剪辑救援协议
-> 成片版本管理与 A/B 决策协议
-> 后期交接与剪辑执行清单协议
-> 平台发布与爆款包装库
-> 交付前红队审查
```

分工：

1. 成片级分镜编译器负责成片骨架。
2. 回放验片负责素材能不能用。
3. 版本管理负责客户版、发布版和测试版分流。
4. 本协议负责剪辑、声音、字幕、调色和交付执行。
5. 发布包装负责标题、封面、评论和复盘。
6. 红队审查负责最后挑错。

## 13. 自检闸门

输出后期交接前检查：

1. 有没有片长、画幅和版本用途？
2. 有没有逐镜剪辑任务？
3. 有没有声音交接？
4. 有没有字幕、屏幕字、品牌字和 Logo 后期规则？
5. 有没有调色统一和产品/肤色保护？
6. 有没有客户版、发布版或备用版去向？
7. 有没有交付前验收标准？

## 14. 最小合格线

一次后期交接至少要输出：

1. 成片目标。
2. 版本用途。
3. 剪辑执行表。
4. 声音交接。
5. 字幕与品牌字规则。
6. 调色规则。
7. 包装交接。
8. 交付版本。
9. 验收标准。

少一项，就不是后期交接，只是把分镜又讲了一遍。
