# AI超级导演画外音、字幕与口播文案库

## 1. 定位

这份库负责所有“画面外的文字和声音文案”：旁白、画外音、字幕、字幕卡、屏幕字、口播、广告短句、品牌收束语、短剧第一句台词和结尾金句。

AI视频尤其要注意：可读中文、品牌字、字幕和海报字，尽量不要交给 Seedance 2.0 直接生成。画面可以预留干净区域，文字后期添加，才能减少乱码、错字、变形和风格漂移。

一句话原则：

```text
画面能说的，别让旁白重复；画面说不出的，才交给旁白和字幕。
```

## 3. 与其他资产的关系

本库不替代表演指导与对白台词库。表演库管“角色怎么说”，本库管“作品要不要说、谁来说、说多少、字幕怎么落”。

默认调用顺序：

```text
剧本结构
-> 分镜与场面调度
-> 微动作与镜头衔接
-> 剪辑节奏与声音设计
-> 画外音、字幕与口播文案
-> Seedance 2.0提示词与后期文字规划
```

分工：

| 资产 | 主要回答 |
| --- | --- |

## 4. 核心判断

### 4.1 先判断要不要说

每一句旁白、字幕或口播都要通过三个问题：

1. 画面已经表达了吗？
2. 这句话会不会打断情绪？
3. 删掉后，观众是否还看得懂？

如果答案是“画面已经表达，删掉也懂”，就删。

### 4.2 文案只承担一种任务

一条文案不要同时介绍背景、解释情绪、推销产品和制造悬念。

常见任务：

- 补信息。
- 给情绪留余味。
- 制造问题。
- 强化卖点。
- 引导下一镜。
- 收束品牌记忆。
- 让观众想评论。

写法：

```text
文案任务：[补信息/留余味/制造问题/强化卖点/引导下一镜/收束品牌/评论触发]
一句话：[具体文案]
落点：[出现在哪个镜头、哪个动作之后]
```

### 4.3 人话优先

少用：

- 温暖治愈的力量。
- 高级电影感。
- 每个人心中都有一束光。
- 重新定义生活方式。
- 让爱与科技相遇。
- 震撼来袭。

改成：

- “它还记得这声门响。”
- “他没回头，但手停住了。”
- “这杯咖啡先替我醒了。”
- “别急，先让它自己靠近。”
- “全班安静了三秒，事情就坏了。”

## 5. 文案形态选择

| 需要解决的问题 | 用什么 | 不适合用什么 |
| --- | --- | --- |
| 观众看不懂背景 | 少量画外音 | 大段字幕解释世界观 |
| 情绪需要余味 | 克制旁白或静音字幕 | 煽情长句 |
| 广告卖点要清楚 | 动作证明 + 短字幕 | 角色硬口播 |
| 短剧冲突要钩人 | 第一句台词 + 反应字幕 | 开场背景介绍 |
| 可爱搞笑要上头 | 短字幕、角色口头禅 | 解释笑点 |
| 旧物情感要动人 | 旧录音感画外音 | 连续旁白解释画面 |
| 信息流要快速理解 | 屏幕短句和字幕条 | 复杂诗意长文 |
| 品牌要记住 | 结尾短句和品牌字 | 整片反复喊品牌 |

## 6. 旁白规则

### 6.1 旁白入口

旁白最好在这些地方进入：

- 旧物被触碰后。
- 角色停住但没说话时。
- 声音桥带出回忆时。
- 画面留白时。
- 结尾动作落下后。

少在这些地方进入：

- 打斗动作正在发生时。
- 喜剧包袱刚要落地时。
- 产品证明动作最关键的一秒。
- 短剧冲突台词互相压住时。

### 6.2 情感旁白公式

```text
旧物/动作 + 没说出口的话 + 时间距离 + 当下回应
```

示例：

- “那年他走得急，连这盘磁带都没来得及倒回去。”
- “我以为它坏了，后来才知道，是我很久没按下去。”
- “有些声音不是回来，是一直没走。”

规则：

1. 每句短。
2. 不解释画面。
3. 不直接喊“感动”“治愈”“遗憾”。
4. 让物件和动作承担一半情绪。

### 6.3 治愈旁白公式

```text
小动作 + 轻判断 + 留一点空
```

示例：

- “今天不用马上好起来。”
- “它只是慢慢把杯子推近了一点。”
- “风停的时候，他才听见自己松了口气。”

### 6.4 搞笑旁白公式

搞笑旁白要像一个忍笑的旁观者，不要解释笑点。

```text
认真语气 + 离谱事实
```

示例：

- “班长宣布，太阳迟到也要写检讨。”
- “事情到这里，本来还有救。”
- “三秒后，全班决定先怪闹钟。”

## 7. 字幕规则

### 7.1 字幕不是画面说明书

字幕应该承担：

- 让台词可读。
- 强化笑点。
- 标记关键信息。
- 给观众一个可复述的句子。
- 帮助无声观看。

字幕不应该承担：

- 把画面正在发生的事再讲一遍。
- 长篇介绍世界观。
- 把情绪标签贴在人物脸上。

### 7.2 字幕行文

短视频字幕默认：

```text
每屏1到2行。
每行尽量少于14个汉字。
一句话只表达一个意思。
强情绪词少用，具体动作词多用。
```

字幕拆分方式：

```text
原句：那一天我终于明白，爸爸一直没有离开，他只是把声音留在了这台旧录音机里。

拆成：
那天我才明白
爸爸没有离开
他只是把声音
留在了这里
```

### 7.3 字幕安全区

竖屏默认：

- 字幕不要压住人物眼睛、手部关键动作、产品、旧物和表情反应。
- 可放在下三分之一，但要避开平台按钮和自动字幕区。
- 如果要屏幕大字，分镜阶段预留左侧、右侧或上方干净区域。
- Seedance 提示词里不要要求生成可读中文文字，改成“画面保留干净留白区域，供后期添加字幕”。

Seedance 提示词写法：

```text
画面文字规划：不生成可读文字，画面右上方保留干净留白区域，供后期添加字幕或品牌短句。
避免：背景文字乱码、错误中文、变形Logo、不可控字幕。
```

## 8. 口播规则

### 8.1 广告口播

广告口播不要像说明书。先让画面证明，再让口播补刀。

公式：

```text
痛点一句话 -> 产品动作一句话 -> 结果一句话 -> 品牌记忆一句话
```

示例：

```text
痛点：每天最累的，不是工作，是回家还要重启自己。
动作：它先把咖啡温好，等你进门。
结果：你不用马上精神，只要先坐下来。
品牌：把照顾，留在你进门前。
```

### 8.2 种草口播

适合第二人称，但不要油。

```text
你有没有过 [真实场景]？
我会先看 [一个细节]。
它厉害的地方不是 [表面卖点]，是 [动作结果]。
所以这个镜头我一定拍 [证明动作]。
```

### 8.3 解说口播

解说只讲观众看不出来的判断。

```text
别先讲故事背景，先讲导演选择：
“这镜不能推太快，推快了观众会觉得我们在逼他哭。”
```

## 9. 屏幕字和字幕卡

### 9.1 什么时候用屏幕字

可以用：

- 开场问题。
- 广告卖点短句。
- 章节标题。
- 时间地点提示。
- 结尾金句。
- 系列固定口号。

少用：

- 大段剧情说明。
- 复杂产品参数。
- 直接写“高端”“治愈”“震撼”。

### 9.2 屏幕字公式

```text
问题型：如果 [反常识事件] 会怎样？
结果型：[结果] 发生在 [意外对象] 身上。
情绪型：有些 [情绪]，会藏在 [具体物件] 里。
广告型：把 [卖点] 拍成 [动作结果]。
系列型：[固定世界] 今天学会了 [本集荒诞任务]。
```

示例：

- “太阳今天迟到了。”
- “这台录音机，只在雨天叫我的名字。”
- “别介绍保温，拍它等你回家。”
- “全班决定先审问闹钟。”

## 10. 类型专用文案

### 10.1 可爱搞笑

文案气质：

- 认真。
- 短。
- 装作事情很正式。
- 不解释笑点。

模板：

```text
字幕钩子：[荒诞问题] 今天正式立案。
反应字幕：[角色] 选择先假装冷静。
结尾字幕：事情解决了，但 [更离谱的小问题] 出现了。
```

### 10.2 怀旧情感

文案气质：

- 克制。
- 像没说完。
- 多用物件和时间。
- 少用“泪目”“破防”。

模板：

```text
旁白1：我以为 [旧物] 只是坏了。
旁白2：后来才知道，它是在等 [具体动作/具体声音]。
字幕收束：有些声音，会替人等很久。
```

### 10.3 治愈

文案气质：

- 小。
- 慢。
- 不说教。
- 给观众喘气。

模板：

```text
字幕1：今天先不急。
字幕2：[具体物件] 已经往前挪了一点。
字幕3：这就够了。
```

### 10.4 创意广告

文案气质：

- 卖点可视化。
- 少形容，多动作。
- 不把产品夸成神。

模板：

```text
开场字：别介绍 [卖点]，拍它怎么 [动作结果]。
中段字幕：[产品动作] -> [用户变化]。
结尾短句：[品牌/产品]，把 [价值] 留在 [具体时刻]。
```

### 10.5 特效

文案气质：

- 先让规则清楚。
- 不替奇观解释。
- 给观众一个问题。

模板：

```text
字幕钩子：他发现 [现实规则] 只剩一秒。
规则字幕：[特效规则]。
结尾字幕：下一次，会轮到谁？
```

### 10.6 打斗

文案气质：

- 短。
- 不抢动作。
- 关键句放在动作前或动作后。

模板：

```text
开场台词：别动那扇门。
反转字幕：他不是在躲，是在等第三步。
结尾句：这一下，才算开始。
```

### 10.7 短剧

文案气质：

- 第一句要有关系压力。
- 字幕帮助观众抓住秘密。
- 结尾留问题，不解释答案。

模板：

```text
第一句台词：[误会/指控/选择/秘密]。
中段字幕：他听见的，不是那句话。
结尾字幕：门外的人，其实早到了。
```

## 13. 修复指南

### 13.1 旁白太AI

表现：

- 抽象词过多。
- 解释画面。
- 每句话都像总结。

修复：

```text
删掉情绪形容词。
把一句大话改成一个动作、一个物件或一个没说完的判断。
```

### 13.2 字幕太满

表现：

- 每屏三行以上。
- 字幕追着画面解释。
- 观众没时间看动作。

修复：

```text
一屏只留一个信息。
动作关键秒不压字幕。
把解释性字幕改成开场问题或结尾余味。
```

### 13.3 Seedance 生成文字乱码

表现：

- 背景出现随机中文。
- 品牌字变形。
- 字幕不可读。

修复：

```text
不要要求模型生成可读文字。
提示词改成：画面保持无文字、无Logo、干净留白，字幕和品牌字后期添加。
```

### 13.4 广告口播像硬广

表现：

- 一直夸产品。
- 没有真实场景。
- 卖点没有动作证明。

修复：

```text
先写痛点动作，再写产品动作，最后只留一句品牌收束。
```

### 13.5 情感片旁白过度煽情

表现：

- 直接说“我好想你”“泪目”“治愈”。
- 画面和旁白同时用力。

修复：

```text
把情绪压回旧物、手部、门声、停顿和环境声。
旁白只说画面说不出的那半句。
```

## 15. 自检

输出前自问：

1. 这句话是否重复了画面已经表达的内容？
2. 旁白是否短、克制、像人话？
3. 字幕是否一屏只承载一个信息？
4. 口播是否先服务真实场景，再服务产品？
5. 是否为 Seedance 画面预留字幕安全区？
6. 画内对白是否短、清楚、单说话人，并给长台词安排后期配音或字幕兜底？
7. 是否避免让模型直接生成可读中文、Logo或品牌字？
8. 每句文案是否有明确出现时机和退场时机？
9. 情感片是否少解释，搞笑片是否不解释笑点，广告是否不硬夸？
9. 结尾是否留下可复述的短句、余味或评论入口？
10. 这套文字是否让作品更像真人导演做出来，而不是像AI总结出来？
