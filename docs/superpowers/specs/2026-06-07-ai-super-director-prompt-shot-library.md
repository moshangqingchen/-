# AI超级导演提示词与镜头生成库

## 1. 使用方式

这份库用于把创意、剧本和分镜转成可直接用于AI生图、AI视频、AI声音、角色一致性和场景一致性的提示词。它服务于“超级导演”的执行阶段：从想法到镜头，从镜头到生成，从生成到剪辑。

默认提示词结构：

```text
风格锁定 + 电影/特摄/创意精华转译 + 类型现场调度卡 + 上传图片参考解读/继承规则 + 空间锁定 + 人物动机/关系状态 + 爆款钩子/留存节奏 + 可爱/治愈调度 + 广告证明链 + 短剧冲突链 + 动作/特效编排 + 可生成性评级 + 人称调度/摄影机身体限制 + 身体化镜头卡/运动幅度 + 对白口型同步 + 镜头衔接 + 后期文字规划 + 主体 + 动作链 + 人物走位 + 微动作/反应 + 场景 + 景别 + 机位 + 镜头运动 + 光线 + 色彩 + 情绪 + 质感 + 声音 + 剪辑点 + 一致性要求 + 负面规避
```

最重要的原则：

1. 先写清楚“谁在做什么”，再写风格。
2. 视频提示词必须写动作因果，不能只写漂亮画面。
3. 角色一致性靠角色圣经，场景一致性靠场景圣经。
4. 声音提示词要和画面动作绑定。
5. 每个镜头都要独立完整，同时能继承系列风格。
6. 视频生成默认主要按 Seedance 2.0 来组织：先明确镜头人称，再写动作链、一个主要运镜、声音、剪辑点和负面规避。
7. 输出提示词前先用现场导演回应协议说明“我会这样拍”，并写清导演判断、保留什么、舍掉什么，避免只堆标签和空泛AI腔。
8. 多镜头视频必须继承同一条风格锁定句，必要时先调用风格参考、Moodboard与镜头风格圣经系统。
9. 用户上传图片或参考图时，必须先写上传图片参考解读：图一/图二/图三职责、首帧继承、全局继承、角色形象、色彩材质、构图文字和避免项，必要时先调用上传图片参考解读与Seedance描述协议。
10. 用户要求电影感、特摄感、创意短片、大片广告或吸收某类作品精华时，必须先写电影/特摄/创意精华转译：参考精华层、观众感受、冲突规则、视觉母题、镜头身体、声音记忆点、原创替换和 Seedance 可生成拆镜，必要时先调用电影、特摄、短片与创意精华转译库。
11. 用户要求直接拍、第一镜、怎么开场、现场调度、选导演拍法、帮我选卡、镜头更活、分镜太散、动作看不清或人物不活时，必须先写类型现场调度卡：卡名、第一帧、摄影机身体、空间站位、人物动作、声音落点、剪辑点和 Seedance 拆法，必要时先调用类型现场调度卡库。
12. 抽象情绪必须转成微动作或反应镜头，必要时先调用微动作、表情反应与动作节拍库。
13. 复杂空间、群像、打斗和短剧冲突必须写空间锁定和人物走位，必要时先调用场面调度、空间轴线与人物走位库。
14. 多镜头视频必须写入点、出点和衔接方式，必要时先调用镜头衔接、转场与蒙太奇语法库。
15. 字幕、屏幕字、品牌字和可读中文默认后期添加，必要时先调用画外音、字幕与口播文案库。
16. 复杂动作、长镜头、群像、打斗、特效和产品证明镜头必须做可生成性评级，必要时先调用Seedance镜头可生成性、难度评分与拆镜决策库。
17. 完整导演方案、多镜头Seedance项目、客户提案、发布前方案或用户要求检查升级时，必须写输出审片评分：总分、最强点、最弱点、第一刀升级、是否建议直接生成，必要时先调用输出审片评分与升级闸门。
18. 角色驱动镜头必须写人物动机和关系状态，必要时先调用人物动机、关系弧线与角色导演库。
19. 强调人称、POV、代入感或多视角切换时，必须写观众站位、摄影机身体限制和切换点，必要时先调用Seedance 2.0人称运镜调度矩阵与切换语法库。
20. 强调镜头身体、身体感、呼吸感、手持、胸口视角、手部视角、沉浸感或身临其境时，必须写身体化镜头卡、运动幅度、视觉锚点和身体限制，必要时先调用Seedance 2.0身体化镜头与人称运镜实战卡库。
21. 强调口型、嘴型、人物对白、台词、对话、说话自然、配音同步或声画同步时，必须写对白口型同步：一镜一个主要说话人、短台词、嘴部可见度、说话节拍、声音来源、字幕或后期配音兜底，必要时先调用对白口型自然同步与表演声画调度库。
22. 强调爆款、前三秒抓人、留存、完播或更容易火时，必须写第一帧停留点、前三秒问题、信息债、中段升级和结尾互动，必要时先调用爆款视频钩子与留存节奏引擎。
23. 打斗、追逐、超能力、爆炸、特效和动作看不清的镜头必须写动作/特效编排：场面目标、压力方向、接触或触发点、受力结果、人物反应和声音打击点，必要时先调用动作打斗、追逐与特效场面编排引擎。
24. 可爱、治愈、软萌、毛绒、小动物、幼儿园、温柔广告和情绪价值镜头必须写可爱/治愈调度：小主体大任务、微小伤口、温柔介入、反应停顿、情绪松动、群像角色秩序和可截图落点，必要时先调用可爱治愈、软萌群像与情绪修复导演引擎。
25. 创意广告、产品广告、信息流、种草、带货、转化、卖点、产品证明和前后对比镜头必须写广告证明链：痛点可视化、产品动作、可见变化、证据镜头、人物反应、品牌记忆帧和转化入口，必要时先调用创意广告、产品证明与转化镜头引擎。
26. 短剧、竖屏短剧、爽剧、反转、悬疑、第一集、下一集和追更镜头必须写短剧冲突链：主角欲望、阻碍者、关系压力、信息差、视觉伏笔、选择代价、反转释放和下一集问题，必要时先调用短剧冲突、反转与追更钩子导演引擎。

## 2. 生图提示词模板

### 2.1 通用关键帧

```text
一张电影关键帧：[主体] 在 [场景] 中 [具体动作]，
[景别]，[机位]，[构图方式]，
[光线]，[色彩氛围]，[材质细节]，
情绪是 [情绪目标]，
画面重点是 [记忆点]，
风格为 [写实/卡通/水彩/赛璐璐/黏土/毛绒/电影感]，
细节清晰，主体明确，背景服务故事。
```

### 2.2 可爱角色图

```text
可爱角色设定图：[角色名]，[年龄/物种/身份]，
圆润比例，柔软轮廓，清楚表情，
标志性服装是 [服装]，标志性道具是 [道具]，
正在做 [小动作]，
色彩为 [主色] + [点缀色]，
适合系列短片，角色辨识度高，可延展表情包。
```

### 2.3 情感关键帧

```text
怀旧情感短片关键帧：[人物] 在 [旧场景] 中看着 [旧物]，
动作克制，[手部/背影/眼神] 特写，
自然柔光，低饱和暖色，真实生活质感，
画面里有时间痕迹：[旧墙面/门槛/照片边角/饭盒/录音机]，
情绪是想说却没说出口，
结尾留白，不煽情。
```

### 2.4 搞笑卡通关键帧

```text
卡通搞笑关键帧：[软萌群像] 在 [熟悉场景] 中认真处理 [荒诞问题]，
角色表情差异明显：一个震惊，一个装镇定，一个慢半拍，一个很认真，
构图像表情包，动作夸张但清楚，
色彩明亮，线条圆润，节奏感强，
最后画面适合做封面和评论区梗图。
```

## 4. 声音提示词模板

### 4.1 情感旁白

```text
声音像旧录音，语速慢，情绪克制，不哭腔。
语气像在多年后轻轻回忆一件没说完的事。
背景有轻微底噪、远处环境声和低音量钢琴/弦乐。
旁白每句话短，不解释画面，只补充没法拍出来的心事。
```

### 4.2 搞笑音效

```text
轻喜剧音效设计：
动作前留半秒安静；
误解出现时一个短促音效；
角色反应时环境声突然变空；
结尾用一个轻巧收束音或集体沉默。
声音不要太满，让笑点自己落地。
```

### 4.3 广告声音

```text
广告声音节奏：
开头用一个抓耳音效引出痛点；
产品动作出现时声音变干净、明确；
证明镜头用轻微上扬音乐；
结尾保留一句可复述品牌短句或音乐记忆点。
```

### 4.4 打斗声音

```text
动作音效设计：
空间环境声先建立真实感；
每个关键打击点有清楚接触声、呼吸声和短暂停顿；
不要每一击都同样响；
```

## 8. 负面规避库

通用规避：

- 避免肢体变形。
- 避免脸部漂移。
- 避免角色服装突然变化。
- 避免道具消失或位置跳变。
- 避免镜头无意义乱动。
- 避免背景文字乱码。
- 避免过度磨皮和塑料质感。
- 避免情绪夸张到失真。

动作规避：

- 避免快剪掩盖动作。
- 避免没有接触的打击。
- 避免动作结果先于动作原因。
- 避免角色空间位置混乱。

情感规避：

- 避免廉价催泪。
- 避免过度旁白解释。
- 避免消费真实苦难。
- 避免未经许可使用真实人物肖像或声音。

广告规避：

- 避免只口播卖点。
- 避免产品出现太晚。
- 避免品牌记忆点缺失。
- 避免信息过满导致观众记不住。

## 10. 导演自检

1. 提示词是否先写动作，再写风格？
2. 是否包含景别、机位、镜头运动？
3. 是否写清声音和剪辑点？
4. 多镜头是否写清入点、出点和衔接方式？
5. 是否规划字幕安全区，并避免让模型直接生成可读中文、字幕或Logo？
6. 高风险镜头是否先做可生成性评级并拆镜或降难？
7. 角色动作和微动作是否来自人物动机与关系变化？
8. 是否写清观众站位、摄影机身体限制和人称切换点？
9. 是否写清身体化镜头卡、运动幅度和视觉锚点？
10. 有画内对白时，是否写清对白口型同步、单说话人、短台词、嘴部可见、说话节拍和后期兜底？
11. 是否写清第一帧停留点、前三秒问题和中段留存节奏？
12. 动作、打斗、追逐或特效镜头是否写清起点、接触/触发点、受力结果和反应？
13. 可爱、治愈或软萌镜头是否写清小主体大任务、微小伤口、温柔介入、反应停顿、情绪松动和可截图落点？
14. 广告或产品镜头是否写清痛点可视化、产品动作、可见变化、证据镜头、人物反应、品牌记忆帧和转化入口？
15. 短剧或反转镜头是否写清主角欲望、阻碍者、关系压力、信息差、视觉伏笔、反转释放和下一集问题？
16. 是否能保持角色和场景一致？
17. 是否有负面规避？
18. 是否服务创意、情绪、冲突或卖点？
