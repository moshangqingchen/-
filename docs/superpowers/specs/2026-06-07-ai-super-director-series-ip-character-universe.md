# AI超级导演系列IP与角色宇宙开发库

## 1. 使用方式

这份文档用于把一次性短片升级成可持续连载的AI内容IP。它服务于短剧、可爱搞笑群像、怀旧情感栏目、创意广告系列、特效动作宇宙和品牌角色账号。

核心目标：

1. 固定世界观，让观众一眼认出。
2. 固定角色，让观众记住性格。
3. 固定结构，让创作可持续生产。
4. 每集变化一个问题、一个笑点、一个情绪或一个奇观。
5. 保持风格一致，但不重复内容。

## 2. 系列IP核心公式

```text
固定世界 + 固定角色关系 + 固定栏目结构 + 每集新问题 + 标志性收尾 + 可复用视觉和声音记忆
```

拆解：

- 固定世界：幼儿园、旧物铺、咖啡馆、超能力学校、小镇、办公室、武馆、未来城市。
- 固定角色关系：老师和学生、老人和旧物、队长和队员、老板和员工、守护者和被守护者。
- 固定栏目结构：每集开场方式、冲突方式、升级方式、结尾方式基本一致。
- 每集新问题：热点、误会、旧物、产品、任务、秘密、危险、愿望。
- 标志性收尾：一句台词、一个动作、一个表情、一个声音、一个画面。
- 可复用记忆：片头、片尾、角色动作、道具、场景、音乐、标题格式。

## 3. 世界观设计

### 3.1 世界观圣经

```text

声音关键词：

这个世界永远会发生什么：
这个世界绝不发生什么：
适合的故事类型：
系列标题格式：
```

### 3.2 世界观类型

可爱搞笑世界：

- 场景：幼儿园、毛绒动物班级、玩具工厂、迷你办公室。
- 规则：小角色认真处理大人世界的问题。
- 爆点：反差、误解、群像反应、表情包。

怀旧情感世界：

- 场景：旧物铺、老巷、留声机房间、旧照片修复室。
- 规则：每个旧物都打开一段未说完的故事。
- 爆点：旧物、缺席关系、克制旁白、安静回应。

特效动作世界：

- 场景：超能力学校、地下武馆、未来城市、异能事务所。
- 规则：每个角色有清楚能力，能力有代价。
- 爆点：规则升级、打斗动线、反转胜负、视觉奇观。

品牌角色世界：

- 场景：产品使用场景变成拟人世界，例如咖啡岛、护肤实验室、清洁小队。
- 规则：产品卖点变成角色能力。
- 爆点：卖点动作化、角色任务化、广告系列化。

## 4. 角色系统

### 4.1 角色群像公式

```text
主心骨 + 反差角色 + 慢半拍角色 + 情绪角色 + 行动角色 + 神秘角色
```

角色功能：

- 主心骨：负责推动故事，是观众理解世界的入口。
- 反差角色：负责制造笑点、冲突或反转。
- 慢半拍角色：负责可爱、停顿和意外理解。
- 情绪角色：负责治愈、共情和情感落点。
- 行动角色：负责打斗、任务和解决问题。
- 神秘角色：负责悬念、秘密和系列钩子。

## 5. 栏目结构

### 5.1 可爱搞笑栏目

适合：绒耀幼儿园类、毛绒群像、动物班级、玩具世界。

每集公式：

```text
固定片头 + 今日离谱问题 + 角色认真误解 + 群像轮流反应 + 意外升级 + 表情包收尾
```

分镜节奏：

1. 固定场景开场。
2. 角色宣布今日问题。
3. 第一位角色认真解释错。
4. 第二位角色把问题升级。
5. 集体沉默或集体行动。
6. 一句短台词收尾。

系列化关键：

- 每个角色必须有固定反应。
- 每集只解决一个小问题。
- 结尾要能截图做表情包。
- 标题格式要统一，例如“幼儿园今天学会了____”。

### 5.2 怀旧情感栏目

适合：旧梦留声机类、旧物故事、寻亲公益、亲情短片。

每集公式：

```text
旧物开场 + 旧声音旁白 + 缺席关系 + 细节回忆 + 当下回应 + 留白收尾
```

分镜节奏：

1. 旧物特写。
2. 旧录音或低声旁白。
3. 展示一段没说出口的关系。
4. 用手、背影、门口、照片边角推进。
5. 当下人物做一个小动作回应过去。
6. 留白，不解释完。

系列化关键：

- 每集一个旧物。
- 每集一个未完成的心愿。
- 每集一个克制动作。
- 标题格式要统一，例如“这台留声机记得____”。

### 5.3 特效动作栏目

适合：超能力短剧、动作短片、游戏宣传、热血连载。

每集公式：

```text
任务出现 + 能力规则 + 空间冲突 + 攻防升级 + 能力代价 + 反转收尾
```

分镜节奏：

1. 快速给任务或危险。
2. 展示场地和目标。
3. 第一轮能力或动作试探。
4. 对手压制。
5. 主角用规则反转。
6. 暴露新代价或新敌人。

系列化关键：

- 能力必须有规则和代价。
- 打斗必须有空间动线。
- 每集揭示一个新能力或新限制。
- 结尾留一个更大的威胁。

### 5.4 品牌角色栏目

适合：产品账号、品牌IP、广告系列、种草栏目。

每集公式：

```text
用户痛点 + 品牌角色任务 + 卖点动作化 + 前后对比 + 品牌记忆收尾
```

分镜节奏：

1. 用户痛点或反常识开场。
2. 品牌角色收到任务。
3. 产品卖点变成角色能力。
4. 展示解决过程。
5. 前后对比证明。
6. 固定品牌动作或口号收尾。

系列化关键：

- 品牌角色不能只是吉祥物，必须能解决问题。
- 每集只讲一个卖点。
- 视觉和声音记忆要固定。
- 结尾能形成品牌识别。

## 6. 标题和封面系统

### 6.1 标题公式

可爱搞笑：

```text
幼儿园今天学会了____
小朋友把____当成了____
老师说____，全班都懵了
```

怀旧情感：

```text
这台留声机记得____
一张旧照片，等了____年
他没说出口的那句话，藏在____里
```

特效动作：

```text
他第一次使用____能力
这场打斗只有____秒，却改变了结局
当____规则被打破
```

品牌广告：

```text
如果____也有救援队
把____问题交给____解决
一个动作看懂____卖点
```

### 6.2 封面帧公式

```text
主体最大表情 + 关键道具 + 明确场景 + 一个疑问/反差 + 高识别色彩
```

封面检查：

- 一眼知道主角是谁。
- 一眼知道发生了不寻常的事。
- 字少但有问题感。
- 画面能和系列其他封面保持统一。

## 7. 系列连续性

### 7.1 必须固定

- 角色外貌。
- 角色服装主色。
- 场景标志物。
- 片头或开场方式。
- 标志性声音。
- 结尾方式。

### 7.2 可以变化

- 每集问题。
- 每集道具。
- 每集情绪。
- 每集对手或任务。
- 每集旧物。
- 每集产品卖点。

### 7.3 禁止变化

- 为了单集效果随意改变角色性格。
- 为了追热点丢掉世界观规则。
- 为了搞笑牺牲角色可爱度。
- 为了催泪消费真实苦难。
- 为了炫技破坏故事逻辑。

## 8. 系列生产流程

```text
1. 设计世界观圣经。
2. 设计3到6个核心角色。
3. 设计固定栏目结构。
4. 设计标题格式和封面格式。
5. 先做3集测试主题。
6. 每集只变化一个核心问题。
7. 每3到5集做一次复盘。
8. 把有效笑点、情感点、镜头点写回方法库。
```

## 10. 风险提醒

1. 不复制现有爆火账号的角色、名称、台词和画面。
2. 可以学习结构，但必须创造自己的世界观和角色。
3. 系列越长，越要保护角色一致性。
4. 情感栏目要尊重真实故事，不制造廉价苦难。
5. 品牌IP要让卖点自然进入任务，不能硬贴广告。

## 11. 导演自检

1. 这个IP一句话能讲清吗？
2. 角色是否有固定记忆点？
3. 世界观是否能支持至少10集？
4. 每集公式是否够简单、够可复制？
5. 封面和标题是否有统一格式？
6. 是否有独立于爆火案例之外的原创性？
