# AI超级导演场面调度、空间轴线与人物走位库

## 1. 定位

这份库用于解决一个导演级问题：观众到底知不知道“谁在什么位置、往哪里走、摄影机站在哪边、动作从哪里打到哪里”。

很多AI视频看起来有质感，但空间是乱的：上一镜人物在左，下一镜突然在右；打斗很快但看不清谁压住谁；短剧对话只有正反打，却没有关系变化；群像喜剧角色挤在一起，Seedance 2.0 生成时还容易互相融合。

场面调度不是摆位置，它是用空间讲故事。

一句话：

```text
镜头先让观众站稳，再让情绪、笑点、打斗和卖点发生。
```

本库服务于：

- 分镜前的空间设计。
- 短剧对话和冲突站位。
- 群像喜剧的桌面/教室/办公室调度。
- 打斗、追逐、特效动作的动线清晰。
- 创意广告的产品介入位置。
- Seedance 2.0 多镜头生成的空间一致性。

## 4. 核心原则

### 4.1 先画空间，再写镜头

复杂场景不要直接写镜头，先写空间：

```text
空间：门在左，窗在右后方，桌子在中央，主角站桌前，反派靠门，关键道具在桌面右侧。
```

只要空间定住，镜头可以换；空间没定住，镜头再漂亮也会散。

### 4.2 轴线不是规则负担，是观众方向感

轴线可以理解成两个人、两股力量或一条运动方向之间的“关系线”。

常用轴线：

- 对话轴线：人物A和人物B之间的线。
- 动作轴线：角色从位置A冲向位置B的线。
- 产品轴线：使用者、产品、结果之间的线。
- 群像轴线：桌子、讲台、中心道具形成的线。
- 第一人称轴线：角色视线和手部动作形成的线。

导演判断：

```text
我不是为了守规则守轴线，我是为了让观众知道角色在看谁、走向哪、危险从哪来。
```

### 4.3 先全局，再局部

复杂动作、打斗、群像和短剧冲突默认：

```text
空间交代镜头 -> 关键动作镜头 -> 反应镜头 -> 结果镜头
```

不要一上来特写。观众还没站稳时，特写只会制造混乱。

### 4.4 走位必须改变关系

人物走位不是让画面动起来，而是改变权力、距离、秘密和选择。

有效走位：

- 靠近：关系变亲密、压迫或危险。
- 后退：害怕、逃避、让步。
- 侧开：隐瞒、拒绝、退出关系。
- 挡门：控制去留。
- 越过桌子：冲突升级。
- 把产品放到中心：卖点进入剧情。
- 围住道具：群像的注意力统一。


示例：

```text

出口：左侧门。

关键家具/障碍：中央木桌、左后方旧柜子。
关键道具：桌面上的老录音机。
角色A初始位置：桌子前方，面向录音机。
角色B初始位置：门口，站在画面左侧。
关系轴线：A和B之间的斜线，经过桌面录音机。
主要动线：B从门口走到桌边，A没有后退。
摄影机默认站边：桌子右前方，看见A的手和B的门口位置。
不可变空间元素：门、窗、桌子、录音机位置不变。
```

## 6. 轴线与机位选择

### 6.1 对话轴线

适合：短剧、情感、争吵、告白、审问。

规则：

```text
先确定A和B的关系线，摄影机默认待在同一侧。
```

可用镜头：

- 双人中景：交代距离。
- 过肩：站进关系里。
- 单人近景：压情绪。
- 反应镜头：接住台词。

避免：

- 正反打时人物方向忽左忽右。
- 不交代距离就切特写。
- 关键台词时人物突然换站位。

### 6.2 动作轴线

适合：打斗、追逐、逃跑、特效冲击。

规则：

```text
动作从左到右，就尽量保持左到右；除非用全景或明确转向镜头重置方向。
```

可用镜头：

- 全景交代起点和终点。
- 跟拍保持动线。
- 近景只拍关键打击。
- 反应镜头承受动作重量。

### 6.3 产品轴线

适合：创意广告、产品种草、功能证明。

规则：

```text
痛点 -> 产品 -> 结果，三者在空间里要有清楚顺序。
```

示例：

```text
用户在左侧处理问题，产品从右侧进入画面，结果出现在画面中央。
```

### 6.4 群像轴线

适合：幼儿园群像、办公室喜剧、会议桌、家庭饭桌。

规则：

```text
给群像一个中心物：桌子、黑板、玩具、产品、旧物。所有反应围绕它发生。
```

避免：

- 角色随机分散。
- 每个人都同一反应。
- 镜头太近导致角色融合。

## 7. 人物走位语法

### 7.1 标准走位句

```text
角色[谁]从[起点]沿[路径]走到[终点]，动作目的为[目的]，关系变化为[靠近/疏远/压迫/逃避/揭示/救场]。
```

示例：

```text
角色B从左侧门口走到中央桌边，动作目的为逼问，关系变化为压迫；角色A留在桌前不退，手压住录音机。
```

### 7.2 走位四件套

```text
起点：
路径：
终点：
关系变化：
```

### 7.3 走位不能只写“走过去”

错误：

```text
男主走过去质问她。
```

可拍：

```text
男主从门口左侧走到桌子前，绕过椅子时停半秒，最后挡住她离开的路线，再低声质问。
```

## 8. 类型场面调度

### 8.1 可爱搞笑群像

空间：

- 小圆桌、黑板、玩具架、地毯、讲台。
- 角色围绕中心物坐或站。
- 摄影机低机位，像和小角色同高。

调度：

```text
秩序站位 -> 一个角色提出荒诞问题 -> 其他角色依次反应 -> 中心物被误用 -> 全体停顿。
```

导演句：

```text
群像喜剧先给秩序，再让一个小动作把秩序弄歪。
```

### 8.2 治愈空间

空间：

- 窗边、桌边、床边、厨房、门口。
- 人物距离慢慢缩短。
- 镜头稳定，走位少但有情绪变化。

调度：

```text
人物在空间边缘 -> 旧物或温暖道具进入中心 -> 人物靠近半步 -> 身体放松。
```

### 8.3 怀旧情感

空间：

- 旧物在中心，人物在边缘。
- 门、窗、空椅子承担缺席关系。
- 走位克制，不要来回乱走。

调度：

```text
人物从门口停住 -> 走到旧物前 -> 手触碰旧物 -> 看向空椅子或窗外。
```

### 8.4 短剧冲突

空间：

- 门口代表去留。
- 桌子代表隔阂。
- 手机、合同、证据代表秘密。

调度：

```text
一人挡门，一人靠桌，证据在两人之间；冲突升级时，一人越过桌子或拿起证据。
```

导演句：

```text
短剧别只让人吵，先让他们在空间里挡住彼此。
```

### 8.5 创意广告

空间：

- 痛点位置。
- 产品进入位置。
- 结果展示位置。
- 品牌记忆位置。

调度：

```text
用户在痛点处失败 -> 产品从侧面介入 -> 结果在画面中心出现 -> 结尾产品和结果同框。
```

### 8.6 特效

空间：

- 先建立真实基准。
- 异常从固定方向进入。
- 人物反应要看向同一方向。

调度：

```text
人物正常行动 -> 异常光从右后方出现 -> 人物停住并看向右后方 -> 空间规则变化。
```

### 8.7 打斗

空间：

- 起点、障碍、武器、出口必须清楚。
- 打斗路线要从全景中能看懂。
- 关键打击后要给受力位置。

调度：

```text
全景交代双方位置 -> A逼近 -> B后退到障碍旁 -> A出手 -> B撞到桌沿 -> 短暂停顿 -> B反击。
```

导演句：

```text
打斗先别急着快剪，先把谁压住谁、谁被逼到哪里交代清楚。
```

## 9. 人称视角与空间衔接

### 9.1 第一人称

第一人称要写清：

- 角色站在哪里。
- 手从画面哪个方向出现。
- 视线看向哪里。
- 背景固定物是什么。

Seedance写法：

```text
第一人称视角，角色站在桌子右前方，画面下方出现自己的手，手伸向中央桌面的录音机，左侧门和右后方窗户保持稳定。
```

### 9.2 第二人称

第二人称要写清：

- 谁在看观众。
- 观众在空间里的位置。
- 道具递向哪个方向。

### 9.3 第三人称

第三人称负责建立空间：

```text
先用第三人称中景或全景交代空间，再进入第一人称或过肩。
```

### 9.4 过肩

过肩镜头要写清前景是谁、焦点是谁、两人位置不互换。

```text
前景保留角色A右肩虚化，焦点落在角色B脸上，角色B始终站在画面左侧门边。
```

## 10. Seedance 2.0空间锁定法

每条复杂镜头提示词增加空间锁定：

```text
空间锁定：门在画面左侧，窗在右后方，桌子在中央，角色A在桌前，角色B在门口；镜头不改变门窗和桌子的位置关系。
```

完整嵌入：

```text
Seedance 2.0 视频提示词：
风格锁定：[项目视觉圣经]。
空间锁定：[固定方向、门窗、家具、关键道具、角色初始位置]。
人称视角：[第一/第二/第三/过肩/道具/回忆/群像]。
动作链：[起始动作] -> [中间变化] -> [结束状态]。
人物走位：[角色从哪里到哪里，关系如何变化]。
摄影：[景别]，[机位站边]，[一个主要运镜]，[运动理由]。
表演/微动作：[眼神、手部、停顿、反应]。
声音：[脚步、环境声、道具声、呼吸]。
剪辑点：[动作或反应落点]。
一致性：[角色、道具、空间方向保持]。
避免：[站位跳变、左右互换、空间穿帮、角色融合、镜头乱飞]。
```

## 12. 常见空间错误与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 左右互换 | 没有轴线和摄影机站边 | 写关系轴线和默认站边 |
| 打斗看不清 | 没有全景交代空间 | 先加空间交代镜头 |
| 群像融合 | 人太近、动作太多 | 固定站位，分组反应 |
| 短剧对话平 | 人物距离没变化 | 让一人挡门、靠近或后退 |
| 广告产品没记忆 | 产品没有空间介入 | 设计痛点、产品、结果三点关系 |
| 特效像背景素材 | 人物不看奇观 | 写人物看向异常来源的反应 |
| Seedance空间乱 | 每条提示词没写固定物 | 加空间锁定句 |

## 14. 自检

输出前自问：

1. 观众是否知道门、窗、桌子、出口或中心道具在哪里？
2. 是否写清人物初始位置？
3. 是否写清人物从哪里走到哪里？
4. 是否确定关系轴线或动作方向？
5. 摄影机是否有默认站边？
6. 是否先给空间交代，再切近景？
7. 打斗是否看得清谁压住谁？
8. 群像是否有固定中心和差异反应？
9. 广告产品是否从空间上介入并改变结果？
10. Seedance 2.0 提示词是否有空间锁定句？
