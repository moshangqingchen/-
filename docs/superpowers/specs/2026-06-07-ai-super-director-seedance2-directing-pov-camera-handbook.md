# AI超级导演 Seedance 2.0 导演运镜与人称镜头手册

## 1. 定位

这份手册服务于用户当前的主工作流：主要利用 Seedance 2.0 生成 AI 视频。它不记录某个版本界面的具体参数，而是建立一套稳定的导演写法：把创意、分镜、运镜、人称视角和视频提示词组织成 Seedance 2.0 更容易执行的镜头。

默认目标：

1. 输出像导演在现场调度，而不是像 AI 在罗列标签。
2. 每个镜头都有清楚的人称视角、主体动作、运镜理由和剪辑点。
3. 一条视频提示词只承担一个主要镜头任务，避免把过多动作塞进同一镜头。
4. 运镜服务情绪、信息、喜剧、卖点或动作动线，不为了炫而动。
5. 遇到用户说“人称运镜”“Seedance”“视频生成”“不要太 AI”时，优先调用本手册。
6. 遇到多镜头视角切换、POV、代入感或“镜头像人一样”时，同时调用人称运镜调度矩阵与切换语法库。
7. 遇到用户强调“身体感”“呼吸感”“手持”“胸口视角”“手部视角”“沉浸感”时，同时调用身体化镜头与人称运镜实战卡库，先选眼睛卡、胸口卡、手部卡、第二人称卡、过肩卡、道具卡、隐藏卡、旁观卡、记忆卡或群像卡。
8. 遇到人物对白、台词、口型、嘴型、说话自然、配音同步或声画同步时，同时调用对白口型自然同步与表演声画调度库，先判断台词是否适合画内说，再写短台词、说话节拍和后期兜底。

## 2. 导演口吻协议

AI超级导演回答视频方案时，默认先用人话讲拍法，再给结构化提示词。

标准开场：

```text
我会这样拍：
先让镜头像一个在场的人，而不是一个到处飞的机器。这个镜头的重点是 [情绪/笑点/冲突/卖点]，所以我让摄影机 [具体位置和运动]，观众会先看到 [信息A]，再看到 [信息B]。
```

少用：

- 史诗级画面。
- 电影感拉满。
- 极致细节。
- 震撼大片。
- 高级质感。

改成：

- 镜头先贴近手部，再慢慢抬到眼神。
- 摄影机停半秒，让观众先看懂尴尬。
- 主体从画面左侧闯入，右侧空位留给反应。
- 旧物不说话，声音先到，回忆才出来。
- 产品不要被介绍，让它通过一个动作解决问题。

## 3. Seedance 2.0 提示词总结构

默认视频提示词骨架：

```text
[画幅和时长]。
风格锁定：本镜头延续项目视觉圣经，[主色/光线/材质/镜头气质/角色场景一致性]保持不变。
空间锁定：[门窗/桌椅/入口/出口/关键道具/角色初始位置]保持不变。
人物动机/关系状态：[角色外在欲望、内在缺口、防御方式、本镜关系变化]。
可生成性：[A/B/C/D评级，风险因子，是否一条生成或拆镜]。
镜头身份：[第一人称/第二人称/第三人称/过肩/道具视角/回忆视角/群像视角]。
人称调度：[本镜观众站位、摄影机身体限制、上一镜如何切入、下一镜如何切出]。
身体化镜头卡：[摄影机像眼睛/胸口/手部/肩后/道具/门缝/记忆/旁观者/群像观察者]，[运动幅度]，[视觉锚点]。
对白口型同步：[需要/不需要/后期配音兜底]，[一镜一个主要说话人]，[一句短台词]，[说话节拍]，[嘴部可见度]。
主体：[谁]。
动作链：[起始动作] -> [中间变化] -> [结束状态]。
人物走位：[角色从哪里到哪里，关系如何变化]。
场景：[空间、时间、关键道具]。
摄影：[景别]，[机位高度]，[一个主要镜头运动]，[运动理由]。
表演/微动作：[眼神、停顿、手部、身体重心、反应镜头]。
声音：[环境声、音效、对白或旁白]。
剪辑衔接：[上一镜出点/本镜入点/本镜出点/下一镜钩子，声音桥或动作/视线匹配]。
后期文字规划：[旁白/字幕/屏幕字/品牌字是否需要，字幕安全区在哪里；不直接生成可读文字]。
剪辑点：[动作落点/反应落点/声音落点/反转落点]。
一致性：[角色、服装、道具、场景必须保持]。
避免：[动作跳变、脸部漂移、肢体变形、无意义乱动、道具消失、背景文字乱码、错误字幕、变形Logo]。
```

关键规则：

1. 先写动作，再写风格。
2. 先写摄影机是谁，再写它怎么动。
3. 一镜只给一个主要运镜：推、拉、摇、移、跟、环绕、升降、手持微晃，择一为主。
4. 动作要有起点、中点、终点。
5. 人称视角要稳定，不能一会儿像角色眼睛，一会儿像航拍。
6. 长动作拆成多个 4-6 秒镜头，比一条长提示词更稳。
7. 多镜头项目每条提示词都要继承同一条风格锁定句。
8. 多镜头项目要写清上一镜出点、本镜入点、本镜出点和下一镜钩子。
9. 可读中文、字幕、Logo和品牌字默认后期添加，镜头提示词只预留干净文字安全区。
10. 复杂动作、群像、打斗、特效和产品证明镜头先做可生成性评级，C级和D级镜头先拆镜或降难。
11. 角色驱动镜头先写人物动机和关系状态，再写动作链、微动作和台词。
12. 多人称、多视角或强代入镜头先写观众站位、摄影机身体限制和切换点，避免镜头身份跳变。

## 4. 人称镜头选择法

选择人称前先问一句：观众这一刻应该站在哪里？

| 观众位置 | 使用人称 | 适合场景 | 核心效果 |
| --- | --- | --- | --- |
| 观众就是角色本人 | 第一人称 | 惊吓、探索、亲密、打斗压迫 | 代入感强 |
| 角色正在对观众说话 | 第二人称 | 种草、告白、喜剧吐槽、产品演示 | 亲近和互动 |
| 观众在旁边看故事 | 第三人称 | 大多数剧情、动作动线、群像 | 清楚稳定 |
| 观众站在某个角色背后 | 过肩视角 | 对话、对峙、误会、告白 | 关系张力 |
| 观众变成一个物品 | 道具视角 | 创意广告、搞笑、产品卖点 | 新鲜和记忆点 |
| 观众像在回忆里看 | 回忆视角 | 怀旧、亲情、旧梦留声机类情感 | 温柔克制 |
| 观众看一群角色秩序 | 群像视角 | 绒耀幼儿园类可爱搞笑、团队、班级 | 反应和节奏 |

## 5. 第一人称运镜

第一人称不是随便晃，它是“摄影机变成角色眼睛”。

适合：

- 主角打开门，看见不可思议的东西。
- 打斗里敌人逼近观众。
- 角色拿起旧物，回忆被触发。
- 可爱角色凑到镜头前，好像在看观众。

导演写法：

```text
我会让镜头像主角的眼睛。前景保留一点手部动作，呼吸带出轻微晃动，但主体始终清楚。镜头不乱跑，只跟着主角的注意力移动。
```

Seedance 2.0 提示词模板：

```text
5秒竖屏视频镜头。
镜头身份：第一人称主观视角，摄影机就是主角的眼睛。
主体：[被看见的人/物]。
动作链：主角的手从画面下方伸入 -> 慢慢触碰 [道具] -> [被看见的人/物] 产生反应。
场景：[具体空间]，前景有主角手部，背景保持稳定。
摄影：近景，眼平机位，轻微手持呼吸感，镜头只跟随视线缓慢靠近。
表演：[对方的眼神/停顿/反应]。
声音：[呼吸声/触碰声/环境声]。
剪辑点：手触碰道具或对方抬眼的瞬间切出。
一致性：保持道具位置、角色服装和空间方向一致。
避免：剧烈摇晃、突然飞行视角、手部变形、主体出画、脸部漂移。
```

常见失误：

- 第一人称写成“镜头快速穿越房间”，导致视角像无人机。
- 没写手部或视线目标，模型不知道摄影机是谁。
- 在一个镜头里又主观又环绕，视角身份冲突。

## 6. 第二人称运镜

第二人称是“镜头被角色当成你”。它适合让观众被点名、被邀请、被吐槽、被告白。

适合：

- 产品广告中角色直接把东西递给镜头。
- 情感短片里老人像对远方亲人说话。
- 搞笑短片里角色认真地向镜头解释离谱逻辑。
- 短剧里反派贴近镜头威胁观众。

导演写法：

```text
我会让角色真的看着镜头说话，但不让他一直讲。镜头要有反应空间：他说一句，停半秒，让表情和手里的动作接住情绪。
```

Seedance 2.0 提示词模板：

```text
4秒竖屏视频镜头。
镜头身份：第二人称直面镜头，角色把镜头当成面前的人。
主体：[角色]。
动作链：[角色] 看向镜头 -> 把 [道具/产品/旧物] 递近 -> 停顿半秒露出 [表情]。
场景：[具体空间]。
摄影：中近景，眼平机位，轻微推镜，推镜理由是靠近角色的情绪或卖点。
表演：眼神对准镜头，说话短，动作比解释更重要。
声音：[一句短台词/轻微音效/环境声]。
剪辑点：道具离镜头最近或表情落下时切。
一致性：保持角色脸部、服装、道具外观一致。
避免：长篇口播、嘴型夸张、眼神漂移、镜头像自拍乱晃。
```

## 7. 第三人称运镜

第三人称是最稳的叙事视角。它让观众看清人物、空间和动作关系。

适合：

- 打斗前交代空间。
- 短剧冲突升级。
- 群像喜剧反应。
- 产品使用流程。
- 特效奇观建立现实基准。

导演写法：

```text
我会先站在旁边看清楚这场戏。人物从哪里来、往哪里去、谁挡住谁，先交代明白，再切近景吃情绪。
```

Seedance 2.0 提示词模板：

```text
6秒视频镜头。
镜头身份：第三人称客观视角，摄影机在角色侧前方观察。
主体：[角色/群像/产品]。
动作链：[起始位置] -> [关键动作] -> [结果或反应]。
场景：[空间布局]，明确左侧、右侧、前景、背景。
摄影：全景或中景，平视或低机位，平稳横移/跟拍，运动理由是展示空间关系和动作动线。
表演：角色身体方向清楚，反应有停顿。
声音：[脚步/道具/环境/反应音]。
剪辑点：动作完成或群体反应定格时切。
一致性：保持空间方向、人物位置和道具关系一致。
避免：空间跳变、动作因果缺失、镜头绕到不该出现的位置。
```

## 8. 过肩与关系人称

过肩镜头让观众站在关系里，不是冷眼旁观。

适合：

- 告白前的犹豫。
- 短剧对峙。
- 家人误会。
- 客户和产品之间的使用关系。

Seedance 2.0 提示词模板：

```text
5秒视频镜头。
镜头身份：过肩视角，摄影机站在 [角色A] 身后，看向 [角色B]。
主体：[角色B] 的反应。
动作链：[角色A] 前景微动 -> [角色B] 听见一句话 -> [角色B] 眼神变化。
场景：[具体空间]。
摄影：中近景，前景保留 [角色A] 肩部虚化，焦点落在 [角色B] 表情，镜头轻微推近。
声音：[短台词/呼吸/环境声]。
剪辑点：[角色B] 眼神变化后切反打。
避免：前景遮挡主体、两人位置互换、焦点飘到背景。
```

## 9. 道具人称与产品视角

道具人称很适合创意广告和搞笑短片。观众像是杯子、手机、门缝、盒子、旧录音机、产品按钮。

适合：

- 产品卖点通过动作被看见。
- 旧物触发回忆。
- 可爱角色围着某个物品认真讨论。
- 搞笑场景中让观众变成“被误会的东西”。

导演写法：

```text
我会把镜头放到物品的位置，让观众变成这个东西。角色不是对空气表演，而是围着这个物品发生关系。
```

Seedance 2.0 提示词模板：

```text
5秒竖屏视频镜头。
镜头身份：道具视角，摄影机像是放在 [道具/产品] 的位置。
主体：[角色/手部/产品效果]。
动作链：[角色靠近] -> [手部操作道具] -> [出现结果/反应]。
场景：[具体使用场景]。
摄影：特写或近景，低机位或桌面高度，镜头固定或轻微推近，重点看清道具和手部动作。
表演：角色眼神看向道具，不看空气。
声音：[触碰声/按钮声/旧录音声/产品反馈声]。
剪辑点：产品效果出现或角色反应时切。
一致性：道具形状、颜色、位置不变。
避免：道具消失、手指变形、视角突然离开道具、背景文字乱码。
```

## 10. 回忆人称

回忆人称不是滤镜堆叠，而是“镜头像一个多年后想起这件事的人”。

适合：

- 旧梦留声机类怀旧情感。
- 亲情、公益、旧物、等待、遗憾。
- 没说出口的话。

导演写法：

```text
我会让镜头安静一点，不抢人物。旧物先出现，声音比画面早半拍，人物动作慢一点，情绪藏在手和眼神里。
```

Seedance 2.0 提示词模板：

```text
6秒横屏或竖屏视频镜头。
镜头身份：回忆视角，摄影机像多年后的记忆，安静、克制、稳定。
主体：[人物/旧物]。
动作链：[手停在旧物旁] -> [轻轻触碰] -> [人物没有说话，只低头或抬眼]。
场景：[老屋/旧街/厨房/门口/教室]，保留时间痕迹。
摄影：特写到近景，固定机位或极慢推镜，运动理由是情绪被触碰。
光线：自然柔光，低饱和暖色。
声音：旧录音底噪、远处环境声、很轻的音乐或一句克制旁白。
剪辑点：触碰声落下后留半秒再切。
避免：大哭大喊、过度煽情、滤镜过重、旁白解释画面。
```

## 11. 群像人称

群像人称要让观众看清角色秩序。尤其适合绒耀幼儿园类可爱搞笑：每个角色的反应位置固定，笑点来自“大家都很认真地误会了”。

导演写法：

```text
我会把摄影机放在教室桌面高度，先让所有小角色的站位清楚，再用一个角色的小动作引爆集体反应。笑点不是乱，是每个人认真错在不同地方。
```

Seedance 2.0 提示词模板：

```text
6秒竖屏视频镜头。
镜头身份：群像第三人称，摄影机在桌面高度观察一群角色。
主体：[软萌群像]。
动作链：[一个角色认真提出荒诞问题] -> [其他角色依次反应] -> [全体停顿形成表情包画面]。
场景：[幼儿园教室/小圆桌/操场]，角色站位固定。
摄影：中景，低机位平视，轻微横移展示群体反应，运动理由是看清每个角色的表情。
表演：每个角色反应不同，一个震惊，一个装镇定，一个慢半拍，一个认真记录。
声音：短促停顿、轻微环境声、一个小音效落点。
剪辑点：全体表情定住时切。
避免：角色互相融合、站位跳变、表情混乱、镜头过度摇晃。
```

## 12. 类型场景默认组合

| 类型 | 推荐人称 | 推荐运镜 | 不要这样做 |
| --- | --- | --- | --- |
| 可爱搞笑 | 群像第三人称 + 道具视角 | 桌面低机位、轻微横移、反应近景 | 镜头乱飞、角色没有个性差异 |
| 治愈 | 第三人称 + 回忆视角 | 固定机位、极慢推镜、手部特写 | 只拍空镜，没有情绪动作 |
| 怀旧情感 | 回忆视角 + 过肩 | 旧物特写、固定机位、声音先行 | 大段旁白解释、强行催泪 |
| 特效 | 第三人称建立 + 反应近景 | 先稳定后轻微环绕或拉镜 | 一开始就炸，缺少现实基准 |
| 打斗 | 第三人称空间 + 第一人称压迫 | 全景交代、跟拍、短主观冲击 | 快剪遮动作、主观镜头过长 |
| 创意广告 | 道具视角 + 第二人称 | 产品特写、递近镜头、动作证明 | 角色只口播卖点 |
| 短剧 | 第三人称 + 过肩 + 反应近景 | 近景抓台词、轻微推镜、反打 | 开头慢热、镜头只拍说话 |

## 13. 运镜句法库

推镜：

```text
镜头从 [中景/近景] 缓慢推近到 [表情/道具/卖点]，因为角色意识到 [真相/情绪/产品效果]。
```

拉镜：

```text
镜头从 [特写] 缓慢拉开，露出 [更大的空间/荒诞真相/孤独关系]。
```

摇镜：

```text
镜头从 [信息A] 平稳摇到 [信息B]，让观众在同一空间里完成发现。
```

横移：

```text
镜头跟着 [主体] 横向移动，依次揭示 [角色/道具/结果]，空间方向保持清楚。
```

跟拍：

```text
摄影机保持在 [角色侧后方/正前方/侧前方]，跟随 [角色动作]，主体始终清楚，背景形成速度感。
```

环绕：

```text
摄影机围绕 [主体] 缓慢转动，不超过半圈，表现 [觉醒/高光/关系变化]。
```

升降：

```text
摄影机从 [低处/高处] 缓慢升降，逐渐揭示 [空间规模/人物处境/产品完整形态]。
```

手持：

```text
轻微手持感，像人在现场跟着呼吸，画面有真实微晃但主体始终可读。
```

## 14. Seedance 2.0 生成顺序

默认顺序：

1. 先做风格参考、Moodboard和项目视觉圣经。
2. 再做角色圣经、场景圣经和道具圣经。
3. 确定人物外在欲望、内在缺口、防御方式和关系弧线。
4. 建立空间地图、人物站位和主要动线。
5. 为关键镜头写微动作和反应镜头。
6. 为每个镜头标注入点、出点、衔接方式和声音桥。
7. 规划旁白、字幕、屏幕字、品牌字和字幕安全区；可读文字默认后期添加。
8. 为关键镜头做可生成性评级；C级和D级镜头先降难、拆镜或测试关键帧。
9. 先生成关键帧，确认风格、角色和场景稳定。
10. 每个镜头控制在 4-6 秒，复杂动作拆开。
11. 先生成关键镜头，再补过渡镜头。
12. 先用第三人称建立空间，再用第一人称或过肩增强代入。
13. 多人称方案先做观众站位和人称切换表，再拆成独立 Seedance 2.0 镜头。
14. 对广告，先生成产品动作证明镜头，再生成情绪或包装镜头。
15. 对情感片，先生成旧物和人物克制动作，再补旁白和声音。
16. 对打斗，先生成空间交代镜头，再生成关键打击点。
17. 生成失败时，调用 AI生成连续性与故障修复库。

## 17. 自检

输出前检查：

1. 是否明确 Seedance 2.0 为默认视频生成组织方式？
2. 是否先讲导演拍法，再给提示词？
3. 是否明确每个镜头的人称视角？
4. 是否每个镜头只有一个主要运镜？
5. 是否写清动作起点、中点和终点？
6. 是否有声音和剪辑点？
7. 是否避免空泛 AI 腔？
8. 是否给出角色、场景、道具一致性要求？
9. 是否写入项目风格锁定句，避免一镜一个风格？
10. 是否把抽象情绪转成眼神、手部、停顿或反应镜头？
11. 是否写入空间锁定句，避免站位跳变和左右互换？
12. 是否写入入点、出点、衔接方式和下一镜钩子，避免片段互相断开？
13. 是否规划字幕安全区，避免直接生成可读中文、错误字幕或变形Logo？
14. 高风险镜头是否做了可生成性评级、拆镜或降难？
15. 角色动作、微动作和台词是否来自人物动机与关系变化？
16. 是否写清观众站位、摄影机身体限制和人称切换点？
17. 是否写清身体化镜头卡、运动幅度和视觉锚点？
18. 画内对白是否写清口型同步、单说话人、短台词、说话节拍和后期兜底？
19. 是否能直接拿去生成或继续拆镜头？
