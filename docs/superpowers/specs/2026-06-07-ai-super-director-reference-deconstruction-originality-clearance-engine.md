# AI超级导演参考作品拆解、原创替换与合规转译闸门

## 1. 定位

这套闸门专门处理“像某部电影、像某个特摄、像某个账号、像某条爆款广告、参考这个作品但要原创、吸取精华别照搬”的需求。

它不替代电影、特摄、短片与创意精华转译库。精华转译库负责把参考变成导演骨架；本闸门负责先判断哪些能继承、哪些必须替换、哪些需要合规提醒，再把参考变成一个新的原创母题和可生成拆镜。

默认判断：

```text
我会这样拍：我不拿它的外壳，只拿它为什么有效。角色、台词、Logo、标志性画面、专属道具和世界观都舍掉；保留情绪压力、结构节拍、场面调度方法、镜头身体、声音记忆和观众感受，再换成我们自己的角色关系、场景任务和视觉母题。
```

核心公式：

```text
参考对象 + 观众想要的感受 + 可继承层 + 禁用层 + 替代层 + 三次原创替换 + 新视觉母题 + Seedance可生成拆镜 + 合规说明
```

## 2. 触发词

用户出现以下说法时，默认调用本闸门：

- “像某电影”“像某导演”“像某特摄”“像某动画”“像某游戏”“像某广告”。
- “吸取精华”“电影感但原创”“参考这个但不要抄”“像这个账号风格”。
- “照这个爆款来一条”“复刻这个结构”“保留感觉换个故事”。
- “像绒耀幼儿园但原创”“像旧梦留声机那种”“像某类作品但要原创”。
- “别侵权”“别太像原片”“换成我们自己的版本”“只要精神不要外壳”。

## 3. 四层拆解

参考对象先拆成四层：

| 层级 | 可以继承 | 必须避开 |
| --- | --- | --- |
| 情绪层 | 观众感受、压力方向、爽点、心疼点、荒诞感、余味 | 具体台词、名场面、角色口头禅 |
| 结构层 | 冷开场方式、三次升级、反转位置、证明链、结尾回收 | 原故事走向、具体桥段、完整剧情复刻 |
| 调度层 | 站位压力、镜头身体、动作因果、声音先行、反应剪辑 | 标志性机位组合、可识别镜头复刻 |
| 美术层 | 色彩关系、材质对比、光线逻辑、视觉母题功能 | 角色造型、Logo、专属符号、世界观设定 |

## 4. 三次原创替换

每次参考转译必须至少替换三处：

1. 角色关系替换：把原作品人物关系换成新的关系压力，例如父女、同事、师生、店主顾客、主播观众、产品使用者。
2. 场景任务替换：把原场面任务换成新的具体任务，例如找东西、证明产品、隐瞒秘密、完成道歉、通过测试、守住一个小承诺。
3. 视觉母题替换：把原标志性符号换成新的原创母题，例如旧钥匙、玻璃杯、红色贴纸、门缝光、桌角划痕、鞋底水声。

如果参考非常具体，再加两刀：

4. 声音记忆替换：换掉原配乐、台词、音效和口头禅，改成新的道具声、环境声或静音点。
5. 结尾回收替换：不复刻原结尾，用新的动作、物件或声音回收主题。

## 5. 高频参考三列表

当用户说“像某作品但原创”时，不要只说“会原创替换”。必须先输出三列：

```text
可继承层：只拿导演方法、观众感受和结构功能。
禁用层：不能拿角色、台词、Logo、专属符号和标志画面。
替代层：立刻换成新的角色关系、场景任务、视觉母题、声音钩子和结尾回收。
```

| 参考类型 | 可继承层 | 禁用层 | 替代层 |
| --- | --- | --- | --- |
| 某电影名场面 | 情绪压力、空间压迫、反应节奏、声音先行 | 原机位组合、角色造型、台词、标志性构图 | 换成新生活空间、新人物选择、新声音源和新结尾动作 |
| 某特摄/英雄作品 | 现实基准、仪式停顿、压力方向、受力结果 | 英雄造型、面具、变身口号、必杀技名、怪兽符号 | 换原创触发物、能力规则、身体姿态、反派压力和声音记忆 |
| 某动画/游戏 | 规则感、角色职能、升级节奏、世界反差 | 角色外观、阵营标志、地图设定、技能名、UI符号 | 换现实任务、原创角色秩序、道具规则和低风险可生成动作 |
| 某爆款短视频 | 前三秒问题、误会升级、评论入口、反差结构 | 原账号人设、口头禅、固定布景、标题句式照搬 | 换角色世界、主动作、封面记忆帧和评论接话口 |
| 某创意广告 | 痛点可视化、产品介入、证据镜头、人物确认 | 原产品包装、品牌口号、广告画面符号、镜头复刻 | 换产品动作、证明方式、使用场景和品牌记忆帧 |
| 某可爱治愈项目 | 小主体大任务、反应停顿、群像秩序、温柔介入 | 原角色造型、固定道具、表情包动作、场景符号 | 换小主体身份、任务规则、群像职能和可截图落点 |
| 某悬疑反转 | 信息差结构、声音线索、空间压力、反转位置 | 原谜题、凶器、身份设定、标志性镜头 | 换秘密载体、空间方向、伏笔物件和反转后的反应镜头 |
| 某情感短片 | 克制表演、旧物回声、留白结尾、声音余味 | 原亲密关系、旧物造型、台词金句、结尾动作 | 换关系缺口、旧物功能、防御动作和收回动作 |
| 某账号栏目 | 栏目节奏、问题结构、互动方式、系列感 | 主播人设、口播句式、布景、声音语气复刻 | 换主持身份、观众问题、道具流程和系列收口动作 |

三列表判断句：

```text
如果替代层写不出来，说明还没有真正原创，只是在换名。
```

## 6. 禁用清单

无论用户怎么说，默认不复刻：

- 可识别角色造型、服装、面具、怪兽、英雄形态、武器和专属道具。
- 真实电影、动画、游戏、广告、账号里的标志性画面、台词、Logo、标题字和音乐。
- 真实人物肖像、声音、口音、说话节奏和身份标签。
- 未授权品牌名、商标、包装字、店招、战队徽章、赛事名和机构名。
- 直接替换姓名、颜色或Logo后照搬原剧情。

可以做：

- 保留“一个普通人被一个规则逼到选择”的结构。
- 保留“先现实基准，再异常升级，再反应确认”的特效方法。
- 保留“产品动作证明卖点”的广告证明链。
- 保留“声音先于画面制造信息差”的调度方法。
- 保留“结尾用物件回声留下余味”的记忆系统。

## 8. 类型专用转译

### 8.1 电影感

```text
只继承情绪压力、空间调度和镜头目的，不继承名场面。
```

输出重点：

- 观众感受：紧张、孤独、热血、心疼、荒诞、宿命、释放。
- 空间压力：门、桌、窗、走廊、车内、雨夜、厨房、楼梯等如何逼人选择。
- 原创替换：换成新的生活场景和人物任务。

### 8.2 特摄感

```text
只继承现实基准、仪式停顿、压力方向和受力结果，不继承英雄造型。
```

输出重点：

- 触发物必须原创。
- 能力规则必须简单。
- 怪兽、英雄、标志动作和必杀技名称必须原创。

### 8.3 可爱治愈爆款

```text
只继承小主体大任务、误解升级和可截图反应，不继承现成角色。
```

输出重点：

- 固定世界换成原创空间。
- 群像职能换成新角色秩序。
- 结尾表情包动作换成原创动作。

### 8.4 怀旧情感

```text
只继承旧物承载关系、没说出口和声音回声，不继承具体故事。
```

输出重点：

- 旧物必须换。
- 关系缺口必须换。
- 旁白和配音必须原创。

### 8.5 创意广告

```text
只继承证明链，不继承广告画面和品牌表达。
```

输出重点：

- 痛点可视化换成新生活处境。
- 产品动作必须和真实卖点绑定。
- 品牌记忆帧原创。

## 9. Seedance 2.0 可生成性规则

参考转译进入 Seedance 2.0 前，默认规则：

1. 不写真实作品名进最终视频提示词，改写为原创风格锁定句。
2. 不写已有角色、Logo、台词、专属道具和可识别造型。
3. 每镜只继承一个导演方法：声音先行、压力站位、仪式动作、反应停顿、视觉母题或证明动作。
4. 复杂名场面必须拆成原创场景里的可生成动作。
5. 如果用户给参考图，先做图片参考解读，说明只继承构图、色彩、材质或动作气质，不继承可读文字和可识别IP。
6. 高风险参考默认先输出“保留/舍掉/原创替换”，再写分镜。

风险评级：

| 需求 | 风险 | 处理 |
| --- | --- | --- |
| “有电影感” | A | 抽取调度和情绪 |
| “像某类短片但原创” | B | 写清可继承层、禁用层和替代层 |
| “像某账号来一条” | B | 提取栏目结构，换角色世界 |
| “像某具体电影名场面” | C | 禁用画面复刻，换场景任务 |
| “复刻某IP角色/台词/Logo” | D | 拒绝复刻，给原创替代方案 |

## 12. 自检

输出前检查：

1. 是否没有复刻具体角色、台词、Logo、造型、专属道具和标志性画面？
2. 是否明确写了用户真正想要的观众感受？
3. 是否写出可继承层、禁用层和替代层三列表？
4. 替代层是否具体到角色关系、场景任务、视觉母题、声音钩子和结尾回收？
5. 是否至少完成角色关系、场景任务和视觉母题三次替换？
6. 声音记忆是否原创，而不是套用原作品配乐或口头禅？
7. 结尾是否用新的动作、物件或声音回收？
8. Seedance 提示词是否不含真实作品名、IP名、Logo和可读标题？
9. 如果用户坚持复刻，是否转为原创替代方案？
