# AI超级导演对白口型自然同步与表演声画调度库

## 1. 定位

这份库负责让人物对白、口型、表情、声音和剪辑同步。AI视频里人物一开口最容易坏：嘴型乱动、台词太长、多人同时说话、表情和声音错位、字幕跟不上、口播像假人。超级导演必须在写分镜和 Seedance 2.0 提示词前先决定：这句话到底要不要让角色在画面里说，能不能靠反应镜头、旁白、字幕或画外声更稳地完成。

本库和这些能力联动：

- 表演指导与对白台词库：决定角色说什么、怎么停顿、潜台词是什么。
- 画外音、字幕与口播文案库：决定哪些信息交给字幕、旁白、口播或后期字幕。
- 剪辑节奏与声音设计库：决定声音入点、出点、静音、环境声和声音桥。
- Seedance 2.0 手册：把口型同步要求写进每条视频提示词。
- AI生成连续性与故障修复库：修复口型错位、声音错位和人物说话异常。

触发词：

- 口型、嘴型、唇形、对口型、口型同步、嘴巴自然、说话自然。
- 人物对白、台词、对话、短剧对白、角色说话、自然说话。
- 配音同步、声画同步、字幕同步、声音和画面对不上。
- 不要假人、不要嘴乱动、不要口播机器、不要说话穿帮。

## 2. 总原则

我会这样拍：
人物说话这件事不能贪。一条 Seedance 镜头里，如果又要复杂走位、又要长台词、又要多人互动，口型一定容易坏。我会把话切短，把情绪放进眼神和停顿，把重要信息交给反应镜头、字幕或画外声。真正需要看见嘴说出来的台词，只保留最短、最有钩子的那一句。

对白口型同步公式：

```text
说话人 + 一句短台词 + 说话时长 + 嘴部可见度 + 表情节拍 + 停顿点 + 声音来源 + 字幕/后期兜底
```

硬规则：

1. 一镜只让一个主要角色说话。
2. 口型要求高时，每句台词尽量 3-8 个汉字，最长不超过 12 个汉字。
3. 复杂台词拆成：近景说一句 -> 反应镜头接下一句 -> 画外声或字幕补信息。
4. 多人对话不用同一镜头互相抢话，改成正反打、过肩、反应近景。
5. 角色说话时不要同时跑、打、转身、低头找东西和大幅运镜。
6. 嘴部要清楚时用近景或中近景，不用远景让模型猜口型。
7. 情绪强时先停半秒再说，或者说完停半秒让表情接住。
8. 高风险口型镜头要标注“可后期配音/字幕同步”，不要把成败全押在生成。

## 3. 对白可生成性评级

| 等级 | 条件 | 建议 | Seedance 2.0 风险 |
| --- | --- | --- | --- |
| A | 单人近景，一句 3-8 字短句，动作少 | 可直接生成 | 低 |
| B | 单人中近景，一句 8-12 字，有轻微表情 | 可生成，保留停顿 | 中 |
| C | 两人对话、台词较长、说话同时有走位 | 拆成正反打和反应镜头 | 高 |
| D | 多人同时说话、长篇口播、打斗中喊台词、情绪崩溃大喊 | 不建议一条生成，改为画外声、字幕或后期配音 | 很高 |

导演判断：

口型同步不是“把台词写进提示词”就完了。真正稳定的做法是让一句话有镜头位置、有时间、有停顿、有反应、有后期兜底。

### 3.1 口型转移决策卡

每句台词先问一句：观众是否必须看到角色嘴巴说出这句话？如果不是必须，就不要为了“信息重要”强行让人物画内开口。重要但长的信息更适合转给反应镜头、画外声、后期字幕或后期配音；转移之后必须补画面证据，让观众不用看嘴也能理解。

逐句判断：

```text
这句话的任务：
必须看见嘴说吗：
如果必须画内说：谁说、几字、说前停顿、说后反应。
如果不必画内说：转给反应镜、画外声、后期字幕还是后期配音。
转移方式：[画内说/反应镜接/画外声/后期字幕/后期配音]。
兜底镜头：听者反应、手部动作、产品动作、道具变化或环境声落点。
失败第一刀：缩短台词、改听者反应、改画外声、改字幕或拆成正反打。
```

转移表：

| 台词类型 | 默认决策 | 稳定拍法 |
| --- | --- | --- |
| 情绪钩子短句 | 画内说 | 单人近景或中近景，3-8 字，说前停半秒，说后给眼神 |
| 信息解释长句 | 画外声或后期字幕 | 画面给听者反应、道具证据或空间变化 |
| 广告卖点参数 | 后期字幕或品牌字 | 画面先给产品动作、手部证明和结果特写 |
| 多人争吵 | 正反打拆句 | 一镜一个主说话人，反应镜接情绪 |
| 打斗中喊话 | 喘息或短口令 | 打斗中不解释规则，结果台词放打前或打后近景 |
| 口型已失败过 | 画外声、后期配音或听者反应 | 用背影、侧脸、手部、环境声和反应镜兜底 |

硬规则：

1. 不是所有重要信息都要画内开口，重要但长的信息优先转移。
2. 转移后必须补一个画面证据：反应、产品动作、道具、环境声或字幕安全区。
3. 如果转移方式说不清，先删台词、缩短台词或拆镜。
4. 口型转移不是偷懒，是把成败从“嘴巴准不准”转到“观众看不看懂”。

## 4. 口型同步镜头设计

### 4.1 单人短句

适合：短剧第一句、告白、威胁、广告口播钩子、角色口头禅。

写法：

```text
角色中近景，脸部清楚，嘴部可见。
角色先停半秒，看向对方或镜头，然后自然说一句短台词：“[短句]”。
说话时头部保持稳定，嘴部动作自然，表情和台词情绪一致。
说完停顿半秒，眼神发生变化。
```

不要这样写：

- 角色边跑边说长台词。
- 角色背对镜头说关键台词。
- 镜头快速环绕时要求精准口型。

### 4.2 两人对话

适合：短剧冲突、情感拉扯、审问、误会、告白。

拆法：

```text
镜头1：过肩或中近景，A说一句短句。
镜头2：B反应近景，不急着说，眼神停住。
镜头3：B说一句短句。
镜头4：A听见后的表情变化，声音可作为画外声延续。
```

原则：

- 每条镜头只让一个人的嘴承担口型。
- 另一个人用背影、肩膀、眼神或手部反应接台词。
- 台词信息密集时，把解释转成字幕或画外声。

### 4.3 群像对白

适合：可爱搞笑、团队、幼儿园、会议、集体误会。

拆法：

```text
群像中景建立角色位置。
切一个角色近景说一句短句。
切群像反应停顿。
切第二个角色近景说一句短句。
最后用集体表情或短字幕收笑点。
```

不要让一群角色同时张嘴说话。群像笑点来自反应顺序，不是每个人一起说。

### 4.4 广告口播

广告人物不能像口播机器。口播只负责补刀，产品动作负责证明。

稳定结构：

```text
痛点画面 -> 产品动作 -> 使用者停住 -> 中近景一句短口播 -> 结果特写
```

口播规则：

- 先有动作证明，再有一句话。
- 一句只讲一个卖点。
- 价格、参数、品牌口号和可读文字后期添加。
- 口播太长时，改成旁白加字幕，不强迫角色全部对口型。

### 4.5 打斗和特效里的台词

动作镜头里不要塞长台词。

推荐：

- 打之前说一句短句。
- 打中只留喘息、喊声或音效。
- 打完切近景说一句结果台词。
- 特效启动时用声音或短口令，不用解释规则。

例子：

```text
错误：角色冲刺、躲闪、挥拳、爆炸，同时说一整句解释能力来源。
修正：角色停住半秒，说“现在轮到我了。”切动作镜头，后续能力规则用画面和音效解释。
```

## 5. 台词长度和节拍

| 用途 | 推荐长度 | 节拍 | 示例 |
| --- | --- | --- | --- |
| 开场钩子 | 3-8字 | 先停再说 | “别开门。” |
| 威胁 | 4-10字 | 靠近后说 | “你终于来了。” |
| 告白 | 6-12字 | 说前看手，说后看眼 | “我其实一直记得。” |
| 反转 | 3-8字 | 说完切反应 | “他没死。” |
| 广告口播 | 6-12字 | 动作后补刀 | “这下真的安静了。” |
| 可爱搞笑 | 3-10字 | 认真说，停半秒 | “月亮请假了。” |
| 打斗口令 | 2-6字 | 动作前 | “别眨眼。” |

台词拆分：

```text
原句：你以为我一直在逃，其实我是在等第三个人进来。

拆镜：
镜头1：角色近景说：“你以为我在逃。”
镜头2：对方眼神停住。
镜头3：角色压低声音说：“我是在等他。”
镜头4：门外脚步声响起。
```

嘴部可见度：[近景/中近景，脸部清楚，嘴部无遮挡]。
说话节拍：[先停半秒 -> 自然说短句 -> 说完停半秒]。
表情同步：[说话前、说话中、说话后各有什么微表情]。

避免：[长对白、多人抢话、嘴型漂移、头部大幅晃动、可读文字乱码、音画不同步]。
```

## 7. 什么时候不用画内口型

这些情况默认不要强求角色嘴巴精准说话：

| 情况 | 更稳做法 |
| --- | --- |
| 需要解释背景 | 画外音或字幕 |
| 台词超过 12 字 | 拆成多镜或改旁白 |
| 角色在跑、打、摔、转身 | 动作镜头不说话，前后近景说 |
| 群像多人同时回应 | 先群像反应，再切单人短句 |
| 画面重点是产品 | 产品动作证明，口播后期加 |
| 情绪很克制 | 让角色不说，用呼吸、眼神、手部和环境声 |
| 口型生成失败过 | 改成背影、侧脸、反应镜头、画外声或后期配音 |

## 8. 口型故障修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 嘴巴乱动但听不清台词 | 提示词没有固定说话人和台词长度 | 改成单人近景，一句短台词，写说话节拍 |
| 口型和声音错位 | 台词太长或动作太多 | 缩短台词，拆镜，关键句后期配音 |
| 多人一起张嘴 | 同镜多人承担对白 | 改正反打，一个镜头一个说话人 |
| 表情和台词情绪不一致 | 没写说话前后表情 | 写“说前停顿、说中克制、说后眼神变化” |
| 字幕乱码 | 要求模型生成可读文字 | 改为画面无文字，字幕后期添加 |
| 广告口播像假人 | 只有讲解没有动作 | 先拍产品动作和结果，再留一句短口播 |

```

## 10. 自检

输出带对白的 Seedance 2.0 方案前，AI超级导演自问：

1. 每个口型镜头是否只有一个主要说话人？
2. 每句画内台词是否尽量 3-8 字，最长不超过 12 字？
3. 是否写清说话前停顿、开口、收口和说完后的反应？
4. 嘴部是否在近景或中近景里清楚可见？
5. 角色说话时是否避免跑、打、转身、大幅运镜和复杂手部动作？
6. 多人对话是否拆成正反打、过肩和反应近景？
7. 每句台词是否先判断必须画内说，还是可以转移到反应镜、画外声、后期字幕或后期配音？
8. 长信息是否改成画外音、字幕或后期配音，而不是硬塞口型？
9. 转移后的信息是否补了反应、产品动作、道具、环境声或字幕安全区这类画面证据？
10. 字幕是否规划为后期添加，避免 Seedance 直接生成乱码文字？
11. 声音来源是否明确：画内声、画外声还是后期配音？
12. 是否有口型风险评级和失败修复方案？
13. 输出是否让人物像真实在说话，而不是像假人开口？
