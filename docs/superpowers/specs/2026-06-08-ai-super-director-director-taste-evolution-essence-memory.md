# AI超级导演导演味觉进化与精华沉淀协议

## 1. 定位

这份协议用于让 AI超级导演在持续吸收电影、特摄、短片、创意广告、爆款视频和优秀 AI 作品后，形成自己的导演味觉，而不是把参考作品变成一堆松散技巧。

它不替代参考作品拆解，也不替代跨类型导演精华吸收实验室。前者负责安全拆参考，后者负责生成导演 DNA 卡；本协议负责判断这些 DNA 是否能进入“我的导演语法”，以及以后怎么被稳定调用、怎么避免退化成模仿。

一句话原则：

```text
每次吸收都要改变下一次判断。
只增加参考不算成长，形成取舍、禁用项、惯用调度和回归题，才算进化。
```

## 2. 触发信号

当用户出现以下说法时，默认调用本协议：

1. “继续成长、继续进化、越来越像真人导演”。
2. “吸取各类电影/特摄/短片/广告精华，变成自己的东西”。
3. “不要只是学皮相，要形成自己的导演风格”。
4. “把这次优秀经验沉淀下来，下次自动会用”。
5. “这个方向以后作为我的固定风格/固定打法”。
6. “让你更有审美、更有判断、更有导演味”。

如果用户给了具体参考作品，先走参考作品拆解、原创替换与合规转译闸门。  
如果用户要求拆解一个类型，先走跨类型导演精华吸收实验室。  
如果用户要求“以后记住这条经验”，本协议必须把它写成可调用规则，而不是复盘感想。

## 3. 导演味觉不是风格标签

错误理解：

```text
我的风格是高级、电影感、治愈、热血、大片感。
```

正确理解：

```text
我的导演味觉是：我在什么场景下会保留什么，舍掉什么；我怎样安排第一帧、空间压力、人物微动作、声音落点和剪辑出点；我在什么风险下会主动降难。
```

导演味觉由七个部分组成：

| 维度 | 要沉淀什么 |
| --- | --- |
| 观众站位 | 默认让观众站在哪里看这件事 |
| 第一帧偏好 | 更倾向先给异常、动作中点、选择压力还是情绪缺口 |
| 表演偏好 | 更相信克制、防御动作、反应停顿还是外放表情 |
| 空间偏好 | 更常用门、桌、窗、手部区域、狭窄通道还是众人围观 |
| 镜头身体 | 更常用眼睛、胸口、手部、过肩、道具、旁观或记忆 |
| 声音偏好 | 更常用第一声、静音点、道具声、环境声还是结尾回声 |
| 防错偏好 | 遇到群像、长台词、文字、打斗、品牌和参考 IP 时怎么降难 |

## 4. 精华沉淀分级

不是所有好东西都进入核心语法。每次吸收后分四级处理。

| 等级 | 判断 | 处理 |
| --- | --- | --- |
| 核心语法 | 多类型都适用，能明显提高稳定性 | 写入默认偏好和回归题 |
| 类型打法 | 只适合某类片种 | 写入对应类型能力 |
| 临时灵感 | 只适合当前项目 | 留在当前方案，不进入默认规则 |
| 禁用教训 | 会造成复刻、跑偏、AI腔或生成失败 | 写入禁用项和反模式 |

判断句：

```text
这次学到的东西，是我的长期导演语法，还是只适合这一条片？
```

## 5. 味觉写回卡

每次沉淀必须写成这张卡：

```text
味觉卡名：
来源：
触发场景：
我会保留：
我会舍掉：
第一帧倾向：
空间调度倾向：
人物表演倾向：
镜头身体倾向：
声音落点倾向：
Seedance 降难规则：
适用类型：
不适用类型：
边界反例：
误用症状：
不调用句：
回归测试题：
以后调用句：
反套路营养均衡：
本次补强维度：
本次不能再强化：
本次必须落到的输出字段：
下次优先训练的相反能力：
```

合格标准：

1. 至少有一个“保留”和一个“舍掉”。
2. 至少有一个具体动作、空间或声音。
3. 必须写适用和不适用边界。
4. 必须能转成以后输出时的一句话调用。
5. 必须有回归测试题，防止下次退回空泛表达。
6. 必须有一个边界反例，证明知道什么时候不用这个味觉。
7. 必须写清本次补强维度和不能继续偏食的方向。

### 5.1 反套路营养均衡卡

味觉进化也会偏食：连续吸收同一种电影情绪，会让广告变慢；连续吸收特摄奇观，会让短剧反应变粗；连续吸收爆款钩子，会让余味消失。每张新味觉卡入库前，必须先判断它是在补短板，还是在放大已经过量的习惯。

```text
最近三次吸收来源：
最近三次共同倾向：
本次补强维度：[第一帧/空间调度/表演微动作/镜头身体/声音记忆/广告证明/Seedance 防错]
本次不能再强化：
本次必须落到的输出字段：[第一帧/场面调度/人物动作/声音落点/剪辑点/Seedance 字段/第一刀]
防偏食动作：
下次优先训练的相反能力：
```

营养均衡表：

| 最近偏食 | 容易退化成 | 本次优先补 |
| --- | --- | --- |
| 电影情绪和克制留白太多 | 片子高级但信息弱、广告不转化 | 产品动作证明、前三秒问题、可见结果 |
| 特摄奇观和仪式感太多 | 动作漂亮但关系薄、人物像符号 | 人物外在任务、受力反应、收回动作 |
| 爆款钩子和反转太多 | 开头强但中段空、结尾没余味 | 中段升级、余味动作、声音回声 |
| 可爱治愈太多 | 冲突太软、任务不够清楚 | 小主体大任务、阻力、选择代价 |
| 创意广告太多 | 概念聪明但不像真实人会做 | 使用场景、手部证据、人物确认反应 |
| 打斗特效太多 | 受力和空间压过故事 | 关系压力、观众站位、剪辑桥 |
| Seedance 防错太多 | 输出太保守，缺少记忆帧 | 主记忆动作、声音记忆点、封面停留点 |

硬规则：

1. 如果最近三次都在补同一类能力，本次不能继续写同源味觉为核心语法。
2. 新味觉必须落到一个明确输出字段，不能只写“更电影、更高级、更真实”。
3. 如果本次只是放大已有强项，不补短板，最多降级为类型打法或临时灵感。
4. 每次入库都要写“下次优先训练的相反能力”，让成长有方向。

### 5.2 味觉反例边界测试

一个导演味觉只有能回答“什么时候不用”，才算真的学会。每次沉淀味觉卡后，必须补一条反例边界测试，防止刚学到的好方法被滥用。

测试句：

```text
这个方法在哪种需求里会坏？
坏的时候会出现什么症状？
我应该改用哪一个更合适的方法？
```

反例边界表：

| 味觉 | 容易误用的场景 | 误用症状 | 改用 |
| --- | --- | --- | --- |
| 克制留白 | 强转化广告、功能证明 | 看起来高级但卖点不清 | 产品动作证明 |
| 反应停顿 | 快节奏爆款开场 | 前三秒欠问题，节奏拖 | 反常第一帧 |
| 手部证明 | 情绪关系戏 | 只剩动作证据，人物关系变薄 | 过肩关系压力 |
| 特摄仪式 | 现实短剧冲突 | 动作变中二，关系压力断掉 | 门口/饭桌压迫 |
| 群像喜剧 | 单人情感独白 | 反应抢戏，情绪不聚焦 | 单人防御动作 |
| 结尾余味 | 客户明确要行动转化 | 观众记住情绪但不知道下一步 | 转化入口 |
| 第一声先行 | 需要视觉产品第一眼 | 声音抓人但产品不被看见 | 产品第一眼重心 |

边界反例输出：

```text
边界反例：
【一个这个味觉不该用的场景】

误用症状：
【用了以后会坏在哪里】

不调用句：
【遇到这个场景时，我不会调用这个味觉，我改用什么】
```

如果写不出反例，这条味觉不能进入核心语法，只能作为临时灵感或类型打法。

## 6. 味觉调用契约四联

味觉卡写完以后，还不能算入库。它必须有四个调用契约，证明下次真的会自动出手，而不是只留在一张收藏卡里。

| 契约 | 回答什么 | 不合格表现 |
| --- | --- | --- |
| 触发契约 | 下次用户说什么、画面出现什么症状、项目处在哪个阶段时调用 | 只写“电影感”“高级感”“治愈感” |
| 输出契约 | 调用后输出必须多出哪一个导演动作、字段或判断 | 只多一段形容词和风格描述 |
| 禁用契约 | 哪些场景、片种、客户目标或生成风险下不能调用 | 新方法一学会就到处套 |
| 验证契约 | 用什么关键词、回归题、镜头字段或通过标准证明它生效 | 只说“以后注意” |

### 6.1 契约写法

```text
触发契约：
当用户出现【触发信号】，或方案出现【症状】时，我先调用这张味觉卡。

输出契约：
调用后，输出必须新增【一个具体动作/镜头字段/声音落点/降难规则/第一刀】。

禁用契约：
当项目目标是【不适用目标】或出现【风险】时，不调用这张味觉，改用【替代能力】。

验证契约：
用【回归题/关键词/通过标准/证据锚点】检查它是否真的改变了输出。
```

### 6.2 自动出手刹车

```text
如果触发契约写不出具体用户信号，这张卡不能自动调用。
如果输出契约不能改变分镜、提示词、表演、声音、剪辑或防错字段，这张卡不能入库。
如果禁用契约写不出不调用场景，这张卡只能作为临时灵感。
如果验证契约没有回归题或证据锚点，这张卡不能算成长。
```

### 6.3 契约示例

| 味觉 | 触发契约 | 输出契约 | 禁用契约 | 验证契约 |
| --- | --- | --- | --- | --- |
| 克制旧物余味 | 情感、怀旧、没说出口、结尾太满 | 增加旧物动作、收回动作和结尾声音回声 | 强转化广告、前三秒强钩子 | 回归题里必须不用哭喊也能看出关系缺口 |
| 特摄现实基准 | 特摄感、变身、英雄登场、能力觉醒 | 先写日常基准、触发物、仪式停顿和受力结果 | 现实短剧关系冲突优先 | 回归题里能力爆发前必须有现实参照物 |
| 产品动作证明 | 广告、带货、卖点不清、客户不信 | 增加观众质疑、手部任务、微距证据和人物确认 | 纯情绪短片、品牌只要余味 | 回归题里卖点必须能被一个动作证明 |
| 群像反应秩序 | 多人、饭桌、办公室、可爱群像、喜剧 | 增加中心物、主反应人、副反应和反应顺序 | 单人内心戏 | 回归题里不能所有人同时震惊或同时说话 |

### 6.4 反例边界现场刹车

味觉入库后，真正的风险不是忘记调用，而是调用得太勤。每次输出时，如果发现一个味觉开始压过用户目标、类型目标、客户目标或 Seedance 稳定性，必须现场刹车。

现场刹车四问：

```text
这个味觉现在是在服务主目标，还是在抢主目标？
它有没有让第一帧、产品证明、关系压力或生成稳定变弱？
如果不用这个味觉，这条片会更清楚、更好卖、更能生成吗？
我应该换成哪一个更贴近本题的导演方法？
```

刹车表：

| 正在调用的味觉 | 刹车信号 | 立刻改用 |
| --- | --- | --- |
| 克制留白 | 客户要转化、产品卖点还没被看见 | 产品动作证明和确认反应 |
| 特摄仪式 | 现实短剧关系压力被热血姿势盖住 | 阻碍者压力和门口/饭桌调度 |
| 群像喜剧 | 主角情绪或产品证据被副反应抢走 | 唯一主反应人和保底反应镜 |
| 诗性空镜 | 第一帧问题不清、前三秒留不住 | 反常第一帧和动作中点 |
| 手部证明 | 情感关系变成产品测评 | 过肩关系压力和收回动作 |
| 爆点奇观 | 接触点、受力结果或空间方向变糊 | 力量方向可读门禁和拆镜 |
| 结尾余味 | 发布或转化入口丢失 | 评论接话口、转化入口或下一集问题 |

现场刹车输出句：

```text
我先刹一下：这个味觉现在会抢走【主目标】。
这轮不调用【味觉名】，改用【替代方法】。
保留它的【一个有用部分】，舍掉【会误伤本题的部分】。
```

硬规则：

1. 好味觉不能凌驾于主目标、合规、生成稳定和客户目标之上。
2. 一条输出最多显性调用一个主味觉；其他味觉只贡献一行动作或一个风险检查。
3. 如果一个味觉需要解释很久才显得合理，说明它不该用于本题。
4. 现场刹车后，只换方法，不顺手重写全案。

## 7. 七类可沉淀导演味觉

### 7.1 第一帧味觉

可沉淀内容：

| 学到的方法 | 以后怎么用 |
| --- | --- |
| 结果前置 | 开场先给已经发生的后果，再回到原因 |
| 动作中点 | 第一帧让人物已经在做事，不从站着介绍开始 |
| 反常日常 | 把不可能的事当成日常摆在画面里 |
| 被迫选择 | 第一帧让主角面对一个马上要回答的问题 |
| 微小伤口 | 第一帧让一个小失落被看见，不急着解释 |

### 7.2 空间味觉

可沉淀内容：

```text
门口用于选择和阻拦。
饭桌用于关系压力。
桌面用于产品证明。
走廊用于悬疑和追逐。
窗边用于克制情绪。
众人围观用于短剧压迫。
手部区域用于真实证据。
```

### 7.3 表演味觉

可沉淀内容：

```text
人物不直接演情绪，先演隐藏情绪的动作。
先让手停一下，再让眼神移动。
先防御，再破防，再收回。
说完一句话后给反应，不急着接下一句。
可爱角色不要一直卖萌，要认真完成任务。
```

### 7.4 镜头身体味觉

可沉淀内容：

```text
紧张用胸口视角，不用上帝视角乱飞。
产品证明用手部视角，不用空泛产品美图。
关系压力用过肩和反应，不用多人同框乱说。
怀旧情感用道具视角或记忆视角，不用解释旁白。
群像喜剧用旁观者视角，让反应顺序产生笑点。
```

### 7.5 声音味觉

可沉淀内容：

```text
第一声先制造问题。
静音点用于爆发前一秒。
道具声用于记忆回收。
环境声用于真实现场。
反差声音用于喜剧。
低频压力用于怪兽、机械和权力压迫。
结尾回声用于余味和系列记忆。
```

### 7.6 广告证明味觉

可沉淀内容：

```text
广告先拍观众最不信的问题。
卖点必须变成产品动作。
结果变化必须让人看见。
人物反应只确认变化，不替产品吹嘘。
品牌记忆帧要能截图复用。
```

### 7.7 Seedance 防错味觉

可沉淀内容：

```text
一镜只保一个主动作。
复杂运镜和复杂动作不能同时要。
多人对白默认拆正反打或反应镜。
中文、Logo、品牌字、屏幕字后期添加。
打斗先空间和受力，再特效。
特摄先现实基准，再仪式，再爆发。
连续两轮失败就换首帧、拆镜或换机位。
```

## 8. 味觉冲突处理

当多个味觉同时出现，按这个顺序取舍：

```text
合规安全 > 生成稳定 > 主审美 > 观众理解 > 客户目标 > 视觉漂亮 > 个人偏好
```

典型冲突：

| 冲突 | 处理 |
| --- | --- |
| 想电影感但广告要转化 | 商业证明做主，电影感只服务证据和反应 |
| 想特摄很炸但动作看不清 | 热血清晰做主，先空间和受力，再加特效 |
| 想可爱又要爆款 | 温柔治愈做主，爆款只放在第一帧问题和结尾互动 |
| 想参考某作品又要原创 | 原创替换做主，参考只保留结构和情绪 |
| 想客户提案又想现场碎念 | 客户可读做主，导演口吻只保留判断和取舍 |

人物表演倾向：

## 10. 与现有资产的关系

## 11. 自检闸门

输出前检查：

1. 有没有区分核心语法、类型打法、临时灵感和禁用教训？
2. 有没有写清保留和舍掉？
3. 有没有把味觉落到第一帧、空间、表演、镜头身体和声音？
4. 有没有写 Seedance 降难规则？
5. 有没有写适用和不适用边界？
6. 有没有写边界反例、误用症状和不调用句？
7. 有没有留下回归测试题？
8. 有没有避免把风格标签当成导演味觉？
9. 有没有写触发契约、输出契约、禁用契约和验证契约？
10. 输出契约是否真的会改变下一次分镜、提示词、表演、声音、剪辑或防错字段？
11. 有没有做反例边界现场刹车，确认这次调用的味觉没有抢走主目标？
12. 有没有检查最近三次吸收来源，判断这次是在补短板还是继续偏食？
13. 新味觉是否明确落到第一帧、场面调度、人物动作、声音落点、剪辑点、Seedance 字段或第一刀之一？
14. 有没有写下次优先训练的相反能力，防止导演味觉越练越窄？

## 12. 最小合格线

一次味觉沉淀至少要输出：

1. 这次吸收的精华。
2. 不吸收的外壳。
3. 沉淀等级。
4. 味觉卡。
5. 写回位置。
6. 边界反例。
7. 回归测试题。
8. 调用契约四联。
9. 反套路营养均衡卡。

少一项，就只是灵感收藏，不是成长。
