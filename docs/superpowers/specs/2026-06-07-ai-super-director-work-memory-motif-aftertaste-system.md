# AI超级导演作品记忆点、视觉母题与余味系统

## 1. 定位

这份库负责让作品被记住，而不只是“拍得顺”。  
它把第一帧、视觉母题、声音钩子、道具回声、角色标志动作、品牌记忆帧、结尾余味和系列复用连接成一套作品记忆系统。

一句话原则：

```text
观众记住一部短片，往往不是因为它解释得完整，而是因为某个画面、声音或动作在脑子里回了一下。
```

默认开口：

```text
我会先给它找一个记忆钉子。
这条片子不能只顺着讲完，要有一个东西从第一帧埋进去，最后换一种方式回来。
```

## 3. 与其他资产的关系

默认调用顺序：

```text
创作人格与审美判断
-> 电影、特摄、短片与创意精华转译
-> 作品记忆点、视觉母题与余味系统
-> 风格参考、Moodboard与镜头风格圣经
-> 剪辑节奏与声音设计
-> 平台发布与爆款包装
-> 输出审片评分
```

分工：

| 资产 | 主要回答 |
| --- | --- |
| 电影/特摄/短片精华转译库 | 从参考中提取导演骨架和视觉母题 |
| 本库 | 把记忆点设计成全片可回收的系统 |
| 风格圣经系统 | 让视觉母题在多镜头里保持统一 |
| 声音设计库 | 把声音钩子变成可剪辑的听觉记忆 |
| 发布包装库 | 把记忆帧转成封面、标题和评论入口 |
| 输出审片评分 | 检查记忆点是否足够硬 |

## 4. 作品记忆总公式

```text
记忆钉子 + 首次出现 + 中段变形 + 结尾回收 + 声音回声 + 发布复用
```

拆解：

- 记忆钉子：一个画面、物件、声音、动作、颜色、姿势、台词短句或空间位置。
- 首次出现：第一帧或前三秒就让观众看见或听见。
- 中段变形：同一个元素在中段承担新的意义。
- 结尾回收：结尾让它回来，但状态不同。
- 声音回声：给它一个轻微声音、静音、呼吸、机械声、铃声或短句。
- 发布复用：把它变成封面帧、标题词、评论问题或系列固定收口。

导演判断：

```text
如果结尾和开头没有任何回声，观众看完就散了。
```

## 5. 六类记忆钉子

### 5.1 视觉母题

适合电影感、特摄、短片、情感、悬疑。

```text
母题类型：颜色、光、门、窗、桌面、楼梯、旧物、影子、圆形、裂痕、反光。
第一次出现：作为问题。
第二次出现：作为阻碍。
第三次出现：作为选择或释放。
```

示例：

```text
一盏坏掉的小夜灯。
第一次：它闪烁，暗示家里有事没说完。
中段：主角修它，实际是在修关系。
结尾：灯亮起来，但主角没有说话，只把它放回旧位置。
```

### 5.2 道具回声

适合怀旧、治愈、亲情、广告产品、短剧伏笔。

```text
道具：
谁拥有它：
第一次用途：
中段误用/失效：
结尾新用途：
声音：
```

规则：

1. 道具不是摆设，必须被手碰到。
2. 道具最好能产生声音。
3. 道具结尾回来时，意义要变了。
4. Seedance 里道具形状要简单稳定，复杂文字后期加。

### 5.3 角色标志动作

适合系列IP、可爱群像、短剧角色、品牌角色。

```text
角色：
标志动作：
这个动作暴露什么性格：
第一次出现：
反转时怎么变化：
系列里怎么复用：
```

示例：

```text
嘴硬角色每次心虚都会整理袖口。
第一集：整理袖口是装镇定。
反转：他第一次没有整理袖口，说明真慌了。
结尾：他整理到一半停住，观众知道他开始变了。
```

### 5.4 声音钩子

适合旧梦留声机、特摄仪式、广告品牌、悬疑、打斗。

```text
声音来源：
第一次听见：
第二次变化：
结尾回声：
是否可复述/可哼：
后期处理：
```

常用声音：

- 旧物启动声。
- 杯子落桌声。
- 门铃或手机震动。
- 变身前的短促静音。
- 产品启动声。
- 脚步、呼吸、衣料摩擦。
- 一句 3 到 8 个字的短句。

规则：

```text
声音记忆点不要太满。真正有记忆的声音，前后要留一小块安静。
```

### 5.5 品牌记忆帧

适合创意广告、产品证明、客户提案、商业发布。

```text
产品：
痛点画面：
产品动作：
结果变化：
人物反应：
品牌记忆帧：
后期文字安全区：
转化入口：
```

合格标准：

1. 产品、人物反应和结果同框，或者动作结果清楚连续。
2. 品牌字、Logo、价格、卖点字默认后期添加。
3. 记忆帧不是摆拍产品，而是产品完成动作后的结果。
4. 封面也能用这帧，不需要重新造图。

### 5.6 结尾余味

适合情感、治愈、短片、短剧、公益、电影感广告。

```text
事件已经结束：
角色最后一个动作：
声音是否留下：
画面是否多留半秒：
观众要补完什么：
```

余味不是慢，而是让观众参与补完。

```text
错误：角色说完“我终于释怀了”。
更好：角色把旧物放回原位，手离开前停半秒，远处声音又响了一次。
```

## 6. 类型记忆设计

### 6.1 可爱治愈

```text
记忆钉子：小主体的固定认真动作。
首次出现：它认真做一件太大的事。
中段变形：失败后还硬撑。
结尾回收：它用同一个动作接受帮助。
声音回声：小脚步、轻碰、软软的短句。
发布复用：封面抓“小主体 + 大任务”的同框。
```

### 6.2 短剧

```text
记忆钉子：证据、门口位置、手机震动、角色防御动作。
首次出现：作为视觉伏笔。
中段变形：观众开始意识到它有问题。
结尾回收：反转时它证明真相。
声音回声：手机震动、门响、脚步停住。
发布复用：标题围绕“那个东西为什么在那里”。
```

### 6.3 特摄/特效

```text
记忆钉子：仪式动作、道具声、光的颜色、必杀前停顿。
首次出现：日常基准里的小异常。
中段变形：能力规则被确认。
结尾回收：同一仪式动作变成真正选择。
声音回声：静音半秒 + 触发声。
发布复用：封面抓仪式动作，不抓最乱的爆炸。
```

### 6.4 动作打斗

```text
记忆钉子：受力结果、空间障碍、武器/道具动作。
首次出现：开打前交代它的位置。
中段变形：它成为阻碍。
结尾回收：它成为反击或逃生点。
声音回声：脚步、撞击、呼吸、金属轻响。
发布复用：封面抓接触点或受力结果。
```

### 6.5 创意广告

```text
记忆钉子：产品动作和结果同框。
首次出现：痛点里缺少这个动作。
中段变形：产品介入，动作变顺。
结尾回收：人物用同一个动作轻松完成。
声音回声：产品启动声、结果出现声、品牌短句。
发布复用：记忆帧就是封面帧。
```

### 6.6 怀旧情感

```text
记忆钉子：旧物、旧声音、没说出口的话。
首次出现：旧物被触碰。
中段变形：旧物不只是物件，而是关系入口。
结尾回收：旧物被放回或重新启动。
声音回声：旧声音、环境声、静音。
发布复用：标题围绕“有些声音/有些东西还记得”。
```

## 7. Seedance 2.0 记忆点写法

Seedance 提示词里不要只写“有记忆点”。要写成可生成字段：

```text
作品记忆钉子：[道具/动作/颜色/声音/构图]。
首次出现：[本镜如何出现]。
角色动作：[谁如何触碰/看见/避开/完成它]。
声音回声：[环境声/触碰声/静音/短句]。
结尾回收：[下一镜或结尾如何再出现]。
后期文字：[字幕/Logo/品牌字后期添加，画面留安全区]。
```

示例：

```text
作品记忆钉子：一只裂了一角的白瓷杯。
角色动作：老人把杯子推到桌边，手指在裂痕处停半秒。
声音回声：杯底轻轻碰桌的声音，环境声压低。
结尾回收：同一只杯子被放回左侧，位置和开头一致，但灯光变暖。
```

## 8. 封面停留点反推

记忆钉子不能只在成片里成立，还要能反推成封面停留点。发布前如果找不到可截图帧，先回到本库重选记忆钉子，不要先写更大的标题。

封面停留点必须从下面四类里选一个：

| 来源 | 适合情况 | 合格画面 | 不合格画面 |
| --- | --- | --- | --- |
| 主动作中点 | 广告、动作、可爱治愈、科普 | 主体正在完成一个动作，结果快要出现 | 只有摆拍姿势或空镜 |
| 反应停顿 | 情感、短剧、群像、喜剧 | 人物刚收到信息或看见结果，身体停半秒 | 只有夸张表情，没有触发原因 |
| 结果变化 | 产品、空间、教育、汽车 | 变化前后或结果证据能一眼看见 | 只放产品或场景，不知道改变了什么 |
| 母题回收 | 短片、悬疑、系列、国风 | 开头出现过的物件或动作以新状态回来 | 只有漂亮意象，和故事动作无关 |

封面停留点句式：

```text
封面停留点来自【主动作中点/反应停顿/结果变化/母题回收】：
观众第一眼看见【主体】正在/刚刚【动作或结果】，
会问【一个具体问题】；
标题安全区在【位置】，不挡【脸/手/产品/接触点/结果证据】；
缩小到手机封面后仍能看见【轮廓/动作方向/结果变化】。
```

硬规则：

1. 封面帧不能只靠字幕成立；字幕只负责放大问题，不负责解释画面。
2. 品牌记忆帧必须让产品动作、结果变化或人物确认至少出现两个。
3. 情感片封面不要选“大哭”，优先选收回动作、手停住、旧物回声或没说出口的半秒。
4. 动作和特效不要选最乱的爆炸，优先选接触点、受力结果或角色反应确认。
5. 如果封面停留点和全片记忆钉子不是同一条线，先改记忆钉子，不先改标题。

### 8.1 冻结后记忆回填

Seedance 执行版为了稳定做过“生成前冻结”后，如果删掉了口型、文字、复杂群像、强运镜、复杂特效或多卖点，不要再为了记忆点把这些高风险变量塞回最终提示词。先保住冻结主任务和主变量，再用低风险记忆方式补回可复述性。

低风险记忆方式只从下面选一类：

| 回填方式 | 适合情况 | 写法 | 禁止 |
| --- | --- | --- | --- |
| 反应停顿 | 情感、短剧、群像、喜剧 | 角色看见结果后停半秒，手或眼神先泄露 | 加长台词或多人同时说话 |
| 声音钩子 | 悬疑、广告、短片、结尾余味 | 一个可后期添加的短促声源或声音回声 | 要求 Seedance 生成可读歌词、品牌口播或复杂声画同步 |
| 道具状态 | 产品、旧物、系列、悬疑 | 同一物件从旧状态变成新状态 | 新增多个道具或让道具承担解释文字 |
| 构图轮廓 | 封面、动作、特摄、可爱治愈 | 主体、手、产品或接触点形成清楚轮廓 | 加强运镜、爆炸和背景细节 |
| 后期入口 | 发布包装、标题封面、评论区 | 标题、置顶评论或字幕只放大已有画面问题 | 用文字替代画面记忆钉子 |

冻结后记忆回填句式：

```text
冻结后记忆回填：
主变量仍保【主任务/主动作】，
记忆点改用【反应停顿/声音钩子/道具状态/构图轮廓/后期入口】；
不把【被删高风险变量】塞回 Seedance，
封面停留点来自【主动作中点/反应停顿/结果变化/母题回收】。
```

第一刀：

如果冻结后看完记不住，先补一个反应镜、声音尾巴、道具状态、构图轮廓或后期评论入口，不先加字幕金句、强运镜、多人台词或复杂特效。

## 10. 自检

输出前问自己：

1. 这条片子的记忆钉子是什么？
2. 它是否在第一帧或前三秒出现？
3. 它是否在中段变形，而不是只出现一次？
4. 它结尾回来时，意义有没有变化？
5. 它有没有声音回声？
6. 它能不能变成封面帧、标题词或评论问题？
7. 如果是广告，它是不是产品动作后的结果，而不是摆拍产品？
8. 如果是系列，它能不能下一条继续复用？
9. Seedance 提示词有没有把记忆点写成具体动作、道具、构图或声音？
10. 文字、Logo 和品牌字是否默认后期添加？
11. 封面停留点是否来自主动作中点、反应停顿、结果变化或母题回收，而不是另造一张漂亮图？
12. 手机缩略图里是否还能看见主体、动作方向或结果变化？
13. 如果执行版删掉记忆点，是否用低风险记忆方式回填，而不是把被删变量塞回 Seedance？

## 11. 回归测试

输入：

```text
这条片看完记不住，帮我补一个记忆点和封面记忆帧。
```

合格输出必须包含：

1. 一个记忆钉子。
2. 首次出现、中段变形、结尾回收和声音回声。
3. 封面停留点来源：主动作中点、反应停顿、结果变化或母题回收。
4. 手机缩略图判断：主体、问题和标题安全区。
5. Seedance 写法：记忆点变成道具、动作、构图或声音，不直接生成可读文字。
6. 第一刀升级：如果封面不成立，先改记忆钉子或主动作，不先改标题。
7. 冻结后记忆回填：如果执行版删掉记忆点，必须写清低风险回填方式和不塞回 Seedance 的被删变量。

失败信号：

1. 只给标题金句，没有画面记忆钉子。
2. 封面帧和全片记忆钉子无关。
3. 封面靠大段文字解释，画面本身不能复述。
4. 执行版已经删掉高风险变量，记忆回填时又把它塞回 Seedance。
