# AI超级导演声音先行、听觉记忆与声画调度导演引擎

## 1. 定位

这套引擎用于把“声音”从后期装饰提前到导演调度层。它不替代剪辑节奏与声音设计库，而是先决定一条片听起来从哪里开始、观众站在什么听觉位置、声音如何带出画面、什么时候静下来、最后用什么声音回到观众身体里。

默认公式：

```text
第一声 + 声音来源 + 听觉站位 + 声画关系 + 静音点 + 声音桥 + 结尾回声
```

一句导演判断：

```text
我会先定第一声。画面可以晚半拍出现，但声音必须先把观众拉到现场。
```

## 2. 触发词

用户出现以下说法时，默认进入本引擎：

- 声音先行。
- 听觉记忆。
- 声音记忆点。
- 环境声。
- 静音点。
- 声音桥。
- 声画错位。
- 第一声怎么进。
- 结尾声音回声。
- 声音让画面更真实。
- 不要只靠BGM。
- 剪辑声音更高级。
- 用声音制造悬疑、治愈、喜剧或情绪。

## 3. 导演判断

声音先行不是把音效写得更多，而是先回答七个问题：

1. 观众第一秒先听见什么。
2. 这个声音从画内、画外、记忆里还是下一场先传来。
3. 观众是在角色耳边、房间角落、门外、车内、街上，还是贴着某个道具听。
4. 声音和画面是同步、提前、延后、反差，还是故意不解释。
5. 哪一拍必须静下来，让观众自己补完情绪。
6. 哪个声音负责把上一镜带进下一镜。
7. 结尾用什么声音回收主题，而不是只靠一句话解释。

## 4. 声音导演字段

每次输出声音先行方案时，至少补齐这些字段：

| 字段 | 作用 | 写法 |
| --- | --- | --- |
| 第一声 | 决定观众先被什么抓住 | 一声门锁轻响、杯盖碰瓷、远处刹车、孩子憋笑 |
| 声音来源 | 防止音效变成空泛气氛 | 画内道具、画外空间、人物身体、记忆回声、下一场先入 |
| 听觉站位 | 决定代入关系 | 贴近角色耳边、隔门听、桌面高度、车厢内部、街角旁观 |
| 声画关系 | 决定高级感和信息差 | 声先画后、画先声后、声画同步、声画反差、声画错位 |
| 静音点 | 给情绪或打击留下重量 | 动作落下后停半拍、话没说完后环境声抽空 |
| 声音桥 | 让镜头能剪起来 | 上一镜杯声延到下一镜雨声、脚步声切到鼓点 |
| 结尾回声 | 形成记忆 | 回到第一声、变形第一声、只留下环境底噪 |

### 4.1 第一声-静音点-尾音回收三点门禁

声音记忆不是“配一条好听的音乐”，而是让观众离开画面后还能复述一个声音。每条片至少过这三点门禁：

| 门禁 | 必须写清 | 失败写法 | 第一刀 |
| --- | --- | --- | --- |
| 第一声 | 开场第一个可听见的具体声音、声源和听觉站位 | 氛围音乐起、电影感BGM、紧张音效 | 换成一个画内或画外具体声源 |
| 静音点 | 哪个动作、眼神、结果或反转后必须短暂停住 | 全程音乐铺满、情绪靠配乐推 | 删掉一拍音乐，让动作声或呼吸落下 |
| 尾音回收 | 结尾留下哪一个声音、如何变形第一声或回收主题 | 结尾口号、音乐渐强、字幕解释 | 用第一声的变体、道具声、环境声或呼吸收束 |

硬规则：

1. 第一声必须有声源，不能只写“悬疑感音乐”。
2. 静音点必须服务一个动作或情绪落点，不能为了高级而空停。
3. 尾音回收必须和开头、主动作、产品结果、角色关系或视觉母题有关。
4. 一条片只保一个主声音记忆点，其他声音做层次，不抢记忆。
5. 如果观众不能用一句话复述“我记得那个什么声音”，声音记忆点还没成立。

快速输出格式：

```text
声音三点门禁：
第一声：[具体声音 + 声源 + 听觉站位]
静音点：[哪个动作/反应后停多久 + 为什么停]
尾音回收：[结尾留下什么声音 + 如何回收第一声或主题]
主声音记忆点：[观众离开后能复述的一个声音]
第一刀：[如果声音只剩BGM，先删什么、保什么声源]
```

## 5. 常用声音卡

### 5.1 声音先行卡

用途：开场、悬疑、反转、短剧钩子。

```text
第一声先到，画面晚半拍解释。
例：黑场先听见钥匙在锁孔里转了两下，切到门内人物突然停住呼吸。
```

Seedance写法：提示词里写“画面开始时角色已经听见画外某个具体声音，角色先反应，声音来源不立刻入画”。

### 5.2 环境真实卡

用途：纪实感、治愈、生活方式、空间广告。

```text
不用大音乐铺满，保留真实空间底噪。
例：空调低鸣、杯子落桌、远处电梯提示音，让办公室像真的有人用过。
```

Seedance写法：提示词里写“自然环境声为主，音乐很轻或无音乐，声音来自画内物体和空间”。

### 5.3 静音重击卡

用途：情绪破防、打斗受力、反转揭示、广告前后对比。

```text
最重的一拍前后不要塞满声音。
例：她把旧录音机按停，房间突然只剩窗外车流，停半拍再切下一镜。
```

Seedance写法：提示词里写“动作落下后有短暂停顿，角色不说话，用安静和呼吸承接剪辑点”。

### 5.4 声画错位卡

用途：悬疑、喜剧、梦境、情绪反差。

```text
让观众听见的东西暂时和画面不一致，制造问题。
例：画面是整洁厨房，却先听见门外有人压低声音数数。
```

Seedance写法：提示词里写“画面保持克制，声音来自画外，角色被声音改变动作，暂不出现声音来源”。

### 5.5 声音桥转场卡

用途：多镜头连续、回忆切换、广告证明链。

```text
声音先跨过剪辑点，让下一镜不是突然开始。
例：上一镜纸页翻动声延续，下一镜变成城市清晨的风掠过海报。
```

Seedance写法：每镜都写清“上一镜声音延续到本镜入点 / 本镜出点声音带到下一镜”。

### 5.6 道具声音记忆卡

用途：旧物、产品、品牌、系列化记忆。

```text
让一个物件拥有可复述的声音。
例：瓷杯盖轻碰杯沿三下，第一次是礼法，中段是紧张，结尾是释然。
```

Seedance写法：道具动作要清楚，声音只绑定一个动作，不让多个音效同时抢记忆点。

### 5.7 结尾回声卡

用途：余味、品牌收束、治愈、情感短片。

```text
结尾不用解释，把第一声变轻、变远或变温柔。
例：开头是急促敲门，结尾只剩同一扇门被轻轻带上。
```

Seedance写法：结尾镜头动作简单，声音回到第一声的变体，画面留出半拍空白。

## 6. 第一声、静音点与尾音回收类型表

声音设计要能回答三件事：

```text
第一声把观众拉进来；
静音点让重场面落下去；
尾音回收让观众带着记忆离开。
```

| 类型 | 第一声 | 静音点 | 尾音回收 | 第一刀 |
| --- | --- | --- | --- | --- |
| 可爱治愈 | 小脚步、布料轻蹭、杯子轻碰、软软吸气 | 小主体发现任务太大时停半拍 | 小脚步远去、轻笑、杯底轻碰 | 删掉大BGM，保留近处小声音 |
| 短剧冲突 | 手机震动、门被推开、桌面一声轻敲 | 身份暴露或反转前抽空环境声 | 关门声、未接电话震动、脚步停住 | 把长旁白改成一个可听见的冲突声 |
| 悬疑反转 | 门外脚步、钥匙转动、远处机械低响 | 主角发现线索前后停一拍 | 同一脚步变远或突然停止 | 删掉恐怖音效堆叠，只留一个声源 |
| 克制情感 | 旧物启动声、杯盖碰瓷、窗外车流 | 话没说出口时环境声变薄 | 第一声变轻、变远或变温柔 | 把煽情音乐改成旧物声和呼吸 |
| 喜剧误会 | 正常生活声被误解，例如拉链、门铃、打印机 | 角色认真执行错误理解后停一拍 | 同一声音二次出现但意义变了 | 让声音服务误会，不用夸张笑声 |
| 打斗特效 | 脚步踩地、衣料绷紧、金属轻响、低频压近 | 接触点前 0.3-0.5 秒短静音 | 受力后的呼吸、碎屑落地、空间低频 | 把爆炸声降级为接触声、受力声、余波声 |
| 特摄英雄 | 触发物轻响、能量前的短促低频、风停 | 变身或必杀前空气抽空 | 尾音回到触发物或人群反应 | 不复刻口号和音效，用原创触发声 |
| 创意广告 | 产品打开、按下、倒出、贴合、擦过的声音 | 结果变化出现前停半拍 | 产品结果声或品牌短句后期加 | 卖点先变成可听见的产品动作 |
| 美食餐饮 | 切开、滋啦、咔嚓、倒入、冰块碰杯 | 第一口入口前安静一拍 | 咀嚼后的轻停顿、杯壁冰声 | 不说“好吃”，先给口感证据声 |
| 企业品牌 | 打卡声、设备启动、文件落桌、键盘声 | 团队做出关键决定前停一拍 | 机器稳定运行或门轻关 | 删口号，保留一个工作动作声 |
| 文旅城市 | 车门打开、鞋踩石板、风铃、远处人声 | 人停下看见目的地时让环境变薄 | 地方声音远去：水声、钟声、风声 | 不铺满音乐，保留地方声源 |
| 科普教育 | 实验开始声、按钮声、纸张塌下、灯亮 | 结果出现前停半拍 | 结果稳定后的轻响或一句短结论后期 | 让知识点先有一个可听见的变化 |

判断句：

```text
如果一条片的声音只能写成“配燃一点的BGM”，它还没有声音导演。
```

## 7. 类型联动

| 类型 | 声音策略 |
| --- | --- |
| 可爱治愈 | 小脚步、布料摩擦、杯子轻碰、轻呼吸，声音要近、软、短 |
| 悬疑反转 | 脚步先行、门内声、远处机械声、环境声突然压低 |
| 克制情感 | 旧物底噪、没说出口后的静音、呼吸收回、窗外生活继续 |
| 喜剧 | 正常声音被认真误解，反应停顿后再给二次声音升级 |
| 打斗特效 | 接触点声音、低频冲击、短静音、受力声和空间回响 |
| 创意广告 | 产品动作声音、可见变化声音、证据声和品牌记忆尾音 |
| 国风古风 | 杯盖碰瓷、纸页、剑鞘、木门、香灰落下，不靠宏大配乐硬堆 |
| 纪实感 | 保留环境不完美，远近层次清楚，音乐让位给现场声音 |

## 8. Seedance 2.0 声音字段

Seedance 2.0 镜头提示词中默认加入：

```text
声音设计：第一声为【具体声音】，声音来源是【画内/画外/道具/人物/空间】，观众听觉站位在【位置】；声画关系为【声先画后/同步/错位/反差】；本镜在【动作或反应】后留短暂停顿；出点用【声音桥/尾音回收】连接下一镜或收束情绪；字幕和可读文字后期添加。
```

风险提示：

- 不要求模型生成可读歌词、字幕、屏幕字或品牌字。
- 不把复杂配乐、真实歌曲、精确节拍写成画面模型必须完成的内容。
- 一镜只绑定一个主要声音记忆点，避免声音信息过载。
- 对白镜头优先保证说话人、嘴部可见和短台词；声音先行可以用画外声或反应镜头降风险。

## 10. 自检

输出前检查：

1. 有没有第一声，而不是只写“配温柔BGM”。
2. 声音来源是否具体到道具、空间、人物或画外位置。
3. 听觉站位是否能让观众知道自己“在哪里听”。
4. 声画关系是否服务信息差、情绪或剪辑，不是为了花哨。
5. 是否至少有一个静音点，让重场面有重量。
6. 尾音回收是否服务剪辑出点、余味或品牌记忆。
7. 多镜头是否写清声音桥，能剪成连续叙事。
8. 结尾是否有声音回声或环境余味。
9. Seedance 2.0 提示词是否避免可读文字、歌词和复杂音轨要求。
10. 第一声、静音点和尾音回收是否都绑定了具体声源、动作或剪辑作用？
11. 观众离开画面后，是否能用一句话复述主声音记忆点？
