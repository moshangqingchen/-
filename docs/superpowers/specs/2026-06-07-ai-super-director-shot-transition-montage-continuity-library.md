# AI超级导演镜头衔接、转场与蒙太奇语法库

## 1. 定位

这份库专门解决一个问题：镜头不是一条条孤立提示词。前一镜的动作、声音、视线、构图和情绪落点，必须把下一镜带出来。

AI超级导演做 Seedance 2.0 多镜头视频时，默认要把每个镜头写成“能生成，也能剪起来”的片段：

1. 每镜有入点。
2. 每镜有出点。
3. 每镜有衔接方式。
4. 重要镜头有声音桥、动作匹配、视线匹配或构图匹配。
5. 转场服务情绪、信息、笑点、卖点、动作因果或时空变化，不为了炫而转。

一句话原则：

```text
镜头怎么切，不是剪辑软件的问题，是导演在分镜阶段就要设计好的问题。
```

## 2. 触发词

用户出现以下说法时，优先调用本库：

- 转场。

- 镜头怎么接。
- 蒙太奇。
- 动作匹配。
- 视线匹配。
- 声音桥。
- 入点。
- 出点。
- 剪辑点。
- 过渡镜头。
- 上一镜怎么接下一镜。

- 镜头不连贯。
- 一镜一镜生成出来很散。
- 时间跳跃。
- 回忆怎么转。
- 广告前后对比怎么切。

## 3. 与其他资产的关系

本库不是替代剪辑节奏与声音设计库，而是补上“镜头与镜头之间”的语法。

默认调用顺序：

```text
场面调度、空间轴线与人物走位
-> 微动作、表情反应与动作节拍
-> 镜头衔接、转场与蒙太奇
-> Seedance 2.0人称运镜
-> 剪辑节奏与声音设计
-> 提示词与镜头生成
```

用途分工：

| 资产 | 主要回答 |
| --- | --- |
| 场面调度库 | 人在哪里，往哪走，机位站哪边 |
| 微动作库 | 人物在镜头内怎么活起来 |
| 本库 | 上一镜怎么把下一镜带出来 |
| Seedance 2.0手册 | 每条视频提示词怎么写得稳 |
| 剪辑声音库 | 整体节奏、音乐、音效和静音怎么安排 |
| 提示词库 | 怎么把镜头变成可生成文本 |

## 4. 核心原则

### 4.1 每次切镜都要有理由

切镜理由只有几类：

1. 信息变化：观众需要看见新信息。
2. 情绪变化：角色的内心或关系发生变化。
3. 动作变化：动作进入下一阶段。
4. 视线变化：角色看见了什么。
5. 声音变化：声音先一步把观众带过去。
6. 时间变化：压缩时间或进入回忆。
7. 空间变化：从局部跳到全局，或从全局进入局部。
8. 笑点变化：铺垫结束，反应或反转要落地。

如果说不出为什么现在切，就先不要切。

### 4.2 AI视频优先用朴素转场

Seedance 2.0 多镜头项目里，最稳的转场通常是：

- 硬切。
- 动作匹配。
- 视线匹配。
- 声音桥。
- 反应剪辑。
- 构图匹配。
- 道具特写接下一镜。
- 克制叠化。

少用复杂花哨转场。过度旋转、闪白、液体变形、无理由穿越，容易让画面像模板，不像导演。

### 4.3 先有出点，再写入点

多镜头分镜默认按这个顺序设计：

```text
上一镜出点 -> 衔接钩子 -> 下一镜入点 -> 本镜动作 -> 本镜出点 -> 下一镜钩子
```

例子：

```text
上一镜出点：小女孩手指碰到旧录音机按钮。
衔接钩子：按钮咔哒声先响。
下一镜入点：声音不断，画面切到年轻父亲当年按下同一枚按钮。
情绪变化：从当下寻找，进入回忆回应。
```

## 5. 衔接语法总公式

任何镜头衔接都可以写成这四项：

```text
出点：[上一镜最后被观众记住的动作/声音/视线/构图]
衔接方式：[硬切/动作匹配/视线匹配/声音桥/构图匹配/叠化/跳切/道具转场/反应切]
入点：[下一镜第一秒观众看见或听见什么]
变化：[信息、情绪、时间、空间、关系或卖点发生了什么变化]
```

导演写法：

```text
我会在 [动作/声音/眼神/构图] 落下去的一瞬间切，不让镜头自己停死。
下一镜一进来就接住这个钩子，观众会觉得不是换了一条提示词，而是同一场戏往前走。
```

## 6. 转场工具箱

### 6.1 硬切

用途：直接、利落、有冲击。

适合：

- 搞笑包袱。
- 打斗打击点。
- 短剧反转。
- 广告痛点到解决。
- 视觉奇观出现。

写法：

```text
上一镜出点：[角色/道具/动作] 落在最清楚的一瞬间。
转场：硬切。
下一镜入点：[反应/结果/新信息] 直接出现。
```

常见失误：每个镜头都硬切，但没有动作或声音钩子，会显得碎。

### 6.2 动作匹配

用途：让两个时间、空间或状态看起来自然相连。

适合：

- 人物长大。
- 产品前后对比。
- 回忆和现实互切。
- 动作连续。
- 训练蒙太奇。

写法：

```text
上一镜出点：角色做 [动作A] 的中段。
转场：动作匹配。
下一镜入点：另一个时间/空间里的角色继续同方向做 [动作A的结果]。
```

例子：

- 小孩把书包甩上肩，切到多年后成年人把公文包甩上肩。
- 手推开旧木门，切到同一方向推开现代玻璃门。
- 产品未使用前皱眉擦拭，切到使用后同一动作变轻松。

### 6.3 视线匹配

用途：用角色的注意力带观众转场。

适合：

- 短剧秘密揭示。
- 情感旧物。
- 群像反应。
- 主观镜头。
- 悬疑和反转。

写法：

```text
上一镜出点：角色看向画外 [左/右/下/上]。
转场：视线匹配。
下一镜入点：观众看见角色正在看的 [人/物/结果/危险]。
```

常见失误：角色看向右边，下一镜信息却从左边来，空间会乱。

### 6.4 声音桥

用途：声音比画面早到，让时空切换更顺。

适合：

- 怀旧情感。
- 旧梦留声机类回忆。
- 广告产品动作。
- 打斗冲击。
- 可爱搞笑反应。
- 短剧门外声音和电话声音。

写法：

```text
上一镜画面还没切，下一镜的声音先进入。
声音桥：[具体声音]。
下一镜入点：画面切到声音来源或声音代表的记忆。
```

例子：

- 旧录音机底噪先响，画面才切进回忆。
- 门铃声先响，下一镜切到门外尴尬的人。
- 产品清脆一声先出现，下一镜展示动作结果。

### 6.5 构图匹配

用途：用相似形状、颜色、位置或运动方向连接两个镜头。

适合：

- 创意广告。
- 视觉诗意转场。
- 怀旧时空跳跃。
- 特效奇观。
- 产品记忆帧。

写法：

```text
上一镜出点：[形状/构图/颜色] 占画面中心。
转场：构图匹配。
下一镜入点：相似 [形状/构图/颜色] 在另一个场景中出现。
```

例子：

- 圆形旧唱片转动，切到孩子圆圆的眼睛。
- 咖啡杯旋涡，切到城市清晨的环形车流。
- 产品按钮特写，切到同位置的笑脸反应。

### 6.6 反应切

用途：让事件有后果，让笑点、震惊或情感真正落地。

适合：

- 搞笑。
- 特效。
- 打斗。
- 短剧冲突。
- 广告证明。

写法：

```text
上一镜事件发生。
出点：事件落地后停半秒。
转场：反应切。
下一镜入点：人物眼神、手部、身体重心或群体表情变化。
```

常见失误：事件发生后马上切走，不给观众看见“这件事造成了什么”。

### 6.7 叠化

用途：柔和地表示时间流逝、回忆进入或情绪过渡。

适合：

- 治愈。
- 怀旧。
- 梦境。
- 轻微时间跳跃。

写法：

```text
上一镜出点：角色动作结束后留白。
转场：短叠化。
下一镜入点：同一情绪下的新时间或新空间。
```

限制：叠化要少用。情绪不够强时，叠化会显得廉价。

### 6.8 跳切

用途：压缩过程、制造轻快节奏或喜剧感。

适合：

- 准备过程。
- 训练过程。
- 试错过程。
- 种草步骤。
- 可爱角色认真忙乱。

写法：

```text
连续3到5个短镜头，每个镜头只保留动作最有信息量的一瞬间。
每个跳切保持同一空间方向或同一构图节奏。
```

例子：

- 戴帽子，拿书包，冲到门口，发现忘带鞋。
- 产品使用三步，每步一个动作落点。
- 训练失败三次，每次反应越来越离谱。

### 6.9 道具转场

用途：用一个物品做镜头桥梁。

适合：

- 旧物情感。
- 创意广告。
- 可爱搞笑道具梗。
- 短剧秘密。
- 视觉特效触发。

写法：

```text
上一镜出点：道具占据画面中心或遮住镜头。
转场：道具转场。
下一镜入点：同一个道具在新场景中出现，或道具动作带出结果。
```

例子：

- 录音机磁带转动，切进过去的房间。
- 产品盒盖合上，下一镜打开后场景已改变。
- 小玩具贴近镜头遮满画面，硬切到玩具视角。

### 6.10 人称视角转场

用途：让观众的位置变化有理由。

适合：

- Seedance 2.0 人称运镜。
- 第一人称代入。
- 第二人称种草。
- 过肩对话。
- 道具视角创意。

写法：

```text
第三人称建立空间 -> 视线或动作钩子 -> 第一人称/过肩/道具视角进入 -> 反应镜头回到第三人称。
```

例子：

- 先用第三人称看见孩子走向旧柜子。
- 孩子伸手，切第一人称看手拉开柜门。
- 柜门声音桥进入回忆。
- 回到第三人称，看见孩子停住。

## 7. 蒙太奇语法

蒙太奇不是把很多镜头堆在一起，而是用短镜头压缩时间、强化情绪或证明变化。

### 7.1 过程蒙太奇

用途：展示一个过程被完成。

结构：

```text
起点状态 -> 三个关键动作 -> 结果状态
```

适合：

- 产品使用。
- 准备上学。
- 房间整理。
- 训练。
- 做饭。
- 修复旧物。

### 7.2 失败蒙太奇

用途：喜剧或成长。

结构：

```text
第一次失败，动作小。
第二次失败，反应变大。
第三次失败，失败方式反常。
第四次出现意外成功或彻底翻车。
```

要点：每次失败保留同一动作入口，让观众看懂升级。

### 7.3 回忆蒙太奇

用途：怀旧、亲情、旧物、遗憾。

结构：

```text
旧物特写 -> 声音桥 -> 三个生活细节 -> 当下反应 -> 留白
```

要点：不要解释回忆。让手部、门槛、饭盒、照片边角、旧声音自己说话。

### 7.4 广告证明蒙太奇

用途：让卖点变成可见证据。

结构：

```text
痛点动作 -> 产品动作 -> 第一次结果 -> 第二次结果 -> 品牌记忆帧
```

要点：产品不是摆拍，它要在动作里解决问题。

### 7.5 打斗压迫蒙太奇

用途：压缩一段攻防，但不牺牲空间清楚。

结构：

```text
空间交代 -> 攻击起手 -> 防守反应 -> 关键打击 -> 反应切 -> 重新交代空间
```

要点：快剪之间必须保留方向、接触和身体结果。

## 8. 类型专用衔接公式

### 8.1 可爱搞笑

```text
铺垫动作 -> 停半秒 -> 硬切反应 -> 群像沉默 -> 表情包收尾
```

常用转场：

- 反应切。
- 跳切。
- 硬切。
- 道具转场。
- 声音桥。

导演判断：笑点不是把动作做大，而是把认真和荒诞接得刚好。

### 8.2 治愈

```text
微动作结束 -> 环境声留住 -> 轻叠化或声音桥 -> 新动作慢慢进入
```

常用转场：

- 声音桥。
- 留白后硬切。
- 短叠化。
- 视线匹配。

导演判断：治愈片不要急着切，要让动作有呼吸。

### 8.3 怀旧情感

```text
旧物特写 -> 旧声音先来 -> 构图匹配/短叠化 -> 回忆生活细节 -> 当下反应
```

常用转场：

- 声音桥。
- 道具转场。
- 构图匹配。
- 叠化。
- 动作匹配。

导演判断：怀旧不是滤镜，是当下和过去被一个动作或声音接住。

### 8.4 创意广告

```text
痛点动作 -> 动作匹配到产品动作 -> 结果反应 -> 构图匹配到品牌记忆帧
```

常用转场：

- 动作匹配。
- 构图匹配。
- 硬切。
- 产品声音桥。
- 前后对比跳切。

导演判断：卖点要剪成“观众一眼懂的变化”，不是文案解释。

### 8.5 特效奇观

```text
现实基准 -> 小异常 -> 反应切 -> 异常升级 -> 声音/光线桥 -> 奇观爆发
```

常用转场：

- 反应切。
- 声音桥。
- 光线匹配。
- 硬切。
- 构图匹配。

导演判断：特效先让观众相信空间是真的，再让奇观进来。

### 8.6 打斗

```text
空间交代 -> 攻击起手 -> 动作匹配接触 -> 反应切 -> 重新交代空间
```

常用转场：

- 动作匹配。
- 硬切。
- 反应切。
- 声音打击点。
- 短跳切。

导演判断：快不是乱。每次切镜都要接住攻击方向和身体结果。

### 8.7 短剧冲突

```text
台词钩子 -> 视线匹配 -> 秘密或对手入画 -> 反应切 -> 关系升级
```

常用转场：

- 视线匹配。
- 过肩切。
- 电话/门铃声音桥。
- 硬切。
- 反应切。

导演判断：短剧的切点跟着关系变化走，谁掌握信息，镜头就转向谁。

## 9. Seedance 2.0 衔接字段

多镜头 Seedance 2.0 输出时，每条提示词默认加入“剪辑衔接”字段。

标准字段：

```text
上一镜衔接：[上一镜出点是什么，没有上一镜则写开场入点]。
本镜入点：[本镜第一秒看到或听到什么]。
本镜出点：[本镜最后落在哪个动作、声音、眼神或构图]。
下一镜钩子：[下一镜要接住的动作、声音、视线或道具]。
剪辑方式：[硬切/动作匹配/视线匹配/声音桥/构图匹配/叠化/跳切/反应切/道具转场]。
```

Seedance 2.0 提示词嵌入模板：

```text
[时长]秒[竖屏/横屏]视频镜头。
风格锁定：本镜头延续项目视觉圣经，[风格锁定句]保持不变。
空间锁定：[空间布局、门窗、桌椅、入口、出口、关键道具和角色位置]保持不变。
镜头身份：[第一人称/第二人称/第三人称/过肩/道具视角/回忆视角/群像视角]。
上一镜衔接：[上一镜出点或开场入点]。
本镜入点：[第一秒画面/声音]。
主体：[谁]。
动作链：[起始动作] -> [中间变化] -> [结束状态]。
人物走位：[角色从哪里到哪里，关系如何变化]。
摄影：[景别]，[机位高度]，[一个主要镜头运动]，[运动理由]。
表演/微动作：[眼神、停顿、手部、身体重心、反应镜头]。
声音：[环境声、音效、对白或旁白]。
本镜出点：[动作落点/反应落点/声音落点/反转落点]。
下一镜钩子：[动作/声音/视线/道具/构图]。
剪辑方式：[具体衔接方法]。
一致性：[角色、服装、道具、场景必须保持]。
避免：[动作跳变、脸部漂移、肢体变形、道具消失、左右方向跳变、无意义乱动、背景文字乱码]。
```

## 10. 分镜衔接表模板

多镜头项目默认增加这张表：

```text
镜头号 | 时长 | 上一镜出点 | 本镜入点 | 本镜出点 | 衔接方式 | 声音桥 | 情绪/信息变化 | 风险
```

示例：

| 镜头号 | 上一镜出点 | 本镜入点 | 本镜出点 | 衔接方式 | 声音桥 | 情绪/信息变化 | 风险 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 开场，旧录音机静止 | 手靠近按钮 | 按钮咔哒 | 开场硬切 | 录音底噪渐入 | 从现实进入旧物 | 道具形状漂移 |
| 2 | 按钮咔哒 | 年轻父亲按同款按钮 | 父亲抬眼笑 | 动作匹配 + 声音桥 | 咔哒声延续 | 当下进入回忆 | 年代风格不稳 |
| 3 | 父亲抬眼笑 | 当下女儿愣住 | 手指停在按钮上 | 视线匹配 | 底噪变弱 | 回忆回到当下 | 情绪过猛 |

## 11. 断裂修复指南

### 11.1 镜头看起来像随机拼接

原因：

- 没有上一镜出点。
- 下一镜入点没有接住任何动作或声音。
- 每条提示词都只写画面，不写剪辑关系。

修复：

```text
为每个镜头补：上一镜出点、本镜入点、本镜出点、下一镜钩子。
优先用动作匹配、声音桥或视线匹配。
```

### 11.2 转场太花，像模板

原因：

- 转场形式比叙事动机更强。
- 为了炫而闪白、旋转、变形。

修复：

```text
改成硬切、反应切、声音桥或构图匹配。
只有梦境、回忆、时间流逝才保留叠化。
```

### 11.3 时空跳跃看不懂

原因：

- 没有时间锚点。
- 过去和现在的道具、声音或动作没有对应。

修复：

```text
加入一个共同物：旧物、同一句话、同一个动作、同一种声音或相似构图。
```

### 11.4 打斗剪乱

原因：

- 方向和轴线没锁。
- 攻击、接触、反应被切散。

修复：

```text
先交代空间，再用动作匹配接触点，打击后切反应，再回到中景重建方向。
```

### 11.5 情感片不动人

原因：

- 镜头之间只有空镜和滤镜。
- 没有让旧物、声音和人物微动作互相接住。

修复：

```text
用旧物特写做出点，用声音桥进回忆，用手部停顿回到当下。
```

### 11.6 广告卖点没记忆

原因：

- 产品镜头和结果镜头没有剪辑因果。
- 卖点靠口播解释。

修复：

```text
用痛点动作匹配到产品动作，再用结果反应或构图匹配到品牌记忆帧。
```

## 12. 生成前剪辑胶水终检

多镜头 Seedance 2.0 项目在逐镜生成前，必须先做一次剪辑胶水终检。不是检查每条提示词漂不漂亮，而是检查每两镜之间有没有一个可剪的钩子。

终检原则：

```text
每两镜之间至少有一个胶水钩子：
动作接动作，声音接画面，视线接信息，道具接结果，反应接情绪。
如果没有钩子，就补桥镜、改出点、改入点或删掉其中一镜。
```

五类胶水钩子：

| 胶水钩子 | 适合场景 | 通过标准 |
| --- | --- | --- |
| 动作钩子 | 打斗、产品、日常任务、训练蒙太奇 | 上一镜动作中点能自然进入下一镜动作 |
| 声音钩子 | 情感、悬疑、广告、特效、转场 | 声音能提前或延续到下一镜 |
| 视线钩子 | 短剧、悬疑、情感、群像 | 上一镜看向的对象在下一镜被看见 |
| 道具钩子 | 旧物、产品、证据、可爱道具 | 同一物件或同类形状带出信息变化 |
| 反应钩子 | 喜剧、打斗、广告证明、情绪落点 | 事件后有人或环境确认结果 |

剪辑胶水终检表：

```text
镜头关系：
【第N镜 -> 第N+1镜】

上一镜出点：
【动作 / 声音 / 视线 / 道具 / 构图 / 情绪】

下一镜入点：
【第一秒接住什么】

胶水钩子：
【动作钩子 / 声音钩子 / 视线钩子 / 道具钩子 / 反应钩子】

是否足够剪：
【可剪 / 需补桥镜 / 改出点 / 改入点 / 删镜】

第一刀：
【只改一个连接点】
```

终检失败处理：

| 失败表现 | 第一刀 |
| --- | --- |
| 上一镜停死 | 改出点，让动作、声音或视线还没完时切 |
| 下一镜突然出现 | 改入点，先接上一镜的动作、声音或视线 |
| 两镜信息重复 | 删一镜，或把后一镜改成新信息/反应 |
| 两镜情绪断开 | 加声音桥或反应镜 |
| 两镜空间跳乱 | 补建立镜头或用视线匹配重建方向 |
| 主镜之间太硬 | 加手部、道具、环境或反应桥镜 |

两镜断裂等级与第一刀：

| 等级 | 断裂表现 | 判断方式 | 第一刀 |
| --- | --- | --- | --- |
| A级：无钩子 | 上一镜结束和下一镜开始没有共同动作、声音、视线、道具或反应 | 把两镜对调也不影响理解，说明它们没有互相带出 | 先改上一镜出点；如果出点救不了，再改下一镜入点 |
| B级：钩子错配 | 有钩子，但类型不服务当前任务 | 动作戏只靠氛围音乐接，情感戏只靠花哨转场接，产品证明只靠情绪表情接 | 换成任务对应钩子：动作接触、声音桥、视线揭示、道具证明或反应确认 |
| C级：信息重复 | 下一镜只重复上一镜已经看懂的内容 | 删掉后一镜后，信息、情绪和动作因果没有损失 | 删后一镜，或把后一镜改成结果、代价、反应、证据或新问题 |
| D级：方向冲突 | 钩子存在，但空间方向、情绪状态或动作阶段互相矛盾 | 上一镜看右，下一镜信息从左来；上一镜刚受力，下一镜已经平静；道具状态突然跳变 | 先修连续性变量；必要时补建立镜头、状态交代镜或反应桥镜 |

胶水钩子优先级：

```text
身体动作连续优先动作钩子。
时间、情绪或空间跳转优先声音钩子。
揭示秘密、危险或答案优先视线钩子。
产品、证据、旧物和记忆母题优先道具钩子。
打击结果、笑点、产品效果和情绪落点优先反应钩子。
```

修复顺序：

```text
先改出点 -> 再改入点 -> 再换钩子类型 -> 再补桥镜 -> 最后删镜或拆镜。
不要第一刀就把两镜都重写；每轮只改一个连接变量。
```

如果一条片里连续两组镜头都没有胶水钩子，不进入逐镜生成，先回到分镜表补衔接。

## 14. 自检

输出多镜头方案前，AI超级导演自问：

1. 每个镜头是否有入点和出点？
2. 上一镜是否把下一镜带出来？
3. 每次切镜是否有动作、声音、视线、构图、情绪或信息理由？
4. 是否避免了无意义花哨转场？
5. 声音桥是否写成具体声音，而不是只写“音乐衔接”？
6. 动作匹配和视线匹配是否遵守空间方向？
7. 蒙太奇是否有起点、过程和结果？
8. Seedance 2.0 提示词是否写入上一镜衔接、本镜入点、本镜出点和下一镜钩子？
9. 打斗、群像和短剧是否先保证空间清楚，再做转场？
10. 这套衔接是否让片子像一个导演剪出来，而不是像几条生成视频拼在一起？
11. 逐镜生成前，是否检查了每两镜之间至少有一个剪辑胶水钩子？
