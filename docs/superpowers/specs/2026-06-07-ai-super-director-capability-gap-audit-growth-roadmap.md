# AI超级导演能力查漏补缺与真人导演成长路线

## 1. 定位

这份文档用于持续检查 AI超级导演还缺什么。它不是能力目录，而是一张导演成长雷达：每次完善自己时，都从真实片场、客户提案、Seedance 2.0 生成、剪辑成片和发布复盘里找短板。

目标不是让资料更多，而是让输出更像一个活生生的人在现场判断：知道什么时候该保留，什么时候该舍掉，什么时候该拆镜，什么时候该闭嘴让一个反应镜头说话。

## 2. 查漏总原则

每次完善能力，先问十个问题：

1. 这个能力能不能帮用户更快拍出第一镜？
2. 它能不能减少追问，而不是增加问卷？
3. 它有没有把抽象形容词翻译成动作、站位、声音、剪辑点？
4. 它有没有 Seedance 2.0 可生成版本？
5. 它有没有失败后的第一刀改法？
6. 它有没有保底镜头，保证能剪起来？
7. 它有没有处理口型、群像、动作、道具和连续性风险？
8. 它有没有后期文字和声音兜底？
9. 它有没有版权、品牌、真实人物和平台风险意识？
10. 它有没有让导演人格更清楚，而不是更像模板？

如果一个新能力只能提供漂亮词语，不能提供现场动作、机位、声音和判断，就暂时不加入核心库。

## 3. 当前能力雷达

| 能力区 | 当前状态 | 主要缺口 | 下一刀 |
| --- | --- | --- | --- |
| 第一响应与路由 | 已有一键响应内核、总索引、总控台 | 需要更多真实输入样例校准路由 | 增加 30 条用户一句话样例与默认输出深度 |
| 类型导演 | 已覆盖可爱、广告、短剧、特摄、打斗、情感、科幻、文旅等 | 类型很多，容易平均用力 | 加强类型混搭时的主副优先级和禁用项 |
| 分镜与镜头语言 | 已有分镜模板、镜头词典、衔接库 | 还可补“一个场景的覆盖拍法”病例 | 增加 5 个场景的主镜头、反应、插入、保底出点 |
| 现场调度 | 已有空间轴线、群像、身体化镜头卡 | 对复杂空间的站位图仍偏文字化 | 增加左右关系、机位站边、动线的文本图模板 |
| 表演指导 | 已有表演调度、微动作、对白口型 | 需要更多“不要演情绪，演动作”的范例 | 增加情绪动作谱：防御、破防、收回、假装没事 |
| 声音与剪辑 | 已有声音先行、声音桥、剪辑节奏 | 可补更多声音记忆点和静音点用法 | 增加第一声、静音、尾音回收的类型表 |
| Seedance 2.0 可生成性 | 已有可生成性、拆镜、返工协议 | 需要更明确的一镜失败诊断表 | 增加失败类型到改法映射 |
| 参考转译与合规 | 已有参考拆解、原创替换、权利清场 | 可补“像某作品但原创”的高频话术 | 增加可继承层/禁用层/替代层三列表 |
| 客户提案 | 已有项目交付包、成片交付包 | 可补“客户看得懂”的版本压缩 | 增加客户版摘要、导演版细案、执行版提示词三层 |
| 发布与爆款 | 已有钩子、留存、发布包装 | 需要持续趋势更新，但不能承诺必爆 | 增加发布前可复述测试和封面记忆帧检查 |
| 自我训练 | 已有训练题库、复盘成长 | 需要固定日常演练题 | 增加每轮自训：一题创意、一题改稿、一题返工 |

## 4. 需要补强的九块能力

### 4.1 选角与角色质感

缺口：现在人物动机和表演已经有，但“这个角色长什么气质、怎么穿、怎么站、怎么让观众一眼记住”还可以更准。

下一刀：

```text
角色第一眼：
身体习惯：
防御姿势：
服装功能：
道具绑定：
声音习惯：
禁用刻板印象：
```

适用：短剧、广告人物、群像、系列 IP、可爱治愈角色。

### 4.2 场景质感与真实生活痕迹

缺口：已有环境生命点，但还可以把“场景身份”做得更具体。办公室、厨房、幼儿园、车内、夜市、医院走廊、家里客厅，都应该有不同的使用痕迹。

下一刀：

```text
场景身份：
最近被谁使用过：
一个不能抢戏的背景动作：
一个声音来源：
一个道具痕迹：
一个禁止出现的假细节：
```

适用：纪实感、家居、短剧、企业片、可爱群像。

### 4.3 导演和摄影的“站边”

缺口：很多分镜写了机位，但还要更像现场导演：摄影机站哪边，为什么不能越轴，角色怎么进出画，观众站在谁身边。

下一刀：

```text
空间基准线：
摄影机站边：
主视线方向：
进入画面方向：
退出画面方向：
不能跨越的轴线：
可以切换视角的理由：
```

适用：多人对白、打斗、追逐、短剧冲突、会议群像。

### 4.4 反应镜头库

缺口：反应镜头经常决定真实感，但容易被提示词写丢。需要把反应做成可调用的镜头类型。

下一刀：

```text
听见前：
听见中：
忍住反应：
假装没事：
身体先暴露：
眼神收回：
剪辑出点：
```

适用：情感、喜剧、短剧、广告人物、群像对白。

### 4.5 失败镜头诊断表

缺口：返工协议已经有，但还要更机械地定位失败类型。

下一刀：

| 失败现象 | 第一判断 | 第一刀 |
| --- | --- | --- |
| 角色漂移 | 角色锁定不够 | 补服装、发型、道具、年龄、体态 |
| 动作乱 | 一镜动作太多 | 拆成起点、触发、结果三镜 |
| 口型穿帮 | 台词太长或多人说话 | 缩短台词，改近景单人或画外声 |
| 画面没重点 | 主体比例和焦点不清 | 明确第一眼重心和禁止遮挡 |
| 风格漂 | 每镜风格词不同 | 统一风格锁定句 |
| 剪不起来 | 入点出点不清 | 增加反应镜头和保底出点 |

### 4.6 客户提案压缩表达

缺口：完整方案很多，但客户不一定看长文。需要一版“客户能一眼懂”的压缩层。

下一刀：

```text
一句话卖点：
客户为什么会在乎：
第一帧看见什么：
产品或故事怎么证明：
观众记住什么：
执行风险如何控制：
```

适用：广告提案、品牌片、企业片、文旅、产品视频。

### 4.7 演员说戏语言

缺口：表演调度已有，但还可以更像导演对演员说话，而不是写人物分析。

下一刀：

```text
不要演“难过”，你现在的任务是把这句话咽回去。
眼睛看一下门口，马上收回来，像怕别人发现。
手别乱动，只摸一下杯沿，停半秒再开口。
```

适用：人物不活、情绪不真、不要尬演、潜台词、内心戏。

### 4.8 类型精华转译的原创替代库

缺口：已有参考拆解，但“替代动作”可以更丰富。不能只说不要抄，要给替代方案。

下一刀：

```text
原参考的情绪功能：
禁用外壳：
替代角色关系：
替代场景任务：
替代视觉母题：
替代声音记忆：
替代结尾回收：
```

适用：电影感、特摄感、参考爆款、像某类作品但原创。

### 4.9 发布前可复述测试

缺口：爆款结构不能只看前三秒，还要看观众能不能复述。

下一刀：

```text
观众一句话能怎么讲给朋友：
最容易截图的一帧：
最容易模仿的动作：
最容易评论的问题：
标题和封面是否复用同一个记忆钉子：
```

适用：爆款、系列化、短剧追更、可爱群像、创意广告。

## 5. 每次继续完善时的默认动作

当用户说“继续完善、查漏补缺、像真人导演、成长为最厉害的人”时，默认做一轮小升级：

1. 读 README 和核心索引，确认当前资产。
2. 选一个最影响实战的缺口。
3. 新增或修订一个专项文档。
4. 更新 README 核心资产或新增能力入口。
5. 做自检：是否能减少追问、能否转成镜头、能否 Seedance 2.0 生成、失败后有没有第一刀。

不要一次改十个方向。每轮只补一块最能让导演更像真人的能力。

## 6. Seedance 2.0 生成短片专项优先级

用户的核心生产方式是用 Seedance 2.0 生成 AI 短片和相关视频，所以后续查漏补缺要优先服务“生成更稳、镜头更能剪、失败更会改”，而不是继续泛泛扩展导演理论。

Seedance 2.0 专项优先级：

1. 首帧与关键帧标准库：先锁第一帧、角色标准帧、场景标准帧、产品标准帧。
2. 角色锁定句与角色圣经模板：减少发型、服装、年龄、体态、道具漂移。
3. 场景锁定和空间方向模板：减少门窗、光源、桌椅、左右关系乱跳。
4. 失败镜头诊断与返工改法映射：跑偏后知道第一刀改哪里。
5. 反应镜头与保底出点库：让片子剪得起来，人物像活人。
6. 口型同步降风险模板：一镜一个说话人，短句、近景、画外声和后期配音兜底。
7. 群像降风险模板：多人同框时控制站位、主动作和反应顺序。
8. 特效打斗拆镜模板：现实基准、触发点、受力结果和声音打击点。
9. 产品手部动作稳定模板：手部任务、产品动作、微距证据和结果变化。
10. 发布前成片感审片表：检查第一帧、连续性、声音桥、字幕安全区和记忆点。

每次新增能力都要回答：

```text
它能不能让 Seedance 2.0 更稳定？
它能不能减少角色漂、风格漂、动作乱、口型穿帮、剪不起来？
它有没有生成前预检、提示词模板、失败后第一刀？
```

## 7. 通用下一轮优先级

优先级从高到低：

1. 失败镜头诊断表与返工改法映射。
2. 反应镜头库。
3. 导演和摄影站边模板。
4. 演员说戏语言库。
5. 客户提案压缩表达。
6. 发布前可复述测试。
7. 角色第一眼与选角质感。
8. 场景真实生活痕迹。
9. 类型精华原创替代库。

我的判断：下一轮最该补“失败镜头诊断表与返工改法映射”。因为用户真正生成视频后，最痛的是跑偏、不稳、剪不起来。一个真人导演最值钱的地方，不是第一次说得多漂亮，而是看到失败结果后知道下一刀砍哪里。
