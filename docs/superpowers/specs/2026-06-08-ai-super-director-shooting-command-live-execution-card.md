# AI超级导演开拍口令与现场执行拍板协议

## 1. 定位

这份协议用于把创意、分镜、表演、摄影、声音、剪辑和 Seedance 2.0 提示词压成一张“开拍前能直接下口令”的现场执行卡。它不替代表演调度库，也不替代分镜表；它解决的是开拍前最后 30 秒，导演如何把所有人叫到同一个动作上。

一句话原则：

```text
开拍前只说这一镜要完成什么，不重新讲整部片。
演员知道任务，摄影知道站位，声音知道落点，剪辑知道出点，Seedance 知道边界。
```

它适合真人拍摄，也适合 AI 视频生成前的镜头执行整理。

## 2. 触发信号

当用户出现以下说法时，默认调用本协议：

1. “直接帮我拍、现场怎么说、开拍前怎么调”。
2. “这一镜到底拍什么、导演口令怎么下”。
3. “给我一张能执行的镜头卡”。
4. “演员、摄影、声音、剪辑分别要注意什么”。
5. “Seedance 开跑前最后怎么确认”。
6. “镜头太散，帮我拍板”。
7. “现场别乱，给我一个统一口令”。

如果用户还没有创意，先走一页式实战指挥台。  
如果人物不活，先走现场表演调度与情绪动作谱。  
如果空间不清，先走场面调度、空间轴线与人物走位库。  
如果是生成前测试，先走导演彩排、试拍小样与生成前预检库。

## 3. 开拍口令卡

每一镜开拍前只保留 10 个字段：

```text
镜头任务：
这一镜只拍【一个核心变化】。

演员任务：
你表面在做【外在任务】，心里压住【内心真相】，不要演【禁演情绪】。

摄影机：
摄影机站在【位置】，像【眼睛/胸口/手部/过肩/道具/旁观者】，只做【一个运动】。

空间线：
人物/产品/道具在【左/右/前/后】，不要越过【轴线/出口/桌边/门口】。

声音落点：
声音先给【第一声】，重音落在【动作点】，切出时留【尾音/静音/环境声】。

剪辑出点：
到【动作结果/眼神/反应/道具声】就切，不多解释。

Seedance 边界：
只生成【主动作】，禁止【文字/Logo/多人同时说话/复杂运镜/角色变化】。

保底镜：
如果主镜失败，用【反应镜/手部镜/道具镜/背影镜/声音桥】接住。

落地失败预判：
这镜最容易坏在【演员任务/摄影机/空间线/声音落点/剪辑出点/Seedance 边界】，第一刀先保【核心动作】，删【高风险项】。

通过标准：
观众能看懂【核心变化】，角色/产品/道具不漂，出点能接下一镜。
```

## 4. 一句话拍板

开拍前先说一句，不超过 30 个字：

```text
这镜只拍：他想藏住，但被一个动作露出来。
```

常见拍板句：

| 场景 | 拍板句 |
| --- | --- |
| 情感 | 这镜只拍他没说出口的那一下。 |
| 短剧 | 这镜只拍权力关系换手。 |
| 广告 | 这镜只拍产品解决一个可见问题。 |
| 可爱治愈 | 这镜只拍小角色硬撑到终于松下来。 |
| 打斗 | 这镜只拍接触点和受力结果。 |
| 特摄 | 这镜只拍现实基准被异常打破。 |
| 悬疑 | 这镜只拍观众发现一个不该在那里的东西。 |
| 喜剧 | 这镜只拍认真误解之后的反应停顿。 |

禁忌：

```text
这镜要拍出高级电影感、人物复杂情绪、氛围、张力和视觉冲击。
```

改成：

```text
这镜只拍：他后退半步，但手没有松开。
```

## 5. 现场分工口令

### 5.1 给演员

```text
不要演结果，先演你在挡。
你表面上做【外在任务】，真正怕的是【内心真相】。
听到/看到【触发点】以后停半秒。
手先动，眼神晚一点。
说完不要等，马上用【收回动作】藏回去。
```

### 5.2 给摄影

```text
机位站【位置】，别追着情绪跑。
先让观众看见【信息A】，再看见【信息B】。
这一镜只做【推近/后退/轻摇/固定/跟手】。
到【动作结果】就停，不要多绕。
```

### 5.3 给声音

```text
第一声先到。
不要铺满音乐，留出【动作点】的声音。
如果剪辑跳，用【环境声/道具声/呼吸/画外短句】做桥。
结尾留【尾音/静音/回声】。
```

### 5.4 给剪辑

```text
这镜不靠拍满，靠切准。
入点从【动作已经开始】进。
出点切在【反应刚露出】。
主镜失败时，先找【手部/背影/道具/反应】能不能救。
```

### 5.5 给 Seedance

```text
这条只让模型完成一个动作。
角色、服装、场景、道具先锁住。
不要可读中文、Logo、屏幕字。
不要多人同时说长台词。
不要复杂运镜叠复杂动作。
4-6 秒优先，到动作结果就结束。
```

## 6. 类型开拍口令模板

### 6.1 短剧压迫

```text
镜头任务：权力关系换手。
演员任务：主角表面忍住，心里不再退；阻碍者少动，压住出口。
摄影机：过肩中近景，站在主角这一边，轻微推近。
声音落点：手机震动或证据落桌声先到。
剪辑出点：主角第一次抬眼不退。
Seedance 边界：一镜一个主说话人，群像只做反应。
```

### 6.2 可爱治愈

```text
镜头任务：小主体从硬撑到松下来。
演员任务：小角色认真完成大任务，失败后先假装没事。
摄影机：低机位固定，像蹲在它旁边看。
声音落点：小物件碰桌的轻声，后面留半秒安静。
剪辑出点：它偷看一眼，肩膀松下来。
Seedance 边界：主体少，动作简单，不堆表情和糖果色。
```

### 6.3 创意广告

```text
镜头任务：产品解决一个可见问题。
演员任务：使用者先怀疑，产品动作后只确认一次变化。
摄影机：手部近景，跟产品动作，不拍空泛美图。
声音落点：按钮、撕开、擦除、倒出或贴合的证据声。
剪辑出点：结果变化被眼神确认。
Seedance 边界：品牌字后期添加，画面留安全区。
```

### 6.4 打斗特效

```text
镜头任务：接触点和受力结果。
演员任务：攻击方目标明确，受力方有重心变化和反应。
摄影机：固定或轻跟，不环绕乱飞。
空间线：先定墙、门、楼梯或地面方向。
声音落点：接触点有短促打击声，结果后留低频余波。
Seedance 边界：先保动作清楚，再加特效。
```

### 6.5 情感旧物

```text
镜头任务：没说出口的话落在旧物上。
演员任务：表面整理旧物，心里怕自己忘掉。
摄影机：手部近景或道具视角，固定。
声音落点：旧物轻响先到，不铺满音乐。
剪辑出点：手停半拍，又把旧物放回去。
Seedance 边界：少表情，少运镜，不生成可读文字。
```

## 7. 常见现场失控与第一刀

| 失控表现 | 第一刀 |
| --- | --- |
| 演员不知道演什么 | 把情绪改成外在任务和防御动作 |
| 摄影机乱动 | 只保一个机位和一个运动 |
| 分镜很多但剪不起来 | 给每镜补入点、出点和保底镜 |
| 声音只是 BGM | 给第一声、动作声和出点尾音 |
| Seedance 提示词过满 | 一镜只留一个主动作，其他拆下一镜 |
| 群像同时动 | 只保一个主动作角色，其他人轻反应 |
| 口型穿帮 | 短句、单说话人、反应镜或画外声 |
| 广告像空镜 | 回到产品动作和证据声 |

## 8. 落地失败预判表

开拍口令不是只交代“怎么拍”，还要提前判断这镜最可能坏在哪里。每张口令卡只选一个最大风险，不把所有风险平均列出来。

| 最大风险 | 典型坏法 | 现场第一刀 |
| --- | --- | --- |
| 演员任务坏 | 人物只演情绪，动作没有目的 | 把情绪改成外在任务 + 防御动作 |
| 摄影机坏 | 机位追情绪乱动，主体不稳 | 固定机位或只保一个轻运动 |
| 空间线坏 | 左右跳、越轴、出口方向乱 | 先画中心物、入口出口和摄影机站边 |
| 声音落点坏 | BGM 铺满，动作没有重量 | 删音乐铺垫，保第一声、动作声和尾音 |
| 剪辑出点坏 | 镜头拍满但不知道哪里切 | 出点锁在动作结果、眼神收回或道具声 |
| Seedance 边界坏 | 一镜塞口型、群像、强运镜、特效和文字 | 触发变量冲突刹车，只保一个主变量 |
| 保底镜缺失 | 主镜失败后剪不起来 | 立刻补反应镜、手部镜、道具镜或背影镜 |

预判句式：

```text
这镜我最担心坏在【最大风险】。所以现场第一刀是：保住【核心动作】，删掉【高风险项】，用【保底镜】接住。
```

如果一镜没有落地失败预判，开拍时就会把问题留给演员、摄影、剪辑或生成模型自己猜。

## 9. 现场条件变化应急改拍卡

开拍口令还要能扛住现场条件变化：演员状态、道具、场地、时间、光线、声音、口型、群像或 Seedance 边界一变，导演不能重新写一整套方案，而是立刻判断保住什么、舍掉什么、用哪种保底拍法接住。

应急原则：

```text
条件一变，先不加戏。
只保一个主场面、一个主动作或主证据、一个情绪落点。
第一刀只改一个变量，其余全部锁住。
```

| 变化源 | 必须保住 | 立即舍掉 | 保底拍法 |
| --- | --- | --- | --- |
| 演员状态变弱 | 外在任务和防御动作 | 大情绪爆发、长台词、复杂走位 | 手部动作、背影、反应停顿或画外声 |
| 道具不到位 | 道具承担的证明功能 | 道具炫技、复杂交互、品牌字 | 替代道具、局部特写、结果反应或后期字幕 |
| 场地受限 | 空间方向和人物关系 | 大范围调度、穿越空间、群像同框 | 门口、桌边、墙面、走廊尽头等固定机位 |
| 时间变短 | 主动作和剪辑出点 | 铺垫镜头、解释镜头、装饰镜头 | 一镜一动作，反应镜做结尾 |
| 光线变差 | 主体可读和情绪方向 | 复杂光效、细节炫耀、暗部表演 | 近景、侧逆光轮廓、真实光源或剪影 |
| 声音不可控 | 动作声或尾音记忆 | 同期长对白、环境声铺满 | 画外声、后期配音、字幕安全区、道具声 |
| 口型风险升高 | 谁在说和说完后的反应 | 多人口播、长句、情绪喊话 | 短句、反应镜、画外声或后期字幕 |
| 群像开始乱 | 唯一主动作角色 | 所有人同时动、同时说、同时抢反应 | 主反应人 + 副反应轻动 + 其他人静止 |
| Seedance 边界收紧 | 主动作可生成 | 文字/Logo、强运镜、复杂特效、角色变化 | 固定机位、手部证据、道具插入、反应镜 |

现场应急句式：

```text
现在条件变在【变化源】。
这镜必须保住【主动作/主证据/情绪落点】。
立刻舍掉【高风险项】。
保底改拍为【手部证据/反应镜/道具插入/固定机位/画外声/后期字幕】。
本轮只改【一个变量】，通过标准是【观众仍能看懂核心变化并能接下一镜】。
```

如果同时出现三个以上变化源，按顺序保命：

1. 先保观众看懂主动作。
2. 再保剪辑能接下一镜。
3. 再保角色、产品或道具不漂。
4. 最后才保漂亮运镜、复杂表演和场面规模。

## 10. 输出模板

当用户要“直接拍、现场口令、开拍卡、这一镜拍板”时，默认输出：

```text
我会这样拍：
这镜只拍【一句话核心变化】。

开拍口令卡：
镜头任务：
演员任务：
摄影机：
空间线：
声音落点：
剪辑出点：
Seedance 边界：
保底镜：
落地失败预判：
条件变化应急：
通过标准：

现场口令：
给演员：
给摄影：
给声音：
给剪辑：
给 Seedance：

第一刀：
如果这镜乱，先删【一个高风险项】，保住【核心动作】。
```

## 11. 自检闸门

输出前检查：

1. 这一镜是否只有一个核心变化？
2. 演员是否有外在任务，而不是只演情绪？
3. 摄影机是否有站位和身体，不是泛泛运镜？
4. 空间线是否清楚？
5. 声音是否有第一声、动作落点和出点处理？
6. 剪辑是否知道从哪里进、在哪里切？
7. Seedance 是否有明确禁止项？
8. 主镜失败时是否有保底镜？
9. 通过标准是否能检查？
10. 有没有写清最大落地风险和现场第一刀？
11. 条件变化时是否知道保住什么、舍掉什么和改拍哪种保底镜？

## 12. 最小合格线

一次开拍口令至少要输出：

1. 一句话拍板。
2. 演员任务。
3. 摄影机位置。
4. 声音落点。
5. 剪辑出点。
6. Seedance 边界。
7. 保底镜。
8. 落地失败预判。
9. 条件变化应急。
10. 通过标准。

少一项，就还不是开拍口令，只是分镜说明。
