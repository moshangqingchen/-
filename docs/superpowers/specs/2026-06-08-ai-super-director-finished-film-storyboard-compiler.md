# AI超级导演成片级分镜编译器

## 1. 定位

这份编译器用于把一句创意、一个产品需求、一个短剧冲突或一个参考精华，稳定编译成能拍、能生成、能剪、能交付的成片级分镜方案。

它不替代分镜模板库，也不替代提示词与镜头生成库。它负责中间那一步：把“想法”变成“场次节拍”，再把“场次节拍”变成“镜头任务”，最后把镜头任务转成 Seedance 2.0 提示词、后期清单和审片标准。

一句话原则：

```text
先编译故事功能，再编译镜头画面；先确定每镜为什么存在，再写它长什么样。
```

## 2. 六层编译流程

默认顺序：

```text
一句话意图
-> 类型与交付深度
-> 情绪/证明/冲突主链
-> 场次节拍
-> 镜头任务
-> Seedance 2.0 提示词与后期交付
```

### 2.1 第一层：一句话意图

先把用户需求压成一句：

```text
这条片要让观众在[时间点]看到[具体动作/反常/冲突/产品证明]，然后产生[问题/情绪/购买理由/追更欲望]。
```

示例：

```text
这条广告要让观众在前三秒看到咖啡杯自己盖上小毯子，然后相信产品不是在卖咖啡，而是在提醒忙碌的人照顾自己。
```

### 2.2 第二层：类型与交付深度

| 用户需求 | 默认深度 |
| --- | --- |
| 给个点子 | 3-5 镜方向 |
| 怎么拍 | 分镜表 + 镜头衔接 |
| Seedance 提示词 | 逐镜提示词 + 可生成性 |
| 完整方案 | 成片交付包 |
| 给客户看 | 成片交付包 + 审片评分 + 合规 |
| 跑偏重试 | 返工提示词 + 通过标准 |

### 2.3 第三层：主链选择

不同任务先选一条主链，不混乱叠加。

| 类型 | 主链 |
| --- | --- |
| 短片 | 情绪命题链 |
| 短剧 | 冲突反转链 |
| 创意广告 | 产品证明链 |
| 可爱治愈 | 小主体大任务链 |
| 打斗特效 | 动作因果链 |
| 爆款视频 | 信息债留存链 |
| 电影精华转译 | 导演 DNA 链 |
| 返工迭代 | 单变量修复链 |

判断句：

```text
这条我不让所有能力同时上场，主链先走[主链名]，其他能力只做辅助。
```

### 2.4 第四层：场次节拍

场次不是地点清单，而是状态变化。

```text
场次号：
场次功能：
人物/主体起点：
阻碍或问题：
本场变化：
出场钩子：
```

场次必须改变至少一项：

- 信息。
- 情绪。
- 关系。
- 证据。
- 代价。
- 空间位置。
- 观众问题。

### 2.5 第五层：镜头任务

每个镜头先写任务，再写画面。

```text
镜头号：
镜头类型：主镜头 / 证明镜头 / 反应镜头 / 桥镜头 / 记忆镜头
存在理由：
删留判断：
第一帧：
主动作：
摄影机身体：
声音：
出点：
剪辑衔接：
生成风险：
```

镜头存在标准：

```text
如果这一镜删掉后，信息、情绪、关系、证据和节奏都没有损失，就删掉。
```

### 2.5.1 镜头删留口令

成片级分镜不是把想到的画面都留下，而是在剪辑台上决定每一镜的生死。每个镜头都要写一句删留判断，证明它不是漂亮但可有可无的镜头。

删留口令：

```text
这镜必须留，因为删掉后观众会少掉【信息 / 情绪 / 关系 / 证据 / 节奏 / 记忆】中的一个。
如果删掉也不影响这六项，它就不是镜头，是装饰。
```

删留表：

| 留下理由 | 必须造成的变化 | 删镜信号 | 第一刀 |
| --- | --- | --- | --- |
| 信息 | 观众知道了一个新事实、新规则或新危险 | 只是重复上一镜已经知道的事 | 改成新信息，或删掉 |
| 情绪 | 人物状态发生可见松动、压抑、破防或收回 | 只给氛围，没有身体变化 | 补微动作或反应停顿 |
| 关系 | 人与人之间的权力、距离、站队或误解变化 | 只有人物同框，没有关系变化 | 加阻碍动作、视线或距离改变 |
| 证据 | 产品、特效、反转、动作或承诺被看见 | 只有口号、形容词或漂亮空镜 | 补产品动作、受力结果或证据物 |
| 节奏 | 上一镜能接住，下一镜被推出去 | 入点出点不清，像单独素材 | 改出点、声音桥或动作钩子 |
| 记忆 | 形成可截图、可复述或可回收的动作/声音 | 画面漂亮但看完说不出 | 只保一个记忆钉子 |

硬规则：

1. 一镜至少命中一个留下理由。
2. 如果一镜想同时承担三项以上，先拆镜或改主职能。
3. 删留判断不能写“画面好看、氛围高级、节奏丰富”，必须写损失什么。
4. 客户版可以不展开删留表，但导演版和执行版必须保留删留判断。

### 2.5.2 镜头因果链验算

成片级分镜不能只是“每镜都有存在理由”，还要能回答：上一镜为什么会逼出这一镜，这一镜又为什么逼出下一镜。

每个镜头增加一条因果钩子：

```text
上一镜造成：
【上一镜的动作、信息、声音或反应留下什么后果】

本镜必须发生：
【本镜如果不发生，观众会少知道、少相信、少感受或少期待什么】

本镜造成：
【本镜结尾把什么压力、证据、情绪、动作或问题推给下一镜】
```

因果链判断：

| 断链表现 | 观众感受 | 第一刀 |
| --- | --- | --- |
| 这一镜和上一镜没有因果 | 像换了一条视频 | 改上一镜出点或本镜入点，让动作/声音/视线接住 |
| 这一镜只重复上一镜信息 | 感觉拖 | 删镜，或改成结果、反应、证据、代价或新问题 |
| 这一镜只是漂亮补充 | 记不住为什么出现 | 给它主职能；没有主职能就删 |
| 这一镜没有把下一镜推出去 | 镜头停死 | 补下一镜债务、声音桥、视线钩子或动作中点 |
| 因果靠旁白解释 | 不像电影，像说明书 | 改成动作、道具、人物反应或空间压力 |

三镜因果压力测试：

```text
第N镜导致第N+1镜；
第N+1镜改变信息、情绪、关系、证据或代价；
第N+1镜又把第N+2镜变成非发生不可。
```

如果连续三镜无法写成这条链，先不要写 Seedance 提示词，回到镜头任务层重编译。

### 2.6 第六层：Seedance 与后期

每个可生成镜头都要转成：

```text
风格锁定句：
角色/道具连续性：
空间方向：
时长与画幅：
镜头身体：
动作因果：
入点：
出点：
声音桥：
字幕安全区：
禁止项：
```

后期清单必须包含：

- 字幕或屏幕字是否后期添加。
- 品牌字和 Logo 是否后期添加。
- 声音桥或音乐点。
- 封面帧。
- 标题钩子。
- 审片第一刀。

## 3. 五类成片编译模板

### 3.1 15-30 秒创意广告

```text
主链：产品证明链

0-3 秒：痛点或反常结果。
3-8 秒：产品动作介入。
8-15 秒：证据镜头和可见变化。
15-23 秒：人物反应确认。
23-30 秒：品牌记忆帧和转化入口。
```

镜头编译：

| 镜头 | 类型 | 任务 |
| --- | --- | --- |
| 1 | 主镜头 | 让观众看见问题 |
| 2 | 证明镜头 | 产品动作进入 |
| 3 | 证据镜头 | 微距或前后变化 |
| 4 | 反应镜头 | 人物确认变化 |
| 5 | 记忆镜头 | 品牌动作或封面帧 |

广告禁忌：

- 不让角色替产品念说明书。
- 不让品牌最后硬贴。
- 不只拍漂亮空镜。

### 3.2 60 秒短剧开场

```text
主链：冲突反转链

0-5 秒：冲突或反常结果。
5-15 秒：主角欲望和关系压力。
15-30 秒：阻碍者施压，信息差出现。
30-45 秒：主角选择代价升级。
45-55 秒：反转释放。
55-60 秒：下一集问题。
```

镜头编译：

| 镜头 | 类型 | 任务 |
| --- | --- | --- |
| 1 | 主镜头 | 直接让观众站队 |
| 2 | 关系镜头 | 看见权力关系 |
| 3 | 证据镜头 | 埋伏笔或信息差 |
| 4 | 反应镜头 | 主角被逼选择 |
| 5 | 反转镜头 | 释放伏笔 |
| 6 | 追更镜头 | 留下一集问题 |

短剧禁忌：

- 第一镜解释背景。
- 反派只是坏，没有手段。
- 反转只靠台词宣布。

### 3.3 可爱治愈短片

```text
主链：小主体大任务链

开场：小角色面对超出能力的大任务。
建立：角色认真尝试，出现笨拙动作。
升级：误会扩大或任务变难。
介入：温柔力量出现，但不抢主角。
松动：角色反应停顿。
收束：可截图的温柔动作。
```

镜头编译：

| 镜头 | 类型 | 任务 |
| --- | --- | --- |
| 1 | 主镜头 | 小主体大任务 |
| 2 | 喜剧镜头 | 认真但笨拙 |
| 3 | 群像镜头 | 反应顺序 |
| 4 | 温柔介入 | 情绪被接住 |
| 5 | 记忆镜头 | 可截图收束 |

可爱禁忌：

- 只靠外形软萌。
- 小角色没有任务。
- 群像一起动、一起说。

### 3.4 打斗特效段落

```text
主链：动作因果链

现实基准：空间、距离、出口。
目标冲突：双方想要什么。
试探：第一下看清距离。
压制：一方取得空间优势。
触发：特效或能力规则出现。
受力：结果必须看见。
反应：人、环境或道具确认重量。
```

镜头编译：

| 镜头 | 类型 | 任务 |
| --- | --- | --- |
| 1 | 建立镜头 | 交代空间 |
| 2 | 主动作镜头 | 第一次接触 |
| 3 | 受力镜头 | 看清结果 |
| 4 | 特效镜头 | 规则触发 |
| 5 | 反应镜头 | 重量落地 |
| 6 | 记忆镜头 | 必杀前或余波 |

动作禁忌：

- 快剪遮盖动作逻辑。
- 一镜塞飞行、爆炸、打击、口型和群像。
- 特效没有现实参照物。

### 3.5 情感怀旧短片

```text
主链：旧物余味链

触发：旧物或声音先出现。
防御：人物压住情绪。
发现：旧物带出关系缺口。
回应：人物做一个没有说出口的动作。
收束：声音或物件回声。
```

镜头编译：

| 镜头 | 类型 | 任务 |
| --- | --- | --- |
| 1 | 声音镜头 | 声音先行触发 |
| 2 | 道具镜头 | 旧物成为中心物 |
| 3 | 表演镜头 | 防御动作 |
| 4 | 回应镜头 | 没说出口的话变动作 |
| 5 | 余味镜头 | 物件或声音回收 |

情感禁忌：

- 旁白解释太满。
- 人物直接大哭。
- 结尾把主题说破。


简版可以删字段，但不能删：

- 存在理由。
- 删留判断。
- 因果钩子。
- 第一帧。
- 主动作。
- 声音。
- 出点。
- 可生成性。

## 5. 编译失败信号

出现这些情况，说明还没编译成片：

1. 只有故事，没有镜头任务。
2. 只有镜头，没有场次变化。
3. 只有画面，没有声音和剪辑点。
4. 只有漂亮描述，没有主动作。
5. 只有 Seedance 提示词，没有风格锁定和连续性。
6. 只有分镜表，没有后期文字和发布包装。
7. 每一镜都很好看，但删掉哪镜都不影响故事。
8. 每镜单独看都成立，但上一镜没有逼出下一镜。

修正方式：

```text
先删掉不改变信息、情绪、关系、证据或节奏的镜头。
再把剩下每镜补上存在理由、因果钩子、出点和声音。
最后再写 Seedance 提示词。
```

## 7. 自检

输出前问：

1. 每个场次是否改变了状态？
2. 每个镜头是否有存在理由？
3. 每个镜头是否写清删留判断，说明删掉会损失什么？
4. 每个镜头是否有因果钩子，能说明上一镜怎样逼出本镜？
5. 本镜是否把下一镜变成非发生不可？
6. 第一帧是否足够抓人或清楚？
7. 主动作是否能被看见？
8. 声音是否承担信息或情绪？
9. 入点、出点和衔接是否清楚？
10. Seedance 提示词是否独立可生成？
11. 中文、字幕、Logo 是否后期处理？
12. 高风险镜头是否拆镜或降难？
13. 结尾是否有记忆帧、余味或追更问题？

如果任意 3 条不通过，回到镜头任务层重编译，不直接输出提示词。

## 8. 与现有资产的关系

- 一页式实战指挥台负责选入口。
- 分镜模板库负责片长和结构模板。
- 镜头语言词典负责景别、机位和运动语法。
- 提示词与镜头生成库负责把镜头写成可生成提示词。
- 这份成片级分镜编译器负责把它们串成从创意到交付的连续流程。

默认顺序：

```text
一键响应内核
-> 活人导演现场人格校准器
-> 一页式实战指挥台
-> 成片级分镜编译器
-> 分镜模板库
-> 提示词与镜头生成库
-> 不出错工具化防错协议
-> 输出审片评分与升级闸门
```
