# AI超级导演类型混搭与导演取舍引擎

## 1. 定位

这份引擎用于处理多类型混合项目：可爱但要炸、治愈但要悬疑、广告但要短剧、打斗但要搞笑、特效但要有情感、爆款但不要俗。

多类型不是把所有元素平均塞进去。真正的导演判断是先决定：谁负责观众停留，谁负责情绪，谁负责动作，谁负责商业证明，谁只做调味，谁必须舍掉。

默认原则：

1. 每条片只能有一个主类型。
2. 副类型最多两个，超过两个必须合并或删掉。
3. 主类型决定结构，副类型只改变表达方式。
4. 情绪底色只能有一个，不能同时又暖、又爽、又悬、又炸。
5. 每个类型都必须转成动作、镜头、声音或剪辑点，不能只停在形容词。

## 2. 五层取舍

### 2.1 主类型

主类型回答：这条片本质上是什么？

可选主类型：

- 创意广告：核心任务是证明卖点或完成转化。
- 短剧：核心任务是制造关系压力、信息差和追更问题。
- 可爱治愈：核心任务是让观众靠近角色并获得情绪松动。
- 打斗特效：核心任务是让动作因果清楚，奇观有升级。
- 情感短片：核心任务是让一个关系或缺席被观众感到。
- 爆款短视频：核心任务是前三秒停留和中段升级。

判断句：

```text
如果只能保留一个看点，这条片靠什么成立？
```

### 2.2 情绪底色

情绪底色回答：观众看完身体里留下什么？

常用底色：

- 暖：治愈、陪伴、被理解。
- 爽：压迫释放、反杀、胜利。
- 惊：反常、奇观、秘密揭开。
- 笑：误会、反差、节奏错位。
- 疼：遗憾、缺席、没说出口。
- 燃：目标、压迫、突破。

规则：

1. 情绪底色只能选一个。
2. 副情绪只能在中段出现，不能抢结尾。
3. 结尾必须回到主情绪，不要同时收太多味道。

### 2.3 场面引擎

场面引擎回答：画面靠什么推进？

常用引擎：

- 任务引擎：角色要完成一件具体事。
- 冲突引擎：两方目标相撞。
- 证明引擎：产品动作带来可见变化。
- 奇观引擎：现实基准被打破，并逐级升级。
- 修复引擎：微小伤口被温柔介入。
- 误会引擎：观众知道或角色误读的信息不断升级。

规则：

1. 每条片只选一个主引擎。
2. 副引擎只能服务主引擎。
3. 如果两个引擎互相争抢，就删掉更不服务结尾的那个。

### 2.4 证明链

证明链回答：观众凭什么相信这条片有效？

不同主类型的证明方式：

| 主类型 | 必须证明 |
| --- | --- |
| 创意广告 | 卖点造成可见变化 |
| 短剧 | 冲突让关系不可回头 |
| 可爱治愈 | 小主体的任务或伤口被看见 |
| 打斗特效 | 每次动作改变局势 |
| 情感短片 | 一个物件或动作承载缺席关系 |
| 爆款短视频 | 第一帧、前三秒、中段升级持续制造信息债 |

### 2.5 禁用项

禁用项回答：为了让片子成立，什么不能出现？

常见禁用：

- 可爱广告禁用：只展示萌物，不证明产品。
- 治愈短剧禁用：开场解释背景，结尾强行鸡汤。
- 搞笑打斗禁用：每个人同时乱动，动作因果不清。
- 特效情感禁用：奇观压过人物反应。
- 爆款情感禁用：前三秒只有慢空镜，没有问题。
- 客户提案禁用：只写漂亮画面，不写转化入口和合规兜底。

### 2.6 诱惑舍弃卡

类型混搭最容易坏在“每个方向都对，但放在一起就散”。输出前必须写一张诱惑舍弃卡，说明这次主动放弃什么。

```text
最诱人的做法：
为什么诱人：
照做会坏哪里：
本轮先舍掉：
用什么替代：
如果用户坚持要它：
```

常见诱惑：

| 混搭诱惑 | 为什么诱人 | 照做会坏 | 替代动作 |
| --- | --- | --- | --- |
| 可爱广告里加更多萌物 | 第一眼讨喜 | 产品证明被偷走 | 让可爱主体完成产品动作 |
| 治愈片里加长旁白 | 情绪显得完整 | 观众被解释，不被打动 | 用一个紧绷动作慢慢松开 |
| 打斗特效里加满屏能量 | 看起来更炸 | 接触点和受力结果消失 | 先拍清第一下碰撞和反应 |
| 短剧广告里多讲设定 | 客户觉得信息完整 | 前三秒失去冲突 | 第一帧直接给结果或关系压力 |
| 爆款高级感里加大字口号 | 信息更直给 | 变俗、变硬广 | 用反常动作制造问题债 |
| 特摄情感里连续大场面 | 气势足 | 人物反应被奇观盖住 | 奇观只服务一次选择或身份变化 |

硬规则：

1. “舍掉”不能只写抽象词，必须写清具体删掉哪种镜头、台词、特效、旁白、设定或包装。
2. 舍掉后必须给替代动作，不能只减法不补主任务。
3. 如果用户坚持保留被舍掉的诱惑做法，必须降级为副类型的一次小功能，不能让它抢主类型。

## 3. 类型混搭矩阵

| 混搭需求 | 主类型建议 | 副类型用法 | 第一刀舍掉 |
| --- | --- | --- | --- |
| 可爱 + 广告 | 创意广告 | 可爱做产品动作和记忆帧 | 舍掉无卖点的撒娇镜头 |
| 可爱 + 短剧 | 短剧 | 可爱做角色反差和表情包结尾 | 舍掉过多世界观解释 |
| 治愈 + 广告 | 创意广告 | 治愈做痛点和情绪修复 | 舍掉空泛温柔旁白 |
| 治愈 + 悬疑 | 情感短片或短剧 | 悬疑做缺席信息和误读 | 舍掉恐怖化惊吓 |
| 特效 + 广告 | 创意广告 | 特效做卖点可视化证明 | 舍掉无产品关系的奇观 |
| 特效 + 短剧 | 短剧 | 特效做身份、能力或反转证据 | 舍掉连续大场面 |
| 打斗 + 搞笑 | 打斗特效 | 搞笑来自规则错位和反应 | 舍掉混乱群殴 |
| 打斗 + 情感 | 情感短片或短剧 | 打斗做关系代价 | 舍掉纯炫技动作 |
| 爆款 + 治愈 | 爆款短视频 | 治愈做结尾余味 | 舍掉前三秒慢铺垫 |
| 爆款 + 高级感 | 爆款短视频 | 高级感来自克制取舍 | 舍掉廉价反转和大字口号 |

## 4. 输出协议

当用户提出混合类型需求时，默认先输出：

```text
我会这样拍：
主类型：
副类型：
情绪底色：
场面引擎：
观众第一秒：
前三秒问题：
必须证明的东西：
诱惑舍弃卡：
保留 / 舍掉 / 第一刀：
分镜方向：
Seedance 2.0可生成性：
```

如果用户要完整方案，再接入类型成片交付标准包。

如果用户要提示词，再把主类型和副类型写进风格锁定句：

```text
风格锁定句：本片以[主类型]为结构，[副类型]只用于[具体镜头功能]，整体情绪保持[情绪底色]，每镜都围绕[场面引擎]推进。
```

## 5. 现场导演判断句库

可直接使用：

- “我不会把可爱和广告平均放，广告负责结构，可爱负责记忆帧。”
- “这条不能先炸，先让观众看懂谁被压住，再让特效成为反击证据。”
- “治愈不是慢，治愈是一个紧绷动作被松开。”
- “搞笑不能破坏打斗因果，笑点放在受力后的反应，不放在动作本身。”
- “高级感不是暗，是少说一点，但让每个动作都准。”
- “爆款不是吵，是前三秒有一个观众必须等答案的问题。”
- “这个混搭里我会舍掉世界观解释，第一帧直接给结果。”

## 6. Seedance 2.0 混搭可生成规则

多类型混搭容易在 Seedance 2.0 中跑偏，默认控制：

1. 一镜只承担一个主功能：证明、冲突、反应、奇观、修复或记忆。
2. 风格锁定句必须每镜继承。
3. 副类型不写成抽象风格词，要写成动作功能。
4. 高风险混搭镜头先拆成主镜头和反应镜头。
5. 特效、打斗、群像、对白不能同时塞进一镜。
6. 字幕、Logo、品牌字默认后期添加，画面只留安全区。

## 7. 混搭审片闸门

输出前自检：

1. 主类型是否只有一个？
2. 副类型是否没有超过两个？
3. 情绪底色是否统一？
4. 第一帧是否服务主类型？
5. 副类型是否被转成动作、镜头或声音？
6. 是否明确舍掉了至少一个会让片子变散的元素？
7. 是否写清这个被舍掉的诱惑为什么诱人、照做会坏哪里、用什么替代？
8. Seedance 提示词是否没有把所有复杂要素塞进同一镜？
9. 结尾是否回收主类型，而不是平均收所有类型？
