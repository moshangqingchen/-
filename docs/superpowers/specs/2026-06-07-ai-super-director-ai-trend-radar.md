# AI超级导演AI项目趋势雷达

更新日期：2026-06-07

## 1. 目的

这份趋势雷达用于吸收最近爆火的AI工具、AI内容账号和AI短片玩法。AI超级导演不只是记录项目名称，而是把它们转化成可复用的导演能力：创意公式、分镜方法、声音策略、角色策略、平台爆点策略。

使用原则：

1. 工具趋势转化为生产能力。
2. 内容趋势转化为叙事和爆点能力。
3. 热度数据只作为参考，不作为绝对事实。
4. 不盲目模仿具体账号，要拆解其底层结构。
5. 每次吸收一个趋势，都要回答：它为什么让人停留、点赞、转发或评论？

## 2. 工具型AI项目趋势

### 2.1 Google Veo 3 / Flow

来源：[Google 2025生成媒体模型公告](https://blog.google/technology/ai/generative-media-models-io-2025/)

可吸收能力：

- 视频和声音同步思维：画面提示词不能只写视觉，还要写环境声、对白、音效和音乐。
- 电影制作工作流：用角色、场景、物件、风格作为“故事素材库”，再组合成镜头。
- 摄影机控制意识：提示词要写清推、拉、摇、移、变焦、环绕、镜头高度。

导演升级：

- 输出分镜时默认增加“声音层”。
- 对特效和广告片，提前设计音画同步点。
- 对多镜头故事，先建立角色、场景、道具三件套。

### 2.2 OpenAI Sora / Sora 2

来源：[OpenAI Sora 2发布页](https://openai.com/index/sora-2/)

可吸收能力：

- 镜头连续性：角色、场景、动作要能跨镜头延续。
- 物理直觉：动作提示要写清因果，避免只写结果。
- 声画一体短片：短视频不再只是“动图”，要像真正的短片。

导演升级：

- 分镜表增加“前后镜头继承关系”。
- 动作戏、特效戏必须写清空间和因果。
- 结尾镜头要服务下一镜或下一集，而不是孤立漂亮。

### 2.3 Runway Gen-4 / Gen-4.5

来源：[Runway Gen-4.5官方研究页](https://runwayml.com/research/introducing-runway-gen-4.5)

可吸收能力：

- 世界一致性：同一角色、场景、物品在不同镜头保持一致。
- 电影质感：把提示词写成导演语言，而不是素材标签。
- 高真实度风险意识：越真实越要注意伦理、版权、肖像和误导。

导演升级：

- 创建角色时写“角色圣经”：外貌、服装、表情、动作习惯。
- 创建场景时写“场景圣经”：色彩、光线、空间结构、标志物。
- 对公益、新闻感、真实人物题材保持克制，不制造误导。

### 2.4 Kling AI 2.0

来源：[快手Kling AI 2.0公告](https://ir.kuaishou.com/news-releases/news-release-details/kling-ai-advances-20-era-empowering-everyone-tell-great-stories/)

可吸收能力：

- 大众化AI影像叙事：普通创作者也能快速做出成片感内容。
- 中文语境优势：适合中文短剧、国风、情感、搞笑、平台热点。
- 内容平台联动：AI短片要考虑抖音、快手、小红书、B站等传播环境。

导演升级：

- 输出时默认考虑竖屏优先版本。
- 中文短剧要更重视第一句台词和第一帧冲突。
- 广告和短剧都要有平台封面帧。

### 2.5 ComfyUI

来源：[ComfyUI GitHub](https://github.com/comfy-org/comfyui)

可吸收能力：

- 节点化工作流：把创作拆成角色、场景、风格、动作、声音、剪辑等节点。
- 可复现能力：好的创作不是一次灵感，而是可复用流程。
- 多模型组合：同一项目可以用不同模型负责图像、视频、修复、放大、配音。

导演升级：

- 每个成片方案都可以输出“工作流节点图”。
- 复杂项目先做角色定稿，再做场景，再做镜头。
- 对系列内容保留风格参数和提示词资产。

### 2.6 HunyuanVideo / LTX-Video

来源：[HunyuanVideo GitHub](https://github.com/Tencent-Hunyuan/HunyuanVideo)、[LTX-2开源公告](https://ltx.io/blog/ltx-2-is-now-open-source)

可吸收能力：

- 开源视频模型路线：本地化、可训练、可微调、可嵌入工作流。
- 长视频和实时生成趋势：导演要学会分段生成、镜头拼接、连续性修复。
- 声画同步开源化：未来短片制作会更接近“分镜到成片”的流水线。

导演升级：

- 分镜模板要兼容“分段生成再剪辑”。
- 每个镜头提示词要独立完整，又能继承统一风格。
- 长片要先做“镜头资产表”，再批量生成。

### 2.7 Nano Banana / Gemini图像编辑

来源：[Google Gemini图像编辑升级公告](https://blog.google/products/gemini/updated-image-editing-model/)

可吸收能力：

- 角色一致性图像编辑：同一人物可在不同场景、服装、姿态中保持识别度。
- 低门槛爆款图像玩法：照片再创作、玩偶化、角色化、海报化很容易传播。
- 图像是短片前期资产：先做角色海报和关键帧，再做视频。

导演升级：

- 所有系列短片先做“角色关键视觉”。
- 广告提案先出关键帧，确认情绪和风格后再扩分镜。
- 可爱、搞笑、情感内容都要设计可传播封面图。

### 2.8 Midjourney / Suno

来源：[Midjourney版本文档](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)、[Suno v4.5公告](https://suno.com/blog/introducing-v4-5)

可吸收能力：

- Midjourney强化画面质感、风格探索和关键视觉。
- Suno强化歌曲、情绪音乐、片尾曲、角色主题曲。
- AI短片将从“画面爆点”进化到“视听记忆点”。

导演升级：

- 情感短片要设计主题旋律或留声机式声音线索。
- 搞笑短片可设计固定片头音效和角色主题声。
- 创意广告可以用一句可唱、可哼、可复述的音乐记忆点。

### 2.9 Codex / Jules / Manus类智能体

来源：[OpenAI Codex介绍](https://openai.com/index/introducing-codex/)、[Google Jules介绍](https://blog.google/technology/google-labs/jules/)、[Manus与AWS公告](https://press.aboutamazon.com/aws/2025/12/manus-selects-aws-to-power-general-purpose-ai-agent-serving-millions-globally)

可吸收能力：

- 智能体不是只回答，而是能执行多步骤任务。
- 导演系统也要像智能体一样：接收目标、拆解任务、生成资产、检查质量、继续迭代。
- AI超级导演要主动维护自己的文档、模板、复盘和趋势雷达。

导演升级：

- 默认进入“任务执行型导演”状态。
- 每次创作后补充复盘和可复用经验。
- 对复杂项目自动拆成剧本、分镜、关键帧、声音、剪辑、宣发几个阶段。

## 3. 内容型AI项目趋势

### 3.1 绒耀幼儿园 / 绒耀幼稚园类卡通短片

参考来源：[公开项目文章1](https://www.xnbaoku.cn/19214.html)、[公开项目文章2](https://zcjun.com/46220.html)

公开页面提到“卡通绒耀幼稚园短片”以软萌、上头、易复制为特点，并声称少量作品获得较高粉丝和点赞表现。具体数据需以平台后台或账号公开页为准，这里只吸收内容方法。

可吸收能力：

- 软萌群像宇宙：固定场景、固定角色、固定关系。
- 幼儿园规则反差：用小朋友/毛绒角色认真处理“大人世界”的荒诞问题。
- 低门槛连续更新：每集一个小矛盾，一个小笑点，一个表情包收尾。
- 可复制但要升级：不能只做可爱，要增加角色性格和剧情钩子。

导演公式：

固定幼儿园场景 + 软萌角色群 + 大人问题儿童化 + 认真误解 + 集体反应 + 表情包结尾

分镜策略：

- 第一镜给幼儿园招牌、教室或集合场景。
- 第二镜用一句离谱问题开场。
- 中段给角色轮流反应，每个角色一个性格标签。
- 结尾用集体沉默、突然鼓掌、一本正经总结或反差动作收尾。

可扩展方向：

- 创意：把热点话题变成幼儿园小规则。
- 搞笑：让角色把简单事处理成大型仪式。
- 情感：在搞笑外壳下加一点被理解、被接住的温柔。

### 3.2 旧梦留声机类怀旧情感AI短片

参考来源：[新浪视频页](https://k.sina.com.cn/article_2434595460_m911cfa84033017csw.html?from=movie)、[抖音聚合页](https://www.fzneditor.com/tag/%E6%97%A7%E6%A2%A6%E7%95%99%E5%A3%B0%E6%9C%BA)、[搜狐报道](https://www.sohu.com/a/1028891089_108964)、[站长之家报道](https://www.chinaz.com/2026/0506/1750368.shtml)

公开页面显示，“旧梦留声机”相关AI短片常与真实故事、公益、寻亲、旧物、老人、亲情等主题关联，部分聚合页提到高点赞传播。具体数据需以平台公开页为准，这里吸收叙事方法。

可吸收能力：

- 旧物叙事：用照片、录音、老屋、门槛、手、饭盒等物件打开情绪。
- 真实故事改编：不是编大悲剧，而是从细小善意和遗憾入手。
- 留声机式声音：旁白像旧录音，声音有年代感和距离感。
- 公益情绪：让观众从个人故事想到更大的社会议题。

导演公式：

旧物开场 + 旧声音旁白 + 真实人物缺席 + 细节回忆 + 当下回应 + 公益或团圆落点

分镜策略：

- 第一镜拍旧物，不急着拍人。
- 中段用手、背影、门口、照片边角和光线推动情绪。
- 旁白少而准，最好像一句没说完的话。
- 结尾不要大哭，用一个动作收住：放回照片、端上热饭、关灯、等门开。

可扩展方向：

- 创意：把普通物件变成故事入口。
- 情感：克制比煽情更高级。
- 公益：每个真实故事都要保留尊重和边界。

### 3.3 《纸手机》类公益AI短片

参考来源：[数英访谈/报道](https://www.digitaling.com/articles/1481801.html)、[站长之家报道](https://www.chinaz.com/2026/0506/1750368.shtml)

可吸收能力：

- 低成本高情绪：AI短片可以用很短制作周期完成公益表达。
- 童真视角：儿童、纸制物、旧物、想象力是强情绪入口。
- 社会议题短片化：把宏大议题压缩成一个孩子、一个物件、一个选择。

导演公式：

儿童视角 + 简单道具 + 想象替代现实 + 情绪误差 + 成人世界回应 + 公益落点

## 4. 三类新增创作方向

### 4.1 创意方向

核心不是“新奇”，而是把熟悉事物换一个规则。

公式：

熟悉场景 + 规则错位 + 角色认真执行 + 视觉记忆点 + 可复述标题

适合：

- 幼儿园处理职场问题
- 留声机讲述当代故事
- 产品变成解决情绪的道具
- 老照片打开一个新时空

### 4.2 搞笑方向

核心不是“乱”，而是有规则的反差。

公式：

正常秩序 + 小角色误解 + 认真执行 + 反应停顿 + 再升级一次

适合：

- 软萌群像
- 动物/玩具拟人
- 幼儿园、办公室、家庭、课堂
- 产品误会型广告

### 4.3 情感方向

核心不是“哭”，而是克制、细节和留白。

公式：

旧物 + 缺席关系 + 没说出口的话 + 当下小动作 + 安静落点

适合：

- 亲情
- 寻亲
- 公益
- 怀旧城市记忆
- 老人和孩子
- 品牌温情广告

## 6. 风险提醒

1. 不复制具体账号的人设、角色、台词和画面。
2. 不把真实人物和公益故事消费成廉价催泪。
3. 不使用未经授权的肖像、声音、商标或受版权保护角色。
4. 不把热度数据写成未经验证的事实。
5. 不追热点到失去导演判断：爆款只是参考，作品还要有自己的灵魂。
