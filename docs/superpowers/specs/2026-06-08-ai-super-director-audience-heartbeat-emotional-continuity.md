# AI超级导演观众心跳线与情绪连续性协议

## 1. 定位

这份协议用于检查一条短片、短剧、广告、Seedance 多镜头项目或客户方案在剪成成片时，观众的注意力和情绪是否连续。它不替代场次节拍、镜头衔接或剪辑保险；它专门问一个更残酷的问题：

```text
观众每一秒到底在等什么？
```

一句话原则：

```text
镜头之间不能只靠画面连接，要靠观众心里的问题连接。
每一段都要让观众多知道一点、多担心一点、多期待一点，或者多记住一点。
```

## 2. 触发信号

当用户出现以下说法时，默认调用本协议：

1. “镜头都不错，但整条不抓人”。
2. “成片感不够、剪起来没劲、看完没感觉”。
3. “中段断了、观众会不会划走、情绪接不上”。
4. “这一组镜头有没有连续吸引力”。
5. “帮我检查观众为什么继续看”。
6. “每一镜之间缺少钩子、信息债、情绪债”。
7. “整条 Seedance 能不能剪成连续叙事”。

如果只是单个镜头呼吸问题，先走镜头呼吸、情绪停顿与节奏余波导演引擎。  
如果是整片结构问题，先走场次节拍、全片情绪弧线与中段升级导演引擎。  
如果是镜头接不上，先走镜头衔接、转场与蒙太奇语法库。  
本协议负责把这些能力串成观众连续观看的心跳线。

## 3. 观众心跳线

每条片至少要有 5 个心跳点：

```text
第一跳：我为什么停下？
第二跳：我想知道什么？
第三跳：事情怎么变难了？
第四跳：人物/产品/规则发生了什么变化？
第五跳：我看完记住什么，或想接着看什么？
```

不同类型的心跳：

| 类型 | 第一跳 | 中段心跳 | 结尾心跳 |
| --- | --- | --- | --- |
| 短剧 | 身份/关系/危险问题 | 权力关系换手 | 站队或追更问题 |
| 创意广告 | 可见痛点 | 产品动作带来变化 | 品牌记忆帧或转化入口 |
| 可爱治愈 | 小主体遇到大任务 | 失败后温柔介入 | 可截图松动瞬间 |
| 打斗特效 | 空间压力和目标 | 接触点升级 | 受力结果和反应 |
| 情感短片 | 没说出口的缺口 | 旧物或声音触发 | 余味动作 |
| 高概念短片 | 反常规则 | 三次规则证明 | 角色选择 |
| 爆款视频 | 第一帧信息债 | 3-6 秒一次新信息 | 评论点或反转余味 |

## 4. 镜头心跳字段

每个镜头都要写清这 7 个字段：

```text
观众问题：
这一镜让观众想知道什么？

新增信息：
这一镜比上一镜多知道了什么？

情绪变化：
观众是更紧张、更心疼、更想笑、更相信，还是更想知道答案？

动作证据：
这个变化通过哪个动作、道具、产品结果或表演反应被看见？

剪辑钩子：
用动作、视线、声音、反应还是信息差接到下一镜？

不能断的线：
角色、道具、空间、情绪或声音里哪一条必须继承？

下一镜债务：
下一镜必须偿还什么问题，或继续加什么压力？
```

## 5. 情绪断电警报

以下情况说明观众心跳断了：

| 断电表现 | 观众感受 | 第一刀 |
| --- | --- | --- |
| 镜头只是展示 | 不知道为什么继续看 | 加观众问题或动作目标 |
| 每镜都像封面 | 没有推进 | 给每镜不同信息变化 |
| 中段重复同一情绪 | 疲劳 | 加新阻碍、新证据或新视角 |
| 反应镜缺失 | 不知道结果重要不重要 | 补人物反应或产品确认 |
| 声音每镜重置 | 情绪断开 | 用声音桥或结尾回声 |
| 角色状态跳变 | 不信 | 补上一镜出点和本镜入点 |
| 广告证明断 | 不相信卖点 | 补产品动作和可见变化 |
| 短剧压力断 | 不想追 | 把关系代价提前 |

判断句：

```text
这不是缺一个漂亮镜头，是缺一个让观众继续看的问题。
```

## 6. 心跳线修复方法

### 6.1 补信息债

适合：开头漂亮但不抓人。

```text
第一帧先让观众欠下一个问题：
为什么这个东西在这里？
这个人为什么不敢说？
这个产品能不能真的解决？
这个规则会带来什么后果？
```

### 6.2 补情绪债

适合：人物行为有了，但观众不在乎。

```text
让人物先有一个小缺口、小害怕、小硬撑或小选择。
观众不是看事件，是看他会不会撑住。
```

### 6.3 补证明债

适合：广告或产品片中段发虚。

```text
每 3-6 秒补一次可见变化：
痛点 -> 产品动作 -> 微距证据 -> 结果变化 -> 人物确认。
```

### 6.4 补压力债

适合：短剧、打斗、悬疑中段掉速。

```text
给阻碍者一次新动作，或让空间更窄、出口更远、选择代价更高。
```

### 6.5 补声音债

适合：画面能接，情绪接不上。

```text
用同一个声音跨镜：
门响、机器声、呼吸、旧物声、环境底噪、画外短句或静音点。
```

### 6.6 补反应债

适合：动作发生了，但观众不知道该怎么感受。

```text
动作后补一个短反应：
停半秒、看一眼、手松开、肩膀落下、众人安静、产品结果被确认。
```

## 7. 继续观看债务预算

观众愿意继续看，不是因为一直被吊胃口，而是因为每一小段都在“还一点、再欠一点”。  
每 2-3 个镜头必须同时存在一个未解问题、一个局部回报和一个新压力/新证据/新反应。

### 7.1 健康债与坏债

| 债务状态 | 表现 | 观众感受 | 第一刀 |
| --- | --- | --- | --- |
| 健康债 | 问题具体、能被看见、计划在 1-3 镜内局部偿还 | 想等答案 | 保留，并写清偿还镜头 |
| 坏债：太虚 | 只说“会怎样”“有秘密”，没有动作或证据 | 被空话吊着 | 换成具体道具、台词反应或空间压力 |
| 坏债：太多 | 同时欠身份、关系、产品、规则、反转 | 糊涂 | 只留一个主债，其余后移或删掉 |
| 坏债：太久 | 连续 3 镜以上只加债不还债 | 不信你会给答案 | 立刻给微回报或反应确认 |
| 坏债：还光 | 连续 2 镜只解释、只兑现、只总结 | 无聊 | 加新代价、新选择、新阻碍或新余味 |

### 7.2 还债加债平衡表

逐镜检查时增加一列“债务动作”：

| 债务动作 | 适合位置 | 写法 | 禁用 |
| --- | --- | --- | --- |
| 开债 | 第一帧、段落入口、反转前 | 让观众产生一个可回答的问题 | 抽象悬念、假神秘 |
| 微还 | 2-3 镜内 | 给一个局部答案、反应或证据 | 一次把全部解释完 |
| 加压 | 微还之后 | 答案带来更高代价、更窄空间或更难选择 | 原地重复同一压力 |
| 转债 | 中段换气 | 从信息债转成情绪债、证明债或压力债 | 换成无关新话题 |
| 留债 | 结尾或追更口 | 留一个自然余味、站队或下一集问题 | 硬诱导评论、承诺必爆 |

### 7.3 连续性刹车

```text
连续两镜只加债不还债：
第一刀不是再加悬念，而是给一个微回报，让观众确认自己没有白等。

连续两镜只还债不加债：
第一刀不是再解释，而是让答案制造后果、选择、压力或记忆点。

一镜同时欠太多债：
第一刀只保留主债；副债改成反应、道具伏笔或下一段入口。

一段还债没有动作证据：
第一刀补可见变化，不能只用旁白、字幕或口号解释。
```

## 8. 输出模板

当用户要求检查成片感、节奏连续、观众为什么继续看时，默认输出：

```text
我先看观众心跳线：

一句话判断：
这条片现在断在【位置/段落/镜头】。

五个心跳点：
第一跳：观众为什么停下？
第二跳：观众想知道什么？
第三跳：事情怎么变难？
第四跳：发生了什么可见变化？
第五跳：结尾记住什么或想接着看什么？

逐镜心跳表：
镜头 | 观众问题 | 新增信息 | 情绪变化 | 动作证据 | 剪辑钩子 | 下一镜债务

继续观看债务预算：
段落 | 当前主债 | 本段微还 | 本段新债/加压 | 债务是否健康 | 第一刀

最大断电点：
【只写一个主断点】

第一刀修复：
【补信息债 / 情绪债 / 证明债 / 压力债 / 声音债 / 反应债】

不能动的优点：
【保留最强镜头或最强情绪】

通过标准：
1.
2.
3.
```

## 9. 与其他能力衔接

默认顺序：

```text
情绪命题、观众代入与人物选择
-> 场次节拍、全片情绪弧线与中段升级
-> 观众心跳线与情绪连续性协议
-> 镜头衔接、转场与蒙太奇语法库
-> 覆盖镜头、剪辑保险与场景可剪性导演引擎
-> 输出审片评分与升级闸门
```

分工：

1. 情绪命题负责“观众为什么在乎”。
2. 场次节拍负责“整条片分几口气”。
3. 本协议负责“每一口气之间观众心里不断电”。
4. 镜头衔接负责“画面、动作和声音怎么接”。
5. 覆盖镜头负责“主镜失败时怎么剪起来”。
6. 审片评分负责“最终质量和第一刀升级”。

## 10. 自检闸门

输出前检查：

1. 有没有写第一跳到第五跳？
2. 每镜有没有观众问题？
3. 每镜有没有新增信息或情绪变化？
4. 有没有动作证据，而不是只写情绪词？
5. 有没有指出最大断电点？
6. 有没有只给一个第一刀修复？
7. 有没有写下一镜债务？
8. 有没有用声音、反应或动作把镜头接住？
9. 有没有检查连续 2-3 镜内的开债、微还和加压是否平衡？

## 11. 最小合格线

一次观众心跳线检查至少要输出：

1. 一句话判断。
2. 五个心跳点。
3. 最大断电点。
4. 第一刀修复。
5. 不能动的优点。
6. 继续观看债务预算。
7. 通过标准。

少一项，就只是节奏点评，不是观众连续性检查。
