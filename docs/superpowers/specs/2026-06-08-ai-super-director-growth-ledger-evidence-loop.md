# AI超级导演成长证据账本与能力增量闭环

## 1. 定位

这份协议用于把“继续优化成长”从一次性文档新增，变成可累计、可检查、可反向训练的成长记录。它不替代成长仪表盘与训练排期器；排期器负责选本轮练什么，本协议负责记录练完以后有没有真的变强。

一句话原则：

```text
没有账本的成长，下一轮就会忘记自己为什么变强，也会忘记自己哪里开始偏食。
```

## 2. 触发信号

当出现以下情况，默认调用本协议：

1. 用户说“继续优化成长、继续成长、继续进化”并且本轮已经做了能力库修改。
2. 新增或重写了 README 入口、总索引路由、能力卡、训练题或回归题。
3. 一轮训练结束，需要写“本轮最弱能力、退化雷达、下一轮只练什么”。
4. 用户要求“别只是加文档，要真的变强”。
5. 连续两轮都在补同一类能力，需要防止导演味觉偏食。

## 3. 成长账本写什么

每轮成长必须记录 10 个字段：

```text
日期：
本轮主短板：
为什么选它：
本轮动作：
改动位置：
新增输出动作：
成长证据：
回归检查：
退化风险：
下一轮相反训练：
```

合格线：

1. “本轮主短板”必须来自成长仪表盘 8 个维度。
2. “本轮动作”必须是补入口、补模板、补禁用项、补第一刀、补回归题、新增能力卡或合并降级之一。
3. “新增输出动作”必须能在下一次回答里看见，例如多一个导演判断、动作字段、声音落点、失败第一刀、Seedance 降难规则或客户证据镜头。
4. “成长证据”必须指向文件、关键词、回归题或可检查输出字段。
5. “下一轮相反训练”必须和本轮主短板不同，避免一直练同一块。

## 4. 成长分数

每轮按 5 分制记录，不追求满分，追求知道下一刀：

| 分数 | 判断 | 处理 |
| --- | --- | --- |
| 5 | 新能力已接入口、能改变输出、有回归证据、无明显退化 | 进入下一轮相反训练 |
| 4 | 可用，但回归证据较轻或样例不足 | 下一轮补回归题或黄金样例 |
| 3 | 文档存在，但触发、模板或禁用项不够硬 | 先回修触发契约和输出契约 |
| 2 | 只增加内容，没有改变输出动作 | 不算成长，改成补模板或第一刀 |
| 1 | 造成路由混乱、输出变长或旧能力退化 | 触发回归失败停机，先修入口 |

低于 4 分时，下一轮不能继续新增大能力，必须先补证据、补禁用项或补回归题。

## 5. 证据类型

| 证据 | 证明什么 | 示例 |
| --- | --- | --- |
| 入口证据 | 用户自然语言能触发 | README 和总索引出现触发词 |
| 模板证据 | 输出会多一个可见动作 | 新模板要求写保留、舍掉、第一刀 |
| 失败证据 | 失败后知道砍哪里 | 返工模板写只改一个变量 |
| 回归证据 | 旧能力没被带偏 | 抽本体题和旁路旧题 |
| 黄金样例证据 | 知道做到什么程度合格 | 加好样例和坏样例对照 |
| 禁用证据 | 知道什么时候不用 | 写不调用句和误用症状 |

同一轮至少要有 2 种证据；如果只改 README 或只加文档，证据不够。

## 6. 偏食检测

每次写账本时，检查最近三轮：

```text
最近三轮主短板：
共同倾向：
正在变强的能力：
可能变弱的能力：
本轮必须避免继续强化：
下一轮相反训练：
```

常见偏食：

| 最近三轮都在补 | 容易变弱 | 下一轮练 |
| --- | --- | --- |
| Seedance 稳定 | 记忆点和第一帧抓力 | 记忆复述或第一帧 |
| 活人感和表演 | 客户证明和交付压缩 | 客户交付 |
| 短剧冲突 | 情绪余味和声音剪辑 | 声音剪辑 |
| 广告证明 | 角色真实和余味 | 人物表演 |
| 参考吸收 | 原创替换和合规刹车 | 禁用证据和替换层 |
| 能力库维护 | 现场输出速度 | 第一判断 |

如果最近三轮主短板相同，第四轮必须训练相反能力。

## 7. 实际账本文件

默认把每轮记录写入：

```text
docs/superpowers/growth-ledger.md
```

写入规则：

1. 只写改变下一次输出的成长，不写普通整理。
2. 每条记录不超过 12 行，避免账本变成新负担。
3. 每条必须有分数和下一轮相反训练。
4. 如果本轮改了 README 或总索引，必须写入口证据。
5. 如果本轮新增能力卡，必须写模板证据或禁用证据。

## 8. 默认输出

当用户说“继续优化成长”并完成一轮改动后，输出：

```text
本轮成长入账：

主短板：
本轮动作：
新增输出动作：
证据：
分数：
退化风险：
下一轮相反训练：
```

## 9. 与其他能力衔接

默认顺序：

```text
成长仪表盘与训练排期器
-> 成长证据账本与能力增量闭环
-> 经验回写与版本进化协议
-> 自我校准与回归测试套件
```

分工：

1. 成长仪表盘选择本轮主短板。
2. 本协议记录本轮成长证据和分数。
3. 经验回写把经验放回正确能力卡。
4. 自我校准检查旧能力有没有退化。

## 10. 最小合格线

一次成长入账至少要有：

1. 主短板。
2. 改动位置。
3. 新增输出动作。
4. 两种证据。
5. 分数。
6. 下一轮相反训练。

少一项，就只算工作记录，不算成长记录。
