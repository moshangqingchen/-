# AI超级导演悬疑信息差、空间压迫与反转伏笔引擎

## 1. 定位

这份引擎用于处理悬疑短片、反转短片、悬疑广告、短剧秘密线、惊悚但不血腥的氛围片、情感悬疑、特效悬疑和品牌微电影里的未知感。

悬疑不是把信息藏起来不说，也不是把画面拍黑。真正有效的悬疑是：观众看见一个不该存在的细节，知道一点但不够，角色的行动不断改变信息差，最后反转能重新解释前面的画面。

默认原则：

1. 第一帧必须有异常信息，不从背景介绍开始。
2. 每段悬疑都要明确“观众知道什么、角色知道什么、镜头故意不让谁知道什么”。
3. 伏笔必须是画面或声音，不只靠台词解释。
4. 反转必须回收至少一个前面出现过的细节。
5. 氛围不能代替事件，压迫感必须推动人物选择。
6. Seedance 2.0 中不要依赖可读手机字、合同字、屏幕字，关键文字默认后期添加。

## 2. 信息差三角

每个悬疑段落先填三角：

```text
观众知道：
角色A知道：
角色B知道：
镜头暂时隐藏：
```

常用结构：

| 类型 | 信息安排 | 适合 |
| --- | --- | --- |
| 观众多知道一点 | 观众看见道具或危险，角色没看见 | 紧张、惊悚、追逐 |
| 角色多知道一点 | 角色藏着秘密，观众只看见异常反应 | 短剧反转、情感悬疑 |
| 双方都误读 | 观众和角色都以为A，结尾证明是B | 反转短片、创意广告 |
| 镜头多知道一点 | 镜头反复经过细节但不解释 | 复看型悬疑、品牌微电影 |

规则：

1. 不要同时隐藏所有信息。
2. 每 6-12 秒给一个小信息回报。
3. 反转前必须让观众有机会回想起伏笔。

## 3. 第一帧异常

第一帧不解释背景，直接给一个不正常但可看懂的东西。

异常类型：

- 空间异常：门开着、椅子倒着、灯只亮一盏。
- 道具异常：桌上多了一杯热水、玩具沾着雨水、录音机自己转动。
- 行为异常：角色在不该沉默的地方沉默。
- 身份异常：熟悉的人做出不属于他的动作。
- 声音异常：先听见不该出现的脚步声或铃声。
- 时间异常：同一个动作像发生过第二遍。

输出句：

```text
第一帧我会直接给异常：[具体画面]，观众先问“为什么会这样”，再让角色进入。
```

## 4. 空间压迫

悬疑空间要让观众知道危险从哪里来。

空间关系：

| 空间元素 | 功能 | 镜头处理 |
| --- | --- | --- |
| 门 | 未知入口、逃生口、偷听口 | 门缝视角、过肩、固定中景 |
| 桌子 | 秘密夹在中间 | 俯拍、手部特写、对峙中景 |
| 走廊 | 逼近和不可回头 | 长焦压缩、低速跟拍 |
| 窗 | 外部注视、过去记忆 | 反射、背影、声音先行 |
| 角落 | 隐藏、被困、旁观 | 静止镜头、局部遮挡 |
| 楼梯 | 权力高低、危险方向 | 低机位或俯视 |

规则：

1. 先定危险方向：前、后、门外、桌下、镜头外。
2. 角色移动必须改变信息差：靠近秘密、远离出口、挡住证据、露出道具。
3. 不用乱晃镜头制造紧张；让空间本身压住人。

## 5. 伏笔设计

伏笔不是藏得越深越好，而是第一次看不刺眼，第二次看有意义。

伏笔类型：

| 类型 | 首次出现 | 反转回收 |
| --- | --- | --- |
| 道具伏笔 | 旧照片、杯子、钥匙、录音机 | 证明身份、时间、关系 |
| 动作伏笔 | 整理袖口、避开眼神、摸伤口 | 揭示紧张、撒谎、真实动机 |
| 声音伏笔 | 脚步声、铃声、风声、机器声 | 解释谁来过、何时发生 |
| 空间伏笔 | 门没关、椅子方向、窗帘动 | 证明路线或隐藏者 |
| 光线伏笔 | 某处一直暗、反射出现影子 | 揭示旁观者或真相 |

伏笔规则：

1. 伏笔第一次出现不要被台词点破。
2. 每个反转最多回收 1-2 个核心伏笔。
3. 伏笔必须能被画面或声音表现。
4. 手机、合同、屏幕文字只做后期补充，不作为 Seedance 画面唯一证据。

## 6. 声音先行

悬疑里声音常常比画面先到。

声音用法：

- 声音先画面半秒：脚步声先响，角色才回头。
- 声音错位：看见空走廊，却听见门内杯子落下。
- 声音被压住：环境声突然变低，观众意识到角色在听。
- 声音回收：结尾同一个声音再次出现，意义改变。
- 声音误导：观众以为是危险，其实是证据启动。

禁用：

- 全程恐怖音乐压满。
- 每次异常都用大声惊吓。
- 声音没有来源，无法回收。

## 7. 反转兑现

反转不是“突然换答案”，而是“让之前的画面有了第二层意思”。

反转公式：

```text
表面答案
-> 伏笔再次出现
-> 角色反应改变
-> 真答案露出
-> 观众回想第一帧
```

常见反转：

| 反转类型 | 用法 |
| --- | --- |
| 身份反转 | 他不是受害者，是守秘密的人 |
| 时间反转 | 这不是第一次发生 |
| 关系反转 | 看似陌生，其实早有关系 |
| 动机反转 | 他不是逃避，是在保护 |
| 道具反转 | 普通物件原来是证据 |
| 广告反转 | 产品不是解决表面问题，而是解决隐藏痛点 |

规则：

1. 反转后给一个短反应镜头，不急着解释。
2. 如果需要解释，用后期字幕或画外音，不让 Seedance 生成复杂屏幕字。
3. 反转不能推翻所有前文，只能重新解释前文。

## 8. 悬疑广告

悬疑广告必须最终证明卖点。

结构：

```text
第一帧异常
-> 用户误读问题
-> 产品动作介入
-> 伏笔回收
-> 真正痛点露出
-> 产品证明
-> 品牌记忆帧
```

规则：

1. 悬疑只负责停留，产品负责兑现。
2. 不让悬疑压过卖点。
3. 产品动作必须可见。
4. 品牌字默认后期添加。

## 9. Seedance 2.0 提示词字段

悬疑镜头提示词必须写清：

```text
第一帧异常：
观众知道：
角色知道：
隐藏信息：
危险方向：
伏笔道具/声音：
空间压迫：
反转回收：
字幕安全区：
禁止项：
```

单镜提示词骨架：

```text
固定中近景，[角色]站在[空间位置]，[异常道具或声音]已经出现但不解释，危险方向来自[门外/身后/桌下/镜头外]，角色做一个克制反应，[伏笔细节]清楚但不突出，镜头缓慢推进，环境声降低，悬疑来自信息差和空间压迫，不生成可读文字、手机字、Logo或字幕，预留干净字幕安全区。
```

## 10. 输出协议

当用户要求悬疑、反转、惊悚氛围、秘密、信息差、压迫感或伏笔时，默认先输出：

```text
我会这样拍：
第一帧异常：
信息差三角：
危险方向：
空间压迫：
核心伏笔：
声音先行：
反转兑现：
Seedance 2.0提示词：
```

## 11. 审片自检

1. 第一帧是否有异常信息？
2. 观众和角色各知道什么是否清楚？
3. 危险方向是否明确？
4. 伏笔是否能由画面或声音表现？
5. 反转是否回收前面的细节？
6. 悬疑是否推动人物选择，而不是只做氛围？
7. 如果是广告，卖点是否被证明？
8. Seedance 提示词是否避免依赖不可控文字？
