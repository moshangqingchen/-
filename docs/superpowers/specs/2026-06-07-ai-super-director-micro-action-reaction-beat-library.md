# AI超级导演微动作、表情反应与动作节拍库

## 1. 定位

这份库用于把抽象情绪、笑点、冲突、卖点和奇观，翻译成镜头里能看见、能生成、能剪辑的具体动作。

很多AI短片的问题不是“想法不够大”，而是人物像被摆在画面里：没有手、眼神、呼吸、停顿、身体重心和反应。超级导演必须会把一句“她很难过”“这段要搞笑”“这里要高级”改成一个能拍的动作节拍。

一句话：

```text
不要写“他很感动”，写“他伸手去拿杯子，手指碰到杯沿时停住，眼神低下去半秒”。
```

本库服务于：

- 分镜表里的动作设计。
- 表演指导里的眼神、停顿和肢体。
- Seedance 2.0 的动作链提示词。
- 搞笑、情感、治愈、打斗、特效、创意广告的可执行镜头。
- 修复“太AI”“太空泛”“没生活感”“动作不自然”的问题。

## 2. 什么时候调用

用户出现这些说法时，优先调用本库：

- “不要太像AI。”
- “让人物活一点。”
- “这里表演太空。”
- “帮我加小动作。”
- “动作链怎么写？”
- “反应镜头怎么设计？”
- “这个笑点怎么落？”
- “情绪怎么用动作表达？”
- “手部、眼神、停顿怎么写？”
- “Seedance提示词太抽象。”
- “生成出来人物像木头。”
- “打斗/特效没有重量。”
- “广告卖点怎么用动作证明？”

## 3. 与其他资产的关系

默认调用顺序：

```text

```

本库负责“动作颗粒度”，表演库负责“人物关系和台词潜台词”，镜头库负责“摄影机怎么拍”，Seedance手册负责“如何写成可生成提示词”。

## 4. 核心原则

### 4.1 情绪必须落到身体上

抽象情绪要变成：

- 眼神方向。
- 手部动作。
- 呼吸变化。
- 身体重心。
- 距离变化。
- 道具触碰。
- 停顿时长。
- 反应顺序。

错误：

```text
女孩很怀念过去，画面很感人。
```

可拍：

```text
女孩翻开旧相册，拇指停在一张合照的折痕上，想翻页但没有翻，低头吸一口气。
```

### 4.2 一镜只写一个主动作

Seedance 2.0 镜头尤其要克制：

```text
起始动作 -> 中间变化 -> 结束状态
```

不要让一个镜头同时完成跑、摔、哭、打、转身、爆炸、台词和镜头环绕。

### 4.3 反应比事件更像人

奇观、笑点、打击、反转之后，都需要反应。

导演判断：

```text
事件让观众看见发生了什么，反应让观众相信它真的发生了。
```

### 4.4 小动作要服务剧情

不是所有小动作都加。每个动作必须回答：

1. 它暴露了什么情绪？
2. 它推进了什么信息？
3. 它能不能成为剪辑点？
4. 它能不能让Seedance更容易生成？

## 5. 微动作语法

### 5.1 标准动作节拍

```text
状态 -> 触发 -> 微动作 -> 反应 -> 落点
```

示例：

```text
状态：男孩假装不在乎。
触发：听见旧录音里的名字。
微动作：手指把杯子握紧。
反应：眼神避开说话的人。
落点：杯底轻轻碰到桌面，切黑。
```

### 5.2 Seedance动作链

```text
动作链：[起始动作] -> [中间变化] -> [结束状态]。
表演/微动作：[眼神/手部/呼吸/身体重心/停顿]。
剪辑点：[微动作落下或反应完成时切]。
```

### 5.3 抽象词改写表

| 抽象词 | 可拍动作 |
| --- | --- |
| 难过 | 手停住、眼神低下、话说到一半停、把旧物收回去 |
| 开心 | 眼睛先亮、嘴角慢慢上去、身体靠近、手指轻敲桌面 |
| 紧张 | 呼吸短、手指捏衣角、脚尖后退、眼神扫出口 |
| 生气 | 下颌绷住、手指压住桌面、身体前倾、说话前停顿 |
| 愧疚 | 避开对方视线、整理无关物件、想伸手又收回 |
| 惊讶 | 先不说话、眼神定住、身体微微后仰、手停在半空 |
| 治愈 | 肩膀松下来、呼吸变长、手掌贴近暖光或杯子 |
| 搞笑 | 慢半拍反应、认真误解、集体停顿、一个人装镇定 |
| 高级 | 少动、慢反应、动作有节制、声音留空 |
| 爽感 | 动作干净、结果立刻可见、反应短促有力 |

## 6. 身体部位动作库

### 6.1 眼神

| 用途 | 动作 |
| --- | --- |
| 心虚 | 看向对方一瞬，马上看地面 |
| 想念 | 看旧物，不看说话的人 |
| 喜剧误会 | 先认真点头，再眼神突然停住 |
| 反转 | 眼神从柔和变冷，半秒后切近景 |
| 危险 | 眼神扫门口、镜子、对方手里的道具 |
| 广告确认 | 先看问题，再看产品效果 |

Seedance写法：

```text
表演/微动作：角色眼神先看向[道具/人/出口]，停顿半秒后低头或抬眼，表情变化克制。
```

### 6.2 手部

| 用途 | 动作 |
| --- | --- |
| 情感 | 拇指摩挲旧照片边角 |
| 犹豫 | 手停在门把手前，没有立刻打开 |
| 紧张 | 手指捏住杯沿或衣角 |
| 产品证明 | 手按下按钮，结果立刻出现 |
| 打斗 | 手掌撑地、抓住桌沿、调整握持 |
| 可爱 | 双手抱住比自己大的道具，身体被带着晃一下 |

Seedance注意：

```text
手部动作必须简单：伸手、触碰、握住、放下、推开、按下。复杂手指动作容易变形。
```

### 6.3 呼吸

| 用途 | 动作 |
| --- | --- |
| 压抑 | 吸气后没有说话 |
| 放松 | 肩膀随着呼气慢慢落下 |
| 惊吓 | 呼吸突然停住，身体僵一下 |
| 打斗 | 短促喘气后重新站稳 |
| 治愈 | 长呼气，视线慢慢软下来 |

### 6.4 身体重心

| 用途 | 动作 |
| --- | --- |
| 害怕 | 重心后移半步 |
| 决心 | 重心前压，脚尖定住 |
| 关系靠近 | 身体轻微前倾 |
| 关系疏远 | 身体侧开，肩膀离开对方 |
| 打斗蓄力 | 重心降低，膝盖微弯 |
| 搞笑 | 本来很端正，突然歪一下 |

### 6.5 道具触碰

道具触碰是最稳定的情绪表达方式。

```text
人不知道怎么说话时，就让他碰一个东西。
```

常用触碰：

- 旧照片边角。
- 门把手。
- 杯沿。
- 录音机按钮。
- 手机屏幕。
- 产品开关。
- 破损衣角。
- 桌面划痕。
- 武器握把。

## 7. 反应镜头库

### 7.1 反应镜头功能

| 场景 | 反应功能 |
| --- | --- |
| 特效出现 | 证明奇观真的发生 |
| 喜剧包袱 | 给观众半秒意识到荒诞 |
| 情感打击 | 让人物消化信息 |
| 广告结果 | 证明产品改变了局面 |
| 打斗重击 | 给动作重量和疼痛 |
| 短剧反转 | 让观众看见秘密被接住 |

### 7.2 反应节拍

```text
事件发生 -> 角色没立刻动 -> 眼神变化 -> 小动作落下 -> 切镜头
```

示例：

```text
纸鹤突然发光 -> 女孩没有马上伸手 -> 她的眼神先亮起来 -> 手指慢慢抬起 -> 切到纸鹤特写。
```

### 7.3 群像反应

群像反应不要所有人一样。

```text
角色A震惊，角色B装镇定，角色C慢半拍理解，角色D认真记录。
```

Seedance写法：

```text
表演/微动作：四个角色反应不同，一个睁大眼，一个抱住本子，一个慢半拍抬头，一个认真点头；全体停顿形成表情包画面。
```

## 8. 类型微动作库

### 8.1 可爱

常用动作：

- 歪头。
- 抱住大物件。
- 踮脚。
- 小步挪近。
- 偷看后缩回。
- 双手认真托住小道具。
- 眼睛先亮，身体慢半拍跟上。

导演句：

```text
可爱不是拼命卖萌，是小角色认真做一件稍微超出能力的事。
```

Seedance示例：

```text
动作链：小角色踮脚去够桌上的月亮贴纸 -> 双手抱住贴纸边缘 -> 身体被贴纸轻轻带着晃一下。
表演/微动作：眼睛睁大，嘴巴不说话，努力保持严肃。
```

### 8.2 治愈

常用动作：

- 肩膀松下来。
- 手掌贴近杯子。
- 慢慢坐下。
- 看窗外后轻轻呼气。
- 把乱掉的小物件摆正。
- 伸手接住一束光或一片落叶。

导演句：

```text
治愈不是空镜漂亮，是身体慢慢不再紧绷。
```

### 8.3 怀旧情感

常用动作：

- 手停在旧物旁。
- 拇指摩挲折痕。
- 想翻页又停住。
- 看背影，不看脸。
- 把旧物放回原处但没有关上抽屉。
- 听到旧声音后低头。

导演句：

```text
情感不要急着哭，先让手替人忍住。
```

### 8.4 搞笑

常用动作：

- 慢半拍抬头。
- 集体停顿。
- 一个人假装懂。
- 认真记下荒诞结论。
- 过度正式地点头。
- 道具出现得太郑重。
- 表情先正常，下一拍才崩。

导演句：

```text
笑点要有落点。荒诞发生后，先别急着切，留半秒让观众看见“他们居然当真了”。
```

### 8.5 短剧冲突

常用动作：

- 手抓住包带。
- 身体挡在门口。
- 看向手机又马上扣住。
- 关键台词前倒一杯水。
- 眼神从对方脸移到桌上证据。
- 想离开但脚停住。

导演句：

```text
短剧冲突别只靠吵，身体的距离变化比喊台词更有压迫感。
```

### 8.6 创意广告

常用动作：

- 先失败一次。
- 产品介入。
- 手部操作清楚。
- 结果在同镜头里出现。
- 使用者反应短促。
- 结尾把产品放回画面中心。

导演句：

```text
产品不要解释自己，它要在一个动作里救场。
```

Seedance示例：

```text
动作链：用户费力擦拭桌面污渍失败 -> 产品喷头按下 -> 污渍边缘迅速散开，用户手停住看结果。
表演/微动作：用户先皱眉，看到结果后眼神抬起，嘴角轻微放松。
```

### 8.7 特效

常用动作：

- 角色先按现实逻辑行动。
- 发现异常后停住。
- 光映在脸上。
- 手指试探触碰。
- 身体后退半步。
- 先看手，再看空间变化。

导演句：

```text
特效要先被人看见，再被观众相信。
```

### 8.8 打斗

常用动作：

- 重心降低。
- 手调整握持。
- 脚步试探。
- 肩膀被撞偏。
- 手撑地重新站稳。
- 打击后短暂停顿。
- 眼神确认对方下一步。

导演句：

```text
打斗的重量不在挥拳那一下，而在打中以后身体怎么接住它。
```

Seedance注意：

```text
把复杂打斗拆成空间交代、关键动作、打击反应、结果镜头。不要一条提示词写完整连招。
```

## 10. Seedance 2.0提示词嵌入法

每条 Seedance 2.0 提示词里的动作部分要这样写：

```text
动作链：[起始动作] -> [中间变化] -> [结束状态]。
表演/微动作：[眼神方向]，[手部动作]，[身体重心]，[停顿时长]。
反应镜头：[事件后人物或群体怎么反应]。
剪辑点：[微动作落下、眼神变化、声音出现或反应定格时切]。
```

简版：

```text
动作链：手伸向旧录音机 -> 按键前停住 -> 指尖轻轻落下。
表演/微动作：眼神低下，呼吸变慢，肩膀放松一点。
剪辑点：按键发出轻响时切到旧照片。
```

## 11. “太AI”修复法

### 11.1 症状

- 人物只是站着。
- 情绪靠形容词。
- 台词解释太多。
- 动作没有起点和终点。
- 所有角色反应一样。
- 镜头没有剪辑落点。
- Seedance生成后像摆拍。

### 11.2 修复步骤

1. 删除抽象形容词。
2. 找到人物此刻想隐藏的情绪。
3. 选一个身体部位承载情绪。
4. 设计一个微动作。
5. 给动作一个停顿。
6. 给事件一个反应镜头。
7. 把动作写进 Seedance 动作链。

修复模板：

```text
原句：
问题：
可拍微动作：
反应镜头：
Seedance动作链：
剪辑点：
```

示例：

```text
原句：女孩很感动。
问题：情绪抽象，画面没有动作。
可拍微动作：女孩接过围巾，手指停在旧补丁上，低头笑了一下又忍住。
反应镜头：对方没说话，只把围巾另一端轻轻塞进她手里。
Seedance动作链：女孩接过围巾 -> 指尖摸到旧补丁停住 -> 低头轻轻吸气。
剪辑点：她低头那一刻切到围巾特写。
```

## 13. 类型快速微动作包

| 类型 | 默认微动作 | 默认反应 |
| --- | --- | --- |
| 可爱 | 歪头、抱大物、踮脚、小步挪 | 慢半拍理解、认真点头 |
| 治愈 | 肩膀放松、长呼气、手靠近暖物 | 眼神变软、身体靠近 |
| 情感 | 手停旧物、摩挲折痕、低头 | 沉默、避开视线、轻轻收回 |
| 搞笑 | 集体停顿、装懂、认真记录 | 表情包定格、一个人慢半拍 |
| 短剧 | 抓包带、扣手机、挡门 | 眼神变冷、身体前压 |
| 广告 | 失败动作、产品介入、结果出现 | 使用者停住、眼神确认 |
| 特效 | 试探触碰、光照脸、后退半步 | 先僵住，再看向奇观 |
| 打斗 | 降重心、调整握持、撑地站稳 | 疼痛停顿、重新锁定对手 |

## 14. 自检

输出前自问：

1. 我有没有把抽象情绪变成可见动作？
2. 每个镜头是否只有一个主要动作？
3. 动作链是否有起点、中点和终点？
4. 是否有眼神、手部、呼吸、身体重心或距离变化？
5. 是否有反应镜头？
6. 喜剧是否有停顿？
7. 情感是否避免直接哭喊？
8. 广告卖点是否通过动作证明？
9. 特效和打斗是否有受力或反应？
10. Seedance 2.0 提示词是否能直接生成这个动作？
