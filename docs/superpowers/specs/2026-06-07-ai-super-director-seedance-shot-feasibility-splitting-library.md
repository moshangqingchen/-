# AI超级导演 Seedance 镜头可生成性、难度评分与拆镜决策库

## 1. 定位

这份库解决 Seedance 2.0 多镜头创作里的前置判断：一个镜头到底能不能一条生成？如果太难，是删、简化、拆镜、先测，还是换成更稳的导演方案？

AI生成连续性与故障修复库是在“生成坏了以后”救火，本库是在“写提示词以前”先把火苗掐掉。

一句话原则：

```text
真正厉害的导演，不是把所有东西塞进一镜，而是知道哪一秒必须拆开。
```

## 4. 可生成性总判断

每个关键镜头先做五项评分，每项 1 到 5 分：

| 维度 | 1分 | 3分 | 5分 |
| --- | --- | --- | --- |
| 主体数量 | 1个主体 | 2到3个主体 | 4个以上主体或群像同框 |
| 动作复杂度 | 一个动作 | 两到三个连续动作 | 跑、打、转身、拿道具、特效同时发生 |
| 运镜复杂度 | 固定或轻推 | 一个明确运镜 | 多运镜、环绕、快速跟拍、视角切换 |
| 空间和道具 | 单一稳定空间 | 有关键道具或轻微移动 | 多空间、道具交换、遮挡复杂 |
| 特效和文字 | 无特效无文字 | 单一特效或后期字幕 | 多层特效、可读文字、Logo、品牌字 |

总分判断：

| 总分 | 等级 | 处理 |
| --- | --- | --- |
| 5-8 | A 稳定镜头 | 可一条生成 |
| 9-13 | B 可控镜头 | 可一条生成，但提示词要克制 |
| 14-18 | C 高风险镜头 | 优先拆成2到4条 |
| 19-25 | D 不建议一条生成 | 重写分镜，拆成关键帧、动作、反应、结果 |

导演判断：

```text
如果一个镜头同时要求多人、快动作、复杂运镜、特效、道具和可读文字，它不是大片镜头，是失败率清单。
```

## 5. Seedance 稳定镜头规则

Seedance 2.0 默认稳镜头：

1. 4到6秒。
2. 一个主要主体。
3. 一个主要动作。
4. 一个主要运镜。
5. 一个明确入点。
6. 一个明确出点。
7. 空间和角色信息保持不变。
8. 可读文字、字幕、Logo和品牌字后期添加。
9. 情绪通过眼神、手部、停顿和反应镜头表达。
10. 复杂事件用“动作镜头 + 反应镜头 + 结果镜头”承接。

不稳定镜头信号：

- 一个镜头里有三个以上动作阶段。
- 角色从远景跑到近景还要说台词。
- 镜头又环绕又推近又升降。
- 四个以上角色同时做不同动作。
- 打斗要求多招连击和复杂接触。
- 特效从小异常直接炸成大奇观。
- 画面内要求清晰中文、Logo或品牌字。
- 主体被遮挡、快速出入画、频繁换方向。

## 6. 拆镜决策树

```text
这个镜头是否承担最强一帧？
-> 否：简化或删除。
-> 是：继续判断。

它是否有超过一个主要动作？
-> 是：按动作阶段拆。
-> 否：继续判断。

它是否有超过一个主要主体？
-> 是：先拍主体A动作，再切反应/关系镜头。
-> 否：继续判断。

它是否有复杂特效或打斗？
-> 是：先现实基准，再触发，再反应，再结果。
-> 否：继续判断。

它是否需要可读文字或品牌字？
-> 是：画面预留安全区，文字后期加。
-> 否：可一镜生成。
```

## 7. 拆镜语法

标准拆镜格式：

```text
原镜头目标：
风险因子：
保留的核心看点：
删除或后置的要求：
拆镜方案：
镜头1：入点 -> 主动作 -> 出点
镜头2：入点 -> 反应/结果 -> 出点
镜头3：入点 -> 变化/记忆帧 -> 出点
衔接方式：
每条 Seedance 2.0 提示词重点：
```

拆镜不是把提示词切碎，而是把因果切清楚：

```text
看见原因 -> 做出动作 -> 产生结果 -> 看见反应
```

## 8. 常用拆法

### 8.1 动作链拆法

适合：跑、拿、躲、推、打开、触碰、追逐。

```text
镜头1：看见目标。
镜头2：手或身体开始动作。
镜头3：动作接触关键物。
镜头4：结果发生。
镜头5：人物反应。
```

例子：

原镜头：

```text
女孩推开门，看见房间漂浮着发光纸鹤，她走进去伸手触碰，纸鹤变成光点围绕她。
```

拆成：

```text
镜头1：女孩推开门，看见房间里漂浮的纸鹤。
镜头2：女孩站在门口停住，手慢慢抬起。
镜头3：手指触碰最近的一只纸鹤。
镜头4：纸鹤变成少量光点，围绕手指一圈。
镜头5：女孩眼神亮起来，房间光线轻轻变化。
```

### 8.2 情绪拆法

适合：崩溃、想念、释怀、治愈、告别。

```text
镜头1：触发物。
镜头2：手部或眼神停顿。
镜头3：环境声或旧声音进入。
镜头4：人物做一个克制动作。
镜头5：留白或背影。
```

原则：不要把“大哭”当作情绪结果。情绪越重，动作越小。

### 8.3 打斗拆法

适合：追逐、攻防、摔倒、反击、武器或超能力。

```text
镜头1：空间交代，谁在左谁在右。
镜头2：攻击起手。
镜头3：接触或躲避。
镜头4：反应和身体结果。
镜头5：重新交代空间。
```

规则：

- 一条 Seedance 镜头只保留一次关键接触。
- 不用快剪遮盖动作因果。
- 每次接触后必须有反应或身体结果。
- 打斗中的第一人称只用于压迫感，不承担复杂招式。

### 8.4 特效拆法

适合：超能力、变形、漂浮、空间扭曲、能量爆发。

```text
镜头1：现实基准。
镜头2：小异常。
镜头3：角色反应。
镜头4：特效升级。
镜头5：结果镜头。
```

规则：

- 特效从小到大，不要第一秒就满屏爆发。
- 先让观众相信空间是真的，再让异常进入。
- 每次特效升级都要有角色反应。

### 8.5 群像拆法

适合：可爱搞笑群像、幼儿园、团队、多人对话。

```text
镜头1：群像建立，所有人位置清楚。
镜头2：主角色动作或台词。
镜头3：两个角色反应。
镜头4：集体反应或表情包收尾。
```

规则：

- 同框角色超过4个时，尽量让他们做同一类反应。
- 不要让每个角色同时做不同动作。
- 群像笑点靠反应层次，不靠画面塞满。

### 8.6 产品广告拆法

适合：卖点证明、前后对比、道具视角、信息流广告。

```text
镜头1：痛点动作。
镜头2：产品介入动作。
镜头3：细节证明。
镜头4：结果对比。
镜头5：品牌记忆帧。
```

规则：

- 一镜只证明一个卖点。
- 产品不要被口播介绍，要通过动作改变结果。
- 品牌字和卖点短句后期添加。

## 9. 降难方法

### 9.1 降主体

```text
从四人同时动作，改成一人主动作 + 两人反应 + 群像收尾。
```

### 9.2 降动作

```text
从跑过去、拿起、转身、躲避、反击，改成：看见 -> 伸手 -> 躲避 -> 结果。
```

### 9.3 降运镜

```text
从环绕加推近加升降，改成固定机位或轻推。
```

### 9.4 降特效

```text
从全屏爆炸，改成手部小光点、空气轻微波动、道具发光。
```

### 9.5 降文字

```text
从让模型生成清晰中文标语，改成画面留白，字幕和品牌字后期添加。
```

### 9.6 降时长

```text
从12秒复杂长镜头，拆成3条4秒镜头。
```

## 10. 先测哪一镜

项目进入生成前，先测这些镜头：

1. 主角标准镜头。
2. 核心场景标准镜头。
3. 产品或关键道具标准镜头。
4. 最强一帧。
5. 最难动作镜头。
6. 最难特效镜头。
7. 群像同框镜头。

先测原则：

```text
先测最容易翻车、但又不能删的镜头。
```

如果最难镜头连续失败三次，不继续硬生成，回到本库拆镜或降难。

Seedance 2.0 提示词嵌入示例：

```text

风险因子：单主体，单动作，轻推镜，无可读文字。
拆镜决策：保留为一条4秒镜头。
本镜保留：女孩手指靠近录音机按钮并停顿。
本镜删除或后置：不在本镜加入回忆画面，回忆另拆下一镜。

4秒竖屏视频镜头。
风格锁定：延续项目视觉圣经，暖色自然光、真实旧物质感保持不变。
空间锁定：旧木桌、录音机、窗边光线位置保持不变。
镜头身份：回忆视角。
主体：女孩的手和旧录音机按钮。
动作链：手指靠近按钮 -> 停半秒 -> 轻轻按下。
摄影：近景，眼平机位，轻微推近。
声音：按钮咔哒声，旧录音底噪轻轻进入。
后期文字规划：不生成可读文字，右上方留干净字幕区。
剪辑衔接：按钮咔哒声作为声音桥进入下一镜回忆。
避免：手指变形、录音机形状漂移、背景文字乱码、镜头突然飞离。
```

## 12. 类型专用决策

### 12.1 可爱搞笑

高风险：

- 群像同框又都做不同动作。
- 表情变化太多。
- 画面里塞满道具和文字。

稳法：

```text
群像建立 -> 主角色认真动作 -> 两人反应 -> 集体沉默或表情包。
```

### 12.2 治愈

高风险：

- 用大动作表达情绪。
- 长镜头里同时走路、哭、回忆、旁白。

稳法：

```text
静物触发 -> 手部微动作 -> 眼神停顿 -> 环境声留白。
```

### 12.3 怀旧情感

高风险：

- 现实和回忆在同一镜里复杂变换。
- 旧物、人物、年代场景同时变化。

稳法：

```text
旧物特写 -> 声音桥 -> 回忆单动作 -> 当下反应。
```

### 12.4 创意广告

高风险：

- 一镜证明多个卖点。
- 产品外形又要变化又要品牌字清楚。

稳法：

```text
痛点动作 -> 产品动作 -> 结果细节 -> 品牌记忆帧。
```

### 12.5 特效

高风险：

- 第一秒就全屏奇观。
- 人物、空间、道具、能量同时剧烈变化。

稳法：

```text
现实基准 -> 小异常 -> 反应 -> 升级 -> 结果。
```

### 12.6 打斗

高风险：

- 一镜多招连击。
- 身体接触复杂。
- 第一人称同时承担闪躲、反击和空间交代。

稳法：

```text
空间交代 -> 起手 -> 接触/躲避 -> 反应 -> 重新交代。
```

### 12.7 短剧

高风险：

- 开场同时交代人物关系、秘密、争吵和反转。
- 多人对话站位不清。

稳法：

```text
一句冲突台词 -> 过肩关系 -> 视线匹配秘密 -> 反应近景 -> 悬念。
```

## 14. 自检

输出 Seedance 多镜头方案前，AI超级导演自问：

1. 每个关键镜头是否做了可生成性评级？
2. 是否有镜头同时承担太多主体、动作、运镜、特效和文字？
3. C级和D级镜头是否已经拆镜、简化或先测？
4. 每条 Seedance 提示词是否只有一个主要动作和一个主要运镜？
5. 群像、打斗、特效和产品镜头是否先保留空间和动作因果？
6. 可读中文、Logo和品牌字是否后期添加？
7. 拆镜后是否补了入点、出点和衔接方式？
8. 是否先测试最难但不能删的镜头？
9. 是否避免为了“炫”而牺牲生成稳定性？
10. 这套拆镜是否让创意更稳、更清楚，而不是把镜头拆碎？
