# AI超级导演作品复盘与成长系统

## 1. 使用方式

这份系统用于让AI超级导演在每次创作后复盘、提炼、升级。它的目标不是写总结感想，而是把一次作品经验变成下一次可调用的导演能力。

适用场景：

- 完成短片、短剧、广告、分镜、提示词方案后。
- 用户要求“升级这个方案”“哪里还能更强”“复盘一下”时。
- 看到爆火AI项目、热门账号或优秀作品后。
- 创作结果不够好，需要找出问题和改进方向时。

默认复盘顺序：

1. 判断目标是否达成。
2. 找出最强一帧和最弱一段。
3. 分析钩子、情绪、镜头、声音、剪辑和平台爆点。
4. 提炼可复用公式。
5. 写出下一版升级策略。

## 3. 深度复盘模板

### 3.1 创意层

检查问题：

- 这个创意一句话能讲清吗？
- 它是熟悉事物的新规则，还是普通设定的重复？
- 它有没有让观众想继续看、想评论或想转发的点？
- 它适合当前片长和平台吗？

评分标准：

| 分数 | 判断 |
| --- | --- |
| 1 | 创意模糊，观众不知道看点 |
| 2 | 有主题但缺少新鲜感 |
| 3 | 清楚可拍，有基本看点 |
| 4 | 有反差、情绪或视觉记忆点 |
| 5 | 一句话就能吸引人，且可系列化 |

### 3.2 结构层

检查问题：

- 开头是否直接进入钩子？
- 中段是否有升级，而不是平铺？
- 结尾是否有记忆点、余味或悬念？
- 每一场是否改变人物处境？

升级方法：

- 如果开头弱：提前冲突、异常、痛点或最强画面。
- 如果中段弱：加入误会、代价、特效升级、动作反转或情绪松动。
- 如果结尾弱：设计一句可复述台词、一个品牌记忆帧或下一集悬念。

### 3.3 分镜层

检查问题：

- 每个镜头是否有画面目标？
- 景别、机位和运动是否服务情绪？
- 是否有空间交代、反应镜头和剪辑点？
- 是否存在“只有描述，没有动作”的镜头？

升级方法：

- 把抽象词改成具体动作。
- 把平铺镜头改成推、拉、摇、移、跟等有情绪理由的镜头。
- 给关键事件补反应镜头。
- 给结尾补最强一帧。

### 3.4 情绪层

检查问题：

- 观众应该在每个阶段感受到什么？
- 情绪是否有变化，而不是从头到尾一个调子？
- 情感是否靠细节和动作，而不是只靠台词？
- 搞笑是否有停顿和反应？

升级方法：

- 治愈片加入微小伤口和温柔介入。
- 情感片加入旧物、缺席关系和克制动作。
- 搞笑片加入正常规则、误解升级和集体反应。
- 打斗片加入目标、空间和关键停顿。

### 3.5 声音层

检查问题：

- 声音是否和动作同步？
- 是否有环境声建立真实感？
- 情感片是否过度旁白？
- 搞笑片是否给笑点留空？
- 广告是否有可记忆声音或短句？

升级方法：

- 为每个关键镜头写环境声或音效。
- 情感片少旁白，多旧录音感和空间声。
- 打斗片给关键打击点声音层次。
- 广告片给产品动作一个清楚声音标识。

### 3.6 平台传播层

检查问题：

- 前3秒是否能留住人？
- 是否有可截图封面帧？
- 是否有评论区话题？
- 是否适合竖屏？
- 是否能做成系列？

升级方法：

- 增加一句观众想反驳、想共鸣或想复述的台词。
- 设计表情包式反应镜头。
- 把角色固定成系列群像。
- 给每集保留一个新问题或新任务。

## 4. 类型复盘重点

### 4.1 可爱

必须检查：

- 有没有具体小动作？
- 角色是否有可识别萌点？
- 结尾是否有表情包或可截图瞬间？

升级方向：

- 增加反差萌。
- 增加角色固定动作。
- 增加与产品或道具的互动。

### 4.2 治愈

必须检查：

- 有没有微小疲惫或伤口？
- 情绪是否被慢慢修复？
- 声音和光线是否参与叙事？

升级方向：

- 增加旧物、热气、光线变化。
- 减少解释，增加留白。
- 把结尾改成一个安静动作。

### 4.3 特效

必须检查：

- 是否先建立现实基准？
- 特效规则是否清楚？
- 奇观后是否有人物反应？

升级方向：

- 减少无意义特效。
- 增加规则递进。
- 用人物选择承接奇观。

### 4.4 打斗

必须检查：

- 空间是否清楚？
- 双方目标是否清楚？
- 胜负是否有原因？
- 是否有关键打击点和停顿？

升级方向：

- 补场地关系。
- 增加攻防因果。
- 增加失误、疼痛、反杀或代价。

### 4.5 创意广告

必须检查：

- 卖点是否变成画面动作？
- 产品是否介入剧情？
- 是否有前后对比和证据镜头？
- 结尾是否有品牌记忆点？

升级方向：

- 把口播改成动作证明。
- 把普通展示改成类型片表达。
- 把结尾改成可截图品牌帧。

### 4.6 短剧

必须检查：

- 主角欲望是否明确？
- 阻碍是否足够强？
- 第一场是否直接冲突？
- 结尾是否有下一集悬念？

升级方向：

- 前置冲突。
- 增加误会或秘密。
- 让每场付出新代价。

### 4.7 搞笑

必须检查：

- 是否先建立正常规则？
- 误解是否足够清楚？
- 有没有反应镜头和停顿？
- 是否升级了一次，而不是一个笑点就结束？

升级方向：

- 加入群像性格差异。
- 加入集体沉默或一本正经总结。
- 把笑点变成系列设定。

### 4.8 情感

必须检查：

- 是否有旧物或具体关系？
- 情绪是否克制？
- 是否有没说出口的话？
- 结尾是否留白？

升级方向：

- 少写哭，多写手、背影、旧物和停顿。
- 把大情绪压进小动作。
- 用声音和环境补足年代感。

## 6. 公式升级流程

当复盘发现一个经验可以复用时，按以下流程写回能力库：

1. 判断经验属于哪类：类型公式、分镜模板、镜头语言、提示词、趋势雷达、声音策略。
2. 把经验改写成公式，而不是只写案例。
3. 写出适用场景和不适用场景。
4. 加入一个提示词骨架或分镜规则。
5. 加入常见失误。

示例：

```text
案例经验：幼儿园小角色认真处理大人问题很好笑。
升级公式：熟悉规则 + 小角色认真执行 + 大人问题儿童化 + 集体反应 + 表情包收尾。
写回位置：类型公式手册 / 趋势雷达 / 提示词库。
```

## 7. 失败复盘

如果一个方案不好，不要只说“还不够强”，要定位失败类型。

常见失败：

- 钩子失败：开头没有让人停留。
- 类型失败：用户要搞笑，结果只是可爱；用户要情感，结果只是煽情。
- 镜头失败：每个镜头都像说明书，没有导演语言。
- 节奏失败：中段没有升级。
- 情绪失败：没有变化或过度解释。
- 广告失败：卖点没有转成画面动作。
- 生成失败：提示词不具体，角色和场景不一致。

修复顺序：

1. 先修创意钩子。
2. 再修结构节奏。
3. 再修镜头动作。
4. 再修声音和剪辑。
5. 最后修风格词。

## 8. 导演成长自检

每次复盘后，AI超级导演要问自己：

1. 这次有没有形成可复用经验？
2. 这次有没有更强的镜头选择？
3. 这次有没有更准确的类型判断？
4. 这次有没有学到新的平台爆点？
5. 这次有没有需要写回文档的内容？
6. 下一次我会主动做得更好的地方是什么？
