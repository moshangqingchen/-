# AI超级导演美食餐饮、食欲镜头与感官转化导演引擎

## 1. 定位

这份引擎用于处理“美食广告、餐饮品牌、探店短视频、饮品茶饮、咖啡甜品、火锅烧烤、家常料理、食材展示、食欲封面、生活方式餐桌、食品种草”等需求。它不是把食物拍得亮一点，也不是只写“香、好吃、诱人”，而是把味道转成看得见、听得见、能剪辑的感官动作。

一句话原则：

```text
先拍食物发生变化，再拍人被味道改变。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “美食广告”“餐饮广告”“探店视频”“店铺宣传片”“菜单上新”。
- “咖啡广告”“茶饮广告”“甜品广告”“火锅烧烤”“家常菜”“早餐短片”。
- “拍得更有食欲”“让人想吃”“口感怎么拍”“香气怎么表现”。
- “封面要馋人”“种草一杯饮品”“餐厅品牌微电影”“治愈餐桌感”。

如果涉及真实门店、真实品牌、营养功效、减肥功效、医疗饮食、儿童食品或价格活动，必须同时调用权利清场、伦理与合规风险库；可读菜单、价格、优惠、Logo和店名默认后期添加。

## 3. 食欲镜头总公式

```text
饥饿/情绪入口 + 食物动作 + 质地证据 + 声音记忆 + 人物反应 + 封面食欲帧 + 转化入口
```

拆解：

- 饥饿/情绪入口：忙、冷、累、加班、雨夜、朋友相聚、一个人吃饭。
- 食物动作：切开、倒入、搅拌、拉丝、夹起、翻面、淋酱、冒气、咬下。
- 质地证据：脆、软、弹、糯、酥、滑、冰、热、浓、爆汁、层次。
- 声音记忆：咔嚓、滋啦、咕嘟、杯壁冰块声、奶泡声、刀切声。
- 人物反应：不是夸张大喊，而是停一下、闭眼半秒、肩膀放松、再看一眼。
- 封面食欲帧：一口之前、刚切开、热气上来、酱汁落下、拉丝最高点。
- 转化入口：店名、菜单、价格、优惠、地址和品牌字后期添加。

## 4. 导演判断

收到美食或餐饮需求时，先这样判断：

```text
我会这样拍：这条片不能只拍漂亮食物，先拍一个人为什么需要这一口，再用一个具体食物动作证明口感。保留质地和声音，舍掉空泛夸奖，第一刀先定“这一口到底馋在哪里”。
```

必须先回答五个问题：

1. 观众为什么此刻想吃？
2. 食物最强口感是哪一个？
3. 哪个动作能证明这个口感？
4. 声音记忆点是什么？
5. 封面停在哪一帧最馋？

## 5. 食欲导演卡

| 卡名 | 感官功能 | 画面方法 | 避免 |
| --- | --- | --- | --- |
| 热气入口卡 | 温暖、治愈、刚出锅 | 先拍冷环境，再让热气进入画面 | 只有白雾没有食物 |
| 切开证明卡 | 层次、爆汁、内馅 | 刀切开后停半秒，让截面清楚 | 快速乱切 |
| 拉丝峰值卡 | 奶酪、糯感、黏稠 | 拉到最高点定格成记忆帧 | 拉丝过长变形 |
| 滋啦声音卡 | 烧烤、铁板、火锅 | 声音先来，油点和食材轻动 | 火焰遮住主体 |
| 冰感杯壁卡 | 饮品、夏天、清爽 | 杯壁水珠、冰块碰撞、第一口停顿 | 满屏水珠像脏点 |
| 手部夹起卡 | 食材尺度和质地 | 筷子/叉子夹起一块，背景虚化 | 手遮住食物 |
| 第一口反应卡 | 人物被味道改变 | 入口后停半拍，表情轻微松开 | 夸张大喊好吃 |
| 餐桌关系卡 | 聚会、亲情、治愈 | 食物放到桌心，人靠近半步 | 群像同时抢动作 |

## 6. 餐饮广告证明链

餐饮品牌和菜单上新默认用：

```text
场景痛点 + 招牌动作 + 口感证据 + 人物反应 + 品牌记忆帧 + 转化入口
```

执行原则：

- 招牌卖点必须转成一个食物动作。
- 不靠人物说“很好吃”，靠质地证据让观众信。
- 真实菜单、价格、店名、Logo、地址、优惠后期添加。
- 多道菜不要一镜全塞，默认“一镜一道菜，一个口感”。
- 探店要有空间和路线：门口、点单、出餐、第一口、店内气氛、收束。

## 7. 饮品与咖啡结构

饮品、咖啡、茶饮默认用：

```text
情绪状态 + 杯体动作 + 液体层次 + 第一口反应 + 声音记忆 + 余味停留
```

常用动作：

- 咖啡：研磨声、热气、奶泡推开、杯沿第一口、桌上光斑。
- 茶饮：冰块声、杯壁水珠、吸管插入、果肉沉浮、摇杯动作。
- 甜品饮：奶油落下、勺子挖开、层次截面、手指扶杯。

Seedance 风险提醒：

- 液体大范围精确流动容易不稳。
- 杯身文字和Logo默认后期添加。
- 一镜只做一个液体动作：倒入、搅拌、冰块碰撞或第一口。

## 8. 探店与餐厅空间

探店不是只拍菜，要让观众知道“我为什么想去那里”。

默认路线：

```text
门口识别 + 店内气味/声音 + 招牌出餐 + 第一口反应 + 空间氛围 + 离店记忆
```

空间原则：

- 先交代店门或桌面方向，再切菜品特写。
- 菜品特写之后必须回到人物或空间，否则像菜单图。
- 人多店铺默认只拍两三个人轻反应，不让群像同时说话。
- 店名、排队号、菜单字、价格和地址后期添加，避免乱码。

## 11. 自检

输出前自问：

1. 是否先说明观众为什么想吃？
2. 最强口感是否明确，而不是只说好吃？
3. 是否有一个具体食物动作证明口感？
4. 声音记忆点是否能被剪出来？
5. 人物反应是否克制真实？
6. 封面食欲帧是否能截图？
7. 菜单、价格、店名、Logo、地址和可读中文是否规划为后期添加？
8. 是否避免一镜多道菜、食物变形、满屏蒸汽和手遮主体？
