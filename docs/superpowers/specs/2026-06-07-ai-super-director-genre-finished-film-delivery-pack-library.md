# AI超级导演类型成片交付标准包库

## 1. 定位

类型成片交付标准包库负责把“我要做某一种片子”直接翻译成可执行的成片方案。

项目交付包与输出模板库解决“交付层级”：快速包、标准包、制作包、商业包、复盘包。  
这份文档解决“片种交付”：可爱治愈、特摄特效、动作打斗、创意广告、爆款短视频、怀旧情感、竖屏短剧、图片转视频分别应该给什么。

核心原则：

```text
先像导演一样定拍法，再像制片一样补齐交付物，最后像剪辑师一样检查它能不能成片。
```

默认开口：

```text
我会这样拍：
这一条不要先堆设定，先定第一帧、人物动作和镜头身体。
```

## 3. 可爱治愈短片包

### 3.1 触发

- “可爱治愈短片”
- “软萌小动物”
- “毛绒、幼儿园、童趣”
- “温柔广告”
- “情绪价值”

### 3.2 导演判断

可爱治愈片不能只靠软萌外形，要让小主体认真处理一个比它大一点点的任务。观众停下来的原因，是它笨拙但真诚。

### 3.3 必交付模块

```text
我会这样拍：
先给一个小主体面对大任务的第一帧，不急着解释世界观。

小主体：
大任务：
微小伤口：
温柔介入者：
群像秩序：
反应停顿：
情绪松动点：
可截图落点：

镜头调度：
低机位靠近主体，动作幅度小，反应镜头多于解释镜头。

Seedance 2.0重点：
4-6秒一镜，保持角色体型和材质一致；用手部、小步伐、眨眼、停顿表达情绪。
```

### 3.4 默认镜头结构

1. 第一帧：小主体卡在一个认真又好笑的困境里。
2. 反应：它先硬撑半秒，不立刻卖萌。
3. 介入：温柔角色不替它完成，只给一个小帮助。
4. 松动：小主体动作变慢，眼神软下来。
5. 群像：周围角色用整齐的小反应收尾。
6. 截图点：主体和任务同框，留下温暖余味。

## 4. 特摄/特效短剧包

### 4.1 触发

- “特摄感”
- “怪兽、变身、英雄登场”
- “超能力觉醒”
- “必杀技”
- “更炸的特效短剧开头”

### 4.2 导演判断

特摄和特效不是先炸，而是先建立现实基准，再让一件不该发生的事破坏基准。观众信了现实，奇观才会有重量。

### 4.3 必交付模块

```text
我会这样拍：
第一镜先给现实基准，第二镜再让异常进入画面。

现实基准：
异常入口：
变身/觉醒触发物：
能力规则：
代价：
英雄登场姿态：
反派/怪兽压力方向：
声音记忆点：
必杀停顿：
特效递进：

空间关系：
先定地面、距离、遮挡物和逃生方向，再让特效发生。

Seedance 2.0重点：
复杂特效拆成触发、扩散、受力、反应四段；不要一镜塞完整变身和大规模破坏。
```

### 4.4 默认镜头结构

1. 现实基准：普通场景里有一个不舒服的声音或影子。
2. 破裂：灯光、地面、道具或空气先异常。
3. 触发：角色手部或眼神接触关键物。
4. 觉醒：只拍局部变化，不全身乱变。
5. 受力：环境和旁人证明能力真的发生。
6. 停顿：必杀前一秒安静，让观众等那一下。

## 5. 动作打斗与追逐包

### 5.1 触发

- “打斗”
- “动作戏”
- “追逐”
- “动作看不清”
- “更炸”

### 5.2 导演判断

动作戏先讲清谁要去哪、谁阻止谁。看不清的原因通常不是不够快，而是没有空间基准和受力结果。

### 5.3 必交付模块

```text
我会这样拍：
先给空间基准，不先剪碎动作。

空间基准：
双方目标：
压力方向：
动作起点：
接触/触发点：
受力结果：
人物反应：
声音打击点：
机位站边：
轴线规则：

Seedance 2.0重点：
每镜只完成一个动作结果；追逐按“看见目标、被阻挡、越过障碍、回头确认”拆开。
```

### 5.4 默认镜头结构

1. 全景定空间和目标。
2. 中景给冲刺或起手。
3. 近景给接触点。
4. 反应镜头给受力结果。
5. 过肩或跟拍给下一次压力。
6. 声音桥把动作接到下一镜。

## 6. 创意广告/产品证明包

### 6.1 触发

- “创意广告”
- “产品广告”
- “信息流广告”
- “种草、带货、转化”
- “卖点、功能证明、前后对比”

### 6.2 导演判断

广告不是先写口号，是把卖点变成一个看得见的动作。观众要先看到痛点，再看到产品介入后的变化。

### 6.3 必交付模块

```text
我会这样拍：
先拍痛点，不先夸产品。

目标人群：
痛点可视化：
产品动作：
可见变化：
证据镜头：
人物反应：
品牌记忆帧：
转化入口：
合规边界：

15秒版：
30秒版：
60秒版：

Seedance 2.0重点：
产品证明镜头要拆清楚“使用前、动作介入、变化结果”；品牌字和中文卖点后期添加。
```

### 6.4 默认镜头结构

1. 第一帧：痛点正在发生。
2. 产品进入：手部动作清楚，别让产品太晚出现。
3. 变化：前后对比要可见。
4. 证据：用特写或反应证明，不用空口夸。
5. 记忆帧：人物、产品、结果同框。
6. 转化：标题、字幕、口播或评论区入口后期补。

## 7. 爆款短视频包

### 7.1 触发

- “爆款视频”
- “前三秒抓人”
- “留存、完播”
- “标题封面”
- “更容易火”

### 7.2 导演判断

不能承诺必爆，但可以把停留理由做硬。爆款结构先做信息债：观众看了第一帧，会想知道下一秒怎么解释。

### 7.3 必交付模块

```text
我会这样拍：
第一帧直接给反常结果，不先铺背景。

第一帧停留点：
前三秒问题：
信息债：
中段升级：
反转/兑现：
结尾互动：
标题A/B/C：
封面帧A/B：
简介：
置顶评论：

Seedance 2.0重点：
开场镜头要独立成立；每个镜头有明确出点，方便快速剪辑。
```

### 7.4 默认镜头结构

1. 反常结果先出现。
2. 人物或旁观者给半秒反应。
3. 信息债抛出问题。
4. 中段加一个更大的变化。
5. 兑现但留一点余味。
6. 评论区问题要具体，不能空喊互动。

## 8. 怀旧情感短片包

### 8.1 触发

- “怀旧”
- “旧物讲故事”
- “亲情、公益感”
- “像旧梦留声机那种情感方向”

### 8.2 导演判断

怀旧片不要用大哭硬煽情，要让旧物替人说没说出口的话。声音和留白比台词更重要。

### 8.3 必交付模块

```text
我会这样拍：
第一镜拍旧物被重新碰到的那一下，不先讲回忆。

旧物入口：
缺席的人/关系：
没说出口的话：
当下动作：
回忆触发：
声音记忆点：
留白结尾：
字幕安全区：

对白口型：
画内台词只保留短句；长情绪交给画外音、旧录音、字幕和反应镜头。

Seedance 2.0重点：
动作要克制，镜头慢，手部触摸、灰尘、光线变化和声音桥是核心。
```

### 8.4 默认镜头结构

1. 旧物被发现或重新启动。
2. 手部停顿，比脸先说话。
3. 声音进入，画面不急着解释。
4. 当下人物有一个细小失控。
5. 回忆只给片段，不全讲。
6. 留白收尾，让观众补完关系。

## 9. 竖屏短剧第一集包

### 9.1 触发

- “竖屏短剧”
- “爽剧、反转、悬疑”
- “第一集”
- “下一集、追更”
- “站队、打脸、反杀”

### 9.2 导演判断

第一集不要解释背景，先给关系压力和身份问题。观众要先站队，再理解设定。

### 9.3 必交付模块

```text
我会这样拍：
第一镜直接把主角推到选择代价面前。

主角外在欲望：
内在缺口：
阻碍者：
关系压力：
信息差：
视觉伏笔：
选择代价：
反转释放：
下一集问题：

空间关系：
谁压迫谁，谁站在出口，谁掌握证据。

对白口型：
正反打拆短句，一镜一个主要说话人；威胁、反问、反杀句尽量3-8个汉字。

Seedance 2.0重点：
多人物对话拆正反打和反应镜头，不让两三个人同时抢口型。
```

### 9.4 默认镜头结构

1. 反常结果或公开羞辱开场。
2. 主角反应但不解释。
3. 阻碍者亮出压力。
4. 视觉伏笔一闪而过。
5. 主角做选择。
6. 小反转释放，再抛下一集问题。

## 10. 图片转视频/参考图 Seedance 包

### 10.1 触发

- 用户上传图片、参考图、角色图、首帧图、封面图。
- “图片转视频”
- “按这张图做 Seedance”
- “图一图二图三”

### 10.2 导演判断

图片不是直接照抄成视频，而是先分配职责：哪张管角色，哪张管风格，哪张管构图，哪张只管道具。可读文字、Logo、品牌字默认后期做。

### 10.3 必交付模块

```text
我会这样拍：
先读图，不急着写提示词。

图一职责：
图二职责：
图三职责：

每张图必须描述：
画幅：
整体风格：
角色形象：
表情：
动作气质：
色彩：
材质：
构图：
文字区域：
需要继承：
不要继承：

Seedance风格锁定句：
字幕安全区：
角色一致性规则：
镜头提示词：
```

### 10.4 默认镜头结构

1. 首帧图只负责开场构图和情绪，不负责所有细节。
2. 角色图负责脸型、发型、服装轮廓和动作气质。
3. 风格图负责光线、色彩、材质和镜头氛围。
4. 道具图只负责关键道具形状和使用动作。
5. 文字、标题、Logo和品牌字全部后期添加。

## 11. 类型包选择规则

```text
用户说“成片级/完整方案/直接可执行” -> 先套通用成片交付骨架
用户说“可爱/治愈/软萌/小动物” -> 可爱治愈短片包
用户说“特摄/超能力/变身/怪兽/特效短剧” -> 特摄/特效短剧包
用户说“打斗/追逐/动作看不清” -> 动作打斗与追逐包
用户说“广告/产品/转化/证明/前后对比” -> 创意广告/产品证明包
用户说“爆款/前三秒/留存/标题封面” -> 爆款短视频包
用户说“怀旧/旧物/亲情/公益感” -> 怀旧情感短片包
用户说“短剧/第一集/反转/追更” -> 竖屏短剧第一集包
用户上传图片或说“图片转视频/参考图” -> 图片转视频/参考图 Seedance 包
```

多类型叠加时，不互相覆盖，而是按主任务合并：

```text
可爱广告 = 创意广告/产品证明包 + 可爱治愈短片包
特效短剧 = 竖屏短剧第一集包 + 特摄/特效短剧包
爆款打斗 = 爆款短视频包 + 动作打斗与追逐包
图片转广告 = 图片转视频/参考图包 + 创意广告/产品证明包
怀旧爆款 = 怀旧情感短片包 + 爆款短视频包
```

## 12. 成片级自检

输出前问自己：

1. 我有没有先像导演一样给判断，而不是直接堆表格？
2. 第一帧能不能截图给别人看懂？
3. 前三秒有没有问题、危险、反常结果或情绪缺口？
4. 这个类型最该有的证明链、冲突链或情绪链有没有完整？
5. 人称运镜和摄影机身体有没有具体到可拍？
6. 对白口型有没有控制在短句、单说话人、嘴部可见？
7. Seedance 2.0 每镜能不能独立生成？
8. 可读中文、Logo、字幕和品牌字有没有规划到后期？
9. 高风险镜头有没有拆镜或降难？
10. 有没有给出审片评分、最弱点和第一刀升级？
