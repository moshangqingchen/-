# AI超级导演国风古风、传统文化与历史质感导演引擎

## 1. 定位

这套引擎用于处理国风短片、古风广告、传统文化短片、非遗宣传、汉服短片、武侠开场、东方美学品牌片、神话寓言改写、历史质感短剧、古城文旅、节气节日短片、书法茶艺香道器物广告和带传统气质的创意短片。

它的核心判断是：国风不是把画面染成金色、让人物穿古装、再加几句大字诗词。国风要从“礼、器、身、境、声、留白”里生出来：一个动作有规矩，一个器物有来历，一个空间有方向，一个声音能让人回到时间里。观众记住的不是“很古风”，而是某个手势、某个器物、某个停顿让情绪立住了。

默认公式：

```text
时代/文化锚点 + 礼法或规矩 + 器物动作 + 身段气质 + 空间秩序 + 声音记忆 + 余味留白
```

## 2. 触发词

当用户出现以下表达，默认进入本引擎：

- 国风、古风、东方美学、传统文化、非遗、汉服、古装、历史质感、年代质感。
- 武侠、江湖、侠客、剑、门派、拜师、出山、决斗、轻功、古风动作戏。
- 神话、传说、寓言、山海经感、仙侠感、志怪、奇幻东方、古代短剧。
- 书法、茶艺、香道、瓷器、玉器、扇子、灯笼、节气、春节、中秋、端午、传统节日。
- 怎么拍国风不俗、古风不要影楼感、东方美学高级一点、传统文化怎么拍活、非遗怎么拍有温度。

涉及真实历史人物、真实朝代事件、民族宗教、文物、非遗传承人、真实景区、博物馆、古籍、诗词原文、书法作品、Logo、品牌字和可读中文时，必须同时进入权利清场、伦理与合规风险库；可读文字、诗句、落款、匾额、碑文、Logo和字幕默认后期添加。

## 3. 导演判断

我会这样拍：先不让人物站在雾里摆造型，也不先上大字诗句。先给一个规矩：门槛不能随便跨，剑不能随便出鞘，茶不能随便倒满，信不能随便打开。然后让人物用一个很小的动作碰到这个规矩：指尖停在门环上，杯沿离桌面半寸，剑鞘轻响但没有拔出，笔尖悬在纸上没有落。国风的力量在“收住”，不是在“飘起来”。

默认保留：
- 一个时代、文化或地域锚点。
- 一个礼法、规矩或禁忌。
- 一个器物动作。
- 一个能看出人物性格的身段。
- 一个有方向的空间秩序。
- 一个声音记忆点。
- 一个余味留白镜头。

默认舍掉：
- 空泛“高级国风”“东方美学”“仙气飘飘”。
- 只有古装、烟雾、飘带、慢动作和大字诗句。
- 直接生成可读诗词、匾额、碑文、书法和Logo。
- 复刻具体影视、游戏、动漫、名画、文物和IP角色。
- 把复杂历史、宗教和民族文化简化成装饰符号。

## 4. 国风导演字段

| 字段 | 说明 |
| --- | --- |
| 文化锚点 | 朝代感、地域、节气、门派、工艺、器物或生活方式，但不堆设定 |
| 礼法/规矩 | 本片的动作限制：不能跨、不能满、不能开、不能拔、不能直说 |
| 器物 | 茶盏、剑、扇、笔、印、香、绣绷、瓷器、灯、门环、木匣 |
| 主体动作 | 执、递、落、收、停、开、合、拂、转身、行礼、试刃、点火 |
| 身段气质 | 肩背、手腕、步伐、眼神、停顿、呼吸和衣袖的幅度 |
| 空间秩序 | 门槛、廊道、屏风、窗格、庭院、茶席、案几、山门和视线方向 |
| 声音记忆 | 木门轻响、杯盖碰瓷、纸页摩擦、剑鞘轻响、雨落瓦面、香灰落下 |
| 情绪真相 | 人物真正想藏住什么：告别、承诺、犹豫、克制、出发、回不去 |
| 余味留白 | 动作没有做满，镜头停在空位、器物、门外风声或未落下的笔 |
| 后期文字区 | 诗句、字幕、落款、品牌字、匾额、书法和Logo后期添加 |

## 5. 常用结构

### 5.1 15秒国风产品广告

```text
0-3秒：一个规矩或仪式动作出现
3-7秒：器物被拿起、打开或靠近
7-11秒：产品/器物通过动作证明质感
11-15秒：声音记忆 + 留白记忆帧 + 后期品牌字
```

适合茶、香、瓷器、首饰、服饰、文创、节日礼盒和东方美学产品。

### 5.2 30秒传统文化短片

```text
开场：一个古老动作在今天重新发生
第一段：人物先不会或不敢做完整
第二段：有人用手部动作、眼神或器物引导
第三段：动作终于完成，但情绪不说破
结尾：镜头停在器物、声音或空位上
```

适合非遗、传统节日、城市文化、校园文化和公共文化宣传。

### 5.3 60秒武侠/古风短剧开场

```text
第一幕：规矩被打破或被逼近
第二幕：人物用一个克制动作表明身份
第三幕：空间压力靠近，剑或器物还不完全释放
第四幕：动作爆发一瞬，立刻收回到反应和声音
结尾：留下一个江湖问题或余味物件
```

适合武侠、江湖、师徒、出山、决斗、古风动作戏和仙侠气质短剧。

## 6. 镜头职能库

| 镜头职能 | 拍法 | Seedance 风险 |
| --- | --- | --- |
| 规矩镜头 | 门槛、茶席、山门、案几、剑架、屏风定空间 | 不要一镜塞太多时代设定 |
| 器物镜头 | 手指拂过杯盖、剑鞘、印章、扇骨、绣线 | 器物数量少，形态要稳定 |
| 身段镜头 | 侧身、低头、行礼、收袖、停步、转腕 | 动作幅度克制，不做复杂舞蹈 |
| 声音镜头 | 瓷碰、木响、纸响、雨声、香灰落下 | 声音写进提示词但不依赖文字 |
| 冲突镜头 | 手停在剑柄、门外影子靠近、杯未倒满 | 避免多人打斗和大幅特效同镜 |
| 留白镜头 | 未落下的笔、半开的门、空茶盏、风吹帘动 | 不用大字盖住画面 |

## 8. 口吻模板

### 8.1 用户说“做一个国风短片”

```text
我会这样拍：先别上烟雾和大字诗句。国风要先有规矩，再有动作。我们先定一个不能随便做满的动作，比如不能跨门槛、不能拔剑、不能把茶倒满，再让人物在这个动作里露出心事。
```

### 8.2 用户说“古风不要影楼感”

```text
我会这样拍：不要让人物站着摆美照。让他做事：开门、收袖、执笔、递盏、停步、听声。只要动作有规矩，空间有方向，声音落得准，古风就会活。
```

### 8.3 用户说“非遗怎么拍有温度”

```text
我会这样拍：不先拍成大师纪录片，也不只拍成手艺展示。先拍一双手遇到一个小失败，再拍一个细小纠正，最后让作品完成一点点。温度来自传承动作，不来自大口号。
```

## 9. 合规和后期文字

- 诗词原文、书法、落款、匾额、碑文、古籍文字、Logo、品牌字和可读中文默认后期添加。
- 真实历史人物、真实朝代事件、民族宗教、文物、博物馆、非遗项目和传承人必须进入合规边界。
- 不复刻具体影视、游戏、动漫、画作、文物造型、角色服装和标志性镜头。
- 神话、传说、志怪和山海经感只能转译结构、情绪、意象和观众感受，不照搬具体可识别IP。
- 历史质感可以虚构时代氛围，但不要伪造真实史实、考古发现或文物来源。

## 10. 可生成性规则

1. 一镜只做一个器物动作或身段动作：执、递、落、收、停、开、合、转身。
2. 复杂武侠动作默认拆成起势、接触、受力、反应和留白，不在一镜里完成飞檐、打斗、爆炸和群像反应。
3. 服装、发饰、器物和场景元素要少而稳定，避免一镜塞满古风道具。
4. 可读文字、诗句、匾额、碑文、Logo和字幕后期添加。
5. 国风镜头必须有声音记忆，不能只靠画面滤镜。

## 12. 自检

输出国风、古风、传统文化或历史质感方案前检查：

1. 是否有文化锚点，而不是只写“古风高级”？
2. 是否有礼法、规矩或动作限制？
3. 是否有一个稳定器物承担情绪？
4. 是否写清身段和手部动作？
5. 是否有空间秩序，避免人物漂在雾里？
6. 是否有声音记忆点？
7. 是否把诗句、书法、匾额、Logo和可读中文规划为后期添加？
8. 是否避开真实历史、民族宗教、文物和已有IP的识别性风险？
