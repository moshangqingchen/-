# AI超级导演动作打斗、追逐与特效场面编排引擎

## 1. 定位

这份库负责把打斗、追逐、超能力、爆炸、空间扭曲、产品科技特效和高难度动作场面，拆成能看懂、能生成、能剪辑的镜头段落。

它不是武术动作大全，也不是特效名词堆砌。它解决的是 AI视频里最容易坏的部分：动作因果不清、空间乱跳、人物受力不成立、特效没规则、镜头又快又糊、Seedance 2.0 一条提示词塞太多任务。

默认原则：

1. 动作场面先清楚，再刺激。
2. 每段动作必须有起点、接触点、结果和反应。
3. 特效必须有规则：从哪里来，影响什么，代价是什么。
4. 打斗、追逐和特效都要先建立空间基准，再给短促冲击。
5. 高难动作默认拆成 4-6 秒镜头，不把连续复杂动作塞进一条 Seedance 2.0 提示词。

一句现场判断：

```text
我先不让镜头乱飞。先把双方位置、目标、障碍和危险方向摆清楚，再给一次有重量的动作，最后用反应镜头证明这一下真的打到了。
```

## 2. 动作场面总公式

```text
动作场面 = 空间基准 + 双方目标 + 压力方向 + 动作起点 + 接触/触发点 + 受力结果 + 反应停顿 + 下一次变化
```

每场动作戏至少回答：

1. 谁想要什么？
2. 谁挡住了谁？
3. 危险从哪个方向来？
4. 主体从哪里移动到哪里？
5. 关键接触点是什么？
6. 结果改变了空间、关系还是能力规则？
7. 观众下一秒想看什么？

## 3. 动作场面分层

| 层级 | 作用 | 必须写清 | Seedance 2.0 风险 |
| --- | --- | --- | --- |
| 空间层 | 让观众知道人在哪里 | 起点、出口、障碍、关键道具、机位站边 | 左右跳、穿帮、角色瞬移 |
| 目标层 | 让动作有原因 | A想逼近、B想逃、产品要证明、能力要启动 | 动作像随机摆拍 |
| 攻防层 | 让打斗有节奏 | 试探、逼近、躲避、接触、受力、反击 | 只见挥舞，看不见因果 |
| 特效层 | 让奇观可信 | 触发条件、出现方向、影响对象、代价 | 满屏光效但不知道为什么 |
| 反应层 | 让重量成立 | 停顿、呼吸、后退、眼神、手部、群体反应 | 动作像没打中 |
| 剪辑层 | 让片段可接 | 入点、出点、声音落点、下一镜钩子 | 多条视频拼不起来 |

## 4. 打斗编排

### 4.1 打斗节拍

```text
空间交代 -> 目标明确 -> 第一轮试探 -> 逼到障碍 -> 关键打击 -> 受力结果 -> 短暂停顿 -> 反击或反转
```

### 4.2 攻防动词表

| 功能 | 动作 | 结果 |
| --- | --- | --- |
| 逼近 | 迈近、压肩、挡路、贴近桌边 | 对手后退或空间变窄 |
| 躲避 | 侧身、后撤、低头、抓住桌沿 | 攻击落空或撞到障碍 |
| 控制 | 抓手腕、按肩、挡住出口 | 对手行动受限 |
| 失衡 | 脚步滑开、背撞桌沿、身体偏向一侧 | 下一招有理由 |
| 反击 | 推开、扫开手、用道具挡住 | 局势反转 |
| 受力 | 后退半步、喘气、扶墙、短暂停住 | 打击有重量 |

### 4.3 打斗镜头拆法

| 镜头 | 任务 | 建议人称 | Seedance 2.0 写法 |
| --- | --- | --- | --- |
| 1 | 交代双方位置和障碍 | 第三人称全景/中景 | 空间清楚，双方站位固定 |
| 2 | A逼近，B后退 | 第三人称跟拍 | 只写逼近和后退，不写打中 |
| 3 | 关键打击或躲避 | 近景/短第一人称冲击 | 只写一个接触点 |
| 4 | 受力结果 | 反应近景 | 后退、扶墙、喘气、眼神变化 |
| 5 | 反击或反转 | 第三人称中景 | 让结果改变空间关系 |

### 4.4 打斗禁忌

- “两人激烈打斗”但没有谁先动。
- 镜头全程手持乱晃，观众看不清空间。
- 一条提示词里写冲刺、翻滚、格挡、反击、爆炸和台词。
- 关键打击没有受力结果。
- 特效能力和拳脚动作同时复杂，模型容易两头都坏。

### 4.5 受力账本与重量落点

动作和特效必须有“力去了哪里”的账本。观众相信一次打击、爆炸、能力或产品科技效果，不是因为画面够亮，而是因为力量改变了某个可见对象。

每一次接触、触发或爆发后，都要写一条受力账：

```text
力量来源：
【拳脚/道具/怪兽压力/能力/产品科技/空间坍缩/爆炸冲击】

承受对象：
【人/道具/墙面/地面/光线/空气/产品结果/群体反应】

可见位移：
【后退半步/扶墙/桌面震动/衣角被风压推开/污渍退开/光线变暗】

声音落点：
【闷响/短促冲击/空气抽空/产品启动声/环境声突然停住】

反应确认：
【眼神停住/呼吸断一下/群像安静/手松开/结果被看见】
```

受力落点表：

| 场面 | 受力最好落在哪 | 不要只落在哪 |
| --- | --- | --- |
| 拳脚打斗 | 身体重心、脚步、墙面或道具 | 光效和快剪 |
| 武器/道具 | 被挡住的手、震动的道具、划开的空间 | 夸张火花 |
| 超能力 | 一个对象的位移、停顿或变形 | 满屏能量 |
| 爆炸 | 风压、碎屑方向、人物反应、环境声抽空 | 白光一闪 |
| 怪兽压力 | 地面震动、影子、群体视线、物体被压动 | 怪兽全身大特写 |
| 产品科技特效 | 痛点对象的可见变化 | 抽象光线环绕产品 |
| 必杀技 | 命中对象、空间结果、反应停顿 | 技能名称和大光束 |

第一刀判断：

```text
如果说不清力量落在哪，先不要加更大的特效。
第一刀：把冲击改成一个可见位移、一个声音落点和一个反应确认。
```

### 4.6 接触点-受力结果-反应确认三联闸门

打斗、爆炸、超能力和追逐冲撞最容易坏在“看起来发生了很多，但观众没看见哪一下真的改变了局面”。每个 4-6 秒动作镜头先过三联闸门：

| 闸门 | 必须看见 | 失败写法 | 第一刀 |
| --- | --- | --- | --- |
| 接触点 | 拳、脚、道具、风压、能量、车门、墙面或产品动作触到哪个对象 | 能量爆发、激烈交锋、双方快速碰撞 | 把动作压成一次触碰、一次挡住或一次撞上 |
| 受力结果 | 受力对象产生位置、姿态、材质、环境或关系变化 | 场面震撼但没人后退、物体没变、空间没改 | 加一个可见位移：退半步、扶墙、桌面震、裂纹停在脚边 |
| 反应确认 | 谁在半秒内确认了结果：受力者、旁观者、攻击者、产品使用者或环境 | 打完立刻切走，只剩光效和烟尘 | 补停顿、呼吸断一下、眼神锁住、手松开或环境声抽空 |

三联闸门硬规则：

1. 接触点不清，不写第二个动作。
2. 受力结果不清，不加更大爆炸。
3. 反应确认不清，不直接进入下一招。
4. 同一镜最多保一个接触点；连续攻防拆成“起点镜、接触镜、结果镜、反应镜”。
5. 超能力可以不直接打到人，但必须打到一个可见对象：墙、地面、空气、道具、光线、产品结果或群体动作。
6. 追逐冲撞要先看见距离缩短，再看见障碍接触，最后看见路线改变。

快速输出格式：

```text
三联闸门：
接触点：[什么力量/动作触到什么]
受力结果：[哪个对象发生什么可见变化]
反应确认：[谁用什么半秒反应证明结果]
第一刀：[如果失败，先删什么或拆哪一镜]
```

通过标准：

```text
关掉特效和音乐，只看静音画面，也能回答：
这一下从哪里来，打到哪里，改变了什么，谁确认了它。
```

### 4.7 力量方向可读门禁

动作、爆炸、超能力和必杀技不能只写“很强”。观众必须能看出力量从哪边来、往哪边去、打中了谁或什么，以及结果被谁确认。每次冲击先过力量方向可读门禁：

| 门禁项 | 必须写清 | 失败写法 | 第一刀 |
| --- | --- | --- | --- |
| 力量来源 | 谁、什么道具、哪团能量、哪次爆炸或哪个产品动作产生力量 | 突然强光、场面爆开、空气震动 | 补一个起手、触发物或爆点来源 |
| 运动方向 | 从画面哪边到哪边，沿哪条轴线推进 | 环绕乱飞、到处爆、镜头乱甩 | 固定空间基准和摄影机站边，只保一个主要方向 |
| 承受对象 | 谁、哪面墙、哪件道具、哪块地面或哪个痛点对象承受力量 | 只有光效，没有对象 | 补命中对象，或改成先打到环境 |
| 可见结果 | 位移、形变、停顿、灰尘方向、碎片方向、身体后退或路线改变 | 爆光盖住结果，烟尘吞掉主体 | 降低光效强度，拆出结果镜或反应镜 |
| 遮挡控制 | 光效、烟尘、火花和镜头运动不能遮住接触点和受力结果 | 满屏白光、黑烟、快剪，看不见命中 | 保留接触点半秒，再让烟尘或爆炸扩散 |
| 反应确认 | 受力者、攻击者、旁观者、环境或产品使用者确认这一下成立 | 命中后直接切走 | 补半秒眼神、扶墙、退步、停顿、环境声抽空 |

硬规则：

1. 一镜只保一个主要力量方向。
2. 看不清力量方向时，不加特效，先定空间基准和机位站边。
3. 光效、烟尘、爆炸不能遮住接触点和受力结果。
4. 大场面先拆成触发镜、命中镜、结果镜和反应镜。
5. 如果方向、对象和结果三项有一项说不清，就先降特效强度，不升级场面规模。

快速输出格式：

```text
力量方向可读门禁：
力量来源：[谁/什么产生力量]
运动方向：[从画面哪边到哪边，沿哪条轴线]
承受对象：[谁/什么被打中或被影响]
可见结果：[位移/形变/停顿/灰尘/碎片/路线改变]
遮挡控制：[哪些光效、烟尘或镜头运动必须压住]
失败第一刀：[先固定站边、降特效、拆结果镜还是补反应镜]
```

## 5. 追逐编排

### 5.1 追逐公式

```text
目标物/人出现 -> 追逐距离建立 -> 障碍改变路线 -> 近距离危险 -> 短暂失去目标 -> 新线索或反转
```

### 5.2 追逐镜头规则

1. 先用一个镜头说明“追谁、为什么追、距离多远”。
2. 每次转向都要有空间原因：门、楼梯、桌子、车辆、行人、光线、道具。
3. 跟拍只跟一个主体，不同时追三个人。
4. 跑动镜头尽量短，复杂动作拆成“跑动 + 障碍 + 反应”。
5. 追逐结尾要改变信息：追上、跟丢、发现陷阱、进入新空间。

Seedance 2.0 模板：

```text
5秒追逐镜头。
空间锁定：[走廊/街角/教室/仓库]，出口在 [方向]，障碍是 [道具/人群/门]。
主体：[追逐者或被追者，只选一个主要主体]。
动作链：[主体从A点跑向B点] -> [遇到障碍] -> [改变方向或短暂停住]。
摄影：中景，侧后方跟拍，一个主要运镜，保持主体清楚。
声音：脚步、急促呼吸、障碍碰撞声。
剪辑点：主体转向或发现新线索时切。
避免：多人乱跑、空间跳变、镜头剧烈摇晃、身体变形。
```

## 6. 特效与超能力编排

### 6.1 特效规则三问

1. 触发条件是什么？
   - 手触碰、眼神锁定、声音响起、产品启动、旧物转动、危险逼近。
2. 特效影响什么？
   - 物体、光线、空间、时间、人物动作、产品结果。
3. 代价或限制是什么？
   - 只能持续一秒、只影响一个物体、需要专注、会让角色失衡、会留下痕迹。

### 6.2 特效递进

```text
现实基准 -> 异常征兆 -> 人物反应 -> 规则显现 -> 奇观扩大 -> 情绪/剧情落点
```

### 6.3 特效镜头拆法

| 镜头 | 任务 | 画面重点 | 风险控制 |
| --- | --- | --- | --- |
| 1 | 现实基准 | 正常空间、正常光线、人物动作 | 不加特效 |
| 2 | 异常征兆 | 小范围光、物体轻微变化、声音先到 | 特效只影响一个对象 |
| 3 | 人物反应 | 眼神、后退、伸手、呼吸停顿 | 用反应证明真实 |
| 4 | 规则显现 | 时间暂停、空间折叠、能量线、产品科技效果 | 保持主体和空间清楚 |
| 5 | 结果落点 | 人物选择、产品结果、局势变化 | 不再堆新特效 |

### 6.4 特效提示词字段

```text
特效规则：[触发条件、影响对象、限制或代价]。
现实基准：[特效出现前的普通空间和普通动作]。
异常征兆：[先出现的小变化，位置和方向]。
人物反应：[角色看向哪里，身体怎么停住或后退]。
特效结果：[空间、道具、人物关系或产品结果如何改变]。
避免：[满屏无规则光效、主体被特效遮住、背景文字乱码、人物脸部漂移]。
```

## 7. 产品科技特效

创意广告里的特效必须服务卖点，不是炫。

| 卖点 | 特效动作化 | 镜头结果 |
| --- | --- | --- |
| 清洁 | 污渍像潮水一样退开 | 桌面露出真实材质 |
| 提速 | 等待时间被压缩成一条光线 | 任务瞬间完成 |
| 保护 | 透明护盾挡住冲击 | 产品和用户保持稳定 |
| 修复 | 裂纹从边缘慢慢合拢 | 前后对比清楚 |
| 智能 | 光线或界面跟随人的动作变化 | 用户少做一步 |
| 连接 | 分散物体被一条线接回中心 | 信息或关系变清楚 |

广告导演句：

```text
我不让特效单独表演。它必须证明产品做了什么：问题出现、产品介入、结果变化，三步都要看得见。
```

## 8. 声音与打击点

动作和特效的重量，一半来自声音。

| 场面 | 声音落点 | 用法 |
| --- | --- | --- |
| 拳脚接触 | 短促低频冲击声 | 接触点切或停半拍 |
| 撞到障碍 | 木头/金属/墙面闷响 | 证明受力结果 |
| 能力启动 | 低频嗡鸣或空气收缩声 | 特效出现前先到 |
| 时间暂停 | 环境声突然抽空 | 让观众感到规则改变 |
| 追逐转角 | 脚步声和呼吸声贴近 | 增强距离感 |
| 产品特效 | 清脆启动音 + 环境变安静 | 让卖点显得可控 |

Seedance/剪辑提示：

```text
声音：[动作前的呼吸/特效前的低频/接触点冲击声/结果后的短暂停顿]。
剪辑点：[声音落下的瞬间切到反应或结果]。
```

## 9. 动作场面可生成性评级

| 评级 | 场面 | 处理 |
| --- | --- | --- |
| A | 单人简单动作、单一特效征兆、固定机位反应 | 可一条生成 |
| B | 双人简单攻防、短追逐、局部特效 | 可生成，但镜头 4-6 秒 |
| C | 多人打斗、连续追逐、打斗+特效同镜 | 先拆镜，关键动作单独生成 |
| D | 群体混战、长镜头一镜到底、复杂手部+爆炸+台词 | 重写场面，不建议直接生成 |

默认降难：

1. 多人改双人。
2. 长动作改三镜。
3. 大特效改小征兆 + 反应 + 结果。
4. 翻滚跳跃改成失衡、后退、扶墙、撞到障碍。
5. 群体混战改成“主角视线里的一个威胁 + 群体反应”。

## 10. 输出模板

当用户说“打斗”“动作戏”“追逐”“特效”“超能力”“更炸”“爆炸”“能力觉醒”“动作看不清”时，默认输出：

```text
我会这样拍：
[现场导演判断，说明先稳空间还是先给冲击]

场面目标：
[谁想要什么，谁挡住谁，危险从哪来]

空间基准：
[起点、出口、障碍、关键道具、机位站边]

动作/特效规则：
[攻防节拍或特效触发条件、影响对象、限制代价]

动作节拍表：
段落 | 动作起点 | 接触/触发点 | 受力/结果 | 反应 | 剪辑点

受力账本：
力量来源 | 承受对象 | 可见位移 | 声音落点 | 反应确认

三联闸门：
接触点 | 受力结果 | 反应确认 | 失败第一刀

力量方向可读门禁：
```

## 12. 自检

输出动作、打斗、追逐或特效方案前检查：

1. 是否先建立空间基准？
2. 双方目标或特效规则是否清楚？
3. 是否写出动作起点、接触/触发点、受力结果和反应？
4. 是否每条 Seedance 2.0 镜头只承担一个主要动作？
5. 是否把高风险动作拆成 4-6 秒镜头？
6. 打斗是否有攻防变化，而不是“激烈打斗”四个字？
7. 特效是否有触发条件、影响对象和限制代价？
8. 声音是否绑定打击点、能力启动或结果停顿？
9. 是否给出可生成性评级和降难方案？
10. 是否让动作服务人物、情绪、卖点或爆款留存，而不是单纯炫？
11. 每次关键接触、触发或爆发是否写清受力账本？
12. 力量是否落到可见位移、声音落点和反应确认，而不是只落到光效？
13. 是否过了接触点-受力结果-反应确认三联闸门？
14. 是否过了力量方向可读门禁，写清力量来源、运动方向、承受对象、可见结果和遮挡控制？
15. 关掉特效和音乐后，观众是否仍能看懂这一下从哪里来、打到哪里、改变了什么？
