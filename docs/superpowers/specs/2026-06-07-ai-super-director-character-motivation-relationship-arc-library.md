# AI超级导演人物动机、关系弧线与角色导演库

## 1. 定位

这份库负责让角色像活人，而不是像完成任务的提示词主体。角色不是“站在那里说台词的人”，而是带着欲望、遮掩、习惯、防御和关系压力进入镜头的人。

剧本结构库回答“故事怎么走”，表演对白库回答“此刻怎么演”，本库回答：

```text
这个人为什么非要这样做？
他不敢说什么？
这场戏结束后，他和别人之间有什么变化？
```

默认原则：

1. 每个主要角色都要有外在欲望和内在缺口。
2. 每场戏都要有关系变化，不只是信息推进。
3. 角色不能只服务剧情反转、产品卖点或视觉奇观。
4. 短剧要靠关系压力留人，情感片要靠未说出口的话动人，广告人物要像真实使用者。
5. Seedance 2.0 提示词里的微动作必须来自人物动机，而不是随机加细节。

## 4. 角色核心公式

```text
外在欲望 + 内在缺口 + 防御方式 + 关系对象 + 压力选择 + 变化落点
```

拆解：

- 外在欲望：角色表面上想得到、躲开、证明、保护、完成什么。
- 内在缺口：角色真正缺的是被看见、被原谅、被理解、被接住、重新相信自己。
- 防御方式：嘴硬、开玩笑、控制别人、逃避、沉默、逞强、讨好。
- 关系对象：这场戏里谁最能刺痛他或改变他。
- 压力选择：在代价变大时，角色必须做的选择。
- 变化落点：场景结束时，他靠近、疏远、承认、隐藏、放下或更执拗。

导演口吻：

```text
我不会先让他解释情绪。我先给他一个想藏住的东西，再让镜头看见他藏不住的那一秒。
```

```text

```

示例：

```text
角色名：女儿
故事功能：当下视角入口。
外在欲望：修好旧录音机。
内在缺口：想确认妈妈真的留下过什么。
最怕失去：最后一点和妈妈有关的声音。
最不敢说：我怕自己已经忘了她的声音。
防御方式：装作只是修东西。
习惯动作：紧张时用拇指摩擦录音机边角。
关系对象：缺席的妈妈和眼前的旧物。
关系压力：旧物越沉默，她越不敢按下播放键。
本片起点：把思念说成维修。
本片终点：承认自己是在等一句回应。
禁止写法：不要让她大哭大喊，不要用旁白解释所有情绪。
```

## 6. 关系弧线

关系弧线不是“两个角色认识”，而是他们之间的距离、权力、误会和信任发生变化。

### 6.1 关系弧线公式

```text
起点关系 -> 隐藏压力 -> 冲突动作 -> 信息变化 -> 新距离
```

常见关系变化：

- 疏远到靠近。
- 靠近到误解。
- 弱者获得主动权。
- 强者暴露脆弱。
- 误会变成理解。
- 保护变成控制。
- 对抗变成合作。
- 依赖变成放手。

### 6.2 关系表

```text
角色A：
角色B：
表面关系：
真实压力：
A想从B那里得到什么：
B想从A那里躲开什么：
谁掌握信息：
谁掌握情绪主动权：
本场关系变化：
外化动作：
下一场遗留问题：
```

### 6.3 关系距离

关系必须能被镜头看见：

| 关系状态 | 站位和动作 |
| --- | --- |
| 亲密但别扭 | 站得近，眼神避开 |
| 对抗 | 面对面，身体前倾 |
| 隐瞒 | 侧身，手压住道具或手机 |
| 疏远 | 中间隔桌子、门框、窗或人 |
| 重新靠近 | 不直接拥抱，先递物、并肩或同看一个方向 |
| 权力反转 | 弱者不再后退，强者第一次停住 |

## 7. 场内心理动作

每场戏都给角色一条“心理动作链”：

```text
进场状态 -> 想要 -> 试探方式 -> 被阻挡 -> 改变策略 -> 暴露一点真心 -> 出场状态
```

例子：

```text
进场状态：女儿装作只是来修机器。
想要：听见录音里有没有妈妈的声音。
试探方式：反复检查按钮，不敢按播放。
被阻挡：机器突然发出底噪。
改变策略：她把手缩回，又慢慢伸回去。
暴露一点真心：听见第一声后，她没有哭，只是停住呼吸。
出场状态：她终于承认这不是维修，是等待。
```

## 8. 类型专用角色导演

### 8.1 可爱搞笑群像

角色不是越多越好，每个角色必须有固定功能。

```text
主心骨：认真推进荒诞任务。
慢半拍：把误会理解得更离谱。
嘴硬角色：明明害怕还装镇定。
情绪角色：负责可爱和共情。
捣乱角色：制造第二层升级。
温柔角色：最后把事情接住。
```

关系重点：

- 笑点来自每个角色对同一件事的不同误解。
- 每集保留一个固定关系梗。
- 不要让所有角色都说一样的话、做一样的表情。

### 8.2 治愈

治愈角色不需要大转变，常常只需要往前挪一点点。

```text
起点：不敢面对。
中段：借一个小动作试探。
落点：没有完全解决，但愿意坐下来、开口、递物或回头。
```

关系重点：

- 不说教。
- 不强行和解。
- 用小动作证明“我还在”。

### 8.3 怀旧情感

怀旧情感常常是“缺席关系”。

```text
当下角色 + 缺席对象 + 旧物 + 没说完的话 + 当下回应
```

角色重点：

- 缺席的人也要有存在感：通过声音、旧物、摆放习惯、别人记忆出现。
- 当下的人不要急着哭，要先抗拒、试探、停顿。
- 旧物不是道具，是关系的代言人。

### 8.4 创意广告

广告人物不能只是产品口播机器。

```text
用户真实场景 + 具体痛点 + 防御或忍耐 + 产品动作介入 + 人物状态变化
```

角色重点：

- 用户先有生活困境，再有产品。
- 产品不是主角，产品是让人物状态改变的动作工具。
- 品牌短句来自人物变化，不来自自夸。

### 8.5 短剧

短剧人物要有关系压力和信息差。

```text
谁想控制关系 -> 谁想隐藏秘密 -> 谁误会了谁 -> 谁在结尾拿回主动权
```

角色重点：

- 第一场就让关系不舒服。
- 每句关键台词都改变权力位置。
- 反转不是为了惊讶，是为了重新解释人物动机。

### 8.6 打斗

打斗不是招式堆砌，是人物目标冲突。

```text
A想守住什么 + B想抢走什么 + 谁更怕输 + 谁先失控 + 谁用规则反转胜负
```

角色重点：

- 每一击都要有目标，不只是好看。
- 反应镜头展示心理变化：慌、狠、犹豫、确认、下决心。
- 胜负最好来自人物选择，而不是纯力量。

### 8.7 特效

特效角色要有“能力代价”。

```text
能力是什么 -> 角色为什么不敢用 -> 何时被迫用 -> 用了失去什么 -> 关系怎么改变
```

角色重点：

- 奇观要从人物压力里长出来。
- 能力越大，选择越难。
- 角色反应比特效本身更能让观众相信奇观。

## 9. 角色常见问题修复

### 9.1 角色太工具人

表现：

- 只负责推进剧情。
- 只说信息。
- 没有私人欲望。

修复：

```text
给角色一个不服务剧情的小防御动作：嘴硬、转移话题、护住旧物、假装不在意。
```

### 9.2 主角不讨喜

表现：

- 只索取不付出。
- 只抱怨不行动。
- 没有脆弱点。

修复：

```text
让主角在前10秒做一个保护、忍住、补救或承担代价的动作。
```

### 9.3 反派太扁

表现：

- 只是坏。
- 没有自己的合理目标。

修复：

```text
给反派一个他自认为正确的理由，再让他的方式伤害别人。
```

### 9.4 情感片太假

表现：

- 人物直接说爱和痛。
- 没有具体关系细节。

修复：

```text
把“我想你”换成“杯子还放左边”，把情绪压进旧物和习惯。
```

### 9.5 广告人物像口播机器

表现：

- 人物只负责夸产品。
- 没有生活状态变化。

修复：

```text
先写人物怎么被问题困住，再让产品用一个动作改变他的状态。
```

## 10. Seedance 2.0 集成字段

多镜头 Seedance 输出默认加入：

```text
人物动机：[本镜角色想要什么，真正怕什么]。
关系状态：[本镜开始时角色之间的距离、权力或误会]。
心理动作：[试探/隐藏/逼近/逃避/承认/放下/反击]。
外化动作：[能被画面看见的手部、眼神、站位、道具动作]。
关系变化：[本镜结束时靠近、疏远、压迫、理解、反转或悬念]。
潜台词：[角色没说出口的那句话]。
```

Seedance 2.0 示例：

```text
人物动机：女儿表面想修好录音机，真正想确认妈妈的声音还在。
关系状态：她和缺席的妈妈之间只剩这台旧录音机，关系是想靠近又害怕失望。
心理动作：试探 -> 退缩 -> 再靠近。
外化动作：手指靠近按钮，停半秒，拇指摩擦录音机边角后才按下。
关系变化：从假装维修，变成承认等待。
潜台词：我怕自己已经忘了你的声音。
```

## 12. 自检

输出角色、分镜或 Seedance 提示词前，自问：

1. 主角是否有外在欲望和内在缺口？
2. 角色是否有防御方式，而不是直接说真心？
3. 每场戏的关系是否发生变化？
4. 关系变化是否能被站位、眼神、手部、道具或距离看见？
5. 台词是否有潜台词？
6. 情感是否来自具体关系细节，而不是抽象情绪词？
7. 广告人物是否像真实使用者，而不是口播机器？
8. 群像角色是否有不同功能和固定关系梗？
9. 打斗和特效是否来自人物目标和代价？
10. Seedance 提示词里的微动作是否来自人物动机？
