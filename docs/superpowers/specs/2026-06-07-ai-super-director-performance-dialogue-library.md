# AI超级导演表演指导与对白台词库

## 1. 使用方式

这份库用于指导角色表演、人物调度、对白台词、眼神、停顿和关系变化。导演不只是安排镜头，还要让人物“活起来”：他们怎么站、怎么看、怎么忍住、怎么说半句话、怎么用动作代替解释。

默认设计顺序：

1. 判断角色此刻想要什么。
2. 判断角色不敢说什么。
3. 设计外在动作。
4. 设计眼神和停顿。
5. 设计对白。
6. 检查对白口型同步：一镜一个主要说话人、短台词、嘴部可见、说话节拍和后期配音/字幕兜底。
7. 设计人物之间的距离和走位。
8. 设计情绪释放或压住。

## 2. 表演核心公式

```text
角色欲望 + 内心阻碍 + 外在动作 + 眼神方向 + 停顿节奏 + 台词潜台词 + 关系距离变化
```

拆解：

- 角色欲望：他想得到、证明、隐藏、逃离或守护什么。
- 内心阻碍：他害怕、羞耻、嘴硬、误会或不能说出口什么。
- 外在动作：用手、脚步、转身、拿物、放物、靠近、后退表达。
- 眼神方向：看人、避开、看物、看门口、看地面。
- 停顿节奏：笑点、心碎、反转和打击都需要停顿。
- 台词潜台词：台词表面说A，真正表达B。
- 关系距离：人物距离的变化就是关系变化。

## 3. 表演层级

### 3.1 过满表演

表现：大哭、大喊、大动作、强解释。

适合：极少数爆发点。

风险：用多了会廉价、像短视频尬演。

### 3.2 克制表演

表现：忍住、停顿、转移话题、小动作。

适合：情感、治愈、怀旧、亲情。

提示：

```text
人物没有立刻说话，先看向旧物，手指轻轻摩擦边角，吸一口气后才说半句。
```

### 3.3 反差表演

表现：角色用非常认真态度处理荒诞事件。

适合：搞笑、可爱群像、荒诞广告。

提示：

```text
角色一本正经地点头，像宣布重大决定一样说出一句离谱的话，其他人集体安静半秒。
```

### 3.4 动作表演

表现：用动作代替台词。

适合：打斗、广告、情感、产品展示。

提示：

```text
角色没有解释产品好，而是直接用产品完成动作，另一个角色表情从怀疑变成惊讶。
```

## 4. 眼神设计

### 4.1 看向对方

功能：对抗、确认、亲密、逼问。

适合：短剧冲突、情感和解、打斗对峙。

### 4.2 避开视线

功能：心虚、隐瞒、忍住、害怕。

适合：秘密、误会、告别、情感压抑。

### 4.3 看向旧物

功能：回忆、怀旧、未说出口的话。

适合：旧梦留声机类、亲情、公益。

### 4.4 看向门口或远处

功能：等待、希望、担心、悬念。

适合：短剧结尾、寻亲、情感等待。

### 4.5 看向镜头

功能：打破距离、制造冲击、形成封面帧。

适合：广告收束、短剧反转、搞笑表情包。

风险：不能滥用，否则显得刻意。

## 5. 停顿设计

### 5.1 喜剧停顿

公式：

```text
离谱事件 -> 半秒安静 -> 角色认真反应 -> 第二层升级
```

用途：搞笑、可爱群像、反差广告。

### 5.2 情感停顿

公式：

```text
听到一句话 -> 低头/看物 -> 手部小动作 -> 轻声回应
```

用途：亲情、怀旧、治愈、公益。

### 5.3 反转停顿

公式：

```text
信息揭示 -> 环境声降低 -> 眼神变化 -> 切近景 -> 新台词
```

用途：短剧、悬疑、特效、广告反常识。

### 5.4 打击停顿

公式：

```text
关键动作 -> 接触声 -> 短暂停住 -> 呼吸/表情 -> 继续动作
```

用途：打斗、动作广告、热血短片。

## 6. 台词原则

### 6.1 少解释

错误：

```text
我现在很难过，因为我想起了小时候你对我很好。
```

更好：

```text
这碗，还是放在左边啊。
```

原则：让旧物、动作和停顿承担情绪。

### 6.2 有潜台词

表面台词：

```text
你怎么才回来？
```

潜台词：

```text
我一直在等你。
```

### 6.3 有角色差异

同一事件，不同角色说法：

- 认真角色：我们必须立刻制定方案。
- 慢半拍角色：所以……现在可以吃饭了吗？
- 嘴硬角色：谁担心了，我只是路过。
- 温柔角色：先坐下，慢慢说。
- 捣乱角色：我有个不成熟但很危险的想法。

### 6.4 有口头禅

适合系列IP：

- 可爱搞笑：今天也不是很懂，但我很努力。
- 怀旧情感：有些声音，会替人记得。
- 打斗热血：规则，是用来付代价的。
- 品牌角色：问题来了，我们出发。

## 7. 人物调度

### 7.1 靠近

功能：关系升温、压迫、逼问、安慰。

提示：

```text
角色向前半步，声音压低，关系从普通对话变成私人冲突。
```

### 7.2 后退

功能：害怕、拒绝、心碎、被真相击中。

提示：

```text
角色听到真相后后退半步，手里的旧物差点滑落。
```

### 7.3 交错站位

功能：制造关系层次和信息差。

适合：三角关系、短剧冲突、群像搞笑。

### 7.4 背对

功能：忍住情绪、拒绝沟通、隐藏秘密。

适合：情感、亲情、告别。

### 7.5 集体反应

功能：强化笑点、震惊或荒诞。

适合：绒耀幼儿园类、办公室群像、家庭小品。

## 8. 类型表演策略

### 8.1 可爱

表演关键词：小、软、慢半拍、认真。

动作：

- 歪头。
- 抱住道具。
- 偷看。
- 小步靠近。
- 认真点头。

台词：

- 短。
- 轻。
- 有一点误解。

### 8.2 治愈

表演关键词：放松、接住、慢慢变好。

动作：

- 坐下。
- 递东西。
- 轻轻整理。
- 深呼吸。
- 抬头看光。

台词：

- 不讲大道理。
- 像生活里自然说出来。

### 8.3 情感

表演关键词：克制、旧物、没说出口。

动作：

- 摸照片边角。
- 把碗摆正。
- 停在门口。
- 低头笑一下。
- 背对着擦眼角。

台词：

- 短。
- 像在躲开真正想说的话。

### 8.4 搞笑

表演关键词：认真、误解、停顿、集体反应。

动作：

- 一本正经。
- 集体沉默。
- 慢半拍举手。
- 强行镇定。
- 突然鼓掌。

台词：

- 反差。
- 不解释笑点。
- 最后一秒再升级。

### 8.5 短剧

表演关键词：欲望、压迫、反转、近景。

动作：

- 逼近。
- 打断。
- 抢过道具。
- 停住。
- 眼神变了。

台词：

- 第一场直接冲突。
- 关键台词要短而狠。
- 结尾台词留下新问题。

### 8.6 打斗

表演关键词：目标、疼痛、呼吸、失误。

动作：

- 试探。
- 躲避。
- 失衡。
- 咬牙。
- 反击。

台词：

- 少。
- 打斗中不要长篇解释。
- 关键台词放在停顿处。

### 8.7 特效

表演关键词：相信、反应、规则、选择。

动作：

- 看见异常。
- 伸手试探。
- 后退。
- 呼吸停住。
- 做出选择。

台词：

- 先反应，再解释。
- 规则用一句话说清。

### 8.8 创意广告

表演关键词：痛点真实、产品动作、结果反应。

动作：

- 先展示真实麻烦。
- 产品介入。
- 用户表情变化。
- 结尾完成品牌动作。

台词：

- 少讲卖点。
- 用反应证明效果。
- 品牌句短而可复述。

## 11. 常见失误

1. 台词解释情绪，画面没有动作。
2. 所有人说话一个腔调。
3. 情感戏一上来就哭。
4. 搞笑戏没有停顿和反应。
5. 打斗戏边打边讲太多。
6. 广告人物像口播机器。
7. 短剧关键台词太长。
8. 人物画内对白没有口型同步设计，嘴巴乱动或台词对不上。
9. AI提示词只写表情，不写动作。

## 12. 导演自检

1. 每个角色此刻想要什么？
2. 有没有没说出口的话？
3. 台词是否可以更短？
4. 能不能用动作替代解释？
5. 眼神和停顿是否清楚？
6. 画内对白是否一镜一个说话人、短台词、嘴部可见且有说话节拍？
7. 人物距离是否发生变化？
8. 角色声音是否有差异？
