# AI超级导演AI生成连续性与故障修复库

## 1. 定位

AI生成连续性与故障修复库负责处理AI生图、AI视频和AI声音制作中的成片硬伤。

提示词库解决“怎么生成”，这份修复库解决“生成坏了怎么救”：

1. 角色漂移。
2. 脸、手、肢体变形。
3. 道具消失或变形。
4. 场景空间不连续。
5. 动作跳变。
6. 镜头乱动。
7. 光线和色彩不统一。
8. 文字乱码。
9. 声音和画面不同步。
10. 情绪表演不准。

核心原则：

```text
先诊断问题层级，再决定修提示词、拆镜头、补剪辑，还是重做镜头。
```

## 2. 故障诊断总公式

```text
生成故障 = 角色问题 + 场景问题 + 动作问题 + 镜头问题 + 光色问题 + 道具问题 + 声音问题 + 剪辑问题
```

每次修复前先回答：

1. 问题发生在哪个镜头？
2. 问题属于哪一层？
3. 它是否影响观众理解？
4. 它是否影响角色一致性？
5. 它是否破坏最强一帧？
6. 是提示词问题、生成模型问题、剪辑问题，还是原分镜过难？
7. 修复成本是否高于重做成本？

## 3. 优先级

优先修：

1. 主角身份变了。
2. 关键道具消失。
3. 动作因果错。
4. 情绪完全不对。
5. 镜头信息看不懂。
6. 产品形状或品牌记忆帧错误。
7. 声音和关键动作错位。

可以后修：

1. 背景小瑕疵。
2. 非关键区域轻微纹理错误。
3. 不影响理解的微小光色差异。
4. 可被剪辑遮掉的动作边角问题。

不值得修：

1. 一个镜头承担太多复杂动作。
2. 多角色同框反复失败。
3. 生成结果和原分镜长期不匹配。
4. 关键镜头缺少可控角色或场景参考。

这时要重写分镜或拆镜头。

## 4. 角色漂移

表现：

- 脸型、年龄、发型、服装变了。
- 同一角色跨镜头像不同人。
- 表情习惯和动作习惯丢失。

原因：

- 角色圣经不够具体。
- 每个镜头提示词没有继承角色信息。
- 服装、发型、标志道具没有被锁定。
- 镜头变化过大，模型重新理解角色。

修复方法：

1. 先补角色圣经。
2. 每个镜头开头写“保持同一角色”。
3. 固定脸部特征、发型、服装主色、标志道具。
4. 少用泛化词，例如“漂亮”“可爱”“年轻”，改成可见特征。
5. 近景失败时，先生成角色标准照，再生成镜头。

修复提示词：

```text
保持同一角色：[角色名]。
必须延续：脸部轮廓、发型、服装主色、标志性道具、动作习惯。
本镜头只改变：[动作/表情/位置]。
不要改变年龄、五官比例、发型长度、服装款式和道具形状。
```

## 5. 道具消失或变形

表现：

- 关键物品忽然不见。
- 道具形状每个镜头不同。
- 产品外观不稳定。
- 旧物、武器、杯子、留声机等记忆符号变形。

原因：

- 道具没有成为剧情功能。
- 提示词只写“桌上有道具”，没有写角色如何使用。
- 道具和主体关系不清。

修复方法：

1. 写清道具功能：它解决什么、触发什么、象征什么。
2. 写清位置：在手里、桌上、门口、画面中央。
3. 写清互动：拿起、放下、盖住、点亮、转动。
4. 产品广告中，单独生成产品标准帧。

修复提示词：

```text
关键道具：[道具名] 必须保持清楚可见。
道具位置：[位置]。
角色与道具互动：[具体动作]。
道具外观必须保持：[形状/颜色/材质/标识位置]。
不要让道具消失、变形、换色或移动到错误位置。
```

## 6. 动作跳变

表现：

- 起始动作和结束动作接不上。
- 角色瞬移。
- 手还没碰到物体，物体已经变化。
- 打斗没有因果。
- 产品效果先于产品动作出现。

原因：

- 一条提示词塞进太多动作。
- 动作顺序不清。
- 镜头时长太长。
- 分镜没有拆关键动作点。

修复方法：

1. 把动作拆成3段：起始、中间、结果。
2. 每个镜头只完成一个主要动作。
3. 复杂动作拆成“动作镜头 + 反应镜头 + 结果镜头”。
4. 打斗镜头先交代空间，再交代关键打击。

修复提示词：

```text
动作顺序必须清楚：
起始：[动作开始]。
中间：[动作变化]。
结果：[动作完成后的状态]。
角色位置从 [位置A] 移动到 [位置B]。
不要跳过接触过程，不要让结果先于动作发生。
```

## 7. 手、脸和肢体错误

表现：

- 手指数量错。
- 手部和道具接触不自然。
- 脸部融化或漂移。
- 身体方向不符合动作。

原因：

- 近景动作过细。
- 手部和道具关系复杂。
- 镜头太长或运动太大。
- 角色处于复杂姿态。

修复方法：

1. 把手部动作改成更简单、更清楚的动作。
2. 用道具遮挡复杂手指。
3. 关键手部镜头改成静态关键帧。
4. 脸部情绪用近景静态，动作在下一个镜头完成。
5. 复杂姿态拆成剪辑，而不是一个镜头完成。

修复提示词：

```text
手部动作简单清楚：[具体动作]。
手只需要完成一个动作，不做复杂手势。
道具和手的接触点清楚。
脸部保持稳定，表情为 [情绪]，不要变形、漂移或过度夸张。
```

## 8. 场景空间不连续

表现：

- 门窗位置变了。
- 桌子、楼梯、窗户方向不一致。
- 角色前后站位变了。
- 打斗空间看不懂。

原因：

- 场景圣经缺失。
- 每个镜头只写局部画面，没有空间关系。
- 机位变化没有说明。

修复方法：

1. 建立场景圣经。
2. 写清不可变元素。
3. 每个镜头写“本镜头机位变化”。
4. 打斗和短剧先给全景或中景建立空间。
5. 空间错乱严重时，用反应镜头或道具特写过渡。

修复提示词：

```text
保持同一场景：[场景名]。
不可变元素：门在左侧，窗在后方，桌子在画面中央，主光来自右侧。
本镜头机位：[机位]。
角色位置：[角色位置]。
不要改变房间布局、门窗方向、主要家具和光源方向。
```

## 9. 镜头乱动

表现：

- 镜头无意义旋转。
- 主体被甩出画面。
- 推拉摇移和动作无关。
- 画面晃到看不清信息。

原因：

- 提示词只写“电影感”“动态镜头”，没有写运动目的。
- 镜头运动和主体动作没有绑定。
- 模型自动添加过多运动。

修复方法：

1. 明确镜头运动：推、拉、摇、移、跟、固定。
2. 写清为什么运动。
3. 不需要运动时写“固定机位”。
4. 可爱、情感、产品证明镜头优先固定或轻微推进。

修复提示词：

```text
镜头运动：[固定机位/轻微推进/缓慢横移/跟随主体]。
镜头运动目的：[靠近情绪/展示产品/交代空间/跟随动作]。
主体始终保持在画面中心或三分线位置。
不要旋转、不要突然变焦、不要无意义晃动。
```

## 10. 光线和色彩不统一

表现：

- 前后镜头像不同时间。
- 人物肤色变化大。
- 情感片忽冷忽暖。
- 广告产品色彩不稳定。

原因：

- 视觉圣经缺失。
- 每个镜头风格词不同。
- 光源方向没有写。

修复方法：

1. 固定主色、点缀色和光源方向。
2. 每个镜头使用同一视觉圣经。
3. 关键帧阶段先统一色彩，再生成视频。
4. 剪辑后用调色统一剩余差异。

修复提示词：

```text
保持统一视觉风格：[风格名]。
主色：[主色]，点缀色：[点缀色]。
光源来自：[方向]，光线质感：[柔和/硬朗/低调/明亮]。
不要改变整体色彩倾向，不要让画面忽冷忽暖。
```

## 11. 文字乱码

表现：

- 背景招牌乱码。
- 黑板、海报、产品包装文字错误。
- 字幕样式不可控。

修复方法：

1. 不让模型生成大量文字。
2. 画面中只保留短字或留空。
3. 字幕、标题、品牌字尽量后期添加。
4. 如果必须出现文字，写清“简单清楚的大字，后期可替换”。

修复提示词：

```text
背景不要出现复杂文字。
画面中的文字区域保持干净，可用于后期添加字幕或品牌字。
如必须出现文字，只保留短词：[短词]，大字、清楚、无乱码。
```

## 12. 声音和画面不同步

表现：

- 口型和台词不匹配。
- 打击声早到或晚到。
- 情绪音乐压过对白。
- 旧录音、留声机、电话声和画面来源不一致。

修复方法：

1. 先确定声音来源：画内声还是画外声。
2. 关键动作点标记声音落点。
3. 对口型要求高时，减少台词长度。
4. 口型要求高时，一镜只保留一个主要说话人，台词尽量 3-8 个汉字，最长不超过 12 个汉字。
5. 多人对话拆成正反打、过肩和反应近景，不让多人同镜同时说话。
6. 长对白改成画外声、字幕或后期配音，不继续硬生成。
7. 情感片把旁白当情绪补充，不让它解释画面。
8. 打斗片用剪辑点对齐打击音。

声音修复模板：

```text
声音来源：
关键动作：
声音落点：
需要同步的画面：
对白口型修复：
说话人：
缩短后的台词：
说话节拍：
需要降低的声音：
需要保留的环境声：
替代方案：
```

## 13. 情绪表演不准

表现：

- 角色笑得太夸张。
- 情感片变成尴尬煽情。
- 可爱角色没有认真感。
- 短剧冲突没有压迫感。

修复方法：

1. 用动作提示代替抽象情绪词。
2. 写“克制”“停顿”“眼神变化”“手部动作”。
3. 降低表情强度，让声音和剪辑补情绪。
4. 用反应镜头加强表演。

修复提示词：

```text
表演克制，不大哭、不夸张。
情绪通过 [眼神停顿/手指停住/轻轻转身/抱紧道具] 表达。
表情幅度小，但观众能看出内心变化。
```

## 14. 拆镜头修复法

当一个镜头反复失败，不要继续硬生成，把它拆掉。

### 14.1 复杂动作拆法

```text
原镜头：角色冲过去、抓住道具、躲开攻击、反击并触发特效。

拆成：
镜头1：角色看见道具。
镜头2：手伸向道具。
镜头3：攻击逼近。
镜头4：角色侧身躲开。
镜头5：道具被触发。
镜头6：对手反应。
```

### 14.2 情绪爆发拆法

```text
原镜头：主角听完旧录音后崩溃大哭。

拆成：
镜头1：旧录音停顿。
镜头2：主角手指停在按钮上。
镜头3：空房间环境声。
镜头4：主角把杯子转回原位。
镜头5：背影留白。
```

### 14.3 产品证明拆法

```text
原镜头：产品出现并解决所有问题。

拆成：
镜头1：痛点特写。
镜头2：产品动作。
镜头3：过程细节。
镜头4：结果对比。
镜头5：品牌记忆帧。
```

## 15. 后期补救法

能通过剪辑解决的，不一定重生成。

可剪辑补救：

- 动作中间小瑕疵：用反应镜头切掉。
- 道具位置轻微变化：用特写遮挡过渡。
- 光色轻微不一致：调色统一。
- 动作不够连贯：用音效和剪辑点建立因果。
- 情绪不足：加环境声、停顿和更克制的音乐。

不可只靠后期补救：

- 主角身份变了。
- 产品形状错误。
- 关键道具消失。
- 空间关系完全错。
- 核心动作看不懂。
- 违规或侵权素材风险。

## 18. 导演自检

修复前问自己：

1. 这是生成瑕疵，还是原分镜过难？
2. 角色是否仍能被观众认出？
3. 道具和产品是否仍清楚？
4. 动作因果是否成立？
5. 声音是否能补足画面？
6. 是否可以用反应镜头解决？
7. 修复成本是否低于重做？
8. 是否保护了最强一帧？
9. 是否影响发布封面？
10. 修完后能不能进入剪辑？
