# AI超级导演类型现场调度卡库

## 1. 定位

这份卡库用于把“电影、特摄、短片、短剧、可爱治愈、动作打斗、创意广告、爆款视频”的方法，压缩成现场可调用的导演调度卡。它不是替代类型公式，也不是替代电影/特摄/创意精华转译库；它负责把抽象判断落成一镜一镜的现场拍法。

一句话用法：

```text
先选卡，再拍镜头。卡片决定第一眼给什么、人物怎么动、镜头像谁、声音落在哪、Seedance 怎么拆。
```

## 2. 触发场景

用户说以下需求时，默认调用本库：

- “直接帮我拍”“你来判断”“现场调度”“像活人导演”。
- “电影感但别空”“特摄感”“短片质感”“创意广告像大片”。
- “这个怎么开场”“前三秒怎么拍”“第一镜怎么抓人”。
- “分镜太散”“镜头不连贯”“动作看不清”“人物不活”。
- “给我选导演拍法”“帮我选卡”“用什么镜头身体”。

## 3. 选卡顺序

```text
主类型 -> 观众站位 -> 第一帧任务 -> 冲突/情绪/卖点 -> 空间关系 -> 镜头身体 -> 声音落点 -> Seedance难度
```

输出前先说：

```text
我会这样拍：这场我先用[卡名]，不急着堆画面。先让观众看见[第一眼信息]，再让[动作/反应/声音]把情绪或冲突推上去。
```

每张调度卡都必须包含：

## 5. 开场卡

### 5.1 反常结果开场卡

适合：爆款视频、短剧、悬疑短片、创意广告、特效短片。

```text
第一帧：直接给结果，不解释原因。
摄影机身体：第三人称旁观或过肩，保证观众看清异常。
空间站位：异常物放在画面中心或角色视线尽头，人物站在边缘反应。
人物动作：角色先停住，再慢半拍靠近或后退。
声音落点：环境声先断一下，再进入轻微低频或角色吸气。
剪辑点：在角色要触碰异常物前切下一镜。
Seedance拆法：4-5秒，只生成“发现异常”这一件事。
避免：一边解释背景一边展示异常，削弱第一眼。
```

### 5.2 声音先行开场卡

适合：情感短片、怀旧、悬疑、公益、品牌微电影。

```text
第一帧：画面安静，但先听到不属于现场的声音。
摄影机身体：记忆卡或旁观卡，镜头不急着找声源。
空间站位：旧物在前景，人物在后景或画外。
人物动作：人物听见声音后手停住，眼神慢慢抬起。
声音落点：旧录音、广播、脚步、门铃、童声、机械声先半拍进入。
剪辑点：声音里出现关键词或熟悉节奏时切到旧物特写。
Seedance拆法：第一镜只做“听见”，第二镜再做“寻找来源”。
避免：用旁白解释“他想起了过去”。
```

### 5.3 尺度反差开场卡

适合：可爱群像、特摄、奇幻、产品广告。

```text
第一帧：小主体面对远超自己尺度的大任务。
摄影机身体：低机位旁观或胸口卡，让观众贴近小主体。
空间站位：小主体靠前，大任务物体占据背景或画面上半区。
人物动作：小主体认真整理工具、抬头、吞口水或点头。
声音落点：小脚步、布料声、轻微鼓点或群像吸气。
剪辑点：小主体做出“我来”的动作时切。
Seedance拆法：建立尺度一镜，行动尝试一镜，群像反应一镜。
避免：只把主体做小，但没有任务压力。
```

## 6. 电影短片卡

### 6.1 选择压力卡

适合：电影感短片、情感、短剧、品牌微电影。

```text
第一帧：角色站在两个选择之间，例如门内门外、桌子两侧、光暗交界。
摄影机身体：旁观卡或过肩卡，镜头保持克制。
空间站位：选择A和选择B必须在画面里有空间方向。
人物动作：角色手伸出又停住，眼神避开，再看向决定方向。
声音落点：环境声变小，只留呼吸、钟声或衣料摩擦。
剪辑点：角色迈出第一步时切，不解释心理。
Seedance拆法：4-6秒，一镜只拍“犹豫到选择”。
避免：用大段台词说“我不知道该怎么办”。
```

### 6.2 余味收口卡

适合：治愈、怀旧、公益、完整短片、品牌微电影。

```text
第一帧：事件已经结束，角色做一个小动作收拾情绪。
摄影机身体：固定旁观或记忆卡。
空间站位：人物不必居中，道具或光线承担记忆点。
人物动作：关灯、合上盒子、把杯子推回原位、替人留一把伞。
声音落点：音乐不抢，保留环境声和动作声。
剪辑点：动作完成后多留半秒。
Seedance拆法：不超过5秒，动作简单，情绪靠停顿。
避免：结尾再用旁白把主题说满。
```

## 7. 特摄与特效卡

### 7.1 仪式变身卡

适合：特摄、英雄登场、产品品牌化、角色IP。

```text
第一帧：手部、道具或胸口标志先进入，不先给全身大特效。
摄影机身体：手部卡、胸口卡或低机位第二人称。
空间站位：角色站在现实场景里，背景要可信。
人物动作：手握道具、停半拍、触发、抬头。
声音落点：环境声抽空，短促机械声或低频进入。
剪辑点：光线包裹到脸或胸口时切下一镜。
Seedance拆法：第一镜触发，第二镜形态稳定，第三镜反应或登场。
避免：一镜里同时变身、飞行、爆炸、打斗。
```

### 7.2 必杀停顿卡

适合：特摄、动作、超能力、爆炸、打斗高潮。

```text
第一帧：角色已经蓄势，但还没释放。
摄影机身体：低机位第三人称或胸口卡。
空间站位：攻击方向、目标、受力对象必须明确。
人物动作：呼吸停住、手腕收紧、肩膀压低，再释放。
声音落点：爆发前静半秒，爆发时低频和冲击声一起进。
剪辑点：释放后切受力结果，不停留在炫光里。
Seedance拆法：蓄势一镜，释放一镜，受力结果一镜。
避免：只写“炫酷能量爆发”，没有结果。
```

### 7.3 现实基准破裂卡

适合：特效短片、科幻、悬疑、产品科技广告。

```text
第一帧：正常现实画面先站住。
摄影机身体：旁观卡或道具卡，稳定机位优先。
空间站位：异常从一个具体对象开始，例如杯水、路灯、玻璃、屏幕。
人物动作：角色先发现小异常，再试探靠近。
声音落点：细小异常声先出现，再扩大成空间低频。
剪辑点：异常开始规则化扩散时切。
Seedance拆法：小异常一镜，规则扩散一镜，人物反应一镜。
避免：没有日常对比就直接奇观。
```

## 8. 可爱治愈卡

### 8.1 小主体大任务卡

适合：可爱、软萌、幼儿园、治愈广告、系列IP。

```text
第一帧：小主体面对一个明显比自己大的任务。
摄影机身体：低机位旁观，像蹲在它旁边。
空间站位：任务物体占据画面一侧，小主体在另一侧认真准备。
人物动作：卷袖子、抱工具、点头、试探性迈步。
声音落点：小脚步、工具碰撞、轻轻吸气。
剪辑点：第一次尝试失败或成功前切反应镜头。
Seedance拆法：任务建立、尝试、反应三镜。
避免：只拍萌，没有任务。
```

### 8.2 温柔介入卡

适合：治愈、温柔广告、亲情、陪伴关系。

```text
第一帧：角色处在一个微小伤口里，比如疲惫、落单、弄坏东西。
摄影机身体：旁观卡或过肩卡，距离不压迫角色。
空间站位：介入者从画面边缘进入，不抢主角。
人物动作：递杯子、扶正物件、把灯调暗、把伞靠过去。
声音落点：动作声比音乐重要。
剪辑点：主角的防御松一下时切。
Seedance拆法：伤口一镜，介入一镜，情绪松动一镜。
避免：介入者用大道理安慰。
```

## 9. 创意广告卡

### 9.1 产品动作证明卡

适合：产品广告、信息流、种草、功能证明。

```text
第一帧：痛点已经可视化，观众一眼看懂问题。
摄影机身体：第三人称或道具卡。
空间站位：产品放在动作路径上，不是摆在角落。
人物动作：产品必须做事：清洁、连接、遮挡、修复、提亮、保护、加速。
声音落点：产品动作要有明确音效。
剪辑点：可见变化出现的一瞬间切证据特写。
Seedance拆法：痛点一镜，产品动作一镜，结果证据一镜。
避免：产品只被展示，不参与改变。
```

### 9.2 品牌记忆帧卡

适合：商业广告、品牌微电影、客户提案。

```text
第一帧：结尾画面要能截图传播。
摄影机身体：稳定旁观或低机位英雄视角。
空间站位：产品、人物反应、品牌色或关键道具形成清楚关系。
人物动作：角色做一个固定动作，例如合上、举起、贴近、放下、回头。
声音落点：一句短口号或一个固定音效后期加。
剪辑点：动作完成后停半秒，留包装空间。
Seedance拆法：画面干净，文字和Logo后期添加。
避免：让模型直接生成复杂品牌字或Logo。
```

## 10. 短剧冲突卡

### 10.1 身份问题卡

适合：竖屏短剧、爽剧、反转、悬疑开场。

```text
第一帧：角色身份和处境冲突同时出现。
摄影机身体：第二人称或过肩卡，让观众像站在冲突现场。
空间站位：压迫者更靠近镜头，主角被压在画面后方或边缘。
人物动作：压迫者逼近，主角先退一步，再停住。
声音落点：一句短台词后留反应，不超过12个汉字。
剪辑点：主角眼神变化时切下一镜。
Seedance拆法：压迫一镜，反应一镜，反转信息一镜。
避免：第一镜解释身世背景。
```

### 10.2 打脸反转卡

适合：爽剧、反杀、站队、追更。

```text
第一帧：先让观众看见主角被低估。
摄影机身体：过肩卡或旁观卡。
空间站位：围观者形成压力圈，出口或证据在主角身后。
人物动作：主角先低头整理一个小物件，再抬眼。
声音落点：嘈杂声先压过主角，反转时突然安静。
剪辑点：证据或身份露出一角时切。
Seedance拆法：低估一镜，主角反应一镜，证据露出一镜。
避免：一镜里把所有真相说完。
```

## 11. 动作打斗卡

### 11.1 空间先行卡

适合：打斗、追逐、动作看不清、群像冲突。

```text
第一帧：先给门、桌、墙、出口、障碍物和双方距离。
摄影机身体：第三人称旁观，稍微宽一点。
空间站位：攻击方、被压制方、逃离方向必须清楚。
人物动作：一方逼近，另一方退到障碍物旁。
声音落点：脚步、碰撞、呼吸先建立节奏。
剪辑点：第一次接触前切近景。
Seedance拆法：空间建立一镜，第一次接触一镜，受力结果一镜。
避免：一上来手持乱晃。
```

### 11.2 受力结果卡

适合：打斗、特效、爆炸、产品冲击证明。

```text
第一帧：动作已经发生，重点拍结果。
摄影机身体：旁观卡或低机位。
空间站位：受力对象、受力方向、落点清楚。
人物动作：后退、撞到桌边、膝盖一软、衣角被风压掀起。
声音落点：打击声后留一拍环境回响。
剪辑点：角色重新抬眼或下一次反击前切。
Seedance拆法：不要把接触和复杂连招塞在同一镜。
避免：没有后果的“重击”。
```

## 12. 组合规则

常见组合：

| 需求 | 推荐卡组 |
| --- | --- |
| 可爱爆款短片 | 尺度反差开场卡 + 小主体大任务卡 + 反应接力 + 品牌/系列记忆帧 |
| 怀旧情感短片 | 声音先行开场卡 + 选择压力卡 + 温柔介入卡 + 余味收口卡 |
| 特摄短剧开头 | 现实基准破裂卡 + 仪式变身卡 + 必杀停顿卡 + 受力结果卡 |
| 产品创意广告 | 反常结果开场卡 + 产品动作证明卡 + 人物反应 + 品牌记忆帧卡 |
| 爽剧反转 | 身份问题卡 + 空间压迫 + 打脸反转卡 + 下一集问题 |
| 动作打斗 | 空间先行卡 + 受力结果卡 + 必杀停顿卡 + 反应镜头 |

## 14. 自检

输出前自问：

1. 我有没有先选卡，而不是直接堆形容词？
2. 第一帧是否能让观众立刻知道要看什么？
3. 摄影机身体是否清楚：眼睛、胸口、手、肩后、道具、记忆、旁观还是第二人称？
4. 空间站位是否能避免左右跳和动作混乱？
5. 声音是否有落点，不是最后才补一行音乐？
6. 每条 Seedance 镜头是否只有一个主要动作和一个主要运镜？
7. 对白是否短、嘴部可见、单说话人优先？
8. 文字、Logo和字幕是否后期添加？
9. 结尾是否有记忆帧、余味、转化或追更问题？
10. 这套卡组是否服务主类型，而不是炫技？
