# AI超级导演特摄变身、英雄登场、怪兽压力与必杀技引擎

## 1. 定位

这份引擎用于处理特摄感、英雄登场、变身、怪兽、超能力觉醒、必杀技、热血短剧、品牌英雄化广告和特效短片高潮。

特摄不是“满屏光效”，而是现实基准、仪式动作、尺度对比、规则显现和受力结果。观众先相信这个世界是真的，才会相信奇观有重量。

默认原则：

1. 先建立现实基准，再让异常破坏基准。
2. 变身必须有触发物、手部动作、短暂停顿和形态稳定。
3. 英雄登场必须让空间关系改变，不只是亮相。
4. 怪兽或反派必须有压力方向，让观众知道危险从哪里来。
5. 必杀技必须有蓄力停顿、释放方向、受力结果和反应镜头。
6. Seedance 2.0 中不要一镜同时完成变身、飞行、爆炸、打斗和群体反应。

## 2. 特摄场面骨架

```text
现实基准
-> 异常征兆
-> 触发物/仪式动作
-> 形态或能力稳定
-> 压力方向
-> 必杀前停顿
-> 释放/碰撞
-> 受力结果
-> 人物或群体反应
```

如果只有 6 秒，至少保留：

```text
现实基准 -> 触发动作 -> 形态稳定 -> 反应
```

如果是 15-30 秒，增加：

```text
怪兽压力 -> 必杀停顿 -> 受力结果
```

## 3. 现实基准

现实基准回答：奇观发生前，这个世界本来是什么样？

可用基准：

| 基准 | 用法 |
| --- | --- |
| 街角/天台/操场 | 英雄或怪兽有空间尺度 |
| 普通人反应 | 证明奇观真实发生 |
| 小道具 | 触发变身或能力 |
| 产品/品牌物 | 品牌英雄化广告 |
| 日常任务 | 可爱特摄、小主体大任务 |

规则：

1. 第一镜不要直接满屏爆炸。
2. 基准里必须有可对比的物体或人物。
3. 现实基准越清楚，奇观越可信。

## 4. 变身仪式

变身不是换皮肤，是角色做出选择。

变身字段：

```text
触发物：
手部动作：
身体停顿：
光/声音征兆：
形态稳定姿态：
旁观者反应：
```

动作例子：

- 手握住道具，拇指按下开关。
- 护住胸口，抬眼停半秒。
- 把产品或徽章推向镜头。
- 脚步停住，肩膀放松，转身面对压力方向。

禁用：

- 长台词解释设定。
- 一镜里从普通人直接变成完整大战。
- 光效遮住脸、手和道具。
- 变身后没有稳定姿态。

## 5. 英雄登场

英雄登场不是摆造型，而是改变局势。

登场方式：

| 登场 | 空间效果 | 镜头 |
| --- | --- | --- |
| 挡在弱者前面 | 改变压力方向 | 低机位中景 |
| 从光后走出 | 未知变成可见 | 逆光剪影到正面 |
| 把道具放到中心 | 让规则显现 | 手部特写到中景 |
| 停住怪兽冲击 | 证明力量 | 受力结果镜头 |
| 背对观众面对危险 | 让观众站在被保护者位置 | 过肩或第二人称 |

登场必须回答：

1. 他保护谁？
2. 他挡住什么？
3. 登场后危险方向有没有改变？

## 6. 怪兽压力

怪兽不一定要完整同框，压力必须清楚。

压力表现：

- 地面震动。
- 影子覆盖角色。
- 远处建筑被挤压。
- 人群或小角色看向同一方向。
- 道具被风压推动。
- 声音先到，画面后到。

规则：

1. 先给尺度对比，再给怪兽局部。
2. 不一定要一镜生成完整怪兽全身。
3. 怪兽动作要简单：逼近、停住、抬爪、低头、冲击。
4. 群体反应用分组镜头，不硬塞大群人同框。

## 7. 必杀技

必杀技不是最大光效，而是一次规则兑现。

必杀字段：

```text
蓄力动作：
短暂停顿：
释放方向：
命中对象：
受力结果：
反应镜头：
声音落点：
```

必杀节拍：

```text
静
-> 手部/身体蓄力
-> 声音抽空
-> 释放
-> 受力结果
-> 反应停顿
```

禁用：

- 没有蓄力，直接爆炸。
- 看不清释放方向。
- 命中后没有结果。
- 爆炸遮住所有动作。

## 8. 品牌英雄化广告

品牌或产品可以做特摄感，但卖点必须被证明。

结构：

```text
现实痛点
-> 产品触发
-> 品牌英雄化仪式
-> 卖点能力显现
-> 可见变化
-> 用户反应
-> 品牌记忆帧
```

规则：

1. 产品不是发光摆件，必须触发动作。
2. 能力规则要对应卖点：快、稳、轻、防护、清洁、修复、补能。
3. 品牌字默认后期添加。
4. 不照搬已有英雄造型、标志、台词或变身动作。

## 9. Seedance 2.0 拆镜规则

高风险镜头默认拆：

| 风险镜头 | 拆法 |
| --- | --- |
| 完整变身 | 触发物特写 -> 光线包裹 -> 形态稳定 -> 反应 |
| 怪兽登场 | 地面震动 -> 影子压过 -> 局部出现 -> 人物反应 |
| 必杀技 | 蓄力手部 -> 释放方向 -> 受力结果 -> 反应停顿 |
| 群体惊呼 | 主角反应 -> 两三人小组反应 -> 空间结果 |
| 品牌英雄化 | 产品动作 -> 能力显现 -> 可见变化 -> 品牌记忆帧 |

特摄镜头提示词必须写清：

```text

尺度对比：

```

单镜提示词骨架：

```text
稳定中景，[现实空间]中先建立普通基准，[角色]面对来自[方向]的压力，手部清楚握住[触发物]并做[仪式动作]，动作后停顿半秒，[光/声音征兆]短暂出现但不遮住脸和手，角色形成稳定登场姿态，周围角色只做轻微反应，特摄感来自现实基准、仪式和尺度对比，不生成已有IP标志、Logo、可读文字或复杂字幕。
```

## 12. 审片自检

1. 是否先建立现实基准？
2. 变身是否有触发物和手部动作？
3. 英雄登场是否改变空间关系？
4. 怪兽压力方向是否明确？
5. 必杀技是否有蓄力、释放、受力和反应？
6. 是否避免复刻已有IP造型、标志、台词或动作？
7. Seedance 提示词是否拆掉了过高风险的一镜多事？
