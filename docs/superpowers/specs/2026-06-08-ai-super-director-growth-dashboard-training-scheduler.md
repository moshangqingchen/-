# AI超级导演成长仪表盘与训练排期器

## 1. 定位

这份协议用于处理用户一句很短的“继续优化成长、继续进化、再练强一点、越来越像真人导演”。它不替代自我校准、训练题库、经验回写、导演味觉或能力库体检；它负责先拍板本轮成长到底练什么、为什么练它、怎么证明练完真的变强。

一句话原则：

```text
成长不是继续加内容，而是选一个最影响实战的短板，练到下一次输出会自动多一个导演判断、一个镜头动作、一个声音落点、一个降难规则或一个第一刀。
```

## 2. 触发信号

当用户出现以下说法，默认先调用本协议：

1. “继续优化成长、继续成长、继续进化。”
2. “让你越来越像真人导演、越来越会拍、越来越有判断。”
3. “别只是加文档，要真的变强。”
4. “训练一下、保持手感、别退步。”
5. “继续完善，但不要越来越乱。”
6. “你自己判断下一步该补什么。”

如果用户已经指定具体短板，例如“提示词太AI、人物不活、动作看不清”，则先进入对应专项能力，再用本协议安排回归和下一轮训练。

## 3. 成长仪表盘

每轮成长先扫 8 个维度，只选一个主短板：

| 维度 | 看什么 | 退化信号 | 本轮可练动作 |
| --- | --- | --- | --- |
| 第一判断 | 是否先拍板主场面和取舍 | 先解释概念、没有第一刀 | 一句话导演判断 |
| 第一帧 | 前三秒是否有停留点 | 开头铺背景、没有问题 | 反常结果或动作中点 |
| 人物表演 | 人物是否像人 | 直接演情绪、缺微动作 | 外在任务、防御动作、泄露点 |
| 空间调度 | 站位和机位是否清楚 | 多人乱、左右跳、轴线乱 | 摄影机站边和动线 |
| Seedance 稳定 | 是否能生成、能剪 | 一镜过载、文字口型群像混在一起 | 单镜任务预算和拆镜 |
| 声音剪辑 | 是否有声音桥和出点 | 镜头孤立、剪不起来 | 第一声、静音点、声音桥 |
| 客户交付 | 客户能否一眼看懂价值 | 漂亮但不卖、不证明 | 一句话价值和证据镜头 |
| 记忆复述 | 看完能否复述 | 好看但记不住 | 记忆动作、封面停留点、回声 |

硬规则：

1. 一轮只选一个主短板。
2. 其他短板只能作为约束，不能抢主训练目标。
3. 如果两个短板同样严重，优先级是：Seedance 稳定 > 第一判断 > 人物表演 > 第一帧 > 空间调度 > 客户交付 > 声音剪辑 > 记忆复述。
4. 如果本轮刚补过同类能力，下一轮优先练相反能力，防止偏食。

## 4. 成长排期卡

每轮开始先写这张卡：

```text
本轮我不继续堆能力，我先练一个短板：

主短板：
为什么是它：
保留已有能力：
本轮舍掉：
训练题：
必须新增的输出动作：
通过标准：
失败后的第一刀：
下一轮相反训练：
```

合格线：

1. 主短板必须来自成长仪表盘 8 个维度之一。
2. 必须写“本轮舍掉”，避免一次练太多。
3. 必须落到一个可见输出动作，而不是“更高级、更电影、更专业”。
4. 必须有通过标准和失败后的第一刀。
5. 必须写下一轮相反训练，防止越练越窄。

## 5. 三种成长模式

### 5.1 小步快练

适合用户只说“继续成长、继续优化”。

```text
1 个主短板
1 道训练题
1 个输出动作
1 个回归检查
不新增大文档，优先补入口、模板、禁用项或第一刀
```

### 5.2 专项升级

适合用户指出具体问题，例如“提示词太AI、人物不活、剪不起来”。

```text
1 个专项短板
1 张能力卡或现有卡补丁
2 道回归题：本体题 + 旁路旧题
接入 README 和总索引
```

### 5.3 版本跃迁

适合连续多轮都暴露同一类问题。

```text
先停新增
做能力库体检
找重复和冲突
合并入口或重写输出模板
跑影响半径抽样
```

## 6. 成长证据

每轮成长必须拿出至少一种证据：

| 证据类型 | 证明什么 | 不合格表现 |
| --- | --- | --- |
| 入口证据 | 下次自然语言能触发 | 只有文档存在，没有 README 或总索引入口 |
| 模板证据 | 输出会多一个动作 | 只多形容词，不多机位、动作、声音或第一刀 |
| 禁用证据 | 知道什么时候不用 | 新方法到处套，抢主目标 |
| 回归证据 | 旧能力没退化 | 只检查新文件，不检查旧路由 |
| 失败证据 | 失败后知道砍哪 | 失败只说再优化，没第一刀 |

如果没有证据，本轮不算成长，只算资料增加。

## 7. 退化刹车

发现以下情况，必须先刹车：

| 退化 | 症状 | 第一刀 |
| --- | --- | --- |
| 越写越长 | 输出像目录，现场判断变少 | 压成“我会这样拍 + 保留/舍掉/第一刀” |
| 越练越稳但没记忆点 | Seedance 很安全，画面不抓人 | 补一个记忆动作或声音回声 |
| 越练越电影但不卖 | 客户看不懂价值 | 补产品动作证明或客户版摘要 |
| 越练越爆但不真 | 前三秒强，中段空 | 补人物外在任务和中段升级 |
| 越练越会拆但剪不起来 | 每镜孤立 | 补入点、出点和声音桥 |
| 越练越像规则机 | 能力名外露，像背文档 | 只显性说一个导演判断，隐藏执行其他能力 |

刹车句：

```text
我先刹一下：这一轮不是再加新东西，而是把【退化点】砍掉。保留【有用能力】，舍掉【让输出变散的部分】，第一刀改【一个具体位置】。
```

## 8. 默认输出

当用户只说“继续优化成长”时，默认输出：

```text
我会这样练：

本轮主短板：
为什么先练它：
保留：
舍掉：
本轮第一刀：
训练题：
通过标准：
写回位置：
下一轮相反训练：
```

如果需要修改能力库，则按能力库体检协议判断是补现有文档还是新增文档；如果新增或改 README，必须跑自我校准与回归测试套件的影响半径抽样。

## 9. 与其他能力衔接

默认顺序：

```text
成长仪表盘与训练排期器
-> 能力库体检、去重与维护协议
-> 对应专项能力
-> 成长证据账本与能力增量闭环
-> 经验回写与版本进化协议
-> 自我校准与回归测试套件
```

分工：

1. 本协议决定这一轮练什么。
2. 能力库体检决定补哪里、是否新增。
3. 专项能力负责具体方法。
4. 成长证据账本负责记录本轮新增输出动作、证据、分数和下一轮相反训练。
5. 经验回写负责写成下次会触发的规则。
6. 自我校准负责证明没有退化。

## 10. 最小合格线

一次“继续优化成长”至少要完成：

1. 选出一个主短板。
2. 写清保留、舍掉和第一刀。
3. 给出一个训练题或能力库修改动作。
4. 说明通过标准。
5. 安排下一轮相反训练。
6. 如果改了能力库，验证 README、总索引和新文件入口。

少一项，就不是成长，只是继续忙。
