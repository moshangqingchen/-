# AI超级导演自我校准与回归测试套件

## 1. 定位

这份套件用于检查 AI超级导演每次进化后有没有真的变强、变稳、变像一个能交付的超级工具。它不是训练题库的替代品，而是一组回归测试：只要能力库新增、改写或升级，就用这些标准题快速检验是否出现退化。

核心原则：

```text
不是写得更长就算进化。
能判断、能取舍、能生成、能剪起来、能防错，才算进化。
```

每次测试都看五件事：

1. 是否先给导演判断，而不是先铺概念。
2. 是否明确保留、舍掉和第一刀。
3. 是否把抽象情绪、卖点或类型变成可见动作。
4. 是否按 Seedance 2.0 的可生成性降难、拆镜和预留字幕安全区。
5. 是否在结尾给出可复用的记忆点、通过标准或下一刀。

## 2. 使用方式

当用户说“继续完善、进化、训练一下、检查能力、别出错、像超级工具”时，可以抽取 3-5 道题做自测。

默认流程：

```text
选题 -> 先写理想输出骨架 -> 对照门禁评分 -> 找最弱项 -> 回写能力库或输出规则
```

评分标准：

| 分数 | 含义 |
| --- | --- |
| 5 | 像现场导演，判断清楚，能生成，能剪，能交付 |
| 4 | 基本可用，有小漏项，但不影响主结果 |
| 3 | 有创意但不稳，容易跑偏或剪不起来 |
| 2 | 主要停留在概念、形容词或堆镜头 |
| 1 | 路由错、风险没处理、交付物不匹配 |

低于 4 分必须写“第一刀修正”。

## 3. 标准回归题

### 3.1 一句话创意题

输入：

```text
做一个可爱治愈的咖啡广告。
```

必须触发：

- 一页式实战指挥台。
- 可爱治愈导演调度。
- 广告证明链。
- 第一帧与前三秒。

通过标准：

1. 第一帧有“小主体大任务”或微小困难。
2. 咖啡卖点通过动作证明，而不是只说香、暖、高级。
3. 有人物或小主体的反应停顿。
4. 有封面可截图落点。
5. Seedance 提示词不直接生成可读中文。

常见失败：

- 只写“温暖治愈的氛围”。
- 只有杯子空镜，没有产品动作。
- 可爱角色只是摆设，没有任务。

### 3.2 短剧冲突题

输入：

```text
做一个竖屏短剧第一集，要爽、反转、让人想看下一集。
```

必须触发：

- 短剧冲突链。
- 阻碍者压力。
- 第一镜冷开场。
- 对白口型同步。

通过标准：

1. 第一镜不解释背景，直接给冲突或反常结果。
2. 主角欲望和阻碍者目标都清楚。
3. 信息差明确：谁知道，谁不知道。
4. 反转不是硬拧，而是回收伏笔。
5. 下一集问题具体，不是“敬请期待”。

常见失败：

- 开头 10 秒介绍人设和世界观。
- 反派只是坏，没有压力手段。
- 反转只靠一句台词宣布。

### 3.3 打斗特效题

输入：

```text
设计一场更炸的超能力打斗，动作要看清楚。
```

必须触发：

- 动作打斗、追逐与特效场面编排。
- 空间轴线。
- Seedance 可生成性拆镜。
- 声音打击点。

通过标准：

1. 先定空间基准和双方目标。
2. 每个动作有起点、触发点、受力结果和反应。
3. 每条 Seedance 镜头控制在 4-6 秒左右。
4. 不在一镜里同时要求复杂运镜、爆炸、飞行、多人反应和精确口型。
5. 声音打击点和剪辑点清楚。

常见失败：

- “两人激烈大战，能量爆炸，镜头环绕”这类空泛写法。
- 动作没有受力结果，看不出谁打中了谁。
- 特效比人物目标更重要。

### 3.4 电影精华转译题

输入：

```text
吸取某类电影的精华，做一个原创品牌微电影。
```

必须触发：

- 参考作品拆解、原创替换与合规转译。
- 电影、特摄、短片与创意精华转译。
- 品牌记忆点。
- 合规风险。

通过标准：

1. 明确可继承层：情绪、结构、调度、视觉母题、声音记忆。
2. 明确禁用层：角色、台词、Logo、IP 符号、标志性画面。
3. 至少完成角色关系、场景任务、视觉母题三次替换。
4. 品牌不只是贴片，而是通过动作或选择进入故事。
5. 有原创记忆帧。

常见失败：

- 换名复刻原片桥段。
- 只说“电影感”，没有转译规则。
- 品牌最后才硬贴 Logo。

### 3.5 Seedance 多镜头题

输入：

```text
把这个分镜写成整条 Seedance 2.0 提示词。
```

必须触发：

- 风格参考与镜头风格圣经。
- Seedance 2.0 人称运镜。
- 连续性场记。
- 可生成性拆镜。

通过标准：

1. 先给统一风格锁定句。
2. 每镜都有画幅、时长、角色连续性、空间方向、动作因果、入点、出点、声音桥和字幕安全区。
3. 高风险镜头有降难或拆镜策略。
4. 多镜头之间有动作、视线或声音匹配。
5. 中文、字幕、品牌字默认后期添加。

常见失败：

- 每镜风格都变。
- 只给画面描述，没有入点出点。
- 让视频模型直接生成可读中文。

### 3.6 人物表演题

输入：

```text
这段人物不活，演得太 AI，帮我调真实一点。
```

必须触发：

- 现场表演调度与情绪动作谱。
- 微动作、表情反应与动作节拍。
- 人物动机与关系弧线。

通过标准：

1. 写清外在任务，而不是让人物直接演情绪。
2. 写清内心真相和防御动作。
3. 有破防瞬间和收回动作。
4. 镜头知道落在手、眼神、道具还是停顿上。
5. 台词短，反应镜头能承接情绪。

常见失败：

- 直接写“他很悲伤、她很愤怒”。
- 情绪一上来就满，没有防御。
- 没有微动作和收回动作。

### 3.7 客户交付题

输入：

```text
给客户看，做成完整方案。
```

必须触发：

- 类型成片交付标准包。
- 项目交付包。
- 输出审片评分。
- 合规风险。

通过标准：

1. 有导演判断、保留、舍掉和第一刀。
2. 有项目名、类型、受众、核心创意和风格锁定。
3. 有分镜表和 Seedance 逐镜提示词。
4. 有后期文字、声音、封面标题和发布包装。
5. 有可生成性评级、合规提醒和审片升级。

常见失败：

- 客户方案像灵感草稿。
- 只有分镜，没有后期和发布。
- 没有风险提示和审片评分。

### 3.8 返工迭代题

输入：

```text
这镜跑偏了，角色漂了，动作也乱，再跑一版。
```

必须触发：

- Seedance 返工迭代协议。
- AI 生成连续性修复。
- 不出错工具化防错协议。

通过标准：

1. 先判断原镜头目标和跑偏原因。
2. 本轮只改一个变量。
3. 明确必须锁住角色、服装、道具或空间方向。
4. 明确必须删掉的复杂要求。
5. 给通过标准和失败后的下一刀。

常见失败：

- 同时改风格、机位、动作、角色和时长。
- 没写锁定项。
- 没有下一轮策略。

## 4. 退化信号

出现这些情况，说明能力库需要回修：

1. 回答越来越长，但第一帧越来越弱。
2. 类型越来越多，但主类型越来越不清。
3. 分镜越来越漂亮，但入点、出点和声音桥缺失。
4. 提示词越来越华丽，但 Seedance 越来越难生成。
5. 客户方案越来越完整，但少了导演判断和第一刀。
6. 返工越来越勤快，但每轮没有固定一个变量。
7. 参考作品越来越像，但原创替换越来越少。

回修方式：

```text
先回到一页式实战指挥台，重新选主入口。
再进不出错防错协议，找最高风险点。
最后只修一个最弱环节。
```

## 5. 输出退化雷达

能力库越厚，输出越要防止“看起来更完整，实际更不导演”。每轮进化后，至少用下面 8 个雷达点扫一遍。

| 退化症状 | 典型表现 | 第一刀修法 |
| --- | --- | --- |
| 短需求不拍板 | 用户只问一句，回答先铺背景、定义和目录 | 改成一句导演拍板：主场面、保留、舍掉、第一刀 |
| 能力目录外露 | 把一堆能力名当答案念出来 | 只显性调用一个主入口，辅助能力隐性执行 |
| 表格过早 | 还没判断就先给大表 | 先写“我会这样拍”和取舍，再上表格 |
| 第一帧变弱 | 方案完整但前三秒没有停留点 | 回到第一帧停留点和前三秒问题 |
| 类型平均化 | 又短剧又广告又电影感，每个都浅 | 锁主类型，副类型只服务主场面 |
| Seedance 过载 | 一镜同时要口型、群像、强运镜、特效、文字 | 触发变量冲突刹车：保一个、拆一个、后期一个、删一个、先测一个 |
| 返工赌博 | 失败后把提示词写更长，同时改很多变量 | 本轮只改一个变量，其余全部锁住 |
| 活人感下降 | 语气像模板扩写，少现场判断和具体动作 | 改成现场导演句：看见现场、做取舍、给可执行动作 |

退化雷达输出卡：

```text
我先做退化雷达：

最明显退化：
【短需求不拍板 / 能力目录外露 / 表格过早 / 第一帧弱 / 类型平均 / Seedance 过载 / 返工赌博 / 活人感下降】

保留：
【本轮新增里真正有用的能力】

舍掉：
【让输出变长、变模板或变难生成的部分】

第一刀：
【只修一个退化点】

回归题：
【用哪一道标准题复测】
```

如果退化雷达发现 2 个以上问题，本轮不要继续新增能力，先回修入口、模板或禁用项。

## 6. 成长后回归抽样

每次完善能力库后，不需要把所有题都跑一遍，但必须按本轮影响范围抽样复测。抽样的目的不是证明“新增内容存在”，而是证明新增内容没有削弱旧能力。

| 本轮改动影响 | 必测回归题 | 重点看什么 |
| --- | --- | --- |
| 路由、仲裁、输出档位 | 一句话创意题、客户交付题 | 是否先拍板，是否只锁一个主入口，是否把能力目录藏起来 |
| 活人感、现场口吻、说戏 | 人物表演题、一句话创意题 | 是否像现场导演，是否有外在任务、防御动作和第一刀 |
| Seedance 提示词、可生成性、连续性 | Seedance 多镜头题、返工迭代题 | 是否一镜一主动作，是否写入点出点，是否只改一个变量 |
| 广告、产品证明、转化 | 客户交付题、一句话创意题 | 是否有产品动作、证据镜头和反应确认，不只写品牌口号 |
| 短剧、冲突、反转、追更 | 短剧冲突题、一句话创意题 | 是否第一镜给关系压力、信息差和选择代价 |
| 打斗、特效、特摄奇观 | 打斗特效题、Seedance 多镜头题 | 是否看清接触点、受力结果和生成拆镜 |
| 参考吸收、电影感、特摄感 | 电影精华转译题、Seedance 小样题 | 是否只继承骨架，不复刻角色、台词、Logo 或标志画面 |
| 审片、返工、救片 | 返工迭代题、Seedance 多镜头题 | 是否先判素材类别，是否单变量重跑，不硬救废段 |
| 客户提案、发布包装、交付 | 客户交付题、完整方案题 | 是否客户先看懂价值，执行细节没有丢 |

影响半径四点抽样：

| 抽样点 | 测什么 | 为什么必须测 |
| --- | --- | --- |
| 本体题 | 本轮被改的能力是否真的出现新行为 | 防止只把文字写进文档，输出没有变化 |
| 上游题 | 路由、仲裁、输出档位是否仍然选对入口 | 防止新增规则抢入口、误触发或把能力目录外露 |
| 下游题 | Seedance、客户交付、发布或后期是否还能执行 | 防止新规则让方案漂亮但不可生成、不可剪、不可交付 |
| 旁路旧题 | 一个看似无关的旧题是否仍保持原本质量 | 防止局部补丁污染通用语气、表格习惯、第一刀和防错门禁 |

四点抽样规则：

```text
每次能力库改动后，至少选 2 题：
1. 本体题必选。
2. 上游题、下游题、旁路旧题至少再选 1 题。
如果本轮改动影响 README 入口、输出状态、Seedance 字段或客户交付，必须选四点全测。
```

旁路旧题优先选和本轮改动不同类型的题。  
例如本轮补的是“参考吸收”，旁路旧题可以选“产品广告证明”或“短剧冲突”；本轮补的是“活人感”，旁路旧题可以选“Seedance 多镜头”或“客户交付”。  
如果旁路旧题变差，说明不是局部问题，而是输出总习惯退化，先回修输出档位、主入口锁定或活人导演校准。

抽样句式：

```text
本轮影响范围：
【路由/活人感/Seedance/广告/短剧/打斗/参考吸收/返工/客户交付】

影响半径：
【本体 / 上游 / 下游 / 旁路旧题】

必测回归题：
1. 本体题：【题名】检查【新增能力是否真的改变输出】。
2. 上游/下游/旁路题：【题名】检查【旧能力是否退化】。

通过线：
旧能力不变弱，新增能力不外露成目录，输出仍能拍、能剪、能生成、能交付。
```

如果抽样复测失败，不允许继续新增能力；先回修本轮改动的入口、模板、禁用项或第一刀。

## 7. 回归失败停机规则

抽样复测失败时，不要把失败写成“后续优化”。这说明本轮进化已经伤到旧能力，必须停机回修。停机不是停止成长，而是先把新能力磨成不会污染旧输出的工具。

### 7.1 失败分级

| 失败类型 | 判断标准 | 停机第一刀 |
| --- | --- | --- |
| 新能力未生效 | 本体题里看不到新增门禁、字段或判断动作 | 回修触发契约和输出契约 |
| 旧能力变弱 | 旁路旧题的第一帧、主类型、动作证据或 Seedance 稳定性下降 | 回修入口优先级和禁用项 |
| 输出变长变散 | 回答更完整但主场面、第一刀和主交付身份更不清 | 回修输出档位和主入口锁定 |
| 生成更难 | 新规则让单镜任务更多、提示词更长或风险变量更多 | 回修拆镜、降难和后期处理规则 |
| 活人感下降 | 语气像模板扩写，少现场判断、保留、舍掉和具体动作 | 回修活人导演校准和现场三秒预演 |
| 客户执行更难 | 客户版、导演版、执行版混在一起 | 回修主交付身份防混线 |

### 7.2 停机回修顺序

```text
1. 停止新增能力。
2. 写清失败回归题和失败症状。
3. 判断是触发错、输出错、禁用项缺失、模板过长还是第一刀不清。
4. 只回修一个位置：README 入口、专项文档模板、禁用项、第一刀或回归题。
5. 重新跑本体题和一个旁路旧题。
6. 两题都回到 4 分以上，才允许继续新增能力。
```

### 7.3 停机输出卡

```text
回归停机：
失败题：【题名】
失败症状：【新能力未生效 / 旧能力变弱 / 输出变长变散 / 生成更难 / 活人感下降 / 客户执行更难】
根因判断：【触发错 / 输出错 / 禁用项缺失 / 模板过长 / 第一刀不清】
保留：【本轮新增里仍然有用的部分】
回修第一刀：【只改一个入口、模板、禁用项、第一刀或回归题】
复测题：【本体题 + 旁路旧题】
恢复通过线：【两题都 4 分以上，且主场面、第一刀、可生成性不变弱】
```

硬规则：

1. 回归失败时，不允许继续新增第三张能力卡。
2. 旁路旧题下降，比本体题不够亮更严重。
3. 新能力如果必须靠长篇解释才能生效，说明触发契约没写好。
4. 回修只改一个位置，避免把一次退化修成新的系统噪音。

## 8. 每轮进化记录模板

每次完善能力库后，可以记录一小段：

```text
本轮新增：
解决的错误：
影响的入口：
新增门禁：
退化雷达：
抽样复测：
回归测试题：
自评分：
下一轮第一刀：
```

示例：

```text
本轮新增：不出错工具化防错协议。
解决的错误：多人同框、口型、中文文字、返工乱改。
影响的入口：Seedance、客户交付、返工。
```
