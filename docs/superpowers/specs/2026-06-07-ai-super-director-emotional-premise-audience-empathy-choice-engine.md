# AI超级导演情绪命题、观众代入与人物选择引擎

## 1. 定位

这套引擎用于把一个粗糙想法、产品需求、短剧设定或视觉概念，先压成观众能进入的情绪命题。它解决的问题是：画面很多，但观众不知道该在乎谁；设定很大，但人物没有选择；类型很准，但看完没有心跳。

它不替代类型公式、人物动机、短剧冲突或广告证明链。它在它们之前工作：先定观众站位、情绪问题、人物缺口、选择代价和最后留下的动作，再进入分镜、Seedance 2.0 提示词或客户方案。

默认公式：

```text
观众站位 + 情绪问题 + 人物缺口 + 外在目标 + 关系压力 + 选择代价 + 动作证明 + 余味回声
```

## 2. 触发词

当用户出现以下表达，默认进入本引擎：

- 这个想法怎么更打动人、怎么让观众在乎、怎么有情绪、怎么更有心。
- 故事没心跳、人物没选择、主题太空、情绪不落地、看完没感觉。
- 帮我提炼核心命题、这条片到底讲什么、观众为什么看、主角为什么非做不可。
- 广告想高级但不要空、短片想有余味、短剧想让人站队、治愈想不鸡汤。
- 第一人称代入、观众站位、让人共情、让人想评论、让客户觉得有温度。

如果用户已经明确要求某一类型，先用本引擎定情绪命题，再进入对应类型引擎；如果用户只要纯执行提示词，可以把本引擎压缩成一句“情绪锁定句”。

## 3. 导演判断

我会这样拍：先不急着找镜头。先问一句，观众是站在谁身边看这件事？如果观众不知道自己该替谁着急、替谁松一口气，再漂亮的镜头也是空的。人物必须有一个外在任务，也有一个不愿说出口的内在缺口；最后不是让他说主题，而是让他做一个带代价的小选择。

默认保留：

- 一个观众能马上理解的处境。
- 一个角色不愿承认的缺口。
- 一个必须完成的外在任务。
- 一个会改变关系的选择。
- 一个动作、声音或物件作为结尾回声。

默认舍掉：

- 抽象主题先行，例如“成长、陪伴、勇气、温暖”但没有动作。
- 角色只表达情绪，没有要做的事。
- 观众站位混乱，一会儿替主角，一会儿替品牌，一会儿替旁观者。
- 结尾用旁白总结道理，而不是用动作留下余味。

## 4. 情绪命题字段

| 字段 | 说明 |
| --- | --- |
| 观众站位 | 观众是主角、见证者、被请求的人、旁观者、加害后的醒悟者，还是未来的自己 |
| 情绪问题 | 观众脑内要问的问题：他会不会被看见、她会不会说出口、这件东西能不能救场 |
| 人物缺口 | 人物真正缺的不是功能，而是安全感、尊严、被理解、掌控感、告别、重新开始 |
| 外在目标 | 人物本镜必须完成的具体任务：送到、藏住、修好、证明、道歉、离开、留下 |
| 关系压力 | 谁在看他、谁不相信他、谁等他、谁误解他、谁会因此改变 |
| 选择代价 | 角色做这个选择会失去什么：面子、机会、秘密、距离、控制权或旧身份 |
| 动作证明 | 用一个动作证明情绪变化，而不是让角色说出情绪 |
| 余味回声 | 结尾回收一个前面出现过的动作、声音、道具或空间 |

## 5. 观众在乎冷启动检查表

粗想法进入分镜前，先用这张表判断观众会不会在乎。只要有两项答不上来，就先别写镜头。

| 冷启动问题 | 不合格表现 | 第一刀修法 |
| --- | --- | --- |
| 观众替谁着急？ | 只有主题、产品或世界观，没有一个可站位的人 | 选一个主视角：主角、见证者、使用者或被请求的人 |
| 他现在非做什么不可？ | 人物只是“感受情绪”，没有外在任务 | 给一个可拍任务：送到、藏住、修好、证明、道歉、留下 |
| 他真正怕失去什么？ | 代价只是“失败”，没有面子、秘密、关系或身份损失 | 写清选择代价，让动作变得有压力 |
| 谁或什么挡住他？ | 没有阻碍，事情顺着发生 | 加一个人、空间、时间、误会或产品痛点 |
| 情绪怎么被看见？ | 靠旁白解释“温暖、感动、勇敢” | 换成手部、眼神、停顿、道具或结果变化 |
| 结尾留下什么回声？ | 结尾靠金句、Logo 或道理总结 | 回收一个动作、声音、物件或空间变化 |

冷启动拍板句：

```text
我先不写镜头，先把观众为什么在乎定住：观众站在【谁】身边，看他必须【外在任务】，但他真正怕失去【选择代价】。这条片的情绪不靠解释，靠【动作证明】。
```

不同类型的“在乎”入口：

| 类型 | 观众在乎的不是 | 观众真正等的是 |
| --- | --- | --- |
| 短剧 | 设定多复杂 | 谁被逼选择，谁的权力被换手 |
| 创意广告 | 品牌多高级 | 产品能不能用一个动作解决真实麻烦 |
| 可爱治愈 | 角色多萌 | 小主体能不能撑过一个比自己大的任务 |
| 打斗特效 | 场面多炸 | 谁的目标被挡住，第一下受力会改变什么 |
| 情感短片 | 人物多悲伤 | 那句没说出口的话会不会变成一个动作 |
| 悬疑反转 | 氛围多黑 | 哪个异常会改变观众对真相的判断 |

这张表通过后，再进入类型公式、广告证明链、短剧冲突、人物表演或 Seedance 分镜。

## 6. 五种常用情绪命题

### 6.1 被看见

```text
观众站位：站在被忽略的人身边。
情绪问题：这一次他会不会终于被看见？
动作证明：别人第一次停下来看他手里的东西。
```

适合治愈短片、公益、品牌温柔广告、亲情、校园、职场和儿童向内容。

### 6.2 不敢说出口

```text
观众站位：知道人物心事的旁观者。
情绪问题：他会不会把那句话说出来？
动作证明：话没说出口，但手把东西递了过去。
```

适合情感短片、旧物叙事、克制爱情、亲情、朋友和离别。

### 6.3 必须证明

```text
观众站位：和质疑者一起看证据。
情绪问题：它到底能不能解决眼前的问题？
动作证明：产品、能力或团队用一个动作改变现场。
```

适合创意广告、企业品牌片、B2B、直播种草、汽车、运动和科普。

### 6.4 选择站队

```text
观众站位：站在关系压力中央。
情绪问题：他会选自己，还是选别人要他成为的人？
动作证明：角色用一个公开动作承担代价。
```

适合短剧、爽剧、反转、职场、群像和家庭冲突。

### 6.5 回到自己

```text
观众站位：看见人物从噪音里收回身体。
情绪问题：他能不能重新找回自己的节奏？
动作证明：人物停止迎合，做回一个很小但属于自己的动作。
```

适合治愈、旅行、家居、国风、梦境、运动恢复和生活方式广告。

## 8. 与其他资产的联动

- 进入短剧前：把情绪命题转成主角欲望、阻碍者、关系压力和选择代价。
- 进入广告前：把情绪命题转成观众不信的问题、产品动作证明和人物反应。
- 进入可爱治愈前：把情绪命题转成小主体大任务、微小伤口和温柔介入。
- 进入打斗特效前：把情绪命题转成双方目标、压力方向、受力结果和情绪落点。
- 进入 Seedance 2.0 前：把情绪命题压成一条风格锁定句和一条人物动作线。

## 9. 自检

输出方案前检查：

1. 观众站位是否清楚？
2. 人物是否有外在目标，而不是只表达情绪？
3. 人物缺口是否能通过动作看出来？
4. 中段是否让选择变难？
5. 结尾是否用动作、声音或物件留下余味？
6. 这条情绪命题是否能进入对应类型引擎？
7. Seedance 2.0 是否能把核心情绪拆成 4-6 秒镜头？
8. 冷启动六问是否至少答出观众替谁着急、人物非做什么不可、真正怕失去什么和情绪怎么被看见？
