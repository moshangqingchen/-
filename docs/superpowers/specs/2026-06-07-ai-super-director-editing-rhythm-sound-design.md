# AI超级导演剪辑节奏与声音设计库

## 1. 使用方式

这份库用于让AI超级导演在设计短片、短剧、广告和AI视频时，同时控制画面节奏、剪辑点、音乐、音效、旁白和静音。好的视频不是只有画面好看，而是每一次停顿、切换、声音进入和声音消失都有导演判断。

默认设计顺序：

1. 确定片长和类型。
2. 设计节奏曲线。
3. 标出关键剪辑点。
4. 设计环境声和动作音效。
5. 决定音乐进入、退出和变化。
6. 判断是否需要旁白。
7. 设计结尾声音记忆点。

## 2. 节奏曲线

### 2.1 15秒强钩子节奏

适合：信息流广告、可爱搞笑、种草、单一卖点。

```text
0-2秒：强钩子，声音先抓人。
2-5秒：快速建立主体和问题。
5-9秒：动作介入或笑点出现。
9-13秒：结果、反转或情绪变化。
13-15秒：标志性收束，保留一个声音记忆点。
```

声音策略：

- 开头用短促声音、反差台词或环境突变。
- 中段声音不要太满，给动作留清晰空间。
- 结尾用固定音效、品牌短句或角色口头禅。

### 2.2 30秒完整广告节奏

适合：产品广告、生活方式广告、小剧情广告。

```text
0-3秒：痛点声音或反常识台词。
3-8秒：环境声建立真实场景。
8-15秒：产品动作出现，声音变干净。
15-23秒：证明镜头，音乐轻微上扬。
23-30秒：品牌记忆，声音收束。
```

声音策略：

- 产品动作要有可识别声音。
- 证明镜头不能只靠音乐，要有细节音。
- 品牌收束短而准，避免口播太长。

### 2.3 60秒短剧节奏

适合：竖屏短剧开头、反转剧情、情感冲突。

```text
0-5秒：冲突台词或危险声音。
5-15秒：人物关系建立。
15-30秒：第一次升级。
30-45秒：第二次升级或反转预兆。
45-55秒：情绪释放或剧情反转。
55-60秒：悬念停顿。
```

声音策略：

- 关键台词前后留半秒空间。
- 反转前可以短暂降低环境声。
- 结尾不要解释太多，让最后一句或最后一个声音悬住。

### 2.4 3分钟短片节奏

适合：完整短片、治愈故事、怀旧情感、动作段落。

```text
0-15秒：气质建立。
15-45秒：人物和空间。
45-90秒：行动开始。
90-135秒：冲突或情绪升级。
135-165秒：转折。
165-180秒：落点和余味。
```

声音策略：

- 前15秒建立声音世界。
- 中段用环境声和动作声保持真实。
- 转折时可以使用静音、低频或音乐断点。
- 结尾留环境声，不急着上满音乐。

### 2.5 5分钟短剧/微电影节奏

适合：短剧单集、品牌微电影、复杂情感或动作故事。

```text
0-20秒：强开场。
20-60秒：第一场建立欲望和阻碍。
60-120秒：第二场行动展开。
120-210秒：第三场爆点。
210-270秒：第四场反转或代价。
270-300秒：情绪释放或悬念。
```

声音策略：

- 每一场要有不同声音主色。
- 爆点段落前要给声音预热。
- 结尾要保留主题声音，让观众记住系列。

## 3. 剪辑方法

### 3.1 动作剪辑

用途：保持动作流畅，让观众感觉动作连续。

适合：打斗、产品使用、走位、拿起旧物。

模板：

```text
在动作完成前一点切入下一镜，让下一镜接住动作结果。
```

常见失误：动作已经结束很久才切，会显得拖。

### 3.2 反应剪辑

用途：让观众理解事件的情绪后果。

适合：搞笑、特效、短剧反转、情感冲击。

模板：

```text
事件发生后停半秒，切到人物近景反应，再让观众消化。
```

常见失误：没有反应镜头，笑点和震撼都会变轻。

### 3.3 静音剪辑

用途：制造震惊、心碎、反转和注意力。

适合：情感片、悬疑反转、打斗关键伤害、特效爆发前。

模板：

```text
关键事件前降低环境声，事件发生瞬间短暂静音，然后让一个细节音回来。
```

常见失误：静音太长会像技术故障。

### 3.4 跳切

用途：压缩时间、制造轻快节奏或喜剧感。

适合：搞笑、训练、准备过程、种草步骤。

模板：

```text
连续3到5个短镜头，每个镜头只保留动作最有信息量的一瞬间。
```

常见失误：跳切过多会让观众失去方向。

### 3.5 留白剪辑

用途：让情绪停留。

适合：治愈、怀旧、亲情、公益。

模板：

```text
人物动作结束后保留1秒到2秒，让环境声承接情绪。
```

常见失误：留白没有内部动作，会变成空镜拖时长。

### 3.6 匹配剪辑

用途：用相似动作、形状或声音连接两个时间或空间。

适合：广告前后对比、怀旧回忆、成长变化。

模板：

```text
用同一个动作、同一个声音或同一个构图，从过去切到现在，或从问题切到解决。
```

常见失误：匹配点不够清楚，观众看不出连接关系。

## 4. 声音层设计

### 4.1 环境声

功能：建立真实空间。

例子：

- 治愈：风声、杯声、脚步声、布料声。
- 怀旧：老钟声、收音机底噪、木门声、远处街声。
- 打斗：鞋底摩擦、呼吸、衣料挥动、空间回声。
- 广告：产品使用声、场景生活声、干净按钮声。

原则：

- 环境声要服务空间，不要铺满。
- 关键情绪前可以降低环境声。
- 真实细节比大音乐更容易让人相信。

### 4.2 动作音效

功能：让动作有重量和反馈。

模板：

```text
动作开始声 + 接触声 + 结果声 + 反应声
```

例子：

- 打斗：脚步、出拳、接触、喘息。
- 产品：打开、按下、喷出、擦过、完成。
- 可爱：小脚步、轻拍、叮、啪嗒。
- 搞笑：短促反差音、停顿后的轻响。

### 4.3 音乐

功能：控制情绪方向。

使用规则：

- 广告音乐要帮助卖点，不要盖过信息。
- 情感音乐要克制，避免逼观众哭。
- 搞笑音乐要轻，不要把笑点讲死。
- 动作音乐要给节奏，但关键打击点可以短暂抽掉。
- 特效音乐要有层次，从低频到爆发再到尾音。

### 4.4 旁白

功能：补充画面无法表达的内心、时间跨度或信息。

适合：

- 怀旧情感。
- 公益短片。
- 品牌态度片。
- 旧梦留声机类故事。

原则：

- 旁白短。
- 旁白不重复画面。
- 旁白像没说完的话，比解释更有力量。
- 情感片中旁白宁可少，不要满。

## 5. 类型声音策略

### 5.1 可爱

声音关键词：轻、短、圆、软。

适合：

- 小脚步。
- 轻轻拍打。
- 小铃声。
- 轻快木琴或拨弦。

禁忌：

- 音效太尖。
- 音乐太满。
- 角色声音过度装嫩。

### 5.2 治愈

声音关键词：慢、暖、近、自然。

适合：

- 风声、雨声、杯声。
- 低音量钢琴或弦乐。
- 人物轻呼吸。
- 空间里的远声。

禁忌：

- 过度煽情音乐。
- 旁白解释太多。
- 每个镜头都铺音乐。

### 5.3 特效

声音关键词：低频、空气、层次、规则。

适合：

- 能量蓄积。
- 瞬间静音。
- 空气震动。
- 粒子尾音。

禁忌：

- 每个特效都同样响。
- 没有现实环境声对比。
- 声音不符合特效规则。

### 5.4 打斗

声音关键词：呼吸、接触、停顿、重量。

适合：

- 出拳破风。
- 接触闷响。
- 脚步滑动。
- 疼痛呼吸。
- 关键打击后的静止。

禁忌：

- 打击声每次一样。
- 音乐盖过动作。
- 没有空间回声。

### 5.5 创意广告

声音关键词：抓耳、清楚、可记忆。

适合：

- 产品专属声音。
- 反常识开场音。
- 品牌短句。
- 可哼唱音乐点。

禁忌：

- 卖点被音乐盖住。
- 口播太长。
- 结尾没有声音记忆。

### 5.6 短剧

声音关键词：台词清楚、情绪停顿、反转落点。

适合：

- 关键台词前停顿。
- 反转前降噪。
- 结尾悬念音。
- 门声、手机提示音、脚步声等剧情音。

禁忌：

- 台词和音乐抢频。
- 所有场景都是同一音乐。
- 反转后解释太多。

### 5.7 搞笑

声音关键词：停顿、反差、轻、准。

适合：

- 半秒沉默。
- 误解出现时短音效。
- 集体沉默。
- 轻巧收束音。

禁忌：

- 用音乐告诉观众“这里要笑”。
- 音效太多。
- 反应没有留空。

### 5.8 情感

声音关键词：克制、旧感、空间、留白。

适合：

- 旧录音底噪。
- 远处生活声。
- 轻微钢琴。
- 门、饭碗、照片纸张等真实声音。

禁忌：

- 大哭配大音乐。
- 旁白解释所有情绪。
- 声音太干净，失去年代感。

## 6. 声音提示词模板

### 6.1 通用

```text
声音设计：[类型]短片。
环境声：[空间声音]。
动作音效：[关键动作声音]。
音乐：[情绪、乐器、进入和退出位置]。
旁白：[是否需要，语气，长度]。
静音点：[在哪个事件前后短暂停顿]。
结尾声音记忆：[固定音效/短句/音乐尾音]。
```

### 6.2 旧梦留声机类

```text
旧录音式声音设计，轻微底噪，语速慢，情绪克制。
环境有远处街声、老屋木门声、纸张摩擦声。
旁白像一句多年没说出口的话，每句很短。
音乐只在情绪松动时轻轻进入，结尾保留环境声和留白。
```

### 6.3 绒耀幼儿园类

```text
可爱搞笑声音设计，教室环境轻快，角色小动作有短促软萌音效。
误解发生前留半秒安静，误解出现时一个轻巧反差音。
集体反应时环境声变空，结尾用固定口头禅或小铃声收束。
```

### 6.4 打斗特效类

```text
动作特效声音设计，先建立空间环境声和脚步声。
能力蓄积时加入低频和空气震动。
关键打击点短暂抽掉音乐，突出接触声和呼吸。
反转后释放节奏和能量尾音。
```

### 6.5 创意广告类

```text
广告声音设计，开头用抓耳反常识声音建立痛点。
产品动作出现时声音干净、清楚、可识别。
证明镜头音乐轻微上扬。
结尾保留品牌短句或产品专属声音，形成记忆点。
```

## 8. 导演自检

1. 声音是否和画面动作绑定？
2. 音乐是否服务情绪，而不是盖住信息？
3. 是否有必要的停顿？
4. 是否有环境声建立真实空间？
5. 是否有结尾声音记忆点？
6. 剪辑是否推动节奏升级？
7. 旁白是否少而有力？
