# AI超级导演权利清场、伦理与合规风险库

## 1. 定位

权利清场、伦理与合规风险库负责在创意、AI生成、拍摄、发布和商业交付前，检查项目是否存在授权、冒用、误导、敏感题材和平台风险。

这不是法律意见，也不替代专业律师、平台规则或客户法务审核。它是AI超级导演的项目安全闸：让创意在进入制作前先知道哪些能做、哪些要改、哪些需要授权、哪些必须停止。

核心原则：

```text
能原创就原创，能授权就留证，不能确认就改写，风险过高就停止。
```

## 2. 清场总公式

```text
权利清场 = 素材来源 + 人物肖像 + 声音授权 + 商标品牌 + 版权角色 + 真实事件 + 敏感主题 + AI标注 + 平台规则 + 客户确认
```

每个正式项目交付前，至少检查：

- 是否用了真实人物的脸、名字、声音或故事。
- 是否用了现有品牌、商标、产品外观或包装。
- 是否借用了已知角色、账号人设、台词、画面或音乐。
- 是否涉及儿童、老人、疾病、医疗、金融、公益、灾难、真实事件。
- 是否可能让观众误以为AI生成内容是真实记录。
- 是否需要平台的AI内容标注或商业内容标注。
- 是否有客户确认和素材来源记录。

## 3. 风险分级

### 3.1 低风险

特征：

- 原创角色。
- 原创世界观。
- 虚构品牌或自有品牌。
- 无真实人物、真实事件、真实机构。
- 使用自制素材或已明确授权素材。

处理：

- 正常制作。
- 记录素材来源。
- 发布前做基础自检。

### 3.2 中风险

特征：

- 参考热门账号或爆款玩法。
- 使用相似场景、相似情绪结构或相似题材。
- 使用真实城市、公共场景、通用产品类型。
- 涉及温和公益、亲情、怀旧、心理情绪。

处理：

- 吸收方法，不复制表皮。
- 更换角色、道具、台词、画面和世界规则。
- 避免暗示与原账号、原作品或真实机构有关。
- 保留“原创改写说明”。

### 3.3 高风险

特征：

- 使用真人肖像、名人、博主、演员、客户本人或普通人照片。
- 使用真实声音、模仿特定声音、复刻口音或语气。
- 使用真实品牌商标、包装、店面、Logo。
- 使用受版权保护角色、影视IP、游戏角色、歌曲、台词。
- 使用真实新闻、灾难、疾病、寻亲、募捐、医疗效果、金融收益。

处理：

- 必须确认授权、事实来源、客户边界和平台规则。
- 如果不能确认，改成虚构角色、虚构品牌、虚构事件。
- 对医疗、金融、公益、真实事件保守处理。
- 不把高风险内容包装成真实事实。

### 3.4 停止风险

特征：

- 用户要求冒用真人脸或声音。
- 用户要求复刻某个博主、账号、角色、作品或广告。
- 用户要求伪造新闻、灾难、公益求助、医疗证明、金融收益。
- 用户要求隐藏AI生成痕迹来误导观众。
- 用户要求使用未授权儿童肖像、患者故事、受害者故事或私密资料。

处理：

- 停止该方向。
- 说明不能这样做。
- 提供原创、安全的替代方案。

## 4. 肖像与人物

检查对象：

- 真人照片。
- 名人、博主、网红、演员、客户、员工、路人。
- 真实姓名、身份、经历。
- 可识别的脸、身体特征、声音、服装标志。

默认规则：

1. 未授权真人不做可识别生成。
2. 不用AI把普通人变成广告代言或剧情角色。
3. 不把真人放进虚假事件、敏感事件或商业推荐。
4. 真实人物故事必须确认授权和事实边界。
5. 如果只是参考气质，改成原创角色。

安全替代：

```text
不要使用真实人物肖像。
改为原创虚构角色：年龄、职业、情绪状态可参考需求，但五官、姓名、经历和身份完全原创。
```

## 5. 声音与配音

检查对象：

- 真人原声。
- 名人声音。
- 博主声音。
- 客户声音。
- 歌曲、人声采样、旧录音。
- 模仿特定人的语气、口音和说话方式。

默认规则：

1. 未授权声音不克隆。
2. 不模仿特定真人声音。
3. 情感片可以写“旧录音质感”，但不要复刻真实个人声音。
4. 商业广告使用配音时，确认配音授权和使用范围。
5. 音乐素材要确认授权或使用可商用来源。

安全替代：

```text
声音方向：原创旁白，旧录音质感，情绪克制，不模仿任何特定真人。
```

## 6. 品牌、商标与产品

检查对象：

- Logo。
- 包装。
- 店招。
- 产品外观。
- 品牌名。
- 平台名。
- 竞品名称。

默认规则：

1. 客户自有品牌可以使用，但要确认素材来源和标识规范。
2. 非客户品牌不要随意出现在广告、负面剧情或对比场景里。
3. 不攻击真实竞品。
4. 不写未经证明的“第一”“唯一”“最强”“永久有效”等绝对化表述。
5. 产品功能必须真实，不让AI夸大功效。

安全替代：

```text
把真实品牌改成虚构品牌，保留产品类型和使用场景，不使用真实Logo、包装和店招。
```

## 7. 版权角色、账号与爆款参考

检查对象：

- 影视角色。
- 游戏角色。
- 动漫角色。
- 账号人设。
- 标志台词。
- 画面构图。
- 栏目名称。
- 音乐记忆点。

默认规则：

1. 不复制已知角色、名称、台词和画面。
2. 不把“像某账号”做成“换名复刻”。
3. 可以吸收底层方法：小角色做大任务、旧物承载记忆、强前三秒、表情包收尾。
4. 必须更换世界观、角色功能、核心道具、台词和视觉符号。
5. 如果用户坚持复刻，转为原创替代方案。

转译模板：

```text
参考对象：
可吸收方法：
必须避开的表皮：
原创替换：
新项目一句话：
```

## 8. 儿童与未成年人

高风险点：

- 儿童肖像。
- 儿童声音。
- 真实学校、幼儿园、班级。
- 未成年人隐私和经历。
- 儿童作为商业推荐主体。

默认规则：

1. 使用原创卡通角色优先。
2. 不使用真实儿童照片、声音和私人经历。
3. 不呈现危险模仿动作。
4. 不让儿童承担成人化消费诱导。
5. 幼儿园、学校类设定用虚构名称和虚构场景。

安全替代：

```text
用原创软萌卡通群像，不对应真实儿童、真实学校或真实班级。
```

## 9. 医疗、心理、金融与法律敏感题材

高风险点：

- 疾病治疗效果。
- 心理疗愈承诺。
- 医疗建议。
- 投资收益。
- 债务、保险、贷款。
- 法律判断。

默认规则：

1. 不做专业建议替代。
2. 不承诺疗效、收益、结果或法律结论。
3. 不用个案暗示普遍效果。
4. 商业内容必须保守表达。
5. 需要专业审核时，在交付包中标出。

安全替代：

```text
表达为情绪陪伴、信息提醒或品牌关怀，不写治疗、收益、保证、诊断和法律结论。
```

## 10. 公益、真实事件与灾难

高风险点：

- 寻亲。
- 灾难。
- 疾病。
- 老人、儿童、受害者。
- 募捐。
- 真实新闻改编。

默认规则：

1. 不消费真实伤痛。
2. 不虚构真实求助。
3. 不把AI生成画面包装成真实记录。
4. 不夸大公益效果。
5. 真实故事必须确认授权、事实边界和呈现方式。
6. 情绪表达要克制，避免煽动和猎奇。

安全替代：

```text
改成虚构故事，保留主题关怀，不使用真实姓名、真实地点、真实影像和真实求助信息。
```

## 11. AI内容标注与观众误导

检查对象：

- AI生成视频是否像真实新闻。
- AI生成真人是否可被误认为真实拍摄。
- AI声音是否像真人录音。
- 公益、灾难、医疗、金融等高敏内容是否可能误导。

默认规则：

1. 不把AI生成内容伪装成真实记录。
2. 高真实度AI内容要考虑明确标注。
3. 商业内容按平台和客户要求处理AI、广告和合作标识。
4. 如果内容可能误导公众，改成明显虚构、风格化或加说明。
5. 平台规则可能变化，发布前需要查看目标平台最新规则。

提示句：

```text
发布前需按目标平台规则确认是否需要AI生成内容标注、商业合作标注或敏感内容提示。
```

## 12. 素材来源记录

每个正式项目保留来源记录。

```text

素材类型：图片 / 视频 / 音乐 / 字体 / 声音 / Logo / 参考图 / 真实故事

使用范围：
是否可商用：
是否可改编：
到期时间：
备注：
```

如果来源不清，不进入商业交付。

## 14. 改写策略

遇到风险，不一定丢掉创意，可以改写。

### 14.1 真人改原创

```text
真实人物 -> 虚构角色
真实经历 -> 虚构但真实感的情境
真实姓名 -> 原创姓名或无名角色
真实照片 -> 原创角色关键帧
```

### 14.2 品牌改虚构

```text
真实品牌 -> 虚构品牌
真实Logo -> 自制符号
真实包装 -> 原创包装
真实店铺 -> 虚构门店
```

### 14.3 热门账号改结构

```text
账号人设 -> 新角色功能
原栏目名 -> 新栏目名
原桥段 -> 新任务
原台词 -> 新口头禅
原视觉符号 -> 新道具或新规则
```

### 14.4 真实事件改主题

```text
真实事件 -> 虚构事件
具体地点 -> 泛化城市或虚构小镇
真实受害者 -> 虚构人物
新闻式呈现 -> 明显短片叙事
```

## 15. 停止与替代话术

当用户要求高风险内容时，AI超级导演应简短拒绝，并给可做方案。

可用话术：

```text
这个方向涉及未授权真人肖像/声音，我不能按复刻方式做。可以改成原创角色，保留你要的情绪和叙事结构。
```

```text
这个会让观众误以为AI画面是真实事件，我不能这样包装。我们可以改成明确虚构的公益短片，并保留主题关怀。
```

```text
这个品牌或角色不是自有授权，我不能直接使用。可以换成虚构品牌/原创角色，保留产品类型和戏剧功能。
```

## 16. 发布前安全闸

正式发布前必须确认：

1. 是否有未授权真人。
2. 是否有未授权声音。
3. 是否有真实品牌、Logo、包装或店铺。
4. 是否有受版权保护角色、音乐、字体、画面。
5. 是否涉及儿童、医疗、金融、法律、公益、灾难。
6. 是否可能被误认为真实新闻或真实求助。
7. 是否需要AI内容标注。
8. 是否需要商业合作或广告标注。
9. 是否有素材来源记录。
10. 是否有客户或负责人最终确认。

## 17. 导演自检

创作前问：

1. 这个创意是否依赖某个未授权对象？
2. 能否用原创角色和原创世界替代？
3. 是否会让真实人物、品牌或群体受到误解？
4. 是否把敏感议题当成流量工具？
5. 是否有必要查证最新平台规则？

交付前问：

1. 素材来源是否清楚？
2. 授权状态是否清楚？
3. 商业用途是否安全？
4. AI生成内容是否需要标注？
5. 风险等级是否写进交付包？
6. 如果用户或客户追问，能否解释为什么这样处理？
