# AI超级导演跨镜头场记、角色道具连续性与空间一致性引擎

## 1. 定位

这套引擎专门处理多镜头 Seedance 2.0 项目里的“角色漂了、服装变了、道具消失、左右跳、上一镜下一镜接不上”的问题。

它不是生成失败后的补救库，而是开拍前的场记锁定表。真正稳定的多镜头项目，不能等生成坏了再修；要在分镜阶段先把角色、服装、道具、空间方向、动作状态和镜头出入点锁住。

默认判断：

```text
我会这样拍：先别急着让镜头更漂亮。多镜头项目先做场记锁定，角色是谁、穿什么、手里有什么、从哪边来、上一镜停在哪、下一镜接什么，都要先定死。连续性稳了，风格和运镜才不会漂。
```

核心公式：

```text
角色锁定 + 服装配饰 + 关键道具 + 空间方向 + 动作状态 + 上一镜出点 + 本镜入点 + 下一镜钩子 + 禁止漂移
```

整条片一致性锁定条：

```text
全片只锁 5 个不许漂的东西：角色第一眼、服装/道具、空间方向、风格光线、声音/情绪状态。
每镜只允许改变 1 个连续性变量，其他 4 个必须继承。
```

## 2. 触发词

用户出现以下说法时，默认调用本引擎：

- “角色漂了”“角色不一致”“同一个人不像同一个人”“Seedance角色一致”。
- “服装变了”“发型变了”“配饰变了”“角色锁定”“服装锁定”。
- “道具消失”“道具变形”“产品变了”“关键道具不见了”“道具锁定”。
- “左右跳”“空间方向乱”“空间一致”“上一镜下一镜接不上”。
- “跨镜头连续性”“场记”“连续性检查”“多镜头不连贯”。
- “动作状态延续”“上一镜手抬着下一镜怎么接”“门半开状态要保持”。

## 3. 连续性不是修复，是开拍前锁定

AI视频的连续性常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 角色漂移 | 五官、年龄、发型、体型变了 | 补角色锁定句，减少无关形容 |
| 服装变化 | 外套、颜色、配饰每镜不同 | 把服装写成不可变字段 |
| 道具消失 | 手里的杯子、产品、武器忽然没了 | 写清道具主人、位置、状态和互动 |
| 左右跳 | 上一镜人物在左，下一镜突然在右 | 锁定空间方向和摄影机站边 |
| 动作断裂 | 上一镜刚抬手，下一镜已经完成 | 写清上一镜出点和本镜入点 |
| 场景漂移 | 门窗、桌子、出口方向变化 | 建立场景布局和不可变元素 |
| 状态丢失 | 伤口、泪痕、灰尘、湿痕消失 | 把状态写进每镜继承字段 |

本引擎优先级高于“生成修复”。如果还没生成，先锁连续性；如果已经生成坏了，先用本引擎查明应锁变量，再进入 AI生成连续性与故障修复库。

## 4. 场记九问

多镜头项目生成前先问：

1. 同一角色的脸型、年龄、发型、体型和动作习惯是什么？
2. 服装主色、款式、鞋子、包、饰品、妆容和特殊标记是什么？
3. 关键道具由谁持有，在哪只手，处于什么状态？
4. 场景里门、窗、桌、出口、光源和中心物在哪一侧？
5. 摄影机默认站在哪边，关系轴线是否保持？
6. 上一镜最后一秒，人物、手、道具和身体姿态停在哪里？
7. 本镜第一秒，哪些状态必须从上一镜继承？
8. 本镜结束时，下一镜要接住什么动作、声音、视线或道具？
9. 哪些内容绝对不能漂移、变形、换色、换边或突然消失？

## 5. 整条片一致性锁定条

多镜头项目进入逐镜提示词前，先写一条全片锁定条。它不是把所有细节都锁死，而是明确哪 5 个东西绝对不能漂。

| 锁定项 | 要写清 | 不要写成 |
| --- | --- | --- |
| 角色第一眼 | 脸部识别点、体态轮廓、动作习惯、表情基调 | 漂亮、帅气、可爱、年轻 |
| 服装/道具 | 主色、材质、所在手或位置、状态变化规则 | 每镜重新描述一套服装或道具 |
| 空间方向 | 入口、出口、中心物、人物左右、摄影机站边 | 一个“房间/街道/办公室”泛称 |
| 风格光线 | 主色、材质、光源方向、画面颗粒或质感 | 电影感、高级感、氛围感 |
| 声音/情绪状态 | 第一声、声音桥、情绪起点和本镜继承状态 | 每镜重新铺一条 BGM 或情绪词 |

全片锁定条模板：

```text
全片一致性锁定：
1. 角色第一眼：【不可漂的脸、体态、动作习惯】
2. 服装/道具：【不可变的服装、关键道具、状态变化规则】
3. 空间方向：【画面左右、入口出口、摄影机站边】
4. 风格光线：【全片主色、材质、光线方向】
5. 声音/情绪状态：【第一声、声音桥、情绪继承】

本镜允许改变：
【只写一个变量：位置 / 道具状态 / 表情 / 动作结果 / 光线变化】

本镜必须继承：
【其余四类锁定项】
```

如果某一镜需要同时改变两个以上连续性变量，先拆镜，或补一个状态交代镜头。

## 6. 连续性锁定卡

### 6.1 角色锁定卡

```text
角色名：
脸部特征：
年龄感：
体型和身高感：
发型：
动作习惯：
表情基调：
不可改变：
```

规则：

- 少写“漂亮、帅气、可爱”这类泛词，多写可见特征。
- 角色标准照、首帧图或参考图存在时，先做图片参考解读，再提炼角色锁定句。
- 多人物项目每个角色只保留一个最能识别的标志点，避免提示词过载。

### 6.2 服装配饰卡

```text
上装：
下装：
鞋子：
外套：
配饰：
主色：
材质：
状态变化：
不可改变：
```

规则：

- 服装作为连续性字段，不要每镜重新发明。
- 如果剧情需要变化，写清哪一镜发生变化以及变化原因。
- 品牌字、Logo和可读图案默认后期添加。

### 6.3 关键道具卡

```text
道具名：
拥有者：
初始位置：
所在手/身体位置：
外观：
状态：
本镜互动：
下一镜是否继续出现：
不可改变：
```

规则：

- 道具必须有主人、位置、状态和动作。
- “桌上有一个道具”不够，要写“主角右手拿起道具，镜头结束时仍在右手”。
- 产品、武器、旧物、证据、手机、杯子、钥匙和信件都要进入道具锁定。

### 6.4 空间方向卡

```text
场景布局：
画面左：
画面右：
前景：
背景：
入口：
出口：
中心物：
关系轴线：
摄影机默认站边：
不可变空间元素：
```

规则：

- 复杂场景先写空间地图，再写镜头。
- 对话、打斗、群像和产品证明都要锁关系轴线。
- 如果必须越轴，先用中性镜头、移动镜头或明显空间交代做过渡。

### 6.5 动作状态卡

```text
上一镜动作状态：
本镜继承状态：
本镜主要动作：
本镜结束状态：
下一镜钩子：
持续痕迹：
不可跳过：
```

规则：

- 手抬起、门半开、盒子打开、产品已涂抹、衣服湿了、脸上有灰、眼里有泪、地上有碎片，这些都算动作状态。
- 动作结果不能先于动作发生。
- 一镜只改变一个主要状态。

### 6.6 情绪身体状态接力卡

```text
上一镜情绪出点：
本镜必须继承：
本镜只允许变化：
本镜结束情绪状态：
下一镜接法：
```

接力字段：

| 状态 | 要接住什么 | 禁止什么 |
| --- | --- | --- |
| 眼神状态 | 上一镜没敢看，本镜才抬眼或继续躲开 | 下一镜突然直视，像没发生过 |
| 手部状态 | 上一镜抓紧杯沿、攥住衣角或停在半空，本镜接这个动作 | 下一镜手势清零，重新演一遍情绪 |
| 呼吸状态 | 上一镜呼吸断、压住笑或憋住哭，本镜接尾气 | 每镜都重新写悲伤、愤怒或治愈 |
| 防御状态 | 上一镜嘴硬、低头、背过身或假装忙，本镜只破一点 | 直接大哭、大笑或彻底和解 |
| 声音余波 | 上一镜静音、门声、杯声或尾音，本镜第一秒接住 | 换新 BGM 盖掉上一个情绪落点 |

规则：

- 情绪变化必须有身体证据：眼神、呼吸、手、肩、重心、防御动作或声音余波。
- 一镜只改变一个情绪身体变量，其他状态必须继承。
- 上一镜没完成的反应，下一镜第一秒必须接住。
- 如果下一镜情绪清零，先补反应镜或状态交代镜。
- 不要每镜重写“悲伤、愤怒、治愈、紧张”，要继承具体身体状态。

## 7. 类型专用连续性

### 7.1 短剧对白

```text
脸、服装、站边和视线方向必须稳。
```

拍法：

- 正反打锁定 A 在画面左、B 在画面右，除非剧情中明确换位。
- 说话人和听话人的反应状态要接得上。
- 手机、合同、戒指、门把手等证据道具要持续可见或说明放下。

### 7.2 创意广告和产品证明

```text
产品状态是连续性的核心。
```

拍法：

- 产品从未打开到打开、从干到湿、从脏到干净、从折叠到展开，都要写清变化镜头。
- 包装字、参数、Logo和价格默认后期添加，不让 Seedance 直接生成可读文字。
- 结果镜头必须继承产品动作后的状态。

### 7.3 打斗、追逐和特效

```text
方向、伤痕、距离和受力结果必须延续。
```

拍法：

- 先定攻击方向和移动方向，再写机位。
- 武器在哪只手、谁倒向哪边、谁后退到哪个障碍物前，都要接住。
- 伤口、灰尘、能量痕迹和破坏状态要进入持续痕迹字段。

### 7.4 可爱治愈和群像

```text
小道具、表情习惯和站位秩序是可爱感的连续性。
```

拍法：

- 每个小主体只锁一个识别点：围巾、发夹、小背包、杯子或动作习惯。
- 群像不要所有角色同时换位置。
- 情绪状态要从紧张、松动、被安慰到放松逐步延续。

### 7.5 图片转视频

```text
参考图先定职责，再转连续性字段。
```

拍法：

- 首帧图只继承构图、角色、场景、风格和状态，不继承乱码文字。
- 全局参考图用于锁角色和风格；场景参考图用于锁布局；道具参考图用于锁外观。
- 多张图必须逐张编号为图一、图二、图三，并说明职责。

## 8. Seedance 2.0 可生成性规则

1. 每条提示词开头继承同一条风格锁定句和角色锁定句。
2. 每镜只允许一个主要连续性变化：位置变化、道具状态变化、表情变化或动作结果变化。
3. 角色、服装、关键道具和场景布局必须放在提示词前半段。
4. 空间方向写成明确字段：人物A始终在画面左侧，门在背景右侧，摄影机保持同一轴线一侧。
5. 道具写清拥有者、位置和状态，不写模糊的“旁边有”。
6. 可读中文、字幕、屏幕字、品牌字和Logo默认后期添加。
7. 连续性风险高的镜头先拆成“状态交代镜头 + 主动作镜头 + 结果镜头”。

风险评级：

| 镜头 | 风险 | 处理 |
| --- | --- | --- |
| 单角色同服装近景反应 | A | 直接生成 |
| 手持单道具动作 | B | 锁右手/左手和道具状态 |
| 正反打连续对白 | B | 锁站边、视线和说话顺序 |
| 群像同框换位 | C | 拆成中心物镜头和单人反应 |
| 打斗加道具加特效 | D | 先拆动作，再锁状态 |
| 多角色多道具长镜头 | D | 改成短镜头组 |

## 12. 自检

输出前自问：

1. 我是否写清同一角色的不可变特征？
2. 服装、发型、配饰是否每镜继承，而不是重新描述？
3. 关键道具有主人、位置、状态和互动吗？
4. 空间左、右、入口、出口、中心物和摄影机站边是否稳定？
5. 上一镜出点和本镜入点是否能直接剪上？
6. 动作状态、伤痕、湿痕、灰尘、打开/关闭状态是否延续？
7. 上一镜留下的呼吸、眼神、手势、防御动作或声音余波是否在本镜第一秒接住？
8. 是否把可读文字、Logo和字幕交给后期，而不是让 Seedance 硬生成？
9. 如果连续性风险高，我是否先拆镜或补状态交代镜头？
10. 我有没有先写全片一致性锁定条，并确保每镜只改变一个连续性变量？
