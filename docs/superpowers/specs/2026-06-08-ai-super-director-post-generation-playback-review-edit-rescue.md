# AI超级导演生成后回放验片与剪辑救援协议

## 1. 定位

这份协议用于 Seedance 2.0 或其他 AI 视频生成后，看回放、判定问题、决定救片方式。它不替代生成前预检，也不替代返工迭代协议；它站在生成结果之后，像导演和剪辑一起看素材：

```text
这条能不能用？能剪救吗？要后期补吗？要单变量重跑吗？还是必须拆镜重做？
```

一句话原则：

```text
生成后先验片，不急着重跑。能剪救的不重跑，必须重跑的只改一个变量。
```

## 2. 触发信号

当用户出现以下说法时，默认调用本协议：

1. “生成出来了，帮我看看”。
2. “这条能不能用、能不能剪、要不要重跑”。
3. “哪里穿帮、哪里能救、哪里必须返工”。
4. “角色有点漂、动作有点乱、口型怪、镜头不错但有瑕疵”。
5. “跑完后怎么审、生成后怎么改下一版”。
6. “客户能不能看、发布前要不要修”。

如果还没有生成结果，只是方案检查，先走输出审片评分与升级闸门。  
如果已经连续失败，走本协议后再进入 Seedance 2.0 返工迭代协议。

## 3. 五类处理结论

| 结论 | 判断 | 处理 |
| --- | --- | --- |
| 可保留 | 主动作清楚，瑕疵不影响理解 | 直接保留，后期小修 |
| 可剪救 | 局部有问题，但有可用片段 | 截取可用段，补反应镜、插入镜或声音桥 |
| 可后期补 | 文字、Logo、字幕、轻微节奏、音效不足 | 后期添加，不重跑 |
| 单变量重跑 | 主体对、结构对，但一个关键变量错 | 只改角色、动作、机位、口型或道具之一 |
| 拆镜重做 | 原镜任务过载或主动作失败 | 拆成 2-4 个低风险镜头 |

判断句：

```text
先判断这条素材属于哪一类，不要一看到瑕疵就重跑。
```

## 4. 回放验片顺序

按这个顺序看，不要先看细节：

1. 主目标是否成立：观众看懂这镜在做什么吗？
2. 主体是否稳定：主角、产品或关键道具有没有变？
3. 主动作是否清楚：起点、过程、结果能否看懂？
4. 空间是否接得上：方向、站位、门窗桌椅有没有跳？
5. 口型是否影响理解：嘴部是否可见，台词是否过长？
6. 文字和 Logo 是否需要后期：有没有乱码或错误品牌字？
7. 声音和剪辑是否能补救：能否用声桥、反应镜或裁切解决？
8. 是否影响客户或发布：瑕疵是否会被普通观众注意？

## 5. 素材可用段切片

回放验片不能只说“好/坏”。先把素材切成三段：能用、危险、废掉。剪辑救援从可用段出发，不从瑕疵出发。

| 切片 | 判断标准 | 处理 |
| --- | --- | --- |
| 可用段 | 主体稳定，主动作或情绪落点能看懂 | 保留，找到最早入点和最干净出点 |
| 危险段 | 局部漂移、动作开始乱、口型开始怪、空间略跳 | 只当过渡，尽快用反应镜、插入镜或声音桥盖过去 |
| 废段 | 角色变人、产品错、主动作反了、记忆帧失败 | 不进成片，进入重跑或拆镜 |

切片句式：

```text
可用段：从【时间点】到【时间点】，因为【主动作/情绪/产品证据】成立。
危险段：从【时间点】开始出现【具体问题】，只可短用或被声音桥盖过。
废段：从【时间点】开始不能用，因为它破坏【角色/产品/动作因果/记忆帧】。
```

如果素材没有明确可用段，不要给“可剪救”。这条要么单变量重跑，要么拆镜重做。

### 5.1 剪救证据门槛

“能剪救”必须有证据，不能因为画面好看就硬留。给出可剪救结论前，先过这张门槛表：

| 证据 | 必须成立 | 不成立时 |
| --- | --- | --- |
| 可用段证据 | 至少有 1 秒以上主体稳定、主动作或情绪落点成立的片段 | 不能剪救，进入单变量重跑或拆镜重做 |
| 主任务证据 | 这镜原本承担的主任务仍能被观众看懂 | 主任务失败，不靠包装硬救 |
| 连续性证据 | 可用段能接上上一镜或下一镜的动作、视线、声音、空间方向或道具 | 先补桥镜；桥不了就重跑 |
| 后期可解证据 | 问题属于字幕、Logo、声音、节奏、边角瑕疵或局部裁切能解决 | 如果是角色、产品、主动作、关系或特效规则错，后期不能解 |
| 观众误读证据 | 普通观众不会把可用段理解成相反意思 | 会误读就不进成片 |

快速判定句：

```text
这条能剪救，因为【可用段证据】成立，主任务仍然是【主任务】，问题只坏在【局部问题】，可以用【裁切/反应镜/插入镜/声音桥/后期覆盖】解决。
```

禁止判定句：

```text
这条不能剪救，因为没有稳定可用段，或主任务已经失败。第一刀不是包装，而是【单变量重跑/拆镜重做/重做首帧/补证明镜】。
```

### 5.2 素材职能降级卡

有些素材不能继续当原本的主镜头，但还可以降级成桥镜、反应镜、插入证据、氛围镜或备用转场。降级不是硬救，前提是它不再承担已经失败的原任务，也不会让观众误以为主动作、产品证明或关系变化已经成立。

降级判断：

```text
原本职能：[主镜头/证明镜头/反应镜头/桥镜头/记忆镜头]
原职能是否成立：[成立/部分成立/不成立]
可降级新职能：[桥镜/反应镜/插入证据/氛围镜/转场/废弃]
降级后还能承担：
降级后不能再承担：
接上一镜的钩子：
接下一镜的钩子：
需要补的镜头：
观众是否会误读：
```

降级表：

| 原素材问题 | 可降级成 | 使用条件 | 禁止伪装成 |
| --- | --- | --- | --- |
| 主动作没完整发生，但起势好看 | 桥镜或动作入点 | 后面必须补主动作结果镜 | 主镜头 |
| 角色轻微漂，但背影、手部或道具可用 | 插入镜或过渡镜 | 不露清晰正脸，不承担身份确认 | 角色主近景 |
| 产品动作没证明卖点，但材质细节好 | 氛围镜或质感插入 | 另补产品证明镜 | 卖点证明镜 |
| 口型失败，但听者反应成立 | 反应镜 | 台词改画外声或后期配音 | 画内口型镜 |
| 特效规模失败，但光影冲击可用 | 反应镜或危险预兆 | 另补接触点和受力结果 | 特效结果镜 |
| 记忆帧不可截图，但运动过渡顺 | 转场或声音桥画面 | 不做封面、不做结尾余味 | 记忆镜头 |

降级硬规则：

1. 原任务失败的素材，不能在成片里继续假装原任务成立。
2. 降级后必须改镜头名字和剪辑职能，写清它现在只负责什么。
3. 降级素材前后必须有钩子：动作、视线、声音、道具、光线或反应至少一个能接上。
4. 如果降级后仍会让观众误读主动作、产品效果、人物身份或关系方向，直接废弃或重跑。

## 6. 故障到救法映射

| 故障 | 能剪救吗 | 第一处理 |
| --- | --- | --- |
| 前半段好，后半段动作乱 | 能 | 只保前半段，切反应镜或插入镜 |
| 角色轻微漂，但动作清楚 | 视情况 | 主镜可保，下一镜用背影、手部或道具过渡 |
| 角色完全变人 | 不能 | 单变量重跑角色锁定，或重做首帧 |
| 道具短暂变形 | 能 | 裁掉变形段，补手部或声音桥 |
| 产品形状错误 | 不能 | 重跑或先做产品标准帧 |
| 口型有点怪 | 能 | 改成画外声、字幕后期、反应镜遮口型 |
| 长台词穿帮 | 不能硬救 | 拆正反打、短句、反应镜 |
| 镜头乱晃但动作可见 | 能 | 裁取稳定段，加声音支撑 |
| 动作因果错 | 通常不能 | 拆成起点、接触、结果、反应 |
| 文字乱码 | 能 | 裁掉文字区域或后期覆盖；下轮禁止生成文字 |
| 背景小瑕疵 | 能 | 不处理或轻微后期 |
| 主记忆帧失败 | 不能 | 必须重跑主镜或重做首帧 |

## 7. 剪辑救援方法

### 7.1 裁切救援

适合：素材前 2-4 秒可用，后面开始跑偏。

```text
保留可用段：
从【时间点】到【时间点】。
切出点：
在【动作停顿 / 眼神 / 声音断点】处切。
补救：
下一镜用反应镜或插入镜接住。
```

### 7.2 反应镜救援

适合：主动作略乱，但人物反应能解释结果。

```text
主动作不用拍满。
切到人物反应，让观众通过反应理解发生了什么。
```

### 7.3 插入镜救援

适合：产品动作、道具变化、合同、旧物、按钮、手部动作不够清楚。

```text
补一个 2-3 秒手部或道具插入镜，承担证明任务。
```

### 7.4 声音桥救援

适合：画面连接略跳，但动作方向还成立。

```text
用同一个环境声、物件声或画外短句跨过剪辑点。
```

### 7.5 后期覆盖救援

适合：字幕、Logo、屏幕字、轻微边角瑕疵。

```text
生成阶段不追可读文字，后期用字幕条、品牌字或裁切遮掉错误区域。
```

## 8. 救片禁止线

救片不是把所有素材都留下。出现以下情况，禁止用字幕、配音、调色或包装硬救：

| 禁救问题 | 为什么不能硬救 | 正确处理 |
| --- | --- | --- |
| 主动作没发生 | 观众没有证据，只剩解释 | 拆成起点、过程、结果、反应 |
| 产品证明失败 | 广告信任会塌 | 重跑产品动作或补手部证据镜 |
| 角色身份漂移 | 连续性断裂，后期盖不住 | 单变量重跑角色锁定 |
| 关系方向错 | 短剧冲突会反向 | 重写本镜任务，重跑主反应 |
| 特效受力错 | 动作重量不存在 | 降低特效规模，重跑接触点和结果 |
| 记忆帧不可截图 | 发布和复述没有锚点 | 重做首帧或主记忆镜 |

禁救句式：

```text
这条不能靠后期硬救，因为【禁救问题】已经破坏【观众理解/产品信任/角色连续/记忆帧】。
第一刀不是加字幕，是【单变量重跑/拆镜重做/补手部证据/重做首帧】。
```

### 8.1 素材发布记忆复核

素材技术上可用，不代表适合发布。生成后如果准备进入标题封面、客户终稿或平台发布，必须追加一次发布记忆复核。

```text
素材发布记忆复核：
一句话复述：观众会怎么讲这段素材？
截图帧：哪一帧能做封面或记忆帧？
动作/声音钩子：观众离开画面后记住什么？
评论接话口：观众最自然会接哪句话？
误解风险：观众可能把它看歪成什么？
```

判定：

| 结论 | 判断 | 处理 |
| --- | --- | --- |
| 可发布复用 | 主任务成立，截图帧和复述句都清楚 | 进入发布前可复述测试 |
| 可剪救但不做封面 | 素材能接叙事，但截图帧弱 | 降级为桥镜、反应镜或过渡镜 |
| 需补记忆镜 | 主任务成立但看完记不住 | 补一个主动作中点、反应停顿、结果变化或母题回收镜 |
| 需重做首帧 | 复述成立但封面看不懂 | 重做首帧或关键帧，不整条重跑 |
| 不建议发布 | 主任务、记忆帧或误解风险伤害理解 | 单变量重跑或拆镜重做 |

硬规则：

1. 可剪救素材不一定能做封面；封面必须另过停留点验钞。
2. 主记忆帧失败时，不靠标题和置顶评论硬救。
3. 如果观众一句话复述和客户价值相反，先改素材或剪辑顺序，不先改文案。
4. 发布记忆复核只改一个传播变量：截图帧、主动作、声音钩子、结尾回收或标题问题。

## 9. 不能救的红线

遇到这些，不要硬剪：

1. 主角身份完全变了。
2. 产品外观或功能错了。
3. 主动作因果反了。
4. 关键道具消失导致剧情看不懂。
5. 打斗受力结果完全错误。
6. 参考作品外壳过于接近。
7. 客户品牌字、Logo 或法律信息错误。
8. 主记忆帧不可用。

判断句：

```text
这不是剪辑问题，是素材地基问题。要重跑或拆镜，不要硬救。
```

## 11. 与返工协议的衔接

如果结论是“单变量重跑”，进入 Seedance 2.0 返工迭代协议第一轮：

```text
只改变量：
必须锁住：
必须删掉：
重试提示词：
通过标准：
```

如果结论是“拆镜重做”，进入第二轮拆镜：

```text
原镜为什么不能救：
拆成几个镜头：
每镜承担什么：
镜头之间如何衔接：
```

如果连续两轮仍失败，进入首帧关键帧锁定器：

```text
重做首帧或关键帧，先锁角色、场景、道具、动作中点和禁止项。
```

## 12. 自检闸门

输出前检查：

1. 有没有先判断素材类别？
2. 有没有指出最能用的部分？
3. 有没有把素材切成可用段、危险段和废段？
4. 有没有只抓一个主病灶？
5. 有没有区分剪辑问题和生成地基问题？
6. 有没有识别不能靠后期硬救的禁救问题？
7. 有没有优先后期处理文字、Logo 和字幕？
8. 如果重跑，是否只改一个变量？
9. 是否给了通过标准？
10. 如果说可剪救，是否证明了可用段证据、主任务证据、连续性证据和后期可解证据？
11. 是否确认普通观众不会把剪救后的可用段理解成相反意思？
12. 如果主任务失败但局部可用，是否先判断能否降级成桥镜、反应镜、插入证据、氛围镜或转场，而不是继续假装它是主镜头？
13. 降级素材是否写清了新职能、不能再承担的任务、前后剪辑钩子和需要补的镜头？

## 13. 最小合格线

一次生成后验片至少要输出：

1. 素材结论。
2. 可用部分。
3. 可用段、危险段、废段切片。
4. 主病灶。
5. 救援方式。
6. 是否触发救片禁止线。
7. 是否重跑。
8. 如果重跑，只改哪个变量。
9. 通过标准。
10. 如果可剪救，必须写出剪救证据门槛。
11. 如果原职能失败但局部可用，必须写出素材职能降级判断。

少一项，就容易把可用素材浪费掉，或者把必须重做的镜头硬剪进片子里。
