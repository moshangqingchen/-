# AI超级导演风格参考、Moodboard与镜头风格圣经系统

## 1. 定位

这份系统用于把“我想要这种感觉”“参考这张图”“像某个爆款账号那种气质”“画面不要散”转成可执行的导演前期规则。

它不是替代视觉风格与美术指导库，而是补上更靠前的一步：先拆参考、定Moodboard、写视觉圣经，再进入关键帧和 Seedance 2.0 视频生成。

核心目标：

1. 让同一项目的角色、场景、道具、色彩、光线、材质和镜头气质保持一致。
2. 把参考图或参考项目拆成可迁移的方法，而不是照搬可识别角色、画面、文案和故事。
3. 让 Seedance 2.0 的每条镜头提示词都带有清楚的风格锁定句。
4. 让导演输出更像现场判断：我会先锁什么，舍掉什么，哪一帧必须稳住。

一句话：

```text
参考不是拿来复制的，是拿来拆骨架、取气质、定边界，再拍成自己的东西。
```

## 2. 什么时候调用

用户出现这些说法时，优先调用本系统：

- “先做风格参考。”
- “做一个Moodboard。”
- “参考图给你，帮我延展。”
- “画面要统一。”
- “不要一镜一个风格。”
- “先做视觉圣经。”
- “角色圣经/场景圣经/道具圣经。”
- “先做关键帧再做视频。”
- “像绒耀幼儿园那种感觉。”
- “像旧梦留声机那种情绪。”
- “Seedance生成出来太散。”
- “帮我把风格锁住。”

如果用户要的是图片生成或图片编辑，仍然遵守 AGENTS 偏好：默认直接调用 image generation，除非用户明确说只要提示词。

如果用户要的是视频生成，默认进入 Seedance 2.0 组织方式，并把本系统的风格锁定句写进每条镜头提示词。

## 3. 与其他能力的关系

本系统通常放在这些资产之间：

```text
需求诊断
-> 趋势雷达/参考拆解
-> 风格参考、Moodboard与镜头风格圣经系统
-> 视觉风格与美术指导库
-> 角色/场景/道具圣经
-> 关键帧
-> Seedance 2.0人称运镜
-> 提示词与镜头生成库
-> 生成修复库
```

简单项目可以轻量执行，只输出一段风格锁定句和3条禁区。

复杂项目必须写完整视觉圣经，尤其是系列IP、商业广告、情感短片、特效片和多镜头 Seedance 视频。

## 4. 核心原则

### 4.1 只借方法，不借身份

可以借：

- 情绪温度。
- 色彩关系。
- 光线方向。
- 镜头距离。
- 构图习惯。
- 叙事节奏。
- 材质触感。
- 群像关系。
- 物件承载情绪的方法。

不要借：

- 可识别角色造型。
- 可识别场景布局。
- 可识别Logo、品牌、文案。
- 对方项目的核心故事。
- 对方独有的视觉符号组合。
- 真实人物的脸、声音和身份。

导演判断句：

```text
我不照着它拍，我只拿它的“工作方法”：它怎么让观众靠近角色，怎么让画面有记忆点，怎么用一个物件把情绪托起来。
```

### 4.2 参考必须转成规则

一句“高级电影感”没有用，必须转成：

- 主体是什么。
- 镜头离主体多近。
- 光从哪里来。
- 色彩主次是什么。
- 哪个道具永远不能变。
- 每个镜头只允许一个主要动作。
- 人称视角怎么服务情绪。

### 4.3 风格要做减法

一个项目最多保留：

- 1个主情绪。
- 1套色彩规则。
- 1个主光线方向。
- 1个记忆符号。
- 1种镜头亲近方式。
- 1条不可越界的禁区。

不做减法，Seedance 2.0 很容易把每个镜头都理解成新项目。

### 4.4 先锁关键帧，再跑视频

多镜头视频默认顺序：

1. 角色圣经。
2. 场景圣经。
3. 道具圣经。
4. 3-5张关键帧。
5. 关键帧一致性检查。
6. Seedance 2.0 单镜生成。
7. 失败镜头修复。
8. 剪辑和声音统一。

## 5. 默认工作流

```text
参考收集
-> 参考拆解
-> 风格关键词减法
-> Moodboard结构
-> 项目视觉圣经
-> 角色视觉圣经
-> 场景视觉圣经
-> 道具视觉圣经
-> 镜头风格圣经
-> 关键帧清单
-> Seedance 2.0风格锁定句
-> 生成顺序
-> 一致性检查
```

导演口吻：

```text
我会先不急着生成。先把这个片子的气味定下来：它是软的、冷的、旧的、亮的，还是有点危险的。风格一散，后面每条Seedance提示词都会像临时拼的。
```

## 6. 参考拆解法

拿到一张参考图、一个视频参考或一个账号参考时，按8层拆：

| 层级 | 要看什么 | 输出什么 |
| --- | --- | --- |
| 情绪 | 观众第一反应 | 主情绪词，不超过2个 |
| 主体 | 画面真正被看的东西 | 主体优先级 |
| 形状 | 圆、尖、硬、软、破旧、整洁 | 造型语言 |
| 色彩 | 主色、辅助色、记忆色 | 三色规则 |
| 光线 | 来源、方向、软硬、明暗 | 光线规则 |
| 材质 | 皮肤、布料、纸、木、金属、雾、光 | 触感关键词 |
| 镜头 | 景别、机位、运动、人称 | 镜头性格 |
| 禁区 | 不能复制或容易跑偏的东西 | 不可照搬清单 |

拆完后必须写成：

```text
可迁移方法：
不可照搬元素：
本项目原创改写方向：
```

## 13. Seedance 2.0风格锁定法

Seedance 2.0 镜头提示词默认增加三层锁定。

### 13.1 项目锁定

每条提示词开头写：

```text
本镜头延续项目视觉圣经：[主色/光线/材质/镜头气质/角色场景一致性]。
```

### 13.2 镜头锁定

每条提示词只写一个主要动作和一个主要运镜：

```text
人称视角：
主体动作：
主要运镜：
时长：
```

### 13.3 禁区锁定

每条提示词结尾写：

```text
保持角色脸部、服装、道具、场景布局一致；不要改变色调，不要增加无关装饰，不要切换到其他美术风格，不要出现夸张变形。
```

### 13.4 Seedance 2.0完整格式

```text
Seedance 2.0 视频提示词：
本镜头延续项目视觉圣经：[风格锁定句]。
人称视角：[第一人称/第二人称/第三人称/过肩/道具视角/回忆视角/群像视角]。
画面：[主体]在[固定场景]中[一个主要动作]。
镜头：[景别]，[机位]，[一个主要运镜]，时长[秒数]。
光线：[方向和光质]。
色彩：[主色、辅助色、记忆色]。
材质：[最重要的触感]。
声音：[环境声/动作声/音乐入口]。
剪辑点：[在什么动作或声音处切走]。
一致性：[角色、服装、道具、场景布局必须保持]。
负面规避：[不要改变风格、不要过度变形、不要增加无关人物、不要镜头乱飞]。
```

## 14. 人称运镜的风格用法

### 14.1 第一人称

适合：沉浸、恐惧、惊喜、亲密互动、玩家感、主观发现。

风格句：

```text
第一人称镜头要像观众亲手伸过去，不要像无人机冲过去。
```

Seedance写法：

```text
人称视角：第一人称，观众像角色本人一样看见自己的手伸向旧物。
镜头：近景，轻微手持前移，只保留一个伸手动作。
```

### 14.2 第二人称

适合：广告产品、邀请感、被角色看见、直面情绪。

风格句：

```text
第二人称不是硬看镜头，而是让观众变成故事里那个被回应的人。
```

### 14.3 第三人称

适合：讲清空间、群像、短剧冲突、动作调度。

风格句：

```text
第三人称先把关系交代清楚，再用近景把情绪压上来。
```

### 14.4 过肩视角

适合：对话、秘密、误会、压迫感。

风格句：

```text
过肩镜头让观众站在关系里面，不是站在场外看热闹。
```

### 14.5 道具视角

适合：广告、旧物情感、创意反转、奇观发现。

风格句：

```text
道具视角要让物件像在见证人，而不是单纯炫一个奇怪机位。
```

### 14.6 回忆视角

适合：怀旧、亲情、遗憾、公益、旧梦留声机类情绪。

风格句：

```text
回忆视角不要演得满，画面留一点空，观众会自己补。
```

### 14.7 群像视角

适合：可爱搞笑、幼儿园群像、办公室喜剧、荒诞会议。

风格句：

```text
群像镜头先给秩序，再让一个小动作把秩序弄歪，笑点就有了。
```

## 15. 关键帧策略

### 15.1 必做关键帧

短片或广告至少做3张：

1. 开场气质帧。
2. 核心动作帧。
3. 结尾记忆帧。

复杂项目做5张：

1. 世界观帧。
2. 主角识别帧。
3. 冲突帧。
4. 情绪/奇观峰值帧。
5. 封面记忆帧。

### 15.2 关键帧检查

每张关键帧自问：

1. 主体一眼清楚吗？
2. 风格和视觉圣经一致吗？
3. 角色识别点稳定吗？
4. 场景标志物稳定吗？
5. 这一帧能不能直接变成视频镜头？
6. 有没有照搬参考的可识别元素？

## 16. 热门项目参考的原创改写

### 16.1 “像绒耀幼儿园”

可借方法：

- 软萌群像。
- 幼儿园或小型集体空间。
- 角色认真处理荒诞问题。
- 低机位桌面视角。
- 明亮、干净、亲近的画面。
- 个体反应镜头制造笑点。

不要照搬：

- 对方具体角色。
- 对方固定场景布局。
- 对方口头禅、文案和剧情。
- 对方可识别造型组合。

原创改写方向：

```text
把“幼儿园群像”改成自己的原创小宇宙：比如云朵托儿所、月亮值班室、玩具修理班、植物小课堂。核心不是复制角色，而是保留“认真讨论荒诞问题”的喜剧机制。
```

Seedance风格锁定句：

```text
保持原创软萌群像风格：明亮浅色教室，小体量圆润角色，低机位桌面视角，表情清楚，动作小而认真，笑点来自集体误会，不照搬任何已有角色造型。
```

### 16.2 “像旧梦留声机”

可借方法：

- 一个旧物作为情绪入口。
- 低饱和怀旧色彩。
- 手部、背影、空椅子、旧墙面推动情绪。
- 声音比画面更早带出回忆。
- 镜头克制，留白多。

不要照搬：

- 对方具体旧物组合。
- 对方故事结构和文案。
- 对方角色关系。
- 对方标志性画面。

原创改写方向：

```text
保留“旧物唤醒没说出口的话”的方法，但换成新的关系、新的物件和新的时代痕迹。旧物可以是修过的雨伞、缝了一半的校服、发黄的公交卡、旧相机里的空胶卷。
```

Seedance风格锁定句：

```text
保持原创怀旧情感风格：低饱和暖灰色调，旧物特写，柔和侧逆光，人物动作克制，环境声安静，镜头稳定缓慢，情绪通过手部和留白表达，不照搬任何已有故事和画面。
```

### 16.3 创意广告参考

可借方法：

- 痛点用画面事件表现。
- 产品在关键动作里救场。
- 结尾留下品牌记忆帧。

不要照搬：

- 竞品具体画面。
- 竞品口号。
- 竞品包装识别。

原创改写方向：

```text
把卖点变成一个小危机，再让产品用动作解决它。观众先看到问题，再看到产品价值，而不是听角色解释。
```

### 16.4 特效打斗参考

可借方法：

- 先建立真实空间。
- 再让一个规则失效。
- 用人物反应镜头增强可信度。
- 关键动作要有材质反馈。

不要照搬：

- 已有英雄形象。
- 已有武器设计。
- 已有标志性招式。

原创改写方向：

```text
把特效规则改成和故事有关的规则，比如“谎话会变成玻璃裂纹”“每次心跳让灯光倒退一秒”“手碰到旧照片，房间短暂恢复十年前”。
```

## 19. 常见跑偏与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 一镜一个风格 | 没有项目风格锁定句 | 每条提示词开头加同一视觉圣经 |
| 角色忽胖忽瘦 | 角色圣经太抽象 | 补轮廓、服装、脸部识别点 |
| 场景变来变去 | 场景固定物不足 | 补入口、窗户、家具、标志物 |
| 颜色忽冷忽暖 | 色彩板缺失 | 锁主色、辅助色、记忆色 |
| 参考感太重 | 没有不可照搬清单 | 写清参考禁区并改换核心符号 |
| Seedance镜头乱飞 | 运镜过多 | 一镜只保留一个主要运镜 |
| 情绪太AI | 风格词多，动作少 | 用手部、停顿、声音、物件承载情绪 |

修复口吻：

```text
这不是风格不够高级，是锁得不够狠。先把主色、光线、角色轮廓和场景标志物钉住，再让镜头动。
```

## 20. 类型快速风格包

### 20.1 可爱搞笑

```text
明亮浅色空间，圆润角色，小幅动作，表情清楚，低机位亲近感，笑点来自认真误会，禁止过度拥挤和花哨背景。
```

### 20.2 治愈

```text
自然柔光，低对比，生活材质，缓慢镜头，细小动作，环境声参与情绪，禁止空泛唯美和无事发生。
```

### 20.3 怀旧情感

```text
低饱和暖灰，旧物特写，侧逆光，手部和背影，留白多，声音先行，禁止煽情过满和照搬参考故事。
```

### 20.4 创意广告

```text
干净构图，产品记忆色，卖点动作化，前后对比清楚，结尾品牌记忆帧，禁止只摆产品和只靠口播解释。
```

### 20.5 特效

```text
现实基准先稳定，异常光或异常材质逐步进入，人物反应镜头增强可信度，禁止一开始满屏特效。
```

### 20.6 打斗

```text
空间关系清楚，高对比光，可见动线，材质反馈，关键打击特写，禁止快切遮羞和动作因果不清。
```
