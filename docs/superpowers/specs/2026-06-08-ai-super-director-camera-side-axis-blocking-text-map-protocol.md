# AI超级导演导演摄影站边、轴线与动线文本图协议

## 1. 定位

这份协议解决一个现场导演问题：摄影机到底站哪边，人物左右关系怎么稳定，动作从哪里来、往哪里去，什么时候可以换边。

它不替代场面调度库。场面调度库负责空间和人物走位的总体设计；本协议负责把空间设计压成一张可检查的文本图，让导演、摄影、剪辑和 Seedance 2.0 提示词都知道同一件事：

```text
观众站在哪一侧看这场戏。
```

只要出现多人对白、短剧对峙、会议、饭桌、打斗、追逐、产品手部证明或空间方向反复出错，先画文本图，再写镜头。

## 2. 触发信号

用户出现这些说法时，默认调用本协议：

- “站位乱。”
- “左右跳。”
- “越轴了。”
- “机位站哪边？”
- “空间关系看不懂。”
- “人物从哪进来？”
- “谁在左谁在右？”
- “多人对白怎么拍？”
- “会议/饭桌/办公室怎么调度？”
- “打斗动作看不清。”
- “追逐方向别乱。”
- “产品手部动作别穿帮。”
- “给我画个场面调度文本图。”

## 3. 导演判断

```text
我会这样拍：
先不急着写漂亮镜头。先把观众站哪边定死：门、桌、证据、产品和人物左右关系先画出来。摄影机只在这一侧工作，除非有一个明确的换边理由和过渡镜头。
```

保留：

- 中心物。
- 入口和出口。
- 角色左右关系。
- 主要视线方向。
- 主要动线。
- 摄影机默认站边。

舍掉：

- 没有空间基准的炫技环绕。
- 正反打随意跨轴。
- 一镜里让多个人从不同方向乱进出。
- 只写“走过去”“冲上去”“大家看向他”。

第一刀：

```text
先画一张文本图，再决定镜头。
```

## 4. 文本图必填字段

```text
场景：
画幅：
中心物：
入口：
出口：
空间基准线：
摄影机站边：
主视线方向：
角色初始站位：
角色动线：
进入画面方向：
退出画面方向：
不能跨越的轴线：
可以换边的理由：
换边过渡镜头：
本场安全保底镜：
```

字段判断：

| 字段 | 作用 | 常见错误 |
| --- | --- | --- |
| 中心物 | 让群像和冲突有共同焦点 | 每个人都看不同方向 |
| 空间基准线 | 定清左右和前后 | 上一镜左，下一镜右 |
| 摄影机站边 | 决定观众站位 | 正反打跨轴 |
| 主视线方向 | 保证对话和反应能接 | 人物眼神互相看不见 |
| 角色动线 | 让动作有因果 | 角色瞬移或乱跑 |
| 不能跨越的轴线 | 给生成和剪辑设边界 | 镜头绕圈后方向乱 |
| 换边理由 | 让换边成为叙事动作 | 为了好看而乱换角度 |

## 5. 文本图画法

### 5.1 两人短剧对峙

```text
门/出口
  |
[压迫者B] ---- 桌子/证据 ---- [主角A]
                 ↑
            证据在中心

摄影机站A侧，贴着桌子右前方工作。
A看向左，B看向右。
本场不越过A-B关系轴线，除非证据被拿起后用证据特写重置方向。
```

适合镜头：

- 双人中景建立轴线。
- A侧过肩看B压迫。
- B侧反应必须仍保持人物左右关系。
- 证据特写作为插入镜。
- 主角反杀短句近景。

### 5.2 会议群像

```text
白板/屏幕
       [领导]

[旁观者C]  会议桌/方案  [旁观者D]
        [主角A]   [阻碍者B]

摄影机站会议桌前方偏A侧。
中心物是桌面方案。
A始终在画面右前方，B始终在画面左前方。
不让摄影机绕到白板背后。
```

调度原则：

- 群像中景只建立秩序，不承担长台词。
- 本镜主说话人只有一个。
- 其他人只做眼神、停顿、低头、看文件。
- 文件或产品特写可作为空间重置点。

### 5.3 饭桌家庭戏

```text
厨房/背景
       [长辈B]

[旁人C]   饭桌/碗筷   [主角A]
              ↓
          摄影机站A侧

A看向左上，B看向右下。
饭桌是关系轴线，不轻易跨过桌子。
筷子停住、碗被推开、空椅子都可以做插入镜。
```

调度原则：

- 桌子不是装饰，是隔阂。
- 谁控制碗筷、座位和沉默，谁控制压力。
- 情绪升级前不要让人物频繁走位。

### 5.4 打斗走廊

```text
出口
  ↑
[B后退] ---- 障碍/桌沿 ---- [A逼近]
  ↑                         ↑
  终点                      起点

摄影机站走廊右侧，保持动作从右向左推进。
不跨到走廊左侧，除非用全景重置双方位置。
```

调度原则：

- 先拍全景确认起点、终点、障碍和出口。
- 一镜只保留一次主要接触或躲避。
- 受力结果必须落到空间里：撞桌沿、退到门边、摔到墙侧。
- 快切不能遮住动作因果。

### 5.5 产品手部证明

```text
痛点物/污渍       产品       结果区
     [左] ---- [中] ---- [右]

摄影机站桌面前方。
手从画面下方进入，产品始终在中间。
不旋转桌面方向，不让左右结果互换。
```

调度原则：

- 痛点、产品、结果形成一条清楚的证明线。
- 手部动作从下方进入最稳定。
- 卖点文字、品牌字和参数后期添加。
- 结果变化要留半秒给观众确认。

## 6. 换边规则

默认不换边。必须换边时，只允许三种理由：

1. 权力关系真的翻转：主角夺回主动权，镜头站到主角新位置。
2. 空间目标改变：从对话变成逃跑、追逐、产品结果展示。
3. 插入镜重置方向：全景、证据特写、手部动作或门口镜头先让观众重新站稳。

换边过渡句：

```text
先用[全景/插入镜/动作转向]重置空间，再把摄影机换到[新站边]，换边理由是[权力反转/目标改变/空间重置]。
```

禁止：

- 没有过渡直接反打到另一侧。
- 用快速环绕假装换边。
- 在多人群像中连续换站边。
- 打斗还没交代方向就切到对侧近景。

## 7. 镜头分层

文本图确定后，再分镜：

| 镜头层级 | 任务 | 站边要求 |
| --- | --- | --- |
| 建立镜头 | 交代空间、中心物和左右关系 | 最清楚，不炫技 |
| 主镜头 | 承担冲突、动作或产品证明 | 保持默认站边 |
| 反应镜 | 接住台词、受力或结果 | 视线方向不跳 |
| 插入镜 | 证据、手部、产品、门、出口 | 可用于重置方向 |
| 保底镜 | 主镜头失败时可剪 | 固定机位、空间清楚 |

## 8. Seedance 2.0 字段

复杂镜头提示词增加这些字段：

```text
空间线：
摄影机站边：
主视线：
角色初始站位：
角色动线：
进入/退出方向：
禁止越轴：
换边理由：
本镜安全出点：
```

示例：

```text
空间线：桌子横在画面中间，门在左后方，证据在桌面中央。
摄影机站边：站在主角A一侧，桌子右前方，不绕到压迫者B背后。
主视线：A看向左，B看向右，双方眼神方向保持。
角色初始站位：A在画面右侧桌边，B在画面左侧门口。
角色动线：B从门口靠近桌边半步，A不后退，手压住证据。
禁止越轴：不跨过A-B关系轴线，不让A和B左右互换。
换边理由：本镜不换边。
本镜安全出点：B停在桌边，A低头看证据，留半秒沉默。
```

## 10. 常见错误与第一刀

| 错误 | 症状 | 第一刀 |
| --- | --- | --- |
| 左右跳 | 正反打人物方向互换 | 重写关系轴线和摄影机站边 |
| 站位乱 | 群像每镜位置都变 | 固定中心物和不可变化站位 |
| 打斗看不清 | 不知道谁逼近谁 | 全景建立起点、终点、障碍 |
| 追逐方向乱 | 前一镜向左跑，后一镜向右跑 | 锁定动作轴线或用全景重置 |
| 产品证明穿帮 | 痛点和结果位置互换 | 写痛点-产品-结果三点线 |
| 换边突兀 | 观众忽然不知道站哪边 | 加插入镜或全景重置空间 |
| 机位太花 | 环绕、推拉、摇移同时发生 | 只保留一个主要运镜 |

## 11. 自检

输出前自问：

1. 文本图里是否有门、出口、中心物、人物和摄影机站边？
2. 观众是否知道自己站在空间哪一侧？
3. A看向左还是右，B看向左还是右，是否稳定？
4. 主动作从哪个方向进入，从哪个方向退出？
5. 哪条轴线不能跨越？
6. 如果要换边，是否有明确理由和过渡镜头？
7. 插入镜是否能帮助剪辑重置方向？
8. Seedance 2.0 提示词是否写了禁止越轴和左右不互换？
9. 主镜头失败时，是否有固定机位保底镜？
10. 这张文本图是否能让另一个人不问问题就拍出来？
