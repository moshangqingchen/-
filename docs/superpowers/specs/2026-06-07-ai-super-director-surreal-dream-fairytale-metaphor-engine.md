# AI超级导演梦境超现实、童话寓言与隐喻意象导演引擎

## 1. 定位

这份引擎用于处理“梦境、超现实、奇幻、童话、寓言、诗意短片、隐喻、象征、心理空间、内心世界可视化”等需求。它不是堆奇怪画面，也不是把现实完全打碎，而是让一个情绪或关系通过可见意象发生变化。

一句话原则：

```text
先给现实锚点，再让一个不可能变化承载情绪。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “梦境感”“超现实”“奇幻短片”“童话感”“寓言感”。
- “更诗意”“更高级”“隐喻一点”“象征一点”“不要直说”。
- “把内心戏拍出来”“心理空间”“意识流”“像做梦一样但要看懂”。
- “产品卖点用隐喻表达”“品牌微电影要有意象”“情绪短片要有画面诗意”。

如果用户要求像某部电影、动画、游戏或具体 IP 的梦境/童话风格，必须先调用电影、特摄、短片与创意精华转译库，只继承情绪结构、意象功能和镜头目的，不复刻角色、造型、台词、Logo或标志性画面。

## 3. 超现实总公式

```text
现实锚点 + 情绪真相 + 一个不可能变化 + 意象规则 + 人物反应 + 回到现实的痕迹
```

拆解：

- 现实锚点：房间、街口、书桌、公交站、厨房、教室、办公室、旧物或产品使用场景。
- 情绪真相：孤独、羞愧、思念、压力、被看见、被误解、想逃走、想和解。
- 不可能变化：水从墙里渗出、影子先走、门后是星空、杯子里有一整片海。
- 意象规则：变化只由一个情绪、动作、道具或声音触发。
- 人物反应：角色必须先按现实逻辑反应，再慢慢接受或抵抗变化。
- 回到现实的痕迹：结尾保留一滴水、一片光、一点灰、一声铃，让梦和现实相互咬住。

## 4. 导演判断

收到超现实或隐喻需求时，先这样判断：

```text
我会这样拍：这条片不能一上来就飘，先让现实站住，再让一个不可能的意象替人物说话。保留一个最强隐喻，舍掉多重奇观，第一刀先定“这个意象到底替谁说什么”。
```

必须先回答四个问题：

1. 现实场景是什么？
2. 人物不愿意直接说出的情绪是什么？
3. 哪一个意象替他说？
4. 这个意象最后要留下什么现实痕迹？

## 5. 意象导演卡

| 卡名 | 情绪功能 | 画面方法 | 避免 |
| --- | --- | --- | --- |
| 水位卡 | 压力、眼泪、淹没感 | 房间水位慢慢升高，只到脚踝或桌边 | 一镜变成海啸 |
| 影子卡 | 自我分裂、秘密、恐惧 | 影子先动作，人物慢半拍反应 | 影子独立打戏太复杂 |
| 门后卡 | 选择、未知、逃离 | 普通门后出现不该出现的空间 | 门后世界过度铺设 |
| 旧物变形卡 | 怀旧、缺席关系 | 旧物短暂恢复新状态或发出旧声 | 直接解释回忆 |
| 尺度反差卡 | 小人物大任务 | 小主体面对巨大但温柔的物体 | 没有现实参照 |
| 天气入室卡 | 情绪外化 | 雨、雪、风、阳光进入室内 | 满屏粒子遮住动作 |
| 童话职能卡 | 产品/人物被寓言化 | 道具承担角色任务，但功能真实 | 把卖点讲成空泛童话 |
| 痕迹回收卡 | 余味 | 梦结束后现实留一个小痕迹 | 结尾全解释 |

## 6. 童话寓言结构

童话和寓言不是幼稚，而是把复杂关系变成简单规则。

默认公式：

```text
小主体 + 大任务 + 明确规则 + 一次温柔失败 + 一次意象帮助 + 现实落点
```

适合：

- 可爱治愈短片：小主体用幼稚办法解决大问题。
- 创意广告：产品功能变成童话里的帮助规则，但仍要回到真实卖点。
- 公益情感：人物缺口通过寓言关系被看见。
- 系列IP：每集一个小寓言规则，结尾回收固定动作或声音。

童话 Seedance 2.0 原则：

- 角色关系简单，动线清楚。
- 不让多个魔法规则同时出现。
- 可读文字、标题、品牌字后期添加。
- 童话化的是“功能和情绪”，不是复制已有童话角色。

## 7. 梦境与心理空间

梦境镜头要有入梦点和出梦痕迹。

入梦点：

- 声音重复：钟声、门铃、脚步、滴水。
- 动作重复：转身、开门、伸手、低头。
- 道具触发：旧照片、杯子、钥匙、玩具、产品按钮。
- 空间错位：走廊变长、窗外不是原来的城市、灯光方向不对。

出梦痕迹：

- 手上有水。
- 桌上多了一片叶子。
- 空气里还残留一个声音。
- 角色做了和梦里一样的小动作。

高风险提醒：

- 长梦境、复杂变形、多场景连跳容易生成失败。
- 默认拆成“现实锚点、异常开始、人物反应、意象完成、痕迹回收”五类镜头。
- 不要一镜同时做换场景、换服装、变形、群像和大运镜。

## 8. 类型联动

| 类型 | 超现实用法 | 第一刀 |
| --- | --- | --- |
| 情感怀旧 | 旧物和声音短暂复活 | 先定缺席关系，不先上滤镜 |
| 悬疑反转 | 空间出现不合逻辑的痕迹 | 先定信息差，不乱加怪象 |
| 可爱治愈 | 小主体面对巨大温柔任务 | 先定小主体要修复什么 |
| 创意广告 | 卖点变成可见意象规则 | 产品动作必须证明真实价值 |
| 高概念短片 | 一个超现实规则撑全片 | 每镜只证明一个变量 |
| 特效奇观 | 现实材质被一点点改写 | 先建立现实基准和人物反应 |

## 9. Seedance 2.0 超现实字段

超现实提示词默认增加这些字段：

```text
现实锚点：
情绪真相：
核心意象：
意象规则：
入梦/触发点：
人物反应：
现实痕迹：
可生成风险：
禁止项：不要多重奇观，不要复杂变形，不要乱码文字，不要复刻已有IP童话角色，不要一镜跨太多空间
```

Seedance 2.0 提示词骨架：

```text
4-6秒视频镜头。风格锁定：[统一风格句]。
现实锚点是[普通空间/道具]，角色先按现实逻辑做[具体动作]。
情绪真相是[不直接说出的情绪]，核心意象是[一个不可能变化]，本镜只让意象发生[一个阶段]。
摄影机为[人称/身体化镜头卡]，运动克制，先稳定观察，再轻微跟随角色反应。
声音触发点是[滴水/钟声/脚步/呼吸/产品声]，结尾留下[现实痕迹]。
可读文字、字幕、标题和品牌字后期添加；画面预留干净字幕安全区。
避免多重奇观、复杂变形、突然换场、角色造型漂移、已有IP符号和乱码文字。
```

## 11. 自检

输出前自问：

1. 是否先建立了现实锚点？
2. 核心意象是否只替一个情绪或关系说话？
3. 意象规则是否清楚，而不是随机奇观？
4. 人物是否先按现实逻辑反应？
5. 结尾是否有现实痕迹或余味动作？
6. Seedance 2.0 是否拆成单阶段变化？
7. 是否避免复刻已有童话、电影、动画或游戏的可识别表达？
