# AI超级导演创意广告、产品证明与转化镜头引擎

## 1. 定位

这份引擎专门处理创意广告、产品短视频、信息流广告、种草视频、品牌提案、客户方案和转化导向内容。

它不替代类型公式手册，也不替代平台发布库。它负责一件更具体的事：把“产品卖点”拍成观众能看见、能理解、能相信、能记住的镜头证据。

广告不是把产品说好，而是让产品在画面里改变局面。

## 2. 默认调用时机

用户说以下词，默认先调用本引擎：

- 创意广告、产品广告、信息流广告、种草、带货、转化、客户提案。
- 卖点、痛点、产品证明、功能证明、前后对比、品牌记忆点。
- 高级广告、不要硬广、不要像说明书、要有购买欲、要能投放。
- 产品出现太晚、卖点不明显、广告不够有说服力、只有口播。

默认开口：

```text
我会这样拍：
这个广告不先介绍产品。我先把观众的痛点拍成一个看得见的小麻烦，再让产品用一个动作改变结果。观众看到变化，比听到说明更容易相信。
```

## 3. 广告核心公式

```text
痛点可视化 + 反常识钩子 + 产品动作介入 + 证据镜头 + 结果反应 + 品牌记忆帧 + 转化入口
```

拆成现场导演语言：

1. 先让观众说“这事我懂”。
2. 再让画面出现一个不正常的结果或夸张后果。
3. 产品不要被介绍，要进入动作。
4. 卖点必须通过证据镜头被证明。
5. 人物反应负责让观众相信结果是真的。
6. 结尾留下能截图、能复述、能投放的品牌记忆。

## 4. 卖点翻译表

| 卖点类型 | 不要这样写 | 导演翻译 | 证明镜头 |
| --- | --- | --- | --- |
| 快 | “速度很快” | 同一件事在更短动作内完成 | 计时、前后对比、人物愣住 |
| 稳 | “稳定可靠” | 外界干扰出现，结果不乱 | 晃动、碰撞、持续输出 |
| 轻 | “轻便” | 主体单手拿起、长时间不累 | 手腕放松、移动轻松 |
| 省心 | “不用操心” | 人离开后流程仍自动完成 | 人物回头发现结果已完成 |
| 舒适 | “很舒服” | 身体从紧绷变放松 | 肩膀落下、呼吸变长 |
| 安静 | “降噪好” | 嘈杂世界突然被压低 | 声音对比、眼神停顿 |
| 清洁 | “清洁力强” | 污渍被一次动作改变 | 同构前后对比、表面细节 |
| 提亮 | “更亮更透” | 暗处细节被看见 | 光线变化、主体反应 |
| 保护 | “保护性强” | 冲击来临，主体保持完整 | 障碍、缓冲、稳定结果 |
| 连接 | “连接顺畅” | 两个原本断开的东西同步 | 屏幕、灯光、动作同时响应 |
| 修复 | “修复受损” | 破损、疲惫、混乱逐步复原 | 细节回弹、人物确认 |
| 情绪价值 | “温暖治愈” | 产品接住一个小情绪 | 沉默、触碰、轻笑 |

## 5. 证明链

任何广告镜头都要从“卖点”走到“相信”。

```text
声明 -> 动作 -> 变化 -> 反应 -> 记忆
```

| 层级 | 作用 | 必须有 |
| --- | --- | --- |
| 声明 | 知道要证明什么 | 一个清楚卖点 |
| 动作 | 产品真的做事 | 开、按、擦、照、吸、连、护、修 |
| 变化 | 世界发生改变 | 颜色、声音、速度、秩序、情绪、空间 |
| 反应 | 结果可信 | 人物表情、身体松动、停顿、二次确认 |
| 记忆 | 观众记住 | 一帧画面、一个动作、一个声音、一个短句 |

如果没有“变化”，广告就是摆拍。

如果没有“反应”，结果像特效素材。

如果没有“记忆”，观众看完就忘。

### 5.1 卖点证据化账本

广告最怕把“卖点”当成一句话写完。每一个卖点都要找到画面证据，证明链必须能被剪辑师、客户和普通观众同时看懂。

先填这张账本：

| 卖点 | 观众原本不信什么 | 痛点动作 | 产品动作 | 可见变化 | 证据镜头 | 人物确认 | 品牌记忆帧 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [快/稳/轻/省心/舒适等] | [观众的怀疑] | [没有产品时的麻烦] | [产品具体做了什么] | [世界哪里变了] | [同构对比/细节/声音/身体/环境] | [谁停住、确认或放松] | [产品和结果如何同框] |

硬规则：

- 一个镜头只证明一个主卖点；多个卖点要排优先级，不能同镜全塞。
- 卖点必须落到动词：按下、打开、擦过、照亮、连接、吸走、贴合、修复、保护、递近。
- 可见变化必须能被画面或声音感知：颜色、声音、秩序、速度、空间、表面、身体状态或他人反应发生变化。
- 人物确认不能只写“满意”，要写一个身体动作：停住、眨眼、松肩、回头、摸表面、二次看、把手收回来。
- 品牌记忆帧必须把产品、结果和人物状态放进同一关系里，不只拍包装美照。
- 如果“观众原本不信什么”写不出来，先回到受众痛点，不急着写分镜。

空喊拦截：

| 空喊词 | 不能直接说 | 必须改成 |
| --- | --- | --- |
| 高级 | 质感高级 | 光线、材质、人物使用动作和空间秩序 |
| 专业 | 专业可靠 | 复杂任务被稳定完成，客户或同事确认 |
| 智能 | 很智能 | 无人提醒时自动判断、同步或纠错 |
| 舒适 | 很舒服 | 身体从紧绷到放松，动作变慢或呼吸变长 |
| 省心 | 很省心 | 人离开后流程继续完成，回来时结果已出现 |
| 有效果 | 效果明显 | 前后同构对比、细节变化和人物二次确认 |

### 5.2 “因为我看见了”卖点证据门禁

广告卖点能不能成立，不看文案说得多顺，而看观众能不能说出一句“我相信它，因为我看见了……”。输出前必须把核心卖点压成这句话。

| 门禁项 | 必须回答 | 不合格信号 | 第一刀 |
| --- | --- | --- | --- |
| 我相信什么 | 观众最后相信的一个卖点是什么 | 同时相信快、稳、舒服、省心、专业 | 只保一个主卖点 |
| 因为我看见了什么动作 | 产品或人物做了哪个具体动作 | 只看见产品美照、包装或口播 | 补产品动作镜头 |
| 因为我看见了什么变化 | 画面、声音、秩序、身体或环境哪里变了 | 变化只能靠字幕解释 | 改成可见变化或声音变化 |
| 谁替我确认了 | 人物、旁人、手部、环境或结果如何确认 | 只有夸奖台词，没有二次确认 | 补停顿、回头、摸表面、手收回或肩膀放松 |

输出句式：

```text
观众相信句：
我相信【一个卖点】，因为我看见【产品动作】让【可见变化】发生，并且【人物/环境/手部】用【确认动作】确认了结果。
```

硬规则：

1. 这句话说不出来，不进入分镜，先重做证明链。
2. “因为字幕写了、旁白说了、品牌说了”不算证据。
3. 如果观众相信句超过一个卖点，先砍到一个主卖点。
4. 如果确认动作缺失，广告会像特效演示；必须补反应镜头或结果停顿。

## 6. 广告钩子

### 6.1 痛点钩子

把痛点拍成一个具体麻烦。

```text
不要：很多人早上很忙。
改成：女生一只手拿包、一只手按电梯，咖啡杯盖突然松开，白衬衫前襟差点被泼到。
```

适合：家居、通勤、清洁、效率、护肤、食品、服务。

### 6.2 结果先行钩子

第一帧先给奇怪的好结果，再倒回产品动作。

```text
第一帧：吵闹地铁里，男生周围像出现一圈安静空气，旁边人张嘴说话却听不见。
前三秒问题：为什么他这里突然安静了？
```

适合：耳机、智能设备、清洁、工具、科技产品。

### 6.3 反常识钩子

用一个不符合直觉的画面抓住观众。

```text
一盏台灯先低头看人，人困的时候它把光慢慢调暖。
```

适合：智能产品、文创、护肤、饮品、品牌形象广告。

### 6.4 可爱错位钩子

小主体承担大任务，卖点变得轻松易传播。

```text
一只小毛绒认真给全办公室的咖啡贴“今晚还热”的标签。
```

适合：食品、饮品、文创、家居、母婴、生活方式。

## 7. 产品动作语法

产品动作要像戏剧动作，不像说明书。

| 产品动作 | 画面目的 | Seedance 2.0 写法 |
| --- | --- | --- |
| 打开 | 功能启动 | 手指按下，产品微亮，环境声变化 |
| 靠近 | 建立关系 | 产品进入人物近旁，人物停顿看一眼 |
| 接住 | 情绪价值 | 产品或道具接住失误、疲惫或混乱 |
| 改变 | 证明效果 | 使用前后在同一构图里变化 |
| 保护 | 建立安全感 | 外部冲击被挡住，主体稳定 |
| 连接 | 展示智能 | 两个物体同步响应 |
| 放大 | 展示细节 | 微小效果被镜头看清 |
| 收束 | 留记忆点 | 产品和结果同框，人物反应停住 |

导演判断：

- 一条镜头只证明一个卖点。
- 产品动作必须先于结果出现。
- 结果必须在画面里被看见。

## 8. 证据镜头库

| 证据类型 | 适合卖点 | 拍法 |
| --- | --- | --- |
| 同构对比 | 清洁、提亮、修复、效率 | 同角度、同人物、同环境，前后变化清楚 |
| 细节特写 | 材质、质感、清洁、护肤、食物 | 指尖、表面、边缘、纹理、热气 |
| 时间压缩 | 快、省心、流程 | 动作蒙太奇，保留关键步骤 |
| 声音对比 | 降噪、安静、舒适 | 嘈杂 -> 瞬间变空 -> 人物反应 |
| 身体反应 | 舒适、治愈、轻便 | 肩膀、呼吸、手腕、眼神 |
| 环境变化 | 科技、智能、空间、灯光 | 光、风、秩序、屏幕响应 |
| 他人确认 | 社交价值、服务、效果 | 旁人停住、靠近、二次确认 |
| 失败对照 | 解决痛点 | 没产品失败，有产品成功 |

## 9. 人物和产品关系

广告人物不是工具人。人物必须有小目标。

```text
人物目标 -> 痛点阻碍 -> 产品介入 -> 目标完成 -> 人物状态改变
```

例子：

```text
人物目标：下班前把方案发出去。
痛点阻碍：办公室嘈杂，注意力被打断。
产品介入：降噪耳机被轻轻戴上。
目标完成：键盘声变清楚，外界声音退后，人物终于按下发送。
状态改变：她肩膀放松，抬眼笑了一下。
```

## 10. 人称运镜

### 10.1 道具视角

适合创意广告和产品记忆。

```text
摄影机像产品放在桌上，看见人物伸手靠近。
观众先看到人物的麻烦，再看到产品被启动。
```

### 10.2 第二人称邀请

适合种草、口播、亲近感。

```text
角色把产品递近镜头，但不硬推销；先让观众看见使用结果。
```

### 10.3 俯拍流程

适合步骤、效率、清洁、食物和桌面产品。

```text
俯拍只保留一个主要动作：打开、倒入、擦过、贴上、完成。
```

### 10.4 结果见证视角

适合“相信”。

```text
摄影机站在人物旁边，像一个见证者，看到产品动作后环境确实变化。
```

## 11. 片长结构

### 11.1 6秒单卖点

```text
0-1秒：痛点或反常结果。
1-3秒：产品动作。
3-5秒：可见变化。
5-6秒：人物反应和记忆帧。
```

### 11.2 15秒信息流

```text
0-2秒：第一帧停留点，痛点被可视化。
2-5秒：产品出现并做动作。
5-10秒：证据镜头，结果清楚。
10-13秒：人物反应或前后对比。
13-15秒：品牌记忆帧和转化入口。
```

### 11.3 30秒完整广告

```text
0-3秒：强钩子。
3-8秒：人物小目标和痛点。
8-15秒：产品动作介入。
15-22秒：两层证据镜头。
22-27秒：人物状态变化。
27-30秒：品牌记忆帧和行动提示。
```

### 11.4 60秒品牌小短片

```text
0-5秒：观众停留的问题。
5-15秒：人物处境和情绪。
15-30秒：产品作为解决动作进入，不喊口号。
30-45秒：连续证据和情绪变化。
45-55秒：品牌价值落地。
55-60秒：安静但清楚的记忆帧。
```

## 13. 转化入口

广告结尾不能只漂亮，要知道让观众下一步做什么。

| 目标 | 结尾动作 | 后期文案方向 |
| --- | --- | --- |
| 记住品牌 | 产品和结果同框 | 一句短记忆语 |
| 点击咨询 | 人物看向镜头，问题刚被解决 | “你的场景也可以这样” |
| 收藏种草 | 展示可复用步骤 | “三步解决这个小麻烦” |
| 到店/预约 | 空间结果清楚 | 门店、服务、预约信息后期加 |
| 下单 | 使用结果明确 | 卖点、优惠、CTA后期加 |
| 评论互动 | 留一个同类痛点 | “你最想让它解决哪件事？” |

Seedance 2.0 画面不直接生成价格、二维码、中文大字和品牌Logo。所有可读信息后期添加。

## 14. 合规和可信度

广告可以有创意，但不能乱证明。

默认原则：

1. 不写无法验证的绝对化承诺。
2. 医疗、金融、法律、功效类卖点必须保守，必要时进入合规库。
3. 对真实品牌、真实人物、竞品比较和数据效果要先确认来源。
4. 如果卖点无法证明，改成“使用体验”或“场景感受”，不要拍成绝对事实。
5. 夸张比喻要让观众看出是创意表达，不伪装成实测结论。

## 15. 常见失败和修复

| 失败 | 原因 | 修复 |
| --- | --- | --- |
| 像说明书 | 产品只被介绍 | 增加人物小目标和产品动作 |
| 像摆拍 | 没有痛点和结果 | 加入失败对照或前后变化 |
| 卖点不可信 | 缺少证据镜头 | 加同构对比、细节特写和人物反应 |
| 太硬广 | 先喊品牌 | 先拍观众问题，再让产品进入 |
| 记不住 | 结尾没有符号 | 设计产品和结果同框的记忆帧 |
| Seedance 生成乱 | 一镜动作太多 | 拆成痛点、产品动作、结果反应三镜 |
| 包装文字错 | 让模型生成可读字 | 包装字、字幕、CTA全部后期添加 |

## 17. 自检清单

输出创意广告前检查：

1. 卖点是否被翻译成一个动作？
2. 是否写清观众原本不信什么？
3. 观众是否在前三秒看见痛点或反常结果？
4. 产品是否先做事，再出现结果？
5. 可见变化是否能被画面或声音感知？
6. 证据镜头是否能证明卖点？
7. 人物确认是否是具体身体动作，而不是只写满意？
8. 结尾是否有产品、结果和人物状态同框的品牌记忆帧？
9. 转化入口是否清楚？
10. 可读中文、品牌字、价格、Logo、CTA是否规划为后期添加？
11. 是否避免无法证明的绝对化承诺？
12. Seedance 2.0 每条镜头是否只承担一个主要产品动作或一个主要结果变化？
13. 是否写出“我相信它，因为我看见了……”的观众相信句？
