# AI超级导演镜头语言词典

## 1. 使用方式

这份词典用于帮助AI超级导演在分镜中选择合适的景别、机位、镜头运动和剪辑策略。镜头语言不是装饰，它必须服务情绪、冲突、信息、卖点或节奏。

默认判断顺序：

1. 这个镜头要让观众知道什么？
2. 这个镜头要让观众感受什么？
3. 主体和空间关系是否清楚？
4. 是否需要移动镜头？
5. 镜头运动的情绪理由是什么？

## 2. 景别词典

### 2.1 远景

功能：交代环境、尺度、孤独感、宏大感。

适合：

- 治愈片的安静空间。
- 特效片的奇观尺度。
- 打斗前的空间交代。
- 短剧开场建立场景关系。

提示词写法：

```text
远景，人物位于画面中的小比例，环境占主导，强调空间尺度和氛围。
```

常见失误：远景用太久会让观众看不清表情和动作。

### 2.2 全景

功能：让观众看清人物全身动作和空间位置。

适合：

- 打斗动线。
- 舞蹈或肢体表演。
- 角色进入场景。
- 群像关系。

提示词写法：

```text
全景，人物全身入画，空间关系清楚，动作路径可见。
```

常见失误：全景里主体不够突出，导致看点分散。

### 2.3 中景

功能：平衡人物动作、表情和环境，是剧情交流的稳定景别。

适合：

- 对话。
- 广告产品使用。
- 短剧冲突。
- 角色关系建立。

提示词写法：

```text
中景，人物腰部以上，能看清动作和表情，背景提供场景信息。
```

常见失误：中景过多会让分镜像普通记录，缺少节奏变化。

### 2.4 近景

功能：强调表情、台词、情绪变化和人物反应。

适合：

- 短剧关键台词。
- 情感片压住眼泪的瞬间。
- 搞笑角色反应。
- 广告中用户感受到变化。

提示词写法：

```text
近景，人物胸部以上，表情清晰，情绪变化是画面重点。
```

常见失误：近景没有表情变化时会显得空。

### 2.5 特写

功能：把注意力集中到一个细节、动作或记忆点。

适合：

- 手拿旧照片。
- 产品按钮、质地、效果。
- 可爱角色的小爪子、小表情。
- 打斗中的关键道具。

提示词写法：

```text
特写，聚焦 [细节/道具/手部/眼神]，背景虚化，细节清楚。
```

常见失误：特写太多会破坏空间连续性。

### 2.6 大特写

功能：制造强烈情绪、悬念、压迫或喜剧停顿。

适合：

- 眼神反转。
- 旧梦留声机类情感克制。
- 搞笑角色呆住。
- 悬疑发现真相。

提示词写法：

```text
大特写，只保留眼睛/嘴角/手指/道具局部，情绪高度集中。
```

常见失误：大特写如果没有情绪理由，会显得做作。

## 3. 机位词典

### 3.1 平视

功能：自然、客观、亲近。

适合：大多数剧情、治愈、广告展示、可爱角色互动。

提示词写法：

```text
平视机位，观众与角色处在同一高度，亲近自然。
```

### 3.2 低机位

功能：增强力量、压迫、英雄感、儿童视角或可爱仰视。

适合：

- 动作打斗的压迫感。
- 短剧角色登场。
- 可爱小角色仰拍。
- 产品显得更有存在感。

提示词写法：

```text
低机位仰拍，主体更有力量或更具存在感。
```

常见失误：低机位滥用会显得虚张声势。

### 3.3 高机位

功能：表现脆弱、孤独、被观察、空间布局。

适合：

- 情感低谷。
- 治愈片中的小人物。
- 打斗空间关系。
- 群像秩序。

提示词写法：

```text
高机位俯拍，主体显得较小，空间关系清楚，带一点距离感。
```

### 3.4 过肩镜头

功能：表现对话关系、信息差、对抗和亲密。

适合：

- 短剧冲突对话。
- 情感和解。
- 广告用户与产品互动。
- 悬疑对峙。

提示词写法：

```text
过肩镜头，前景保留一侧人物肩部，焦点落在对面人物表情。
```

### 3.5 主观镜头

功能：让观众进入角色视角，增强代入、恐惧、好奇或亲密。

适合：

- 开门看见意外。
- 旧物被拿起。
- 打斗中被逼近。
- 可爱角色看向观众。

提示词写法：

```text
主观视角，画面像角色亲眼所见，前景可有手部动作，增强代入感。
```

常见失误：主观镜头太多会让空间关系混乱。

## 4. 镜头运动词典

### 4.1 推镜

功能：靠近情绪、强调发现、制造压迫或揭示重点。

适合：

- 人物意识到真相。
- 情感被触动。
- 产品卖点显现。
- 恐惧或悬疑升级。

提示词写法：

```text
缓慢推镜，从中景推到近景，观众逐渐靠近人物情绪。
```

常见失误：没有情绪变化时推镜会显得机械。

### 4.2 拉镜

功能：从细节退到全局，揭示环境、孤独、反转或荒诞关系。

适合：

- 搞笑反差：先看认真表情，再拉开看到离谱场面。
- 情感孤独：从人物拉到空房间。
- 特效奇观：从小异常拉到大规模变化。

提示词写法：

```text
缓慢拉镜，从特写拉到全景，逐步揭示更大的空间和反转信息。
```

### 4.3 摇镜

功能：从一个信息点转向另一个信息点，制造发现、关系和节奏。

适合：

- 发现门口的人。
- 从产品转到用户反应。
- 打斗中跟随攻击方向。
- 搞笑中从角色表情摇到荒诞道具。

提示词写法：

```text
横向摇镜，从 [信息A] 摇到 [信息B]，形成发现或反差。
```

常见失误：摇镜没有明确目标会像随便扫视。

### 4.4 移镜

功能：跟随空间变化，展示环境和人物关系。

适合：

- 人物走入新空间。
- 广告展示使用流程。
- 治愈片的慢生活。
- 短剧跟随主角行动。

提示词写法：

```text
平稳横移镜头，跟随主体穿过场景，空间层次逐渐展开。
```

### 4.5 跟镜

功能：让观众跟着角色行动，增强临场感和节奏。

适合：

- 追逐。
- 打斗。
- 主角进入冲突现场。
- 产品使用流程。

提示词写法：

```text
跟拍镜头，摄影机保持在主体侧后方，跟随主体移动，动作连续。
```

常见失误：跟拍过晃会让动作看不清。

### 4.6 升降镜头

功能：改变视角层级，展示空间、仪式感、压迫或释放。

适合：

- 品牌广告的高级感。
- 特效奇观展开。
- 角色登场。
- 情绪从低谷到释放。

提示词写法：

```text
升降镜头，摄影机从低处缓慢升起，逐步展示人物和空间关系。
```

### 4.7 环绕镜头

功能：制造沉浸、眩晕、情绪包围、关系变化或高光时刻。

适合：

- 角色觉醒。
- 产品高光展示。
- 情感重逢。
- 特效能量环绕。

提示词写法：

```text
环绕镜头，摄影机围绕主体缓慢旋转，主体保持画面中心，背景形成流动感。
```

常见失误：环绕太快会显得炫技，抢走故事。

### 4.8 手持镜头

功能：真实、紧张、纪实、混乱、临场。

适合：

- 打斗、追逐、惊慌。
- 伪纪录片。
- 公益真实感。
- 情绪失控。

提示词写法：

```text
轻微手持镜头，有真实呼吸感和微小晃动，但主体始终清楚。
```

常见失误：手持不是乱晃，必须保留主体可读性。

### 4.9 静止镜头

功能：克制、观察、留白、压住情绪。

适合：

- 旧梦留声机类怀旧情感。
- 治愈片。
- 冷幽默。
- 情绪爆发前的安静。

提示词写法：

```text
固定机位，画面稳定，人物在镜头内完成细小动作，情绪靠动作和声音推进。
```

常见失误：静止镜头没有内部动作会变空。

## 5. 剪辑语言词典

### 5.1 动作剪辑

功能：在动作完成点切镜，保持流畅。

适合：打斗、产品使用、角色走位。

提示词写法：

```text
在 [动作完成/手触碰道具/角色回头] 的瞬间切入下一镜。
```

### 5.2 反应剪辑

功能：事件发生后切到人物反应，让观众理解情绪。

适合：搞笑、特效、短剧反转、情感冲击。

提示词写法：

```text
事件发生后停半秒，切到人物近景反应，表情变化清楚。
```

### 5.3 匹配剪辑

功能：用相似动作、形状或构图连接两个镜头。

适合：广告、情感回忆、时间跳跃。

提示词写法：

```text
用相同构图或相似动作从 [镜头A] 匹配剪辑到 [镜头B]。
```

### 5.4 跳切

功能：压缩时间、制造节奏或喜剧感。

适合：搞笑、种草、训练、准备过程。

提示词写法：

```text
快速跳切，连续展示几个动作阶段，节奏轻快，信息清楚。
```

常见失误：跳切过碎会让观众失去方向。

### 5.5 留白剪辑

功能：让情绪停留，不急着解释。

适合：治愈、怀旧、公益、亲情。

提示词写法：

```text
动作结束后保留一秒静默，让环境声和人物停顿承接情绪。
```

## 6. 类型适配

### 6.1 可爱

优先：近景、特写、低机位、轻推镜、静止小动作。

避免：过度高速运动、主体太远、表情不可见。

### 6.2 治愈

优先：固定机位、慢移镜、缓慢推镜、留白剪辑。

避免：快切、强对比光、镜头运动过多。

### 6.3 特效

优先：现实基准远景、推镜发现异常、拉镜揭示奇观、反应剪辑。

避免：一上来大特效、没有人物反应。

### 6.4 打斗

优先：全景交代空间、跟镜保持动线、动作剪辑、关键打击特写。

避免：只用近景快切、看不清谁打谁。

### 6.5 创意广告

优先：产品特写、动作剪辑、匹配剪辑、推镜卖点、品牌记忆帧。

避免：只拍漂亮产品，没有功能动作。

### 6.6 搞笑

优先：静止停顿、反应剪辑、拉镜揭示荒诞、近景表情。

避免：过早解释笑点、剪太快不给反应。

### 6.7 情感

优先：旧物特写、固定机位、手部特写、慢推镜、留白剪辑。

避免：强行大哭、旁白过满、没有具体物件。

## 8. 导演自检

1. 镜头语言是否服务情绪、冲突或卖点？
2. 景别是否让观众看清必要信息？
3. 机位是否有明确态度？
4. 镜头运动是否有情绪理由？
5. 剪辑点是否清楚？
6. 类型适配是否正确？
