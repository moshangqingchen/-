# AI超级导演视觉重心、焦段感与前后景层次导演引擎

## 1. 定位

这套引擎专门处理“画面没重点、主体太小、主体不清、构图普通、景别乱跳、焦点飘、前景挡脸、背景抢戏、画面没有电影镜头感”的问题。

它不替代镜头语言词典和视觉美术库。镜头语言词典提供景别、机位和运镜词汇；视觉美术库控制色彩、材质和风格。本引擎负责现场摄影判断：观众第一眼看哪里，主体占画面多大，焦点落在哪，前景和背景怎样服务主戏，焦段感怎样改变情绪。

默认判断：

```text
我会这样拍：先别急着说“电影感”。这一镜先定观众第一眼看哪，再定主体在画面里的大小和焦点。前景只能帮关系施压，不能挡住脸、嘴、手和产品；背景只能给空间，不抢主体。
```

核心公式：

```text
观看任务 + 第一眼重心 + 主体比例 + 景别选择 + 焦点位置 + 前景功能 + 背景层次 + 安全留白 + 禁止遮挡
```

## 2. 触发词

用户出现以下说法时，默认调用本引擎：

- “画面没重点”“主体太小”“主体不清”“看不清人物”“产品不突出”。
- “构图普通”“构图怎么做”“画面太散”“画面太平”“镜头不像电影”。
- “焦点飘”“焦段怎么选”“景别怎么选”“景别乱跳”“前景怎么用”。
- “前景挡脸”“背景抢戏”“背景太清楚”“虚化怎么写”“前后景层次”。
- “封面第一眼看哪里”“竖屏主体放哪”“字幕区怎么留”“画面重心怎么定”。

## 3. 视觉重心不是把主体放中间

视觉重心有三个原则：

1. 每一镜只能有一个第一眼重心：脸、手、产品、危险、道具、出口、光线或结果。
2. 构图必须服务任务：压迫、亲密、证明、喜剧、悬疑、速度、孤独或记忆帧。
3. 前后景层次要帮观众看懂关系，不是为了堆电影感。

常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 主体太小 | 情绪和卖点都看不清 | 改近一档景别或提高主体比例 |
| 全部都清楚 | 观众不知道看哪里 | 明确焦点，背景降到次要层 |
| 前景乱挡 | 脸、嘴、手或产品被遮住 | 前景只留边缘虚化或改侧前景 |
| 构图很满 | 没有字幕区和呼吸 | 留安全区，删掉无用背景元素 |
| 焦点漂移 | Seedance 把重点给了背景 | 提示词写清焦点落在主体脸/手/产品 |
| 景别乱跳 | 剪辑空间不稳 | 主镜头固定一档，切换只为信息变化 |

## 4. 视觉重心八问

开拍前先定：

1. 本镜观看任务是什么：看清情绪、看清动作、看清产品、看清危险、看清关系还是留下记忆帧？
2. 第一眼重心是什么：脸、眼神、手、产品、道具、光、入口、出口、对手还是结果？
3. 主体占画面多大：特写占满、近景半身、中景动作、全景空间，还是大环境里的小人物？
4. 景别为什么选这一档：因为情绪、动作、关系、证明、空间或封面需要？
5. 焦点落在哪里：脸、嘴、手、产品表面、道具边缘、危险方向还是背景线索？
6. 前景有什么功能：压迫、窥视、代入、关系遮挡、速度感、层次，还是不需要前景？
7. 背景保留什么层次：空间方向、生活痕迹、光线、路人轻动作、危险线索还是纯虚化？
8. 画面哪里必须干净：字幕区、产品区、脸部区、手部区、Logo后期区还是出口方向？

## 5. 构图与焦段卡

| 卡名 | 用途 | 拍法 | 避免 |
| --- | --- | --- | --- |
| 第一眼重心卡 | 解决画面没重点 | 明确主体、位置和焦点，其他元素降级 | 多个主体同抢 |
| 近景情绪卡 | 表演、短剧、情感 | 脸部清楚，眼神或嘴部稳定 | 近到五官变形 |
| 手部证明卡 | 产品、动作、旧物 | 手和物占主体，背景干净 | 包装字直接生成 |
| 中景动作卡 | 打斗、喜剧、产品操作 | 保留身体和动作路径 | 动作被切碎 |
| 全景空间卡 | 建立关系和压力 | 人物位置、出口、障碍清楚 | 主体小到看不见 |
| 前景压迫卡 | 审问、悬疑、关系压力 | 前景虚化挡一部分空间，不挡脸 | 前景遮住关键表情 |
| 过肩关系卡 | 对话、对峙、亲密关系 | 前景肩部虚化，焦点落在对方脸 | 站位互换 |
| 背景线索卡 | 悬疑、反转、纪实证据 | 背景线索轻清楚，主体仍主导 | 背景抢主戏 |
| 竖屏安全卡 | 短剧、口播、广告 | 主体偏中上，底部留字幕和货架区 | 头顶太空或字幕盖脸 |
| 记忆帧卡 | 封面、结尾、品牌帧 | 主体、颜色、道具和留白稳定 | 画面元素太碎 |

## 6. 类型专用视觉重心

### 6.1 短剧与对白

```text
脸是主战场，焦点不能漂。
```

拍法：

- 关键台词用近景或中近景，嘴部和眼神都要清楚。
- 反应镜头焦点落在听的人，不要永远拍说的人。
- 过肩镜头写清前景是谁、焦点是谁、两人站边不换。

### 6.2 创意广告和产品证明

```text
产品动作是主角，不是产品摆在那里。
```

拍法：

- 手和产品占画面主要区域，结果出现后保持同一构图。
- 背景只给使用场景，不抢包装和手部动作。
- Logo、包装字、价格和参数默认后期添加。

### 6.3 可爱治愈

```text
主体靠近，空间柔软，边缘干净。
```

拍法：

- 小主体不要拍太远，近景和特写更容易有亲近感。
- 留出圆润空间和柔和背景，不要杂乱细节压住主体。
- 可截图点要有稳定构图。

### 6.4 悬疑压迫

```text
焦点在人物，线索在边缘。
```

拍法：

- 前景可以形成窥视感，但不能挡住关键表情。
- 背景线索只露一个，不要全画面都是线索。
- 门缝、窗框、镜面要服务危险方向。

### 6.5 打斗和特效

```text
关键动作看完整，奇观出现后焦点稳定。
```

拍法：

- 打击点用中景或中近景，保留身体路径和接触点。
- 特效触发时焦点落在触发物、手部或身体姿态。
- 爆炸、粒子和光效不能遮住主体轮廓。

## 7. Seedance 2.0 可生成性规则

视觉重心对 Seedance 2.0 是高优先级字段。默认规则：

1. 每镜写清一个第一眼重心，不要让模型自己猜。
2. 焦点必须明确：焦点落在主角脸、嘴部、手部、产品、道具或危险方向。
3. 前景只能有一个功能，且不能挡住脸、嘴、手、产品和关键道具。
4. 背景层次要降级：虚化、轻动作、暗一点、远一点或只保留线索。
5. 复杂群像中一镜只保留一个主动作角色或主说话人。
6. 竖屏镜头要写清字幕安全区和主体位置。
7. 可读文字、屏幕字、Logo、价格和参数默认后期添加。

风险评级：

| 镜头 | 风险 | 处理 |
| --- | --- | --- |
| 近景脸部焦点稳定 | A | 可直接写入 |
| 手部产品证明同一构图 | A | 包装字后期加 |
| 过肩关系镜头 | B | 写清前景、焦点和站位 |
| 背景线索加人物表演 | B | 背景只保留一个线索 |
| 多人群像前后景复杂 | C | 拆成主镜头 + 反应镜头 |
| 大特效遮挡主体 | D | 降低特效密度或拆镜 |

## 11. 自检

输出前检查：

1. 本镜第一眼重心是否唯一？
2. 主体是否足够大，能看清本镜最重要的信息？
3. 景别选择是否有明确理由，而不是随机变化？
4. 焦点是否写清，不会漂到背景或路人？
5. 前景是否只服务一个功能，且不挡脸、嘴、手、产品和关键道具？
6. 背景是否降级为服务主戏的层次或线索？
7. 字幕、Logo、屏幕字和品牌字是否预留后期安全区？
8. Seedance 2.0 是否能在一镜内稳定完成这个构图？
