# AI超级导演平台发布与爆款包装库

## 1. 定位

平台发布与爆款包装库负责把一个已经成型的短片、短剧、AI视频或创意广告，转化成更容易被观众第一眼看见、第一秒看懂、第一轮愿意互动的发布方案。

它不承诺“必爆”，也不把平台算法写成玄学结论。它只做导演能够控制的部分：开头、封面、标题、简介、评论区、系列记忆点、平台适配和复盘回写。

如果用户还没有成型片子，只是说“爆款视频”“前三秒抓人”“留存”“完播”，先调用爆款视频钩子与留存节奏引擎，设计第一帧停留点、前三秒问题、信息债和中段升级；本库负责在内容结构成型后继续做标题、封面、简介、置顶评论和发布复盘。

核心目标：

1. 让观众在前三秒知道为什么要看。
2. 让封面成为全片最有识别度的一帧。
3. 让标题产生问题感、情绪感或行动感。
4. 让评论区有自然讨论点。
5. 让作品能被纳入系列，而不是一次性消耗。
6. 让发布后的数据和观众反馈反哺下一次创作。

## 2. 总公式

一条完整发布包装默认使用：

```text
发布包装 = 留存结构确认 + 前三秒钩子 + 封面强帧 + 标题问题感 + 简介补刀 + 评论触发 + 系列记忆 + 平台适配 + 复盘回写
```

每次输出发布方案时，至少给出：

- 3个标题方案。
- 2个封面帧方案。
- 1个前三秒强化建议。
- 1条简介。
- 1条置顶评论。
- 1个下一集或下一条延展方向。
- 1个复盘指标清单。

## 3. 平台适配

平台规则会持续变化，因此这里只固定导演层面的表达策略，不写未经验证的算法结论。

### 3.1 抖音 / 快手

适合：强钩子、强情绪、强反转、强动作、短时间高密度信息。

包装重点：

- 第一帧必须有异常、冲突、可爱动作、危险感或情绪悬念。
- 前三秒不要铺垫世界观，直接给结果、误会、危险、惊喜或一句刺耳台词。
- 标题尽量让观众想确认答案，例如“它真的听懂了吗？”“这个幼儿园今天又出事了”。
- 评论区适合引导站队、猜结局、选下一集角色。
- 结尾最好留下下一条的动作入口，而不是只写“未完待续”。

常用包装：

```text
第一秒异常画面
第二秒人物反应
第三秒抛出问题
中段给升级
结尾留下一条更大的问题
```

### 3.2 小红书

适合：情绪价值、生活场景、审美封面、可收藏经验、治愈和轻叙事。

包装重点：

- 封面要清楚、干净、有情绪，不要只追求混乱冲击。
- 标题可以偏“感受”和“场景”，例如“下班后看见这台留声机，我突然安静了”。
- 简介补充创作意图、角色关系、场景设定或使用价值。
- 适合把治愈、旧梦留声机、产品种草、审美短片做成系列。
- 评论引导可以问“你想把哪段回忆交给它？”“你小时候也见过这个物件吗？”

常用包装：

```text
封面先给情绪
标题给生活场景
简介给共鸣入口
评论区收集观众记忆
下一条从评论里长出来
```

### 3.3 B站

适合：世界观、制作过程、系列追更、技术拆解、长一点的剧情和幕后复盘。

包装重点：

- 标题可更明确地写出概念、设定或挑战。
- 封面要有角色、世界观符号、关键冲突或制作亮点。
- 可以把AI短片、特效测试、角色宇宙、旧梦留声机式情感项目做成“正片 + 幕后拆解”。
- 简介中可写清工具链、创作方法、分镜思路，但不要泄掉剧情核心。
- 评论区适合征集下一集设定、角色能力、道具功能、剧情走向。

常用包装：

```text
标题说明创作挑战
封面展示最强画面
正片给完整体验
简介补创作方法
评论区收下一集设定
```

### 3.4 商业投放 / 品牌发布

适合：创意广告、产品短片、品牌故事、招商展示、门店宣传。

包装重点：

- 标题先说痛点或结果，不要先说品牌自夸。
- 前三秒展示问题或戏剧化反差，再让产品介入。
- 封面要让产品、使用场景和结果同时可见。
- 简介补充品牌、卖点、活动、门店或行动入口。
- 评论区避免低级诱导，重点回答真实问题或引导咨询。

常用包装：

```text
痛点画面
产品动作
结果证明
记忆口号
行动入口
```

## 4. 前三秒钩子库

前三秒是导演对观众的第一句台词。它不能只是热闹，要让观众立刻产生一个问题。

### 4.1 视觉异常钩子

公式：

```text
正常场景 + 一个不该出现的东西 + 人物反应
```

示例：

- 幼儿园教室里，所有小朋友都戴着迷你导演帽，只有老师拿着场记板发愁。
- 老旧留声机自己转动，放出的不是音乐，而是一句几十年前的留言。
- 普通便利店的货架突然折成科幻走廊，主角却只想买一瓶水。

适合：AI短片、特效、搞笑、悬疑、创意广告。

### 4.2 台词冲突钩子

公式：

```text
第一句台词 = 误会 / 指控 / 反常识 / 情绪爆点
```

示例：

- “今天谁把月亮偷到午睡区了？”
- “这不是唱片，这是我妈妈没说完的话。”
- “你卖的不是咖啡，你卖的是我今晚能不能撑下去。”

适合：短剧、情感、旧梦留声机、广告。

### 4.3 可爱动作钩子

公式：

```text
小主体 + 大任务 + 笨拙失败 + 立刻补救
```

示例：

- 小朋友想把太阳贴纸贴到天空上，结果贴到老师额头。
- 小动物认真开会，却被自己的尾巴打断三次。
- 小机器人学会哄人，第一步却是把纸巾递给了台灯。

适合：绒耀幼儿园式可爱搞笑、萌系广告、治愈短片。

### 4.4 情感旧物钩子

公式：

```text
旧物 + 声音 / 光影 / 触感 + 被遗忘的关系
```

示例：

- 留声机针头落下，空房间里响起童年喊名字的声音。
- 旧相机拍出的不是现在，而是当年没来得及道歉的一秒。
- 一只磨旧的保温杯突然发出父亲年轻时的笑声。

适合：旧梦留声机式怀旧情感、公益、品牌故事、治愈短片。

### 4.5 产品痛点钩子

公式：

```text
观众熟悉的麻烦 + 被夸张到可视化 + 产品用动作解决
```

示例：

- 凌乱桌面像潮水一样淹没主角，产品一出现，所有物件自动排队。
- 外卖袋里的热气变成小云朵，暴露保温问题。
- 主角一开口讲需求，客服机器人已经把答案投到墙上。

适合：创意广告、产品种草、品牌短片。

## 5. 封面强帧

封面不是截图，是观众进入作品前看到的第一张分镜。

### 5.1 封面公式

```text
清楚主体 + 异常信息 + 情绪表情 + 关键道具 + 少字标题
```

封面必须回答：

1. 主体是谁？
2. 发生了什么不寻常的事？
3. 情绪是可爱、搞笑、心疼、紧张还是惊奇？
4. 观众为什么点进来？

### 5.2 类型封面

可爱搞笑：

- 主体表情要大，动作要清楚。
- 画面里保留一个荒唐细节。
- 少字标题偏口语，例如“今天又闯祸了”。

怀旧情感：

- 旧物必须占据视觉中心之一。
- 光线可以柔和，但主体不能被暗掉。
- 少字标题偏情绪，例如“它还记得我”。

特效动作：

- 封面要有能量、空间变化、危险位置或人物反应。
- 不只放炫光，要有明确人物和处境。
- 少字标题偏冲突，例如“他暂停了这一秒”。

创意广告：

- 产品、痛点、结果至少出现两个。
- 品牌标识不要压倒剧情，但必须可识别。
- 少字标题偏结果，例如“桌面终于活过来了”。

短剧：

- 人物关系要一眼看懂：谁压迫谁、谁隐藏秘密、谁情绪失控。
- 表情比大字更重要。
- 少字标题偏问题，例如“她为什么不认他？”

## 6. 标题库

标题不是解释剧情，而是制造观看理由。

### 6.1 问题型

适合悬念、情感、短剧。

- “这台留声机为什么只在雨天响？”
- “幼儿园今天到底谁当导演？”
- “他为什么把最后一杯咖啡留给陌生人？”

### 6.2 反差型

适合搞笑、可爱、广告。

- “全班最小的孩子，管住了全场”
- “一个玩具，把老板讲沉默了”
- “最会迟到的人，发明了最准时的闹钟”

### 6.3 情绪型

适合治愈、旧梦留声机、公益、品牌故事。

- “有些声音，隔了很多年才回来”
- “这不是旧物，是没说出口的想念”
- “我以为它坏了，直到它叫出我的名字”

### 6.4 系列型

适合持续IP、角色宇宙。

- “绒耀幼儿园第3次开会，又偏题了”
- “旧梦留声机：雨夜档案01”
- “小导演宇宙：今天拍月亮”

### 6.5 商业价值型

适合广告、种草、投放。

- “这个收纳动作，比说一百句卖点更清楚”
- “30秒看懂它为什么适合小店”
- “让客户愿意停下来的门店开场”

## 7. 简介与置顶评论

简介负责补充信息，置顶评论负责打开互动。

### 7.1 简介公式

```text
一句设定 + 一句情绪 / 卖点 + 一个下一步
```

示例：

- “绒耀幼儿园今天学拍电影，但第一个镜头就失控了。下一集让谁当导演？”
- “一台旧留声机，只播放人们没来得及说出口的话。你想让它播放哪段回忆？”
- “这个广告把产品卖点改成了一个动作：混乱自动归位。适合门店、产品种草和品牌短片。”

### 7.2 置顶评论公式

```text
站队 / 猜测 / 共鸣 / 选择下一集
```

示例：

- “你觉得今天最该被批评的是老师，还是那个认真拿反场记板的小朋友？”
- “如果这台留声机只能播一句话，你最想听见谁的声音？”
- “下一条想看治愈版、搞笑版，还是特效升级版？”

### 7.3 评论区原则

1. 不用虚假承诺诱导互动。
2. 不消费真实伤痛，不把观众隐私当素材。
3. 不把评论区当硬广复读机。
4. 观众给出好设定时，可以沉淀进系列IP库。
5. 高频评论要回写到下一次标题、封面和分镜设计。

## 9. A/B测试

A/B测试不是把作品方向摇来摇去，而是在核心创意不变的前提下测试包装。

优先测试：

1. 封面主体：人物表情 vs 关键道具。
2. 标题方向：问题型 vs 情绪型。
3. 前三秒：异常画面 vs 台词冲突。
4. 结尾：情绪余韵 vs 下一集悬念。
5. 简介：设定说明 vs 观众提问。

不建议频繁测试：

- 一次性改变过多变量。
- 为了追热点破坏角色设定。
- 把情绪片硬改成吵闹冲突。
- 把品牌广告包装成虚假剧情。

## 10. 热门项目转译方法

对最近爆火的AI项目、AI账号和AI短片玩法，只吸收方法，不复制表皮。

### 10.1 绒耀幼儿园式吸收

可吸收：

- 可爱群像。
- 小角色做大任务。
- 童真误会。
- 轻喜剧节奏。
- 可持续栏目感。

不可复制：

- 具体角色设定。
- 原账号的台词、画面、标识和人设。
- 完全相同的桥段。

转译公式：

```text
小角色群体 + 成人世界任务 + 认真执行失败 + 善意收场 + 下一条新任务
```

### 10.2 旧梦留声机式吸收

可吸收：

- 旧物承载情感。
- 声音唤醒记忆。
- 怀旧影像质感。
- 低声量情绪。
- 留白结尾。

不可复制：

- 原项目的具体世界观、叙事桥段和视觉标识。
- 未授权声音、肖像、照片和真实私人故事。
- 把真实悲伤包装成廉价煽情。

转译公式：

```text
旧物 + 被封存的声音 + 一个未完成关系 + 当下人物的选择 + 安静余韵
```

### 10.3 创意广告式吸收

可吸收：

- 把卖点变成动作。
- 把痛点夸张成画面。
- 把产品能力变成故事转折。
- 把品牌记忆变成最后一帧。

转译公式：

```text
真实痛点 + 夸张可视化 + 产品介入 + 前后对比 + 一帧记住品牌
```

## 11. 风险与伦理

发布包装越强，越要守住边界。

1. 不承诺未经验证的热度、收益和平台推荐结果。
2. 不冒用真人肖像、声音、账号名、品牌标识和作品设定。
3. 不复制热门账号的具体桥段，只学习结构和方法。
4. 不制造虚假社会事件、虚假救助、虚假灾难和虚假医疗效果。
5. 商业内容要保留真实卖点，避免夸大功效。
6. 情感内容要尊重真实伤痛，不把观众私密经历当廉价素材。
7. 面向儿童、老人、医疗、金融等敏感主题时，优先做保守表达。

## 12. 复盘回写

发布后的复盘要同时看数据和内容判断。

### 12.1 复盘指标

- 完播率：前三秒和中段节奏是否有效。
- 点赞率：情绪或爽点是否成立。
- 评论质量：观众是在复读、争论、共鸣，还是提供下一集素材。
- 收藏率：作品是否有方法、审美、情绪或实用价值。
- 转发率：是否有可传播的关系、笑点、泪点或奇观。
- 关注转化：角色、栏目或导演风格是否值得追更。
- 商业转化：咨询、点击、到店、购买或品牌记忆是否提升。

## 13. 导演自检

发布前问自己：

1. 第一帧能不能在静音状态下看懂？
2. 前三秒有没有产生明确问题？
3. 标题是在制造观看理由，还是只是在复述内容？
4. 封面是不是全片最强、最清楚、最有识别度的一帧之一？
5. 评论区有没有自然互动点？
6. 这个作品能否延展成系列？
7. 平台适配有没有破坏原片气质？
8. 是否避免了抄袭、冒用、夸大和消费伤痛？
9. 发布后要记录哪一个变量的效果？
10. 下一条作品能从这条作品的反馈里长出来吗？
