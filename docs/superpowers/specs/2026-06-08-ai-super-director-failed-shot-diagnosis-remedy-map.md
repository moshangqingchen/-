# AI超级导演失败镜头诊断表与返工改法映射

## 1. 定位

这份表用于 Seedance 2.0 或其他 AI 视频生成失败后的第一判断：看到失败症状后，先判根因，再决定本轮只改哪个变量。

它不替代生成后回放验片，也不替代返工迭代协议。它站在两者中间：

```text
回放验片：这条素材能不能用？
失败镜头诊断表：到底坏在哪一个变量？
返工迭代协议：第几轮应该怎么改？
```

一句话原则：

```text
失败后不要先重写提示词，先给镜头看病。
```

## 2. 触发信号

用户出现这些说法时，默认调用本表：

- “这镜失败了。”
- “跑偏了。”
- “不知道哪里坏了。”
- “怎么改下一版？”
- “角色漂了。”
- “动作乱。”
- “口型穿帮。”
- “空间乱了。”
- “风格变了。”
- “产品不像。”
- “特效没出来。”
- “镜头太飘。”
- “剪不起来。”
- “同一镜又失败了。”
- “下一轮只改什么？”

## 3. 诊断口径

```text
我会这样判断：
先别急着说模型不听话。失败镜头通常只有一个主病灶：角色、动作、空间、口型、产品、风格、运镜、特效、文字或剪辑出点。本轮只抓一个变量，其他全部锁住。
```

保留：

- 已经对的构图、风格、角色、道具或动作段落。
- 可剪救的前半段、停顿、反应或声音点。
- 用户真正要的镜头任务。

舍掉：

- 同一轮同时改风格、机位、动作、角色和台词。
- 把负面词越堆越长。
- 继续硬跑一个已经过载的镜头。
- 用“更自然、更电影、更高级”代替具体变量。

第一刀：

```text
先写失败症状，再选一个主变量。本轮只改这个变量。
```

## 4. 十五类失败镜头速查表

| 失败症状 | 第一判断 | 本轮只改 | 必须锁住 | 必须删掉 | 通过标准 |
| --- | --- | --- | --- | --- | --- |
| 角色漂移 | 角色锁定不够或参考职责混乱 | 角色锁定句 | 风格、场景、动作、机位 | 新发型、新服装、新年龄、新角色 | 脸、发型、服装、体态和标志道具稳定 |
| 服装/道具变了 | 连续性字段弱 | 服装道具连续性 | 角色、空间、动作 | 多余道具、临时装饰 | 同一件衣服和同一道具不变形、不消失 |
| 动作看不清 | 一镜动作过多或受力结果缺失 | 动作链 | 角色、空间、机位 | 额外动作、复杂运镜 | 起点、触发点、结果和反应能看懂 |
| 打斗方向乱 | 空间轴线和受力方向没锁 | 空间/轴线 | 角色、风格、动作任务 | 环绕、跨轴、多人混战 | 谁逼近谁、谁受力、退到哪里清楚 |
| 口型穿帮 | 台词过长、多人说话或嘴部不可见 | 台词与景别 | 角色、情绪、空间 | 长句、多人同时开口 | 一人一句短台词，嘴部可见，说前说后有停顿 |
| 群像融合 | 同框人数多且任务不清 | 主动作角色 | 中心物、站位、风格 | 多人同时说话、同时跑动 | 一镜只有一个主动作和最多一个主说话人 |
| 产品不像 | 产品标准帧或材质角度没锁 | 产品外观 | 手部动作、场景、风格 | 变形角度、额外配件 | 产品轮廓、颜色、材质和关键部位稳定 |
| 产品证明不清 | 痛点、产品、结果三点线不清 | 手部证明动作 | 产品外观、机位、结果区 | 多卖点、花哨转场 | 观众看见产品如何造成结果变化 |
| 风格漂移 | 每镜风格词不同或参考权重乱 | 统一风格锁定句 | 角色、动作、空间 | 新风格词、新滤镜、新时代感 | 本镜和前后镜的光线、色彩、质感一致 |
| 镜头太飘 | 运镜承担了太多情绪 | 运镜 | 动作、角色、空间 | 环绕、快速推拉、无目的摇移 | 主体始终清楚，镜头只有一个运动理由 |
| 特效没打中 | 特效没有现实触发点和人物反应 | 特效触发点 | 空间、角色、机位 | 大规模爆炸、多个能力同时出现 | 异常从固定方向出现，人物看见并反应 |
| 文字乱码 | 让模型生成可读中文、Logo或屏幕字 | 后期文字处理 | 画面主体、构图 | 生成内文字、品牌字、Logo | 画面只留干净安全区，文字后期添加 |
| 剪不起来 | 入点、出点和反应镜头缺失 | 剪辑出点 | 主动作、空间、声音 | 无意义空镜、悬浮结尾 | 这一镜有明确切点，下一镜能接动作/视线/声音 |
| 情绪不真 | 角色直接演情绪，没有防御动作 | 微动作/停顿 | 台词、空间、镜头任务 | 大哭、夸张表情、解释旁白 | 情绪通过手、眼神、停顿或收回动作露出来 |
| 主体没重点 | 第一眼重心和主体比例不清 | 构图重心 | 风格、动作、角色 | 抢戏背景、过多前景遮挡 | 观众第一眼知道该看谁或看什么 |

## 5. 诊断顺序

不要同时诊断所有问题。按这个顺序往下走，找到第一个会让镜头失败的主病灶：

1. 主任务是否看懂？
2. 主体是否稳定？
3. 动作因果是否清楚？
4. 空间方向是否稳定？
5. 口型或文字是否可控？
6. 风格是否和前后镜一致？
7. 入点和出点是否能剪？

判断规则：

```text
如果主任务都看不懂，先不修风格。
如果主体不稳定，先不修运镜。
如果动作因果不清，先不加特效。
如果剪不起来，先补出点和反应，不继续堆画面。
```

## 6. 单变量返工模板

```text
我会这样改：

失败症状：
【只写一个最影响成片的问题】

根因判断：
【角色锁定 / 动作链 / 空间轴线 / 口型 / 群像 / 产品 / 风格 / 运镜 / 特效 / 文字 / 剪辑出点】

保留：
【已经对的部分】

舍掉：
【本轮删掉的过载要求】

本轮只改：
【一个变量】

必须锁住：
【不允许变化的角色、服装、道具、空间、风格、机位】

重试提示词改法：
【只围绕这个变量改写】

通过标准：
1. 【可看见标准一】
2. 【可看见标准二】
3. 【可看见标准三】

如果仍失败：
【下一刀：拆镜 / 换机位 / 重做首帧 / 重做角色标准帧 / 后期兜底】
```

## 7. 病例示范

### 7.1 角色漂了，动作也乱

错误改法：

```text
再来一版，更电影感，角色更稳定，动作更自然，镜头更高级。
```

诊断：

```text
主病灶先按角色漂移处理。角色不稳时，动作再好也接不上。
```

第一刀：

```text
本轮只改角色锁定。锁同一张脸、同一发型、同一灰蓝外套、右手拿旧照片、站在同一客厅桌前。动作只保留“低头看照片”，先不升级运镜。
```

通过标准：

1. 人物脸、发型和外套不漂。
2. 右手旧照片不消失。
3. 没有新增人物和乱码文字。

### 7.2 打斗没重量

诊断：

```text
不是不够炸，是受力结果没拍出来。
```

第一刀：

```text
本轮只改动作链。A从走廊右侧逼近，B后退到门边，A的拳头打中墙面，墙面裂纹出现，B肩膀撞到门框后停半秒。固定机位，不环绕。
```

通过标准：

1. A从哪来、B退到哪里清楚。
2. 打击点和受力结果可见。
3. 镜头不靠乱晃制造力量。

### 7.3 产品动作没证明卖点

诊断：

```text
不是产品不够美，是痛点、产品和结果没有形成一条证明线。
```

第一刀：

```text
本轮只改手部证明动作。桌面左侧是污渍，产品在中央，右侧是擦净结果。手从画面下方进入，只做一次按压和擦拭，结果区留半秒给观众确认。
```

通过标准：

1. 产品外观稳定。
2. 手部动作单一清楚。
3. 结果变化在画面右侧可见。

### 7.4 口型穿帮

诊断：

```text
台词太长，而且镜头任务还要表演和运镜，口型风险过高。
```

第一刀：

```text
本轮只改台词与景别。改成单人中近景，只说“别签”，说前停半秒，说完立刻看向桌面合同。长信息改成下一镜画外声或后期字幕。
```

通过标准：

1. 只有一个主要说话人。
2. 台词 3-8 个汉字。
3. 嘴部清楚，说完有反应出点。

### 7.5 剪不起来

诊断：

```text
镜头不是画面不够好，是没有出点。
```

第一刀：

```text
本轮只改剪辑出点。动作结束后让人物手停在门把上半秒，声音留一声门锁轻响，下一镜从同一声响接到对方反应。
```

通过标准：

1. 本镜有动作停顿。
2. 有声音或视线可接下一镜。
3. 不以无意义空镜结束。

## 8. 什么时候必须拆镜

出现以下情况，别再做单变量小修：

1. 同一镜同时失败两个以上地基变量：角色完全变人且动作看不懂。
2. 口型连续两次失败，且还想保留长台词。
3. 群像连续融合，人数超过 4 个。
4. 打斗连续看不清受力结果。
5. 产品外观连续错误，影响客户识别。
6. 主记忆帧失败，无法用后期或裁切救。

拆镜判断句：

```text
这镜不是提示词不够细，是任务太贪。拆成低风险镜头：主动作、反应、证据、结果。
```

## 9. 与其他能力的衔接

默认顺序：

```text
生成后回放验片与剪辑救援
-> 失败镜头诊断表与返工改法映射
-> Seedance 2.0 返工迭代协议
-> 首帧/关键帧锁定器
-> 错误记忆与自动避坑案例库
```

分工：

- 回放验片决定素材能不能救。
- 本表决定失败主变量。
- 返工协议决定第一轮、第二轮还是第三轮。
- 首帧/关键帧锁定器处理地基不稳。
- 错误记忆库把复发问题写成长期门禁。

## 10. 最小合格线

一次失败镜头诊断至少要输出：

1. 失败症状。
2. 根因判断。
3. 保留什么。
4. 舍掉什么。
5. 本轮只改一个变量。
6. 必须锁住什么。
7. 通过标准。
8. 如果仍失败的下一刀。

少一项，就容易把返工变成“再试一次”，而不是导演判断。
