# AI超级导演覆盖镜头、剪辑保险与场景可剪性导演引擎

## 1. 定位

这套引擎用于解决“这一场戏拍得出来，但剪不起来”的问题。它不替代镜头优先级系统，也不替代镜头语言词典；它负责在一场戏里补齐必要的覆盖镜头，让主镜头失败时还有反应镜头、插入镜头、过肩镜头、手部镜头、建立镜头和保底出点能救剪辑。

默认公式：

```text
建立镜头 + 主镜头 + 正反打/过肩 + 反应镜头 + 插入镜头 + 手部/道具镜头 + 保底出点
```

一句导演判断：

```text
我会先给这场戏做覆盖。主镜头负责赢，覆盖镜头负责让它一定剪得起来。
```

## 2. 触发词

用户出现以下说法时，默认进入本引擎：

- 剪不起来。
- 这场戏怎么补镜头。
- 需要哪些保底镜头。
- 主镜头失败怎么办。
- 这场戏怎么拍全。
- 正反打怎么拆。
- 反应镜头要不要补。
- 插入镜头拍什么。
- 过肩怎么拍。
- 需要补拍什么。
- 分镜能不能剪成片。
- 口型容易穿帮怎么兜底。
- 动作不连贯怎么救。
- 客户提案要稳一点。
- Seedance 先生成哪些安全镜头。

## 3. 覆盖镜头不是堆镜头

覆盖镜头不是把同一个动作换十个角度拍一遍，而是给剪辑准备功能不同的“救命点”：

1. 建立镜头让空间清楚。
2. 主镜头让事件成立。
3. 正反打让对白和关系清楚。
4. 反应镜头让情绪落地。
5. 插入镜头让证据、道具和产品可见。
6. 手部镜头让动作可剪。
7. 保底出点让下一镜能接。

如果一场戏只有主镜头，Seedance 2.0 一旦口型、动作、同框或道具漂移，就没有剪辑退路。

## 4. 覆盖镜头字段

| 字段 | 作用 | 写法 |
| --- | --- | --- |
| 建立镜头 | 交代空间和人物关系 | 门、桌、窗、出口、中心物、人物站位 |
| 主镜头 | 承担本场最重要事件 | 冲突爆开、产品证明、第一次反应、关键选择 |
| 正反打 | 拆对白和关系压力 | A说一句、B反应一句，轴线不跳 |
| 过肩镜头 | 让观众站进关系 | 前景是谁、焦点是谁、谁压住谁 |
| 反应镜头 | 兜情绪和口型风险 | 眼神、手部、身体重心、停顿 |
| 插入镜头 | 兜证据、道具和产品 | 录音笔、杯盖、按钮、合同、旧物、包装动作 |
| 保底出点 | 兜剪辑衔接 | 转头、放下、门响、手收回、视线离开 |

## 5. 七张覆盖卡

### 5.1 建立镜头卡

用途：复杂空间、群像、打斗、短剧对峙、产品使用流程。

```text
先让观众知道人在哪里、出口在哪里、中心物在哪里。
```

Seedance写法：第三人称中景或全景，镜头稳定，人物只做轻动作，主要任务是固定空间关系，不急着演高潮。

### 5.2 主镜头卡

用途：本场最重要的一下。

```text
只承担一个关键动作或一个关键信息变化。
```

Seedance写法：本镜头职能是主镜头，必须稳住一个核心动作，不增加额外角色动作、长台词或复杂运镜。

### 5.3 正反打卡

用途：对白、逼问、谈判、告白、短剧冲突。

```text
一镜一个主要说话人，另一方只做轻反应。
```

拍法：先定关系轴线，A镜和B镜不跨轴；台词尽量 3-8 个汉字，最长不超过 12 个汉字；长信息交给画外声、字幕或反应镜头。

### 5.4 过肩压迫卡

用途：关系压力、误会、审问、反派压迫、亲密拉扯。

```text
前景肩膀让观众感觉被挡住，焦点落在被压的人脸上。
```

Seedance写法：写清前景是谁、焦点是谁、两人站位不互换；禁止肩膀挡住关键表情。

### 5.5 反应保险卡

用途：口型失败兜底、笑点、情绪、特效可信度、广告证明。

```text
事件发生后，不急着解释，先让人反应。
```

Seedance写法：近景或中近景，角色不说或只说短句，重点是眼神、手部、呼吸、身体重心变化。

### 5.6 插入证据卡

用途：道具、合同、手机、产品、旧物、按钮、证据。

```text
把关键信息从嘴里拿出来，放到物件上。
```

Seedance写法：只拍物件形态和动作，不要求可读文字；合同字、手机字、包装字、Logo 后期添加。

### 5.7 保底出点卡

用途：多镜头剪辑、Seedance 片段拼接、情绪留白、动作连续。

```text
每场戏至少留一个可剪出去的动作。
```

常用出点：手收回、杯子落桌、人物转头、门声响起、视线落到道具、背影停住、对方吸气、环境声进入。

## 6. 类型联动

| 类型 | 覆盖策略 |
| --- | --- |
| 短剧冲突 | 建立轴线 -> 过肩压迫 -> 正反打短句 -> 证据插入 -> 主角反应 |
| 情感治愈 | 旧物插入 -> 手部停顿 -> 反应近景 -> 留白出点 |
| 喜剧 | 规则镜头 -> 错误执行 -> 反应保险 -> 二次升级 -> 封口出点 |
| 打斗动作 | 空间建立 -> 关键动作 -> 受力反应 -> 道具/脚步插入 -> 结果出点 |
| 特效奇观 | 现实基准 -> 触发插入 -> 奇观主镜头 -> 人物反应 -> 环境结果 |
| 创意广告 | 痛点建立 -> 产品手部动作 -> 变化证据 -> 用户反应 -> 品牌记忆 |
| 群像 | 群像建立 -> 主说话人 -> 单人反应 -> 中心物插入 -> 群体轻反应 |
| 直播种草 | 主播短句 -> 手部证明 -> 产品插入 -> 评论/追问后期 -> 反应收口 |

## 7. Seedance 2.0 覆盖策略

Seedance 多镜头项目默认先生成三类安全镜头：

1. 建立镜头：空间和人物站位不乱。
2. 插入镜头：道具、产品、手部动作可控。
3. 反应镜头：口型和复杂动作失败时可替换。

再生成主镜头：

```text
本镜头职能：【建立/主镜头/正反打/过肩/反应/插入/保底出点】。
本镜只承担【一个主要动作或信息】，其他角色只做轻反应。
上一镜出点是【具体动作/声音】，本镜入点接【具体动作/视线/声音】。
本镜出点留【保底出点】，方便剪到下一镜。
不生成可读文字、合同字、手机字、屏幕字或Logo，预留干净字幕安全区。
```

## 9. 自检

输出前检查：

1. 是否有建立镜头交代空间和轴线。
2. 主镜头是否只承担一个核心事件。
3. 对白是否拆成一镜一个主要说话人。
4. 是否有反应镜头兜情绪和口型风险。
5. 是否有插入镜头兜道具、证据、产品或旧物。
6. 每场戏是否有一个保底出点。
7. 多镜头之间是否写清入点和出点。
8. 高风险主镜头失败后，是否有替代镜头能剪过去。
9. 可读文字、Logo、合同、手机和屏幕字是否规划为后期添加。
