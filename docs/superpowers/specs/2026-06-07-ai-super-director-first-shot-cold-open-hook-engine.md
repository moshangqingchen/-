# AI超级导演第一镜、冷开场与首帧停留导演引擎

## 1. 定位

这套引擎用于处理“第一镜怎么拍”“怎么开场”“前三秒先给什么”“第一帧不抓人”“开头太慢”“Seedance 第一条先跑哪一镜”等需求。它不是爆款承诺，也不替代爆款视频钩子与留存节奏引擎；它只解决导演开机前最具体的一刀：第一帧放什么，第一声从哪里来，第一动作做到哪里切。

默认公式：

```text
第一帧停留点 + 第一声 + 第一动作中点 + 第一反应 + 第一信息债 + 第一切点
```

## 2. 触发词

当用户出现以下表达，默认进入本引擎：

- 第一镜怎么拍、怎么开场、开头怎么拍、冷开场、第一帧、首帧、前三秒先给什么。
- 先拍哪一镜、Seedance先跑哪一镜、开场镜头稳不稳、第一条测试镜头。
- 开头太慢、第一帧不抓人、开场像解释背景、第一秒没东西。
- 给我一个抓人的开场、短剧第一集怎么开、广告第一镜怎么证明、可爱短片第一镜怎么可截图。
- 标题封面之前画面是什么、第一声怎么进、第一切点在哪。

如果用户强调平台留存、完播、标题封面和评论互动，本引擎之后再进入爆款视频钩子与留存节奏引擎；如果用户强调现场调度和人物站位，本引擎与类型现场调度卡库联动。

## 3. 导演判断

我会这样拍：第一镜不要负责交代全部背景，它只负责让观众停住，并且让下一镜必须发生。开场最怕“漂亮但没问题”。我会先找一个动作已经发生一半的瞬间，让观众一眼知道这里不正常，再给一个很短的反应或声音，把问题压到下一镜。

默认保留：

- 一个不用解释也能看懂的画面问题。
- 一个已经发生到一半的动作。
- 一个声音入口。
- 一个角色反应。
- 一个能切出去的信息债。

默认舍掉：

- 普通空镜。
- 开场解释世界观。
- 先放大段字幕、Logo、标题或口号。
- 主体太小、动作太慢、信息太满。
- 第一镜同时完成出场、解释、打斗、转场和反转。

## 4. 第一镜字段

| 字段 | 作用 |
| --- | --- |
| 第一帧停留点 | 无声状态下也能看懂的异常、冲突、结果、可爱动作或产品证据 |
| 第一声 | 门响、呼吸、杯盖、警报、脚步、笑声、物件轻响或画外一句短声 |
| 第一动作中点 | 动作已经开始，不从准备动作拍起 |
| 第一反应 | 人物眼神、停手、退半步、抬头、握紧、松开 |
| 第一信息债 | 观众想问的一个问题 |
| 第一切点 | 反应落下、动作卡住、声音断掉或问题出现时切出 |
| Seedance风险 | 第一镜是否一镜多动作、多角色、多口型、多特效或文字不可控 |

## 5. 七种冷开场卡

### 5.1 结果先给卡

先给结果，再让观众想知道原因。

```text
第一帧：结果已经摆在眼前。
第一声：一个不合时宜的轻响。
第一动作：角色伸手想确认结果。
切点：角色反应落下，切到原因镜头。
```

适合广告、短剧、特效、爽感短片和产品证明。

### 5.2 动作中点卡

从动作进行到一半的地方开，不拍准备。

```text
第一帧：手已经抓住门把、杯子已经倾斜、拳头已经停在半空。
第一声：衣料摩擦、喘息、撞击前的停顿。
切点：动作没完成，观众想看结果。
```

适合打斗、短剧、情感、国风和悬疑。

### 5.3 错位物件卡

正常空间里出现不该出现的物件。

```text
第一帧：熟悉场景 + 一个错位物件。
第一反应：角色看见它后停住。
切点：物件发出声音或被碰到。
```

适合特效、高概念、梦境、可爱搞笑和悬疑。

### 5.4 声音先行卡

先用声音把观众拉进来，再给画面答案。

```text
第一声：门外一句短促声音、远处警报、旧物响起、杯盖碰瓷。
第一帧：人物听见声音后的身体反应。
切点：声音再次出现或突然断掉。
```

适合纪实感、情感、悬疑、公益、国风和企业片。

### 5.5 关系压迫卡

第一帧直接给两个人的距离和压力。

```text
第一帧：两人站位不舒服，一个人退无可退。
第一动作：某个道具被放到两人之间。
切点：谁先看向谁，关系问题出现。
```

适合短剧、家庭群戏、办公室冲突、情感和谈判广告。

### 5.6 小主体大任务卡

小角色承担明显过大的任务。

```text
第一帧：小主体面对大任务。
第一动作：它认真执行一个不可能完成的小动作。
切点：动作失败或意外成功一半。
```

适合可爱治愈、软萌广告、儿童向、宠物感角色和轻喜剧。

### 5.7 产品正在证明卡

第一镜不介绍产品，直接拍产品正在解决问题。

```text
第一帧：问题正在发生。
第一动作：产品介入动作已经开始。
第一反应：人或环境立刻出现可见变化。
切点：变化只完成一半，下一镜继续证明。
```

适合创意广告、直播种草、企业服务、汽车车品、美妆护肤和家居产品。

## 6. Seedance 2.0 第一镜写法

每条第一镜提示词默认包含：

```text
第一镜冷开场：
第一帧停留点：
第一声：
第一动作中点：
第一反应：
第一信息债：
摄影机身体：
景别/机位/运镜：
切点：
禁止项：
```

Seedance 2.0 降难规则：

1. 第一镜控制在 4-6 秒。
2. 只让一个主体承担主动作。
3. 只给一个主要运镜。
4. 不在第一镜里生成可读中文、Logo、复杂屏幕字或长台词。
5. 多人冲突优先过肩、中近景或道具视角，不让所有人同时动。
6. 打斗和特效只拍动作中点或触发点，不在第一镜完成整套动作。

## 8. 自检

输出第一镜前检查：

1. 第一帧无声状态下能不能看懂？
2. 是否有一个具体问题，而不是只有漂亮画面？
3. 第一动作是否已经进行到中点？
4. 第一声是否参与叙事？
5. 第一切点是否逼出下一镜？
6. Seedance 2.0 是否只承担一个主要动作和一个主要运镜？
7. 是否避免开场字幕、Logo、世界观解释和多信息堆叠？
