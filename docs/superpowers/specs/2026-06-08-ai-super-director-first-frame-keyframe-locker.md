# AI超级导演首帧关键帧锁定器

## 1. 定位

这份能力用于把“第一帧”从一句漂亮描述变成可执行的关键帧资产。很多 Seedance 2.0 视频失败，不是创意错，而是首帧没有锁住：角色长相、服装、道具、空间方向、动作中点、光线、构图和字幕安全区都太松，后面镜头自然会漂。

首帧不是封面图，也不只是开场图。它是视频生成的地基。

一句话原则：

```text
首帧必须同时承担停留、锁定和生成边界。好看不够，必须能把下一秒托住。
```

## 2. 触发信号

当用户出现以下需求时，默认调用首帧关键帧锁定器：

1. “首帧、第一帧、关键帧、封面帧、先做关键帧”。
2. “Seedance 先跑哪一镜、第一镜稳不稳、角色漂、风格漂、动作乱”。
3. “图片转视频、参考图转视频、首帧图用于视频”。
4. “开头不抓人、封面记忆帧、第一秒没东西”。
5. “多镜头要统一、角色场景道具别变”。

如果用户上传图片，先进入上传图片参考解读与 Seedance 描述协议，再用本锁定器生成首帧字段。

## 3. 首帧锁定字段

每个首帧至少锁 10 个字段：

| 字段 | 必须回答 |
| --- | --- |
| 画幅 | 9:16、16:9、1:1 或其他明确比例 |
| 主体 | 谁或什么是第一眼中心 |
| 主体位置 | 画面左/中/右、前景/中景/背景 |
| 角色锁定 | 年龄感、发型、服装、配饰、姿态 |
| 场景锁定 | 地点、门窗桌椅、出口、空间方向 |
| 道具锁定 | 必须不变的道具和它的位置 |
| 动作中点 | 动作已经做到哪里，不从准备开始 |
| 光线与色彩 | 主光方向、冷暖、明暗关系 |
| 字幕安全区 | 哪里留干净区域，文字后期添加 |
| 禁止项 | 不生成可读中文、Logo、额外人物、错位道具 |

判断句：

```text
如果首帧说不清主体位置、动作中点和禁止项，这帧还不能拿去跑视频。
```

## 4. 七类首帧模板

### 4.1 可爱治愈首帧

```text
画幅：竖屏 9:16。
主体：小主体在画面下三分之一。
动作中点：它正在认真搬一个比自己大的物件，动作已经开始一半。
空间：背景干净，有柔软材质，不放过多角色。
光线：柔和侧光，色彩温暖但不糖果色铺满。
字幕安全区：上方或右侧留干净区域。
禁止项：不加可读文字、不加额外小动物、不让主体表情过度夸张。
```

### 4.2 短剧冲突首帧

```text
画幅：竖屏 9:16。
主体：主角被压在画面一侧，对手或道具形成压力。
动作中点：一支笔、合同、手机或门把已经被推到主角面前。
空间：会议桌、门、出口和人物站边清楚。
光线：现实办公光或压迫性侧光。
字幕安全区：顶部留干净区域，台词字幕后期添加。
禁止项：不让多人同时开口，不加大段屏幕文字。
```

### 4.3 产品广告首帧

```text
画幅：按投放默认竖屏 9:16。
主体：产品和问题同时可见，产品不只是摆设。
动作中点：手正在把产品介入问题，动作已经开始。
空间：桌面、手、产品、痛点物件关系清楚。
光线：产品材质可见，反光不过曝。
字幕安全区：一侧留品牌字和卖点后期区域。
禁止项：不直接生成 Logo、品牌字、屏幕中文。
```

### 4.4 打斗特效首帧

```text
画幅：竖屏或横屏按用途确定。
主体：两方位置、距离和压力方向清楚。
动作中点：第一下接触前或接触瞬间，身体重心可见。
空间：走廊、墙面、障碍物、出口明确。
光线：受力点和人物轮廓清楚。
字幕安全区：不在动作区域放文字。
禁止项：不加满屏爆炸、不快速环绕、不同时出现多人反应。
```

### 4.5 情感旧物首帧

```text
画幅：按短片用途确定。
主体：手和旧物是第一眼中心。
动作中点：手停在旧物旁边，碰或不碰的瞬间。
空间：房间方向、桌面、窗或门形成情绪边界。
光线：克制、真实光源、阴影保留。
字幕安全区：画面边缘留干净区域。
禁止项：不让人物大哭，不加煽情文字。
```

### 4.6 参考转译首帧

```text
画幅：按新项目用途确定。
主体：原创角色、原创道具、原创场景。
动作中点：继承参考的调度方法，但动作和道具全部替换。
空间：不得复刻参考作品的标志性构图。
光线：继承情绪温度，不继承可识别视觉外壳。
字幕安全区：后期添加文字。
禁止项：不出现原作品角色、Logo、标志动作、标志画面。
```

### 4.7 发布封面首帧

```text
画幅：按平台封面比例确定。
主体：一眼能复述的动作或反常结果。
动作中点：问题已经发生，但答案未完全揭开。
空间：背景信息少，主体清楚。
光线：主体和表情可读。
字幕安全区：预留标题区域，文字后期添加。
禁止项：不把标题直接交给生成模型。
```

## 5. 首帧与第一镜的区别

| 项目 | 首帧关键帧 | 第一镜 |
| --- | --- | --- |
| 任务 | 锁画面地基 | 让动作发生并切出去 |
| 核心 | 主体、空间、道具、动作中点、禁止项 | 第一声、反应、信息债、切点 |
| 输出 | 一张关键帧描述或图像生成要求 | 4-6 秒视频提示词 |
| 风险 | 角色漂、空间漂、文字乱码 | 动作乱、口型穿帮、剪辑接不上 |

默认顺序：

```text
首帧锁定 -> 第一镜动作 -> Seedance 提示词 -> 生成前预检
```

```text

```

## 7. 首帧失败与第一刀

| 失败症状 | 第一刀 |
| --- | --- |
| 角色漂 | 补角色锁定：发型、服装、配饰、姿态和道具 |
| 场景漂 | 补空间方向：门、窗、桌、出口、前后景 |
| 动作乱 | 把首帧改成动作中点，不从准备动作开始 |
| 主体不清 | 改主体位置和画面比例，删背景干扰 |
| 文字乱码 | 删除生成文字要求，只留安全区 |
| 参考太像 | 替换角色、道具、场景和标志构图 |
| 产品不突出 | 让产品和痛点同框，并写清手部动作 |
| 打斗看不清 | 拉开双方距离，保留一个接触点 |

## 8. 手机缩略图与标题安全区闸门

首帧如果会被当封面、标题图或发布首屏，必须额外通过手机缩略图检查。不是大图好看就够，缩小后也要一眼能懂。

缩略图四问：

```text
缩到手机封面大小后，第一眼还能看见谁/什么吗？
标题或品牌字放上去，会不会挡住脸、手、产品、接触点或动作中点？
平台裁切成 9:16、1:1 或横版预览时，主体会不会被切掉？
没有字幕解释时，观众能不能看出一个问题、动作或反常结果？
```

安全区规则：

| 项目 | 通过标准 | 不通过第一刀 |
| --- | --- | --- |
| 主体比例 | 主体或产品至少占画面可视重心，缩小后仍可辨认 | 放大主体，删背景干扰 |
| 动作中点 | 手、脸、产品、接触点或结果变化不被标题遮挡 | 把动作中点移到画面中部或侧上方 |
| 标题安全区 | 预留一块干净区域，标题后期添加 | 清理背景，避免在脸和产品上压字 |
| 裁切安全 | 9:16、1:1、16:9 预览都不切掉核心主体 | 主体不要贴边，关键物离边缘留空间 |
| 无字理解 | 不看标题也能知道发生了什么或有什么反常 | 把问题变成画面动作，不靠大字解释 |

输出时加一行：

```text
缩略图检查：
主体缩小后仍能看懂；标题区在【位置】；裁切时不能切掉【主体/手/产品/接触点】；不靠文字也能看出【问题/动作/反常结果】。
```

禁忌：

1. 不要把标题区放在人物脸、产品手部、打斗接触点和情绪眼神上。
2. 不要让主体贴边，平台裁切会直接毁掉首帧。
3. 不要用大段标题解释一个本该画面看懂的问题。
4. 不要让封面只剩漂亮空镜，必须有动作中点或反常状态。
5. 不要让 Seedance 直接生成标题、品牌字或可读中文，文字后期添加。

## 10. 自检闸门

输出首帧前检查：

1. 画幅是否明确？
2. 主体是否一眼能看见？
3. 角色是否能跨镜头继承？
4. 空间方向是否清楚？
5. 道具是否锁定位置？
6. 动作是否在中点？
7. 字幕和 Logo 是否后期添加？
8. 禁止项是否明确？
9. 下一秒动作是否只有一个主任务？
10. 如果会用于封面或发布首屏，缩略图、标题安全区和裁切安全是否过关？

## 11. 最小合格线

一次首帧锁定至少要输出：

1. 画幅。
2. 主体与位置。
3. 角色锁定。
4. 场景锁定。
5. 道具锁定。
6. 动作中点。
7. 字幕安全区。
8. 禁止项。
9. 下一秒动作。
10. 缩略图检查。

少一项，首帧就只是好看的描述，不是能托住视频的关键帧。
