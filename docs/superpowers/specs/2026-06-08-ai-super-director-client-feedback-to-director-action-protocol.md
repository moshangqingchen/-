# AI超级导演客户反馈翻译成导演动作协议

## 1. 定位

这份协议解决客户反馈难落地的问题。客户常说“不高级、不够卖、不年轻、不像我们、感觉弱、品牌感不够、用户看不懂、太像广告、预算感太重”。这些话不是最终修改方案，而是客户的担心。

AI超级导演要把客户语言翻译成导演动作：改哪一镜、补什么证明、删什么噪音、换什么第一帧、增加什么反应、保住什么品牌记忆。

一句话原则：

```text
客户说的是担心，导演改的是证据。
```

默认目标：

1. 不把客户反馈直接照字面执行。
2. 每条反馈都翻译成一个可拍、可剪、可生成的动作。
3. 保留客户真正要的商业结果，舍掉误导性的表面词。
4. 每轮只改一个主问题，避免越改越不像原片。

## 2. 什么时候必须启用

遇到以下信号，默认调用本协议：

1. 用户说“客户反馈、甲方说、客户觉得、客户不满意、客户不买单、提案被打回、客户要更高级/更年轻/更品牌/更卖货”。
2. 反馈是抽象评价，不是明确镜头修改。
3. 反馈同时包含商业、审美、用户理解和品牌口吻多个方向。
4. 客户要求“加点品牌感、加卖点、加年轻感、加情绪价值”，但没有说明具体怎么加。
5. 用户担心按客户原话改会变俗、变硬广、变空或变复杂。
6. 发布前需要把客户意见转成下一版可执行修改清单。

不必启用的情况：

1. 客户给了明确硬性信息，例如产品型号、价格、活动时间、法务禁用词。
2. 客户要求删除真实不可用素材或敏感内容。
3. 用户只要内部创意探索，不涉及客户验收。

## 3. 客户语言翻译表

| 客户原话 | 真正担心 | 不要误改成 | 导演动作 |
| --- | --- | --- | --- |
| 不够高级 | 品牌显得廉价、审美无取舍 | 加滤镜、慢动作、空镜 | 删无任务空镜，统一主审美，改光线和动作质感 |
| 不够品牌 | 观众记不住是谁 | 堆 Logo、喊口号 | 设计品牌记忆帧、产品入画动作和后期品牌字安全区 |
| 不够卖 | 卖点没有被看见 | 加促销文案 | 补痛点、产品动作、结果变化和人物确认 |
| 不够年轻 | 节奏、人物状态和语言不像目标人群 | 加潮流词、快剪乱切 | 改人物任务、生活场景、反应节奏和封面语气 |
| 不像我们 | 品牌气质错位 | 照搬品牌手册词 | 定品牌人格、禁用气质、第一帧行为和声音口吻 |
| 用户看不懂 | 信息释放顺序错 | 加解释旁白 | 重排信息债，补可见证据和反应镜 |
| 感觉弱 | 主场面不够有力 | 全片都加戏 | 押一场主场面，补冲突、证明或受力结果 |
| 太像广告 | 人物只在卖货 | 去掉所有产品 | 让产品在真实任务里介入，不让角色背卖点 |
| 太 AI | 语言模板、人物没有真实动作 | 加更多专业术语 | 改成现场导演判断和具体手眼身声 |
| 预算感太重 | 画面像廉价堆效果或场景空 | 加大场面 | 减少虚假奇观，改真实光源、近景证据和声音细节 |
| 不够有记忆点 | 看完复述不出 | 加金句 | 设计一个可截图动作、视觉母题或声音回声 |
| 产品露出不够 | 产品没有承担任务 | 硬塞特写 | 让产品在关键动作里改变结果 |
| 情绪价值不够 | 人物反应没有被看见 | 加煽情音乐 | 补停顿、收回动作、眼神和声音余波 |
| 太平 | 第一帧没有问题，中段没升级 | 加更多镜头 | 前置反常结果，补中段新阻碍 |
| 不够真实 | 场景、表演和口播像摆拍 | 改成晃动镜头 | 补环境生命点、防御动作和非满分反应 |

## 4. 翻译流程

默认按 6 步处理：

```text
客户原话
-> 客户真正担心
-> 不能照做的误区
-> 保留原方案有效部分
-> 一条导演动作
-> 下一版通过标准
```

关键判断：

1. 客户是在担心品牌，还是担心转化？
2. 客户是在担心观众看不懂，还是担心审美不对？
3. 这条反馈要改第一帧、主场面、产品证明、人物反应、声音，还是后期包装？
4. 哪个修改能最小动作解决最大担心？

## 5. 客户反馈去伪存真

客户反馈分四类，不能混在一起处理。

| 反馈类型 | 例子 | 处理方式 | 导演判断 |
| --- | --- | --- | --- |
| 硬性事实 | 产品型号错了、价格错了、活动日期错了、法务禁词 | 直接改 | 这是信息准确性，不争论审美 |
| 真实担心 | 不够卖、用户看不懂、不像我们、品牌记不住 | 翻译成导演动作 | 找证据、信息顺序、品牌人格或记忆帧 |
| 表面词 | 高级、年轻、炸、温暖、大气、国际化 | 不照词改，先定具体表现 | 把形容词转成动作、光线、节奏、声音 |
| 有害字面要求 | 多加 Logo、全程讲卖点、加大段解释、每镜都更炫、照参考再像一点 | 礼貌转译或拒绝照做 | 保护主目标、原创边界、生成稳定和观众体验 |

去伪存真的判断顺序：

```text
客户原话
-> 哪部分是必须改的事实
-> 哪部分是真担心
-> 哪部分只是表面形容
-> 哪部分照做会伤害作品
-> 给一个替代导演动作
```

### 5.1 有害字面要求的转译

| 客户字面要求 | 照做会怎样坏 | 转译后动作 |
| --- | --- | --- |
| “Logo 再大一点，多出现几次” | 变硬广，观众反感，画面不高级 | 做品牌记忆帧，Logo 后期一次干净出现 |
| “卖点都说出来” | 口播堆砌，产品证明变弱 | 选一个最不信卖点，拍动作证据 |
| “开头先介绍一下背景” | 前三秒变慢，留存掉 | 第一帧先给问题，背景放到后面偿还 |
| “参考那个片子再像一点” | IP/风格复刻风险，原创性弱 | 只继承情绪骨架和调度，替换角色、场景、母题 |
| “每个镜头都要高级/都要炸” | 主次消失，剪辑没有层级 | 只押一个主镜头，其他镜头做证明和反应 |
| “字幕写满一点，怕观众不懂” | 画面变解释页，Seedance 文字风险高 | 后期只加短字幕，关键理解落到动作和反应 |
| “人物情绪再夸张点” | 表演变假，像 AI 演情绪 | 改成防御动作、停顿和收回动作 |

回应客户时可以这样说：

```text
这条我不建议照字面加。
我理解您真正担心的是【担心点】。
如果直接【客户字面要求】，会伤到【观众理解 / 品牌质感 / 转化证明 / 生成稳定 / 原创边界】。
我会改成【替代导演动作】，这样既回应担心，也不破坏片子。
```

### 5.2 客户真担心账本

客户反馈不能只在内部翻译，还要能对客户解释。每条反馈先过这张账本，避免改法对了但沟通说不清：

| 字段 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 客户原话 | 原句是什么，尽量不改写 | 只写“不满意” |
| 表面词 | 高级、年轻、卖、品牌、真实、看不懂等字面词 | 把表面词当最终方案 |
| 真担心 | 客户怕损失什么：品牌廉价、转化弱、观众误解、记不住、像竞品、生成不稳 | 只猜审美偏好 |
| 误改禁区 | 不能照做成什么：加滤镜、堆Logo、堆卖点、加旁白、照参考复刻 | 没写禁区，越改越俗 |
| 证据动作 | 用哪一镜、哪个动作、哪个产品证据或哪个反应回应担心 | 只改口号和形容词 |
| 客户可接受回话 | 怎么向客户解释“我理解了，但不照字面改”的理由 | 内部懂，客户不买单 |
| 通过标准 | 客户、观众或团队怎么判断这刀有效 | “更高级一点” |

快速输出格式：

```text
客户真担心账本：
客户原话：[原句]
表面词：[客户用了哪个抽象词]
真担心：[客户真正怕什么失败]
误改禁区：[这轮绝不照字面改成什么]
证据动作：[改哪一镜/补什么证据/删什么噪音/换什么第一帧]
客户可接受回话：[给客户的解释话术]
通过标准：[客户能看见的 2-3 条结果]
```

客户回话句式：

```text
我理解您说的【表面词】，核心担心其实是【真担心】。
我不建议直接【误改禁区】，那样会伤到【品牌质感/转化证明/观众理解/原创边界】。
这版我会改【证据动作】，让【客户最关心的结果】在画面里被看见。
```

## 6. 常见客户场景修法

### 6.1 客户说“不够高级”

导演判断：

```text
这不是让画面更贵，而是让取舍更狠。
```

第一刀：

1. 删掉没有任务的漂亮空镜。
2. 统一一种主审美：克制、商业证明、粗粝真实、温柔治愈或科技冷静。
3. 让人物或产品动作更慢半拍，但不要拖节奏。
4. 用真实光源、材质证据和声音细节替代抽象高级词。

通过标准：

1. 第一帧不靠大字和滤镜撑气质。
2. 每个镜头都有动作任务。
3. 品牌质感来自行为、光线和材质，不来自形容词。

### 6.2 客户说“不够卖”

导演判断：

```text
这不是多喊卖点，而是让卖点在画面里发生。
```

第一刀：

1. 找出观众最不信的一点。
2. 把卖点改成手部任务或场景问题。
3. 拍产品介入前后变化。
4. 给一个人物短反应确认结果。

通过标准：

1. 关掉字幕也能看见产品解决了什么。
2. 产品特写不是摆拍，而是承担动作。
3. 结尾品牌记忆帧能复用成封面。

### 6.3 客户说“不够年轻”

导演判断：

```text
年轻感不是网络词，而是人物状态和节奏。
```

第一刀：

1. 把说教口吻改成场景里的即时反应。
2. 让人物先做事，再短句表达。
3. 删除长旁白和过满价值观。
4. 改封面第一帧，让问题更直接。

通过标准：

1. 台词像人当场说出来，不像品牌稿。
2. 节奏有反应停顿，不是乱快剪。
3. 场景和道具像目标人群真的会用。

### 6.4 客户说“不像我们”

导演判断：

```text
这是品牌人格错位，不是元素不够多。
```

第一刀：

1. 先写品牌人格三词和禁用三词。
2. 改第一帧行为，让品牌像这个品牌会做的事。
3. 声音口吻统一：冷静、温柔、锋利、可靠或松弛。
4. 删除与品牌气质冲突的转场、笑点、特效或台词。

通过标准：

1. 只看第一帧和第一声，就能感到品牌气质。
2. 没有为了潮流牺牲品牌一致性。
3. 产品、人物和场景都服务同一人格。

### 6.5 客户说“用户看不懂”

导演判断：

```text
不是补解释，而是重排信息。
```

第一刀：

1. 写清观众、主角、镜头分别知道什么。
2. 第一镜只给一个问题，不一次解释完。
3. 每两三镜还一小笔信息债。
4. 把重要信息落到动作、道具、反应或后期字幕。

通过标准：

1. 观众知道下一镜为什么要看。
2. 反转有提前半步的证据。
3. 卖点露出不早不晚，和动作结果绑定。

## 8. 多条客户反馈仲裁

客户经常一次说很多：

```text
不够高级，也不够卖，年轻人可能不爱看，品牌露出也弱。
```

不要四个方向一起改。按项目类型仲裁：

1. 产品广告先解决“不够卖”，再解决“不够高级”。
2. 品牌片先解决“不像我们/不够品牌”，再解决“不够年轻”。
3. 短剧广告先解决“用户看不懂/不追更”，再解决“品牌露出”。
4. 种草带货先解决“观众不信”，再解决“包装不够好”。
5. 客户提案先解决“客户会误读的点”，再解决审美加分项。

仲裁句：

```text
这几条反馈里，我先抓【主担心】。因为它决定客户是否相信这条片能完成任务。其他反馈先不动，等这一刀过线再改。
```

## 9. 与其他能力衔接

默认顺序：

```text
客户反馈翻译成导演动作协议
-> 模糊反馈解码器
-> 能力调用仲裁器
-> 创意广告产品证明 / 品牌片团队叙事 / 观众知情控制
-> 导演改稿手术
-> 交付前红队审查
-> 经验回写与错误记忆
```

分工：

1. 本协议负责把客户话翻译成导演动作。
2. 模糊反馈解码器负责病灶判断。
3. 能力调用仲裁器负责多反馈取舍。
4. 专项能力负责改具体镜头。
5. 改稿手术负责重排方案。
6. 红队审查负责交付前防翻车。
7. 经验回写负责沉淀客户常见误读。

## 10. 自检闸门

输出前检查：

1. 有没有复述客户原话？
2. 有没有写清客户真正担心？
3. 有没有指出不能照字面改的误区？
4. 有没有区分硬性事实、真实担心、表面词和有害字面要求？
5. 有没有保留原方案有效部分？
6. 第一刀是否只改一个主变量？
7. 导演动作是否具体到镜头、动作、反应、声音或后期？
8. 通过标准能不能被客户和创作者一起检查？
9. 有没有写客户真担心账本？
10. 有没有给出客户可接受回话，而不是只写内部改法？

## 11. 最小合格线

一次客户反馈翻译至少要输出：

1. 客户原话。
2. 真正担心。
3. 不要误改成什么。
4. 去伪存真判断。
5. 保留项。
6. 第一刀。
7. 导演动作。
8. 后期配合。
9. 通过标准。
10. 客户真担心账本。
11. 客户可接受回话。

少一项，就容易把客户意见改成更空、更硬、更像广告的方案。
