# AI超级导演多参考权重与继承边界协议

## 1. 定位

这份协议解决多张参考图、多段参考视频、多种风格要求同时出现时的冲突问题。用户可能同时给首帧图、角色图、场景图、风格图、排版图、产品图和客户参考。AI超级导演不能把所有参考平均继承，否则 Seedance 很容易一镜一个风格、角色漂移、文字乱码、IP风险和画面任务过载。

上传图片参考解读协议负责逐张看图；本协议负责给每张参考分权重、定边界、裁冲突。

一句话原则：

```text
参考不是一起叠加，而是分工继承。
```

默认目标：

1. 每张参考只承担自己的职责。
2. 高权重参考决定全局，低权重参考只给局部。
3. 可读文字、Logo、IP符号和品牌字默认后期添加或原创替换。
4. 冲突时有拍板规则，不让模型自己猜。
5. 每条 Seedance 提示词都写清继承和禁止继承。

## 2. 什么时候必须启用

遇到以下信号，默认调用本协议：

1. 用户上传两张及以上图片、参考图、首帧图、角色图、风格图或产品图。
2. 用户说“图一做首帧，图二做全局参考，图三参考风格/道具/排版”。
3. 不同参考之间风格、角色、场景、文字或品牌信息冲突。
4. 用户要求“都参考一下”，但没有说每张图的职责。
5. 参考里出现可读中文、Logo、品牌字、IP角色、真实人物或独特画面。
6. Seedance 已经因为参考图职责不清而角色漂、风格漂、文字乱码。

不必启用的情况：

1. 只有一张参考图，且职责明确。
2. 用户明确只要图片描述，不进入生成、分镜或视频方案。
3. 参考只是灵感，不进入具体视觉继承。

## 3. 参考权重等级

| 权重 | 作用 | 常见参考 | 能决定什么 | 不能决定什么 |
| --- | --- | --- | --- | --- |
| S级 | 全局锁定 | 角色设定图、风格圣经、客户指定主视觉 | 角色、风格、色彩、材质、气质 | 不直接生成文字和Logo |
| A级 | 关键帧锁定 | 首帧图、封面图、主场面关键帧 | 第一帧构图、主体位置、动作中点 | 不承担全片所有镜头 |
| B级 | 局部继承 | 场景图、道具图、产品图 | 空间、道具、产品外观、手部关系 | 不改变全局风格 |
| C级 | 气质参考 | Moodboard、账号参考、电影感参考 | 光线、镜头距离、情绪温度 | 不复制角色、画面和文案 |
| D级 | 后期参考 | 排版图、字幕图、Logo图 | 字幕区、标题位置、品牌露出策略 | 不交给视频模型硬生成 |

默认判断：

```text
角色连续性优先于漂亮风格。
首帧构图优先于背景细节。
产品证明优先于装饰氛围。
合规边界优先于参考相似度。
```

## 4. 参考职责分工表

| 参考类型 | 继承 | 不继承 |
| --- | --- | --- |
| 首帧图 | 构图、主体位置、第一眼停留点、动作中点、光线方向 | 全片所有动作、乱码文字、无法控制的小细节 |
| 角色图 | 发型、脸型、服装轮廓、配饰、体型、表情气质、动作习惯 | 可识别IP身份、原作品符号、复杂背景 |
| 风格图 | 色彩、光线、材质、镜头气质、画面密度 | 具体角色、具体文字、Logo和独有画面 |
| 场景图 | 空间布局、光源、前后景、环境身份、道具位置 | 角色设定、主审美方向 |
| 产品图 | 产品形状、材质、颜色、使用方式、手部关系 | 夸大功效、虚假文字、不可控品牌字 |
| 排版图 | 标题区域、字幕安全区、主体与文字关系 | 可读中文、品牌字、Logo硬生成 |
| 竞品参考 | 结构、证明链、镜头功能、节奏 | 品牌元素、文案、独特视觉符号 |
| 电影/特摄参考 | 情绪、调度、镜头身体、声音记忆、场面结构 | 角色、台词、Logo、标志动作和标志画面 |

## 5. 冲突裁决规则

### 5.1 角色和风格冲突

如果角色图和风格图冲突：

```text
角色图决定角色外观，风格图只决定光线、色彩和材质。
```

不要为了风格把角色换脸、换服装或换年龄。

### 5.2 首帧和全片风格冲突

如果首帧图很强，但全片风格另有参考：

```text
首帧图只负责第一帧构图和动作中点，全片风格由全局参考决定。
```

首帧不能强行承担每一镜的场景和动作。

### 5.3 产品图和审美参考冲突

如果产品图偏真实，审美参考偏风格化：

```text
产品外观和使用动作必须真实清楚，风格只作用于光线、背景和节奏。
```

不要为了美术风格改变产品形状、颜色和关键结构。

### 5.4 排版图和视频生成冲突

如果排版图有大量中文、Logo或标题：

```text
排版图只继承文字位置和留白关系，可读文字、Logo和品牌字后期添加。
```

Seedance 提示词只写干净安全区，不要求直接生成可读字。

### 5.5 参考作品和原创要求冲突

如果参考来自电影、特摄、账号或IP作品：

```text
只继承情绪、结构、调度、母题和观众感受，角色、台词、Logo、标志动作和标志画面全部原创替换。
```

## 6. 冲突优先级矩阵

多参考同时冲突时，不按“哪张图更好看”裁决，按项目任务裁决。

默认优先级：

```text
合规边界 > 产品真实性 > 角色连续性 > 主场面任务 > 首帧停留点 > 全片风格 > 局部道具 > 排版参考
```

| 冲突双方 | 谁优先 | 谁让位 | 处理动作 |
| --- | --- | --- | --- |
| 合规/IP边界 vs 任何参考 | 合规/IP边界 | 所有参考 | 只继承抽象骨架，替换角色、符号、文案和标志画面 |
| 产品图 vs 风格图 | 产品图 | 风格图 | 产品形状、颜色、关键结构不变，风格只改光线和背景 |
| 角色图 vs 风格图 | 角色图 | 风格图 | 角色脸型、服装、体态不变，风格只改色彩和材质 |
| 角色图 vs 首帧图 | 角色图 | 首帧图 | 首帧只继承构图和动作中点，不改角色身份 |
| 主场面任务 vs 漂亮构图 | 主场面任务 | 漂亮构图 | 先保证动作、证明或冲突看清，再保构图气质 |
| 首帧图 vs 全片风格 | 全片风格 | 首帧图 | 首帧负责第一帧，全片风格由风格圣经锁定 |
| 排版图 vs 视频生成 | 视频生成稳定 | 排版图 | 只继承安全区和留白，文字、Logo、品牌字后期添加 |
| 多张风格图互相冲突 | 主审美 | 副风格 | 只选一个主审美，副风格降为局部光线或材质 |

强制让位规则：

1. 任何会导致可读文字、Logo 或品牌字直接生成的参考，必须让位给后期处理。
2. 任何会改变产品外观、结构、颜色或使用动作的风格参考，必须让位给产品图。
3. 任何会让角色换脸、换年龄、换服装轮廓的风格参考，必须让位给角色图。
4. 任何会复刻 IP 角色、标志动作、标志画面或独特文案的参考，必须让位给原创替换。
5. 任何会让一镜承担三张以上参考任务的提示词，必须让位给本镜任务，只保本镜需要的参考。

输出时必须写一句拍板话：

```text
这组参考里，我先保【不可动项】，让【让位项】只承担【局部职责】。
```

## 7. 多参考继承卡

默认输出格式：

```text
我先给这些参考分权重：

参考权重表：
| 参考 | 职责 | 权重 | 继承什么 | 不继承什么 | 冲突时谁让位 |
| --- | --- | --- | --- | --- | --- |
| 图一 |  |  |  |  |  |
| 图二 |  |  |  |  |  |
| 图三 |  |  |  |  |  |

全局锁定：
角色锁定：
场景锁定：
风格锁定：
产品/道具锁定：
字幕与品牌字处理：

冲突裁决：
【如果图一和图二冲突，按什么规则处理】

不可动项：
【合规 / 产品真实性 / 角色连续性 / 主场面任务 / 首帧停留点】

让位项：
【哪张图或哪类参考只做局部参考】

Seedance 继承句：
【每条镜头提示词都要继承的统一句】

禁止继承：
【可读文字、Logo、IP元素、错误品牌、过复杂背景等】
```

## 8. Seedance 字段

每条 Seedance 2.0 镜头提示词增加：

```text
参考职责：
S级全局参考：
A级首帧/关键帧参考：
B级局部参考：
本镜继承：
本镜不继承：
冲突裁决：
文字与Logo处理：
角色一致性：
风格锁定句：
不可动项：
让位项：
```

示例：

```text
参考职责：图一为首帧构图，图二为角色设定，图三为风格参考。
本镜继承：图二角色外观和服装，图三柔和暖光和低饱和色彩，图一只继承主体在画面左侧的构图关系。
本镜不继承：图一中的中文标题、图三中的具体品牌Logo、任何可识别IP符号。
冲突裁决：角色外观以图二为准，风格以图三为准，首帧构图只在第一镜生效。
文字与Logo处理：字幕、标题和品牌字后期添加，画面下方预留干净安全区。
```

| 项目类型 | 权重优先级 |
| --- | --- |
| 可爱治愈 | 角色图 > 首帧图 > 风格图 > 排版图 |
| 竖屏短剧 | 角色图 > 场景图 > 首帧图 > 风格图 |
| 创意广告 | 产品图 > 产品使用图 > 首帧图 > 风格图 > 排版图 |
| 打斗特效 | 空间图 > 角色图 > 动作关键帧 > 风格图 |
| 情感短片 | 旧物/道具图 > 角色图 > 光线风格图 > 首帧图 |
| 企业品牌片 | 品牌主视觉 > 产品/服务证据图 > 场景图 > 风格图 |
| 文旅旅行 | 地点真实图 > 路线/场景图 > 人物图 > 风格图 |

## 10. 常见错误与第一刀

| 错误 | 症状 | 第一刀 |
| --- | --- | --- |
| 全部参考平均继承 | 风格杂、角色漂 | 选一个 S级全局参考，其余降为局部 |
| 首帧图承担全片 | 后面镜头动作受限或跑偏 | 首帧只管第一镜构图和动作中点 |
| 风格图改了角色 | 角色换脸、换衣服 | 角色外观以角色图为准 |
| 排版图硬生成文字 | 中文乱码、Logo错误 | 文字后期添加，只留安全区 |
| 产品被风格化变形 | 卖点看不清 | 产品外观和动作以产品图为准 |
| 参考IP太像 | 合规风险 | 三次原创替换，删标志动作和符号 |
| 参考太多 | 提示词过载 | 每镜只写本镜需要继承的参考 |
| 没写不可动项 | 每张图都想保，模型自己乱猜 | 先写不可动项和让位项，再写提示词 |

## 11. 与其他能力衔接

默认顺序：

```text
上传图片参考解读与 Seedance 描述协议
-> 多参考权重与继承边界协议
-> 风格参考、Moodboard 与镜头风格圣经系统
-> 首帧关键帧锁定器
-> 跨镜头场记、角色道具连续性与空间一致性
-> Seedance 镜头可生成性评分
```

分工：

1. 上传图片协议负责逐张看懂参考。
2. 本协议负责权重、边界和冲突裁决。
3. 风格圣经负责把可继承内容写成全片规则。
4. 首帧锁定器负责第一帧和关键帧。
5. 场记连续性负责跨镜头角色、道具和空间。
6. 可生成性评分负责判断是否需要拆镜或降难。

## 12. 自检闸门

输出前检查：

1. 是否给每张参考写了职责？
2. 是否给每张参考定了权重？
3. 是否写清继承什么和不继承什么？
4. 是否有冲突裁决？
5. 是否把文字、Logo和品牌字规划为后期添加？
6. 是否避免可识别IP、真实人物和独有画面复刻？
7. 是否把继承规则写进 Seedance 字段？
8. 是否避免每条镜头提示词都塞全部参考？
9. 是否写清不可动项和让位项？

## 13. 最小合格线

一次多参考处理至少要输出：

1. 参考权重表。
2. 全局锁定。
3. 角色/场景/风格/产品或道具锁定。
4. 冲突裁决。
5. Seedance 继承句。
6. 禁止继承项。
7. 文字和 Logo 后期处理规则。
8. 不可动项和让位项。

少一项，就不是多参考管理，只是把所有参考丢给模型猜。
