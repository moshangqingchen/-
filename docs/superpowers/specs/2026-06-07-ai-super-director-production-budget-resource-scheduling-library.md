# AI超级导演制片规划、预算与资源管理库

## 1. 定位

制片规划、预算与资源管理库负责把创意、剧本、分镜和AI生成方案转成可排产、可控成本、可执行的项目计划。

导演不能只会想画面，还要知道：

1. 需要哪些角色、场景、道具、声音和视觉资产。
2. 哪些镜头最花时间、最容易失败、最该优先测试。
3. 哪些内容可以压缩，哪些不能省。
4. 真人拍摄、AI生成、混合制作分别如何排期。
5. 如何给返工和审核留缓冲。

核心原则：

```text
先锁关键资产，再排镜头批次；先测最难镜头，再铺全片生产。
```

## 2. 制片总公式

```text
制片计划 = brief + 交付包 + 镜头表 + 资产表 + 预算档位 + 排期 + 风险缓冲 + 质量门禁
```

每个项目至少要明确：

- 目标成片。
- 片长和画幅。
- 交付包类型。
- 角色数量。
- 场景数量。
- 关键道具。
- 镜头数量。
- 声音需求。
- 发布素材。
- 最难镜头。
- 返工缓冲。

## 3. 预算档位

这里不写固定市场报价，而按资源复杂度分档。

### 3.1 极简档

适合：

- 15秒到30秒短视频。
- 单角色或无角色。
- 1个主场景。
- 1个核心道具。
- AI生成或轻量剪辑。

特征：

- 镜头少。
- 场景统一。
- 声音简洁。
- 发布包装简单。

适合类型：

- 产品种草。
- 可爱小短片。
- 治愈片段。
- 单一特效测试。

### 3.2 标准档

适合：

- 30秒到60秒短片。
- 1到3个角色。
- 1到2个场景。
- 有分镜表、关键帧、声音和发布包装。

特征：

- 有完整情绪曲线。
- 有3到8个关键镜头。
- 有AI生成或拍摄资产管理。
- 有标题、封面和复盘计划。

适合类型：

- 创意广告。
- 怀旧情感短片。
- 可爱搞笑群像小集。
- 特效短剧开头。

### 3.3 进阶档

适合：

- 1到3分钟短片。
- 多角色。
- 多场景。
- 特效、打斗、复杂声音、系列化设定。

特征：

- 需要角色圣经。
- 需要场景圣经。
- 需要镜头资产表。
- 需要分批生成或分段拍摄。
- 需要剪辑节奏和声音设计。

适合类型：

- 短剧单集。
- 系列IP试播。
- 动作打斗。
- 情感公益短片。
- 品牌故事。

### 3.4 项目档

适合：

- 系列账号。
- 多集短剧。
- 品牌整套内容。
- 需要客户提案、排期、版本管理和复盘。

特征：

- 需要栏目结构。
- 需要角色宇宙。
- 需要多条发布包装。
- 需要复盘写回。
- 需要资产复用规则。

适合类型：

- 系列IP。
- 长期广告栏目。
- AI短片账号。
- 品牌季度内容计划。

## 4. 成本驱动项

项目变贵或变慢，通常不是因为“创意大”，而是以下因素失控：

| 成本项 | 为什么增加成本 | 压缩方法 |
| --- | --- | --- |
| 角色数量 | 角色一致性、表演和生成难度增加 | 合并角色功能，减少群像同框 |
| 场景数量 | 美术、调度、连续性增加 | 把故事压进一个核心空间 |
| 复杂动作 | 拍摄和AI生成都容易失败 | 拆成关键动作点和反应镜头 |
| 特效规则 | 需要测试和返工 | 先做最难镜头测试 |
| 打斗 | 空间、动作、安全、剪辑要求高 | 明确三段攻防，不追求过多招式 |
| 情绪戏 | 表演、声音和节奏要求高 | 用物件和动作承载情绪 |
| 产品展示 | 卖点和画面都要清楚 | 用一个动作展示一个卖点 |
| 多平台版本 | 标题、画幅、封面和节奏不同 | 先做主版本，再改包装 |
| AI一致性 | 角色、服装、道具易漂移 | 建立角色/场景圣经 |

## 6. 镜头难度分级

### 6.1 A级镜头

简单镜头：

- 静态人物。
- 道具特写。
- 空镜。
- 简单推拉摇移。
- 单一动作。

处理方式：

- 放在批量生产阶段。
- 作为剪辑缓冲镜头。

### 6.2 B级镜头

中等镜头：

- 人物和道具互动。
- 简单群像。
- 情绪表演。
- 产品动作展示。
- 场景轻微变化。

处理方式：

- 先做提示词或分镜测试。
- 确认风格后批量生成或拍摄。

### 6.3 C级镜头

高难镜头：

- 打斗。
- 复杂群像。
- 大幅特效变化。
- 快速动作连续性。
- 角色近脸情绪稳定。
- 同一角色跨镜头一致。

处理方式：

- 开工第一批先测试。
- 失败时拆成多个简单镜头。
- 为剪辑准备替代镜头。

## 7. AI生成批次规划

AI视频或图像项目不应按成片顺序生成，而应按风险顺序生成。

推荐顺序：

```text
1. 角色关键视觉
2. 场景关键视觉
3. 最难镜头测试
4. 最强一帧
5. 普通叙事镜头
6. 反应镜头和补剪镜头
7. 封面和发布图
```

批次模板：

```text
批次号：
目标：
包含镜头：
使用角色圣经：
使用场景圣经：
统一风格：
成功标准：
失败风险：
返工规则：
是否进入下一批：
```

AI生成返工优先级：

1. 角色脸和身份不一致。
2. 关键道具消失或变形。
3. 动作逻辑错。
4. 情绪不对。
5. 光线和色彩偏离。
6. 背景文字乱码。
7. 细节小瑕疵。

## 8. 真人拍摄排期

真人拍摄优先按场景和光线排，不按剧情顺序排。

排期原则：

1. 同一场景集中拍。
2. 同一光线条件集中拍。
3. 演员情绪高强度段落留出准备时间。
4. 打斗和复杂动作预留排练。
5. 产品特写单独留时间。
6. 收尾拍补镜和备用封面帧。

拍摄日模板：

```text
日期：
场景：
角色：
道具：
镜头范围：
重点镜头：
光线要求：
声音要求：
风险镜头：
备用镜头：
收工检查：
```

## 9. 混合制作排期

混合制作指真人素材 + AI生成 + 后期合成。

默认顺序：

```text
1. 真人部分锁定表演和产品动作
2. AI部分生成奇观、背景、补充镜头
3. 合成测试关键帧
4. 声音和剪辑统一节奏
5. 输出主版本
6. 输出平台包装版本
```

混合制作最容易失败：

- 真人光线和AI光线不一致。
- 透视不一致。
- 人物边缘不自然。
- 产品形状变化。
- 声音空间不统一。

解决方式：

- 拍摄时保留干净背景和参考光线。
- AI提示词写清镜头高度、焦段感和光源方向。
- 产品和人物关键帧先锁定。
- 合成前先做5秒测试。

## 10. 时间计划模板

### 10.1 极简项目

```text
阶段1：brief和创意
阶段2：分镜和关键帧
阶段3：生成/拍摄
阶段4：剪辑和声音
阶段5：发布包装
阶段6：复盘
```

### 10.2 标准项目

```text
第1段：brief、创意、脚本
第2段：分镜、角色/场景圣经
第3段：最难镜头测试
第4段：批量生成/拍摄
第5段：剪辑、声音、调色
第6段：封面标题和平台版本
第7段：复盘写回
```

### 10.3 系列项目

```text
阶段1：IP设定和三集测试
阶段2：角色、场景、道具统一资产
阶段3：前三集分镜
阶段4：批量生成/拍摄
阶段5：发布节奏和评论反馈
阶段6：复盘并调整栏目公式
阶段7：下一批选题
```

## 11. 成本压缩策略

### 11.1 压场景

把多个场景压成一个空间里的不同区域。

示例：

- 不拍整座城市，只拍一扇亮着灯的窗。
- 不拍完整幼儿园，只拍午睡区、黑板和门口。
- 不拍整场战斗，只拍门口三步范围。

### 11.2 压角色

合并功能相似角色。

示例：

- 解说者和反应者合成一个旁观角色。
- 三个路人缩成一个代表性路人。
- 群像同框改成轮流特写。

### 11.3 压动作

把复杂连续动作拆成关键动作点。

示例：

- 打斗连续招式改成“建立空间 -> 关键打击 -> 反应 -> 结果”。
- 特效变化改成“现实基准 -> 异常出现 -> 人物反应 -> 奇观一帧”。

### 11.4 压说明

用画面和声音减少台词解释。

示例：

- 产品保温不靠口播，用杯子仍冒热气证明。
- 亲情想念不靠长旁白，用旧物和声音留言承载。

## 12. 不该省的地方

可以省场景、角色和镜头数量，但不要省：

1. 前三秒钩子。
2. 最强一帧。
3. 角色/场景一致性。
4. 产品卖点证明镜头。
5. 情感片的关键声音。
6. 打斗片的空间交代。
7. 特效片的现实基准。
8. 发布封面和标题。
9. 返工缓冲。

## 13. 制片风险表

```text

```

常见风险：

- 角色不一致。
- 场景变化太多。
- 关键镜头生成失败。
- 动作不清楚。
- 产品露出不稳定。
- 声音和画面情绪不一致。
- 平台封面不够强。
- 客户反馈改变方向。
- 真实人物或品牌授权不清。

## 15. 制片自检

输出制片计划前问自己：

1. 是否知道最终交付物是什么？
2. 是否识别预算档位？
3. 是否列出角色、场景、道具和声音？
4. 是否标出最难镜头？
5. 是否先测试高风险镜头？
6. 是否有返工缓冲？
7. 是否有低成本替代方案？
8. 是否保护了最强一帧和前三秒？
9. 是否避免为了省成本毁掉核心创意？
10. 是否能直接进入制作？
