# AI超级导演 Seedance 2.0 返工迭代协议

## 1. 定位

这份协议处理 Seedance 2.0 生成后“不够对”的情况：不是彻底坏掉，也不是完全可用，而是角色漂了一点、动作不够清楚、口型有风险、镜头太飘、情绪不到、产品证明不够、特效没打中、群像有点乱。

它和其他修复库的分工：

- 可生成性库：生成前判断能不能一条跑。
- 试拍预检库：正式生成前先测哪一镜。
- AI生成修复库：生成坏了以后诊断具体故障。
- 本协议：生成结果不理想时，按第几轮返工决定怎么改，避免无限重试。

一句话原则：

```text
返工不是把提示词越写越长，而是每一轮只改最该改的一个变量。
```

## 2. 触发词

用户出现以下说法时，默认进入本协议：

- 再跑一版
- 重试
- 返工
- 迭代
- 这一版不够好
- 生成不理想
- Seedance 跑偏了
- 这个镜头没出来
- 角色漂了
- 动作不清楚
- 口型有点穿帮
- 镜头太乱
- 要不要拆镜
- 要不要重做首帧
- 第一次失败
- 第二次失败
- 连续失败
- 怎么改下一版
- 提示词怎么改一轮
- 生成后怎么审

## 3. 导演返工口径

默认先这样说：

```text
我会这样改：
先别急着全盘重写。这一轮只抓最影响成片的一件事。第一次重试改提示词变量，第二次还不稳就拆镜，第三次还不稳就重做首帧或关键帧，别把预算耗在同一个坏结构上。
```

导演第一刀：

- 不同时改风格、动作、台词、运镜、构图和特效。
- 不把失败镜头越写越复杂。
- 不让高风险口型继续硬跑。
- 不让多人物同框继续多人同时动。
- 不让主镜头连续失败还继续原样重试。

## 4. 三轮返工节奏

### 4.1 第一轮：单变量重试

适合：

- 核心构图对了，但动作不准。
- 角色大体一致，但细节漂。
- 情绪方向对，但表演太满或太平。
- 运镜有点过，但画面能用。
- 产品或道具出现了，但动作关系不够清楚。

规则：

```text
只改一个变量，其他全部锁住。
```

第一轮不是重新生成一个“更好版本”，而是继承上一版已经成立的部分，只补最坏的那个变量。进入重试提示词前，先写救片变量冻结单：

```text
上一版可继承：
已经成立：
本轮只改：
绝对不改：
删掉：
新增提示词只服务：
通过标准：
失败后第二刀：
```

如果新版本把上一版已经成立的角色、产品、构图、风格、空间方向、可用段或出点改坏，即使本轮变量变好，也不能算通过。先回滚可用段，再决定补桥镜、换机位或拆镜。

常见单变量：

| 问题 | 第一轮只改什么 |
| --- | --- |
| 动作不清楚 | 改动作链，减少动作数量 |
| 镜头太飘 | 改运镜，固定机位或轻推 |
| 角色漂移 | 加角色锁定句 |
| 口型不稳 | 缩短台词，改近景或后期配音兜底 |
| 群像乱 | 固定站位，只保留一个主动作角色 |
| 特效太乱 | 降低特效规模，从小异常开始 |
| 产品不清楚 | 改产品位置和手部动作 |
| 情绪不准 | 改微动作和停顿 |

第一轮输出：

```text
第一轮返工目标：
上一版可继承：
只改变量：
必须锁住：
删掉：
重试提示词：
通过标准：
失败后第二刀：
```

### 4.2 第二轮：拆镜或换机位

适合：

- 第一轮重试后，核心问题仍存在。
- 动作因果还是不清楚。
- 口型、手部、道具、多人同框持续不稳。
- 镜头目标本身太贪。

规则：

```text
第二轮不继续堆提示词，改结构。
```

处理方式：

- 动作失败：拆成起点、接触、结果、反应。
- 口型失败：拆成短句近景、反应镜头、画外声或后期配音。
- 群像失败：拆成群像建立、单人动作、双人反应、群像收尾。
- 特效失败：拆成现实基准、小异常、人物反应、特效升级、结果。
- 产品失败：拆成痛点、产品动作、过程细节、结果对比、品牌记忆帧。

第二轮输出：

```text
第二轮判断：
原镜头为什么继续失败：
结构问题：
拆镜方案：
镜头1：
镜头2：
镜头3：
衔接方式：
每镜 Seedance 2.0 提示词要点：
```

### 4.3 第三轮：重做首帧、关键帧或替换方案

适合：

- 同一关键镜头连续两轮仍不稳定。
- 角色、场景或产品核心形象无法锁住。
- 主镜头失败会影响整条片。
- 参考图职责不清，Seedance 不知道继承什么。
- 原镜头设计已经超出模型稳定范围。

规则：

```text
第三轮不再修同一条坏镜头，回到关键帧或导演方案。
```

处理方式：

1. 重做首帧：重新定义第一眼停留点、主体位置、光线、构图。
2. 重做角色标准帧：锁脸、服装、比例、材质、标志动作。
3. 重做产品标准帧：锁外观、角度、材质、使用方式。
4. 重做场景标准帧：锁空间方向、门窗、桌子、道具位置。
5. 替换镜头功能：把高风险动作镜头改成反应镜头、道具镜头或后期合成。

第三轮输出：

```text
第三轮判断：
不再继续原样重试的原因：
需要重做的资产：
首帧/关键帧描述：
替代镜头方案：
新生成顺序：
保留旧版哪些素材：
废弃旧版哪些素材：
```

## 5. 返工决策树

```text
生成结果不理想
-> 核心信息是否看懂？
   -> 看不懂：先拆镜或重做，不做小修。
   -> 看得懂：继续判断。
-> 角色、产品或道具是否错到影响识别？
   -> 是：重做标准帧或关键帧。
   -> 否：继续判断。
-> 是否只是动作、运镜、表情、口型中的一个变量不稳？
   -> 是：第一轮单变量重试。
   -> 否：继续判断。
-> 是否已经同一问题失败两次？
   -> 是：第二轮拆镜或换机位。
   -> 否：第一轮重试。
-> 是否同一关键镜头连续失败三次？
   -> 是：停止硬跑，第三轮重做首帧/关键帧/替代方案。
```

## 6. 不同失败类型的返工刀法

### 6.1 角色漂移

第一轮：

- 加角色锁定句。
- 固定发型、服装、主色、标志道具。
- 减少景别变化。

第二轮：

- 先生成角色标准帧。
- 把动作镜头拆成角色近景和动作局部。

第三轮：

- 重做角色设定图或全局参考图。
- 所有镜头继承同一角色圣经。

### 6.2 动作不清楚

第一轮：

- 把动作改成起点 -> 接触 -> 结果。
- 删除额外动作。
- 固定或轻推镜头。

第二轮：

- 拆成动作镜头、反应镜头、结果镜头。

第三轮：

- 改成更低风险表达：道具特写、声音桥、反应镜头或后期剪辑。

### 6.3 口型不自然

第一轮：

- 台词缩到 3-8 个汉字，最长不超过 12 个汉字。
- 近景或中近景，嘴部清楚。
- 说前停半秒，说后停半秒。

第二轮：

- 拆成正反打、反应镜头、画外声、字幕或后期配音。

第三轮：

- 取消画内口型，只保留表演和后期配音。

### 6.4 群像融合

第一轮：

- 固定站位。
- 同一镜只让一个主动作角色。
- 其他角色只做轻反应。

第二轮：

- 拆成群像建立、单人动作、双人反应、群像收尾。

第三轮：

- 减少同框人数，改成小组镜头或表情包定格。

### 6.5 特效太乱

第一轮：

- 降低特效规模。
- 从小异常开始。
- 固定触发点。

第二轮：

- 拆成现实基准、小异常、人物反应、特效升级、结果。

第三轮：

- 生成关键帧或改后期特效，不让 Seedance 单独承担所有奇观。

### 6.6 产品证明不清楚

第一轮：

- 固定产品位置。
- 明确手部动作。
- 只证明一个卖点。

第二轮：

- 拆成痛点、产品动作、过程细节、结果对比。

第三轮：

- 重做产品标准帧或改成图文后期证明。

## 8. Seedance 2.0 返工提示词字段

每条返工提示词增加：

```text
返工轮次：[第一轮单变量重试 / 第二轮拆镜 / 第三轮重做关键帧]。
本轮只改：[动作/运镜/角色锁定/口型/站位/特效规模/产品动作/情绪微动作]。
必须锁住：[角色、场景、构图、风格、道具、产品、光线、站位]。
必须删除：[多余动作、长台词、复杂运镜、多人同时说话、可读文字、额外特效]。
通过标准：[观众必须看懂什么]。
失败下一刀：[拆镜/换机位/重做首帧/改后期/放弃原镜头]。
```

## 9. 停止硬跑标准

以下情况不要继续原样重试：

- 同一主镜头连续失败三次。
- 口型两次错位且台词仍然超过 12 个汉字。
- 群像同框连续两次角色融合。
- 产品形状或关键道具连续两次漂移。
- 动作因果连续两次看不懂。
- 参考图职责仍不清楚。
- 失败原因来自原分镜过难，而不是提示词不够清楚。

导演判断：

```text
这时候不是模型不听话，是镜头设计太贪。停，拆掉。
```

## 10. 自检

返工前自问：

1. 这是第几轮返工？
2. 这一轮是否只改一个变量？
3. 必须锁住的角色、场景、风格、道具是否写清？
4. 是否删掉了多余动作、长台词和复杂运镜？
5. 如果第一轮失败，第二轮是否已经准备拆镜？
6. 如果第二轮失败，是否准备重做首帧或关键帧？
7. 是否区分了“可后期补救”和“必须重做”的问题？
8. 是否避免把提示词越写越长？
9. 是否明确通过标准？
10. 是否知道什么时候停止硬跑？
