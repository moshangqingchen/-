# AI超级导演喜剧节拍、误会升级与反应剪辑引擎

## 1. 定位

这份引擎用于处理搞笑、可爱搞笑、荒诞短片、职场喜剧、幼儿园群像、产品搞笑广告、打斗喜剧和短剧轻喜剧。

搞笑不是让角色乱动，也不是给台词加段子。真正可生成、可剪辑的喜剧来自：一个清楚规则被误解，一个角色认真执行错误逻辑，镜头给观众半秒反应，再让结果升级一次。

默认原则：

1. 笑点来自规则，不来自吵闹。
2. 角色越认真，反差越好笑。
3. 每个笑点必须有反应镜头。
4. 台词越短越好，解释笑点会杀死笑点。
5. 群像喜剧一镜只让一个角色负责主动作，其他角色只做轻反应。
6. Seedance 2.0 中复杂喜剧要拆成“规则镜头 + 误解镜头 + 反应镜头 + 升级镜头”。

## 2. 六步喜剧节拍

### 2.1 正常规则

先让观众知道这里本来应该怎么运转。

示例：

- 幼儿园老师说今天学习“晒太阳”。
- 办公室主管说今天要“降本增效”。
- 产品广告里用户想快速解决一个小麻烦。

镜头要求：

- 画面清楚、空间稳定。
- 角色站位有秩序。
- 不急着给笑点，先让正常规则成立。

### 2.2 错误理解

一个角色把规则理解偏了。

常见误解：

- 字面误解：把“晒太阳”理解成把太阳拿来晒。
- 身份误解：把普通道具当成重要人物。
- 任务误解：把简单任务当成重大仪式。
- 因果误解：把产品效果理解成荒诞魔法。
- 权力误解：最小的角色突然拿出最严肃的权威。

镜头要求：

- 中近景或特写。
- 表情认真，不挤眉弄眼。
- 手部动作清楚，观众一眼看懂错在哪里。

### 2.3 认真执行

角色不是“知道自己好笑”，而是真相信这个错误逻辑。

动作要求：

- 动作要具体：贴标签、排队、盖章、举手、搬道具、认真记录。
- 动作不能太多，一镜只做一个主动作。
- 让角色的小身体或小身份承担大任务，反差会更强。

### 2.4 反应停顿

笑点落下前必须给观众半秒钟看见“不对劲”。

反应类型：

- 单人愣住。
- 集体同步沉默。
- 一个角色慢半拍看向另一个角色。
- 手停在半空。
- 声音突然收掉。

镜头要求：

- 近景或中近景。
- 停顿 0.3-0.8 秒。
- 不加解释性旁白。

### 2.5 二次升级

第一次笑点后不要马上结束，要再升一级。

升级方式：

- 错误逻辑被更多角色认真接受。
- 一个小道具被当成更大的系统。
- 产品动作解决了问题，却造成更可爱的误会。
- 原本旁观的人突然比主角更认真。
- 反应角色反过来成为下一个误解者。

### 2.6 封口镜头

结尾用短动作、短台词、声音或表情收住。

封口类型：

| 类型 | 用法 |
| --- | --- |
| 表情包定格 | 可爱搞笑、群像、短视频结尾 |
| 一本正经总结 | 幼儿园、办公室、荒诞会议 |
| 声音落点 | 盖章声、铃声、轻咳、啪嗒 |
| 道具反转 | 道具突然成为真正关键 |
| 集体沉默 | 反差最大时停住，不解释 |

## 3. 喜剧角色职能

群像喜剧要先分职能，不要所有人都搞笑。

| 职能 | 作用 | 表演方式 |
| --- | --- | --- |
| 误解者 | 制造错误逻辑 | 认真、笃定、动作清楚 |
| 监督者 | 维护正常规则 | 想纠正但被带偏 |
| 慢半拍 | 延迟理解 | 迟疑、眨眼、慢慢转头 |
| 过度执行者 | 把误会升级 | 动作更正式、更夸张但不乱 |
| 旁观反应者 | 替观众反应 | 停顿、看向中心物、轻微后退 |
| 封口者 | 收尾 | 一句短台词或一个动作 |

规则：

1. 一镜只让一个职能主导。
2. 每个角色有固定反应速度。
3. 同框角色超过三个时，优先拆反应镜头。
4. 不让所有角色同时说话、同时挥手、同时做夸张表情。

## 4. 喜剧镜头语法

| 镜头 | 功能 | 注意 |
| --- | --- | --- |
| 稳定中景 | 建立正常秩序 | 不急着动镜头 |
| 中近景 | 看清误解者表情 | 表情认真，不演滑稽 |
| 手部特写 | 展示错误执行动作 | 道具清楚 |
| 拉镜揭示 | 先看认真表情，再揭示荒诞全貌 | 适合大反差 |
| 反应近景 | 让笑点落地 | 保留停顿 |
| 集体定格 | 表情包结尾 | 角色不要融合 |

禁用：

- 一直快速剪辑，观众没时间反应。
- 角色直接说“好搞笑”。
- 旁白解释笑点。
- 同一镜里塞多个误会。
- 表情过度扭曲导致角色不可爱或不真实。

## 5. 声音与剪辑

喜剧声音不是越多越好，而是要准。

常用声音：

- 动作声：啪嗒、咔哒、轻轻一拍、盖章声。
- 空白声：音乐突然停住。
- 反应声：轻咳、吸气、短促停顿。
- 反差声：严肃提示音配很小的动作。
- 封口声：铃声、门响、道具落下。

剪辑规则：

1. 笑点前少剪，先让观众看清。
2. 笑点落下时切反应。
3. 升级时切回误解者。
4. 封口时不要再补解释镜头。

## 6. 产品搞笑广告

产品搞笑广告不能只搞笑，必须证明产品。

结构：

```text
小痛点
-> 错误理解
-> 产品动作介入
-> 可见变化
-> 角色反应
-> 二次误会或表情包封口
```

规则：

1. 产品必须参与动作，不只摆在旁边。
2. 笑点不能遮住卖点。
3. 产品结果要可见：变干净、变快、变轻松、变整齐、变好吃、变舒服。
4. 品牌字和可读中文默认后期添加。

## 7. 打斗喜剧

打斗喜剧不能牺牲动作因果。

结构：

```text
空间基准
-> 攻防目标
-> 错误判断
-> 动作结果
-> 反应停顿
-> 二次错位
```

规则：

1. 打击点必须清楚。
2. 笑点放在受力后的反应，不放在动作本身。
3. 不做群体混战喜剧，先锁一个对手、一个障碍、一个结果。
4. Seedance 高风险时拆成“动作镜头 + 反应镜头 + 结果镜头”。

## 8. Seedance 2.0 提示词字段

喜剧镜头提示词必须写清：

```text
正常规则：
误解者：
错误理解：
主动作：
反应角色：
反应停顿：
二次升级：
封口动作：
声音落点：
禁止项：
```

单镜提示词骨架：

```text
稳定中近景，[角色]在[场景]中认真执行[错误理解后的动作]，[道具]清楚可见，其他角色只做轻微反应，动作结束后停顿半秒，[反应角色]慢慢看向[中心物]，喜剧节奏来自认真误会，不夸张乱动，不生成字幕或Logo，预留干净字幕安全区。
```

## 9. 输出协议

当用户要求搞笑、可爱搞笑、喜剧、荒诞、轻松广告或笑点升级时，默认先输出：

```text

喜剧规则：
误解者：
错误理解：
认真执行动作：
反应停顿：
二次升级：
封口镜头：
声音落点：
Seedance 2.0提示词：
```

## 10. 审片自检

1. 笑点是否来自规则和误解，而不是乱？
2. 角色是否认真执行，而不是故意卖弄？
3. 是否有反应停顿？
4. 是否有二次升级？
5. 台词是否短，是否没有解释笑点？
6. 群像是否有职能分工？
7. 产品广告是否证明了产品？
8. Seedance 提示词是否避免多人同时乱动？
