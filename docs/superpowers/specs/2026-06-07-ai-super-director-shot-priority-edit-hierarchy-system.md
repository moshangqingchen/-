# AI超级导演镜头优先级与剪辑层级系统

## 1. 定位

这份手册解决一个现场导演和剪辑导演都会遇到的问题：一条片不能每个镜头都抢戏。

当用户说“分镜太散”“镜头平均”“不知道哪一镜最重要”“剪不起来”“帮我选主镜头”“哪一镜必须稳”“哪个镜头先生成”“节奏不聚焦”“画面很多但没重点”时，默认先进入镜头优先级与剪辑层级系统。

它的目标不是增加镜头，而是给镜头排队：谁负责打中观众，谁负责证明信息，谁负责让人物活，谁负责接住剪辑，谁负责留下记忆。

## 2. 导演判断口径

默认先这样判断：

```text
我会这样拍：
这条片不能平均用力。先定一个主镜头赢观众，再用证明镜头让信息成立，用反应镜头让人相信，用桥镜头把剪辑接顺，最后把记忆镜头留住。
```

如果镜头已经很多，第一刀不是继续加，而是先删掉以下镜头：

- 只漂亮但不推进信息的空镜。
- 只解释背景但没有动作变化的镜头。
- 多个功能重复的近景。
- 角色同一情绪连续出现两次以上的反应。
- Seedance 2.0 高风险但不承担核心信息的复杂镜头。

## 3. 五类镜头职能

### 3.1 主镜头

主镜头负责让观众立刻知道“这条片看什么”。它通常放在开头、转折点或高潮处。

主镜头必须具备：

- 一个明确动作。
- 一个明确视觉重心。
- 一个可截图的瞬间。
- 一个能被标题或封面复用的画面。
- Seedance 2.0 可生成性不低于 B。

常见形式：

- 可爱治愈：小主体面对大任务的第一帧。
- 短剧：关系冲突爆开的近景或双人对峙。
- 广告：产品动作介入并产生可见变化。
- 打斗特效：触发点或受力结果，而不是一堆乱动。
- 爆款视频：前三秒的问题帧。

### 3.2 证明镜头

证明镜头负责让观众相信“这件事真的发生了”。广告、产品、特效、剧情反转尤其需要它。

证明镜头要拍：

- 原因。
- 动作。
- 结果。
- 前后对比。
- 道具或环境变化。

Seedance 写法要避免“变得更好”这种空话，改成具体变化：

```text
产品被按下后，桌面上的水渍从边缘向中心收缩，人物手指停住半秒，低头确认变化。
```

### 3.3 反应镜头

反应镜头负责让人物像活人。它不负责解释剧情，而是负责让观众相信刚刚那一下真的打到了人心里。

反应镜头优先拍：

- 眼神先动，嘴巴后动。
- 手部小动作。
- 身体重心变化。
- 说话前的停顿。
- 说完后的收口。
- 群像里第二个人的反应。

对白口型场景里，反应镜头可以替长对白兜底：把长话拆成画外声、字幕或后期配音，让画面只保留短句口型。

### 3.4 桥镜头

桥镜头负责让剪辑顺。它不一定最漂亮，但它决定片子能不能接起来。

桥镜头优先解决：

- 上一镜出点和下一镜入点。
- 动作匹配。
- 视线匹配。
- 声音桥。
- 道具遮挡转场。
- 空间方向不跳轴。

桥镜头不宜复杂。Seedance 2.0 中建议 2-4 秒，动作单一，镜头运动克制。

### 3.5 记忆镜头

记忆镜头负责让观众看完后能复述、截图或记住。它通常不是信息最多的镜头，而是最容易被留下的镜头。

记忆镜头要和作品记忆点系统联动：

- 记忆钉子。
- 视觉母题。
- 声音回声。
- 标志性动作。
- 品牌记忆帧。
- 结尾余味。

如果主镜头和记忆镜头是同一镜，必须保证它既有信息冲击，也有画面留存；如果两者分开，主镜头负责拉住，记忆镜头负责留下。

## 4. 镜头层级排序

默认排序：

```text
主镜头 > 证明镜头 > 反应镜头 > 桥镜头 > 记忆镜头
```

但不同类型会调整：

| 类型 | 第一优先级 | 第二优先级 | 第三优先级 |
| --- | --- | --- | --- |
| 可爱治愈 | 反应镜头 | 主镜头 | 记忆镜头 |
| 创意广告 | 证明镜头 | 主镜头 | 品牌记忆镜头 |
| 短剧冲突 | 主镜头 | 反应镜头 | 桥镜头 |
| 打斗特效 | 证明镜头 | 桥镜头 | 主镜头 |
| 爆款视频 | 主镜头 | 证明镜头 | 记忆镜头 |
| 怀旧情感 | 记忆镜头 | 反应镜头 | 桥镜头 |
| 图片转视频 | 主镜头 | 桥镜头 | 反应镜头 |

导演判断原则：

- 如果观众看不懂，先补证明镜头。
- 如果观众不信，先补反应镜头。
- 如果剪不顺，先补桥镜头。
- 如果看完忘了，先补记忆镜头。
- 如果前三秒弱，先重做主镜头。

### 4.1 五镜成片骨架门禁

多镜头方案不怕镜头少，怕每一镜都漂亮但没有剪辑职能。进入详细分镜前，先用五镜骨架确认这条片能不能剪成一口气。

| 骨架镜头 | 必须回答 | 缺失时第一刀 |
| --- | --- | --- |
| 主镜头 | 观众第一秒到底看什么冲突、动作或选择？ | 重写第一帧或主动作 |
| 证明镜头 | 哪个动作、证据或结果让观众相信这件事成立？ | 补产品动作、受力结果、信息证据或关系压力 |
| 反应镜头 | 谁的身体反应让观众相信情绪、爽点、笑点或产品结果？ | 补唯一主反应人和说完后的半秒 |
| 桥镜头 | 上一镜怎么带出下一镜，靠动作、视线、声音、道具还是空间方向？ | 改出点、改入点或补 2-4 秒桥镜 |
| 记忆镜头 | 哪个动作、物件、声音或构图能被截图、复述或回收？ | 补视觉母题、声音回声或结尾余味 |

硬规则：

1. 五镜骨架不是规定只能五镜，而是先确认五种职能都有承载。
2. 同一镜可以兼任副职能，但必须说清主职能；说不清就拆镜。
3. 如果没有证明镜头，广告、打斗、特效和反转都容易虚。
4. 如果没有反应镜头，情绪、笑点、爽感和产品结果都没人确认。
5. 如果没有桥镜头，Seedance 片段会像拼接素材，不像成片。

输出句式：

```text
我先搭五镜成片骨架：
主镜头：【拉住观众的一镜】
证明镜头：【让信息成立的一镜】
反应镜头：【让情绪可信的一镜】
桥镜头：【让剪辑接顺的一镜】
记忆镜头：【让观众带走的一镜】
最弱的是【一个职能】，第一刀先补【一个镜头或一个出点】。
```

### 4.2 镜头职能越界刹车表

一个镜头可以有副作用，但只能有一个主职能。  
如果一镜同时想当主镜头、证明镜头、反应镜头、桥镜头和记忆镜头，它通常会变成什么都没打中。

| 越界表现 | 为什么会坏 | 第一刀 |
| --- | --- | --- |
| 主镜头里塞证明、解释、口播和记忆帧 | 第一秒不聚焦，观众不知道看什么 | 主镜头只保一个冲突动作；证明和口播拆到后面 |
| 证明镜头开始追求漂亮运镜和情绪表演 | 证据不清，产品、特效或反转无法被相信 | 证明镜头只拍原因、动作、结果和可见变化 |
| 反应镜头开始解释剧情或承担长对白 | 人物像在讲资料，情绪不落地 | 反应镜头只拍身体先露馅；解释改画外声、字幕或下一镜 |
| 桥镜头开始炫技、变长或引入新信息 | 剪辑胶水抢主戏，片子节奏变散 | 桥镜头只接出点和入点，2-4 秒，动作单一 |
| 记忆镜头塞太多信息、卖点和剧情反转 | 观众记不住，截图也不干净 | 记忆镜头只保一个动作、物件、声音或构图回收 |
| 覆盖镜头重复主镜头内容 | 镜头数变多，但剪辑没有新选择 | 改成反应、插入、手部、过肩或保底出点 |

职能判断句：

```text
这镜如果删掉，整条片少的是【冲突/证据/情绪/衔接/记忆】哪一项？
答案就是它的主职能。
```

拆镜规则：

```text
一镜超过一个主职能，先拆成“主职能镜头 + 副职能镜头”。
如果副职能不改变信息、情绪、证据、衔接或记忆，就删掉。
```

## 5. Seedance 2.0 输出字段

多镜头方案默认增加一列：

```text
镜头职能：主镜头 / 证明镜头 / 反应镜头 / 桥镜头 / 记忆镜头
优先级：S / A / B / C
必须稳住：是 / 否
失败第一刀：重写动作 / 降低运镜 / 拆镜 / 改成反应镜头 / 改后期
```

每条 Seedance 2.0 提示词里加一句功能锁定：

```text
本镜头职能：主镜头，必须让观众在第一秒看清冲突，不增加额外动作。
```

或：

```text
本镜头职能：桥镜头，只负责动作衔接，镜头运动克制，不抢主镜头。
```

## 6. 生成前优先级检查

正式生成前先问五个问题：

1. 哪一镜失败会让整条片垮掉？
2. 哪一镜必须先试生成？
3. 哪一镜只是好看但可以删？
4. 哪一镜承担口型、动作、特效或产品证明的最高风险？
5. 哪一镜适合作封面、标题图或结尾回收？
6. 五镜成片骨架里，哪一个职能最弱？

如果答案不清楚，不进入最终提示词，先做一次镜头排序。

## 9. 和其他能力的联动

- 和现场导演回应协议联动：先说“我会这样拍”，再定保留、舍掉、第一刀。
- 和作品记忆点系统联动：记忆镜头必须能回收到封面、标题或结尾余味。
- 和对白口型系统联动：长对白优先拆进反应镜头或画外声，主镜头不硬塞长口型。
- 和 Seedance 可生成性系统联动：S 级主镜头如果高风险，先彩排试拍；C 级镜头高风险则直接删或后期替代。
- 和镜头衔接系统联动：桥镜头必须写清入点、出点、动作匹配或声音桥。
