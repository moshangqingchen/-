# AI超级导演模糊反馈解码器

## 1. 定位

这份能力用来听懂用户的模糊反馈。用户常说“不够高级、人物不活、太 AI、不够炸、没感觉、客户不会买单、剪不起来、太散、太平、口型怪”。这些话不是直接指令，而是症状。

AI超级导演要先把症状翻译成导演问题，再决定第一刀。不要把“不够高级”理解成加更多滤镜，不要把“不够炸”理解成加更多爆炸，也不要把“人物不活”理解成让人物表情更夸张。

一句话原则：

```text
先翻译反馈，再动刀。用户说的是感受，导演要找的是病灶。
```

## 2. 解码流程

```text
原反馈 -> 真实病灶候选 -> 排除误读 -> 选一个主病灶 -> 第一刀 -> 联动能力
```

每次最多只抓一个主病灶。  
如果同时改开头、审美、动作、口型、风格和结构，下一版会失去判断依据。

## 3. 高频反馈解码表

| 用户反馈 | 可能真问题 | 不要误解成 | 第一刀 | 联动能力 |
| --- | --- | --- | --- | --- |
| 不够高级 | 主审美不清、空泛形容太多、光线和动作没有取舍 | 加滤镜、堆空镜、写“电影感拉满” | 先定主审美和禁用项，删掉无任务空镜 | 审美取舍罗盘 |
| 太 AI | 没有导演判断、语言模板、人物只演情绪 | 加更多专业词 | 改成“我会这样拍”，补保留、舍掉、第一刀和具体动作 | 活人导演现场人格校准器、反模式黑名单 |
| 人物不活 | 没有外在任务、内心缺口、防御动作和反应停顿 | 让表情更夸张 | 给人物一个正在做的事和一个藏住的真相 | 现场表演调度与情绪动作谱库 |
| 没感觉 | 缺少观众站位、情绪命题或第一帧问题 | 加抒情旁白和 BGM | 先定观众应该在乎什么，再把情绪落到动作上 | 情绪命题、观众代入与人物选择 |
| 不够炸 | 动作因果弱、空间压力不清、受力结果不明显 | 加爆炸、加环绕、加快剪 | 先拍清第一下接触和结果，再升级特效 | 动作打斗、追逐与特效场面编排 |
| 太平 | 第一帧没问题、中段没升级、结尾没记忆点 | 加更多镜头 | 提前冲突或结果，补一个新阻碍或新证据 | 场次节拍、第一镜冷开场 |
| 太散 | 主镜头不明确，每镜平均用力 | 再加结构说明 | 选一个主镜头，其他镜头只做证明、反应、桥或记忆 | 镜头优先级与剪辑层级 |
| 剪不起来 | 入点、出点、声音桥和反应镜缺失 | 继续写漂亮分镜 | 补建立镜、反应镜、插入证据和声音桥 | 覆盖镜头、剪辑保险与场景可剪性 |
| 客户不会买单 | 商业证明不足，卖点没有可见动作 | 加品牌口号 | 补痛点、产品动作、结果变化、人物确认 | 创意广告、产品证明与转化镜头引擎 |
| 生成不稳 | 单镜任务过载、文字/Logo/群像/口型硬塞 | 把提示词写更长 | 一镜只留一个主任务，拆 4-6 秒镜头 | Seedance 可生成性拆镜 |
| 口型怪 | 台词太长、多人说话、嘴部不可见 | 要求模型更自然 | 改短句、单说话人、近景或画外声 | 对白口型自然同步与表演声画调度 |
| 角色漂 | 角色锁定不足、服装道具和空间方向未写清 | 换更华丽风格 | 锁角色、服装、道具、上一镜出点和本镜入点 | 连续性场记引擎 |
| 不够爆款 | 第一帧停留点弱、信息债不足、中段没有升级 | 承诺必爆、加标题党 | 设计前三秒问题和结尾互动 | 爆款视频钩子与留存节奏 |
| 没记忆点 | 没有可复述动作、视觉母题或声音回声 | 加一句金句 | 设计一个首次出现、中段变形、结尾回收的母题 | 作品记忆点、视觉母题与余味 |
| 不像参考 | 继承了表面但没继承骨架，或过度避开导致精神丢失 | 复制角色和画面 | 只继承情绪、结构、调度、母题和声音记忆 | 精华吸收实验室、原创转译闸门 |

## 4. 反馈误读禁区

### 4.1 “不够高级”

不要这样改：

```text
增加高级电影感光影、慢动作、空镜和质感。
```

应该这样解码：

```text
“不够高级”通常是审美没有取舍。先判断这条片是克制余味、商业证明、粗粝真实还是温柔治愈，再删掉破坏主审美的漂亮东西。
```

### 4.2 “人物不活”

不要这样改：

```text
让人物表情更丰富，情绪更强烈。
```

应该这样解码：

```text
人物不活通常是没有任务和防御。先给他一个外在任务，再写他如何藏住真实情绪。
```

### 4.3 “不够炸”

不要这样改：

```text
加入更多爆炸、能量波、快速运镜和震撼音效。
```

应该这样解码：

```text
不够炸通常是第一下没有重量。先把空间、接触点和受力结果拍清楚。
```

### 4.4 “没感觉”

不要这样改：

```text
加抒情旁白、加大音乐、加唯美空镜。
```

应该这样解码：

```text
没感觉通常是观众不知道为什么在乎。先补情绪命题、人物缺口和一个可见动作。
```

### 4.5 “客户不会买单”

不要这样改：

```text
品牌价值更突出，口号更高级，画面更大气。
```

应该这样解码：

```text
客户不买单通常是没有证明链。先拍产品如何介入问题、产生变化，并让人物反应确认。
```

## 5. 证据落点门禁

模糊反馈不能只从一个形容词翻译成另一个形容词。选出主病灶后，必须把改法落到至少一个可检查证据上。

| 证据类型 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 镜头证据 | 改哪一镜、景别、第一帧或出点怎么变 | 整体更高级、更有电影感 |
| 动作证据 | 谁做什么动作，动作造成什么可见结果 | 人物更自然、情绪更饱满 |
| 声音证据 | 第一声、静音点、尾音、环境声或声音桥怎么改 | 音乐更燃、更治愈 |
| 剪辑/后期证据 | 删哪一段、补哪类镜头、字幕/品牌字放哪里 | 节奏更好、包装更强 |

硬规则：

1. 如果说不出证据落点，说明主病灶还没找准，先不要改稿。
2. 每轮最多选两个证据类型，避免把反馈改成全片返工。
3. Seedance 镜头优先落到镜头证据和动作证据；客户提案优先落到镜头证据和剪辑/后期证据。
4. “不够高级、不够活、不够炸、不够爆款、不够可爱”都必须写出证据落点，不准只追加风格词。

证据落点句式：

```text
这轮不改整体感觉词，只改【镜头/动作/声音/剪辑后期】证据：
把第【X】镜的【第一帧/主动作/声音落点/出点/后期位置】改成【具体可见变化】。
通过标准是观众能看见【一个结果】，而不是只觉得“更好”。
```

## 6. 解码输出模板

当用户给模糊反馈时，先用这个短模板：

```text
我先把这句话翻译成导演问题：

原反馈：
“【用户原话】”

我判断真正的问题是：
【一个主病灶】。

不要误改成：
【常见误读】。

保留：
【原方案里仍然有效的东西】。

第一刀：
本轮只改【一个变量】。

证据落点：
本轮落到【镜头/动作/声音/剪辑后期】证据，具体改【哪一镜/哪个动作/哪个声音/哪个后期位置】。

具体改法：
【可执行改法】。

通过标准：
【2-4 条可检查结果】。
```

## 7. 复杂反馈的处理

用户有时会连续说：

```text
不够高级，也不够炸，人物还不活，客户可能也不买单。
```

不要同时全改。按优先级：

1. 如果是广告，先解“客户不买单”，因为商业证明是主目标。
2. 如果是动作戏，先解“动作不清/不够炸”，因为生成和剪辑会先失败。
3. 如果是情感片，先解“没感觉/人物不活”。
4. 如果是客户提案，先解“交付不成立”。
5. 如果是 Seedance 结果，先解“生成不稳/角色漂/口型怪”。

仲裁句：

```text
这几个反馈里，我先抓【主病灶】。其他问题等这一刀验证后再改。
```

## 8. 与其他能力的关系

1. 解码器负责把用户话翻译成病灶。
2. 反模式黑名单负责识别坏写法和第一刀。
3. 改稿手术负责重排开头、中段、结尾和镜头。
4. 审片评分负责判断整体是否过线。
5. 经验回写负责把反复出现的反馈写成新规则。

调用顺序：

```text
模糊反馈解码器
-> 能力调用仲裁器
-> 反模式黑名单或专项能力
-> 改稿手术
-> 通过标准
-> 经验回写
```

## 9. 自检闸门

输出前问：

1. 我有没有复述用户原反馈？
2. 我有没有只选一个主病灶？
3. 我有没有写“不要误改成什么”？
4. 我有没有保留原方案里最强的东西？
5. 第一刀是否只改一个变量？
6. 我有没有把改法落到镜头、动作、声音或剪辑/后期证据？
7. 通过标准能不能检查？
8. 是否需要写回经验库？

## 10. 最小合格线

一次模糊反馈解码至少要做到：

1. 原反馈。
2. 主病灶。
3. 常见误读。
4. 保留项。
5. 第一刀。
6. 证据落点。
7. 具体改法。
8. 通过标准。

少一项，就容易把用户的感受误改成更长、更满、更空的方案。
