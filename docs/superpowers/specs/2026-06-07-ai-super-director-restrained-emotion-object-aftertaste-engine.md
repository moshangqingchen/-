# AI超级导演克制情感、旧物叙事与余味留白引擎

## 1. 定位

这份引擎用于处理情感短片、亲情、怀旧、公益、旧物故事、内心戏、没说出口的话、关系缺席、治愈情绪落点和品牌微电影里的高级情绪。

情感不是让人物哭，也不是用旁白解释伤口。真正动人的情感来自：一个人想靠近但不敢靠近，一个旧物替他说话，一个动作停在半路，声音先进来，结尾留一个没有说完的余味。

默认原则：

1. 情绪必须落在具体物件、动作、声音或空间空位上。
2. 不让人物直接说“我很难过、我很想你、我被治愈了”。
3. 内心戏要演防御动作，不演情绪本身。
4. 旧物不是装饰，是关系的代言人。
5. 旁白只补缺口，不解释画面。
6. 结尾留白，不把所有情绪讲完。

## 2. 情感五件事

每个情感项目先定五件事：

```text
缺席的人或关系：
旧物或情绪载体：
没说出口的话：
当下人物的防御动作：
结尾余味动作：
```

示例：

```text
缺席的人或关系：多年没回家的父亲。
旧物或情绪载体：修过三次的旧雨伞。
没说出口的话：其实我一直等你回来。
防御动作：把伞放回原处，假装只是整理房间。
结尾余味动作：门口雨声停了，她还是没有把伞收起来。
```

## 3. 旧物叙事

旧物要承担关系，不只承担年代感。

旧物选择：

| 旧物 | 情绪功能 |
| --- | --- |
| 旧照片 | 证明曾经在一起 |
| 录音机/磁带 | 让缺席的人用声音回来 |
| 旧雨伞 | 等待、保护、没送出的关心 |
| 饭盒/杯子 | 日常照顾、习惯延续 |
| 校服/围巾 | 成长、错过、被记得 |
| 车票/公交卡 | 离开、没赶上、想回去 |
| 修过的玩具 | 童年、亏欠、陪伴 |

规则：

1. 第一次出现旧物，不能解释它的意义。
2. 中段让人物和旧物发生一次犹豫接触。
3. 结尾让旧物的状态变化，替人物说话。

## 4. 防御动作谱

情感要拍人物怎么藏住情绪。

| 内心真相 | 防御动作 | 破防瞬间 |
| --- | --- | --- |
| 想念 | 假装整理旧物 | 手停在按钮上 |
| 愧疚 | 转移话题 | 听见旧声音后沉默 |
| 害怕失望 | 不敢打开盒子 | 盒子里掉出熟悉物件 |
| 不肯承认在乎 | 嘴硬、轻笑 | 看见对方留下的痕迹 |
| 想和解 | 先退半步 | 把物件递回去 |
| 放不下 | 把东西放回原位 | 又轻轻拿起来 |

规则：

1. 镜头拍防御，不拍情绪标签。
2. 破防只需要一个小动作，不需要大哭。
3. 说话前后都要有停顿，嘴部不必承担全部情绪。

## 5. 声音桥

声音是情感片的第二只手。

常用声音：

- 旧录音底噪。
- 雨声、风声、远处车声。
- 杯子轻碰桌面。
- 门锁声。
- 布料摩擦。
- 旧物开合声。
- 一个没说完的称呼。

声音规则：

1. 声音可以先于画面半秒进入。
2. 旧声音不要解释回忆，只把人物带回去。
3. 情绪高点可以降低环境声，让手部动作更清楚。
4. 结尾声音可以回收第一镜。

## 6. 留白镜头

留白不是空镜，是事件之后的余温。

留白类型：

| 留白 | 用法 |
| --- | --- |
| 空椅子 | 缺席的人仍在关系里 |
| 门口 | 等待、离开、没说出口 |
| 窗边 | 时间过去、想念未到达 |
| 旧物静止 | 关系被放回原处 |
| 背影 | 情绪不解释 |
| 手停住 | 选择还没完成 |

规则：

1. 留白镜头必须承接前一个动作。
2. 留白时间不需要长，但要有声音或微动作。
3. 不用旁白把留白说破。

## 7. 情感广告

情感广告必须让产品成为情绪动作的一部分。

结构：

```text
微小伤口
-> 旧物或日常习惯
-> 产品动作介入
-> 人物防御松动
-> 可见变化
-> 品牌记忆帧
-> 留白余味
```

规则：

1. 产品不能突然出现，要像生活里本来就需要它。
2. 卖点必须通过动作证明。
3. 情绪不能压过产品结果。
4. 品牌字和中文标语默认后期添加。

## 8. Seedance 2.0 提示词字段

情感镜头提示词必须写清：

```text
缺席关系：
旧物/情绪载体：
防御动作：
破防动作：
声音桥：
留白位置：
结尾余味：
字幕安全区：
禁止项：
```

单镜提示词骨架：

```text
固定中近景或手部特写，[角色]站在[空间位置]，面前是[旧物/产品/情绪载体]，角色没有直接哭或说出情绪，只做[防御动作]，手在[关键动作]前停顿半秒，环境声安静，[声音桥]轻轻进入，画面留出[空椅子/门口/窗边/旧物]作为余味，不生成可读文字、Logo或字幕，预留干净字幕安全区。
```

## 9. 输出协议

当用户要求情感、怀旧、亲情、内心戏、没说出口、旧物、余味、克制一点、高级一点或不要煽情时，默认先输出：

```text
我会这样拍：
缺席关系：
旧物/情绪载体：
没说出口的话：
防御动作：
破防动作：
声音桥：
留白镜头：
Seedance 2.0提示词：
```

## 10. 审片自检

1. 情绪是否落在具体物件、动作或声音上？
2. 人物是否在藏情绪，而不是直接演情绪？
3. 旧物是否承载关系，而不是怀旧装饰？
4. 旁白是否没有解释画面？
5. 结尾是否留白，没有把情绪说完？
6. 如果是广告，产品动作是否证明卖点？
7. Seedance 提示词是否避免大哭、复杂文字和强行煽情？
