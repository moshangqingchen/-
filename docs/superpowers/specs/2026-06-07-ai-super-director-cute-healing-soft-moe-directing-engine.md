# AI超级导演可爱治愈、软萌群像与情绪修复导演引擎

## 1. 定位

这份引擎专门处理“可爱、治愈、软萌、毛绒、小动物、幼儿园群像、温柔广告、情绪价值短片”这类项目。

它不替代类型公式手册，而是把散落在可爱公式、治愈公式、微动作库、风格圣经、爆款钩子和 Seedance 2.0 手册里的规则，收束成一个现场导演可以直接调用的调度系统。

它解决的不是“画面可不可爱”这么浅的问题，而是：

- 可爱从哪里来。
- 治愈怎么发生。
- 群像怎么不乱。
- 小角色怎么像活的。
- Seedance 2.0 怎么生成稳定、柔软、清楚的动作和反应。

## 2. 默认调用时机

用户说以下词，默认先调用本引擎：

- 可爱、萌、软萌、毛绒、小动物、玩具、幼儿园、童趣、表情包。
- 治愈、温柔、疗愈、暖、陪伴、情绪价值、慢一点、想被安慰。
- 可爱治愈广告、萌系广告、咖啡/甜品/家居/护肤/文创/宠物广告。
- 像绒耀幼儿园那种，但要原创。
- 角色太平、不可爱、不够暖、像摆拍、太幼稚、太甜腻。

默认输出先写：

```text
我会这样拍：
这个片子的可爱不靠卖萌，靠小角色认真做一件超出能力的大事。
治愈也不是漂亮空镜，而是一个小伤口被轻轻接住。
```

## 3. 核心判断

可爱不是形容词，是动作关系。

```text
可爱 = 小主体 + 大任务 + 认真态度 + 轻微失误 + 清楚反应 + 可截图落点
```

治愈不是慢镜头，是情绪修复。

```text
治愈 = 微小伤口 + 温柔介入 + 抗拒松动 + 身体放松 + 安静留白
```

可爱治愈广告不是把产品放在可爱画面里。

```text
可爱治愈广告 = 小角色困境 + 产品温柔做事 + 情绪被修复 + 卖点变成动作 + 记忆帧
```

软萌群像不是一群角色同时动。

```text
软萌群像 = 固定角色秩序 + 一个荒诞问题 + 轮流反应 + 集体误会 + 表情包收束
```

## 4. 现场导演取舍

### 4.1 我会保留

- 小主体承担大任务的反差。
- 认真、笨拙、慢半拍的动作。
- 观众能截图的表情或姿势。
- 轻而准的声音：脚步、布料、杯声、贴纸、呼吸。
- 一点点被接住的情绪，而不是灌满鸡汤。

### 4.2 我会舍掉

- 只写“很可爱、很治愈、很温暖”的空话。
- 过甜、过亮、过奶油的单一色彩。
- 大段解释情绪的旁白。
- 群像同一时间乱动。
- 角色故意装傻、乱喊、做网络段子。
- Seedance 2.0 一条镜头里塞太多角色动作。

### 4.3 第一刀怎么改

如果用户给的方案太普通，第一刀不是加形容词，而是加一个“具体小任务”：

```text
普通：一只可爱小熊在教室里。
导演改法：一只圆滚滚小熊踮脚给月亮贴请假条，贴歪了还严肃点头。
```

如果方案太治愈但没变化，第一刀是加一个“微小伤口”：

```text
普通：女孩在窗边喝咖啡，很治愈。
导演改法：女孩加班回家，杯子旁边还放着没回完的消息，她握住热杯时肩膀才慢慢松下来。
```

## 5. 可爱度调度表

| 层级 | 导演问题 | 可拍写法 | 风险 |
| --- | --- | --- | --- |
| 外形 | 观众第一眼想靠近吗 | 圆润比例、短手短脚、柔软边缘、清楚表情 | 只堆圆、胖、萌 |
| 任务 | 它正在认真做什么 | 搬大物、贴标签、排队、保护别人、解释规则 | 没任务，只摆姿势 |
| 反差 | 小主体和大任务怎么错位 | 小小身体做很正式的事 | 反差太硬，像段子 |
| 失误 | 哪里笨拙但不讨厌 | 贴歪、抱不稳、慢半拍、理解错 | 变成嘲笑角色 |
| 反应 | 观众从哪里笑或心软 | 眨眼、停顿、看向同伴、假装镇定 | 没有反应镜头 |
| 收尾 | 最后一帧能截图吗 | 集体愣住、严肃点头、抱住大物、眼睛变亮 | 解释太多 |

## 6. 治愈弧线表

治愈片必须有变化。可以很小，但不能没有。

```text
紧绷 -> 温柔物件出现 -> 抗拒或迟疑 -> 触碰/靠近 -> 身体放松 -> 安静回应
```

| 阶段 | 画面动作 | 身体信号 | 声音 |
| --- | --- | --- | --- |
| 紧绷 | 低头、停在门口、手握紧、消息未读 | 肩膀高、呼吸短 | 冷环境声、雨声、空调声 |
| 介入 | 热杯、灯光、宠物、风、产品、别人递来的手 | 眼神停一下 | 杯声、脚步、布料声 |
| 迟疑 | 没立刻接、看一眼又移开 | 手指微动 | 声音变空一点 |
| 松动 | 接住、靠近、坐下、轻轻笑 | 肩膀放下、呼吸变长 | 暖音、近处小声 |
| 留白 | 不说破，继续做一个小动作 | 眼神变软 | 环境声留下 |

导演判断：

- 治愈前必须有一点冷。
- 温柔不要来得太猛。
- 结尾不要替观众哭。

### 6.1 微小挫折与温柔介入账本

可爱治愈最容易失手的地方，是把“温柔介入”写成外力替主角解决一切。真正让人心软的不是被拯救，而是小主体被托住以后，自己完成最后一点点。

每个可爱治愈段落都要先过这张账本：

| 字段 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 小主体 | 谁在认真承担任务 | 只有“可爱角色” |
| 过大任务 | 它想完成什么超出能力的小事 | 只摆姿势、只卖萌 |
| 微小挫折 | 哪个动作失败、卡住或露出小伤口 | 没有变化，直接温暖 |
| 温柔介入 | 谁或什么轻轻帮了一下 | 外力直接包办结果 |
| 主体最后动作 | 小主体自己完成哪一步 | 帮助者替主角完成 |
| 反应停顿 | 观众在哪里心软、笑或安静 | 没有反应镜头 |
| 情绪松动证据 | 身体、眼神、呼吸或动作哪里变软 | 只写“被治愈了” |
| 可截图落点 | 最后一帧能被记住的姿势或关系 | 解释性旁白收尾 |

硬规则：

- 不偷主角功劳：温柔介入只能托住、照亮、递近、减轻阻力，最后一个选择或动作必须还给小主体。
- 不用软萌遮丑：粉色、圆眼、慢音乐、毛绒材质不能替代任务、挫折、反应和松动。
- 不让帮助者压过主体：帮助者的动作要小，主角的反应要清楚。
- 不把治愈拍成鸡汤：结尾用一个动作落地，不用旁白宣布意义。

快速输出格式：

| 小主体 | 过大任务 | 微小挫折 | 温柔介入 | 主体最后动作 | 反应停顿 | 情绪松动证据 | 可截图落点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [谁] | [想完成什么] | [哪里卡住] | [谁轻轻帮] | [自己完成哪一步] | [停几拍/看向哪里] | [肩膀、眼神、呼吸、手部变化] | [最后一帧] |

### 6.2 被治愈前后证据门禁

治愈必须能被看见。不能只让画面变暖、音乐变软、角色笑一下，就宣布“被治愈了”。输出前先检查前后证据是否成立。

| 证据 | 必须拍出来 | 不合格写法 | 第一刀 |
| --- | --- | --- | --- |
| 治愈前证据 | 紧绷、疲惫、孤单、笨拙、没被理解或任务卡住的具体动作 | 只写“他很难过/很孤独/很累” | 改成手、肩、眼神、呼吸或道具状态 |
| 介入证据 | 谁或什么轻轻靠近、托住、递近、照亮或减轻阻力 | 只写“温暖出现/被治愈/被陪伴” | 改成一个小动作或一个可听见的声音 |
| 松动证据 | 角色身体哪里真的变软，或关系哪里真的靠近 | 只写“露出微笑/气氛变好” | 改成肩膀放下、手松开、眼神停住、呼吸变长 |
| 保留余味 | 结尾不解释意义，只留一个继续生活的小动作 | 旁白说教、字幕总结、强行升华 | 改成动作回收、声音回声或安静停顿 |

硬规则：

1. 治愈前没有证据，后面的温柔会像摆拍。
2. 介入证据不能替主角完成全部任务，只能让主角有力气完成最后一步。
3. 松动证据必须小而具体，不能只靠笑容。
4. 结尾不替观众总结情绪；用动作或声音让观众自己补完。

输出句式：

```text
被治愈前证据：【一个身体/道具/空间动作】
温柔介入证据：【一个轻动作或声音】
被治愈后证据：【一个身体松动或关系靠近】
余味动作：【一个不解释的结尾动作】
```

## 7. 软萌群像角色秩序

群像可爱要有秩序。角色越固定，笑点越容易叠。

| 角色功能 | 外在动作 | 喜剧作用 | 治愈作用 |
| --- | --- | --- | --- |
| 认真班长 | 站最前、拿纸条、点名 | 把荒诞事当正式任务 | 负责把大家组织起来 |
| 慢半拍同学 | 反应晚半秒、眨眼 | 后知后觉补刀 | 让节奏变软 |
| 爱哭同学 | 抱道具、吸鼻子 | 把小事放大 | 提供共情入口 |
| 嘴硬同学 | 双手叉腰、装镇定 | 强行解释 | 保护群体面子 |
| 捣乱同学 | 偷偷换道具、打乱规则 | 制造升级 | 让故事不平 |
| 温柔老师 | 蹲下、轻声纠正、递物 | 接住混乱 | 情绪落点 |

默认反应顺序：

```text
认真角色宣布问题 -> 慢半拍角色误解 -> 捣乱角色升级 -> 集体沉默 -> 温柔角色接住 -> 表情包收尾
```

## 8. 空间与机位

### 8.1 可爱空间

可爱空间要让角色显得小，但不要让它被背景吞掉。

- 桌面低机位：适合幼儿园、玩具、毛绒、零食、文具。
- 近景平视：适合让观众像蹲在角色面前。
- 俯拍小任务：适合看清桌面规则、贴纸、纸条、摆放。
- 反应近景：适合笑点和心软瞬间。

### 8.2 治愈空间

治愈空间要有“可以被靠近的东西”。

- 门口：从外面疲惫进入里面。
- 窗边：用光线变化推动情绪。
- 桌面：用杯子、旧物、便签、产品介入。
- 沙发/床边：用坐下、靠近、放松完成修复。

### 8.3 群像空间锁定

Seedance 2.0 群像最怕角色乱跑。必须写固定位置：

```text
空间锁定：教室桌面在画面下方，黑板在后方，门在右侧。
角色位置：认真班长在桌子左前方，慢半拍同学在右前方，爱哭同学抱着纸盒坐中间，温柔老师在后方蹲下。
本镜只让一个角色执行主要动作，其他角色做轻微反应。
```

| 人称 | 摄影机像谁 | 适合任务 |

## 10. Seedance 2.0 可生成性规则

### 10.1 稳定写法

每条 Seedance 2.0 镜头只承担一个主要动作或一个主要情绪变化。

稳定：

```text
小熊踮脚把纸条贴到黑板上，贴歪后停半秒，认真点头。
```

高风险：

```text
一群小动物同时跑来跑去、互相对话、贴纸条、摔倒、笑、哭、跳舞。
```

### 10.2 群像拆镜

| 镜头 | 任务 | 推荐时长 |
| --- | --- | --- |
| 1 | 建立空间和荒诞问题 | 3-4秒 |
| 2 | 一个角色认真执行任务 | 4-5秒 |
| 3 | 另一个角色误解或升级 | 4-5秒 |
| 4 | 集体反应或沉默 | 3-4秒 |
| 5 | 温柔接住或表情包收尾 | 4-5秒 |

### 10.3 难度评级

| 评级 | 特征 | 处理 |
| --- | --- | --- |
| A | 单角色、小动作、稳定机位 | 可直接生成 |
| B | 2-3个角色，主动作清楚 | 只保留一个主要动作 |
| C | 4个以上角色、同时反应、道具较多 | 拆镜，先做空间锁定 |
| D | 多角色同时跳、跑、说、拿道具、复杂转场 | 降难，改成轮流反应 |

```text
Seedance 2.0 视频提示词：

声音：[小脚步/杯声/贴纸声/布料摩擦/环境声/轻音乐]。
剪辑点：[停顿、反应、轻笑、动作落点或声音落点]。
后期文字规划：字幕、品牌字和可读中文后期添加，画面预留干净安全区。
可生成性评级：[A/B/C/D，风险因子，是否拆镜]。
避免：卖萌过头、角色乱动、群像融合、表情漂移、颜色过甜、背景文字乱码、字幕错误。
```

## 12. 可爱治愈广告公式

```text
痛点小到能共情
-> 小主体认真想解决
-> 产品轻轻介入
-> 一个可见结果出现
-> 主体反应变软
-> 结尾留下品牌记忆帧
```

例子骨架：

```text
一只圆滚滚小猫熬夜陪主人工作，困到把便签贴在自己额头上。
一盏护眼灯自动变暖，桌面不刺眼了。
小猫眯着眼把便签贴正，主人终于放下肩膀。
最后一帧：灯光、猫、热杯在同一个安静桌面里。
```

广告导演判断：

- 产品不能突然被夸。
- 产品必须“做一件温柔的事”。
- 卖点要被结果证明：更暖、更稳、更亮、更舒服、更省心。

## 13. 软萌群像短片公式

```text
固定空间 + 固定角色秩序 + 大人世界问题儿童化 + 认真误解 + 轮流反应 + 意外升级 + 温柔或表情包收尾
```

默认分镜：

| 镜头 | 内容 | 导演重点 |
| --- | --- | --- |
| 1 | 第一帧给异常问题 | 让观众立刻停下 |
| 2 | 认真角色宣布规则 | 不解释太多 |
| 3 | 慢半拍角色误解 | 留半秒反应 |
| 4 | 捣乱角色升级 | 让笑点多一层 |
| 5 | 集体沉默 | 给表情包 |
| 6 | 温柔角色接住或反转 | 收住，不讲笑点 |

## 14. 治愈短片公式

```text
微小疲惫 + 空间冷感 + 温柔物件出现 + 迟疑触碰 + 身体松动 + 留白动作
```

默认分镜：

| 镜头 | 内容 | 导演重点 |
| --- | --- | --- |
| 1 | 疲惫状态 | 低头、手紧、冷环境声 |
| 2 | 温柔介入 | 热杯、灯、宠物、旧物、产品 |
| 3 | 迟疑 | 不立刻接受 |
| 4 | 触碰或靠近 | 情绪开始变化 |
| 5 | 放松 | 肩膀、呼吸、眼神 |
| 6 | 留白 | 不说破，给观众补完 |

## 15. 自检清单

输出可爱治愈方案前检查：

1. 可爱是否来自具体任务，而不是形容词？
2. 小主体是否有认真态度和轻微失误？
3. 治愈是否有微小伤口和情绪松动？
4. 产品或温柔介入是否真的做了事？
5. 温柔介入是否没有偷走主角功劳，最后一步是否还给小主体？
6. 是否写了反应停顿和情绪松动证据，而不是只写“被治愈了”？
7. 是否写了被治愈前证据、温柔介入证据、被治愈后证据和余味动作？
8. 群像是否有固定角色秩序和轮流反应？
9. 是否写了可截图落点？
10. 是否避免过甜、装傻、乱动、鸡汤旁白？
11. Seedance 2.0 每镜是否只有一个主要动作？
12. 人称运镜是否写清观众站位和摄影机身体限制？
13. 字幕和品牌字是否规划为后期添加？
