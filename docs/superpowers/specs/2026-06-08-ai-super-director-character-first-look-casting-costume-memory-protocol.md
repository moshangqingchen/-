# AI超级导演角色第一眼、选角质感与造型记忆协议

## 1. 定位

这份协议解决“角色第一眼不成立”的问题。很多短剧、广告、可爱治愈、特摄动作和系列 IP 里，角色有动机、有台词、有分镜，但观众第一眼还是记不住：不知道他是什么气质，为什么这样穿，身体怎么站，遇到压力会怎么防御，声音和动作有什么习惯。

人物动机库回答“他为什么这样做”；视觉美术库回答“画面怎么统一”；本协议回答：

```text
这个角色第一眼怎么被看见，怎么被记住，怎么在下一镜还像同一个人。
```

默认目标：

1. 让角色第一眼有功能，而不只是好看。
2. 让服装、道具、身体习惯和声音习惯服务人物。
3. 让 Seedance 角色一致性更容易锁住。
4. 让广告人物不像口播机器，短剧人物不像工具人，可爱角色不像随机萌物。
5. 让系列角色能被复述、复用和延展。

## 2. 什么时候必须启用

遇到以下信号，默认调用本协议：

1. 用户说“角色不立、人物不活、这个人没记忆点、角色第一眼、选角、造型、服装、气质、角色设定图、系列角色”。
2. 短剧、广告或品牌片里需要让人物一出场就可信。
3. 可爱治愈角色、毛绒群像、特摄英雄、反派、主播、企业人物需要固定形象。
4. 多镜头 Seedance 里角色容易漂移。
5. 客户要求“更年轻、更高级、更像我们品牌的人”。
6. 需要把参考图里的角色转成原创角色。

不必启用的情况：

1. 角色只是远景路人。
2. 用户只要场景、产品或纯视觉风格。
3. 角色外观已经由客户硬性确定，只需要连续性锁定。

## 3. 角色第一眼公式

```text
角色功能 + 第一眼轮廓 + 服装功能 + 标志道具 + 身体习惯 + 防御姿势 + 声音习惯 + 禁止变化
```

拆解：

| 字段 | 作用 |
| --- | --- |
| 角色功能 | 他在片子里承担入口、阻碍、反应、证明、情绪还是奇观 |
| 第一眼轮廓 | 观众静音一眼能看见的体态、比例、发型、形状 |
| 服装功能 | 服装不是装饰，要说明身份、性格、状态或任务 |
| 标志道具 | 角色和一个物件绑定，让动作可记住 |
| 身体习惯 | 紧张、撒谎、认真、逞强、害羞时身体怎么动 |
| 防御姿势 | 他如何藏住真实情绪 |
| 声音习惯 | 语速、音色、停顿、口头禅或不说话的方式 |
| 禁止变化 | 多镜头里绝不能变的特征 |

导演判断：

```text
我不会先给角色堆设定。我先让观众看到他怎么站、手放哪、拿着什么、第一句怎么憋出来。
```

### 3.1 可生成角色锁定三件套

角色能不能在 Seedance 多镜头里稳定，先看三件事有没有被锁住：体态轮廓、功能道具、身体习惯。脸和服装当然重要，但真正让观众觉得“还是这个人”的，往往是轮廓、手里东西和固定小动作。

| 锁定项 | 必须写清 | 失败写法 | 第一刀 |
| --- | --- | --- | --- |
| 体态轮廓 | 年龄感、身高比例、肩颈状态、站姿、走路重心或身体形状 | 高级、可爱、帅、冷艳 | 改成静音一眼能看见的轮廓 |
| 功能道具 | 道具是什么、为什么必须在他身边、每次怎么被使用 | 拿一个好看的道具 | 让道具承担任务：藏、递、擦、压、修、挡、证明 |
| 身体习惯 | 紧张、撒谎、认真、逞强、害羞、进入战斗或确认结果时固定怎么动 | 有气质、有故事感 | 改成一个可重复的小动作 |

硬规则：

1. 三件套一旦锁定，多镜头里不能随便换；每镜只允许改变动作或情绪状态。
2. 服装和发型服务三件套，不要每场为漂亮换造型。
3. 功能道具必须被使用，不使用就不是角色锚点。
4. 身体习惯要能在中景或近景看见，不能只写心理。
5. 角色漂移时，先回到三件套，不先升级风格、运镜或表情。

快速输出格式：

```text
角色锁定三件套：
体态轮廓：[静音一眼能认出的身体形状/站姿/重心]
功能道具：[固定道具 + 它承担的动作任务]
身体习惯：[压力/确认/防御时反复出现的小动作]
本镜允许改变：[只改动作/情绪状态/站位之一]
禁止变化：[年龄、脸型、发型、服装核心、功能道具、身体习惯不变]
```

## 4. 角色第一眼卡

默认输出格式：

```text
角色名：
角色功能：
第一眼关键词：
角色锁定三件套：
体态轮廓：
脸部/发型：
服装功能：
标志道具：
身体习惯：
防御姿势：
声音习惯：
第一帧动作：
关系压力下的反应：
Seedance 锁定句：
禁止变化：
```

示例：

```text
角色名：旧物修理师
角色功能：情感入口和旧物见证者。
第一眼关键词：安静、慢、手很稳。
体态轮廓：微驼背，肩膀不张开，像长期低头修小东西的人。
服装功能：旧围裙和浅色衬衫，说明他不是摆拍文艺，而是在工作。
标志道具：一块擦旧的绒布，总在说话前先擦一下旧物。
身体习惯：听见别人提到“忘了”时，手会停半秒。
防御姿势：不看对方眼睛，只看手里的零件。
声音习惯：低声、慢半拍，句子短。
第一帧动作：他把螺丝放回小盒子，却没有盖上。
Seedance 锁定句：角色始终保持旧围裙、浅色衬衫、微驼背、手部动作克制、低声慢节奏的旧物修理师气质。
禁止变化：不换服装，不突然年轻化，不夸张大哭，不新增华丽道具。
```

## 5. 类型角色设计

### 5.1 短剧主角

重点：欲望和压力第一眼可见。

```text
第一眼：正在忍住或被逼选择。
服装功能：身份、阶层或处境。
身体习惯：退半步、攥证据、避开视线、压住手机。
防御姿势：嘴硬、沉默、假笑、装不在乎。
记忆点：一个能反复出现的压抑动作。
```

禁止：

1. 只写“漂亮、冷艳、霸气”。
2. 开场让角色解释背景。
3. 每场戏都换造型，破坏连续性。

### 5.2 广告人物

重点：像真实使用者，不像卖点播报员。

```text
第一眼：他正在被一个具体问题卡住。
服装功能：使用场景可信。
身体习惯：先处理问题，再说短句。
防御姿势：怕麻烦、怕浪费、怕被看见窘迫。
记忆点：产品介入后身体松下来的一秒。
```

禁止：

1. 一出场就笑着展示产品。
2. 服装像棚拍模特，不像真实场景。
3. 让角色背参数和口号。

### 5.3 可爱治愈角色

重点：小主体有大任务，萌点来自认真动作。

```text
第一眼：小身体正在承担超出能力的任务。
体态轮廓：圆、短、软，但动作清楚。
服装/配件：一个小标志就够。
身体习惯：失败后先停一下，再悄悄补救。
声音习惯：短、轻、慢半拍。
记忆点：一个固定小动作或表情包姿势。
```

禁止：

1. 堆太多配件。
2. 表情一直夸张。
3. 群像角色互相融合。

### 5.4 特摄英雄/怪兽/反派

重点：轮廓和规则第一眼成立。

```text
第一眼：姿态、轮廓和能力规则能被看懂。
服装功能：保护、仪式、限制或能力来源。
身体习惯：登场前有固定仪式动作。
防御姿势：反派控制空间，英雄保护身后的人。
记忆点：一个可复述的登场姿态或手部动作。
```

禁止：

1. 复刻已有 IP 角色造型。
2. 一镜完成复杂变身、飞行、爆炸和打斗。
3. 只靠发光特效，没有姿态和规则。

### 5.5 企业/品牌人物

重点：可信度来自具体任务。

```text
第一眼：正在解决真实工作问题。
服装功能：职业可信，但不过度样板。
身体习惯：看数据、递文件、停顿确认、和团队交换眼神。
声音习惯：短句、稳、少口号。
记忆点：一个协作动作或客户反应。
```

禁止：

1. 全员西装鼓掌。
2. 大楼空镜替代人物可信度。
3. 让人物像 PPT 旁白。

## 6. 服装和道具规则

服装不是美术摆设，要承担至少一个任务：

| 服装任务 | 示例 |
| --- | --- |
| 身份 | 工装、围裙、校服、运动服、实验服 |
| 状态 | 皱、湿、旧、没扣好、袖口卷起 |
| 性格 | 整齐、随意、克制、夸张、过度防御 |
| 关系 | 两人同色但不同材质，显示亲近或疏离 |
| 品牌 | 品牌色点缀，不硬贴 Logo |
| 动作 | 袖口方便手部证明，外套限制动作 |

道具必须能被角色使用：

```text
角色拿它、藏它、擦它、递它、压住它、修它、避开它。
```

如果道具只是装饰，不进入镜头任务，就删。

## 7. Seedance 角色锁定字段

每条含角色的 Seedance 提示词增加：

```text
角色第一眼：
角色锁定三件套：
体态轮廓：
服装功能：
标志道具：
身体习惯：
防御姿势：
声音习惯：
本镜动作：
禁止变化：
```

压缩版锁定句：

```text
角色始终保持【体态轮廓】、【服装核心】、【标志道具】和【身体习惯】；本镜只改变【动作/情绪状态】，不改变年龄、脸型、服装和道具。
```

三件套锁定句：

```text
角色始终保持同一【体态轮廓】、同一【功能道具】和同一【身体习惯】；所有镜头只改变本镜任务、情绪状态或站位，不改变年龄感、脸型、发型、服装核心、道具功能和固定动作习惯。
```

## 8. 常见错误与第一刀

| 错误 | 症状 | 第一刀 |
| --- | --- | --- |
| 角色只有形容词 | 高级、可爱、霸气但不可见 | 改成体态、服装、道具和动作 |
| 服装只为好看 | 看不出身份和场景 | 给服装一个任务 |
| 广告人物像模特 | 不像真实使用者 | 加一个具体问题和手部动作 |
| 可爱角色太满 | 配件多、表情乱 | 只留一个标志配件和一个小动作 |
| 反派只会凶 | 没有控制空间的方式 | 给他一个阻碍动作和站位优势 |
| 多镜头角色漂 | 脸、服装、道具变化 | 写 Seedance 锁定句和禁止变化 |
| 角色不像品牌 | 气质和品牌人格错位 | 写品牌人格三词和禁用三词 |

## 9. 与其他能力衔接

默认顺序：

```text
人物动机、关系弧线与角色导演库
-> 角色第一眼、选角质感与造型记忆协议
-> 视觉风格与美术指导库
-> 跨镜头场记、角色道具连续性与空间一致性
-> 现场表演调度与情绪动作谱库
-> Seedance 提示词终检与负面约束压缩器
```

分工：

1. 人物动机决定角色为什么这样做。
2. 本协议决定角色第一眼怎么被看见。
3. 视觉风格决定全片美术一致性。
4. 场记连续性保证多镜头不漂。
5. 表演调度把防御姿势变成微动作。
6. 提示词终检压缩成最终生成字段。

## 10. 自检闸门

输出角色方案前检查：

1. 是否写清角色功能？
2. 第一眼是否能静音看懂？
3. 服装是否有功能？
4. 道具是否会被使用？
5. 是否有身体习惯和防御姿势？
6. 是否有声音习惯？
7. 是否有 Seedance 锁定句和禁止变化？
8. 是否写清角色锁定三件套：体态轮廓、功能道具、身体习惯？
9. 每镜允许改变项是否只有一个，而不是同时改造型、道具、动作和情绪？

## 11. 最小合格线

一次角色第一眼设计至少要输出：

1. 角色功能。
2. 第一眼关键词。
3. 体态轮廓。
4. 服装功能。
5. 标志道具。
6. 身体习惯。
7. 防御姿势。
8. Seedance 锁定句。
9. 禁止变化。
10. 角色锁定三件套。
11. 本镜允许改变项。

少一项，就只是角色形容，不是能拍、能演、能生成的角色设计。
