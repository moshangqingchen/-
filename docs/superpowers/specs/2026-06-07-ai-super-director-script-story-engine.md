# AI超级导演剧本结构与故事引擎库

## 1. 使用方式

这份库用于把一句灵感发展成可拍、可分镜、可生成的故事结构。它服务短片、短剧、创意广告、可爱搞笑、治愈情感、特效动作和系列IP。

默认设计顺序：

1. 找主角或主体。
2. 找欲望。
3. 找阻碍。
4. 找代价。
5. 找升级。
6. 找反转。
7. 找情绪落点。
8. 拆成场次和分镜。

## 2. 故事核心公式

```text
谁 + 想要什么 + 为什么现在必须要 + 谁/什么挡住他 + 代价如何变大 + 他如何选择 + 结尾留下什么
```

拆解：

- 谁：主角、产品、群像、旧物、品牌角色或事件主体。
- 想要什么：得到、逃离、证明、保护、修复、隐藏、重逢。
- 为什么现在必须要：时间限制、误会爆发、危险到来、机会消失。
- 谁/什么挡住他：对手、规则、身份、恐惧、误会、现实条件。
- 代价如何变大：失去关系、暴露秘密、任务失败、伤害自己、错过机会。
- 他如何选择：主动行动，而不是等剧情推着走。
- 结尾留下什么：释放、悬念、记忆点、品牌动作或余味。

## 3. 人物欲望库

### 3.1 外在欲望

角色表面上想要的东西：

- 赢一场比赛。
- 找到一个人。
- 卖出一个产品。
- 逃离危险。
- 完成任务。
- 证明自己。
- 隐藏秘密。
- 得到原谅。

### 3.2 内在欲望

角色真正想要的东西：

- 被看见。
- 被理解。
- 被接住。
- 不再害怕。
- 不再孤单。
- 证明自己值得被爱。
- 修复过去的遗憾。
- 找回生活的秩序。

### 3.3 欲望自检

1. 主角想要的东西是否具体？
2. 观众是否能在10秒内理解？
3. 如果主角失败，会失去什么？
4. 欲望能不能转成动作？

## 4. 阻碍库

### 4.1 人物阻碍

- 对手。
- 误会者。
- 嘴硬的人。
- 爱他但不理解他的人。
- 更强的竞争者。
- 隐藏真相的人。

### 4.2 环境阻碍

- 时间限制。
- 空间限制。
- 天气。
- 距离。
- 规则。
- 贫穷、年龄、身份差距。

### 4.3 内心阻碍

- 不敢说。
- 不愿承认。
- 害怕失去。
- 认为自己不配。
- 对过去愧疚。
- 嘴硬或自尊。

### 4.4 阻碍自检

1. 阻碍是否具体？
2. 阻碍是否能逼主角行动？
3. 阻碍是否能升级？
4. 阻碍是否和主题有关？

## 5. 冲突升级

### 5.1 三段升级

```text
小麻烦 -> 真问题 -> 必须选择
```

例子：

- 广告：使用不便 -> 影响工作/生活 -> 产品介入解决。
- 短剧：一句误会 -> 关系破裂 -> 真相反转。
- 打斗：试探 -> 被压制 -> 付代价反击。
- 情感：看到旧物 -> 想起遗憾 -> 当下做出回应。

### 5.2 代价升级

常见代价：

- 时间变少。
- 关系变坏。
- 秘密暴露。
- 身体受伤。
- 产品痛点扩大。
- 选择变得不可逆。

### 5.3 升级自检

1. 中段是否发生新变化？
2. 代价是否变大？
3. 主角是否被迫主动选择？
4. 升级是否服务结尾反转或释放？

## 6. 反转设计

### 6.1 反转公式

```text
观众以为A + 前面埋了B的证据 + 关键时刻揭示B + 情绪或行动改变
```

### 6.2 常见反转类型

身份反转：

- 看似普通的人其实是关键人物。
- 看似弱小的人有隐藏能力。

动机反转：

- 看似阻碍的人其实在保护主角。
- 看似冷漠的人一直在默默帮助。

信息反转：

- 观众和角色知道的信息不同。
- 一条消息、一张照片、一个旧物改变理解。

能力反转：

- 主角不是更强，而是更懂规则。
- 打斗胜负来自空间、道具或心理，而不是蛮力。

广告反转：

- 观众以为是麻烦，结果是产品卖点的证明。
- 观众以为是普通物品，结果是解决问题的关键。

### 6.3 反转自检

1. 反转前有没有伏笔？
2. 反转后情绪是否改变？
3. 反转是否能重新解释前面的镜头？
4. 反转是否服务人物、卖点或主题？

## 7. 情绪弧线

### 7.1 治愈弧

```text
疲惫 -> 被看见 -> 被接住 -> 慢慢松开 -> 安静落点
```

### 7.2 情感弧

```text
旧物触发 -> 忍住 -> 回忆浮现 -> 当下回应 -> 留白
```

### 7.3 搞笑弧

```text
正常规则 -> 误解 -> 认真执行 -> 意外升级 -> 反应收尾
```

### 7.4 爽剧弧

```text
被压制 -> 代价变大 -> 伏笔显现 -> 反转释放 -> 新悬念
```

### 7.5 打斗弧

```text
目标明确 -> 试探 -> 被压制 -> 失误/疼痛 -> 反击 -> 胜负代价
```

### 7.6 广告弧

```text
痛点 -> 产品介入 -> 变化显现 -> 证据证明 -> 品牌记忆
```

## 8. 场次结构

### 8.1 15秒

```text
钩子 -> 介入 -> 结果 -> 记忆点
```

### 8.2 30秒

```text
问题 -> 主体/产品 -> 行动 -> 对比 -> 收束
```

### 8.3 60秒

```text
强开场 -> 建立欲望 -> 第一次升级 -> 第二次升级 -> 释放/悬念
```

### 8.4 3分钟

```text
引子 -> 建立 -> 行动 -> 升级 -> 转折 -> 落点
```

### 8.5 5分钟

```text
强开场 -> 第一场欲望 -> 第二场行动 -> 第三场爆点 -> 第四场反转 -> 结尾悬念/余味
```

## 10. 故事失败修复

### 10.1 开头弱

修法：

- 提前最强冲突。
- 把解释删掉。
- 用动作开场。
- 用一句危险台词开场。

### 10.2 中段平

修法：

- 增加新代价。
- 增加信息差。
- 增加倒计时。
- 增加第三方打断。

### 10.3 结尾散

修法：

- 回到主角欲望。
- 回到产品卖点。
- 回到旧物。
- 留一个动作、台词或画面悬念。

### 10.4 反转假

修法：

- 前面补伏笔。
- 让反转来自人物选择。
- 让反转改变行动后果。
- 不靠突然解释。

### 10.5 情绪空

修法：

- 增加具体物件。
- 增加人物小动作。
- 增加没说出口的话。
- 减少口号式台词。

## 12. 导演自检

1. 谁想要什么？
2. 为什么现在必须要？
3. 谁或什么挡住了他？
4. 代价是否变大？
5. 反转是否有伏笔？
6. 情绪是否有变化？
7. 结尾是否留下记忆点、余味、悬念或转化动作？
