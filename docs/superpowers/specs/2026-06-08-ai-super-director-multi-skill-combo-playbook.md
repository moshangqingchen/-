# AI超级导演多能力组合调用范例包

## 1. 定位

这份范例包解决“能力知道很多，但临场不知道怎么串”的问题。真实需求往往不是单一类型：一个可爱广告同时需要广告证明、治愈调度、审美取舍、Seedance 风险控制和发布包装；一个短剧开场同时需要冲突链、口型、空间站位、第一镜和追更钩子。

本范例包不是黄金样例，也不是总索引。黄金样例回答“做到什么程度算好”；总索引回答“有哪些能力”；本范例包回答：

```text
这类需求来了，几张能力卡应该按什么顺序一起上。
```

## 2. 使用原则

1. 先选主组合，不平均展开所有能力。
2. 每个组合只显性调用 3-6 个关键能力。
3. 防错、字幕后期、Logo 后期、Seedance 降难默认隐性执行。
4. 输出先给导演判断，再给组合链，再进入实际内容。
5. 组合链服务成片，不服务炫耀能力目录。

默认开口：

```text
我会这样拍：这条需求我不平均展开，先走【主组合】。
```

## 3. 组合一：可爱治愈产品广告

### 3.1 用户信号

```text
做一个可爱治愈广告 / 萌一点但要卖点 / 温柔信息流 / 小动物带货 / 咖啡、甜品、家居小物广告
```

### 3.2 调用顺序

```text
现场判断中枢
-> 审美取舍罗盘：温柔治愈
-> 创意广告、产品证明与转化镜头引擎
-> 可爱治愈导演调度
-> Seedance 可生成性拆镜
-> 输出档位：标准分镜卡或 Seedance 执行卡
```

### 3.3 仲裁

产品证明高于卖萌。可爱只能服务“产品解决了什么”，不能让产品变成摆设。

### 3.4 输出骨架

```text

产品证明动作：
第一帧：
分镜：

防错检查：
```

## 11. 组合调用自检

输出前问：

1. 我选的是哪一条主组合？
2. 主能力是否明确？
3. 辅助能力有没有超过 6 个？
4. 有没有把防错规则隐性处理，而不是把目录念出来？
5. 有没有把组合链落成实际输出骨架？
6. Seedance、字幕、Logo、口型、群像和参考合规是否处理？
7. 用户下一步能不能直接确认、拍摄、生成、返工或发布？

## 12. 最小合格线

一次组合调用至少要给出：

1. 主组合名称。
2. 3-6 个调用能力。
3. 一条仲裁判断。
4. 输出骨架。
5. 高风险默认处理。
6. 下一步动作。

如果只是列一堆能力名，没有把它们变成拍法，就不算组合调用。
