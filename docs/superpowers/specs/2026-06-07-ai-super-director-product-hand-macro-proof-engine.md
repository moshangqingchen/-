# AI超级导演产品手部证明、微距动作与材质证据导演引擎

## 1. 定位

这套引擎专门处理产品广告、种草、直播切片、开箱测评、功能证明、美妆护肤、食品饮品、家居好物、数码工具和车品装备里最容易翻车的一类镜头：手在画面里做了动作，但观众没有看懂产品到底证明了什么。

它不替代创意广告证明链，也不替代直播带货引擎。它负责把“产品动作”拍成可见证据：手怎么拿、怎么按、怎么倒、怎么擦、怎么贴合、怎么开箱、怎么展示材质、结果怎么出现、人物怎么确认。

默认判断：

```text
我会这样拍：这类镜头不要先夸产品，也不要把镜头贴到看不清。先让手承担一个小任务，让产品只完成一个动作，再给一个可见变化和半秒确认。手部动作清楚，证据才成立。
```

核心公式：

```text
观众质疑 + 手部任务 + 产品动作 + 微距证据 + 结果变化 + 反应确认 + 保底出点
```

## 3. 手部证明不是手部摆拍

手部镜头有三种常见失败：

1. 手太忙：一镜里又开箱、又说明、又展示、又反应。
2. 镜头太近：质感变成一团纹理，产品轮廓和动作因果看不清。
3. 结果缺席：手做了动作，但画面没有变化，观众只能听卖点。

导演判断：

```text
手部镜头只做一件事：把卖点变成动作证据。
```

每条手部证明镜头必须回答：

1. 观众最不信哪一句卖点？
2. 手要完成什么小任务？
3. 产品动作从哪里开始，到哪里结束？
4. 证据出现在表面、声音、形变、秩序、速度、轻重还是人物身体上？
5. 结果由谁确认：手、眼神、停顿、二次动作还是画外声？

## 5. 微距证据层

微距不是越近越好。微距只负责让观众看见“普通镜头看不见的证据”。

| 证据层 | 画面看什么 | 适合卖点 | 风险 |
| --- | --- | --- | --- |
| 表面层 | 纹理、污渍、粉感、水珠、划痕 | 材质、清洁、护肤、食品 | 太近会失去产品轮廓 |
| 边缘层 | 贴合线、缝隙、接口、拉链、包装口 | 精准、密封、顺滑、工艺 | 手容易遮挡关键边缘 |
| 形变层 | 回弹、折叠、压缩、弯曲、吸附 | 弹性、耐用、省空间 | 形变过大容易像特效 |
| 流动层 | 液体、粉末、泡沫、蒸汽、油脂 | 口感、质地、清洁、护肤 | 流动不稳定，需拆短镜 |
| 声音层 | 咔哒、撕开、倒出、吸住、擦过 | 可靠、清爽、仪式感 | 需要后期补声音，不靠画面文字 |
| 秩序层 | 从乱到整、从卡顿到顺、从混浊到清 | 效率、收纳、修复 | 前后构图必须一致 |
| 身体层 | 肩膀放松、手腕不累、眼神确认 | 舒适、轻便、省心 | 不要夸张表演 |

## 6. 三段式手部证明

### 6.1 起手：让观众知道任务

```text
手从画面边缘进入，先停在问题前：污渍、乱线、未打开的包装、卡住的按钮、褶皱的布料。
```

要点：

- 起手不要太快。
- 问题和产品要同框或连续明确。
- 不要一上来就是产品美拍。

### 6.2 动作：只证明一个卖点

```text
手完成一个动作：按下、擦过、抹开、倒出、装入、扣上或拉开。
```

要点：

- 一镜只做一个动作方向。
- 镜头稳定或轻微跟随，不做大幅摇晃。
- 手、产品、证据三者不要互相遮挡。

### 6.3 确认：让结果落地

```text
动作结束后停半秒，手不急着离开；人物看一眼、手指二次确认，或声音落下。
```

要点：

- 反应确认比口播夸奖更可信。
- 结果最好在同一构图内出现。
- 出点要能剪：手收回、产品停稳、盖子扣上、声音落下。

## 8. Seedance 2.0 可生成性规则

手部、微距和产品证明是 Seedance 的中高风险镜头，默认按以下规则降难：

1. 一镜只做一个动作，不把开箱、试用、反应和口播塞在一起。
2. 手部数量尽量一双以内，避免多只手交叉操作。
3. 产品外形、颜色和摆放方向必须在风格锁定句中固定。
4. 包装字、屏幕字、成分字、价格、Logo 和可读中文默认后期添加。
5. 微距镜头控制在 3-5 秒，动作链最多三步。
6. 结果变化如果复杂，拆成“动作镜头 + 结果镜头 + 反应镜头”。
7. 液体、粉末、烟雾、泡沫、透明材质和镜面反光优先试拍一条小样。

可生成性评级：

| 镜头 | 风险 | 处理 |
| --- | --- | --- |
| 单手按按钮，灯光响应 | A | 可直接生成 |
| 指腹抹开护肤品，皮肤微变化 | B | 控制近景，效果不过度 |
| 倒出液体并同时人物说话 | C | 拆成倒出 + 反应/画外声 |
| 多人同时开箱、讲解、展示包装字 | D | 重做方案，文字后期加 |
| 透明液体、镜面瓶身、可读包装同框 | C | 固定构图，包装字后期加 |

## 12. 自检

输出前检查：

1. 是否先定了观众最不信的问题？
2. 本镜是否只证明一个卖点？
3. 手部动作是否从起点、过程到结果都清楚？
4. 微距证据是否有产品轮廓和动作因果，不只是漂亮纹理？
5. 结果变化是否能被画面看见？
6. 是否有反应确认，而不是只靠口播夸？
7. 是否给了保底出点，方便剪到下一镜？
8. 包装字、Logo、价格、参数、成分和可读中文是否规划为后期添加？
9. 高风险液体、粉末、透明材质、镜面反光或复杂开箱是否拆镜或先试拍？
