# AI超级导演多人物群像调度与对白秩序系统

## 1. 定位

这份手册专门处理多人物、群像、团队、教室、办公室、饭桌、会议、家庭、短剧对峙、可爱群像和多人对白。

群像最容易坏在三件事：

1. 角色站位乱，上一镜在左，下一镜忽然换到右。
2. 所有人同时动、同时说，Seedance 2.0 容易融合、抢口型、动作变形。
3. 每个角色都想表现，最后没有主次，笑点、冲突和情绪都散掉。

本系统的目标是：先定群像秩序，再写镜头。让每个角色在镜头里有清楚职责，而不是一起挤进画面。

## 2. 默认导演判断

```text
我会这样拍：
群像不能靠人多热闹，得靠秩序。先把谁是主动作、谁是阻碍、谁是误会、谁是反应、谁是收尾定住；同一镜只让一个人承担主要动作或主要台词，其他人只给轻反应。
```

第一刀：

- 人物超过 4 个时，不先写台词，先写站位。
- 同框超过 3 个主要动作时，拆镜。
- 多人同时说话，改成正反打、单人短句、群像反应或画外声。
- 群像喜剧先要反应顺序，群像短剧先要权力站位。

## 3. 群像角色职能

多人物场景先把角色分成五类：

| 职能 | 作用 | 可拍动作 | 风险 |
| --- | --- | --- | --- |
| 主动作角色 | 负责推动本镜事件 | 递出、走近、按下、拿起、停住 | 同时说长台词 |
| 阻碍角色 | 制造冲突或压力 | 挡路、打断、靠近、压住道具 | 动作太大抢主角 |
| 误会角色 | 制造笑点或信息差 | 慢半拍、看错、拿错、反应错 | 变成乱演 |
| 反应角色 | 让事件可信 | 看向、停顿、眨眼、退半步 | 反应太满 |
| 收尾角色 | 接住情绪、笑点或温柔 | 轻声补一句、递物、点头、沉默 | 解释太多 |

群像里每个人不能都是主角。每一镜只指定一个“主动作角色”，最多一个“主说话人”。

## 4. 站位秩序

### 4.1 先画空间

多人物场景默认先写：

```text
空间方向：
中心物：
入口：
出口：
主角位置：
阻碍者位置：
旁观者位置：
反应角色位置：
摄影机默认站边：
不可变化的站位：
```

示例：

```text
空间方向：竖屏，桌子横在画面下方，门在画面左后方，窗在右后方。
中心物：桌面上的红色便签。
主角位置：桌子右前方。
阻碍者位置：桌子左前方，挡住主角去路。
旁观者位置：后方两侧，只做轻微反应。
摄影机默认站边：桌子正前方偏右，不跨越主角和阻碍者之间的关系线。
不可变化的站位：主角始终在画面右侧，阻碍者始终在画面左侧。
```

### 4.2 常用站位阵型

| 阵型 | 适合场景 | 调度重点 |
| --- | --- | --- |
| 半圆围中心 | 可爱群像、会议、产品证明 | 所有人看同一个中心物 |
| 左右对峙 | 短剧冲突、谈判、打脸 | 权力关系清楚，不跳轴 |
| 前后压力 | 审问、家庭压力、办公室上级 | 前景压迫，后景旁观 |
| 桌面低机位 | 幼儿园、玩具、软萌群像 | 小角色有体积，动作清楚 |
| 门口阻拦 | 关系拉扯、离开、反杀前 | 谁控制出口谁有权力 |
| 产品三角 | 广告、种草、功能证明 | 人物、产品、结果形成三角 |

## 5. 说话顺序

多人对白不是谁都开口。先排说话顺序：

```text
主说话人 -> 被打断者反应 -> 第二说话人短句 -> 群像停顿 -> 收尾角色补一句
```

口型规则：

- 一镜一个主要说话人。
- 画内台词尽量 3-8 个汉字，最长不超过 12 个汉字。
- 群像中景只建立位置，不承担长台词。
- 关键信息交给近景、画外声、字幕或后期配音。
- 多人同框时，非说话人只做眼神、手部、身体重心的轻反应。

示例拆法：

```text
镜头1：群像中景，建立四人站位，没有人说话。
镜头2：A中近景，说：“别签。”
镜头3：B反应近景，手停住，没说话。
镜头4：C过肩短句，说：“已经签了。”
镜头5：群像停顿，所有人看向桌面。
```

### 5.1 群像对白轴线闸门

多人对白不能只排台词，还要排“谁看谁、谁在画面哪边、嘴在不在画面里”。如果轴线没锁，观众会迷路；如果主说话人没锁，Seedance 2.0 会抢口型；如果听者反应没接住，剪辑会断。

每个多人对白段落先过这张闸门：

| 字段 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 对话轴线 | 主要关系线是谁到谁，中心物在不在线上 | 只写“大家聊天” |
| 摄影机站边 | 本段默认站在线的哪一侧，何时允许换边 | 正反打左右乱跳 |
| 主说话人 | 本镜唯一画内开口的人 | 两三个人同框抢话 |
| 听者位置 | 听的人在画面左/右/前/后，是否看向说话人或中心物 | 听者无反应 |
| 嘴部可见度 | 主说话人是近景/中近景，嘴无遮挡 | 远景说关键句 |
| 说前停顿 | 开口前停几拍，视线落在哪 | 一上来张嘴 |
| 收口反应 | 说完后看谁、手停在哪、下一镜接谁 | 台词说完直接断 |
| 兜底镜头 | 口型失败时用哪条反应镜、插入镜或画外声替换 | 把成败全押在口型 |

硬规则：

- 群像中景只负责建立站位或集体反应，不承担关键长台词。
- 正反打必须保持同一对话轴线；换边要用中心物、人物走位或插入镜解释。
- 一镜最多一个主说话人；如果两个人都必须说，拆成两镜，中间加听者反应。
- 主说话人开口时，其他人只做眼神、手部或身体重心的轻反应，不张嘴抢口型。
- 台词落点之后必须接一个听者反应、中心物插入、静音点或声音桥，不能让对白悬空。

快速输出格式：

| 镜头 | 对话轴线 | 摄影机站边 | 主说话人 | 听者位置 | 台词 | 嘴部可见度 | 收口反应 | 兜底镜头 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| [编号] | [A-B/人物-中心物] | [线哪侧] | [唯一开口者] | [左/右/前/后] | [3-12字] | [近景/中近景] | [说完后的动作] | [反应/插入/画外声] |

## 6. 反应顺序

群像情绪不是同时爆发，而是像波纹一样传开。

默认反应顺序：

```text
事件发生 -> 离事件最近的人先停住 -> 主角眼神变化 -> 阻碍者压住反应 -> 旁观者慢半拍 -> 收尾角色接住
```

类型反应顺序：

| 类型 | 反应顺序 |
| --- | --- |
| 可爱搞笑 | 认真角色宣布 -> 慢半拍误解 -> 捣乱角色升级 -> 集体沉默 -> 温柔角色收尾 |
| 短剧冲突 | 压迫者先逼近 -> 主角忍住 -> 旁观者交换眼神 -> 证据出现 -> 权力反转 |
| 广告产品 | 用户困住 -> 产品介入 -> 使用者确认 -> 旁观者认可 -> 产品和结果同框 |
| 治愈情感 | 受伤者抗拒 -> 介入者停住 -> 手部靠近 -> 身体放松 -> 群像安静 |
| 打斗特效 | 触发者动作 -> 最近角色闪避 -> 受力者结果 -> 旁观者确认方向 -> 主角再行动 |

## 7. Seedance 2.0 群像风险控制

### 7.1 同框人数建议

| 同框人数 | 建议 | 风险 |
| --- | --- | --- |
| 1人 | 适合口型、情绪、关键动作 | 低 |
| 2人 | 适合对峙、过肩、关系变化 | 中低 |
| 3人 | 适合小群像和产品三角 | 中 |
| 4人 | 只建议中景建立秩序或集体反应 | 中高 |
| 5人以上 | 拆成小组、反应近景和群像定格 | 高 |

### 7.2 一镜一任务

每条 Seedance 2.0 群像提示词必须写清：

```text
本镜主动作角色：
本镜主说话人：
其他角色反应：
固定站位：
禁止：
```

示例：

```text
本镜主动作角色：小班长。
本镜主说话人：小班长，只说一句“月亮请假了”。
其他角色反应：右侧慢半拍同学眨眼，后方爱哭同学抱紧纸盒，老师只轻轻低头。
固定站位：小班长始终在桌子左前方，慢半拍同学在右前方，老师在后方。
禁止：所有角色同时说话、同时跑动、角色位置互换、镜头绕圈。
```

## 8. 类型调度卡

### 8.1 可爱群像卡

```text
卡名：小会议秩序卡
空间：桌面低机位，角色围绕中心物半圆站位。
主动作：一个小角色认真执行荒诞任务。
说话顺序：认真角色一句短句 -> 慢半拍角色反应 -> 捣乱角色小动作 -> 群像停顿。
镜头身体：群像卡或桌面旁观卡。
Seedance拆法：群像中景建立秩序 -> 单人动作近景 -> 群像反应定格。
```

### 8.2 短剧对峙卡

```text
卡名：左右权力对峙卡
空间：主角在画面右侧，压迫者在画面左侧，证据在中间。
主动作：压迫者靠近或挡住出口。
说话顺序：压迫者短句 -> 主角沉默 -> 旁观者反应 -> 主角反杀短句。
镜头身体：过肩卡、旁观卡、反应近景。
Seedance拆法：双人中景定轴线 -> 过肩压迫 -> 主角反应 -> 证据特写 -> 反杀短句。
```

### 8.3 办公室/会议卡

```text
卡名：桌面权力卡
空间：会议桌为中心，领导在画面后方中间，主角在右前方，旁观者分列两侧。
主动作：文件、产品或证据被放到桌面中心。
说话顺序：领导一句 -> 主角停顿 -> 旁观者看向文件 -> 主角一句短答。
镜头身体：旁观卡、道具卡、过肩卡。
Seedance拆法：群像中景建立秩序 -> 文件特写 -> 主角反应 -> 单人短句。
```

### 8.4 家庭饭桌卡

```text
卡名：饭桌沉默卡
空间：饭桌为中心，关系压力通过座位距离体现。
主动作：某个物件被放下，或某个人停筷。
说话顺序：长辈一句 -> 主角不答 -> 旁人低头 -> 主角短句。
镜头身体：旁观卡、手部卡、反应近景。
Seedance拆法：饭桌中景 -> 手部停筷 -> 主角眼神 -> 画外声或短句。
```

### 8.5 产品多人证明卡

```text
卡名：产品三角证明卡
空间：使用者、产品、结果形成三角。
主动作：产品介入痛点。
说话顺序：使用者不先解释，先看结果；旁观者一句短认可；卖点文字后期加。
镜头身体：道具卡、第二人称卡、旁观卡。
Seedance拆法：痛点中景 -> 产品动作特写 -> 结果变化 -> 人物反应 -> 品牌记忆帧。
```

## 10. 自检

输出多人物或群像方案前，自问：

1. 是否先写了空间方向和中心物？
2. 是否固定了主角、阻碍者、旁观者和反应角色的位置？
3. 每一镜是否只有一个主动作角色？
4. 每一镜是否最多一个主要说话人？
5. 画内台词是否尽量 3-8 个汉字，最长不超过 12 个汉字？
6. 非说话人是否只做轻反应？
7. 多人对白是否写清对话轴线、摄影机站边和听者位置？
8. 主说话人的嘴部是否近景或中近景可见，且无遮挡？
9. 台词落点后是否有听者反应、中心物插入、静音点或声音桥兜底？
10. 群像反应是否有顺序，而不是所有人一起乱动？
11. 同框超过 4 人时是否拆成小组或反应近景？
12. 是否写清摄影机站边，避免左右跳？
13. Seedance 2.0 提示词是否写了固定站位和禁止项？
