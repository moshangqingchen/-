# AI超级导演不出错工具化防错协议

## 1. 定位

这份协议让 AI超级导演从“会写方案”继续进化成“会自检、会降难、会防穿帮、会稳定交付”的超级工具。它不承诺绝对不会出错，而是要求每次输出前主动拦住高概率错误，并给出可执行的修正方法。

核心判断：

```text
先防错，再炫技。
先稳住人物、空间、动作和交付项，再追求更炸、更美、更复杂。
```

默认目标：

1. 路由不乱：用户一句话进来，先选主入口，不平均展开所有能力。
2. 风格不漂：多镜头项目先锁定统一风格句。
3. 人物不漂：角色、服装、道具、空间方向跨镜头保持一致。
4. 动作不乱：复杂动作先拆成起点、触发点、受力结果和反应。
5. 口型不穿帮：一镜只保一个主说话人，长对白默认拆镜或后期配音。
6. 文字不乱码：中文、Logo、品牌字、字幕默认后期添加。
7. 交付不漏项：客户方案补齐分镜、提示词、后期、声音、发布、合规和审片。
8. 返工不乱改：每轮只改一个变量，失败后再拆镜或换关键帧。

## 2. 十大常见错误与第一刀

| 错误 | 典型表现 | 第一刀 |
| --- | --- | --- |
| 需求路由错 | 用户要分镜，却先写大段理论 | 先判断交付物：创意、分镜、Seedance、完整方案、审片、返工 |
| 类型平均用力 | 可爱、特效、广告、短剧全塞满 | 定主类型、副类型和禁用项 |
| 第一帧不抓人 | 从背景介绍、世界观、品牌理念开始 | 改成反常结果、选择压力、动作中点或情绪缺口 |
| 人物像工具人 | 只服务情节，没有欲望和防御 | 补外在欲望、内在缺口、防御动作和关系变化 |
| 群像混乱 | 多人同框说话、角色融合、站位跳 | 定中心物、站位、说话顺序、反应顺序 |
| 打斗特效乱 | 一镜里飞行、爆炸、攻击、受伤全要 | 拆成 4-6 秒动作因果镜头 |
| 产品卖点空 | 只说高级、好用、效率提升 | 改成手部任务、产品动作、微距证据、结果变化 |
| 口型穿帮 | 长台词、多人口播、嘴部不可见 | 短句、近景、单说话人；长句改画外声或后期字幕 |
| 文字乱码 | 让视频模型直接生成中文、Logo、屏幕字 | 提示词只留干净安全区，文字后期添加 |
| 返工失控 | 一次改风格、机位、动作、角色、时长 | 本轮只改一个变量，并写通过标准 |

## 3. 输出前质量门禁

每次输出前，按任务类型走对应门禁。

### 3.1 创意门禁

必须回答：

1. 这条片一句话到底拍什么？
2. 第一帧有什么反常、压力或可截图点？
3. 主角或主体在做什么具体动作？
4. 结尾有没有记忆点、声音回声或余味动作？

失败处理：

```text
如果只剩概念和形容词，退回情绪命题，把它改成动作、道具、选择和反应。
```

### 3.2 分镜门禁

必须回答：

1. 空间方向清不清楚？
2. 人物从哪里来，到哪里去？
3. 每镜有没有入点和出点？
4. 镜头之间靠动作、视线、声音还是情绪连接？
5. 有没有主镜头、反应镜头和保底镜头？

失败处理：

```text
如果剪不起来，先补建立镜头、反应保险和插入证据，不继续堆新镜头。
```

### 3.3 Seedance 门禁

必须回答：

1. 风格锁定句是否统一？
2. 每条提示词是否能独立生成？
3. 动作因果是否清楚？
4. 运镜是否克制？
5. 有没有字幕安全区和禁止项？
6. 高风险镜头有没有降难版本？

失败处理：

```text
如果一镜承担太多任务，拆成主动作镜头、反应镜头和证据镜头。
```

### 3.4 广告门禁

必须回答：

1. 观众最不信什么？
2. 产品动作如何介入？
3. 结果变化在哪里看见？
4. 人物反应是否证明了变化？
5. 品牌记忆帧能不能截图复用？

失败处理：

```text
如果只有口号，把卖点改成痛点可视化、手部动作、证据镜头和反应确认。
```

### 3.5 短剧门禁

必须回答：

1. 主角想要什么？
2. 谁阻止他？
3. 关系压力在哪里？
4. 信息差谁知道、谁不知道？
5. 第一镜是否先给冲突而不是背景？
6. 结尾是否留下下一集问题？

失败处理：

```text
如果冲突太晚，把开场改成危险、反常结果、身份问题或被迫选择。
```

### 3.6 客户交付门禁

必须回答：

1. 是否有导演判断、保留、舍掉和第一刀？
2. 是否有分镜表和逐镜提示词？
3. 是否有后期文字、声音、封面标题和发布包装？
4. 是否有可生成性评级和拆镜策略？
5. 是否有合规提醒和审片评分？

失败处理：

```text
如果只给创意和分镜，补齐交付包；客户方案不能像灵感草稿。
```

### 3.7 返工门禁

必须回答：

1. 原镜头目标是什么？
2. 跑偏原因是什么？
3. 本轮只改哪一个变量？
4. 必须锁住什么？
5. 必须删掉什么？
6. 通过标准是什么？

失败处理：

```text
如果连续两轮失败，不继续微调同一条提示词，改为拆镜、换机位或重做首帧。
```

## 4. 最终一口气复核闸门

复杂输出写完后，不要急着交付。最后必须用一口气把方案压回四件事，确认它不是“看起来很完整，实际上执行时会散”。

一口气复核：

```text
这版真正要拍的是【一个主场面】；
必须保住的是【一个主动作或主证据】；
最可能坏在【一个主风险】；
第一刀只改【一个变量】；
通过标准是【一个可检查结果】。
```

如果这五项说不清，说明方案还没稳，必须退回上一层门禁，不继续扩写。

复核失败处理：

| 说不清的项 | 代表的问题 | 第一刀 |
| --- | --- | --- |
| 主场面说不清 | 类型和交付目标混在一起 | 回到主入口和主类型判断 |
| 主动作说不清 | 画面只剩氛围和概念 | 改成手部、身体、产品或关系动作 |
| 主风险说不清 | 没有真正做防错 | 从角色、动作、空间、口型、文字和剪辑里选一个 |
| 第一刀说不清 | 改稿会变成全案重写 | 只选一个变量，其余锁住 |
| 通过标准说不清 | 交付后无法验收 | 写成观众能懂、模型能跑、客户能执行或剪辑能接 |

一口气复核禁忌：

1. 不要写三个主场面。
2. 不要把“更高级、更电影感、更有爆点”当主动作。
3. 不要同时列多个最大风险。
4. 不要把第一刀写成“整体优化”。
5. 不要把通过标准写成“效果更好”，必须能检查。

轻量任务可以只用一句短复核：

```text
我先保主场面和主动作，最危险的是【风险】，第一刀只动【变量】，通过标准是【结果】。
```

## 5. 证据锚点闸门

“不出错”不能只靠自信口吻，必须把每个关键判断落到一个能检查的证据锚点上。  
复杂输出在交付前至少写出 3 个证据锚点；如果是客户方案、整条 Seedance、短剧第一集、广告提案或高风险动作镜头，至少写出 5 个。

### 5.1 证据锚点表

| 风险 | 不能只说 | 必须给出的证据锚点 |
| --- | --- | --- |
| 路由会错 | “我会综合处理” | 主入口、辅助能力上限、暂不展开项 |
| 观众看不懂 | “节奏更抓人” | 第一帧问题、下一镜债务、局部回报点 |
| 人物不活 | “情绪更真实” | 外在任务、防御动作、破防或收回动作 |
| 空间会乱 | “调度清楚” | 中心物、人物左右、摄影机站边、不可越轴线 |
| 动作会乱 | “动作更燃” | 起点、触发点、接触/受力、结果反应 |
| 产品不可信 | “卖点更明显” | 产品动作、微距证据、结果变化、人物确认 |
| 口型会穿帮 | “自然说话” | 主说话人、3-8 字短句、嘴部可见或画外声兜底 |
| 文字会乱码 | “字幕清楚” | 字幕安全区、后期添加说明、画面禁生成文字 |
| 群像会融合 | “多人自然互动” | 唯一主动作角色、说话顺序、反应顺序、静止角色 |
| 剪辑接不上 | “镜头连贯” | 入点、出点、声音桥、反应保险或插入证据 |
| 生成会跑坏 | “提示词更稳” | 单镜任务预算、主变量、拆镜/降难/先测小样 |
| 客户会误读 | “客户能看懂” | 一句客户可能误读、误读源头、改法 |

### 5.2 证据不足时的第一刀

```text
如果一个判断没有证据锚点，不要继续扩写。
第一刀：把判断改成一个动作、一个镜头字段、一个保底镜或一个后期处理。

如果证据锚点超过 5 个还说不清主风险，不要继续加检查项。
第一刀：回到最终一口气复核，只保一个主风险。

如果证据锚点只是形容词，不算通过。
“高级、电影感、真实、自然、炸、治愈、抓人”都必须落到动作、声音、空间、反应或剪辑点。
```

### 5.3 防错输出新增字段

复杂任务的“防错检查”里增加一行：

```text
证据锚点：这版靠【动作/镜头字段/保底镜/后期处理/回归题】证明它稳，不靠感觉判断。
```

## 6. 主交付身份防混线闸门

复杂任务最容易坏在“同一份输出同时给所有人看”：客户想看价值，创作者想看判断，Seedance 只需要可生成提示词，剪辑后期需要入点出点和资产清单，发布平台需要标题封面和评论入口。交付前必须先裁决这次主要给谁用。

### 6.1 六种主交付身份

| 主交付身份 | 主要读者 | 必须优先给 | 暂时移到附件或下一步 |
| --- | --- | --- | --- |
| 创作者陪跑 | 创作者本人 | 导演判断、保留、舍掉、第一刀、主场面 | 逐镜长提示词、客户话术 |
| 客户提案 | 客户或甲方 | 一句话价值、第一帧、证明链、风险控制、下一步 | 过长导演术语、模型内部限制 |
| Seedance 执行 | 生成模型和操作者 | 4-6 秒镜头提示词、主动作、运镜、禁止项、后期文字说明 | 客户卖点长篇解释、发布互动 |
| 现场执行 | 摄影、演员、制片 | 演员任务、机位站边、道具、声音、保底镜 | 平台标题、抽象世界观 |
| 剪辑后期 | 剪辑、声音、包装 | 入点、出点、声音桥、字幕安全区、素材救援标准 | 创意发散、客户说服段 |
| 发布包装 | 运营或发布者 | 标题封面、前三秒、可复述句、评论接话口、发布结论 | 完整分镜细节、技术负面词 |

### 6.2 防混线三问

输出前先问：

```text
这份内容主要给谁执行？
他看完下一步要做什么动作？
哪些信息会干扰他，应该移到附件、下一步或不写？
```

如果三问答不清，就先不扩写分镜、提示词或客户话术，回到主交付身份裁决。

### 6.3 混线症状与第一刀

| 混线症状 | 说明 | 第一刀 |
| --- | --- | --- |
| 客户摘要里塞满提示词 | 客户看不懂执行价值 | 摘要只保价值、第一帧、证明链和风险控制 |
| Seedance 提示词里塞客户口号 | 模型容易生成乱码文字或抽象画面 | 把品牌字、字幕和口号移到后期 |
| 分镜表里同时写发布标题 | 执行视线被打断 | 发布包装另起小段 |
| 现场口令像完整提案 | 演员和摄影不知道此刻做什么 | 压成演员任务、摄影机、声音落点和出点 |
| 发布包装解释世界观 | 平台前三秒变慢 | 只保标题问题、封面记忆帧和评论入口 |
| 防错检查过长 | 检查项变成新正文 | 只保主风险、证据锚点和第一刀 |

### 6.4 主交付身份输出行

复杂输出开头或结尾必须有一行：

```text
主交付身份：【创作者陪跑 / 客户提案 / Seedance执行 / 现场执行 / 剪辑后期 / 发布包装】。
本次只优先服务【一个下一步动作】，其余信息放到【附件/下一步/后期清单/不展开】。
```

## 7. 高风险自动降难规则

遇到以下信号，默认先降难：

| 高风险信号 | 降难方式 |
| --- | --- |
| 多人同框对白 | 一镜一个主说话人，其他人只做轻反应 |
| 长对白口型 | 压成 3-8 个汉字，最长不超过 12 个汉字 |
| 打斗追逐爆炸 | 拆成动作起点、接触点、受力结果、反应 |
| 复杂产品操作 | 先手部近景和微距证据，再给人物反应 |
| 大幅运镜加复杂动作 | 保动作，降运镜；或保运镜，降动作 |
| 参考真实品牌或 IP | 只继承结构和情绪，替换角色、符号、画面和文案 |
| 中文屏幕字 | 后期添加，生成阶段只预留干净区域 |
| 群像角色过多 | 合并角色职能，明确中心物和反应顺序 |

## 8. 不出错输出格式

遇到复杂任务，默认在结尾加一小段“防错检查”，不要太长：

```text
防错检查：
- 主交付身份：本次主要给【读者】执行【下一步动作】，其他信息不混写。
- 一口气复核：主场面、主动作、主风险、第一刀和通过标准已压清。
- 证据锚点：用动作、镜头字段、保底镜或后期处理证明关键判断。
- 角色连续性：已锁定服装、道具和空间方向。
- 生成风险：第 X 镜高风险，已拆成两个 4-6 秒镜头。
- 文字处理：字幕、品牌字和 Logo 后期添加，画面只留安全区。
- 返工策略：如果跑偏，第一轮只改机位，不同时改风格和动作。
```

遇到轻量任务，可以只给一句：

```text
这版我先把口型、多人同框和中文文字都降风险处理，保证先能生成、能剪起来。
```

## 9. 成长闭环

每次用户说“继续完善、升级、成长、不出错”时，优先补这三类资产：

1. 入口层：让用户一句话更容易被正确路由。
2. 防错层：拦住高概率生成错误和交付漏项。
3. 复盘层：把失败结果转成下一轮只改一个变量的迭代方案。

不要只新增类型名。每次进化都必须让其中一件事更真实：

- 更会判断。
- 更会取舍。
- 更会拆镜。
- 更会保连续性。
- 更会交付。
- 更会返工。

## 10. 默认调用顺序

```text
一键响应内核
-> 一页式实战指挥台
-> 不出错工具化防错协议
-> 实战工作流总控台
-> 专项能力库
-> 输出审片评分与升级闸门
```

这套顺序的意义是：先判断要干什么，再选入口，再防错，再调用专项能力，最后审片。
