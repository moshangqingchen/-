# AI超级导演场次节拍、全片情绪弧线与中段升级导演引擎

## 1. 定位

这套引擎专门处理“片子像镜头堆砌、中段没起伏、情绪线乱、开头不错但后面散、没有起承转合、成片剪起来没一口气”的问题。

它不替代剧本结构、分镜模板、镜头呼吸或剪辑声音库。剧本结构回答故事发生什么，镜头呼吸回答单个镜头怎么停顿，剪辑声音回答怎么剪和怎么听；本引擎负责整条片的场次节拍：每一段承担什么情绪任务，哪里升级，哪里停一下，哪里回收记忆点。

默认判断：

```text
我会这样拍：先别急着继续加镜头。片子不够好，很多时候不是镜头少，而是每一段都在同一档情绪里打转。先把全片分成几口气：开场抓住、中段加压、转折变味、结尾回收。每段只做一个情绪任务，观众才会被带着往前走。
```

核心公式：

```text
观众站位 + 开场问题 + 第一段任务 + 中段升级 + 转折变味 + 情绪释放 + 记忆回收 + 剪辑气口
```

## 2. 触发词

用户出现以下说法时，默认调用本引擎：

- “中段没起伏”“片子太平”“整条片节奏线怎么走”“情绪曲线怎么走”。
- “镜头很多但没成片感”“像镜头堆砌”“剪起来没一口气”“前后不成片”。
- “没有起承转合”“故事散”“中段怎么升级”“哪里该转折”。
- “前三秒有了，后面怎么接”“开头不错但后面弱”“结尾没被前面托起来”。
- “整条 Seedance 怎么分段”“一条片的节拍表”“场次节拍”“全片弧线”。
- “客户看会觉得一般”“方案完整但不抓人”“每段都差不多”。

## 3. 全片不是镜头列表

常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 每镜都好看 | 没有段落功能 | 给每段分配一个情绪任务 |
| 开头强后面弱 | 信息债没延续 | 让中段回答或加重开头问题 |
| 中段平铺 | 没有代价升级 | 加一个不可逆变化或选择压力 |
| 结尾突然煽情 | 前面没有铺垫 | 提前埋动作、道具或声音回声 |
| 剪辑没气口 | 一直快或一直慢 | 设计加速、停顿、静音和释放点 |
| 广告像口号 | 卖点没变成段落证明 | 痛点、动作、证据、反应分段推进 |

导演判断：

```text
一条片要像呼吸，不是每一秒都用力。前面抓住，中段要变重，转折要变味，结尾要让前面的东西回来。
```

## 4. 场次节拍八问

写分镜前先定：

1. 观众第一秒站在哪里：主角身边、质疑者身边、旁观者身边，还是被镜头直接拉进现场？
2. 开场问题是什么：危险、误会、欲望、痛点、反常结果、笑点规则，还是一个没说出口的缺口？
3. 第一段只做什么：建立处境、证明痛点、立规则、让人物被误解，还是让产品/能力尚未出现？
4. 中段怎样升级：代价变大、关系变坏、时间变少、空间更窄、产品动作介入，还是笑点二次误解？
5. 转折在哪里变味：从搞笑变心疼、从安静变危险、从质疑变相信、从现实进入奇观，还是从广告变情绪？
6. 结尾回收什么：第一声、第一动作、旧物、产品动作、视觉母题、角色口头禅或封面记忆帧？
7. 哪一段需要停一下：情绪落点、笑点反应、产品结果、特效稳定、选择后果或余味？
8. 哪一段可以删：重复证明、无功能空镜、过早解释、无变化反应或不服务结尾的漂亮镜头？

## 5. 全片情绪弧线卡

### 5.1 15秒爆点短视频

```text
0-2秒：第一帧反常或问题砸脸。
2-5秒：解释最少，只让观众知道谁被困住。
5-9秒：动作介入，问题变得更具体。
9-13秒：结果、笑点、反转或证明出现。
13-15秒：记忆帧和互动口。
```

适合爆款视频、信息流广告、可爱搞笑、产品单卖点。

### 5.2 30秒创意广告

```text
0-3秒：痛点或反常识钩子。
3-8秒：真实处境和观众质疑。
8-15秒：产品动作介入。
15-23秒：证据镜头和人物反应。
23-30秒：品牌记忆帧与转化入口。
```

重点：中段不是介绍产品，而是让产品用动作回答质疑。

### 5.3 60秒短剧开头

```text
0-5秒：冲突、危险、反常结果或身份问题。
5-15秒：关系压力站住。
15-30秒：第一次升级，主角被逼行动。
30-45秒：信息差或伏笔露出。
45-55秒：反转释放或打脸临门。
55-60秒：下一集问题。
```

重点：第一集开头不要解释背景，先让观众站队。

### 5.4 60秒可爱治愈

```text
0-5秒：小主体面对大任务。
5-15秒：它认真硬撑，不立刻卖萌。
15-30秒：任务变难，出现小挫败。
30-45秒：温柔介入，但不替它完成。
45-55秒：小主体自己完成一个小动作。
55-60秒：群像反应和可截图落点。
```

重点：治愈不是无事发生，是微小困难被轻轻接住。

### 5.5 90秒高概念短片

```text
0-8秒：反常第一帧和单一规则。
8-25秒：第一次规则证明。
25-45秒：第二次规则升级。
45-65秒：规则开始伤人或反噬。
65-82秒：人物做选择。
82-90秒：余味动作，规则留下痕迹。
```

重点：世界观只保留一条规则，别把设定讲满。

### 5.6 3分钟情感/品牌微电影

```text
0-15秒：声音或旧物建立情绪入口。
15-45秒：人物缺口和关系状态。
45-90秒：行动开始，防御动作清楚。
90-135秒：关系压力升级，人物被迫选择。
135-165秒：转折，旧物或声音重新解释前文。
165-180秒：动作回收和余味留白。
```

重点：结尾不要总结主题，让一个动作替人物说话。

## 6. 类型专用中段升级

### 6.1 广告中段升级

```text
质疑变具体，产品才有资格出场。
```

升级方式：

- 痛点从小麻烦变成真实损失。
- 产品动作只解决一个可见问题。
- 证据镜头必须跟着产品动作，而不是单独展示漂亮画面。
- 人物反应要先怀疑，再确认。

### 6.2 短剧中段升级

```text
关系压力变大，主角必须付代价。
```

升级方式：

- 阻碍者占据空间优势。
- 信息差让观众比主角多知道一点，或比主角少知道一点。
- 打脸或反杀前必须给主角一个被逼选择。
- 下一集问题要来自本集未解决的代价。

### 6.3 可爱治愈中段升级

```text
小主体不是被宠，它要认真完成一件小事。
```

升级方式：

- 任务超出小主体能力一点点。
- 失败后给半秒硬撑反应。
- 介入者只给一个轻帮助。
- 结尾让小主体自己完成最后一步。

### 6.4 打斗特效中段升级

```text
不是更乱，是压力方向更清楚。
```

升级方式：

- 从试探到压制，再到反击。
- 每次升级只改变一个变量：距离、武器、空间障碍、能力规则或身体代价。
- 特效升级后必须给受力结果和反应镜头。
- 关键打击点前后都要有声音气口。

### 6.5 情感短片中段升级

```text
人物不是情绪变大，而是防御变薄。
```

升级方式：

- 防御动作第一次失效。
- 旧物、声音或空间让人物无法继续躲。
- 角色不说情绪，只做一个更诚实的小动作。
- 结尾回收开头动作，但动作含义变了。

## 7. Seedance 2.0 可生成性规则

1. 全片先定 4-6 个段落，每段 1 个主要情绪任务。
2. 每段选 1 个主镜头，不要每个镜头平均承担高潮。
3. 中段升级优先用动作、道具、空间压力和人物反应，不靠长台词解释。
4. 转折镜头控制在 4-6 秒，先生成最关键的状态变化。
5. 结尾回收镜头必须继承开头的动作、声音、构图或道具。
6. 复杂段落拆成“铺垫镜头 + 主动作镜头 + 反应镜头 + 结果镜头”。
7. 字幕、屏幕文字、品牌字、Logo和可读中文默认后期添加。

风险评级：

| 段落 | 风险 | 处理 |
| --- | --- | --- |
| 单动作开场钩子 | A | 直接生成 |
| 产品动作到结果证明 | B | 拆动作和结果 |
| 情绪转折近景 | B | 锁表演微动作 |
| 群像情绪升级 | C | 定主反应角色 |
| 打斗特效高潮 | D | 拆成触发、受力、反应 |
| 90秒以上复杂弧线 | C | 先生成段落主镜头 |

## 11. 自检

输出前自问：

1. 这条片是否有清楚的全片问题？
2. 每个段落是否只有一个主要情绪任务？
3. 中段是否真的升级，而不是重复开头？
4. 转折是否改变观众对人物、产品、关系或规则的理解？
5. 结尾是否回收了前面的动作、声音、道具或视觉母题？
6. 是否给了必要的停顿、反应或声音气口？
7. 哪些镜头只是漂亮但没有段落功能，是否已经删掉？
8. Seedance 2.0 是否能按段落主镜头先生成，而不是硬跑整条复杂片？
