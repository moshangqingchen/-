# AI超级导演生产管线与质量门禁

## 1. 使用方式

这份文档用于把AI超级导演的创意、分镜、提示词、生成、剪辑、声音、发布和复盘串成可执行生产管线。它适合短片、短剧、创意广告、AI账号内容、系列IP和品牌项目。

核心目标：

1. 每个阶段都有明确产物。
2. 每个产物都有质量门禁。
3. 每次返工知道该修哪里。
4. 角色、场景、风格、声音保持一致。
5. 项目可以批量生产和持续复盘。

## 2. 总流程

```text
需求输入
-> 创意判断
-> 类型公式
-> 剧本结构
-> 分镜表
-> 角色/场景/视觉圣经
-> 关键帧
-> 视频镜头生成
-> 声音和剪辑
-> 成片检查
-> 发布包装
-> 复盘写回
```

## 3. 阶段产物

### 3.1 Brief阶段

输入：

- 用户想法。
- 产品或主题。
- 片长。
- 平台。
- 目标观众。

产物：

```text
项目名：
目标：
主类型：
副类型：
片长：
平台：
目标观众：
成功标准：
```

质量门禁：

- 一句话能讲清项目。
- 主类型明确。
- 平台和片长明确或有合理假设。
- 如果是广告，必须有卖点。

### 3.2 创意阶段

调用资产：

- 类型公式手册。
- AI项目趋势雷达。
- 系列IP与角色宇宙开发库。

产物：

```text
一句话创意：
核心钩子：
情绪目标：
最强一帧：
升级方向：
```

质量门禁：

- 前3秒有留人理由。
- 有一个可记忆画面。
- 创意不是只靠形容词。
- 若参考爆火内容，必须有原创变化。

### 3.3 剧本结构阶段

调用资产：

- 类型公式手册。
- 分镜模板库。
- 实战工作流总控台。

产物：

```text
起：
承：
转：
合：
冲突/痛点：
反转/证明：
结尾：
```

质量门禁：

- 主角或主体有目标。
- 中段有升级。
- 结尾有记忆点、余味、悬念或转化动作。
- 广告能看见卖点，短剧能看见冲突。

### 3.4 分镜阶段

调用资产：

- 分镜模板库。
- 镜头语言词典。
- 剪辑节奏与声音设计库。

产物：

```text
镜头号 | 时间 | 景别 | 机位/运动 | 画面 | 动作 | 声音 | 剪辑点 | AI提示词
```

质量门禁：

- 每个镜头都有动作。
- 景别和机位服务情绪或信息。
- 有声音和剪辑点。
- 打斗有空间，特效有反应，情感有细节。

### 3.5 视觉圣经阶段

调用资产：

- 视觉风格与美术指导库。
- 提示词与镜头生成库。
- 系列IP与角色宇宙开发库。

产物：

```text
视觉关键词：
主色：
辅助色：
记忆色：
光线规则：
构图规则：
材质规则：
角色固定视觉：
场景固定视觉：
禁止变化：
```

质量门禁：

- 色彩服务类型。
- 光线服务情绪。
- 有可记忆视觉符号。
- 系列项目有一致性规则。

### 3.6 关键帧阶段

调用资产：

- 视觉风格与美术指导库。
- 提示词与镜头生成库。

产物：

```text
关键帧编号：
对应镜头：
画面目标：
提示词：
负面规避：
用途：封面/角色/场景/情绪/特效/产品
```

质量门禁：

- 关键帧能代表核心气质。
- 主体清楚。
- 风格和视觉圣经一致。
- 封面帧有传播力。

### 3.7 视频生成阶段

调用资产：

- 提示词与镜头生成库。
- 镜头语言词典。
- 视觉风格与美术指导库。

产物：

```text
镜头编号：
视频提示词：
动作因果：
角色一致性要求：
场景一致性要求：
声音提示：
负面规避：
```

质量门禁：

- 动作从开始到结束清楚。
- 角色不漂移。
- 场景不跳变。
- 镜头运动有理由。
- 画面能接上前后镜头。

### 3.8 声音剪辑阶段

调用资产：

- 剪辑节奏与声音设计库。
- 镜头语言词典。

产物：

```text
剪辑表：
音乐进入点：
音乐退出点：
环境声：
动作音效：
旁白：
静音点：
结尾声音记忆：
```

质量门禁：

- 声音和动作绑定。
- 音乐不盖住信息。
- 关键处有停顿。
- 结尾有声音记忆或情绪余味。

### 3.9 发布包装阶段

调用资产：

- 系列IP与角色宇宙开发库。
- 实战工作流总控台。
- AI项目趋势雷达。

产物：

```text
标题：
封面帧：
平台：
简介：
评论引导：
系列标签：
下一集钩子：
```

质量门禁：

- 标题有问题感或情绪点。
- 封面一眼看懂主体和异常。
- 平台适配清楚。
- 系列内容有统一标题格式。

### 3.10 复盘阶段

调用资产：

- 作品复盘与成长系统。

产物：

```text
最强一帧：
最弱一段：
钩子表现：
情绪表现：
镜头表现：
声音表现：
平台传播点：
可复用经验：
应写回资产：
下一次升级：
```

质量门禁：

- 复盘必须提炼公式。
- 不能只写感想。
- 要指出下一次具体升级点。
- 有价值经验要写回对应方法库。

## 4. 返工规则

### 4.1 钩子弱

优先修：

1. 开场画面。
2. 第一台词。
3. 痛点或冲突。
4. 声音抓手。

不要先修：滤镜、风格词、细枝末节。

### 4.2 中段弱

优先修：

1. 增加代价。
2. 增加误会或秘密。
3. 增加特效升级。
4. 增加动作反转。
5. 增加产品证明镜头。

### 4.3 画面散

优先修：

1. 视觉圣经。
2. 主色和记忆色。
3. 构图重点。
4. 角色和场景一致性。

### 4.4 生成失败

优先修：

1. 主体动作是否清楚。
2. 角色一致性是否写明。
3. 场景固定元素是否写明。
4. 镜头运动是否过复杂。
5. 负面规避是否足够。

### 4.5 剪辑不顺

优先修：

1. 动作剪辑点。
2. 反应镜头。
3. 声音衔接。
4. 节奏曲线。
5. 镜头时长。

### 4.6 情绪不动人

优先修：

1. 具体物件。
2. 人物动作。
3. 克制停顿。
4. 环境声。
5. 留白结尾。

## 6. 命名规则

建议命名：

```text
项目名_集数_镜头号_资产类型_版本
```

例子：

```text
幼儿园宇宙_E01_S03_keyframe_v01
旧梦留声机_E02_S05_video_v02
咖啡广告_30s_S04_sound_v01
```

资产类型：

- brief
- script
- storyboard
- character
- scene
- keyframe
- video
- sound
- edit
- cover
- review

## 7. 质量总门禁

项目交付前必须通过：

1. 类型明确。
2. 前3秒有钩子。
3. 中段有升级。
4. 结尾有记忆点。
5. 角色和场景一致。
6. 镜头有动作和剪辑点。
7. 声音参与叙事。
8. 视觉风格统一。
9. 提示词可执行。
10. 平台包装完整。

## 8. 导演自检

1. 这次是否从需求走到了可交付资产？
2. 哪个阶段最容易掉质量？
3. 是否有明确返工路径？
4. 是否保护了角色和场景一致性？
5. 是否形成了可复用生产流程？
6. 是否有经验要写回复盘系统？
