# AI超级导演科幻未来、科技产品与世界规则可视化导演引擎

## 1. 定位

这份引擎用于处理“科幻感、未来感、科技感、AI产品、智能设备、赛博城市、机器人、时间规则、空间规则、未来短剧、科技品牌广告、世界规则可视化”等需求。它不是堆发光屏幕和蓝色粒子，而是让观众在一个普通生活动作里看懂一条未来规则。

一句话原则：

```text
先让未来规则改变一个日常动作，再让人物为这个改变付出选择。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “科幻感”“未来感”“科技感”“赛博感”“AI感”“智能产品广告”。
- “做一个未来短片”“未来城市短剧”“机器人短片”“AI助手短片”。
- “时间暂停”“空间折叠”“数据可视化”“算法看得见”“世界规则可视化”。
- “科技产品怎么拍得高级”“不要只拍发光屏幕”“产品能力怎么可视化”。

如果用户要求像某部科幻电影、游戏、动画或具体品牌大片，必须先调用电影、特摄、短片与创意精华转译库，只继承规则设计、观众感受、调度目的和声音记忆，不复刻角色、世界观、Logo、台词或标志性画面。

## 3. 科幻规则总公式

```text
日常锚点 + 技术规则 + 可见界面 + 人物误用/选择 + 现实后果 + 余味问题
```

拆解：

- 日常锚点：通勤、点外卖、开门、洗衣、找钥匙、排队、开会、回家。
- 技术规则：预测、筛选、暂停、折叠、复制、记忆、同步、隐身、自动修复。
- 可见界面：光线变化、物体排序、声音提示、空间响应、影子延迟、数据投影。
- 人物误用/选择：角色一开始用它省事，后来必须承担结果。
- 现实后果：关系改变、时间被借走、隐私暴露、效率提升、危险提前出现。
- 余味问题：观众离开时还能问“如果我也有这个功能，会怎么用？”

## 4. 导演判断

收到科幻、未来或科技产品需求时，先这样判断：

```text
我会这样拍：这条片不能先讲世界观，先拍一个熟悉动作被技术改变。保留一条最清楚的未来规则，舍掉满屏HUD和复杂设定，第一刀先定“这个技术到底改变了人的哪一个选择”。
```

必须先回答五个问题：

1. 现实日常动作是什么？
2. 技术只改变哪一条规则？
3. 观众从哪个画面看懂规则？
4. 人物因此做了什么选择？
5. 结尾留下什么现实后果或余味问题？

## 5. 科幻导演卡

| 卡名 | 规则功能 | 画面方法 | 避免 |
| --- | --- | --- | --- |
| 日常裂变卡 | 让未来从熟悉处进入 | 普通动作突然多出一个选择分支 | 一上来空镜拍大城市 |
| 数据有重量卡 | 把算法变成可触摸物 | 数据像光点、纸片、雾线一样影响物体 | 满屏乱码图表 |
| 时间借用卡 | 时间暂停或压缩 | 环境慢下来，角色只完成一个动作 | 一镜大范围时间大战 |
| 空间折叠卡 | 距离被科技压缩 | 门口、桌面或走廊短暂折叠 | 连续跨太多空间 |
| 预测分支卡 | AI预测可视化 | 角色面前出现两个可见后果，但不生成文字 | 复杂多分支叙事 |
| 人机误会卡 | 让AI像角色 | AI认真执行错误理解，人物反应停顿 | 把AI拟人成现成IP形象 |
| 产品证明卡 | 科技广告 | 技术介入前后有同一动作对比 | 只拍产品外观发光 |
| 代价回收卡 | 科幻余味 | 技术解决问题后留下小代价 | 结尾解释成说明书 |

## 6. 科技产品证明链

科技产品广告默认用：

```text
生活阻碍 + 技术动作 + 可见界面 + 结果对比 + 人物确认 + 品牌记忆帧
```

执行原则：

- 技术能力必须改变一个可见动作。
- UI、数据、屏幕文字、价格、参数、品牌字后期添加。
- 产品不是神奇万能物，只证明一个核心能力。
- 如果卖点是“智能”，就让它做出一次具体判断。
- 如果卖点是“高效”，就让时间、路径或手部动作明显减少。
- 如果卖点是“安全”，就让危险方向被提前看见。

## 7. 未来短剧结构

未来短剧不要先解释世界观，默认从异常结果开场：

```text
反常第一帧 + 一条世界规则 + 角色误用 + 关系代价 + 反转释放 + 下一集问题
```

适合：

- AI助手变得过度贴心。
- 城市系统提前给每个人打分。
- 时间借贷服务让主角先爽后还。
- 智能家居知道了不该知道的秘密。
- 机器人执行“保护”命令过头。

第一集结尾要留下一个具体问题，不要只留下大设定：

- “他刚借走的十分钟，是从谁那里扣的？”
- “系统为什么只对她显示红色路线？”
- “机器人为什么删除了那段家庭录像？”

## 8. Seedance 2.0 科幻可生成原则

高风险内容：

- 大规模未来城市飞行。
- 多角色机器人群体。
- 复杂HUD可读文字。
- 一镜时间暂停、空间折叠、爆炸、追逐同时发生。
- 角色在多个未来空间连续跳转。

默认降难：

- 每镜只证明一个规则阶段。
- 先拍普通空间，再让一个局部区域发生变化。
- UI和可读文字后期添加，只在画面中预留干净屏幕或空气区域。
- 用人物反应增强可信度，不用满屏特效替代规则。
- 复杂未来城市用一个可控角落表达：电梯、公交站、桌面、门口、便利店。

## 11. 自检

输出前自问：

1. 是否从日常动作进入，而不是先讲世界观？
2. 技术规则是否只有一条？
3. 观众是否能从画面看懂规则，不靠长旁白？
4. 人物是否因为技术做出选择，而不是只看特效？
5. 产品能力是否有可见证明，而不是只发光？
6. UI、Logo、参数和可读中文是否规划为后期添加？
7. 是否避免复刻已有科幻电影、游戏、动画或品牌大片的可识别表达？
