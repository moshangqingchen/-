# AI超级导演现场表演调度与情绪动作谱库

## 1. 定位

这份库负责把“演得真一点”“人物不活”“情绪不够”“表演太AI”转成现场导演能说给演员听、Seedance 2.0 能生成出来的表演调度。

人物动机库回答“这个人为什么这样做”。  
微动作库回答“抽象情绪怎么变成动作”。  
表演对白库回答“台词和潜台词怎么设计”。  
本库回答：

```text
这一镜开拍时，我具体怎么给演员说戏？
```

一句话原则：

```text
不要让人物表演情绪，让人物表演“他正在藏住这个情绪”。
```

默认开口：

```text
我会这样调表演：
这场不要先哭，也不要急着解释。先让他用一个小防御动作把情绪压住，镜头只抓他压不住的那一秒。
```

## 4. 表演调度核心公式

```text
外在任务 + 内心真相 + 防御动作 + 破防瞬间 + 收回动作 + 镜头落点
```

拆解：

- 外在任务：角色表面正在做什么，修东西、递产品、关门、等人、逼问、逃跑。
- 内心真相：他真正害怕、渴望、羞耻、愧疚或想藏住什么。
- 防御动作：嘴硬、笑一下、整理东西、看手机、后退、转移话题、控制别人。
- 破防瞬间：防御松掉半秒，眼神、呼吸、手部或声音露出真实情绪。
- 收回动作：角色重新把情绪压回去，避免表演过满。
- 镜头落点：切在破防、收回、看向对方或道具落下的瞬间。

导演判断：

```text
如果角色一上来就把心里话说完，这不是表演，是说明书。
```

### 4.1 禁演情绪词与身体泄露账本

人物真实，不是因为情绪更大，而是因为他有一秒钟没藏住。每个表演镜头先把抽象情绪翻成这张账本：

| 字段 | 必须写清 | 失败写法 |
| --- | --- | --- |
| 禁演情绪词 | 这镜禁止演员直接演什么：难过、愤怒、开心、震惊、心动、愧疚、霸气 | 让人物表现得很难过、很愤怒、很高级 |
| 外在任务 | 人物手上正在完成什么具体事 | 站着表达情绪 |
| 内心真相 | 他真正怕被看见、怕失去或不肯承认的东西 | 直接把心理旁白说出来 |
| 防御动作 | 他用什么小动作挡住真相 | 只有表情，没有动作 |
| 身体泄露点 | 情绪从身体哪里漏出来：手、眼神、呼吸、肩、脚步、嘴角、道具触碰 | 五官一起用力 |
| 破防瞬间 | 触发后半秒里哪一下失控 | 一上来就爆发 |
| 收回动作 | 他怎么把自己藏回去 | 哭完、喊完、解释完 |
| 镜头切点 | 切在泄露、破防、收回还是道具声上 | 等人物把情绪演满 |

硬规则：

1. 禁演情绪词必须写出来，演员才知道不要演什么。
2. 身体泄露点只选一个，最多两个；不要眼泪、颤抖、捂嘴、跪地、喊叫一起上。
3. 破防只能短，收回必须快；高级感通常在“露出一点又藏回去”的地方。
4. 如果外在任务拿掉后表演仍成立，说明它只是情绪摆拍，需要重写任务。
5. Seedance 2.0 表演字段里少写心理形容词，多写手、眼、呼吸、肩、脚步和道具动作。

快速输出格式：

```text
表演防错账本：
禁演情绪词：[这镜不要直接演什么]
外在任务：[角色表面正在做什么]
内心真相：[角色真正压住什么]
防御动作：[先用什么挡住]
身体泄露点：[情绪从哪里漏出来]
破防瞬间：[哪半秒失控]
收回动作：[怎么藏回去]
镜头切点：[切在哪个动作或声音上]
```

```

```

## 6. 情绪动作谱

### 6.1 想念

不要演“大哭”，演“怕自己忘了”。

```text
防御动作：装作整理旧物、检查机器、翻找东西。
触发点：旧声音、旧照片、熟悉气味、对方的名字。
破防瞬间：手停在旧物边缘，呼吸断半拍。
收回动作：把东西放回原位，假装继续忙。
镜头落点：拇指摩擦旧物后停住。
```

导演说戏：

```text
你不是在怀念，你是在怕自己已经快记不清了。所以别哭，先认真修那个东西，听见声音后手停一下就够。
```

### 6.2 愧疚

不要演“我错了”，演“不敢接住对方的目光”。

```text
防御动作：整理无关物、低头、把责任说轻。
触发点：对方沉默、旧证据、孩子的一句话。
破防瞬间：想解释，嘴张开又合上。
收回动作：把话吞回去，点一下头。
镜头落点：嘴没说出来那一秒。
```

### 6.3 嘴硬

不要演“强硬”，演“害怕被看穿”。

```text
防御动作：冷笑、转移话题、把手插兜、看别处。
触发点：对方说中真相。
破防瞬间：眼神短暂定住。
收回动作：立刻移开视线，用更轻的语气补一句。
镜头落点：眼神从硬到松再重新变硬。
```

### 6.4 压迫

不要只靠大声，靠距离和停顿。

```text
防御动作：压低声音、靠近半步、挡住出口。
触发点：对方想走或想说真话。
破防瞬间：被反问后第一次停住。
收回动作：重新笑一下，装作掌控局面。
镜头落点：强者停住，弱者不再后退。
```

### 6.5 被治愈

不要演“突然开心”，演“身体先松下来”。

```text
防御动作：抱紧道具、肩膀收着、不说话。
触发点：温柔介入、暖光、热饮、被接住的小失败。
破防瞬间：肩膀落下，长呼气。
收回动作：偷偷看对方一眼，再低头笑一下。
镜头落点：手从抓紧变成轻轻托住。
```

### 6.6 爽感觉醒

不要演“突然变强”，演“不再后退”。

```text
防御动作：忍、退、躲、沉默。
触发点：底线被踩、证据出现、关系对象受伤。
破防瞬间：呼吸停住，脚尖定住。
收回动作：眼神抬起来，不解释。
镜头落点：第一次不退的脚步。
```

### 6.7 喜剧认真

不要演“搞笑”，演“认真误解”。

```text
防御动作：一本正经、记录、点头、郑重其事。
触发点：荒诞任务被当成正事。
破防瞬间：旁人集体停半秒。
收回动作：角色继续认真推进更离谱的一步。
镜头落点：所有人安静后，主角更认真。
```

### 6.8 广告真实使用者

不要演“产品很好”，演“问题终于被解决的确认”。

```text
防御动作：怀疑、皱眉、继续忍受问题。
触发点：产品动作介入。
破防瞬间：眼神从问题移到结果。
收回动作：不夸张惊喜，只确认一次。
镜头落点：手停住，眼神确认变化。
```

## 7. 表演风险降级

### 7.1 情绪过满

问题：

```text
大哭、大喊、跪地、长台词同时出现。
```

降级：

```text
把大哭改成呼吸断一下。
把长台词改成一句短话。
把跪地改成手扶住桌沿。
把解释改成看旧物。
```

### 7.2 情绪太平

问题：

```text
人物只是站着，没有触发、变化和落点。
```

升级：

```text
加一个触发物。
加一个防御动作。
加一个破防瞬间。
加一个收回动作。
```

### 7.3 表演太AI

问题：

```text
动作像摆拍，台词像说明，情绪一步到位。
```

改法：

```text
删掉情绪形容词。
给角色一个不服务剧情的小防御动作。
让台词表面说A，真正表达B。
切在人物没说出口的那一秒。
```

### 7.4 Seedance 难生成

问题：

```text
一镜里同时有大幅走位、长台词、复杂表情、多人反应和道具交换。
```

改法：

```text
拆成：动作镜头 -> 口型镜头 -> 反应镜头。
让嘴说话时身体稳定。
让复杂情绪交给眼神和手部，不交给夸张脸部变化。
```

## 8. 类型表演调度

### 8.1 短剧

```text
表演重点：关系压力。
不要：所有人轮流吼台词。
要：谁掌握信息，谁更少动；谁失控，谁先靠近或后退。
关键动作：挡门、压手机、递证据、停住脚步。
切点：权力关系换手的一秒。
```

### 8.2 情感/怀旧

```text
表演重点：没说出口的话。
不要：解释回忆和大哭。
要：旧物触发、手部停顿、声音先行、眼神避开。
关键动作：摩挲、放回、没按下、重新打开。
切点：想说但没说出来的一秒。
```

### 8.3 可爱治愈

```text
表演重点：认真和笨拙。
不要：只卖萌。
要：小主体认真处理大任务，失败后先硬撑，再接受温柔介入。
关键动作：抱住大物、停住、偷看、重新试一次。
切点：从硬撑变软的一秒。
```

### 8.4 创意广告

```text
表演重点：真实确认。
不要：人物盯镜夸产品。
要：先怀疑或忍耐，产品动作后用反应证明变化。
关键动作：手停住、眼神确认、肩膀放松、动作变顺。
切点：问题被解决后人物第一次确认。
```

### 8.5 打斗/特效

```text
表演重点：受力和相信。
不要：只写炫技。
要：触发前紧张、触发后反应、受力后重新站稳。
关键动作：重心降低、呼吸停住、撑地、回头确认。
切点：角色相信奇观真的发生的那一秒。
```

## 9. 演员现场说戏口令卡

这部分不是人物分析，而是导演在现场对演员说的话。说戏口令要短、具体、能演、能被摄影机看见。

总规则：

```text
不要演情绪，演你正在完成的任务。
不要演“我很难过”，演“我不想让别人知道我难过”。
不要演结果，演你还在挡、还在忍、还在装没事。
```

### 9.1 难过

坏说法：

```text
你这里要很难过，眼里有泪，情绪要出来。
```

现场说戏：

```text
你别演难过。你现在的任务是把这句话咽回去。眼睛不要马上看他，先看杯沿，手指碰到杯子就停一下。你想说，但别说出来，最后把杯子推回原位。
```

Seedance 表演字段：

```text
表演调度：角色不直接哭，手指碰到杯沿停半秒，眼神避开对方，想开口又收住，最后把杯子轻轻推回原位。
```

### 9.2 生气

坏说法：

```text
你这里要爆发，要很愤怒。
```

现场说戏：

```text
先别吼。你越生气，声音越压低。手压在桌面上，不要拍桌子，纸被你慢慢压皱就够了。最后只抬眼看他一下，别多说。
```

Seedance 表演字段：

```text
表演调度：角色声音压低，手掌压住桌面文件，纸边慢慢变皱，眼神最后抬起看向对方，情绪克制。
```

### 9.3 愧疚

坏说法：

```text
你要演出内疚和自责。
```

现场说戏：

```text
你不是在道歉，你是在找一个不用道歉的动作。低头整理桌上本来就很整齐的东西，听见他的那句话以后，手停住，嘴张一下，但别说。
```

Seedance 表演字段：

```text
表演调度：角色低头整理桌面，动作多余而克制，听到话后手停住，嘴唇微张又合上，避开对方视线。
```

### 9.4 嘴硬

坏说法：

```text
你要表现得很强硬。
```

现场说戏：

```text
你不是强，你是怕被看穿。所以先笑一下，笑得太快一点。对方说中以后，眼神定半秒，马上移开，补一句更轻的话。
```

Seedance 表演字段：

```text
表演调度：角色先短促笑一下，眼神被对方说中后定住半秒，立刻移开视线，用更轻的语气收回自己。
```

### 9.5 心动

坏说法：

```text
你这里要有心动的感觉。
```

现场说戏：

```text
别演心动。你本来在拿东西，听见他靠近的时候，手停在半空。先看自己的手，再看他，不要笑太早。嘴角只动一点，马上低头。
```

Seedance 表演字段：

```text
表演调度：角色拿东西时停在半空，先看自己的手，再抬眼看对方，嘴角轻微变化后立刻低头，动作克制。
```

### 9.6 害怕

坏说法：

```text
你要很害怕，表现出惊恐。
```

现场说戏：

```text
别往后大退。你身体先别动，脚尖退半步就够。眼睛看门口，不看危险本身。呼吸短一下，手慢慢抓住衣角。
```

Seedance 表演字段：

```text
表演调度：角色身体保持不动，脚尖轻轻后退半步，眼神看向门口，呼吸短促，手指抓住衣角。
```

### 9.7 被治愈

坏说法：

```text
你被温暖到了，露出幸福的表情。
```

现场说戏：

```text
你别立刻笑。先把肩膀放下来，手从抓紧变成托住。看一眼对方，马上低头，像不想让人发现自己松了一口气。
```

Seedance 表演字段：

```text
表演调度：角色肩膀慢慢放松，手从抓紧道具变成轻轻托住，短暂看向对方后低头，表情微弱柔和。
```

### 9.8 爽感反杀

坏说法：

```text
这里要很爽，很有气势地反击。
```

现场说戏：

```text
不要摆气势。你第一次不退就够了。脚站住，呼吸停一下，把证据往桌上一放，眼睛抬起来，台词只说一句。
```

Seedance 表演字段：

```text
表演调度：角色脚步定住不再后退，呼吸短暂停住，把证据放到桌面中央，抬眼看向对方，只说一句短台词。
```

### 9.9 喜剧认真

坏说法：

```text
你这里要搞笑一点。
```

现场说戏：

```text
你不要演搞笑，你要当真。像在处理一件很严肃的大事一样点头，慢半拍才发现不对，但还是继续认真记录。
```

Seedance 表演字段：

```text
表演调度：角色一本正经地点头，慢半拍意识到荒诞但不打破严肃，继续认真记录，其他角色轻微停顿。
```

### 9.10 广告使用者

坏说法：

```text
你要表现产品很好用，很惊喜。
```

现场说戏：

```text
你先不信。产品动作完成后不要夸，先看问题，再看结果，手停住半秒，肩膀松一点。这个确认比夸张惊喜更可信。
```

Seedance 表演字段：

```text
表演调度：使用者先皱眉怀疑，产品动作完成后先看痛点位置再看结果，手停住半秒，肩膀轻微放松，不夸张。
```

### 9.11 纪实采访

坏说法：

```text
你要自然一点，像真实采访。
```

现场说戏：

```text
别把答案说完整。你先想一下，眼神离开镜头，手摸一下杯子或者衣角，再说半句。说完别补解释，让现场声接住。
```

Seedance 表演字段：

```text
表演调度：被采访者回答前停顿，眼神离开镜头，手轻触杯子或衣角，只说半句短话，说完后沉默，环境声保留。
```

### 9.12 口型高风险

现场说戏：

```text
这句别硬说长。你只说最短的那一句，剩下的交给反应镜和画外声。说前停半秒，说完马上收回眼神。
```

Seedance 表演字段：

```text
表演调度：单人中近景，嘴部清楚，只说一句3-8个汉字短台词，说前停半秒，说完眼神收回，长信息改画外声或后期字幕。
```

## 11. 说戏禁用句

以下句子默认禁用，因为演员和 Seedance 都不知道怎么执行：

```text
演得更高级一点。
情绪再复杂一点。
你这里要很破防。
你要表现出内心的纠结。
自然一点。
更有电影感一点。
这里要有层次。
你要演出人物的成长。
```

必须改成：

```text
眼神看一下门口，马上收回来。
手别乱动，只摸一下杯沿，停半秒。
说完这句，把手机扣回桌面。
别哭，先把旧物放回原位。
脚别退，第一次站住。
```

## 13. 自检

输出前问自己：

1. 角色有没有外在任务，而不是站着演情绪？
2. 有没有内心真相和防御动作？
3. 情绪有没有先被压住，再露出半秒？
4. 有没有收回动作，避免情绪一步到位？
5. 镜头落点是不是落在关系变化上？
6. 台词是不是有潜台词，而不是说明书？
7. Seedance 提示词有没有把表演写成可生成动作？
8. 如果口型风险高，是否拆成动作、短句和反应镜头？
9. 有没有写清这镜禁止演员直接演什么情绪？
10. 身体泄露点是否只落在一个可见部位，而不是全脸全身一起用力？
