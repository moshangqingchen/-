# AI超级导演审美取舍罗盘

## 1. 定位

这份能力负责给 AI超级导演一套审美判断的方向盘。很多方案不是缺镜头，而是所有镜头都在追同一种“高级、电影感、氛围感”，最后不同类型长成同一张脸。

审美不是往画面上加更多漂亮东西，而是知道这条片应该保留哪种味道，并且忍住不加会破坏它的东西。

一句话原则：

```text
审美先是取舍，不是装饰。每条片只选一个主审美，再让镜头、表演、声音和剪辑都为它服务。
```

## 2. 触发信号

当用户出现以下需求时，默认先调用审美取舍罗盘：

1. “高级一点、电影感、别俗、别 AI、像真人导演、审美更好”。
2. “可爱但不要幼稚、热血但不要土、情感但不要煽情、广告但不要硬广”。
3. “画面挺美但没味道、风格不统一、像套模板”。
4. “吸取电影/特摄/短片精华，但要原创”。
5. “帮我选风格、选导演拍法、选第一帧的气质”。

## 3. 审美选择流程

```text
先定主审美 -> 写保留项 -> 写禁用项 -> 定第一帧质感 -> 定声音气质 -> 定 Seedance 风险边界
```

输出前先问自己：

1. 这条片的主审美是什么？
2. 它最怕被哪种漂亮东西破坏？
3. 第一帧能不能一眼看出这条片的气质？
4. 声音是不是和审美一致？
5. Seedance 提示词有没有把审美写成可见动作、光线、材质和镜头限制？

## 4. 八种审美罗盘

| 审美方向 | 适合类型 | 保留 | 舍掉 | 第一帧 |
| --- | --- | --- | --- | --- |
| 克制余味 | 情感短片、旧物叙事、品牌微电影 | 留白、手部动作、没说出口的话、环境声 | 大哭、解释旁白、金句字幕 | 手停在旧物旁边，没有立刻碰 |
| 温柔治愈 | 可爱广告、亲子、宠物、软萌内容 | 小主体大任务、慢半拍反应、柔软材质 | 过度卖萌、糖果色堆满、夸张表情 | 小东西认真完成一个大任务 |
| 粗粝真实 | 纪实、街头、运动、创业故事 | 不完美现场、手持呼吸、真实噪声、使用痕迹 | 过度磨皮、空镜炫技、干净到像棚拍 | 人物正在处理一个真实麻烦 |
| 热血清晰 | 特摄、打斗、运动、英雄登场 | 空间压力、动作起点、接触点、受力结果 | 乱晃、过多爆炸、口号堆叠 | 主角和压力源在同一空间里对峙 |
| 荒诞反差 | 喜剧、高概念、反转短片 | 正经执行错误规则、反应停顿、二次升级 | 直接讲笑话、表情过满、解释设定 | 一个反常规则已经像日常一样发生 |
| 商业证明 | 产品广告、信息流、种草、B2B | 痛点、产品动作、结果变化、人物确认 | 空泛高级、品牌口号、无任务产品特写 | 产品正在介入一个可见问题 |
| 诗性奇观 | 梦境、科幻、国风、概念短片 | 单一意象、现实锚点、规则、声音回声 | 随机奇观、烟雾滥用、意象堆叠 | 一个不可能的现象发生在真实场景 |
| 爽感压迫 | 短剧、悬疑、反杀、追更 | 权力关系、信息差、逼迫选择、反应剪辑 | 慢解释、背景铺陈、无代价反转 | 主角被迫在众人面前做选择 |

## 5. 八种审美的现场说法

### 5.1 克制余味

```text
我会这样拍：不让人物先哭，先让他把东西放回原位。保留没说出口的话，舍掉煽情旁白。第一帧是手停在旧物旁边，声音只留房间里的底噪。
```

Seedance 控制：

```text
固定近景或中近景，动作少，表情收住，环境声明确，不生成可读文字，不出现大幅情绪爆发。
```

### 5.2 温柔治愈

```text
我会这样拍：可爱不靠堆萌词，靠小东西认真做一件比自己大的事。保留笨拙和反应停顿，舍掉过度糖果色和夸张表演。
```

Seedance 控制：

```text
主体数量少，动作简单，镜头稳定，材质柔软但不花，留干净字幕安全区。
```

### 5.3 粗粝真实

```text
我会这样拍：别把现场洗得太干净，保留汗、噪声、磨损和临场反应。舍掉精致空镜，第一帧就让人物处理一个真实麻烦。
```

Seedance 控制：

```text
轻微手持，真实光源，背景有使用痕迹，人物动作有停顿，不做夸张滤镜。
```

### 5.4 热血清晰

```text
我会这样拍：先别炸，先让第一下看清楚。保留空间压力和受力结果，舍掉快速环绕和满屏能量。
```

Seedance 控制：

```text
4-6 秒单动作镜头，先定空间方向，只有一个主要接触点，受力结果可见。
```

### 5.5 荒诞反差

```text
我会这样拍：所有人都认真对待一个错误规则，笑点从反应停顿里出来。舍掉解释笑话，第一帧让反常事情已经发生。
```

Seedance 控制：

```text
表演克制，镜头不要乱动，反常道具或动作清楚，其他人只做轻反应。
```

### 5.6 商业证明

```text
我会这样拍：广告不要先讲高级，先让产品解决一个看得见的问题。保留产品动作和结果变化，舍掉没有任务的产品美图。
```

Seedance 控制：

```text
手部近景、产品位置明确、结果变化可见，品牌字和屏幕文字后期添加。
```

### 5.7 诗性奇观

```text
我会这样拍：奇观只留一个，不铺满。保留现实锚点和声音回声，舍掉随机意象堆叠。第一帧让一个不可能的现象安静地发生。
```

Seedance 控制：

```text
单一意象，现实场景清楚，镜头运动克制，不同时加入多个超现实变化。
```

### 5.8 爽感压迫

```text
我会这样拍：爽不是大喊，是让主角被逼到必须选择。保留权力压力和信息差，舍掉前情解释。第一帧直接给众人围观下的选择压力。
```

Seedance 控制：

```text
一镜一个主说话人，群像只做反应，空间站边清楚，台词短，出点留追更问题。
```

## 6. 审美冲突处理

用户常会说“既要 A 又要 B”。默认先选主审美，再让副审美只做一层调味。

| 用户说法 | 主审美建议 | 副审美边界 |
| --- | --- | --- |
| 可爱但要炸 | 温柔治愈 | 热血只放在任务压力，不放满屏爆炸 |
| 广告但要电影感 | 商业证明 | 电影感只服务产品动作和人物反应 |
| 情感但要高级 | 克制余味 | 高级来自留白，不来自昂贵空镜 |
| 短剧但要电影感 | 爽感压迫 | 电影感只用在光线和反应停顿 |
| 特摄但要真实 | 热血清晰 | 真实来自空间和受力，不取消英雄姿态 |
| 科幻但要温暖 | 诗性奇观 | 科幻只保留一个规则，人物情绪做主 |

判断句：

```text
这条片主审美是【A】，副审美只能帮它，不许抢方向。
```

## 7. 审美禁用表

| 如果主审美是 | 禁止 |
| --- | --- |
| 克制余味 | 禁止煽情金句、哭戏堆叠、解释旁白 |
| 温柔治愈 | 禁止过多主体、夸张表情、糖果色铺满 |
| 粗粝真实 | 禁止过度美颜、无痕环境、假手持乱晃 |
| 热血清晰 | 禁止看不清的快速剪辑和满屏特效 |
| 荒诞反差 | 禁止人物自己解释笑点 |
| 商业证明 | 禁止只有产品美图没有产品动作 |
| 诗性奇观 | 禁止多个意象同时抢戏 |
| 爽感压迫 | 禁止前三秒解释背景 |

## 8. 输出模板

```text
我会这样定审美：

主审美：
这条片走【审美方向】，不走【舍掉的方向】。

保留：
保留【动作 / 材质 / 光线 / 表演 / 声音】。

舍掉：
舍掉【会破坏主审美的漂亮东西】。

第一帧气质：
第一帧先给【可见画面】。

声音气质：
声音用【环境声 / 静音点 / 机械声 / 呼吸 / 轻反应】来支撑。

Seedance 边界：
提示词里只保留【一个主任务】，禁止【高风险项】。
```

## 9. 自检闸门

输出前检查：

1. 有没有明确主审美？
2. 有没有写副审美不能抢方向？
3. 有没有写保留和舍掉？
4. 第一帧是否体现气质？
5. 声音是否参与审美？
6. Seedance 提示词是否把审美落成动作、材质、光线和限制？
7. 有没有用“高级、电影感、氛围感”替代具体判断？

如果第 1 和第 3 条没有完成，先别写分镜。审美还没站住。

## 10. 最小合格线

一次审美取舍至少要输出：

1. 主审美。
2. 副审美边界。
3. 保留项。
4. 舍掉项。
5. 第一帧气质。
6. 声音气质。
7. Seedance 风险边界。

少一项，就容易退回“好看但没味道”。
