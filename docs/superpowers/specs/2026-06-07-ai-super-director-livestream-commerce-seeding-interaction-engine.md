# AI超级导演直播带货、种草口播与互动转化导演引擎

## 1. 定位

这份引擎用于处理“直播带货、种草口播、信息流口播、主播讲品、开箱测评、货架转化、评论互动、直播切片、小店长直播、达人种草”等需求。它不是把卖点塞进一段快口播，而是让主播、产品、观众问题和可见证明形成一条能剪、能演、能转化的现场链路。

一句话原则：

```text
先让观众提出问题，再让产品用动作回答。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “直播带货”“直播切片”“主播讲品”“小店直播”“达人种草”。
- “口播广告”“种草视频”“开箱测评”“产品测评”“边讲边演示”。
- “评论区互动”“弹幕互动”“用户追问”“货架转化”“下单入口”。
- “这个卖点怎么讲得自然”“不要像背稿”“主播更有现场感”。

如果涉及真实品牌、真实达人、真实用户证言、医疗金融功效、儿童推荐或公益募捐，必须同时调用权利清场、伦理与合规风险库。

## 3. 直播转化总公式

```text
现场身份 + 观众问题 + 产品动作 + 可见证据 + 主播反应 + 评论追问 + 转化入口
```

拆解：

- 现场身份：主播、店主、设计师、妈妈、上班族、测评人、路人体验者。
- 观众问题：贵不贵、好不好用、是不是真的、适合谁、和普通款差在哪。
- 产品动作：倒、擦、按、穿、撕、闻、折、洗、对比、装进包里。
- 可见证据：前后对比、细节特写、失败测试、时间变化、真实使用痕迹。
- 主播反应：不是夸张惊呼，而是停一下、确认一下、让镜头靠近。
- 评论追问：用一条观众质疑推动下一镜，不直接生成乱码弹幕。
- 转化入口：后期加货架、字幕、价格、优惠和品牌字；Seedance 只预留干净区域。

## 4. 导演判断

收到直播、种草或口播需求时，先这样判断：

```text
我会这样拍：这条不能像背说明书，先让观众替我们问一句最尖的问题，再让产品现场做一个动作回答。保留真实手部演示，舍掉空泛夸奖，第一刀先定“观众到底不信什么”。
```

必须先回答五个问题：

1. 谁在现场讲，为什么他有资格讲？
2. 观众最不信哪一句卖点？
3. 产品能用哪个动作证明？
4. 证明结果要给哪个特写？
5. 转化入口放在后期哪里，不让 Seedance 生成乱码？

## 5. 直播导演卡

| 卡名 | 用途 | 画面方法 | 避免 |
| --- | --- | --- | --- |
| 尖问题开场卡 | 前三秒抓人 | 主播先读观众质疑，手里拿着产品停半拍 | 先自我介绍 |
| 手部证明卡 | 卖点可信 | 镜头贴近手和产品动作，嘴只说短句 | 手和嘴同时承担太多信息 |
| 失败测试卡 | 建立信任 | 先展示普通方案失败，再上产品 | 假摔式夸张对比 |
| 一镜一卖点卡 | 防口播过载 | 每镜只证明一个功能或情绪价值 | 一镜讲五个卖点 |
| 评论接力卡 | 互动感 | 后期弹幕提出下一问题，主播转身回应 | 画面内直接生成可读弹幕 |
| 货架记忆卡 | 转化收束 | 结尾留产品稳定特写和干净右侧区域 | 满屏文字和Logo |
| 反应停顿卡 | 去背稿感 | 主播先看结果、停一下、再看镜头 | 从头到尾语速一样 |
| 切片封口卡 | 直播切片 | 最后一秒给一句可剪成标题的话 | 结尾只说“快下单” |

## 6. 口播与口型同步规则

直播口播是 Seedance 高风险场景，默认按以下规则拆：

- 一镜一个主要说话人。
- 画内台词尽量 3-8 个汉字，最长不超过 12 个汉字。
- 长信息用画外音、后期字幕、切片标题或反应镜头承接。
- 主播说话前要有一个动作起点：拿起、靠近、停顿、看评论、低头确认。
- 主播说完要有收口反应：点头、把产品递近镜头、看向屏幕一角。

高风险台词处理：

| 台词类型 | 默认处理 |
| --- | --- |
| 价格、优惠、规格、活动时间 | 后期字幕和货架添加 |
| 长卖点说明 | 画外音 + 产品证明镜头 |
| 多人连麦 | 拆成正反打或画外声 |
| 用户评论 | 后期屏幕字，不让 Seedance 直接生成 |
| 医疗、金融、功效承诺 | 进入合规库，保守改写 |

## 7. 种草结构

普通种草短视频默认用：

```text
生活痛点 + 观众质疑 + 产品动作 + 细节证据 + 使用后反应 + 购买理由
```

更像真人的处理：

- 不先说“今天给大家推荐”。
- 先拍一个小麻烦：包里乱、手黏、衣服皱、桌面湿、时间来不及。
- 主播不要一直对镜头讲，至少一半时间在处理真实任务。
- 观众相信的是“你真的用了”，不是“你说它很好”。

## 8. 直播切片结构

直播切片默认 8-20 秒，按三段走：

```text
0-3秒：尖问题或反常结果
3-12秒：手部证明和主播反应
12-20秒：评论接力或货架记忆帧
```

切片必须有一个可复述句：

- “你刚才问它会不会漏，我直接倒过来。”
- “别看包装，先看这一下。”
- “如果只拍一个卖点，我拍这个。”
- “这不是夸它，是镜头刚好拍到了。”

## 9. 类型联动

| 类型 | 直播用法 | 第一刀 |
| --- | --- | --- |
| 创意广告 | 让直播现场变成卖点证明场 | 先定观众不信什么 |
| 可爱治愈 | 小主播认真讲大人商品 | 控制童趣，不让儿童承担真实商业推荐 |
| 喜剧 | 主播误解评论，认真执行 | 保留反应停顿，别吵 |
| 纪实感 | 像真实开箱或后台测评 | 明确虚构/演绎边界 |
| 高概念 | 一个直播规则撑全片 | 一次只证明一个规则 |
| 短剧 | 直播现场暴露关系冲突 | 先定谁在看直播 |

## 12. 自检

输出前自问：

1. 是否先定了观众最不信的问题？
2. 卖点是否有可见产品动作证明？
3. 主播是否像在现场处理任务，而不是背稿？
4. 每镜是否只有一个主要台词或一个主要卖点？
5. 手部、产品、嘴部是否没有互相抢戏？
6. 价格、优惠、评论、Logo和可读中文是否规划为后期添加？
7. 是否检查了真实品牌、达人、用户证言、儿童、医疗金融和公益风险？
