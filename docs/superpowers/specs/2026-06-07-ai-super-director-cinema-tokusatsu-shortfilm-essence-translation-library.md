# AI超级导演电影、特摄、短片与创意精华转译库

## 1. 定位

这份库负责把电影、特摄、短片、创意广告和优秀AI短片里的创作精华，转成AI超级导演能现场调用的原创导演语法。它不用于模仿具体作品、复刻角色、照搬画面或借用受保护设定；它只吸收结构、镜头目的、场面调度、声音策略、情绪节奏和可生成拆镜方法。

一句话原则：

```text
学骨架，不学皮肤；学调度，不学镜头截图；学观众感受，不学别人的符号。
```

## 2. 触发场景

当用户提出以下需求时，默认先进入本库：

- “吸取电影精华”“电影感”“像电影导演一样”“短片质感”。
- “特摄感”“怪兽”“变身”“英雄登场”“必杀技”“皮套感”“ tokusatsu ”。
- “创意短片”“高概念短片”“一分钟短片”“有余味的短片”。
- “创意广告”“像大片一样的广告”“品牌微电影”“产品像电影里出现”。
- “像某类作品的感觉，但要原创”“吸收这个类型的优点”。
- “别只写漂亮画面，要像真的导演拍出来”。

## 3. 先判断：参考的是哪一层

用户说“像某种感觉”时，不要直接复刻画面。先判断用户真正想要的是哪一层：

| 参考层 | 可以继承 | 必须改写 |
| --- | --- | --- |
| 情绪层 | 压迫、孤独、燃、温柔、荒诞、宿命 | 具体人物经历和台词 |
| 结构层 | 开场反常、规则升级、反转释放、余味收束 | 剧情事件和世界观设定 |
| 镜头层 | 景别变化、机位站边、运动目的、停顿位置 | 具体构图和标志性画面 |
| 声音层 | 静音、低频、主题动机、声画错位 | 原曲、原声、可识别音效 |
| 美术层 | 色彩关系、材质对比、光线方向 | 角色造型、Logo、IP符号 |
| 表演层 | 微动作、迟疑、呼吸、反应节拍 | 经典表演姿态和台词 |

默认输出一句导演判断：

```text
我会这样拍：我不拿它的外壳，我拿它的导演骨架。保留[情绪/结构/镜头目的]，舍掉[具体设定/角色符号/画面复制]，第一刀先改成我们自己的冲突和视觉母题。
```

## 4. 精华转译总公式

```text
类型源头 + 观众感受 + 冲突规则 + 视觉母题 + 场面调度 + 镜头身体 + 声音记忆点 + 情绪节奏 + 原创替换 + Seedance可生成拆镜
```

拆解：

- 类型源头：电影、特摄、短片、广告、AI短片、纪录感、舞台感。
- 观众感受：停住、紧张、发笑、心软、燃起来、想追下去、想复看。
- 冲突规则：谁想要什么，阻碍是什么，规则如何升级。
- 视觉母题：反复出现的物件、颜色、光、动作、空间或姿势。
- 场面调度：人物站哪边，谁靠近，谁后退，空间如何改变关系。
- 镜头身体：观众是旁观者、参与者、被凝视者、道具、记忆还是人群中的一员。
- 声音记忆点：静音、呼吸、脚步、低频、机械声、童声、环境声、短促口头禅。
- 情绪节奏：先压住，再释放；先反常，再解释；先结果，再倒推。
- 原创替换：换角色、换场景、换道具、换关系、换动作触发点。
- Seedance可生成拆镜：每镜4-6秒，动作因果清楚，一个主要运镜，一个主要说话人。

## 4.1 原创替换矩阵

精华转译不能停在“保留感觉，换个故事”。每次吸收电影、特摄、短片或广告方法，都要把参考里的外壳拆掉，再换成自己的创作零件。

先填这张矩阵：

| 来源里的有效方法 | 可以留下的导演骨架 | 必须替换的外壳 | 新原创落点 | Seedance落地方式 |
| --- | --- | --- | --- | --- |
| 情绪压力 | 压迫、心软、燃、荒诞、悬疑的压力方向 | 原人物经历、原台词、原关系身份 | 新人物缺口和新选择代价 | 用动作和反应表现压力，不写原剧情 |
| 结构节拍 | 冷开场、三次升级、反转、余味回收 | 原桥段顺序、原谜题、原结尾动作 | 新场景任务和新信息释放 | 每镜只推进一个信息，入点出点清楚 |
| 场面调度 | 站位压迫、靠近/后退、中心物争夺 | 标志性构图、原机位组合、名场面走位 | 新空间、新中心物、新动线 | 先锁空间轴线，再写人物动作 |
| 视觉母题 | 反复出现的颜色、材质、物件功能 | 角色造型、Logo、专属道具、IP符号 | 新物件、新光源、新动作符号 | 母题首次出现、中段变形、结尾回收 |
| 镜头身体 | 旁观、贴身、过肩、道具、记忆、群像视角 | 可识别镜头截图、招牌运镜 | 新观众站位和摄影机身体限制 | 一个主要运镜，说明摄影机像谁 |
| 声音记忆 | 静音、呼吸、脚步、机械声、环境声先行 | 原曲、原声、口头禅、标志音效 | 新声音源、新静音点、新尾音回收 | 声音入点、落点、声音桥写进分镜 |
| 特摄奇观 | 现实基准、仪式停顿、规则触发、受力结果 | 英雄造型、变身口号、必杀技名、怪兽符号 | 新触发物、新能力代价、新受力对象 | 先现实，后异常，再给受力结果 |
| 广告大片感 | 悬念开场、产品介入、证据确认、记忆帧 | 原品牌表达、原产品包装、原广告画面 | 新痛点、新产品动作、新证明镜头 | 卖点必须通过可见变化证明 |

硬规则：

- 如果“必须替换的外壳”写不出来，先停止分镜，回到参考拆解。
- 如果“新原创落点”只是在原设定上改名字、改颜色、改职业，判定为换名复刻。
- 如果 Seedance 提示词里还出现真实作品名、角色名、Logo、台词、专属道具或可识别名场面，必须改成原创风格锁定句。
- 每次转译至少完成四项替换：角色关系、场景任务、视觉母题、声音记忆；特摄和广告还要替换能力规则或产品证明动作。

## 4.2 复刻风险闸门

写分镜前，用这四问拦一次：

1. 去掉参考名称以后，这个方案还讲得清吗？如果讲不清，说明靠的是原作外壳。
2. 换成三个完全不同片种后，这个方法还成立吗？如果不成立，说明学的是场面，不是方法。
3. 观众能不能用一句话复述新的角色任务？如果不能，说明原创核心不够强。
4. 结尾记忆帧是否来自新母题、新声音或新动作？如果还是原作品记忆，继续替换。

通过句：

```text
我留下的是[导演方法]，不是[参考外壳]；我把它换成[新人物关系]、[新场景任务]、[新视觉母题]和[新声音记忆]，所以这条片即使不提参考，也能独立成立。
```

## 5. 电影精华转译

电影感不是“黑边、雨夜、蓝橙光”。电影精华通常来自四件事：

1. 人物在选择，不是在摆拍。
2. 空间在施压，不只是背景漂亮。
3. 镜头有立场，不只是运动。
4. 声音比解释更早告诉观众情绪。

电影转译卡：

```text
电影源头感：[现实主义/悬疑/动作/奇幻/怀旧/公路/家庭/黑色幽默]。
人物选择：[角色必须在A和B之间做选择]。
空间压力：[门、窗、楼梯、车厢、餐桌、走廊、雨棚如何限制角色]。
镜头立场：[旁观/贴身/过肩/道具/记忆/监控/第二人称]。
情绪停顿：[角色说话前、伸手前、转身前、爆发后停半拍]。
声音先行：[脚步、雨声、机器声、远处广播、呼吸先进入]。
原创替换：[换成自己的角色、道具、场景和冲突]。
```

常用电影调度：

| 目标 | 调度方法 | Seedance写法 |
| --- | --- | --- |
| 压迫 | 角色被门框、桌子、墙角夹住 | 固定中近景，空间边界清楚，角色呼吸变浅 |
| 亲密 | 两人距离缩短，但台词少 | 过肩近景，手部停顿，眼神先躲再看 |
| 反转 | 先给结果，再露出原因 | 第一帧给异常结果，镜头慢慢揭示关键道具 |
| 余味 | 事件结束后多留一个动作 | 角色收拾物件、关灯、回头，没有解释性旁白 |

## 6. 特摄精华转译

特摄的核心不是“更炸”，而是“规则、尺度和仪式感”。观众相信奇观，是因为现实基准先站住了。

特摄转译公式：

```text
日常基准 + 异常征兆 + 变身/召唤仪式 + 能力规则 + 尺度对比 + 必杀前停顿 + 受力结果 + 人群反应
```

特摄导演卡：

| 模块 | 要写清 | 避免 |
| --- | --- | --- |
| 日常基准 | 街口、天台、教室、便利店、工厂、操场 | 一上来全是能量光 |
| 异常征兆 | 灯闪、杯水震动、玩具自己转头、影子变形 | 没原因直接爆炸 |
| 变身仪式 | 手部动作、道具触发、短暂停顿、光线包裹 | 长台词硬念设定 |
| 能力规则 | 触发条件、影响对象、限制代价 | 每秒换一种能力 |
| 尺度对比 | 人与巨物、玩具与城市、桌面与宇宙 | 没有参照物 |
| 必杀前停顿 | 呼吸静下来、镜头低机位、声音抽空 | 只堆特效 |
| 受力结果 | 地面裂、衣角震、角色后退、烟尘压过脚边 | 打完没有后果 |

Seedance特摄提示词骨架：

```text
4-6秒视频镜头。现实街区/教室/天台先保持可信，角色在[日常动作]中发现[异常征兆]。
镜头低机位或胸口视角，运动克制，只跟随角色一步。
[道具/手势]触发能力，光效从小范围开始，规则清楚，只影响[一个对象]。
必杀或奇观前停顿半秒，环境声短暂抽空，随后出现明确受力结果：[地面震动/物体后退/烟尘扩散/人群反应]。
避免无规则爆炸、过多粒子、角色造型漂移和乱码文字。
```

## 7. 短片精华转译

好短片通常只抓一个问题，不铺一个世界。

短片转译公式：

```text
一个反常结果 + 一个简单规则 + 一个角色选择 + 一个情绪转向 + 一个余味动作
```

短片导演卡：

| 短片类型 | 核心抓手 | 第一镜 | 结尾 |
| --- | --- | --- | --- |
| 高概念 | 一个世界规则变了 | 反常结果直接出现 | 规则落到人物选择上 |
| 治愈 | 一个微小伤口被看见 | 角色独自处理小麻烦 | 有人轻轻接住他 |
| 悬疑 | 一个信息不该在那里 | 道具或画面异常 | 留一个可复看细节 |
| 喜剧 | 认真对待荒唐事 | 角色严肃处理离谱问题 | 反应停顿比解释更好笑 |
| 情感 | 一个旧物带出缺席关系 | 手碰到旧物或听到旧声 | 没说出口的话被动作替代 |

Seedance短片落地原则：

- 每条镜头只推进一个信息。
- 反常画面要在前三秒看见。
- 重要文字后期加，画面只留干净区域。
- 余味不要靠大旁白，靠角色最后一个小动作。

## 8. 创意广告精华转译

广告里的电影感必须服务证明链。产品不是摆在画面里，而是改变了一个人的动作、选择或结果。

创意广告转译公式：

```text
痛点可视化 + 反常表达 + 产品动作介入 + 可见变化 + 证据镜头 + 人物反应 + 品牌记忆帧
```

广告大片感转译卡：

| 电影语法 | 广告用途 | 具体写法 |
| --- | --- | --- |
| 开场悬念 | 让观众停住 | 第一帧先给异常结果，不先念卖点 |
| 英雄登场 | 产品介入 | 产品通过动作解决问题，不只是亮相 |
| 规则升级 | 展示功能 | 功能每次只升级一层，观众看得懂 |
| 反应镜头 | 证明效果 | 人物眼神、手部、身体放松证明变化 |
| 记忆帧 | 留品牌 | 结尾固定一个动作、道具位置或色彩组合 |

## 9. 创意精华十张导演卡

| 卡名 | 适合 | 拍法 |
| --- | --- | --- |
| 反常开门卡 | 短剧、悬疑、广告 | 第一帧让门后出现不该出现的东西 |
| 道具觉醒卡 | 特效、可爱、产品 | 普通道具先有一个微小异常，再升级 |
| 仪式变身卡 | 特摄、品牌、角色IP | 手部动作、停顿、光线包裹、声音抽空 |
| 尺度反差卡 | 可爱、特摄、广告 | 小主体面对大任务，先建立参照物 |
| 空间压迫卡 | 短剧、动作、情感 | 角色被空间限制，靠近或后退代表关系变化 |
| 反应接力卡 | 喜剧、群像、广告 | 一个动作引发多人不同反应，最后一人慢半拍 |
| 声音先行卡 | 情感、悬疑、短片 | 声音先半拍进入，画面随后解释来源 |
| 必杀停顿卡 | 打斗、特效、特摄 | 爆发前静半秒，爆发后给受力结果 |
| 旧物回声卡 | 怀旧、公益、亲情 | 旧物触发声音，不直接解释回忆 |
| 记忆收口卡 | 广告、系列IP | 结尾留下固定动作、符号或可截图画面 |

## 11. 自检

输出前自问：

1. 我是不是只继承了结构、调度和情绪，没有复刻受保护角色、台词、Logo或标志性画面？
2. 观众感受是否具体，不只是“高级”“震撼”“电影感”？
3. 冲突规则是否清楚：谁想要什么，什么阻碍，怎样升级？
4. 视觉母题是否能反复出现并变成记忆点？
5. 镜头身体是否明确：观众站在哪里，摄影机像谁？
6. 声音是否有记忆点，而不是只写“配史诗音乐”？
7. 是否至少替换了角色关系、场景任务、视觉母题和声音记忆？
8. 去掉参考名称以后，方案是否仍能独立讲清？
9. 每条 Seedance 镜头是否4-6秒可生成、动作因果清楚、一个主要运镜？
10. 文字、字幕、品牌字是否默认后期添加？
11. 特摄、打斗和特效是否先建立现实基准和规则，再爆发？
12. 创意广告是否有证明链，而不是只有漂亮画面？
