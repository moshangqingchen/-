# AI超级导演类型公式手册

## 1. 使用方式

这份手册是AI超级导演的类型能力库。它的作用是把“可爱、治愈、特效、打斗、创意广告、短剧、搞笑、情感”等常见创作方向，拆成可以反复调用的创作公式。

当用户只给一句想法时，先判断主类型和副类型，再套用对应公式。如果一个项目同时包含多种类型，例如“可爱治愈广告”或“特效打斗短剧”，先确定主目标，再组合公式。

如果项目包含可爱、治愈、软萌、毛绒、小动物、幼儿园、温柔广告、情绪价值或“像绒耀幼儿园但要原创”的需求，类型公式之后必须调用可爱治愈、软萌群像与情绪修复导演引擎，把小主体大任务、微小伤口、温柔介入、反应停顿、情绪松动、群像角色秩序和可截图落点写清，再进入 Seedance 2.0 提示词。

如果项目包含创意广告、产品广告、信息流广告、种草、带货、转化、卖点、产品证明、功能证明或前后对比，类型公式之后必须调用创意广告、产品证明与转化镜头引擎，把痛点可视化、产品动作、可见变化、证据镜头、人物反应、品牌记忆帧和转化入口写清，再进入分镜和 Seedance 2.0 提示词。

如果项目包含短剧、竖屏短剧、爽剧、反转、悬疑、第一集、下一集、追更、站队、打脸、反杀或关系拉扯，类型公式之后必须调用短剧冲突、反转与追更钩子导演引擎，把主角欲望、阻碍者、关系压力、信息差、视觉伏笔、选择代价、反转释放和下一集问题写清，再进入分镜和 Seedance 2.0 提示词。

如果项目包含打斗、追逐、超能力、爆炸、特效奇观或动作看不清的问题，类型公式之后必须调用动作打斗、追逐与特效场面编排引擎，把空间基准、攻防节拍、触发规则、受力结果和声音打击点写清，再进入 Seedance 2.0 提示词。

如果项目包含吸取电影精华、电影感、像电影导演一样、特摄感、怪兽、变身、英雄登场、必杀技、创意短片、高概念短片、大片广告、品牌微电影或“像某类作品但要原创”，类型公式之后必须调用电影、特摄、短片与创意精华转译库，把参考精华层、观众感受、冲突规则、视觉母题、场面调度、镜头身体、声音记忆点、原创替换和 Seedance 可生成拆镜写清，再进入分镜和提示词。

默认输出顺序：

1. 类型判断
2. 核心公式
3. 故事或广告结构
4. 分镜规则
5. 镜头级提示词骨架
6. 升级方向

## 2. 可爱公式

### 2.1 适用场景

适合萌宠、儿童、玩具、小物件、轻食、饮品、生活方式、IP角色、轻松种草、治愈广告和社交传播短视频。

### 2.2 核心公式

可爱主体 + 具体小动作 + 亲近镜头 + 轻微反差 + 可记忆瞬间

公式拆解：

- 可爱主体：外形圆润、比例柔和、表情清楚、让人想靠近。
- 具体小动作：眨眼、歪头、踮脚、抱住、探头、偷看、蹭一下、轻轻拍打。
- 亲近镜头：中近景、特写、低机位、浅景深，让观众像在旁边看见它。
- 轻微反差：小小的主体做认真、笨拙、勇敢或一本正经的事。
- 可记忆瞬间：一个能截图传播的表情、姿势、动作或道具互动。

### 2.3 分镜规则

- 开头先给一个小动作，不要先解释背景。
- 镜头运动要轻：缓慢推镜、轻微跟拍、稳定横移。
- 多用特写表现触感：毛发、杯沿、手指、爪子、贴纸、包装边缘。
- 色彩要有主次：柔和底色配一个明亮记忆点。
- 音效要细：叮、啪嗒、轻轻吸气、小脚步、布料摩擦。

### 2.4 镜头提示词骨架

主体在场景中做具体小动作，近景或特写，柔和自然光，浅景深，圆润构图，轻快温暖色彩，一个可截图的可爱瞬间，细节清楚，动作明确。

### 2.5 常见失误

- 只写“很可爱”，没有具体动作。
- 主体太远，看不到表情和细节。
- 色彩全部甜腻，缺少一个清楚的视觉重点。
- 镜头没有变化，导致可爱感停留在静态展示。

### 2.6 升级方向

- 更萌：增加反差动作和表情特写。
- 更治愈：加入陪伴关系、微小伤口、温柔介入和慢节奏环境声。
- 更广告：让产品成为可爱动作的一部分。

## 3. 治愈公式

### 3.1 适用场景

适合情绪短片、生活方式广告、咖啡茶饮、家居、护肤、宠物、旅行、疗愈空间、慢节奏短视频。

### 3.2 核心公式

微小疲惫 + 温柔介入 + 慢节奏细节 + 情绪松动 + 安静落点

公式拆解：

- 微小疲惫：不是大苦难，而是一天很累、错过消息、下雨、失眠、孤单、紧绷。
- 温柔介入：一杯热饮、一只手、一盏灯、一只宠物、一阵风、一件产品。
- 慢节奏细节：光线变化、热气、衣角、脚步、窗帘、杯声。
- 情绪松动：人物从紧绷到放松，从低头到抬眼，从沉默到轻笑。
- 安静落点：最后一帧让观众想停留，而不是被硬推走。

### 3.3 分镜规则

- 第一镜给情绪状态：低头、停顿、疲惫手势或空房间。
- 中段用环境和细节推动，不靠大段台词。
- 镜头长度可以比普通短视频更长，但每镜都要有情绪变化。
- 光线从冷到暖、暗到亮、硬到软，是最常用的治愈弧线。
- 声音比台词重要：风声、雨声、杯声、脚步声、远处城市声。

### 3.4 镜头提示词骨架

人物处在微小疲惫的生活场景中，柔和环境光，缓慢稳定镜头，细节特写，温暖物品或陪伴关系介入，情绪逐渐放松，安静治愈氛围，真实生活质感。

### 3.5 常见失误

- 没有“伤口”，只有漂亮空镜。
- 节奏慢但没有变化。
- 治愈被写成鸡汤台词，而不是画面变化。
- 结尾太满，缺少留白。

### 3.6 升级方向

- 更电影：增加光线变化和空间调度。
- 更广告：让产品成为情绪修复的触发点，并用一个可见结果证明卖点。
- 更短剧：在治愈前加入误会或关系裂缝。

## 4. 特效公式

### 4.1 适用场景

适合科幻、奇幻、超能力、产品科技感广告、游戏宣传、短剧高概念开场、视觉奇观短片。

### 4.2 核心公式

现实基准 + 异常出现 + 规则升级 + 奇观爆发 + 人物反应 + 情绪落点

公式拆解：

- 现实基准：先让观众知道正常世界是什么样。
- 异常出现：一个细小但不合理的视觉事件。
- 规则升级：异常不是随机发生，而是形成可理解的规则。
- 奇观爆发：让画面进入高记忆点，例如空间折叠、时间暂停、能量释放。
- 人物反应：用眼神、后退、伸手、呼吸停顿证明奇观真实存在。
- 情绪落点：奇观最后要服务剧情、卖点或人物选择。

### 4.3 分镜规则

- 特效前必须有普通画面作对比。
- 特效规则要写清触发条件、影响对象和限制代价。
- 大特效前给一个安静停顿，增强爆发。
- 每次升级只改变一个核心规则，避免观众看不懂。
- 奇观镜头后必须接反应镜头。
- 声音设计要有层次：低频、空气震动、瞬间静音、能量尾音。

### 4.4 镜头提示词骨架

真实生活场景中出现超现实异常，物体或空间逐渐发生规则化变化，能量光效、粒子、空间扭曲或时间暂停，人物清晰反应，电影感光影，奇观递进，画面可信。

### 4.5 常见失误

- 一开始就大爆炸，没有现实基准。
- 特效很多，但不知道为什么发生。
- 没有人物反应，奇观像背景素材。
- 特效不服务故事或产品，只是堆视觉。

### 4.6 升级方向

- 更震撼：增加尺度对比和低频声音。
- 更高级：减少特效数量，强化规则感。
- 更广告：把产品卖点变成特效规则。

## 5. 打斗公式

### 5.1 适用场景

适合动作短片、热血短剧、武侠、近身搏斗、超能力战斗、游戏宣传、带冲突的创意广告。

### 5.2 核心公式

空间交代 + 目标明确 + 攻防试探 + 动线变化 + 关键打击 + 短暂停顿 + 反转胜负

公式拆解：

- 空间交代：门、桌子、墙角、楼梯、车辆、障碍物、出口。
- 目标明确：抢夺、逃跑、保护、阻止、反击、争取时间。
- 攻防试探：第一轮不要立刻决胜，要看出双方能力。
- 动线变化：从远到近、从站立到倒地、从开阔到狭窄。
- 关键打击：一次有重量、有后果的动作。
- 短暂停顿：呼吸、眼神、疼痛、环境声，让打击变重。
- 反转胜负：用道具、地形、心理、节奏或隐藏能力完成逆转。

### 5.3 分镜规则

- 先用广一点的镜头建立空间，再切近景。
- 先编排攻防节拍：谁逼近、谁后退、谁失衡、谁反击。
- 关键动作要让观众看清开始、接触和结果。
- 快剪只用于增强节奏，不能遮盖动作逻辑。
- 每段动作都要有因果：因为躲避所以撞到桌子，因为失衡所以被压制。
- 打击点要配声音、表情或短暂停顿。

### 5.4 镜头提示词骨架

明确空间中的动作冲突，双方目标清楚，先建立场地关系，再进入近身攻防，动作动线清晰，关键打击有重量，短暂停顿后反转，紧张节奏，电影动作场面。

### 5.5 常见失误

- 只写“激烈打斗”，没有空间和动作路径。
- 镜头太碎，观众不知道谁在哪。
- 每一击都一样重，缺少节奏。
- 胜负没有原因，只是突然赢。

### 5.6 升级方向

- 更燃：增加目标代价和反杀点。
- 更真实：强化疲惫、失误、疼痛和空间限制。
- 更特效：加入规则清楚的能力变化。

## 6. 创意广告公式

### 6.1 适用场景

适合品牌广告、产品短视频、信息流广告、种草视频、发布会概念片、电商主图视频、服务类广告。

### 6.2 核心公式

痛点钩子 + 反常识表达 + 产品动作介入 + 前后对比 + 证据镜头 + 记忆收束

公式拆解：

- 痛点钩子：观众立刻意识到“这和我有关”。
- 反常识表达：用夸张、反转、误会、视觉奇观或反差吸引注意。
- 产品动作介入：产品必须做事，而不是被介绍。
- 前后对比：展示使用前后的变化。
- 证据镜头：细节、数据、反应、场景结果。
- 记忆收束：最后留一句话、一个动作或一个画面符号。

### 6.3 分镜规则

- 前3秒不要铺垫品牌历史，直接进入痛点或反常识画面。
- 卖点要变成动作：清洁、提亮、加速、保护、连接、修复、放大。
- 产品特写要有功能含义，不只是漂亮展示。
- 对比镜头要同构：同一角度、同一人物、同一环境下变化更清楚。
- 结尾必须能截图成传播物。
- 先写广告证明链：卖点声明、产品动作、可见变化、人物反应、品牌记忆帧。

### 6.4 镜头提示词骨架

用户痛点以强钩子开场，产品通过明确动作介入解决问题，前后对比清楚，细节证据镜头突出卖点，结尾形成品牌记忆画面，节奏紧凑，商业广告质感。

### 6.5 常见失误

- 一上来讲品牌理念，观众还没被抓住。
- 卖点停留在口播，没有画面证明。
- 产品出现太晚或出现后没有行动。
- 结尾没有记忆点。

### 6.6 升级方向

- 更转化：强化痛点和结果证明。
- 更高级：用隐喻或类型片包装卖点。
- 更传播：制造一句能被复述的短句。

调用规则：先用创意广告、产品证明与转化镜头引擎确认卖点能否被画面证明；如果卖点涉及医疗、金融、法律、功效、真实品牌或竞品比较，先进入合规库保守处理。

## 7. 短剧公式

### 7.1 适用场景

适合竖屏短剧、剧情短视频、连续剧集开头、爽剧、情感、都市、悬疑、反转、奇幻、动作短剧。

### 7.2 核心公式

人物欲望 + 阻碍者 + 开场钩子 + 冲突升级 + 秘密或误会 + 反转释放 + 下一集悬念

公式拆解：

- 人物欲望：主角想得到什么、证明什么、保护什么或逃离什么。
- 阻碍者：另一个人、制度、误会、身份差距、危险或主角自己的弱点。
- 开场钩子：一句冲突台词、一个危险动作、一个身份反转、一个强选择。
- 冲突升级：每场都让代价更大。
- 秘密或误会：让观众比角色知道更多，或让角色以为错了。
- 反转释放：让压抑的情绪爆开。
- 下一集悬念：结束在新问题，而不是全部解释完。

### 7.3 分镜规则

- 第一场直接给冲突，不慢热。
- 关键台词用近景或特写，保留表情变化。
- 每集至少有一个“观众想评论”的点：太气、好爽、怎么会这样、他终于来了。
- 反转前埋一个视觉伏笔，例如戒指、合同、伤痕、手机消息、站位变化。
- 结尾用动作或画面悬念，不只靠旁白。

### 7.4 镜头提示词骨架

竖屏短剧开场，主角欲望明确，阻碍者制造冲突，第一场直接进入高压情境，近景捕捉表情和关键台词，中段误会或秘密升级，结尾反转并留下悬念，节奏强。

### 7.5 常见失误

- 开头解释太多，冲突来得太晚。
- 主角没有明确欲望。
- 反转没有伏笔。
- 每场只是聊天，没有新的代价。

### 7.6 升级方向

- 更爽：让压迫更强，释放更痛快。
- 更悬疑：把信息差拆成多层。
- 更情感：让每次误会都伤到人物最在意的东西。

调用规则：先用短剧冲突、反转与追更钩子导演引擎确认第一镜冲突、关系压力、视觉伏笔和下一集问题；关键台词、手机字、合同字和屏幕文字默认后期添加。

## 8. 搞笑公式

### 8.1 适用场景

适合反差短视频、卡通群像、校园/幼儿园设定、职场荒诞、家庭小品、产品搞笑广告、无厘头AI短片。

### 8.2 核心公式

正常规则 + 小人物认真执行 + 反差误解 + 节奏停顿 + 意外升级 + 荒诞收束

公式拆解：

- 正常规则：先建立一个观众熟悉的场景，例如上课、排队、考试、开会、吃饭。
- 小人物认真执行：角色越认真，反差越好笑。
- 反差误解：角色把简单事理解成大事，或把大事当成小事。
- 节奏停顿：笑点前留半秒反应，让观众先意识到不对劲。
- 意外升级：第一次笑点后不能结束，要再多一层更离谱的结果。
- 荒诞收束：最后用一句短台词、一个动作或一个集体反应封口。

### 8.3 分镜规则

- 第一镜给正常场景，第二镜立刻打破正常。
- 搞笑镜头要保留反应，不能只展示事件。
- 用近景捕捉呆住、装镇定、强行解释、集体沉默。
- 群像搞笑要给每个角色一个固定性格：认真、爱哭、嘴硬、捣乱、慢半拍。
- 收尾不要解释笑点，让画面自己收住。

### 8.4 镜头提示词骨架

熟悉生活场景中出现荒诞误解，小角色认真执行离谱任务，表情反应清楚，节奏有停顿和升级，卡通或真人喜剧质感，结尾用一句短台词或集体反应形成笑点。

### 8.5 常见失误

- 只有奇怪，没有规则，观众不知道哪里好笑。
- 台词太长，笑点被解释没了。
- 反应镜头缺失，事件发生但没有喜剧节奏。
- 每个角色都一样，群像没有记忆点。

### 8.6 升级方向

- 更可爱：把角色做成软萌群像，增加小动作和表情包瞬间。
- 更广告：让产品成为误会的解决者或升级道具。
- 更短剧：把笑点变成下一集悬念。

## 9. 情感公式

### 9.1 适用场景

适合亲情、怀旧、公益、寻亲、告别、重逢、旧物回忆、人生故事、真实事件改编、温情广告。

### 9.2 核心公式

旧物触发 + 缺席的人 + 被压住的情绪 + 细节回忆 + 当下回应 + 留白落点

公式拆解：

- 旧物触发：照片、录音、旧门槛、校服、饭盒、车票、玩具、手写纸条。
- 缺席的人：不在场的亲人、走散的人、离开的朋友、无法再说话的人。
- 被压住的情绪：人物不直接哭，先忍住、停顿、转移话题。
- 细节回忆：一个动作比一段解释更有效，例如把杯子摆正、摸旧照片边角。
- 当下回应：现在的人做出一个小选择，回应过去的遗憾。
- 留白落点：结尾不把情绪说满，让观众自己补完。

### 9.3 分镜规则

- 开头用物件或声音，不急着解释人物关系。
- 情感爆点前要有克制，不能一上来大哭。
- 多拍手、背影、旧物、门口、空椅子、窗边光。
- 旁白可以用，但必须短，画面承担主要情绪。
- 结尾用安静动作收束，例如关灯、放回照片、把饭端上桌。

### 9.4 镜头提示词骨架

怀旧生活场景，旧物或旧录音触发回忆，人物克制情绪，细节特写推动故事，过去与当下形成呼应，温柔自然光，真实质感，结尾留白，情感真挚不煽情。

### 9.5 常见失误

- 只堆悲伤，没有具体关系。
- 台词替代画面，观众被告知而不是被打动。
- 情绪过满，没有克制和留白。
- 真实事件改编缺少尊重，变成廉价催泪。

### 9.6 升级方向

- 更治愈：让遗憾被一个当下动作轻轻修复。
- 更公益：把个人故事连接到社会议题。
- 更广告：让品牌价值成为陪伴、守护或重逢的媒介。

## 10. 组合公式

### 10.1 可爱治愈广告

可爱主体 + 微小疲惫 + 产品温柔介入 + 小动作修复情绪 + 可截图结尾

适合宠物、咖啡、甜品、家居、护肤、文创、生活方式品牌。

调用规则：先用可爱治愈、软萌群像与情绪修复导演引擎写清小主体大任务、温柔介入方式、情绪松动动作和品牌记忆帧，再进入分镜和 Seedance 2.0 提示词。

### 10.2 特效打斗短剧

现实冲突 + 空间交代 + 能力异常 + 近身攻防 + 规则升级 + 反转胜负 + 悬念收尾

适合超能力、游戏、热血、奇幻、短剧开篇。

### 10.3 悬疑广告

异常问题 + 错误猜测 + 产品揭示真相 + 证据镜头 + 记忆收束

适合科技、安防、清洁、检测、智能设备、效率工具。

### 10.4 治愈短剧

人物疲惫 + 关系裂缝 + 温柔误会 + 细节修复 + 情绪释放 + 新关系悬念

适合情感、家庭、都市、宠物、生活向短剧。

### 10.5 可爱搞笑群像

软萌角色群 + 熟悉规则 + 认真误解 + 集体反应 + 表情包收尾

适合幼儿园、动物班级、玩具世界、办公室拟人、家庭小剧场。

调用规则：先用可爱治愈、软萌群像与情绪修复导演引擎固定群像角色秩序和轮流反应，避免一群角色同时乱动。

### 10.6 怀旧情感公益

真实故事 + 旧物触发 + 缺席关系 + 克制回忆 + 当下回应 + 公益落点

适合寻亲、亲情、老人、小人物善意、城市记忆、社会议题。

## 12. 导演自检

每次调用类型公式后，AI超级导演都要快速自检：

1. 类型是否清楚？
2. 观众前3秒为什么会继续看？
3. 有没有一个可记忆画面？
4. 镜头是否能拍、能生成、能剪？
5. 画面是否服务情绪、冲突或卖点？
6. 是否有升级空间？

这套自检保证类型公式不会变成套路堆砌，而是持续服务更强的导演判断。
