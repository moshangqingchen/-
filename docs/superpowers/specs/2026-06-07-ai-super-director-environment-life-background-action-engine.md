# AI超级导演环境生命、背景动作与现场细节导演引擎

## 1. 定位

这套引擎专门处理“画面太空、场景像空壳、背景不活、没有生活气息、世界不像真的在运转、路人怎么安排、环境细节怎么加、空间怎么呼吸”的需求。

它不替代场面调度库。场面调度库解决人物站位、空间轴线和主动作关系；本引擎解决主戏之外的现场生命：背景人物的轻动作、桌面痕迹、远处声音、风、光、物件小变化和环境对主戏的反应。

默认判断：

```text
我会这样拍：主戏不要被背景抢走，但背景不能死。给场景留一个轻动作、一点使用痕迹和一个远处声音，让观众感觉这件事发生在一个还在运转的世界里。
```

核心公式：

```text
主戏任务 + 场景身份 + 环境生命点 + 背景轻动作 + 使用痕迹 + 远处声音 + 主体不被抢 + 保底静止点
```

## 2. 触发词

用户出现以下说法时，默认调用本引擎：

- “场景太空”“画面太空”“空间像空壳”“背景不活”“场景不真实”。
- “生活气息”“现场感”“环境细节”“背景动作”“背景人物”“路人怎么安排”。
- “世界感”“场景怎么呼吸”“不要像棚拍”“不要像摆拍”“像真实发生”。
- “办公室怎么活”“教室怎么活”“街道怎么活”“家里怎么有生活痕迹”。
- “背景别抢戏”“路人不要乱”“背景人物不要融合”“群演怎么安排”。

## 3. 环境生命不是堆杂物

环境生命有三个原则：

1. 背景只证明世界在运转，不承担主信息。
2. 一镜只留一个环境生命点，不同时安排路人、宠物、屏幕、车流、风、道具乱动。
3. 环境动作要和主戏气质一致，不能为了热闹而热闹。

常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 背景太干净 | 像样板间或棚拍 | 加一个使用痕迹：杯印、翻开的书、椅子没推回 |
| 背景太乱 | 主戏看不清 | 删到只剩一个环境生命点 |
| 路人乱走 | 抢主动作和轴线 | 路人只在远景轻移动，不穿过主角脸和手 |
| 所有人都反应 | 像舞台表演 | 只让一个背景角色轻停顿，其他人继续自己的事 |
| 环境声太满 | 情绪被噪音盖住 | 只保留一个可辨认声音点 |
| AI背景融合 | 人物手脸混乱 | 背景人物减少、虚化、轻动作、远离主体边缘 |

## 4. 环境生命七问

开拍前先定：

1. 这是什么场景身份：家、办公室、教室、街边、车内、店铺、医院、展厅、直播间还是夜市？
2. 主戏是什么：冲突、产品证明、情感停顿、喜剧误会、特效触发还是采访证据？
3. 背景可以活在哪里：远处、窗外、桌面、门口、墙边、地面、声音里还是光影里？
4. 哪一个环境生命点最适合：人、物、风、光、声音、痕迹、时间变化？
5. 它会不会抢主角动作、产品动作、口型或关键信息？
6. 它能不能给剪辑提供声音桥、反应点或保底出点？
7. Seedance 2.0 会不会把背景人物融合、文字生成乱码或动作变乱？

## 5. 环境生命卡

| 卡名 | 用途 | 拍法 | 避免 |
| --- | --- | --- | --- |
| 使用痕迹卡 | 让空间像被人用过 | 杯印、折角、鞋、椅子、钥匙、半开的抽屉 | 满桌杂物抢主戏 |
| 远处人声卡 | 建立真实现场 | 远处低声交谈、教室翻书、办公室键盘声 | 多人画内同时说话 |
| 背景轻停顿卡 | 强化冲突或反常 | 一个路人短暂停下看一眼，又继续走 | 所有人集体回头 |
| 风动卡 | 治愈、悬疑、空场情绪 | 窗帘、纸张、衣角、树影轻动 | 大风吹乱主体动作 |
| 光影变化卡 | 时间、情绪、秘密 | 云影、车灯、屏幕冷光、门缝光轻变 | 频繁闪烁 |
| 生活循环卡 | 世界继续运转 | 店员擦杯、孩子远处跑过、同事拿文件 | 过多角色同框 |
| 道具自带声卡 | 真实触感 | 杯子落桌、门锁声、抽屉声、纸页声 | 声音点太多 |
| 时间痕迹卡 | 让场景有过去 | 墙上痕迹、旧贴纸、磨损桌角、植物干叶 | 生成可读文字 |
| 空间呼吸卡 | 避免画面太满 | 背景留一点安静空位，只有环境声 | 空到没有情绪锚点 |
| 结果余波卡 | 事件发生后环境轻反应 | 灯轻晃、纸落下、远处人停半拍 | 夸张灾难化 |

## 6. 场景身份与真实使用痕迹矩阵

场景身份不能只写“办公室、厨房、教室”。要写清这个空间最近被谁用过、留下什么痕迹、有什么声音还在继续。

```text
场景身份 = 最近使用者 + 正在进行的生活循环 + 一个使用痕迹 + 一个声音来源 + 一个不抢戏背景动作
```

| 场景 | 最近被谁使用过 | 使用痕迹 | 声音来源 | 不抢戏背景动作 | 禁用 |
| --- | --- | --- | --- | --- | --- |
| 办公室 | 加班的人、刚开完会的团队 | 半开的笔记本、未收的杯子、椅子没推回 | 键盘声、打印机轻响、远处低声讨论 | 远处同事拿文件经过 | 白板大字、多人同时说话 |
| 厨房 | 正在做饭的人、刚吃完饭的家人 | 水槽水珠、案板痕迹、蒸汽、半开的调料瓶 | 水壶声、锅盖轻响、冰箱低鸣 | 背景蒸汽轻散或水滴落下 | 满桌杂物、火焰过大抢戏 |
| 幼儿园/教室 | 孩子、老师、刚下课的人 | 歪掉的小椅子、散开的蜡笔、折角作业纸 | 翻书声、远处脚步、轻轻笑声 | 远处孩子慢半拍抬头 | 多个孩子围上来、可读黑板字 |
| 车内 | 刚开车的人、赶路的人 | 安全带压痕、杯架水杯、后座外套 | 转向灯、雨刷、路噪、导航提示后期加 | 车窗外光影扫过 | 复杂屏幕文字、危险驾驶动作 |
| 夜市/街边 | 摊主、路人、刚买东西的人 | 塑料袋、一次性餐盒、油烟、湿地反光 | 远处叫卖声、锅铲声、车流声 | 一个路人远处停半拍又走 | 人群穿过主体、摊牌文字乱码 |
| 医院走廊 | 候诊者、护士、家属 | 塑料椅空位、纸杯、靠墙的拐杖 | 轮子声、广播后期、远处脚步 | 护士远处推车经过 | 可读病历、医疗承诺、拥挤病患 |
| 家里客厅 | 刚回家的人、等人回来的人 | 沙发褶皱、遥控器、拖鞋、杯印 | 冰箱声、楼上脚步、窗外车声 | 窗帘轻动或门缝光变化 | 样板间式整洁、满墙照片文字 |
| 卧室 | 刚醒的人、失眠的人 | 被角、床头水杯、充电线、衣物搭椅 | 呼吸、布料摩擦、远处闹钟后期 | 床帘轻动或手机微亮 | 暧昧化过度、杂物过多 |
| 门店/咖啡店 | 店员、顾客、刚营业的空间 | 账单夹、杯垫水痕、擦过一半的桌面 | 咖啡机、门铃、杯碟轻响 | 店员远处擦杯 | Logo和价目表直接生成 |
| 工厂/车间 | 工人、质检员、刚完成一批产品 | 手套、工具位置、材料边角、警示线 | 机器低频声、推车声、金属轻碰 | 远处一盏工作灯闪一下 | 复杂机械动作、危险生产细节 |
| 酒店/民宿 | 刚入住的人、整理房间的人 | 行李箱、拖鞋、半拉窗帘、床尾毯 | 门卡声、空调声、走廊脚步 | 窗外光线慢变 | 空房扫拍、品牌字乱生成 |
| 展厅/发布会 | 工作人员、参观者、布展团队 | 未完全收起的线缆、手套、样机擦拭痕 | 低声介绍、脚步、设备低鸣 | 远处人员调整展台灯 | 大屏乱码、多人围观抢主产品 |

判断句：

```text
场景真实感不是多放东西，而是让观众感觉“刚有人在这里生活、工作、等待或离开”。
```

## 7. 类型专用背景调度

### 7.1 可爱治愈

环境不要复杂，只要软一点。

```text
背景生命点：小道具轻晃、远处角色慢半拍反应、桌面有小任务痕迹。
```

拍法：

- 背景角色只做轻反应：眨眼、抱住本子、慢慢抬头。
- 小主体承担主任务，背景给秩序。
- 声音用杯声、脚步、布料声，不要热闹BGM盖住反应。

### 7.2 情感治愈

环境要像有人生活过。

```text
背景生命点：旧物位置、窗帘轻动、远处水声、桌面杯印。
```

拍法：

- 不要让空间太干净。
- 背景痕迹要服务缺席关系：空椅子、没收好的鞋、未关严的门。
- 环境声可以替人物说话。

### 7.3 悬疑短剧

背景生命负责制造不确定。

```text
背景生命点：远处门缝光、脚步声、窗外影子、桌面物件位置变化。
```

拍法：

- 背景只露一条线索，不要把真相全给。
- 让主角没注意到，观众先看到一点。
- 避免满屏黑和随机路人乱动。

### 7.4 创意广告

环境生命负责证明产品改变世界。

```text
背景生命点：痛点前环境混乱，产品动作后环境秩序变清楚。
```

拍法：

- 产品前：桌面乱、噪声多、灯光散、人物烦。
- 产品后：一个环境细节变顺，不要全世界一起变魔法。
- 背景人物只做确认，不做夸张惊喜。

### 7.5 纪实采访

环境生命负责可信度。

```text
背景生命点：被拍者防御动作、远处现场声、工作痕迹。
```

拍法：

- 背景不能像摆好的广告布景。
- 保留一点不完美：衣角、桌面、纸张、设备声。
- 不要伪造真实机构、真实媒体标识或可读证件。

### 7.6 办公室/企业片

环境生命负责“工作真的在发生”。

```text
背景生命点：同事轻声沟通、文件递过、键盘声、白板后期文字区。
```

拍法：

- 背景同事不看镜头。
- 每个背景人物只做一个轻任务。
- UI、数据、客户名和白板字后期添加。

### 7.7 街道/城市/旅行

环境生命负责地方性。

```text
背景生命点：摊主动作、车声、远处人群秩序、地方材质。
```

拍法：

- 路人只给方向和节奏，不要挡主体。
- 地方证据用声音、手艺、摊位、脚步和光线。
- 不要随机人群堆满画面。

## 8. Seedance 2.0 可生成性规则

环境生命对 AI 视频是高收益、中风险。默认规则：

1. 背景人物最多一到三个，且只做轻动作。
2. 背景人物不要贴着主体边缘，避免融合。
3. 背景动作不要穿过主角脸、嘴、手、产品或关键道具。
4. 不直接生成可读海报、路牌、白板字、屏幕字、Logo 和字幕。
5. 一镜只保留一个环境生命点。
6. 环境动作最好在入点或出点发生，不要贯穿全镜抢戏。
7. 如果主镜头有口型、产品手部、打斗或特效，背景必须降到更轻。

风险评级：

| 镜头 | 风险 | 处理 |
| --- | --- | --- |
| 窗帘轻动、桌面杯声 | A | 可直接写入 |
| 远处一个路人停半拍 | B | 虚化或远景，动作轻 |
| 办公室两人背景递文件 | B | 远离主体边缘，不说话 |
| 夜市多人走动加主角口播 | C | 减少人群，改画外环境声 |
| 群演围观、多人同框反应 | D | 拆成主角反应 + 一个背景轻停顿 |

## 12. 自检

输出前检查：

1. 主戏是否仍然一眼清楚？
2. 是否只保留一个环境生命点？
3. 背景动作是否不抢脸、嘴、手、产品和关键道具？
4. 使用痕迹是否服务场景身份，而不是乱堆杂物？
5. 是否说清最近被谁使用过，而不是只写一个空间名？
6. 使用痕迹、声音来源和背景动作是否属于同一个场景身份？
7. 远处声音是否只有一个可辨认声音点？
8. 背景人物是否数量少、动作轻、不会融合？
9. 可读文字、Logo、屏幕字、路牌和海报是否规划为后期添加？
10. 环境生命是否能提供声音桥、反应点或保底出点？
