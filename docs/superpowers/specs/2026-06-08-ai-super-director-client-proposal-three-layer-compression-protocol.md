# AI超级导演客户提案三层压缩表达协议

## 1. 定位

这套协议用于把完整导演方案压成三层交付：

1. 客户版摘要：让客户一眼判断值不值得买单。
2. 导演版细案：保留创作判断、取舍和现场调度。
3. 执行版提示词：让 Seedance 2.0、剪辑、后期和团队能直接开工。

它不替代项目交付包、类型成片交付标准包和成片级分镜编译器。它只负责压缩表达层级，避免客户被长分镜和技术细节淹没，也避免执行团队只拿到漂亮口号。

## 2. 触发信号

用户出现以下表达时，先调用本协议：

- 给客户看
- 客户提案
- 客户看不懂
- 提案压缩
- 一页提案
- 客户版摘要
- 导演版细案
- 执行版提示词
- 别写太长
- 客户能一眼懂
- 客户会不会买单
- 先给客户版
- 这版怎么向甲方解释

默认开口：

```text
我会这样给客户看：
这不是完整导演碎念版，先压成客户能一眼判断价值的摘要；导演细案和执行提示词放在后面，给内部团队继续开工。
```

## 3. 三层职责

### 3.1 客户版摘要

客户版只回答六个问题：

```text
一句话价值：
客户为什么会在乎：
第一帧看见什么：
产品或故事怎么证明：
观众记住什么：
执行风险如何控制：
客户下一步确认什么：
```

客户版禁用：

- 不堆镜头表。
- 不讲 Seedance 参数、镜头生成失败变量、负面提示词细节。
- 不把导演内部犹豫写给客户看。
- 不用“高级感、电影感、爆款感”单独当理由，必须落到可见证明。

客户版必须做到：

- 一句话价值能被客户转述。
- 第一帧能被客户想象。
- 证明链能对应产品卖点、故事冲突或品牌利益。
- 风险控制讲得稳，不吓客户，也不假装没有风险。

### 3.2 导演版细案

导演版保留判断，不急着变成提示词：

```text
导演判断：
保留：
舍掉：
第一刀：
类型主场面：
结构节拍：
关键场面调度：
视觉记忆：
声音记忆：
审片第一刀：
```

导演版要回答：

- 这条片押哪一场赢。
- 哪些好看但会拖垮主线的东西要舍掉。
- 第一帧、前三秒、中段升级和结尾余味分别靠什么成立。
- 如果客户只给一次修改机会，第一刀先改哪里。

### 3.3 执行版提示词

执行版只写能拍、能剪、能生成的动作：

```text
镜头：
任务：
入点：
出点：
画面动作：
摄影机：
声音：
Seedance 2.0 提示词：
后期文字/Logo/字幕安全区：
可生成风险：
失败第一刀：
```

执行版禁用：

- 不写营销空话。
- 不把客户价值口号塞进视频画面文字。
- 不让 Seedance 直接生成可读中文、Logo、品牌字或长字幕。
- 不在一条镜头里塞多个主动作、多人台词、复杂转场和高风险特效。

## 4. 压缩顺序

先压客户版，再展开导演版，最后写执行版。

```text
完整想法
-> 客户能听懂的价值
-> 导演必须守住的判断
-> 执行团队能生成的镜头动作
```

不要反过来从提示词摘要成客户版。提示词会天然偏技术，容易让客户看见过程而不是价值。

## 5. 客户版判断闸门

客户版摘要写完后，必须自检：

| 闸门 | 通过标准 | 失败第一刀 |
| --- | --- | --- |
| 一眼懂 | 客户 10 秒内知道这条片卖什么 | 重写一句话价值 |
| 有画面 | 第一帧不是抽象概念 | 改成具体人物、产品、动作或场景 |
| 有证明 | 卖点不是口号，有可见变化 | 增加产品动作或故事后果 |
| 有记忆 | 观众能复述一个画面或动作 | 补视觉母题或声音回声 |
| 能执行 | 风险控制说清楚测试、拆镜或后期兜底 | 增加最小测试小样和失败第一刀 |

## 7. 场景适配

### 7.1 广告提案

客户版重点：

- 客户为什么会在乎：痛点、差异、转化入口。
- 证明链：产品动作介入、可见变化、人物反应。
- 风险控制：产品外观、手部证明、字幕和品牌字后期添加。

导演版重点：

- 不要先讲品牌口号，先押产品证明场。
- 第一刀通常改第一帧、证明动作或反应确认。

### 7.2 品牌片和企业片

客户版重点：

- 客户为什么会在乎：品牌可信度、行业压力、团队能力。
- 证明链：具体任务、协作动作、客户或使用者结果。
- 风险控制：避免大楼、握手、口号堆砌。

导演版重点：

- 把抽象价值拍成一个真实工作动作。
- 团队群像一镜只保留一个主动作或主说话人。

### 7.3 短剧和剧情提案

客户版重点：

- 客户为什么会在乎：前三秒冲突、关系钩子、追更问题。
- 证明链：身份问题、选择代价、反转释放。
- 风险控制：对白拆短，复杂关系用反应镜头和字幕兜底。

导演版重点：

- 第一镜不要解释背景，先给冲突或反常结果。
- 人物不直接演情绪，演防御动作和破防收回。

### 7.4 文旅、公益和形象类

客户版重点：

- 客户为什么会在乎：目的地、行动、城市或公共价值可被记住。
- 证明链：路线、人物停顿、地方证据或微小行动。
- 风险控制：不要空镜堆砌，不靠大字口号。

导演版重点：

- 先定一个观众愿意停下来的动作。
- 结尾留一个可复述的余味画面。

## 8. 与其他能力的衔接

- 如果用户只给一句模糊需求，先调用一页式实战指挥台或提问克制与直接开拍协议，再调用本协议压缩给客户看。
- 如果用户要完整成片，先调用类型成片交付标准包或成片级分镜编译器，再用本协议分层。
- 如果客户已经反馈不满意，先调用客户反馈到导演动作翻译协议，再用本协议重新组织客户版。
- 如果用户问“这版稳不稳”，客户版之后接交付前红队审查和最小测试小样选择器。

## 9. 回归测试

输入：

```text
给客户看一版，不要太长，但后面也要能直接给团队做 Seedance。
```

合格输出必须包含：

1. 客户版摘要，而且第一屏不出现长镜头表。
2. 导演版细案，写清保留、舍掉和第一刀。
3. 执行版提示词，写清入点、出点、Seedance 2.0 提示词、后期和风险。
4. 客户版不暴露过多生成失败变量；执行版不写营销空话。
