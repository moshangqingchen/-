# AI超级导演错误记忆与自动避坑案例库

## 1. 定位

这份案例库让 AI超级导演把错误变成下一次的自动避坑动作。它不是普通复盘，也不是情绪化道歉；它负责把一次翻车压成可触发、可检查、可回归的错误记忆卡。

一句话原则：

```text
错过一次可以，重复同一种错不行。
```

默认目标：

1. 用户说“下次别再犯”时，能立刻写入错误记忆。
2. 用户说“又跑偏了”时，能判断是不是旧错复发。
3. 生成、分镜、客户提案和发布前检查，都能调用旧错提醒。
4. 错误不只被记住，还要变成禁用项、第一刀、回归题或输出门禁。

## 2. 什么时候必须启用

遇到以下信号，默认调用本库：

1. 用户说“记住这个错误、下次别再犯、以后不要这样、又错了、又跑偏了、为什么老是这样”。
2. 同一类问题第二次出现，例如口型穿帮、人物漂移、动作看不清、信息说早、客户觉得空。
3. 一条 Seedance 镜头连续两轮失败，且失败症状相似。
4. 发布前或交付前发现重大漏项，例如字幕安全区、品牌字后期、可生成性评级、合规提醒缺失。
5. 用户指出输出不像真人导演、像模板、太空、太散、只有形容词。
6. 一次错误已经能被写成“触发词 -> 禁用项 -> 第一刀 -> 通过标准”。

不必启用的情况：

1. 用户只是临时改审美，不代表默认规则要变。
2. 错误来自用户明确要求的特殊实验。
3. 只是措辞不喜欢，但没有影响判断、生成、剪辑或交付。
4. 还无法定位原因，只能先进入回放验片或系统调试。

## 3. 错误记忆卡格式

每条错误必须写成 9 个字段：

```text
错误编号：
【类型-日期-序号】

触发信号：
用户、素材或输出里出现什么提示？

错误症状：
具体错在哪里，不能只写“不好”。

根因判断：
是路由错、任务过载、信息释放错、空间错、口型风险、交付漏项，还是审美误判？

下次自动提醒：
以后遇到什么场景，先提醒哪一句？

禁用项：
下次禁止怎么做？

第一刀：
下次先改一个什么变量？

通过标准：
怎样证明这次没有再犯？

回写位置：
写回哪张能力卡、门禁、黄金样例或回归题？
```

禁止写成空泛记忆：

```text
以后要更认真。
以后要更高级。
以后注意细节。
以后别写太AI。
```

这些不会改变下一次输出，不能算错误记忆。

## 4. 错误分级

| 等级 | 判断标准 | 处理动作 |
| --- | --- | --- |
| S级 | 会导致客户误解、合规风险、明显侵权、成片不可交付 | 立刻写错误记忆卡，补 README 触发入口，加入红队检查 |
| A级 | 会导致 Seedance 大概率失败、剪不起来、角色漂、口型穿帮 | 写错误记忆卡，补可生成性或连续性门禁 |
| B级 | 会导致观众看不懂、第一帧不抓人、中段平、信息释放错 | 写第一刀和回归题 |
| C级 | 影响审美、语言像模板、现场感不足 | 写坏写法和好写法对照 |
| D级 | 一次性偏好或轻微措辞问题 | 不写入长期库，只在当前输出修正 |

判断句：

```text
如果下次再犯，是否会让作品失败、客户不信或生成跑坏？
```

答案是“会”，至少按 B级处理。

## 5. 常见错误记忆索引

| 错误类型 | 触发信号 | 下次自动提醒 | 第一刀 |
| --- | --- | --- | --- |
| Seedance 单镜过载 | 一镜同时要群像、口型、强运镜、特效、字幕 | 这一镜只能保一个主任务 | 拆成主动作、反应、证据或后期项 |
| 角色连续性失守 | 角色漂、服装变、道具消失 | 先锁角色、服装、道具和动作状态 | 不升级运镜，先稳角色 |
| 口型高风险 | 长台词、多人口播、嘴部不可见 | 一镜一个主说话人，短句优先 | 长句改画外声、反应镜或字幕 |
| 中文文字乱码 | 屏幕字、字幕、品牌字直接生成 | 可读文字后期添加 | 画面只留干净安全区 |
| 信息释放太早 | 开头把秘密、卖点或反转全说破 | 先欠一个信息债 | 改第一镜，只给结果或半个证据 |
| 信息藏太久 | 观众看不懂主角在干什么 | 每两三镜要还一小笔信息债 | 补动作证据或反应确认 |
| 广告卖点空 | 高级、好用、智能、治愈但无证明 | 卖点必须变成可见动作 | 补手部任务、结果变化和人物反应 |
| 打斗看不清 | 环绕、爆炸、多人冲突、无受力结果 | 先定空间和接触点 | 拆起点、触发、受力、反应 |
| 群像融合 | 多人同框同时动同时说 | 定中心物和说话顺序 | 一镜只让一个人承担主动作 |
| AI腔模板 | 先写套话、形容词堆砌、没有取舍 | 先说“我会这样拍” | 写保留、舍掉、第一刀 |
| 参考复刻 | 角色、台词、Logo、标志画面相似 | 只继承导演骨架 | 三次原创替换 |
| 交付漏项 | 客户方案缺后期、声音、合规、可生成性 | 交付包必须补齐 | 走交付前红队审查 |

## 6. 旧错复发检查

当用户说“又错了”或“怎么还是这样”，先按这个顺序查：

1. 这次错误和旧错误是不是同一症状？
2. 上次的第一刀有没有被执行？
3. 是触发入口没调用，还是调用了但通过标准太弱？
4. 这次是否需要把错误等级上调？
5. 是否要新增回归题，防止第三次复发？

输出判断句：

```text
这不是新问题，是【旧错名称】复发。上次只改了【变量】，但没有锁住【门禁】。这轮第一刀先补【门禁或拆镜】，不再继续加形容词。
```

## 7. 自动避坑流程

默认流程：

```text
识别触发信号
-> 查是否旧错复发
-> 判定错误等级
-> 写错误记忆卡
-> 选择回写位置
-> 补禁用项或第一刀
-> 增加回归题或黄金反例
-> 下次输出前自动提醒
```

关键要求：

1. 不把所有问题都写成“审美不够”。
2. 不把所有问题都靠加长提示词解决。
3. 不在同一轮同时改风格、角色、机位、动作和台词。
4. 不让错误记忆只停在文档里，必须有触发词和通过标准。

### 7.1 输出前旧错召回三问

只在用户指出错误后才复盘，还是会反复撞同一堵墙。进入高风险输出前，先用三问把旧错召回到当前方案里。

| 召回问题 | 必须回答 | 如果答不出 |
| --- | --- | --- |
| 这像哪一种旧错？ | 从单镜过载、角色漂、口型穿帮、文字乱码、信息释放错、卖点空、打斗看不清、群像融合、AI腔模板、参考复刻、交付漏项里选一个最像的 | 先跑反模式黑名单，不急着扩写 |
| 哪个门禁能拦住它？ | 指向 Seedance 门禁、空间轴线、对白口型、产品证明、发布可复述、交付红队或一口气复核中的一个 | 补一个可检查门禁，再继续输出 |
| 这轮第一刀锁什么？ | 只锁一个变量：主动作、说话人、空间方向、字幕后期、产品证据、参考禁用项、标题封面或保底镜 | 本轮不允许同时改风格、机位、台词和角色 |

输出前简句：

```text
我先做旧错召回：这次最像【旧错类型】，用【门禁】拦，第一刀只锁【一个变量】。
```

硬规则：

1. 旧错召回不是把全部错误列一遍，只选最可能毁掉当前交付的一个。
2. 如果旧错和当前任务无关，不要强行套用，改走对应专项能力。
3. 如果同一旧错第三次出现，必须上调等级，并补回归题或黄金反例。
4. 旧错召回不能代替创作判断；它只负责踩刹车，不能把输出变成风险清单。

## 8. 与其他能力衔接

默认顺序：

```text
生成后回放验片与剪辑救援协议
-> 反模式黑名单与第一刀修法
-> 错误记忆与自动避坑案例库
-> 经验回写与版本进化协议
-> 自我校准与回归测试套件
```

分工：

1. 回放验片负责判断素材还能不能救。
2. 反模式黑名单负责抓当前最致命的病灶。
3. 本库负责把这个病灶变成下次自动避坑。
4. 经验回写负责把错误写回正确资产。
5. 回归测试负责确认以后没有退化。

## 9. 输出模板

```text
我先把这次错误记住：

错误类型：
【一句话命名】

不是哪里不够美，而是：
【具体症状和根因】

下次自动提醒：
【以后遇到什么场景先提醒什么】

禁用项：
【以后禁止的坏做法】

第一刀：
【下一版只先改一个变量】

通过标准：
1. 【可检查标准一】
2. 【可检查标准二】
3. 【可检查标准三】

写回位置：
【能力卡 / 门禁 / 回归题 / 黄金反例】
```

## 10. 回归题写法

每个 A级以上错误，至少补一条回归题：

```text
输入题：
【故意包含旧错触发信号的用户需求】

必须触发：
【本库 + 对应专项能力】

通过标准：
1. 必须识别旧错风险。
2. 必须写禁用项。
3. 必须只改一个第一变量。
4. 必须给可检查标准。

常见失败：
【继续写长提示词 / 同时改太多变量 / 忘记字幕后期 / 复刻参考外壳】
```

## 11. 最小合格线

一次错误记忆至少要输出：

1. 错误类型。
2. 触发信号。
3. 根因判断。
4. 下次自动提醒。
5. 禁用项。
6. 第一刀。
7. 通过标准。
8. 写回位置。

少一项，就只是复盘，不是能防复发的错误记忆。
