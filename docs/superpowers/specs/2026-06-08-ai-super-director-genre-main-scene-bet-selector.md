# AI超级导演类型主场面选择与押注协议

## 1. 定位

这份协议用于在一条短片、短剧、广告、Seedance 多镜头项目或客户方案开始前，先选出最该押注的一场主场面。它不替代类型公式，也不替代镜头优先级；它负责决定整条片的“主战场”在哪里。

一句话原则：

```text
一条片只能有一个最该赢的主场面。
先选主场面，再分配镜头、表演、声音、生成预算和审片标准。
```

很多方案的问题不是没有镜头，而是每个镜头都像重点，最后没有一场真正打穿观众。

## 2. 触发信号

当用户出现以下说法时，默认调用本协议：

1. “这条片哪一场最重要？”
2. “主场面在哪、主戏是哪场、该押哪一段？”
3. “镜头很多但没重点、每场都平均”。
4. “帮我选最该稳住的一场”。
5. “客户预算有限，先做哪一场最值？”
6. “Seedance 先生成哪一段最能判断成败？”
7. “这条片缺一个能打穿人的场面”。

如果用户问单镜头优先级，走镜头优先级与剪辑层级。  
如果用户问整片节奏，走场次节拍与全片情绪弧线。  
本协议站在更前面：先决定整条片要押哪一场。

## 3. 主场面类型表

| 类型 | 最该押的主场面 | 这一场必须赢什么 |
| --- | --- | --- |
| 短剧 | 冲突换手场 | 权力关系、站队、下一集问题 |
| 创意广告 | 产品证明场 | 痛点、产品动作、可见变化 |
| 可爱治愈 | 情绪松动场 | 小主体硬撑到被接住 |
| 打斗特效 | 接触受力场 | 空间、接触点、受力结果 |
| 特摄英雄 | 仪式登场场 | 现实基准、触发物、姿态、规则 |
| 情感短片 | 破防收回场 | 没说出口、旧物或声音回声 |
| 高概念短片 | 规则证明场 | 反常规则被清楚看懂 |
| 悬疑反转 | 信息揭露场 | 观众发现关键真相 |
| 喜剧 | 误解升级场 | 认真执行错误规则和反应停顿 |
| 企业品牌片 | 任务协作场 | 团队如何解决具体行业压力 |
| 文旅城市 | 停下来的场 | 人为什么愿意在这里停住 |
| 知识科普 | 顿悟演示场 | 误解被一个可见变化打破 |

## 4. 类型第一刀速查表

选中主场面后，不要平均升级全片。先按类型下第一刀，把最能决定成败的动作改硬。

| 类型 | 第一刀先改哪里 | 不能先改什么 | 通过标准 |
| --- | --- | --- | --- |
| 短剧 | 第一镜的关系压力和选择代价 | 背景解释、人物履历、世界观 | 观众能立刻站队，并想知道下一步谁输谁赢 |
| 创意广告 | 产品介入动作和可见变化 | 口号、空镜、品牌理念 | 不看字幕也能明白产品解决了什么 |
| 可爱治愈 | 小主体失败或硬撑那一秒 | 堆萌物、堆糖果色、堆表情 | 观众能复述它努力做了一件什么小事 |
| 打斗特效 | 第一下接触点、受力方向和出口 | 爆炸、环绕、完整大战 | 关掉特效也看得清谁打到谁、谁被迫退到哪里 |
| 特摄英雄 | 现实基准、触发物和稳定姿态 | 必杀技名、满屏光效、完整变身 | 观众相信日常空间被规则改变了 |
| 情感短片 | 没说出口前的防御动作 | 哭戏、旁白、煽情配乐 | 观众能看出人物想说但忍住了什么 |
| 悬疑反转 | 第一处异常物和信息差方向 | 黑画面、故弄玄虚、解释真相 | 观众知道“有东西不对”，但还欠一个答案 |
| 喜剧 | 角色认真执行错误理解的动作 | 俏皮台词、夸张表情、硬抖包袱 | 观众笑的是行为逻辑，不是台词解释 |
| 企业品牌片 | 具体任务里的协作动作 | 大楼、握手、口号、荣誉墙 | 观众看见团队如何解决一个真实压力 |
| 文旅城市 | 人愿意停下来的动作和声音 | 航拍堆景、口号、景点罗列 | 观众能说出这个地方让人停住的一瞬间 |
| 知识科普 | 误解被打破的可见演示 | 术语堆叠、长口播、PPT感 | 观众能用一句话复述“原来是这样” |

第一刀句式：

```text
这条我先不动其他镜头，第一刀只改【类型成败点】：让【主动作】在【主场面】里被看清。
```

如果第一刀不是一个可见动作、声音落点或关系变化，它还不是导演第一刀，只是文字优化。

## 5. 主场面选择标准

选主场面时问 7 个问题：

1. 这一场能不能代表整条片的一句话核心？
2. 这一场有没有可见动作，而不是只讲概念？
3. 这一场能不能产生观众心跳：问题、压力、变化或余味？
4. 这一场能不能截图成封面或客户记忆帧？
5. 这一场失败后，整条片是不是会塌？
6. 这一场能不能被 Seedance 拆成 2-4 个稳定镜头？
7. 这一场能不能带出声音记忆或剪辑出点？

如果一场戏不能回答第 1、3、5 条，它不配当主场面。

## 6. 镜头资源分配

选定主场面后，资源按这个比例分配：

```text
主场面：50%
证明/反应/桥镜：30%
背景和气氛：20%
```

如果是 30 秒广告：

```text
前 3 秒给痛点和信息债。
中间 15 秒押产品证明场。
后 6 秒押品牌记忆帧和转化入口。
剩余时间只做必要过渡。
```

如果是 1 分钟短片：

```text
开场 10 秒建立问题。
中段 30 秒都服务主场面升级。
结尾 10-15 秒回收余味或追更问题。
```

## 7. 主场面输出卡

```text
我会押这一场：
【主场面名称】

为什么押它：
【它决定整条片成败的原因】

这一场必须赢：
【权力 / 证明 / 情绪 / 规则 / 受力 / 记忆】

类型第一刀：
【先改这一类型最能决定成败的动作、声音或关系变化】

保留：
【最有价值的动作、关系或视觉母题】

舍掉：
【会分散主场面的副线、空镜或炫技】

主场面拆镜：
1. 起点：
2. 压力：
3. 可见变化：
4. 反应/余味：

Seedance 先测：
【最能判断成败的一镜】

失败第一刀：
【如果跑偏，先改哪个变量】
```

## 8. 常见误押与修法

| 误押 | 表现 | 第一刀 |
| --- | --- | --- |
| 押了空镜 | 画面漂亮但不决定成败 | 改押人物选择或产品证明 |
| 押了设定 | 世界观很大但没有动作 | 改押一个规则证明场 |
| 押了结尾金句 | 话好听但画面弱 | 改押结尾前的动作回收 |
| 押了特效奇观 | 炸但看不清 | 改押接触点和受力结果 |
| 押了产品展示 | 只拍美图 | 改押痛点到结果变化 |
| 押了群像同框 | 人多但融合 | 改押中心物和主动作角色 |
| 押了情绪爆发 | 太满太假 | 改押破防前的防御动作 |

判断句：

```text
这场不是最漂亮的场，但它是整条片最不能输的场。
```

## 9. 与其他能力衔接

默认顺序：

```text
现场判断中枢
-> 类型主场面选择与押注协议
-> 场次节拍、全片情绪弧线与中段升级
-> 镜头优先级与剪辑层级
-> 开拍口令与现场执行拍板协议
-> Seedance 可生成性与拆镜决策
```

分工：

1. 现场判断中枢决定主目标和第一刀。
2. 本协议决定哪一场最该押。
3. 场次节拍负责整条片怎么推进到这一场。
4. 镜头优先级负责这一场内部哪些镜头最重要。
5. 开拍口令负责把主场面压成可执行口令。
6. Seedance 拆镜负责降低生成风险。

## 10. 自检闸门

输出前检查：

1. 有没有明确只押一个主场面？
2. 有没有说清为什么它决定成败？
3. 有没有写这一场必须赢什么？
4. 有没有舍掉分散主场面的东西？
5. 有没有拆成起点、压力、变化和反应？
6. 有没有标出 Seedance 先测哪一镜？
7. 有没有失败第一刀？
8. 有没有按类型写出第一刀，而不是泛泛说“优化开头”？

## 11. 最小合格线

一次主场面选择至少要输出：

1. 主场面名称。
2. 为什么押它。
3. 这一场必须赢什么。
4. 类型第一刀。
5. 保留和舍掉。
6. 主场面拆镜。
7. Seedance 先测。
8. 失败第一刀。

少一项，就还没有真正拍板，只是在排列镜头。
