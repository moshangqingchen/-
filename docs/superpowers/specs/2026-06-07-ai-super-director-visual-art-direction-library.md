# AI超级导演视觉风格与美术指导库

## 1. 使用方式

这份库用于让AI超级导演在短片、短剧、广告和AI生成内容中稳定控制视觉风格。它补足美术指导层：色彩、光线、构图、材质、场景、服装、道具和风格一致性。

默认设计顺序：

1. 确定主类型和情绪目标。
2. 选择主色、辅助色和记忆色。
3. 设计光线方向和光质。
4. 设计构图重点。
5. 设计材质和空间细节。
6. 建立角色、场景、道具的视觉一致性。
7. 输出关键帧提示词。

## 2. 视觉风格公式

```text
类型情绪 + 色彩系统 + 光线系统 + 构图系统 + 材质细节 + 记忆符号 + 一致性规则
```

拆解：

- 类型情绪：可爱、治愈、特效、打斗、广告、短剧、搞笑、情感。
- 色彩系统：主色决定气质，辅助色稳定画面，记忆色制造识别。
- 光线系统：决定情绪温度、质感和戏剧强度。
- 构图系统：决定观众第一眼看哪里。
- 材质细节：让画面真实、可触摸、可记住。
- 记忆符号：一个颜色、道具、形状、光影或场景标志。
- 一致性规则：系列内容必须保持角色和场景识别度。

## 3. 色彩系统

### 3.1 三色法

```text
主色：负责整体气质。
辅助色：负责空间和层次。
记忆色：负责观众记住的一点。
```

例子：

- 可爱：奶白 + 浅蓝 + 樱桃红。
- 治愈：雾灰绿 + 暖米色 + 一点金黄。
- 搞笑：明亮浅色 + 高饱和小点缀 + 干净背景。
- 情感：低饱和暖灰 + 旧木色 + 暖灯黄。
- 特效：现实低饱和 + 能量色 + 冷暖对比。
- 打斗：暗中性色 + 危险红/冷蓝 + 金属灰。
- 广告：品牌主色 + 中性空间 + 产品记忆色。

### 3.2 色彩情绪

暖色：

- 亲近、治愈、食物、家庭、怀旧。
- 风险：过暖会俗、腻、像滤镜。

冷色：

- 科技、悬疑、孤独、夜晚、特效。
- 风险：过冷会失去人情味。

高饱和：

- 搞笑、儿童、卡通、潮流、强传播。
- 风险：容易廉价，必须有干净背景控制。

低饱和：

- 情感、电影感、怀旧、现实。
- 风险：过灰会没记忆点。

### 3.3 色彩自检

1. 主色是否服务类型？
2. 画面有没有一个明确记忆色？
3. 色彩是否过多？
4. 系列内容是否能保持同一套色彩规则？
5. 品牌广告是否尊重品牌色？

## 4. 光线系统

### 4.1 柔光

功能：亲近、温柔、可爱、治愈。

适合：

- 可爱角色。
- 治愈片。
- 情感缓和段落。
- 护肤、家居、咖啡广告。

提示词：

```text
柔和自然光，阴影边缘柔软，主体轮廓温和，画面有亲近感。
```

### 4.2 逆光

功能：梦感、回忆、希望、轮廓。

适合：

- 怀旧情感。
- 治愈结尾。
- 角色登场。
- 品牌高级感。

提示词：

```text
温柔逆光，主体边缘有柔和光晕，背景略微虚化，情绪有回忆感。
```

### 4.3 侧光

功能：立体、戏剧、冲突、人物内心。

适合：

- 短剧冲突。
- 悬疑。
- 情感压抑。
- 打斗前的对峙。

提示词：

```text
侧向光线，人物一侧明亮一侧阴影，面部有戏剧张力。
```

### 4.4 硬光

功能：紧张、现实、危险、强对比。

适合：

- 打斗。
- 犯罪、悬疑。
- 强烈广告视觉。
- 特效爆发前的压迫。

提示词：

```text
硬光，高对比阴影，边缘清晰，画面有紧张和压迫感。
```

### 4.5 光线弧线

常用变化：

- 治愈：冷到暖，暗到亮，硬到软。
- 情感：暖光出现得晚，前面克制。
- 特效：现实光稳定，异常光逐步侵入。
- 打斗：空间光清楚，关键打击点用强反差。
- 广告：产品出现时光线变干净、聚焦。

## 5. 构图系统

### 5.1 中心构图

功能：明确、稳定、符号化。

适合：产品、可爱角色、封面帧、品牌记忆帧。

风险：过多会单调。

### 5.2 三分构图

功能：自然、舒服、有空间呼吸。

适合：治愈、生活方式、情感短片。

风险：如果主体太小，会缺少冲击力。

### 5.3 对称构图

功能：仪式感、秩序、荒诞、压迫。

适合：搞笑群像、品牌高级感、悬疑、特效规则。

风险：过度对称会显得摆拍。

### 5.4 前景遮挡

功能：层次、窥视感、回忆感、真实感。

适合：旧梦留声机类、情感、悬疑、短剧偷听。

风险：遮挡主体会影响信息。

### 5.5 留白构图

功能：孤独、治愈、等待、情绪停留。

适合：怀旧、公益、亲情、失落状态。

风险：没有内部动作会变空。

## 6. 材质系统

### 6.1 可爱材质

关键词：毛绒、软陶、奶油、棉花、圆润塑料、纸贴。

用途：

- 让角色更想被触摸。
- 增加表情包传播感。
- 适合儿童、宠物、IP角色。

### 6.2 治愈材质

关键词：木头、亚麻、陶瓷、玻璃、热气、纸张、植物。

用途：

- 建立真实生活触感。
- 让空间变得可停留。
- 适合咖啡、家居、生活方式。

### 6.3 情感材质

关键词：旧照片、旧木门、泛黄纸、布纹、搪瓷碗、录音机、老墙。

用途：

- 提供时间痕迹。
- 让情绪落到具体物件上。
- 适合怀旧、公益、亲情。

### 6.4 特效材质

关键词：粒子、雾气、金属、玻璃、能量纹理、空间裂缝、光痕。

用途：

- 表现规则变化。
- 让奇观有层次。
- 现实材质与超现实材质必须有对比。

### 6.5 打斗材质

关键词：金属、混凝土、皮革、汗水、灰尘、破碎木片、布料拉扯。

用途：

- 强化打击重量。
- 让空间成为动作的一部分。
- 关键道具要有材质反馈。

## 7. 类型视觉方案

### 7.1 可爱

视觉公式：

```text
圆润主体 + 柔和底色 + 明亮记忆色 + 近距离构图 + 软材质
```

避免：

- 主体太尖锐。
- 色彩太杂。
- 背景抢主体。

### 7.2 治愈

视觉公式：

```text
自然光 + 低对比 + 生活材质 + 慢构图 + 微小情绪变化
```

避免：

- 只有漂亮空镜。
- 过度滤镜。
- 没有情绪动作。

### 7.3 特效

视觉公式：

```text
现实基准 + 单一异常色 + 规则化光效 + 人物反应 + 奇观层次
```

避免：

- 能量色太多。
- 一开始就满屏特效。
- 没有现实材质对比。

### 7.4 打斗

视觉公式：

```text
清楚空间 + 高对比光 + 可见动线 + 材质反馈 + 关键打击特写
```

避免：

- 只用暗光和快切。
- 看不清动作路径。
- 所有打击同一种视觉重量。

### 7.5 创意广告

视觉公式：

```text
品牌色 + 产品记忆色 + 干净构图 + 卖点动作 + 结尾品牌帧
```

避免：

- 产品漂亮但没有功能。
- 背景太花。
- 结尾没有识别。

### 7.6 短剧

视觉公式：

```text
人物表情清楚 + 空间关系明确 + 关键道具可见 + 冲突光线 + 竖屏友好构图
```

避免：

- 人物太远。
- 重要信息在画面边缘。
- 竖屏裁切破坏关系。

### 7.7 搞笑

视觉公式：

```text
正常场景 + 荒诞道具 + 表情清楚 + 停顿构图 + 表情包收尾
```

避免：

- 视觉太乱。
- 笑点发生在看不清的位置。
- 表情没有被拍到。

### 7.8 情感

视觉公式：

```text
旧物 + 克制色彩 + 柔和或侧向光 + 手部/背影/空椅子 + 留白
```

避免：

- 大哭大喊。
- 没有具体物件。
- 画面太干净，缺少时间痕迹。

## 8. 系列视觉一致性

### 8.1 固定项

- 角色脸部特征。
- 角色服装主色。
- 场景标志物。
- 主色和记忆色。
- 光线方向。
- 关键道具。
- 片头或封面构图。

### 8.2 可变项

- 每集道具。
- 每集天气。
- 每集问题。
- 每集局部色彩。
- 每集新场景角落。

## 9. AI关键帧提示词模板

```text
[类型]关键帧，[主体]在[场景]中[动作]。
视觉风格：[写实/卡通/毛绒/电影感/怀旧/科技感]。
色彩：[主色]为主，[辅助色]稳定空间，[记忆色]突出看点。
光线：[柔光/逆光/侧光/硬光]，情绪为[情绪]。
构图：[中心/三分/对称/留白/前景遮挡]。
材质细节：[材质]清楚可见。
画面记忆点：[记忆符号]。
保持角色和场景一致，避免杂乱背景和无意义装饰。
```

## 10. 导演自检

1. 色彩是否服务类型？
2. 光线是否推动情绪？
3. 构图是否让观众第一眼看到重点？
4. 材质是否让画面有触感？
5. 是否有可记住的视觉符号？
6. 系列内容是否保持一致？
7. 画面是否能变成关键帧或封面？
