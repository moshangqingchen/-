# AI超级导演镜头呼吸、情绪停顿与节奏余波导演引擎

## 1. 定位

这套引擎专门处理“节奏太平、太赶、太满、太像AI、人物没有反应、镜头没有呼吸、情绪没落点、笑点不响、动作没有重量、结尾没有余味”的问题。

它不替代剪辑节奏与声音设计库。剪辑节奏库解决整条片怎么切；本引擎解决每一镜内部怎么活：动作前的等待、动作中的节拍、动作后的余波、人物反应、声音抽空和剪辑出点。

默认判断：

```text
我会这样拍：别急着把动作做完。先给动作一个起因，中间留一个观众能看懂的变化，动作落下后多留半秒，让人物、声音或环境接住结果。镜头有呼吸，片子才像人拍的。
```

核心公式：

```text
情绪任务 + 动作起因 + 入点呼吸 + 动作中点 + 结果落点 + 反应停顿 + 声音余波 + 剪辑出点
```

用户出现以下说法时，默认调用本引擎：

- “节奏太平”“节奏太赶”“太满了”“太散了”“没呼吸感”“镜头没有呼吸”。

- “笑点不响”“喜剧节奏不对”“停顿怎么留”“哪里该慢一点”“哪里该快一点”。
- “动作没重量”“打击没感觉”“特效不炸”“产品证明没被看清”。
- “结尾没余味”“看完没感觉”“剪辑点怎么找”“出点怎么留”。

## 3. 镜头呼吸不是拖慢

镜头呼吸有三个原则：

1. 停顿必须发生在信息变化之后，不能用空停顿冒充高级。
2. 一镜只留一个主要停顿：反应停顿、声音停顿、手部停顿、环境停顿或剪辑停顿。
3. 快慢要服务类型：短剧冲突快进慢出，情感片慢进轻出，广告证明动作清楚，打斗重在接触后的余波。

常见失败：

| 失败 | 问题 | 第一刀 |
| --- | --- | --- |
| 全片一个速度 | 观众抓不到重点 | 给主镜头加动作中点和结果停顿 |
| 每镜都慢 | 像空镜堆砌 | 只在情绪变化或证据出现后停 |
| 快剪太多 | 动作和卖点看不清 | 主证明镜头保留完整动作 |
| 人物不反应 | 事件像没发生 | 补一个眼神、手部或身体收回 |
| 声音铺满 | 没有情绪落差 | 在结果落点后抽空半秒 |
| 停顿太演 | 像摆拍 | 改成微动作：吞咽、收手、避开眼神 |

## 4. 镜头呼吸八问

开拍前先定：

1. 本镜情绪任务是什么：抓人、证明、压迫、释放、笑点、心疼、惊奇还是余味？
2. 动作从哪里开始：手、眼神、脚步、道具、声音、光线还是对手压力？
3. 入点是否需要呼吸：直接进动作，还是先停半秒让观众站进来？
4. 动作中点是什么：观众在哪一刻看懂变化正在发生？
5. 结果落点是什么：动作结束后画面里什么变了？
6. 谁来反应：主角、对手、旁人、环境、道具、声音还是观众自己？
7. 声音余波是什么：静音、呼吸、道具声、环境声、低频、远处声还是下一镜声音桥？
8. 剪辑出点在哪里：动作完成即切、反应后切、声音先切，还是停在余味帧？

## 5. 镜头呼吸卡

| 卡名 | 用途 | 拍法 | 避免 |
| --- | --- | --- | --- |
| 入点半秒卡 | 让观众进入空间 | 动作开始前，角色手或眼神先停半秒 | 空等太久 |
| 动作中点卡 | 让变化被看懂 | 倒出、按下、击中、转身、发现的中间状态清楚 | 一闪而过 |
| 结果余波卡 | 让动作有重量 | 动作后保留身体、道具或环境反应 | 结果没出现就切 |
| 眼神收回卡 | 拍克制情绪 | 眼神看见后立刻避开或低下 | 直演悲伤 |
| 手部停住卡 | 拍内心犹豫 | 手指停在门把、杯沿、按钮或旧物上 | 手部动作复杂 |
| 声音抽空卡 | 放大冲击 | 打击、揭露、选择后短静音 | 全程静音 |
| 喜剧反应卡 | 让笑点响 | 荒诞动作后留半秒集体或单人反应 | 所有人同时夸张表演 |
| 产品确认卡 | 让卖点被看清 | 产品动作完成后让手、表面、结果停住 | 快速扫过产品 |
| 特效稳定卡 | 让奇观可信 | 特效出现后给稳定姿态和旁人轻反应 | 一镜持续变形 |
| 余味空位卡 | 让结尾留下来 | 人物离开后留物件、门、光或声音 | 结尾硬字幕解释 |

## 6. 类型专用节奏

### 6.1 短剧冲突

```text
快进冲突，慢出代价。
```

拍法：

- 开头别停，直接给危险、身份问题或反常结果。
- 关键台词后给对方半秒反应，不要立刻接下一句。
- 反转后先看被打中的人，再看赢家。

### 6.2 情感治愈

```text
慢进情绪，轻出余味。
```

拍法：

- 情绪不靠哭，靠手部停住、眼神收回、呼吸变浅。
- 旧物、空椅子、门声和窗外环境声负责接住停顿。
- 结尾多留一帧物件或空间空位。

### 6.3 喜剧可爱

```text
动作认真，反应停半秒，二次升级再切。
```

拍法：

- 荒诞动作不能太快，观众要看见角色认真执行。
- 笑点后只让一个角色先反应，别全员一起吵。
- 封口镜头短而准：一个表情、一个道具声、一句短台词。

### 6.4 创意广告和产品证明

```text
证明动作要完整，结果停住给观众看。
```

拍法：

- 产品介入前给痛点半秒，不要直接进入漂亮特写。
- 手部动作要有开始、中点、结果。
- 结果出现后停住，留给字幕、货架或品牌记忆帧。

### 6.5 打斗和特效

```text
接触点之后才有重量。
```

拍法：

- 打击前给压力方向，打击中保留接触点，打击后给受力余波。
- 大特效出现前可以静半秒，出现后要稳定一拍。
- 不用快剪遮盖动作，关键动作要看完整。

## 7. Seedance 2.0 可生成性规则

镜头呼吸对 Seedance 2.0 很重要，但要写得具体。默认规则：

1. 每镜只指定一个主要停顿，不同时写眼神、手部、环境、声音全部停。
2. 停顿时间写短：半秒、一拍、动作后短暂停住。
3. 停顿必须绑定可见动作：手停住、眼神避开、身体后退、道具落桌、光线稳定。
4. 复杂表演不写“内心崩溃”，改写成外在微动作。
5. 口型镜头的停顿放在说话前或说完后，不要在一句话中间乱停。
6. 产品证明镜头的停顿放在结果出现后。
7. 打斗和特效镜头的停顿放在接触、触发或稳定之后。

风险评级：

| 镜头 | 风险 | 处理 |
| --- | --- | --- |
| 手部停在按钮上半秒 | A | 可直接写入 |
| 角色说完一句短台词后看向对方 | A | 单说话人，嘴部可见 |
| 荒诞动作后群像停顿 | B | 改成一个主反应角色 |
| 打斗中连续多次停顿 | C | 只保留关键打击后的停顿 |
| 长镜头多情绪递进 | D | 拆成动作镜头 + 反应镜头 + 余味镜头 |

## 11. 自检

输出前检查：

1. 本镜停顿是否服务一个明确情绪任务？
2. 动作是否有起因、中点和结果？
3. 停顿是否发生在信息变化之后？
4. 是否只保留一个主要停顿？
5. 人物反应是否是可见微动作，而不是抽象情绪词？
6. 声音余波是否能帮助剪辑，而不是全程铺满？
7. 产品、打斗、特效和口型镜头是否在正确位置停？
8. 出点是否能和下一镜通过动作、视线或声音接上？
