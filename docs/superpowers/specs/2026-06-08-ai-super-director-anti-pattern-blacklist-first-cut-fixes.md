# AI超级导演反模式黑名单与第一刀修法

## 1. 定位

这份黑名单用来拦住那些“看起来很完整，实际拍不出来、剪不起来、生成不稳、听起来像 AI”的输出。它不是审美批评，而是现场急救表：先判断坏味道，再砍掉最危险的部分，最后给一条能落地的改写方向。

一句话原则：

```text
先抓最致命的一个病灶。不要同时改风格、故事、机位、角色、动作和口型。
第一刀只解决一个会让片子失败的问题。
```

默认触发信号：

1. 用户说“太 AI、太空、太散、没重点、剪不起来、动作看不清、口型穿帮、生成不稳、客户不会买单”。
2. 输出里出现大量形容词，但缺少动作、站位、声音、入点和出点。
3. Seedance 2.0 提示词把多人对白、复杂打斗、强运镜、特效、文字和品牌 Logo 塞进同一镜。
4. 参考作品被复制成角色、台词、Logo、标志动作或标志画面。
5. 返工时一次改太多变量，导致下一轮失败原因无法判断。

## 2. 使用顺序

```text
读输出 -> 标记一个主反模式 -> 写清为什么坏 -> 只砍第一刀 -> 给低风险改写 -> 调用对应能力卡补完
```

不要一上来重写整条片。先问自己：

1. 这个输出最可能在哪里翻车？
2. 是观众看不懂，还是模型生成不了，还是客户感受不到卖点？
3. 第一刀砍掉什么之后，片子会立刻更稳？

## 3. 十大反模式黑名单

| 反模式 | 典型症状 | 为什么会坏 | 第一刀修法 | 联动能力 |
| --- | --- | --- | --- | --- |
| AI腔开口 | “以下是完整方案”“融合多种元素”“电影感拉满”“高级质感扑面而来” | 没有导演判断，像模板扩写，用户看不到取舍 | 改成“我会这样拍”，先写保留、舍掉、第一刀 | 活人导演现场人格校准器 |
| 镜头堆砌 | 连续写很多漂亮空镜，每个镜头都像海报 | 镜头没有存在理由，剪辑没有主链 | 给每镜补“存在理由”，删掉不能推动动作、证明或反应的镜头 | 成片级分镜编译器、镜头优先级与剪辑层级 |
| 情绪直给 | “他很悲伤”“她很愤怒”“观众会被感动” | 人物在演情绪，不是在藏情绪、做任务、被关系逼住 | 改成防御动作、破防动作和收回动作 | 现场表演调度与情绪动作谱库 |
| 广告空喊 | “高级、好用、效率提升、治愈、品质感”但没有产品动作 | 卖点没有被看见，客户无法验证 | 改成痛点可视化、手部任务、产品介入、结果变化、反应确认 | 创意广告、产品证明与转化镜头引擎 |
| 打斗看不清 | 快速环绕、能量爆炸、多人冲突、镜头乱晃 | 缺少空间基准、接触点、受力结果和反应 | 先拍空间，再拍起点、触发点、受力结果、反应，拆成 4-6 秒镜头 | 动作打斗、追逐与特效场面编排引擎 |
| Seedance硬塞 | 一条提示词要求群像、口型、复杂运镜、特效、字幕、Logo、长动作 | 单镜任务过载，模型会漂、乱、穿帮 | 保留一个主任务，其余拆成反应镜、证明镜或后期项 | Seedance镜头可生成性、难度评分与拆镜决策库 |
| 群像融合 | 多人同框同时说话、同时移动、没有中心物 | 角色职能不清，模型容易融合，剪辑也没有视线顺序 | 定中心物、站位、主说话人、反应顺序，一镜只让一个人承担主动作 | 多人物群像调度与对白秩序系统 |
| 文字乱码 | 要求视频模型直接生成中文标题、屏幕字、品牌字、Logo | 可读文字不可控，容易乱码和侵权 | 提示词只写干净安全区，字幕、Logo、品牌字后期添加 | 不出错工具化防错协议 |
| 参考复刻 | “像某作品”后直接照搬角色、台词、标志动作、标志画面 | 创意不原创，合规风险高，也限制新片生命力 | 只继承情绪、结构、调度、母题和观众感受，完成三次原创替换 | 参考作品拆解、原创替换与合规转译闸门 |
| 返工乱改 | 上一版失败后同时改风格、角色、机位、动作、时长和提示词长度 | 无法知道哪一项导致改善或恶化 | 本轮只改一个变量，写清必须锁住、必须删掉、通过标准 | Seedance 2.0 返工迭代协议 |

## 4. 第一刀改写示例

### 4.1 AI腔开口

坏写法：

```text
以下是一套融合电影感、治愈感与高级质感的完整短片方案。
```

第一刀：

```text
我会这样拍：不先讲高级，先拍一个人把快冷掉的咖啡往自己手心里拢。保留“被照顾”的情绪，舍掉咖啡馆空镜和大段旁白。第一刀先让产品在一个动作里证明它真的有用。
```

### 4.2 镜头堆砌

坏写法：

```text
城市航拍、霓虹街道、人物背影、产品特写、慢动作转场，整体高级电影感。
```

第一刀：

```text
先删掉没有任务的空镜。保留一条主链：人物赶时间 -> 产品介入 -> 结果变化 -> 人物反应 -> 品牌记忆帧。每个镜头只回答一个问题：观众为什么必须看这一镜？
```

### 4.3 情绪直给

坏写法：

```text
女孩非常伤心，眼含热泪，表现出强烈的失落。
```

第一刀：

```text
别让她演伤心。让她把已经写好的消息删掉，手机扣在桌上，手指还停在屏幕边缘半秒。镜头落在她收回手的动作上，声音只留空调声。
```

### 4.4 广告空喊

坏写法：

```text
产品让办公更高效，画面高级，节奏明快，体现智能科技感。
```

第一刀：

```text
把“高效”改成可见动作：桌上一叠乱文件，手指按下扫描键，屏幕上不要生成可读文字，只出现整齐色块界面，人物肩膀松下来，旁边同事停住催促。
```

### 4.5 打斗看不清

坏写法：

```text
两人激烈大战，镜头快速环绕，能量爆炸，场面震撼。
```

第一刀：

```text
先把走廊、出口和两人的距离摆清楚。第一镜只拍反派踩碎地上的玻璃，第二镜只拍主角侧身躲过第一击，第三镜拍拳头砸到墙面后的裂纹，第四镜拍反派后退半步。炸点跟着受力结果走，不跟着形容词走。
```

### 4.6 Seedance硬塞

坏写法：

```text
一个 8 秒镜头里，五个人在会议室争吵，主角说长台词，镜头环绕推进，窗外爆炸，屏幕出现中文标题和品牌 Logo。
```

第一刀：

```text
拆成三镜：主角近景只说一句短台词；反应镜拍众人沉默和一只手停在合同上；窗外震动做画外声和灯光变化。中文标题、品牌 Logo 后期加，生成阶段只留右上角干净安全区。
```

### 4.7 返工乱改

坏写法：

```text
再生成一版，更电影感，角色更稳定，动作更自然，镜头更酷，情绪更强。
```

第一刀：

```text
本轮只改角色稳定。锁住同一角色、同一服装、同一房间、同一道具，先不升级运镜和情绪。通过标准是脸和服装不漂，右手拿照片动作清楚，没有新增人物和乱码文字。
```

## 5. 反模式诊断输出模板

当用户要求“检查一下、哪里不对、怎么升级、怎么返工”时，默认用这个短模板：

```text
我会先砍这一刀：

主病灶：
这版最大问题不是不够美，而是【具体反模式】。

为什么坏：
它会导致【观众看不懂 / 模型生成不稳 / 客户卖点不成立 / 剪辑接不上】。

保留：
保留【最有价值的情绪、动作、角色关系或产品证明】。

舍掉：
舍掉【最危险的过载要求、空泛形容、复刻元素或不可控文字】。

第一刀：
本轮只改【一个变量】。

改写方向：
【给一条更低风险、更具体、能生成、能剪起来的版本】。

通过标准：
【写出 2-4 条可检查结果】。
```

## 6. 触发后的联动规则

1. 如果问题是“像 AI”，先联动活人导演现场人格校准器，不要先加更多术语。
2. 如果问题是“剪不起来”，先联动镜头优先级与剪辑层级、成片级分镜编译器。
3. 如果问题是“生成不稳”，先联动 Seedance 可生成性评分与拆镜决策。
4. 如果问题是“人物不活”，先联动表演调度和情绪动作谱。
5. 如果问题是“卖点不清”，先联动广告证明链和产品手部证明。
6. 如果问题是“参考太像”，先联动原创替换与合规转译闸门。
7. 如果问题是“返工失败”，先联动 Seedance 2.0 返工迭代协议。

## 7. 禁止动作

遇到反模式时，不要这样处理：

1. 不要把提示词继续写长来掩盖问题。
2. 不要用“更高级、更电影、更真实、更自然”代替具体动作。
3. 不要在同一轮同时改多个变量。
4. 不要为了酷炫牺牲空间、动作因果和出点。
5. 不要把可读中文、Logo、品牌字交给视频模型硬生成。
6. 不要把参考作品的外壳当成“精华”继承。
7. 不要每个镜头平均用力。主镜头必须先稳住。

## 8. 最小合格线

一次反模式修复至少要做到：

1. 明确指出一个主病灶。
2. 写清为什么会失败。
3. 写清保留什么、舍掉什么。
4. 第一刀只改一个变量。
5. 给出能直接替换原输出的一段改写。
6. 写出可检查的通过标准。

如果做不到这 6 条，就不要说“已经升级”。那只是换了一层漂亮说法。
