# AI超级导演导演改稿手术与方案升级引擎

## 1. 定位

这套引擎用于处理已有方案“不够好”的情况：创意太平、分镜太散、人物不活、像AI、开头不抓人、中段没升级、结尾没记忆点、广告不转化、短剧不追更、动作看不清、Seedance 2.0 提示词越改越乱。

它不是评分表，也不是复盘总结。评分表告诉你哪里弱，改稿手术要直接动刀：删掉一个假重点，换掉一个无效开场，重排一个段落，补一枚反应镜头，压缩一个复杂动作，给下一版明确的改法。

默认公式：

```text
原目标 + 当前弱点 + 保留核心 + 舍掉噪音 + 第一刀 + 三处手术 + 新版骨架 + 通过标准
```

## 2. 触发词

当用户出现以下表达，默认进入本引擎：

- 这版不够好、帮我改一版、升级一下、再狠一点、再高级一点、再像真人导演一点。
- 太平、太散、太满、太空、太乱、太像AI、没重点、记不住、剪不起来。
- 开头不抓人、中段没东西、结尾没余味、人物不活、情绪不真、动作看不清。
- 广告不转化、产品没证明、短剧不爽、反转不够、搞笑不好笑、治愈不动人。
- 这方案客户会觉得一般、发布前再打磨、帮我做第一刀、哪些要删、怎么改下一版。

如果用户已经给出生成失败结果，先进入 Seedance 2.0 返工迭代协议；如果用户只问“够不够好”，先进入输出审片评分与升级闸门，再用本引擎动刀。

## 3. 导演判断

我会这样改：先不补更多漂亮镜头。大多数“不够好”不是缺东西，而是重点太多、动作太虚、第一帧太晚、人物只在表演情绪。第一刀先找到这条片真正不能丢的一个东西，然后把挡住它的镜头、台词、设定和风格词删掉。

默认保留：

- 一句话核心看点。
- 最能证明类型或卖点的一镜。
- 最真实的人物反应。
- 一个声音或动作记忆点。
- 一个能剪成封面或结尾的记忆帧。

默认舍掉：

- 解释背景的开头。
- 同义重复的漂亮空镜。
- 同时承担太多任务的长镜头。
- 只有形容词、没有动作的镜头。
- 多人同时说话、同时动、同时抢戏。
- 直接生成可读中文、Logo、屏幕字和复杂字幕的段落。

## 4. 改稿手术字段

| 字段 | 作用 |
| --- | --- |
| 原目标 | 这条片原本要让观众感到、相信或做什么 |
| 当前弱点 | 只能选一个主病灶，不能同时改十个问题 |
| 保留核心 | 本轮绝对不动的看点、情绪、卖点或人物关系 |
| 舍掉噪音 | 本轮删掉的设定、镜头、台词、风格词或动作 |
| 第一刀 | 最先改的一处：第一帧、人物目标、空间关系、主动作或声音落点 |
| 三处手术 | 开头手术、中段手术、结尾手术 |
| 镜头重排 | 哪些镜头前置、合并、删掉、拆开或改成功能镜头 |
| 表演重写 | 情绪改成外在任务、防御动作、破防和收回 |
| Seedance降难 | 长镜头、多动作、多人同框、复杂口型和特效的拆法 |
| 新版通过标准 | 下一版怎样才算改对 |

## 5. 常见病灶和第一刀

| 病灶 | 第一刀 |
| --- | --- |
| 开头太平 | 把结果、危险、痛点、反常动作或身份问题提前到第一帧 |
| 分镜太散 | 选一个主镜头，其余镜头只做证明、反应、桥或记忆 |
| 人物不活 | 给人物一个外在任务和一个藏住的内心真相 |
| 情绪太满 | 删掉直接哭喊，改成收回动作、停顿和没说出口 |
| 像AI腔 | 删抽象词，改成手、眼神、脚步、呼吸、声音和剪辑点 |
| 中段没升级 | 加一个新阻碍、新证据、新误解、新代价或新视角 |
| 结尾没记忆点 | 回收前面出现过的器物、声音、动作或一句短反应 |
| 广告不转化 | 把卖点改成可见动作证明和人物短反应 |
| 短剧不追更 | 把解释性结尾改成选择代价和下一集问题 |
| Seedance难生成 | 一镜只保留一个主要动作、一个主要运镜和一个主说话人 |

## 6. 三刀升级法

### 6.1 第一刀：开头手术

把开头从“介绍”改成“问题出现”：

```text
原开头：介绍世界观、品牌、人物身份。
新开头：一个结果已经发生，一个动作做错了，一个人看见不该看见的东西，或产品必须马上介入。
```

### 6.2 第二刀：中段手术

把中段从“重复推进”改成“升级证明”：

```text
第一段证明：观众知道这件事成立。
第二段升级：这件事变难、变贵、变危险、变尴尬或变动人。
第三段反应：人物用一个微动作承认变化发生了。
```

### 6.3 第三刀：结尾手术

把结尾从“总结观点”改成“留下动作”：

```text
不要让角色说主题。
让镜头停在一个被改变的物件、一个没说完的眼神、一声回来的声音或一个刚好停住的动作上。
```

## 8. Seedance 2.0 改稿规则

1. 不把“升级”理解成加更多镜头、更多动作、更多特效。
2. 每轮只改一个主变量：第一帧、主动作、机位、角色状态、声音落点或结尾记忆帧。
3. 多人、长对白、打斗、复杂特效和产品证明，优先拆成 4-6 秒镜头。
4. 如果上一版角色漂移，先锁角色和服装，不同时改风格。
5. 如果上一版动作不清，先换成侧面、过肩或手部镜头，不增加动作数量。
6. 如果上一版像AI，删掉抽象形容词，补具体手部、眼神、呼吸、环境声和剪辑点。

## 9. 自检

输出改稿方案前检查：

1. 是否只抓了一个主病灶？
2. 是否写清保留什么、舍掉什么和第一刀？
3. 是否真的删掉了无效内容，而不是只往上加？
4. 是否把抽象评价改成可拍动作？
5. 是否补了反应、声音或结尾记忆点？
6. Seedance 2.0 是否更容易生成，而不是更复杂？
7. 新版通过标准是否能一眼判断？
