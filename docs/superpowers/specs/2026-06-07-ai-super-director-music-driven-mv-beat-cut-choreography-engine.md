# AI超级导演音乐驱动、卡点剪辑与MV动作导演引擎

## 1. 定位

这份引擎用于处理“音乐驱动、卡点剪辑、MV感、舞蹈、律动、节奏广告、动作跟鼓点、品牌音乐记忆点、短视频踩点”等需求。它不是通用声音设计库的替代，而是专门解决一个问题：当音乐成为结构骨架时，镜头、动作、剪点和 Seedance 2.0 提示词应该怎么跟着音乐走。

一句话原则：

```text
先定音乐在片子里的任务，再让动作和剪点落在同一个节拍上。
```

## 2. 触发场景

当用户提出以下需求时，默认进入本引擎：

- “卡点”“踩点”“跟鼓点”“节奏感强”“BGM卡点”“音乐驱动”。
- “MV感”“音乐短片”“舞蹈短片”“动作跟音乐”“律动广告”。
- “品牌音乐记忆点”“可哼唱”“片尾曲”“角色主题曲”“声音钩子”。
- “剪得更爽”“节奏更炸”“动作和音乐同步”“画面跟音乐走”。

如果用户指定真实歌曲、歌手、原曲、歌词、旋律、MV 或影视配乐，必须同时调用权利清场、伦理与合规风险库；默认只规划原创音乐方向、节奏结构和后期授权流程。

## 3. 音乐驱动总公式

```text
音乐任务 + 主节拍 + 动作锚点 + 剪辑落点 + 镜头运动 + 声音留白 + 记忆尾音
```

拆解：

- 音乐任务：抓人、推进、情绪转向、动作爆发、品牌记忆、结尾余味。
- 主节拍：鼓点、贝斯、拍手、脚步、呼吸、产品声、角色口头禅。
- 动作锚点：抬手、转身、落脚、撞击、开门、产品启动、眼神回头。
- 剪辑落点：切在动作开始、动作接触、动作结果、静音前或尾音后。
- 镜头运动：推、拉、跟、环绕、手持、定格、跳切，不跟音乐乱晃。
- 声音留白：关键情绪、笑点、打击点或反转前，音乐可以短暂抽掉。
- 记忆尾音：片尾留下一个能复述、能哼、能做系列的声音。

## 4. 导演判断

收到音乐驱动需求时，先这样判断：

```text
我会这样拍：这条片不能只是把画面剪快，音乐要决定动作落点。保留一个主节拍和一个记忆尾音，舍掉满屏乱切，第一刀先把每个关键动作卡到鼓点、停顿或尾音上。
```

必须先回答四个问题：

1. 音乐在这条片里负责抓人、推进、爆发还是记忆？
2. 主节拍是什么：鼓点、脚步、产品声、呼吸还是口头禅？
3. 哪个动作必须精准落点？
4. 哪一处需要静音或留白，让音乐别盖住戏？

## 5. 音乐功能卡

| 功能卡 | 适合 | 拍法 | 避免 |
| --- | --- | --- | --- |
| 鼓点卡 | 打斗、特效、燃向广告 | 打击、转身、爆发切在鼓点 | 每个鼓点都切，节奏疲劳 |
| 脚步卡 | 追逐、走秀、街头、校园 | 脚步成为节拍，镜头跟半步 | 脚步和剪点不一致 |
| 产品声卡 | 创意广告、种草 | 产品启动声变成音乐节拍 | 产品声被BGM盖掉 |
| 呼吸卡 | 情感、治愈、紧张 | 呼吸先于音乐，音乐轻进 | 大音乐压过表演 |
| 拍手卡 | 可爱、群像、舞蹈 | 群体动作分层进入 | 多人同时乱动 |
| 静音卡 | 悬疑、反转、喜剧 | 关键前抽掉音乐，留半秒 | 静音太长像故障 |
| 尾音卡 | 品牌、系列、MV结尾 | 固定尾音配固定动作 | 每集尾音变化太大 |

## 6. MV与舞蹈调度

MV感不是只有炫光和快剪。它要有“动作段落”和“情绪段落”的交替。

默认结构：

```text
音乐前奏 -> 角色入场 -> 第一组动作锚点 -> 反应/情绪停顿 -> 第二组动作升级 -> 静音或慢半拍 -> 记忆动作收口
```

舞蹈或律动镜头规则：

- 一镜只给一组主要动作，不让全身复杂编舞和大幅运镜同时发生。
- 先建立身体重心，再写手部、脚步、转身或队形变化。
- 群舞默认定中心角色，其他人只做同步小动作或背景律动。
- 关键动作要有起点、最高点和落点。
- Seedance 2.0 中不要要求复杂精确舞步；用“节奏清楚的简单动作组”替代。

## 7. 卡点剪辑表

卡点不是越密越好。默认把一条 15-60 秒短片分成三种点：

| 点位 | 功能 | 示例 |
| --- | --- | --- |
| S点 | 最重要的动作或情绪爆发 | 产品启动、拳头接触、主角回头、群像定格 |
| A点 | 推进信息或强化节奏 | 开门、落脚、道具出现、表情反应 |
| B点 | 过渡或氛围 | 空镜、灯光变化、手部小动作 |

剪辑规则：

- S点不超过3个，否则每个点都不重要。
- A点可以用跳切、匹配剪辑或动作剪辑。
- B点负责呼吸，不要全部卡死。
- 情感片和治愈片要允许音乐慢半拍，别把每个动作都剪成机械节奏。

## 8. 类型联动

| 类型 | 音乐用法 | 第一刀 |
| --- | --- | --- |
| 可爱搞笑 | 小音效、拍手、停顿、轻快尾音 | 先定误会前的半秒静音 |
| 治愈情感 | 呼吸、环境声、轻音乐、尾音留白 | 先保留动作后1秒环境声 |
| 特效打斗 | 低频、鼓点、静音、受力声 | 关键打击点抽掉音乐 |
| 创意广告 | 产品声、品牌短句、可哼记忆点 | 让产品声成为主节拍 |
| 短剧反转 | 台词前留白、反转后低频释放 | 避免音乐盖住关键台词 |
| 高概念短片 | 规则声、重复节拍、尾音变形 | 规则每升级一次，声音变化一次 |
| 纪实证言 | 环境声优先，音乐后退 | 采访台词不压音乐 |

## 9. Seedance 2.0 音乐驱动字段

音乐驱动提示词默认增加这些字段：

```text
音乐任务：
主节拍：
动作锚点：
剪辑落点：
镜头运动：
静音/留白点：
记忆尾音：
后期音乐版权：
禁止项：不要生成歌词字幕，不要复刻真实歌曲MV，不要复杂精确舞步，不要多人同时大幅动作，不要让音乐盖住台词
```

Seedance 2.0 提示词骨架：

```text
4-6秒视频镜头。风格锁定：[统一风格句]。
本镜是音乐驱动镜头，音乐任务是[抓人/推进/爆发/记忆]，主节拍来自[鼓点/脚步/产品声/呼吸/拍手]。
[角色/主体]从[动作起点]开始，完成[一个主要动作组]，动作最高点落在[节拍点]，动作结果落在[剪辑点]。
摄影机为[人称/身体化镜头卡]，运动克制，只服务动作节奏，不乱晃。
声音设计：[环境声/动作声]清楚，音乐在[进入/退出/静音点]处理，结尾保留[记忆尾音或动作声]。
可读歌词、字幕、品牌字和音乐标题后期添加；音乐方向为原创或已授权，不复刻真实歌曲和MV。
避免复杂精确舞步、多人同时大幅动作、长歌词字幕、音画不同步和角色造型漂移。
```

## 11. 自检

输出前自问：

1. 音乐任务是否明确，不只是“配个好听BGM”？
2. 主节拍是否能被动作、剪辑或产品声看见？
3. S点是否少而准？
4. 是否给动作起点、最高点和落点？
5. 是否有静音或留白，避免音乐压满？
6. 是否处理了真实歌曲、歌词、MV和版权边界？
7. Seedance 2.0 是否避免复杂精确舞步和多人同时大幅动作？
